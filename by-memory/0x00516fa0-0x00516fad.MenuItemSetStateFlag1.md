# 0x00516fa0-0x00516fad MenuItem Set State Flag 1

## Status

- Entity kind: raw class method-shaped helper.
- Owner: [UID:00007V][MenuItem](by-class/MenuItem.md).
- Likely source file: [UID:0000MN][PopupMenuControls](by-file/PopupMenuControls.md).

## Behavior

Stores the caller-provided byte argument into the second byte of the shared `MenuItem` state word at `this + 0x15`.

## Evidence

- IDA does not currently model this raw helper as a function, but disassembly at `0x00516fa0` is a complete function-shaped body:
  - prologue at `0x00516fa0`;
  - loads byte argument from `[ebp+8]`;
  - writes it to `[ecx+0x15]`;
  - returns with `retn 4` ending at `0x00516fad`.
- IDA `py_eval` byte review shows the surrounding alignment bytes are `0xcc` and that this body occupies the non-padding part of the earlier apparent gap.
- [UID:0002J5][0x00516f90-0x00516f94.MenuItemStateFlag1Accessor](by-memory/0x00516f90-0x00516f94.MenuItemStateFlag1Accessor.md) reads the same byte, and [UID:0002JA][0x005170f0-0x005171a2.StringMenuItemDrawItem](by-memory/0x005170f0-0x005171a2.StringMenuItemDrawItem.md) checks it for highlighted rendering.
