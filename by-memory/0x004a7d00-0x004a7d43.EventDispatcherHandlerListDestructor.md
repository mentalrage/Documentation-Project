## Behavior

This helper tears down the dispatcher handler/modal circular list wrapper that lives at `EventDispatcher + 0x20`. The scalar deleting destructor passes `Block + 8` dwords, proving the byte offset from the dispatcher object.

The live IDA decompilation shows the helper:

1. Treats `this + 0x00` as a sentinel/head pointer.
2. Reads the old first node from `head->next`.
3. Resets the sentinel to an empty circular list by writing `head->next = head` and `head->prev = head`.
4. Clears the wrapper count at `this + 0x04`.
5. If the old first node is not the sentinel, walks the old chain by saving each node's `next` pointer before freeing the current node.
6. Frees each old 12-byte list node through `sub_5C7526(node, 0x0c)`.
7. Frees the sentinel/head node itself through `sub_5C7526(head, 0x0c)`.
