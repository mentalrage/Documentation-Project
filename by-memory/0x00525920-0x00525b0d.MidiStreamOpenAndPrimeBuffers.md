# 0x00525920-0x00525b0d Midi Stream Open And Prime Buffers

## Status

- Confidence: strong for behavior and source family.
- Entity kind: internal MIDI helper function.
- Proposed owner: [UID:0000LD][MidiPlayer](by-file/MidiPlayer.md)
- Related callback: [UID:0001CG][0x00525be0-0x00525dbb.MidiStreamCallback](by-memory/0x00525be0-0x00525dbb.MidiStreamCallback.md)

## Behavior

This helper opens the WinMM MIDI stream and primes the two-buffer playback queue.

IDA MCP decompilation shows:

- Opens `hms` through `midiStreamOpen` when no stream is currently open, passing [UID:0001CG][0x00525be0-0x00525dbb.MidiStreamCallback](by-memory/0x00525be0-0x00525dbb.MidiStreamCallback.md) as the callback pointer.
- Allocates two `0x400` byte global-memory buffers and stores them in the two `MIDIHDR` slots.
- Opens/parses the current MIDI document from the selected destination filename through [UID:00023B][0x00526650-0x005270d5.MidiFileReaderAndSMFParserHelpers](by-memory/0x00526650-0x005270d5.MidiFileReaderAndSMFParserHelpers.md) and [UID:00023C][0x005271b0-0x005277bb.MidiSMFLoadAndStreamFillHelpers](by-memory/0x005271b0-0x005277bb.MidiSMFLoadAndStreamFillHelpers.md).
- Initializes the per-channel volume table.
- Sets MIDI stream time division through `midiStreamProperty`.
- Reads one or two chunks from the MIDI document into the prepared buffers.
- Calls `midiOutPrepareHeader` when headers are not already prepared.
- Submits buffers with `midiStreamOut`, tracks the active buffer index and pending buffer count, and marks headers as prepared.
- Cleans the MIDI document through [UID:0001CI][0x005270e0-0x005271a3.MidiDocumentRelease](by-memory/0x005270e0-0x005271a3.MidiDocumentRelease.md) on failure.
