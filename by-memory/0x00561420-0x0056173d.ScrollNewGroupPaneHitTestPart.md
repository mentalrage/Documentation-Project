## Behavior

The helper loops over scrollbar part ids, obtains the cursor and pane screen offset, computes the candidate part rectangle from the pane bounds and scroll state fields at offsets `0xfc-0x104`, and returns the first part containing the input point.

It handles both orientation modes:

- orientation byte at `this + 0xfc` selects the axis;
- current scroll position is read from `this + 0xfe`;
- max range is read from `this + 0x100`;
- thumb/track enabled state is read from `this + 0x102`;
- highlighted/active fields near `this + 0x103` and `this + 0x104` match the neighboring `ScrollNewGroupPane` methods.
