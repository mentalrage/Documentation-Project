## Behavior

`ScrollNewGroupPane::HitTestPart` loops over the five scrollbar part ids, computes the candidate rectangle for each id from the pane bounds and current scroll state, and returns the first part whose rectangle contains the supplied point. The supplied coordinate order follows the project `RectBounds` convention: `PointInRect(mouseY, mouseX, &rect)`.

The method also reads the live cursor position and pane screen offset inside the loop. The live cursor is converted to pane-local coordinates when the origin helper does not return the sentinel `(-1000, -1000)`. That local cursor is used for the vertical thumb-drag geometry path; the point actually tested is still the method's explicit `(mouseY, mouseX)` input.

Observed return values align with:

- `0`: leading end/edge part.
- `1`: page area before the thumb.
- `2`: thumb or disabled middle track.
- `3`: page area after the thumb.
- `4`: trailing end/edge part.
- `-1` / `0xff`: no part hit.

## Orientation Geometry

`m_orientation == 0` is the vertical branch:

- The fixed thumb span comes from `kScrollPanePartExtentBySkin[m_scrollSkinIndex]`, the one shared [UID:0003CQ][0x00624138-0x00624168.ScrollPaneScrollbarConstantData](by-memory/0x00624138-0x00624168.ScrollPaneScrollbarConstantData.md) `const int[3]` object `{38,38,38}` at `0x00624144`.
- Part `0` collapses the top edge by setting `bottom = top`.
- Part `4` collapses the bottom edge by setting `top = bottom`.
- When `m_scrollEnabled` is false or `m_scrollRange <= 0`, part `2` becomes the middle track with top/bottom end spans removed, while parts `1` and `3` are empty rectangles from `InitRectBounds(&rect, 0, 0, 0, 0)`.
- When enabled and ranged, part `2` is the thumb, part `1` is the page area before the thumb, and part `3` is the page area after the thumb.
- The `m_thumbDragActive` path exists only in this vertical branch for [UID:0001GQ]; it uses the live local cursor and `m_thumbDragOffset.y`, clamps the thumb top between the track start and `bottom - thumbSpan`, and then derives the candidate rectangles from the clamped thumb.

`m_orientation != 0` is the horizontal branch:

- The fixed thumb span is `m_bounds.bottom - m_bounds.top`.
- Part `0` collapses the left edge by setting `right = left`.
- Part `4` collapses the right edge by setting `left = right`.
- When `m_scrollEnabled` is false or `m_scrollRange <= 0`, part `2` becomes the middle track with left/right end spans removed, while parts `1` and `3` are empty rectangles.
- When enabled and ranged, the thumb position is derived from `m_scrollPosition` and `m_scrollRange`; the horizontal branch in this binary does not consult `m_thumbDragActive`.

This method duplicates the same part-rectangle geometry family as [UID:0001GR][0x00561740-0x005619c7.ScrollNewGroupPanePartRect](by-memory/0x00561740-0x005619c7.ScrollNewGroupPanePartRect.md) inline. It is not a call-through wrapper around `GetPartRect`.
