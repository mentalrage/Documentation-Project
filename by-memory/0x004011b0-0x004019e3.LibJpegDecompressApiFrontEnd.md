## Range Role

This range is the decompression application-interface front end from IJG libjpeg 6b. It is stock third-party code and should remain under `third_party/libjpeg/`, not under NexusTK image-loader source.

The product-owned callers are [UID:000175][0x004d05f0-0x004d0f4a.ImageDecodeWrappers](by-memory/0x004d05f0-0x004d0f4a.ImageDecodeWrappers.md), which use these routines to decode `JPF` portrait payloads and raw minimap JPEG blobs into RGB565 tile contexts.

The downstream decompression internals reached from this API are now split into focused source-file pages for the [UID:0000VR][0x00401b00-0x0040391f.LibJpegMarkerReader](by-memory/0x00401b00-0x0040391f.LibJpegMarkerReader.md), [UID:0000VV][0x00404a60-0x0040505b.LibJpegInputController](by-memory/0x00404a60-0x0040505b.LibJpegInputController.md), and [UID:0000VX][0x00405c80-0x004063c8.LibJpegDecompressMaster](by-memory/0x00405c80-0x004063c8.LibJpegDecompressMaster.md).

Live disassembly shows alignment at `0x004019e3-0x004019f0`, raw retained `jdapistd.c` code at `0x004019f0-0x00401af2`, alignment at `0x00401af3-0x00401b00`, then [UID:0000VR][0x00401b00-0x0040391f.LibJpegMarkerReader](by-memory/0x00401b00-0x0040391f.LibJpegMarkerReader.md).
