## Behavior

`MiniMapRenderer::BuildSymbolViews` uses this loader to read local `.mnm` minimap files. The loader keeps:

- a map path or file path wide string at offset `+0x00`;
- an expected map/version wide string at offset `+0x18`;
- a decoded payload pointer at offset `+0x30`;
- a payload length or file-body length at offset `+0x34`.

The load path seeks from file offset `0x42`, reads the stored UTF-16 version string at the file tail, compares it with the expected version string, and only allocates/reads the payload when the strings match and no payload is already loaded. The decode helper derives two one-byte XOR key streams from the path string and its reverse and applies them to the first 200 bytes of the loaded payload.

## Evidence

- `simroot_v2/class_MiniMapRenderer.cpp` contains raw-address wrappers named `ConstructMiniMapFileLoader_457620`, `DestroyMiniMapFileLoader_4576B0`, and `LoadMiniMapDocument_457850`, called from `MiniMapRenderer::BuildSymbolViews`.
- IDA MCP `callers` on 2026-05-27 reports `0x00457620`, `0x004576b0`, and `0x00457850` are each called only by `sub_4543F0`, the current `MiniMapRenderer::BuildSymbolViews` body.
- IDA MCP `decompile` on 2026-05-27 reports:
  - `0x00457620` initializes strings through `sub_421590` and literal tables `off_61093C` / `off_610968`;
  - `0x004576b0` frees the payload pointer and both wide-string buffers, with MSVC large-allocation validation;
  - `0x00457850` opens via `dword_69BE14`, uses `fseek`, `ftell`, `fread`, `wcscmp`, and calls `0x00457960`;
  - `0x00457960` creates forward/reverse key buffers and XORs up to 200 bytes of payload.
- IDA MCP byte checks show alignment padding at `0x00457613-0x00457620`, `0x004576a6-0x004576b0`, `0x00457953-0x00457960`, and `0x00457a5d-0x00457a60`.
- IDA does not currently define function objects at `0x00457760` or `0x00457780`, but linear decoding shows complete function-shaped code bodies ending with `retn` and `retn 4`; keep them as decoded helper bodies until a later xref/ownership pass proves they are dead, compiler-only, or reachable through indirect metadata.
