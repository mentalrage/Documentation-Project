## Behavior

`MiniMapRenderer::BuildSymbolViews` uses this loader to read local `.mnm` minimap files. The loader keeps:

- a map path or file path wide string at offset `+0x00`;
- an expected map/version wide string at offset `+0x18`;
- a decoded payload pointer at offset `+0x30`;
- a payload length or file-body length at offset `+0x34`.

The load path opens the caller-supplied `.mnm` path through `dword_69BE14` with binary-read mode, stores a computed payload length at `+0x34`, reads a UTF-16 version string sized from the expected-version length field at `+0x28`, compares it with the expected version string at `+0x18`, and only allocates/reads the payload when the strings match and no payload is already loaded. The decode helper derives two one-byte XOR key streams from the path string at `+0x00` and its reverse, then applies both streams to the first 200 bytes of the loaded payload or to the full payload when it is shorter.
