## Behavior

The function renders the horizontal progress bar using the inherited pane rectangle at object offset `0x44`. It reads the lower bound at object offset `0xf8`, current value at object offset `0xfa`, and upper bound at object offset `0xfc`. When the lower and upper bounds differ, it computes:

```text
split_x = rect.left + ((current - lower) * (rect.right - rect.left)) / (upper - lower)
```

When the range is degenerate, it uses the rectangle left edge as the split point. It then builds two temporary rectangles: the filled rectangle has its right edge replaced with `split_x`, and the empty rectangle has its left edge replaced with `split_x`. The function clears the byte at object offset `0x70`, sets draw color `1`, dispatches [UID:0000TN][SurfaceRenderCallbackTable](by-global/SurfaceRenderCallbackTable.md) callback slot `0x0069b3fc` for the filled rectangle, sets color `143` for the empty rectangle, dispatches the same callback for the empty rectangle, then sets color `128` and calls [UID:000168][0x004ba450-0x004ba53b.GrafPortDrawRectFrame](by-memory/0x004ba450-0x004ba53b.GrafPortDrawRectFrame.md) for the outer frame.
