## Behavior

The constructor creates the exchange alert dialog used by exchange cancel/ready/confirmation paths. It constructs the DialogPane base as `DialogPane(L"", -1, false)`, publishes or clears the active [UID:0000QV][g_pExchangeAlertPane](by-global/g_pExchangeAlertPane.md) singleton through `0x0069b330`, installs `ExchangeAlertPane` primary/secondary/tertiary vtable views, measures the message, clamps alert width according to button count, creates the static message text, optionally creates left and right text buttons, centers the alert over the parent pane, shows/focuses the pane, and stores the layout-reference pointer at primary offset `+0x26c` (`620` decimal, verified with `tools/int_convert.py`) as `m_layoutReference`.

The source-facing constructor signature inferred from all current callers is:

```cpp
ExchangeAlertPane::ExchangeAlertPane(const wchar_t *messageText,

```
