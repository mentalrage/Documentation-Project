# 0x00460e80-0x00460f09 Byte Span Add Rows

## Status

- Disposition: reconstructable NexusTK render/support code.
- Entity kind: free helper.
- Likely source file: [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) `SoftwareBlend16` or neighboring alpha-mask/span utility source.
- Confidence: strong for boundary, caller, and behavior.
- Rebuild handling: `source-authored`.

## Behavior

Adds source bytes into destination bytes row-by-row. It dispatches eight-byte blocks to the MMX `paddb` helper at `0x00461050` and handles the scalar tail with byte addition.
