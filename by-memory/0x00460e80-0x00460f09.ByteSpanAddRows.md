# 0x00460e80-0x00460f09 Byte Span Add Rows

## Status

- Disposition: reconstructable NexusTK render/support code.
- Entity kind: free helper.
- Likely source file: [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) `SoftwareBlend16` or neighboring alpha-mask/span utility source.
- Confidence: strong for exact boundary, sole caller, callee, block/tail split, row stepping, and wrapping byte-add behavior; medium-high for final source-facing helper name/signature.
- Rebuild handling: `source-authored`.

## Address Range

`0x00460e80-0x00460f09` (`sub_460E80`, size `0x89`, 63 decoded instructions).

The preceding `0x00460e79-0x00460e80` and following `0x00460f09-0x00460f10` bytes are alignment padding.

## Behavior

Adds source bytes into destination bytes row-by-row. The helper receives a source row pointer, source row pitch, destination row pointer, destination row pitch, byte width, and row count.

For each span it splits the width into `width / 8` eight-byte blocks and a `width % 8` scalar tail. When the block count is positive it calls [UID:00020H][0x00461050-0x0046109e.ByteSpanAdd8Blocks](by-memory/0x00461050-0x0046109e.ByteSpanAdd8Blocks.md), then advances both row pointers past the completed block bytes. It adds each remaining tail byte from source into destination with normal byte wrapping semantics and advances source/destination by their row pitches for each row.
