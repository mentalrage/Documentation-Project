## Behavior

The scalar deleting destructor delegates to the application cleanup/destructor body at `0x00463970`, then handles the MSVC deleting-destructor flag. If bit `1` is set and bit `4` is clear, it frees the object through project delete at `0x004f4ac0`; otherwise it returns the object pointer after cleanup.
