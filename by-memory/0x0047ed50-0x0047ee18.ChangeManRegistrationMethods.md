## Behavior Notes

`ChangeMan::Register` stores four fields into a local record before insertion:

| Offset | Source |
| --- | --- |
| `0x00` | owner pointer |
| `0x04` | listener pointer |
| `0x08` | `bool allMessages`: exact true matches all message types, exact false requires the message tag to match; bytes `+9..+0xb` are natural padding |
| `0x0c` | `MessageType messageType` |

`ChangeMan::UnregisterFiltered` uses the `LObject *owner` as the sorted-list key. Null `LObject *listener` works as a wildcard. `allMessages == true` is the all-message wildcard; `allMessages == false` requires the supplied `MessageType` to equal record offset `+0x0c`; invalid non-boolean byte values match neither branch. When a record is removed, the loop decrements the current index and count before continuing. Source-facing return type is `void`: no wrapper caller proves a consumed insert index, success flag, or removed-count contract.
