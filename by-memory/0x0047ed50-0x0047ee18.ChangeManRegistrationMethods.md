## Behavior Notes

`ChangeMan::Register` stores four fields into a local record before insertion:

| Offset | Source |
| --- | --- |
| `0x00` | owner pointer |
| `0x04` | listener pointer |
| `0x08` | scope/all-messages byte |
| `0x0c` | message type/filter value |

`ChangeMan::UnregisterFiltered` uses the owner pointer as the sorted-list key. Listener pointer `0` works as a wildcard, and scope byte `1` works as an all-message wildcard; otherwise it matches the message type against record offset `+0x0c`. When a record is removed, the loop decrements the current index and count before continuing.
