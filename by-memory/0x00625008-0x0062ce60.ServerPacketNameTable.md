## Summary

This `.rdata` span is a fixed-width UTF-16 server packet name/debug table. The main table runs from `0x00625008` to `0x0062ce08` as 256 entries with a `0x7e` byte stride, followed by three packet-format/support strings through `0x0062ce60`.
