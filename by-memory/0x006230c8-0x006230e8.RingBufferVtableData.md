# 0x006230c8-0x006230e8 RingBuffer Vtable Data

## Range

- Address range: `0x006230c8-0x006230e8`
- Entity kind: `vtable-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: the class declarations/destructors must be reconstructed; the vtable and complete-object-locator pointers are compiler-emitted from those declarations.

## Summary

This exact `.rdata` child contains the `RingBuffer` and `RingBufferIterator` complete-object-locator pointers and their three-slot primary vtables. It starts immediately after the right-click/vote menu string table and ends before the `ScreenPane` complete-object-locator pointer at `0x006230e8`.

## Reconstruction Notes

- This data should be generated by the compiler from the `RingBuffer` and `RingBufferIterator` class definitions and virtual destructors, not hand-ported as fixed-address bytes.
- `0x006230c8` belongs with `RingBuffer`, not with the preceding menu-pane string/data aggregate. The previous aggregate boundary at `0x006230cc` omitted the `RingBuffer` complete-object-locator pointer.
- The dword at `0x006230e8` is the next class's complete-object locator pointer for `ScreenPane` and is intentionally excluded from this child range.
