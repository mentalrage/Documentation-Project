## Summary

This corrected container replaces the legacy `0x006192c6-0x00619344.DecoderReadOnlyData` row. The old span mixed two zero terminator/boundary bytes after the AddEmployee alert string, the `Encoder` RTTI/vtable record, the `Decoder` RTTI/vtable record, six DAT parser constant vectors, and the first `Error` RTTI pointer. The `Error` prelude now belongs to [UID:0002ND][0x00619340-0x00619448.ErrorHierarchyVtableData](by-memory/0x00619340-0x00619448.ErrorHierarchyVtableData.md), so this page ends at exclusive `0x00619340`.

The page is a coverage/index container only. It should not emit source as one object because no single source owner covers AddEmployee string padding, BinaryCodec vtables, and DAT parser constants.

The BinaryCodec-owned interval ends at `0x006192e0`. The successor `0x006192e0-0x00619340` table belongs to `ParseEntries`, is referenced at `0x004a5e9e`, and remains excluded from BinaryCodec ownership and emission. This boundary is preserved even though the records are adjacent.
