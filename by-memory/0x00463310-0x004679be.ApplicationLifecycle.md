## Reconstruction Notes

- Keep this range attached to `app/Application.cpp` except for `BaramApp` if a later pass proves a separate `BaramApp.cpp`.
- `0x004671de-0x004671e5` is a thunk-sized item in Wave3's memory children and should be reviewed before naming.
- `Application::ValidateLicense` should stay in the app module because it uses app-local license fields and the embedded key.
- The current `GetVersionMajor` / `GetVersionMinor` labels are stale/provisional. `ValidateLicense` shows `this + 0x850` is a license/version-validation status code and `this + 0x842` stores `LOWORD(VS_FIXEDFILEINFO.dwFileVersionLS)`.
- `BuildExecutablePathForVersionInfo` and `GetExecutableVersionLowWord` are reconstructable but not autogen-attached yet because their final source placement crosses Application and diagnostics callers.
- `LoadIndexedDATSeries` should stay near `Application::Initialize` as a startup helper. It has no observed `this` parameter, so it should not be modeled as an `Application` method unless later evidence changes the calling convention.
- Keep crash-reporting implementation in [UID:0000J8][ExceptionHandler](by-file/ExceptionHandler.md) and deliberate crash trigger code in [UID:0000II][Crasher](by-file/Crasher.md). This lifecycle range proves startup/cleanup ownership, not final source-file containment.
