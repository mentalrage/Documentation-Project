# 0x0067a940-0x0067a980 PasswordGuardProtectedToken

## Summary

- Address range: `0x0067a940-0x0067a980`
- Entity kind: password guard static buffer
- Proposed name: `PasswordGuardProtectedToken`
- Disposition: reconstructable NexusTK global data
- Confidence: strong for address, size, and password-guard role

This 64-byte buffer stores a protected wide-character password token. The login path updates it from the submitted password, and later chat/input validation decodes/checks it to prevent accidental password disclosure.

## Layout

| Range | Current IDA name | Proposed source form |
| --- | --- | --- |
| `0x0067a940-0x0067a980` | `word_67A940` through `word_67A97E` | `wchar_t g_passwordGuardToken[32];` |

## Evidence

- `SetProtectedPasswordToken` at `0x004657d0` copies up to 32 wide characters into `word_67A940`, explicitly clears `word_67A97E`, and obfuscates the token in place.
- `ValidateChatInputOrThrowPasswordError` at `0x00465890` copies from `word_67A940`, decodes/checks the protected token, and throws `PasswordError` on a match.
- Existing [UID:0000YS][0x004657d0-0x00467406.PasswordGuardAndFatalError](by-memory/0x004657d0-0x00467406.PasswordGuardAndFatalError.md) documents the owning helper range and password-protection behavior.

## Reconstruction Notes

Keep this buffer with [UID:0000MG][PasswordGuard](by-file/PasswordGuard.md). It is not a UI text buffer; UI/login code only supplies the password value and consumes the validation result.
