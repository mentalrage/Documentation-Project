## Behavior

These helpers search ObjectList storage for a specific object pointer and return the same packed key format decoded by [UID:0002BA][0x00535b10-0x00535df0.ObjectListEncodedKeyAndRectHelpers](by-memory/0x00535b10-0x00535df0.ObjectListEncodedKeyAndRectHelpers.md). All functions return `-1` when the object is not present.

The direct-list helpers read a `List*` field from the ObjectList instance, iterate from `0` to `list->count - 1`, call the list accessor virtual at vtable slot `+0x10`, compare the first dword in the returned entry with the requested object pointer/id, and return the matching index with the category prefix for that list.

The row-list helpers first call `sub_5374D0(object, &scratch)` to derive the object's map row/coordinate data, build a padded map `RectBounds` through `sub_4B7C50`, select the row-list pointer at `rowDelta = objectRow - bounds.top`, and then run the same list scan. They encode both the row delta and matching list index into the returned key.
