# 0x00553b10-0x00553b55 Queue ReadSlot Raw

## Status

- Disposition: reconstructable NexusTK project code with raw-function boundary caveat
- Entity kind: raw method-shaped helper
- Owner class: [UID:0000BF][Queue](by-class/Queue.md)
- Likely source module: [UID:0000MW][Queue](by-file/Queue.md)
- Confidence: strong for behavior, class ownership, slot layout, and byte boundaries; medium-high for final method name because IDA still does not model the raw start as a function.

## Behavior

This helper reads one fixed-size record from the circular queue at `readIndex`. It computes `buffer + readIndex * slotSize`, copies `slotSize` bytes into the caller destination pointer, then advances `readIndex`, wrapping back to zero once it reaches `slotCount - 1`.

Layout evidence:

| Offset | Meaning |
| --- | --- |
| `+0x04` | slot byte size |
| `+0x08` | slot count/wrap limit |
| `+0x0c` | backing buffer |
| `+0x10` | read index |

## Boundary Notes

IDA does not currently model `0x00553b10` as a function and reports no direct xrefs to this raw start. The bytes are aligned, method-shaped, and end at `retn 4` at `0x00553b52`.

2026-06-01 IDA MCP byte review corrects the end-exclusive range to `0x00553b55` because the `retn 4` instruction at `0x00553b52` is three bytes (`c2 04 00`). The following `0x00553b55-0x00553b60` span is `0xcc` alignment padding before [UID:0001FR][0x00553b60-0x00553b6a.QueueIsEmptyRaw](by-memory/0x00553b60-0x00553b6a.QueueIsEmptyRaw.md).

## Evidence

- IDA MCP `lookup_funcs 0x00553b10` reports `Not a function`.
- IDA MCP raw `disasm 0x00553b10` shows slot copy through memory-manager copy helper `0x00516220`, read-index arithmetic, wrap to zero, and `retn 4`.
- `0x00553b16` calls `sub_516030`, then `0x00553b2e` calls [UID:0000L7][MemoryMan](by-file/MemoryMan.md)-owned copy helper `sub_516220` with destination argument, source `buffer + readIndex * slotSize`, and copy size `slotSize`.
- `0x00553b33-0x00553b4d` implements wrap handling: compare `slotCount - 1` against `readIndex`, store zero at `+0x10` when at/after the limit, otherwise store `readIndex + 1`.
- `xrefs_to` and `callers` still report no direct references to the raw start, matching the compact raw-helper treatment in the queue cluster.
- Current `source-3/simroot_v2/class_Queue.cpp` omits this helper.
