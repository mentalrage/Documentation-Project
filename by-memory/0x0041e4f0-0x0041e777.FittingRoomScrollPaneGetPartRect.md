## Behavior

Computes the output rectangle for a requested fitting-room scrollbar part. IDA decompiles the signature as `int __thiscall sub_41E4F0(int this, char part, int *outRect)`: the return value is an incidental register value, while the meaningful source result is the rectangle written through `outRect`.

The helper first reads the current cursor point through [UID:00028L][0x0067a754-0x0067a758.g_pEventMan](by-memory/0x0067a754-0x0067a758.g_pEventMan.md) / `sub_4A9090`, asks `sub_5447C0` for the pane-local offset, and subtracts that offset from the cursor point. If the offset helper returns the sentinel `(-1000, -1000)`, the function returns early without building a rectangle.

The part id uses the same convention as the hit-test, draw, and interaction helpers:

- `0`: leading arrow/end cap
- `1`: page area before thumb
- `2`: thumb
- `3`: page area after thumb
- `4`: trailing arrow/end cap

The method starts from the pane rectangle at `this + 0x44`, then branches on orientation byte `this + 0xfc`:

- the nonzero-orientation path builds horizontal part rectangles, using the current rectangle height as the fixed arrow/thumb span and current/range fields at `this + 0xfe` and `this + 0x100` when scrolling is enabled;
- the zero-orientation path builds vertical part rectangles, using `kFittingRoomScrollPartExtentBySkin[m_scrollSkinIndex]` as the fixed arrow/thumb span;
- vertical thumb calculation normally derives the thumb top from current/range, but when drag flag `this + 0xfb` is set it instead uses the converted cursor coordinate minus drag anchor `this + 0x108`, clamped to the available track;
- disabled or zero-range state collapses page-area rectangles for parts `1` and `3` through `sub_4B7C50(outRect, 0, 0, 0, 0)`;
- disabled or zero-range part `2` returns the middle track rectangle between the leading and trailing end-cap spans.

The table at `0x0060dc78` is resolved as the FittingRoom scroll-part extent table, best source name `kFittingRoomScrollPartExtentBySkin`. It contains exactly three dwords `{38, 38, 38}` and is indexed by the scroll-pane field at `+0xf8` (`m_scrollSkinIndex`). The apparent following dword is the RTTI complete-object-locator pointer for the adjacent vtable block and must not be modeled as table data.
