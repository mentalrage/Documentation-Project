## Behavior

Computes the rectangle for a requested scrollbar part. The part id uses the same convention as the hit-test and draw routines:

- `0`: leading arrow/end cap
- `1`: page area before thumb
- `2`: thumb
- `3`: page area after thumb
- `4`: trailing arrow/end cap

The method adjusts from pane-local coordinates through viewport/scroll offsets, then branches on orientation:

- horizontal orientation uses left/right span calculations and thumb width;
- vertical orientation uses top/bottom span calculations and thumb height;
- disabled or zero-range state collapses page-area rectangles to empty for parts `1` and `3`;
- part `2` returns the computed thumb rect, using current scroll value when range is positive.

`dword_60DC78[this + 0xf8]` provides the fixed arrow/thumb dimension for the current scroll skin/index.
