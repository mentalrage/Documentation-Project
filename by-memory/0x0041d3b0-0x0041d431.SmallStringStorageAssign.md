## Behavior

Copies a small-string storage object into another small-string storage object. The storage layout is the same 24-byte pattern used elsewhere in this binary:

- inline storage starts at offset `0`
- current length at offset `+0x10`
- capacity at offset `+0x14`
- capacity `< 0x10` means the bytes are stored inline
- capacity `>= 0x10` means offset `0` holds a heap pointer

The destination length and capacity fields are initialized to zero before the copy. If the source length is less than `0x10`, the helper copies the 16-byte inline buffer, stores the length, and sets destination capacity to `15`. If the source length is at least `0x10`, it allocates `((length | 0xF) + 1)` bytes through `0x0041b6e0`, copies `length + 1` bytes with `memmove`, stores the length, and stores the rounded capacity.
