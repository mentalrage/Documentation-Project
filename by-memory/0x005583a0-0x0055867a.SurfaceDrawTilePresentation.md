## Behavior

`sub_5583A0` saves `ecx` as the receiver and reads the single stack argument as a 16-bit frame/count value. If the count is non-positive, it skips the animation loop, resets presentation state, and calls sibling presentation helper `0x00557140`.

For each positive iteration, the helper:

- sets random shake offsets `this+0x59e = rand() % 10` and `this+0x5a0 = rand() % 40`;
- marks the presentation dirty flag at `this+0x59c = 1`;
- calls a DirectDraw-style virtual through [UID:0000QS][g_pDirectX](by-global/g_pDirectX.md) / `dword_67AB20`;
- branches on presentation mode `this+0x5a4`;
- redraws/synchronizes the active browser control when [UID:0000PO][g_activeBrowserControlPane](by-global/g_activeBrowserControlPane.md) is non-null;
- clears force-full-redraw flag `this+0x5b0`;
- decrements the frame counter and repeats.

Mode `1` is the traversal/clipped redraw path. It initializes a temporary region object, clears dirty flag `+0x59c`, calls [UID:0003A3][0x00559410-0x005595ca.ScreenPanePresentationTraversal](by-memory/0x00559410-0x005595ca.ScreenPanePresentationTraversal.md) / `ScreenPane::TraversePresentationList(Region *dirtyRegion)`, tests whether traversal set the dirty flag, clips the dirty rectangle against [UID:0000SU][g_screenWidth](by-global/g_screenWidth.md) and [UID:0000ST][g_screenHeight](by-global/g_screenHeight.md), optionally expands to the full screen when `+0x5b0` is set, calls [UID:0003A4][0x005595d0-0x00559a0f.BlitSurfaceToDisplay](by-memory/0x005595d0-0x00559a0f.BlitSurfaceToDisplay.md), then destroys the temporary region.

Modes `2` and `3` use the direct block-transfer path. The helper builds a full-screen rectangle from `g_screenWidth` and `g_screenHeight`, invokes a surface virtual on the active surface pointer at `this+0x18`, calls `UpdateSurfaceInfo` at `0x004b9820`, dispatches [UID:0000TN][SurfaceRenderCallbackTable](by-global/SurfaceRenderCallbackTable.md) slot 11 / `g_pfnTransferPixels` with the active mutable 16-bit pixel buffer, computed active-surface pixel count, and signed ordinal `m_fadeStep` at `this+0x5ac`, calls `EndPaint` at `0x004b98c0`, synchronizes the active browser pane if present, and blits to display. The callback return is ignored.

The exact slot contract is `SurfaceTransferPixelsProc`: `void (__cdecl *)(unsigned short *pixels, unsigned int pixelCount, int fadeStep)`. Under compat/RGB555 selection, [UID:0002YJ][0x004bee40-0x004c069e.SoftwareRenderCompatBlockTransferCallback](by-memory/0x004bee40-0x004c069e.SoftwareRenderCompatBlockTransferCallback.md) clamps the step to `0..24`, preserves step 0, applies the exact packed/scalar attenuation sequence, and clears at step 24. Under RGB565 selection, source-ready [UID:0002YO][0x004c4790-0x004c5fde.SoftwareRenderRgb565BlockTransferCallback](by-memory/0x004c4790-0x004c5fde.SoftwareRenderRgb565BlockTransferCallback.md) uses channel-safe masks `s1=(x>>4)&0x0841`, `s2=(x>>3)&0x18c3`, `s4=(x>>2)&0x39c7`, and `s8=(x>>1)&0x7bcf` across the same 25-step progression.

UID0002YO transforms packed pixel pairs and one final scalar pixel for odd counts, performs no internal clipping and no write for a zero count, preserves full intensity at step 0, and clears exactly `pixelCount * 2` bytes at step 24. Its intermediate formulas are `x-s1`, `x+s1-s2`, `x-s2`, `x-s1-s2`, `x+s1-s4`, `x-s4`, `x-s1-s4`, `x-s2-s4`, `x-s1-s2-s4`, `x+s1-2*s4`, `x+s1-s8`, `s1+s8`, `s8`, `s8-s1`, `2*s4-s1`, `s1+s2+s4`, `s2+s4`, `s1+s4`, `s4`, `s4-s1`, `s1+s2`, `s2`, and `s1`. This sharpens the callback dependency without resolving the retained helper's independent no-entry or Surface-versus-ScreenPane source-placement questions.

Other mode values skip the core presentation path and continue to browser redraw, force-redraw clear, and loop decrement. After the loop, final state reset sets `this+0x59c = 1`, zeroes `this+0x59e/+0x5a0`, calls the same DirectDraw-style virtual, and calls sibling [UID:00039P][0x00557140-0x00557377.SurfaceRenderPresentation](by-memory/0x00557140-0x00557377.SurfaceRenderPresentation.md).
