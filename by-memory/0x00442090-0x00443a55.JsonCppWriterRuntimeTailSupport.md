# JsonCpp Writer Runtime Tail Support

## Address Range

- `0x00442090-0x00443a55`
- Entity kind: mixed third-party/runtime support island.
- Disposition: ignored for NexusTK-owned reconstruction.
- Rebuild handling: `third-party/runtime` plus `compiler/linker-generated`.

## Summary

This range is the tail support area between JsonCpp valid writer keys and the LodePNG helper island. It contains MSVC/Dinkumware stream/string helpers, CRT runtime helpers, JsonCpp writer/string escaping and special-float formatting helpers, an embedded lookup/table block, and small startup/runtime glue. It should not be reconstructed as NexusTK product code.

The rebuilt project should keep JsonCpp writer behavior in the vendored JsonCpp source and let the compiler/runtime provide equivalent standard-library and CRT support code.

## Evidence

- Read-only IDA MCP `py_eval` on 2026-05-27 reports 40 modeled functions from `sub_442090` at `0x00442090` through `sub_443A30` ending at `0x00443a55`.
- Standard-library/runtime diagnostics and names in the range include `ios_base::badbit set`, `ios_base::failbit set`, `ios_base::eofbit set`, `iostream stream error`, `iostream`, `UserMathErrorFunction`, and local stdio initialization callers.
- JsonCpp writer evidence appears in `sub_443200` and `sub_4436C0`: strings include JSON escape fragments such as `\"`, `\\`, and formatting/special-value text such as `%%.%dg`, `NaN`, `null`, and `-Infinity`.
- IDA reports a non-function data/table block at `0x0044363b-0x004436c0` between `sub_443200` and `sub_4436C0`; bytes include code pointers into the surrounding helper and a compact byte table, consistent with a compiler-emitted switch/lookup table for writer formatting or escaping.
- Boundary check: `0x00442084-0x00442090` is twelve `0xcc` bytes after [UID:0000XD][0x00441d30-0x00442084.JsonCppValidWriterKeys](by-memory/0x00441d30-0x00442084.JsonCppValidWriterKeys.md); `0x00443a55-0x00443a60` is eleven `0xcc` bytes before [UID:0000XE][0x00443a60-0x00450c9f.LodePngHelperIslandInventory](by-memory/0x00443a60-0x00450c9f.LodePngHelperIslandInventory.md).
