## Address Range

`0x00490510-0x00490809`, ending before the exported start at `0x00490810`.

IDA does not currently model this start as a function, but live IDA disassembly decodes a normal stack-frame prologue at `0x00490510`.

## Behavior

This helper tokenizes a five-argument startup command line, accepts either a hostname or dotted IPv4 address, stores the resolved endpoint plus two trailing launcher strings into the startup-state block, and aborts on DNS or validation failure.

On success it writes the resolved IPv4 bytes to `param_1 + 0x2915b4`, the parsed port to `param_1 + 0x2916c4`, sets `param_1 + 0x2916ca` to `1`, sets state byte `param_1 + 0x28de28` to `5`, and converts two trailing wide arguments into multibyte strings at `0x28d9e0` and `0x28da20`.

## Evidence

- Legacy Wave2 report records `FUN_00490510` as `0x00490510 .. 0x00490808`, with no live Wave2 method/global resolution.
- IDA live disassembly shows calls to `GetCommandLineW`, `_wcstok_s`, `WideCharToMultiByte`, `gethostbyname`, `MessageBoxA`, `PostQuitMessage`, and `__loaddll`.
- IDA string inventory records `NWind` at `0x0061701c`, referenced from `0x004907e1` inside this helper.

## Reconstruction Notes

This remains a free launcher/network bootstrap helper. The two trailing payload strings should be named only after their consumers in the startup state are verified.
