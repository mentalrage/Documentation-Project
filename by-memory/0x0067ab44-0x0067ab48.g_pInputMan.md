# 0x0067ab44-0x0067ab48 g_pInputMan

## Summary

- Address range: `0x0067ab44-0x0067ab48`
- Entity kind: global pointer
- Proposed name: `g_pInputMan`
- Disposition: reconstructable NexusTK global data
- Confidence: very strong for address, singleton role, and source owner

This four-byte `.data` slot stores the active [UID:00006J][InputMan](by-class/InputMan.md) singleton used by Win32 input, IME handling, and higher-level UI event conversion.
