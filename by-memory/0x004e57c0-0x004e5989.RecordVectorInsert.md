## Behavior Details

- Treats `this` as a three-pointer vector header over `0x28`-byte records.
- If capacity remains, shifts the suffix and copies the inserted record into place.
- If growth is required, computes a larger capacity, allocates new storage, copies the prefix and suffix around the inserted record, frees the old storage, and updates begin/end/capacity pointers.
- Uses the shared `CopyRecordVector40Range` helper for record-range copies.
