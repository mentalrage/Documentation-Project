# 0x00623d58-0x00624184 Scroll Pane Read-Only Data

## Range

- Address range: `0x00623d58-0x00624184`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and scrollbar resource strings must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains the base scroll pane vtable family and inventory/group/collection/volume scroll pane variants. IDA MCP shows the range starts at the `ScrollPane` RTTI-adjacent word at `0x00623d58` and ends before the `SelfLookPane` RTTI-adjacent word at `0x00624184`.

## Evidence

- IDA MCP `py_eval` on 2026-06-01 reports vtables from `??_7ScrollPane@@6B@` through `??_7ScrollVolumePane@@6B@`.
- Vtable xrefs point to scroll-related executable ranges including `ScrollablePaneCore`, `ScrollSpellInventoryPane`, `ScrollNewGroupPaneCore`, `ScrollCollectionPane`, `ScrollInventoryPane`, and `ScrollVolumePane`.
- Start boundary: `0x00623d50` is `qword_623D50` and is referenced by ScreenEffecter code at `0x0055b3fa`; `0x00623d58` is the next RTTI-adjacent word and begins the `ScrollPane` read-only aggregate.
- Exact child boundary: `0x00623f18` begins the `ScrollNewGroupPane` vtable family; `0x00623fa0` is the RTTI-adjacent word before the `ScrollCollectionPane` primary table.
- End boundary: `0x00624184` is the RTTI-adjacent word immediately before `??_7SelfLookPane@@6B@` at `0x00624188`, whose constructor/destructor references are separate from this scroll-pane aggregate.

## Reconstruction Notes

- The base scroll classes should remain tied to the scroll bar/control source family.
- Specialized inventory/group/collection/volume scroll panes are physically adjacent in `.rdata`, but final source files should follow the feature-level pages when evidence is stronger.
- The `rbutt2.epf` string is preserved here as an adjacent resource literal until xrefs justify moving it to a more specific source module.
- Nested vtable child pages should be split when IDA evidence is strong enough. This page now delegates the exact `ScrollNewGroupPane` vtable family to [UID:0002OS][0x00623f18-0x00623fa0.ScrollNewGroupPaneVtableData](by-memory/0x00623f18-0x00623fa0.ScrollNewGroupPaneVtableData.md).
