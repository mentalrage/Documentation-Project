# 0x0066dee4-0x0066df00 Option Palette Static Resource Data

## Summary

- Address range: `0x0066dee4-0x0066df00`
- Entity kind: initialized resource pointer and mutable wide resource string
- Disposition: reconstructable project data
- Rebuild handling: source-declared/generated-binary static data
- Confidence: strong for consumers and contents; medium for final symbol names

This range contains an option-pane resource pointer and a mutable wide palette filename used by the palette library bootstrap.

## Layout

| Range | Current IDA name | Initial value | Notes |
| --- | --- | --- | --- |
| `0x0066dee4-0x0066dee8` | `off_66DEE4` | pointer to `0x00621264` | Points to the read-only wide `DLGOPT.EPD` option-pane resource string. |
| `0x0066dee8-0x0066df00` | `off_66DEE8` / `aPal_2` neighborhood | wide `SUPER0.PAL` | Mutable wide string probed by `PaletteLib::PaletteLib`; IDA names the middle of the string at `0x0066def4`. |

## Evidence

- IDA MCP xrefs to `0x0066dee4` come from `0x0053d89f`, `0x0053d8cb`, and `0x0053d8fd` inside [UID:0001DO][0x0053d820-0x0053e520.OptionPane](by-memory/0x0053d820-0x0053e520.OptionPane.md).
- IDA MCP xrefs to `0x0066dee8` and `0x0066def2` come from `0x00543a73`, `0x00543a78`, and `0x00543a92` inside [UID:0001E6][0x005431c0-0x0054445b.PaletteLib](by-memory/0x005431c0-0x0054445b.PaletteLib.md).
- Raw bytes decode as pointer `64 12 62 00` followed by UTF-16LE `SUPER0.PAL` and a terminating NUL.
- The string is writable `.data`, not read-only `.rdata`, so treat it as a source-declared mutable buffer or compiler-emitted writable literal copy.
