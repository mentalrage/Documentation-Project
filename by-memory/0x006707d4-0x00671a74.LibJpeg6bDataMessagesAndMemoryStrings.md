# 0x006707d4-0x00671a74 LibJpeg 6b Data Messages And Memory Strings

## Summary

- Address range: `0x006707d4-0x00671a74`
- Entity kind: third-party static diagnostic and memory-manager strings
- Disposition: reconstructable third-party static-embed data
- Rebuild handling: restored by compiling/linking IJG libjpeg 6b
- Confidence: strong

This range contains the writable `.data` copy of IJG libjpeg 6b diagnostic strings and memory-manager support strings. It belongs to the statically linked third-party JPEG library, not to NexusTK handwritten project logic, but it is reconstructable because the rebuilt executable must contain equivalent libjpeg static-embed data.
