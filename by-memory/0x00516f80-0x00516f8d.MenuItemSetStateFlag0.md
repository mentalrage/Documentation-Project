# 0x00516f80-0x00516f8d MenuItem Set State Flag 0

## Status

- Entity kind: raw class method-shaped helper.
- Owner: [UID:00007V][MenuItem](by-class/MenuItem.md).

## Behavior

Stores the caller-provided byte argument into the first byte of the shared `MenuItem` state word at `this + 0x14`.

## Evidence

- IDA does not currently model this raw helper as a function, but disassembly at `0x00516f80` is a complete function-shaped body:
  - prologue at `0x00516f80`;
  - loads byte argument from `[ebp+8]`;
  - writes it to `[ecx+0x14]`;
  - returns with `retn 4` ending at `0x00516f8d`.
- IDA `py_eval` byte review shows the surrounding alignment bytes are `0xcc` and that this body occupies the non-padding part of the earlier apparent gap.
