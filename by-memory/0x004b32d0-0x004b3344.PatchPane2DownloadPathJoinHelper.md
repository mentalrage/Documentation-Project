## Behavior

IDA decompilation shows a small three-argument helper:

- destination/output string object at argument 1;
- source string object pointer at argument 2;
- formatted suffix string object at argument 3.

The helper calls the shared string copy/construct helper at `0x00582a90`, asks `0x00584cf0` for the suffix length, then appends that suffix through `0x00584320`. In the only observed caller, this combines the selected PatchPane2 download base/path entry with the formatted `%d/%d/%s` request component before queueing the request on `g_pMiscWorkThread`.
