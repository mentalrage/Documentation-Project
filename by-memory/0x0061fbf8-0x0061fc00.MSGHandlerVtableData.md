## Heuristic and Inference Resolution

`sub_528DF0` is best treated as the MSVC scalar deleting destructor for `MSGHandler`, not as a handwritten ordinary method. The ordinary destructor body is `0x00528d80`; the scalar wrapper repeats handler restoration and conditionally calls the delete helper based on the delete flag.

`sub_528DD0` is best named `MSGHandler::DispatchMessage(MSG *message)`. Generic alternatives such as `HandleMessage` or `OnMessage` are plausible but weaker because the application message loop explicitly performs Win32 message dispatch through the active handler slot. Names implying a browser object or a generic target are rejected because the stored value is the previous application handler and Browser state lives in separate BrowserControlPaneOld fields.
