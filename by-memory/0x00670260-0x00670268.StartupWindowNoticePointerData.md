# 0x00670260-0x00670268 StartupWindow Notice Pointer Data

## Summary

- Address range: `0x00670260-0x00670268`
- Entity kind: initialized window string pointer pair
- Disposition: reconstructable project data
- Rebuild handling: source-declared/generated-binary static data
- Confidence: strong

This range stores the `StartupWindow` notice-window class and title string pointers used by the startup update/notice window creation paths.

## Layout

| Address | Current IDA name | Points to | Notes |
| --- | --- | --- | --- |
| `0x00670260` | `lpClassName` | `0x0062d418` / `"BaramNoticeWnd_Class"` | Notice window class name. |
| `0x00670264` | `lpWindowName` | `0x0062d430` / `"Notice"` | Notice window title. |

## Evidence

- IDA MCP xrefs to `lpClassName` come from `0x005808ac` in [UID:0001IO][0x005807d0-0x0058206e.StartupWindowUpdateCheck](by-memory/0x005807d0-0x0058206e.StartupWindowUpdateCheck.md) and a raw notice-window path at `0x005819e1`.
- IDA MCP xrefs to `lpWindowName` come from `0x00580ab1` in [UID:0001IO][0x005807d0-0x0058206e.StartupWindowUpdateCheck](by-memory/0x005807d0-0x0058206e.StartupWindowUpdateCheck.md) and a raw notice-window path at `0x00581b47`.
- The pointed-to strings are documented in [UID:00026K][0x0062d418-0x0062d5ac.StartupWindowReadOnlyData](by-memory/0x0062d418-0x0062d5ac.StartupWindowReadOnlyData.md), the `StartupWindow` read-only data span.

## Reconstruction Notes

Keep these pointers with [UID:0000O5][StartupWindow](by-file/StartupWindow.md). The string storage itself is `.rdata`, but the writable pointer slots are part of `.data` static initialization.
