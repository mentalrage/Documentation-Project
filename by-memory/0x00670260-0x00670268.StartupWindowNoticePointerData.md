# 0x00670260-0x00670268 StartupWindow Notice Pointer Data

## Summary

- Address range: `0x00670260-0x00670268`
- Entity kind: source-declared initialized ANSI string pointer pair
- Disposition: reconstructable file-static pointer objects; pointed literals and relocations are generated-binary consequences
- Rebuild handling: emit the exact two declarations through [UID:0000O5][StartupWindow](by-file/StartupWindow.md) at emitter position `0`, before every unpositioned consumer

This range stores the `StartupWindow` notice-window class and title string pointers used by the startup update/notice window creation paths. Both slots point into the StartupWindow read-only string span and are consumed by the notice-window registration/create code.

- Before this direct pass, blank emitter position placed UID000288 after both consumers in generated `StartupWindow.cpp`.
