# 0x006702c8-0x00670784 Rain Coordinate Tables

- Disposition: reconstructable NexusTK static data.
- Entity kind: weather-layer coordinate table blob.

## Covered Ranges

| Range | Proposed name | Element layout | Primary use |
| --- | --- | --- | --- |
| `0x006702c8-0x00670478` | `g_minimapRainStreaks` | Three frames, each with a 24-entry stride of `RainStreakCoord { short x, short y, short length }` | Target/minimap streak draw path. Each frame draws the first 18 entries and leaves six zero entries as stride padding. |
| `0x00670478-0x006704cc` | `g_minimapRainSplashSmall` | Three frames of seven `RainSplashCoord { short x, short y }` pairs | Target/minimap two-pixel splash marks. |
| `0x006704cc-0x006704d0` | padding | One zero coordinate pair | Alignment before the target/minimap large-splash table. |
| `0x006704d0-0x00670524` | `g_minimapRainSplashLarge` | Three frames of seven `RainSplashCoord` pairs | Target/minimap four-pixel splash marks. |
| `0x00670524-0x00670528` | padding | One zero coordinate pair | Alignment before the main-view streak table. |
| `0x00670528-0x006706d8` | `g_rainStreakCoords` | Three frames, each with a 24-entry stride of `RainStreakCoord` | Main-view streak draw path. Each frame draws the first 18 entries and leaves six zero entries as stride padding. |
| `0x006706d8-0x0067072c` | `g_rainSplashSmall` | Three frames of seven `RainSplashCoord` pairs | Main-view two-pixel splash marks. |
| `0x0067072c-0x00670730` | padding | One zero coordinate pair | Alignment before the main-view large-splash table. |
| `0x00670730-0x00670784` | `g_rainSplashLarge` | Three frames of seven `RainSplashCoord` pairs | Main-view four-pixel splash marks; this table ends exactly before the snow byte data. |

The last table is bounded at `0x00670784`. The following byte range belongs to [UID:0001OO][0x00670784-0x006707d0.SnowPatternByteTables](by-memory/0x00670784-0x006707d0.SnowPatternByteTables.md); live xrefs land at `0x00670785`, `0x00670788`, `0x0067078c`, and later snow entries, while `0x00670784` itself has no direct xref.

## Evidence

- 2026-06-06 live IDA xrefs confirm the target/minimap table starts are referenced only from `RainingLayerPane::DrawRainOnTarget` at `0x005c1810-0x005c1bc7`: streak base `0x006702c8`, small-splash base `0x00670478`, and large-splash base `0x006704d0`.
- 2026-06-06 live IDA xrefs confirm the main-view table starts are referenced only from `RainingLayerPane::OnPaint` at `0x005c1460-0x005c180c`: streak base `0x00670528`, small-splash base `0x006706d8`, and large-splash base `0x00670730`.
- Live decompilation of the two rain draw paths shows the same index formulas in both target and main-view paths: streaks use `3 * (entry + 24 * frame)` over 16-bit words, and splash marks use `2 * (entry + 7 * frame)` over 16-bit words.
- Live decompilation of the weather timer and rain constructor shows the rain frame byte at object offset `0x0f8` cycles modulo `3`, and the rain constructor stores the timer interval `120`; this proves the three-frame table interpretation.
- Live table audit reports both streak tables as `432` bytes, or `72` triples. For each of the three frames, entries `0..17` are drawn and entries `18..23` are zero padding triples.
- Live table audit reports the target/minimap small, target/minimap large, and main-view small splash ranges as `88` bytes: `21` used coordinate pairs plus one zero padding pair. The main-view large splash range is `84` bytes: exactly `21` used coordinate pairs ending at `0x00670784`.
- Boundary bytes at `0x00670778-0x00670790` are `61 00 f6 00 a1 00 e6 00 31 01 e6 00 00 32 64 00 04 03 00 00 00 0f 0f 00`; the last rain words before `0x00670784` decode as `(97, 246)`, `(161, 230)`, and `(305, 230)`, while bytes from `0x00670784` begin the snow-pattern data.

## Data Caveats

IDA has individual word items rather than typed arrays for these tables. Treat the names above as proposed reconstruction names derived from the owning rain draw paths and observed access patterns, not as finalized original symbol names.
