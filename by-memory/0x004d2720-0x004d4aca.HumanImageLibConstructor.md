## Behavior

`HumanImageLib::HumanImageLib` constructs the legacy human/equipment image-library singleton. The constructor:

1. Allocates a large stack frame through `__alloca_probe` and sets the MSVC exception-registration/security-cookie state.
2. Calls the `LObject` constructor at `0x004f4a80`.
3. Stores `this` into [UID:0000R5][g_pHumanImageLib](by-global/g_pHumanImageLib.md) at `0x0069b43c`, with a guard path that clears the singleton when the constructed subobject pointer is null.
4. Installs [UID:0001XQ][HumanImageLibVtable](by-type/by-vtable/HumanImageLibVtable.md) at object offset `+0x00`.
5. Initializes embedded `ProtectedArray` members for old-human part families with default capacity `10`.
6. Loads table files with DAT helpers, grows array storage as needed, and sets [UID:00029J][0x0069b420-0x0069b424.ImageLibraryLoadErrorFlag](by-memory/0x0069b420-0x0069b424.ImageLibraryLoadErrorFlag.md) on failed reads.
7. Loads old-human frame-table resources through [UID:0000UY][LoadImageFrameTable_004D0F50](by-item/LoadImageFrameTable_004D0F50.md).
8. Validates EPF frame counts against table-derived counts, shows a modal data-error message on mismatch, and exits through `_loaddll(0)`.
9. Parses `ACC2DRW.TBL` into accessory draw flags and `HAIRCOL.TBL` into hair-color entries.
10. Destroys all local `DATFile` objects before returning `this`.
