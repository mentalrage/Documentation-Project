## Behavior

This range is the modal quit confirmation implementation used by [UID:0001KP][0x005a94b0-0x005a95d2.QuitPromptLauncher](by-memory/0x005a94b0-0x005a95d2.QuitPromptLauncher.md) when the alert-style prompt is selected instead of the legacy typed [UID:0000BH][QuitInputPane](by-class/QuitInputPane.md) prompt. The split children now carry the exact source-bearing methods:

- the constructor builds an `AlertPane`-style Yes/No confirmation dialog using localized string id `3`;
- the key handler mirrors the button flow so `Y/y` confirms, `N/n` cancels, and unrelated keys fall back to inherited dialog handling;
- the switch-data child documents the compiler-lowered table/padding used by the key-handler switch;
- the primary/OK handler calls the same map teardown path used by other affirmative quit flows.
