## Behavior

This range implements the modal quit confirmation path used when [UID:0001KP][0x005a94b0-0x005a95d2.QuitPromptLauncher](by-memory/0x005a94b0-0x005a95d2.QuitPromptLauncher.md) chooses the alert-style prompt instead of the older typed [UID:0000BH][QuitInputPane](by-class/QuitInputPane.md) prompt.

The constructor belongs to the alert/dialog hierarchy: it creates a Yes/No confirmation dialog for the quit action and installs the `QuitDialog` virtual-method views. The key handler mirrors the button flow so `Y`/`y` confirms and `N`/`n` cancels; unrelated keys are delegated to the inherited dialog key handler rather than being consumed locally. The OK handler is intentionally tiny and routes to the same exit-to-menu helper used by other map/parcel teardown paths.
