## Behavior

All append helpers operate on the pointer-backed [UID:0001VQ][RefCountedStringBufferHeader](by-type/by-struct/RefCountedStringBufferHeader.md) model:

- `*this` / `m_data` is the character-data pointer.
- `data - 0x0c`, represented as `reinterpret_cast<int*>(data)[-3]`, is `refCount`; the fast append path accepts `1` and `-1`.
