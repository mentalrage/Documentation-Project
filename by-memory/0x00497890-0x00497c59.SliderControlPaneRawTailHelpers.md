## Raw Behavior

The island is part of the slider input/geometry tail.

`0x00497890-0x00497a98` computes slider part rectangles. It reads:

- orientation byte `this+0x108`;
- control bounds at `this+0x44`;
- active/enabled byte `this+0x101`;
- current value/range words around `this+0xfa` and `this+0xfc`;
- frame extent fields around `this+0x198` and `this+0x1a0`.

It switches on slider part ids such as `0x0d`, `0x0e`, `0x0f`, `0x10`, and `0x11` and writes the selected rectangle to the caller output pointer. For some track/thumb cases it calls `sub_4B7C30` to build a rectangle from computed origin/size.

`0x00497aa0-0x00497c29` handles active interaction/repeat geometry. It stores the incoming part id into byte `this+0x2f0`, performs thumb/track geometry from current value and range, initializes and reads the exact `Point m_dragOffset` at `this+0x2f4`/`this+0x2f8`, calls the modeled input processor `sub_497C60` at `0x00497bff`, and starts the repeat timer through `sub_5975E0(..., 200, ...)`.

`0x00497c30-0x00497c59` cancels the repeat timer through `sub_597600`, stores active part id `0x0a` at `this+0x2f0`, calls the owner/state virtual at slot `+0x48`, invalidates through vtable slot `+0x20`, and returns.
