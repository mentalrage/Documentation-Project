## Behavior Summary

The dialog initializes as a blank `DialogPane` with a forced-message background. In EPF asset mode it creates a larger centered layout with `DLGSTAFF.EPF`, `DLGSTAFF.PAL`, a read-only text edit pane, and Accept/Decline buttons. In EPD asset mode it creates a smaller fixed-position dialog with `DLGSTAFF.EPD`, `NPAL8.PAL`, and text-only content.

Accept preserves `m_bAccepted`, closes the dialog, and lets teardown restore the login dialog if the client is in the relevant EPF/login state. Decline clears `m_bAccepted`, closes the dialog, and calls the application exit helper.
