2026-06-03 IDA MCP reports `sub_478240` at this exact half-open range, size `0x62`. The predecessor `0x00478238-0x00478240` and successor `0x004782a2-0x004782b0` are `0xcc` alignment.

## Behavior

Handles predefined article dialog button clicks. Button id `0` reads the current board/session selection and calls `SubmitArticle` at `0x00478be0`, then restores the current dialog pointer in `dword_67A748 + 0x214` before closing/popping the dialog. Button id `1` forwards cancellation through the bulletin session helper at `0x004a10e0`.
