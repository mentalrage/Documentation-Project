## Behavior

The helper decodes a PNG file path into an `EPFTileContext`-style destination:

- passes the first stack argument to LodePNG file decoder front end `0x00443c40`;
- `0x00443c40` decompiles as a wrapper over `0x00443b80(..., 6, 8)`, matching `lodepng_decode32_file` / RGBA8 file decode behavior;
- initializes the destination through the `EPFTileContext` allocation helper at `0x00458490`, documented in [UID:0000XY][0x00457a60-0x00458610.EPFTileContext](by-memory/0x00457a60-0x00458610.EPFTileContext.md), using decoded width/height;
- converts each decoded RGBA pixel to RGB565 in the destination pixel plane;
- converts alpha as `32 - int(alpha / 255.0f * 32.0f)` into the destination mask/alpha plane;
- frees the decoded RGBA buffer through the CRT free wrapper;
- finalizes the destination through [UID:000200][0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels](by-memory/0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels.md).

## Callees

- `0x00443c40` LodePNG RGBA8 file decode front end.
- `0x00458490` `EPFTileContext` allocation helper from [UID:0000XY][0x00457a60-0x00458610.EPFTileContext](by-memory/0x00457a60-0x00458610.EPFTileContext.md).
- `__ftoui3` for float-to-integer alpha scaling.
- CRT free wrapper.
- [UID:000200][0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels](by-memory/0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels.md).
