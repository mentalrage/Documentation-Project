# 0x0061a45c-0x0061a5c4 FolderSelect/FolderTree Read-Only Data

## Range

- Address range: `0x0061a45c-0x0061a5c4`
- Entity kind: `vtable/table-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: `source-declared/generated-binary`

## Summary

This `.rdata` span contains `FolderSelectDialog`, `FolderTreePane`, and folder-tree template vtables/tables. It ends immediately before the already ignored `TREEICON.EPF` UTF-16 string data at `0x0061a5c4`.

## Observed Contents

- Vtables for `FolderSelectDialog` at `0x0061a45c`, `0x0061a4bc`, and `0x0061a4ec`.
- Small dword table labels at `0x0061a4f4` and `0x0061a4f8`.
- Vtables for `Tree<FolderTreePane::TreeElem>`, `TreeItor<FolderTreePane::TreeElem>`, and `FolderTreePane`.
- `FolderTreePane` primary and secondary vtable labels at `0x0061a518`, `0x0061a58c`, and `0x0061a5bc`.

## Evidence

- IDA MCP `py_eval` on 2026-05-28 lists the folder-select and folder-tree labels up to `??_7FolderTreePane@@6B@_1` at `0x0061a5bc`.
- The next bytes at `0x0061a5c4-0x0061a5dc` are separately documented in `-ignored.md` as `TREEICON.EPF` UTF-16 string data that generated tools can misread as virtual slots.
- This range connects directly to existing `FolderSelectDialog` and `FolderTreePane` code pages and the folder-tree template documentation.
