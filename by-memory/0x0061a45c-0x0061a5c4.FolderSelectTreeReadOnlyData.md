# 0x0061a45c-0x0061a5c4 FolderSelect/FolderTree Read-Only Data

## Range

- Address range: `0x0061a45c-0x0061a5c4`
- Entity kind: `vtable/string/table-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: `source-declared/generated-binary`
- Autogen status: intentionally unassigned. The span mixes [UID:0000JF][FolderSelectDialog](by-file/FolderSelectDialog.md) dialog vtables/drive-root string data with [UID:0000JG][FolderTreePane](by-file/FolderTreePane.md) tree-control/template vtables, and the direct candidate parents do not satisfy the corrected 85/85 child-and-parent assignment gate.

## Summary

This `.rdata` span contains `FolderSelectDialog` vtables, a local `X:\` drive-root literal, `Tree<FolderTreePane::TreeElem>`, `TreeItor<FolderTreePane::TreeElem>`, and `FolderTreePane` vtable data. It begins at the `FolderSelectDialog` primary vtable immediately after the `FieldMapPane` read-only-data span, and it ends immediately before the already ignored `TREEICON.EPF` UTF-16 string data at `0x0061a5c4`.
