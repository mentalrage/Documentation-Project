## Behavior

This paint method draws the old-layout icon strip. It starts at icon index `0` in full mode or `6` in reduced mode, draws 20-pixel-wide frames until the x position reaches `160`, and draws the selected pressed icon with frame `index + 8`.

The render assets are:

| Asset | Role |
| --- | --- |
| `ICONS.EPD` | icon strip frames |
| `NPAL7.PAL` | palette |
