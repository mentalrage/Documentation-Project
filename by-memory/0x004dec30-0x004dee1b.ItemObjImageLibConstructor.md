## Behavior

Constructs the process-wide item object image library used by item drawing paths. The constructor installs the `ItemObjImageLib` vtable, initializes the singleton storage, seeds the fallback item-info row, opens the item metadata table, grows the protected item-info array, and reads item metadata rows from either `ITEM.TBL` or the alternate `ITEM.TBD` path.

The class/file docs describe this as the owner of item-specific render table rows, legacy item-entry remapping, `ITEM.EPF` / `ITEM.EPD` frame use, palette slot `10`, and the item draw variants. This constructor is the startup loading side of that module.

## Constructor Flow Notes

1. Calls the base `LObject`-style initializer (`sub_4F4A80`) before installing class-owned state.
2. Sets the process singleton and class vtable, then initializes `ProtectedArray<ItemInfo>` in place at `this + 0x04`.
3. Builds the default/fallback row and opens the selected table resource path according to `g_useEpfAssets`.
4. Reads the row count and resizes the protected array to exactly that count, using 20-byte `ItemInfo` rows.
5. Reads every table row into stack storage and copies each row into the protected-array slot, with fallback-slot handling for out-of-range indexes.
6. Releases the local table/path object and returns the constructed object pointer.
