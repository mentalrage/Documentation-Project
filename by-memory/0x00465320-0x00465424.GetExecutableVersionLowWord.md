# 0x00465320-0x00465424 Get Executable Version Low Word

## Scope

- Range: `0x00465320-0x00465424`
- Entity kind: file-local helper function
- Likely owner file: [UID:0000HG][Application](by-file/Application.md)

## Behavior

Reads the current executable's version-resource root block and returns the low 16 bits of `VS_FIXEDFILEINFO.dwFileVersionLS`. If the version-resource size, load, or root query fails, it returns `0`.

Observed flow:

- calls [UID:0002JX][0x004651f0-0x004652dc.BuildExecutablePathForVersionInfo](by-memory/0x004651f0-0x004652dc.BuildExecutablePathForVersionInfo.md) to build the executable path;
- calls `GetFileVersionInfoSizeW`, allocates a temporary block, calls `GetFileVersionInfoW`, and queries the version root with `VerQueryValueW(block, L"\\", ...)`;
- reads `*(DWORD *)(fixedInfo + 0x14)`, which is `dwFileVersionLS`, and returns the low 16 bits due the function's `__int16` return type;
- frees the temporary block before returning.
