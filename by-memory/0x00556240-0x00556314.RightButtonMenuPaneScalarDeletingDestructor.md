# 0x00556240-0x00556314 - RightButtonMenuPane Scalar Deleting Destructor

## Status

- Confidence: strong.
- Proposed owner: [UID:0000C0][RightButtonMenuPane](by-class/RightButtonMenuPane.md).

## Behavior

The scalar deleting destructor:

- restores `RightButtonMenuPane` vtables;
- clears any highlighted target object held by the parcel/right-click state;
- removes and unregisters the pane;
- clears `g_pRightButtonMenuPane`;
- runs the pane/base destructor path;
- optionally frees the object when the scalar-delete flag is set.

## Evidence Notes

- IDA MCP confirms `0x00556240` as a 0xd4-byte function.
- This range intentionally excludes adjacent `VoteMenuPane` thunks at `0x00556228`/`0x00556233` and `VoteMenuPane` scalar deleting destructor at `0x00556320`.
