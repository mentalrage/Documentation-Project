## Layout Inferred

The parser fills a 560-byte reward entry:

| Offset | Size | Meaning |
| --- | ---: | --- |
| `+0x000` | 16 bytes | `wchar_t rankStart[8]` |
| `+0x010` | 16 bytes | `wchar_t rankEnd[8]` |
| `+0x020` | 512 bytes | `wchar_t symbolText[256]` |
| `+0x220` | 1 byte | symbol frame/index |
| `+0x221` | 1 byte | extra symbol/flag byte copied from packet |
| `+0x224` | 12 bytes | nested vector of 520-byte reward-item rows: begin/end/capacity |

Each reward item row is 520 bytes: 256 UTF-16 characters, a 32-bit quantity, a 16-bit icon id, and a one-byte palette/index.

`0x0045d7e0` parses one reward entry from a packet payload and returns the number of consumed bytes. It reads three length-prefixed multibyte strings, converts them through `MultiByteToWideChar`, stores rank-start, rank-end, and symbol text, then reads two one-byte fields and an item count. For each item it reads a length-prefixed name, a 32-bit quantity, a 16-bit icon id, and a one-byte palette/index, then appends a 520-byte item row to the reward entry's nested item vector.
