## Behavior

Rebuilds the fitting-room category button strip used by the preview/list view. The method removes an existing child `7` button if present, creates buttons for command/control IDs `7` through `16`, attaches them to the dialog, and invalidates the dialog bounds when finished.

The first button is labeled `UsableItems`. If the item catalog state at `this + 0x504` has no usable entries for category `0`, the method marks that button selected and stores `7` at `this + 0x788`. Other observed labels include `Mounts`, `Coats`, and `SpecialtySets`; the remaining labels are referenced through read-only string pointers near `off_60DBE4` through `off_60DC4C`.

Each button uses [UID:0002CW][0x0041d150-0x0041d284.FittingRoomControlBounds](by-memory/0x0041d150-0x0041d284.FittingRoomControlBounds.md) to compute its rectangle.
