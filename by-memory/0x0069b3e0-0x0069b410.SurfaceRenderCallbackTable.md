## Data Caveats

Generated source currently gives callsite-biased names to these slots. Examples include `g_uiTileRenderer`, `g_pfnBlitTileFrame`, `g_pfnBlitSprite`, `g_pfnBlitText`, `g_pfnLockSurface`, and composition-renderer aliases. Treat those names as provisional projections until each slot has a dedicated signature/name pass.

A 2026-05-25 IDA MCP recheck of `0x00499310` shows `dword_69B3FC(this, this + 68)`, while active `simroot_v2` emits `g_pfnLockSurface(drawSurface)`. Keep the generated one-argument call shape as suspect until callback slot 7 receives a signature pass.

IDA also reports writes near `0x0055874a` / `0x00558753` outside a named function in the current database. Those should be raw-disassembly reviewed before finalizing initialization/lifetime notes.
