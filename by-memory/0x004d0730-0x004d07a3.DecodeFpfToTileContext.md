## Behavior

This helper decodes a direct/raw `FPF` payload into an `EPFTileContext`-style tile context without the outer `ZPF` compression layer.

IDA MCP disassembly on 2026-06-03 shows the helper:

- clears/resets the destination tile context through `EPFTileContext::ReleaseBuffers` / raw `sub_458500`;
- validates FPF version word `1` at header offset `+0x04`;
- validates the `FPF` signature with `_strncmp`;
- allocates the destination tile context with width/height values from header offsets `+0x10` and `+0x12` through `EPFTileContext::AllocateRgb16Pixels` / `AllocateWordPixels` / raw `sub_458430`;
- computes the 16-bit pixel byte count from the destination context bounds;
- copies pixels from `header + *(uint32_t *)(header + 0x18)` into the destination pixel buffer with `_memmove`;
- tail-calls [UID:000200][0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels](by-memory/0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels.md) / `EPFTileContext::NormalizePostDecodePixels` on the success path.

The failure path restores registers and returns without finalization.
