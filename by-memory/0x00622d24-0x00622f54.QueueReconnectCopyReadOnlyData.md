# 0x00622d24-0x00622f54 Queue/Reconnect/Copy Read-Only Data

## Range

- Address range: `0x00622d24-0x00622f54`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and reconnect/copy-window string literals must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains the compact `Queue` vtable, `ConnectionClosedDialog`, `ReconnectDialog`, and `CopyWindow` vtables, plus short reconnect/copy-window UI strings. It ends before the `Region` complete-object locator at `0x00622f54`.

## Observed Contents

| Address | Item | Notes |
|---|---|---|
| `0x00622d24` | `Queue` vtable | Compact queue class table. |
| `0x00622d34-0x00622dcc` | `ConnectionClosedDialog` vtables | Three dialog vtable views. |
| `0x00622dd8-0x00622e70` | `ReconnectDialog` vtables | Three dialog vtable views. |
| `0x00622e7c-0x00622f14` | `CopyWindow` vtables | Three dialog/window vtable views. |
| `0x00622f20-0x00622f4c` | short UI strings | Includes `Ave`, `Connect`, `No`, and `Baram` string symbols. |

## Evidence

- IDA MCP `py_eval` on 2026-05-28 reports named vtables from `??_7Queue@@6B@` through `??_7CopyWindow@@6B@_1`.
- Vtable xrefs point to executable ranges `0x005539e0-0x00553c07` for `Queue` and `0x00553c10-0x00554635` for connection/reconnect/copy-window logic.
- Short string xrefs include reconnect/copy-window code at `0x00553ebb`, `0x005544c5`, and a `Baram` reference at `0x00554276`.
- The next named item at `0x00622f54` is `??_R4Region@@6B@`, the complete-object locator for the `Region` vtable documented in [UID:0002OP][0x00622f54-0x00622f64.RegionVtableData](by-memory/0x00622f54-0x00622f64.RegionVtableData.md).

## Reconstruction Notes

- Keep the `Queue` table tied to the queue utility module even though it is adjacent to UI dialog data.
- `ConnectionClosedDialog` and `ReconnectDialog` appear intentionally grouped under the reconnect dialog source file.
- `CopyWindow` has a separate file/class page but its read-only data is physically adjacent to reconnect dialog tables.
