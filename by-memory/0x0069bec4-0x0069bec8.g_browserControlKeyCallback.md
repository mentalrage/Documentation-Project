## Storage

`0x0069bec4-0x0069bec8` is the four-byte `.data` item IDA names `dword_69BEC4`.

Generated browser sources name it `g_browserControlKeyCallback` or `g_pTransportCallback` depending on context. Current IDA evidence shows those are callsite-biased aliases over the `SendMessageW` entry in the wide API dispatch table.
