## Behavior

This method is the crop-to-fit/scaled item draw path used by item menu and preview UI. It resolves the source frame, applies the legacy non-EPF item-entry remap and clamp policy when extended item archives are disabled, adjusts the source/destination rectangles for scaled drawing, prepares palette/render state, and dispatches the surface render callback without overlay mask output.

The method owns item-specific scaling/cropping policy. UI callers choose the destination rectangle, item id, and palette flags; the class method owns the item row lookup, legacy remap constants, EPF/EPD choice, palette slot `10` policy, and render callback dispatch.

## Callback Order And Options Evidence

The final dispatch sets `ecx` from `drawOwner` and pushes these six stack arguments, right-to-left:

```text
arg1: EPFTileContext *sourceContext
arg2: RectBounds *sourceRect
arg3: RectBounds *destinationRect
arg4: mode value, here 1
arg5: palette pointer returned by GetSlotPalette
arg6: const SurfaceSpriteBlitOptions *options
```

The target-local options block is a 32-byte stack area at `[ebp-0x5c]`. Disassembly writes only:

- `0x004df418`: byte `+0` = option kind `4`;
- `0x004df420`: byte `+0` = option kind `6` when `paletteFlags != 0`;
- `0x004df424`: byte `+8` = `paletteFlags` on the option-6 path;
- `0x004df42a-0x004df43c`: `lea eax, [ebp-0x5c]`, then push options, palette, mode `1`, destination rect, source rect, source context before calling slot 2.

A bounded search for `[ebp-0x40]` / `var_40` found no target write to options offset `+0x1c` before dispatch.

Installed slot-2 targets prove the final argument is a pointer when non-null. Compat target `0x004bc090-0x004bd3e8` tests the pointer, switches on byte `+0`, reads byte `+8`, and reads dword `+0x0c` on other option paths. RGB565 target `0x004c0f80-0x004c3123` tests the pointer, switches on byte `+0`, reads byte `+8`, reads dword `+0x0c`, and reads byte `+0x1c`; its option-kind-6 path reads `byte ptr [ebx+0x1c]` at `0x004c1eee`.

UID00041U uses option kind `6` but initializes only `+0` and conditionally `+8`; RGB565 option `6` reads `+0x1c`, so raw byte arrays, two-field structs, zero-init structs, partial-init structs, and scalar `int flags` would be decompiler-shaped or behavior-unsafe.

## Crop / Scale Rectangle Semantics

The target copies the tile context bounds into a local source rectangle, then crops the source around its center when either source dimension is larger than twice the destination dimension. Width is equivalent to:

```cpp
const int dstWidth = dstRect->right - dstRect->left;
const int sourceWidth = sourceRect.right - sourceRect.left;
if (sourceWidth > dstWidth * 2) {
    const int centeredLeft = ((sourceRect.left + sourceRect.right) / 2) - dstWidth;
    sourceRect.left = centeredLeft;
    sourceRect.right = centeredLeft + dstWidth * 2;
}
```

Height uses the same `top`/`bottom` pattern. The machine code implements midpoint division with `cdq; sub eax, edx; sar eax, 1`, matching signed truncation-toward-zero behavior.
