## Behavior

This virtual paint method draws the popup selector. It first calls two sibling virtuals, likely background and border drawing, then paints the six row labels:

- Talk/default text through `off_615364`.
- `aSh` for shout.
- `aWh` for whisper.
- `L"Group"`.
- `L"Clan"`.
- `L"-Color-"`.

Each label is drawn twice with a one-pixel x offset, matching the shadowed text style also used by the compact variety button.

If `this + 0xf9` is in the range `0..5`, it calls the row rectangle helper, then draws a two-color highlight frame. The highlight color order flips based on the pressed/captured byte at `this + 0xf8`.
