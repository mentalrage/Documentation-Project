# 0x00670268-0x00670294 String Buffer Sentinel Headers And Whitespace Pointer

## Summary

- Address range: `0x00670268-0x00670294`
- Entity kind: initialized string-buffer sentinels plus whitespace pointer
- Disposition: reconstructable project data
- Rebuild handling: source-declared/generated-binary string infrastructure data
- Confidence: strong for sentinel roles; medium for final source-facing names

This range contains the wide and ANSI empty-string sentinel headers used by the ref-counted string implementation, plus a pointer to a read-only whitespace string used by trimming/search helpers.

## Layout

| Range | Current IDA name | Role |
| --- | --- | --- |
| `0x00670268-0x00670278` | header before `Src` | Wide empty-string sentinel header/data prefix; includes `0xffffffff` refcount-style sentinel fields and the zero character at `0x00670274`. |
| `0x00670278-0x0067027c` | `Src` | Pointer to `0x00670274`, the empty wide string data. |
| `0x0067027c-0x00670280` | `off_67027C` | Pointer to `0x0062d5d8`, a read-only whitespace string. |
| `0x00670280-0x00670290` | header before `off_670290` | ANSI empty-string sentinel header/data prefix; includes `0xffffffff` and the zero byte/data area at `0x0067028c`. |
| `0x00670290-0x00670294` | `off_670290` | Pointer to `0x0067028c`, the empty ANSI string data. |

## Evidence

- [UID:0000TM][StringBufferSentinelsAndPools](by-global/StringBufferSentinelsAndPools.md) identifies `0x00670278` and `0x00670290` as the shared wide and ANSI empty-string sentinels.
- IDA MCP reports broad xrefs to `0x00670278` from string construction/allocation/release helpers in [UID:0001J1][0x00582500-0x00583206.LObjectStringConstructionAndCow](by-memory/0x00582500-0x00583206.LObjectStringConstructionAndCow.md) and [UID:0001J3][0x005832f0-0x00584d7e.LObjectStringReleaseFormatAndMutation](by-memory/0x005832f0-0x00584d7e.LObjectStringReleaseFormatAndMutation.md).
- IDA MCP reports broad xrefs to `0x00670290` from the ANSI construction/allocation/release helpers in the same string family.
- IDA MCP xrefs to `off_67027C` come from `0x00491a80`, `0x00491a92`, `0x0053f8a7`, `0x0053f8b6`, `0x00570d53`, `0x00570d68`, `0x00588aea`, and `0x00588aff`, all using a whitespace constant.
- The raw bytes match sentinel-style headers: `ff ff ff ff` followed by zero fields and data pointers.

## Reconstruction Notes

Keep the empty sentinels with [UID:0000OA][StringBase](by-file/StringBase.md) / [UID:0000OB][StringUtil](by-file/StringUtil.md) string infrastructure and cross-link [UID:0000MM][PoolAllocator](by-file/PoolAllocator.md) for pool allocation behavior. The whitespace pointer may become a local static in string trim/search helpers if source reconstruction proves a narrower owner.
