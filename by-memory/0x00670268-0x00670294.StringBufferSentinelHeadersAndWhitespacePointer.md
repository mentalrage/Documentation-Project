# 0x00670268-0x00670294 String Buffer Sentinel Headers And Whitespace Pointer

## Summary

- Address range: `0x00670268-0x00670294`
- Entity kind: initialized string-buffer sentinels plus whitespace pointer
- Disposition: reconstructable project data
- Rebuild handling: source-declared string infrastructure data
- Confidence: strong for contents, sentinel use, whitespace use, and boundaries; medium for final source-facing owner split

This range contains the wide and ANSI empty-string sentinel headers used by the ref-counted string implementation, plus a pointer to a UTF-16 whitespace string used by wide trim helpers.
