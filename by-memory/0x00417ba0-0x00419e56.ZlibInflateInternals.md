# zlib Inflate Internals `0x00417ba0-0x00419e56`

## Status

- Confidence: strong for zlib 1.1.4 source identity and source-file split.
- Proposed owner: [UID:0000PC][Zlib](by-file/Zlib.md)
- Parent range: [UID:0000W3][0x004142c0-0x00419e56.ZlibCore](by-memory/0x004142c0-0x00419e56.ZlibCore.md)
- Evidence basis: official `zlib-1.1.4.tar.gz` source staged under [UID:0001QX][README](by-meta/obtained_thirdparty_files/README.md), read-only IDA MCP lookup/decompile/callee checks on 2026-05-25, and existing `simroot_v2` recovered wrappers. `wave3.py` was not executed for this pass.

## Range Role

This range contains the non-public inflate implementation files from zlib 1.1.4: block-state management, Huffman code decoding, inflate tree construction, window flushing, and fast literal/length/distance decoding.

## Function Map

| Range | zlib 1.1.4 source | Role |
| --- | --- | --- |
| `0x00417ba0-0x00417c1b` | `infblock.c`: `inflate_blocks_reset` | Resets block decoder state and check/window cursors. |
| `0x00417c20-0x00417cbf` | `infblock.c`: `inflate_blocks_new` | Allocates block state, Huffman workspace, and sliding window. |
| `0x00417cc0-0x0041898d` | `infblock.c`: `inflate_blocks` | Main deflate block decoder for stored, fixed, and dynamic blocks. |
| `0x004189d0-0x00418a09` | `infblock.c`: `inflate_blocks_free` | Resets and frees block state/window/workspace. |

| `0x00418a50-0x004191ce` | `infcodes.c`: `inflate_codes` | Literal/length/distance Huffman decode state machine. |
| `0x00419200-0x00419214` | `infcodes.c`: `inflate_codes_free` | Frees the code decoder state. |
| `0x00419220-0x004192c3` | `inftrees.c`: `inflate_trees_bits` | Builds the bit-length Huffman tree. |

| `0x00419a90-0x00419e56` | `inffast.c`: `inflate_fast` | Fast Huffman decode loop used by `inflate_codes`. |

## Evidence

- The staged zlib 1.1.4 source places `inflate_blocks_reset`, `inflate_blocks_new`, `inflate_blocks`, and `inflate_blocks_free` together in `infblock.c`, matching the binary order from `0x00417ba0` through `0x004189d0`.
- IDA callees for `0x00417cc0` include `0x00419220`, `0x00419790`, `0x00419920`, `0x00418a10`, `0x00418a50`, `0x00419200`, and `0x00419950`, matching the stock `inflate_blocks` calls to tree builders, code decoder allocation/free, and flush.
- The staged source places `inflate_codes_new`, `inflate_codes`, and `inflate_codes_free` in `infcodes.c`; IDA callees for `0x00418a50` include `0x00419a90` and `0x00419950`, matching `inflate_codes` use of `inflate_fast` and `inflate_flush`.
- The staged source places `inflate_trees_bits`, `huft_build`, `inflate_trees_dynamic`, and `inflate_trees_fixed` in `inftrees.c`, matching the contiguous `0x00419220-0x0041994e` table-builder block.
- `0x00419950` and `0x00419a90` match the source-file tail split for `infutil.c` and `inffast.c`.

## Ownership Decision

Keep this full range under `third_party/zlib/`. These are stock zlib inflate internals and should not be assigned to DAT/resource loaders, image libraries, metadata validation, or render code.
