## Range Role

This range is `jinit_compress_master`, IJG libjpeg's compression-side module coordinator. It initializes the compression master-control, color conversion, downsampling, preprocessing, DCT, entropy, coefficient, main, and marker writer modules, then starts the first compression pass.

The range begins at `0x00406d90` and ends at `0x00406e46` half-open. The target itself starts exactly at `0x00406d90`; B014 proves `0x00406d8c-0x00406d8f` is marker-writer `write_tables_only` epilogue/return, not padding, so there is no gap after [UID:0000VZ][0x004064a0-0x00406d90.LibJpegMarkerWriter](by-memory/0x004064a0-0x00406d90.LibJpegMarkerWriter.md). The next documented range at `0x00406e50` is [UID:0000W1][0x00406e50-0x00406ed1.LibJpegNoBackingStoreMemoryBackend](by-memory/0x00406e50-0x00406ed1.LibJpegNoBackingStoreMemoryBackend.md), and live bytes show `0x00406e46-0x00406e50` is NOP padding between this target and the no-backing-store backend.
