## Behavior

Draws the fitting-room dialog background and chrome. The method loads fitting-room bitmap/resource pieces through the global resource manager at `dword_67A744`, marks the dialog draw-state byte at `this + 0x70`, computes an inner background rectangle from the dialog bounds at `this + 0x44` through `this + 0x50`, tiles the center area, then draws the top, bottom, left, right, and corner frame pieces.

The center fill is clipped to the dialog's inset content area:

- left = `bounds.left + 11`
- top = `bounds.top + 42`
- right = `bounds.right - 11`
- bottom = `bounds.bottom - 40`

If the loaded center tile has a non-positive width or height, the routine skips the tiling path and releases the temporary drawing resource. Otherwise it calculates horizontal and vertical tile counts, repeatedly draws the center tile, restores the previous draw state, and then draws the frame slices using resource indices `0` through `7`.

## Reconstructed C++ Candidate

```cpp
void FittingRoomDialog::DrawBackground()
{
    DrawResource center;
    DrawState savedState;

    LoadResource(g_resourceManager, kFittingRoomCenterResource, 0, center);
    m_drawStateByte = 1;

    Rect content = m_bounds;
    content.left += 11;
    content.top += 42;
    content.right -= 11;
    content.bottom -= 40;

    SaveDrawState(savedState);
    ClipToRect(content);

    const int tileWidth = center.Width();
    const int tileHeight = center.Height();
    if (tileWidth > 0 && tileHeight > 0) {
        for (int y = content.top; y < content.bottom; y += tileHeight) {
            for (int x = content.left; x < content.right; x += tileWidth) {
                DrawResourceTile(center, x, y, m_drawStateByte);
            }
        }

        RestoreDrawState(savedState);
        DrawFittingRoomFrame();
    }
}
```
