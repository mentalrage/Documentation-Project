## Behavior

This helper resolves and draws a riding/mount frame:

1. Uses the riding definition vector at `this+0x04/+0x08` and an input word transformed through `0x8000 + inputWord` to select the active riding definition.
2. Calls the shared bucket-entry lookup helper at `0x00528b10` to find frame/bucket metadata.
3. Loads a frame descriptor from `RIDINGS.EPF` through the shared frame lookup path using [UID:0000UY][LoadImageFrameTable_004D0F50](by-item/LoadImageFrameTable_004D0F50.md)-related state.
4. Applies render rectangle offsets through `0x004b7e10`.
5. Dispatches final composition through the sprite/composition callback table at `dword_69B3F0`.
6. Finishes through the stack-cookie check path, confirming this is compiler-emitted code from source rather than data or padding.
