## Behavior

This helper computes a scrollbar part rectangle into an output `RECT`-like four-integer buffer. The part argument uses the same codes as the hit-test and mouse-handler logic:

| Part | Meaning |
| --- | --- |
| `0` | leading/end-cap edge |
| `1` | track before the thumb |
| `2` | thumb or center track when no thumb exists |
| `3` | track after the thumb |
| `4` | trailing/end-cap edge |

It supports both orientations:

- orientation `0`: vertical scrollbar geometry with a fixed `38` pixel thumb height;
- nonzero orientation: horizontal scrollbar geometry where the control thickness becomes the thumb width.

When scrolling is enabled and the max position is positive, the thumb position is derived from the current position and max range. In vertical mode, active dragging instead uses the current mouse position and drag anchor (`this + 0x108`) clamped to the track. For parts `1` and `3` when no scrollable range exists, the helper returns an empty rectangle through `0x004b7c50`.
