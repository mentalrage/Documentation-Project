## Role

Refreshes the selected object after receiving an underscore-prefixed object-list payload. The virtual reads the payload pointer from `arg + 0x0c`, requires a leading `_`, reads the following count byte through `std::_Narrow_char_traits<char,int>::to_char_type`, then walks four-byte object-id entries starting at payload offset `2`. If the current saved object id in `dword_69BF28` is still present, the function returns without changing selection. If that id is absent, it clears the old highlight, falls back to the local player object from `dword_67A748`, writes that object's id from offset `0xfc` back to `dword_69BF28`, and highlights the local player object.
