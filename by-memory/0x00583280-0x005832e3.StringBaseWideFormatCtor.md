## Behavior

This function is a UTF-16 varargs initializer for the pointer-backed string layout. It starts a `va_list`, stores the wide empty-string sentinel pointer `0x00670278` into the destination object, then forwards the destination, wide format string, and argument list to the wide formatting worker at `0x00583840`. It returns the destination pointer after the worker completes.

IDA decompilation shape:

```text
va_start(va, Format);
*this = Src;
sub_583840(this, Format, va);
return this;
```

Observed calling shape:

```text
void **StringBaseWideFormatCtor(void **out, const wchar_t *format, ...);
```

The decompiler presents this as a varargs free/static helper rather than a `thiscall` method because the destination object is passed as the first stack argument.
