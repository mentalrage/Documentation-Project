# 0x006224c0-0x00622d24 Message Dialog Read-Only Data

## Range

- Address range: `0x006224c0-0x00622d24`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and dialog resource literals must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains the vtables and resource strings for the NPC/message dialog family: `MessageDialog`, `MessageDialogLarger`, menu-question dialogs and item-list variants, `HeadSelectDialog`, `TextDialog`, and the anonymous-namespace `NexonclubProxyDialog`. It ends at the `Queue` vtable boundary.

## Reconstruction Notes

- Keep the `dlgmsg*` strings with the dialog source modules unless later resource-manifest evidence proves they were centralized.
