## Behavior

This method reconciles a one-tile local-player movement step with the active `MapPane` viewport. The only direct caller is the `UserPane::OnTimer` FWdA movement path, which calls this helper after final local-player movement adjustment.

The method remaps the incoming direction through the shared living-object direction helper at `0x0053a6b0`, converts the remapped direction into a two-integer tile delta with [UID:00041W][0x00505080-0x00505100.MapPaneDirectionToTileOffset](by-memory/0x00505080-0x00505100.MapPaneDirectionToTileOffset.md), then scales that pair by [UID:0000T7][MapTilePixelDimensions](by-global/MapTilePixelDimensions.md). The scaled delta is passed to [UID:0001D3][0x00532530-0x00532f67.ObjectListAccessorsAndSweeps](by-memory/0x00532530-0x00532f67.ObjectListAccessorsAndSweeps.md)'s `ObjectList::ShiftAll` candidate so all tracked object panes move with the scrolled map.

After shifting object panes, it reads two coordinate pairs from the active local-player/living-object pane: a map/object coordinate pair through the scattered accessor at `0x005374d0`, and the cached viewport row/column pair through [UID:0002RW][0x005a2de0-0x005a2dfb.UserPaneGetViewportPosition](by-memory/0x005a2de0-0x005a2dfb.UserPaneGetViewportPosition.md). [UID:0002RW][0x005a2de0-0x005a2dfb.UserPaneGetViewportPosition](by-memory/0x005a2de0-0x005a2dfb.UserPaneGetViewportPosition.md) resolves that accessor's raw output order as row/y in element 0 and column/x in element 1. It then calls the tile/object-grid refresh helper in [UID:0001AT][0x00506970-0x0050e320.MapPaneInputPacketRenderCore](by-memory/0x00506970-0x0050e320.MapPaneInputPacketRenderCore.md) with the two coordinate pairs and the original direction byte.
