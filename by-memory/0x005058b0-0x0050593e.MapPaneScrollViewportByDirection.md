## Behavior

This method reconciles a one-tile local-player movement step with the active `MapPane` viewport. The only direct caller is the `UserPane::OnAnimationStep` movement path, which calls this helper after updating the local player and before the movement animation continues.

The method remaps the incoming direction through the shared living-object direction helper at `0x0053a6b0`, converts the remapped direction into a two-integer tile delta with the nearby direction-to-offset helper at `0x00505080`, then scales that pair by [UID:0000T7][MapTilePixelDimensions](by-global/MapTilePixelDimensions.md). The scaled delta is passed to [UID:0001D3][0x00532530-0x00532f67.ObjectListAccessorsAndSweeps](by-memory/0x00532530-0x00532f67.ObjectListAccessorsAndSweeps.md)'s `ObjectList::ShiftAll` candidate so all tracked object panes move with the scrolled map.

After shifting object panes, it reads two coordinate pairs from the active local-player/living-object pane: a map/object coordinate pair through the scattered accessor at `0x005374d0`, and the cached viewport position through [UID:0002RW][0x005a2de0-0x005a2dfb.LivingObjectPaneGetViewportPosition](by-memory/0x005a2de0-0x005a2dfb.LivingObjectPaneGetViewportPosition.md). It then calls the tile/object-grid refresh helper in [UID:0001AT][0x00506970-0x0050e320.MapPaneInputPacketRenderCore](by-memory/0x00506970-0x0050e320.MapPaneInputPacketRenderCore.md) with the two coordinate pairs and the original direction byte.

## Direction And State

| State or helper | Role |
| --- | --- |
| `0x0053a6b0` | Remaps direction bytes as `1 -> 3`, `2 -> 0`, `3 -> 1`, and default/other -> `2`, matching the living-object movement direction convention. |
| `0x00505080` | Converts a direction byte to a tile delta: north/south/east/west-like cases produce `(-1, 0)`, `(1, 0)`, `(0, 1)`, or `(0, -1)` in the helper's row/column pair, while invalid input becomes `(0, 0)`. |
| [UID:0000T7][MapTilePixelDimensions](by-global/MapTilePixelDimensions.md) | Scales the first delta component by the 48-pixel tile height and the second by the 48-pixel tile width before the object-list shift. |
| `MapPane +0x418` | Active/local object pointer consumed by the coordinate accessors. |
| `MapPane +0x424` | [UID:00009Q][ObjectList](by-class/ObjectList.md) pointer passed to the object-list shift helper. |
