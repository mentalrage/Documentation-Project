## Behavior

This helper destroys a three-pointer item-entry vector. If the begin pointer is null, it returns immediately. Otherwise it calls [UID:0002E0][0x004214d0-0x004214f7.FittingRoomDialogItemEntryRangeRelease](by-memory/0x004214d0-0x004214f7.FittingRoomDialogItemEntryRangeRelease.md) for the half-open begin/current range, computes the allocation size from a `0xb4` byte element stride, frees the backing storage, and clears the begin/current/capacity triple.

For allocation sizes below `0x1000`, the begin pointer is freed directly through the shared heap-free wrapper at `0x005c7526`. For larger allocations, the helper validates the stored allocation base immediately before the begin pointer, rejects front padding greater than `0x1f` through `_invalid_parameter_noinfo_noreturn`, adjusts the free size by the aligned-allocation header overhead, and then frees the stored base.
