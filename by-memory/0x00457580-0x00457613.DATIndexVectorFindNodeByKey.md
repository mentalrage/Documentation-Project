## Behavior

`DATIndexVector::FindNodeByKey` hashes the supplied four key bytes with FNV-1a, masks the hash by `bucketMask`, then scans the bucket range from `bucket.first` up to `bucket.last->next`. It returns the matching node when `node->key` equals the search key, otherwise it returns the list sentinel.
