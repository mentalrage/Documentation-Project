- Computes the scan stop as the sentinel when `bucket.last` is the sentinel, otherwise as `bucket.last->next`.
- Walks forward from `bucket.first` using `node->next` at offset `+0x00`.
- Compares the stored 32-bit node key at offset `+0x08` against the requested four-byte key.
