# 0x006125a8-0x00612f3c Application Startup Read-Only Data

## Summary

- Address range: `0x006125a8-0x00612f3c`
- Entity kind: project vtables and startup/resource string literals
- Disposition: reconstructable NexusTK project data
- Rebuild handling: `source-declared/generated-binary`
- Confidence: strong for Application ownership, medium for smaller helper owner names

This range contains `PasswordError`, `Application`, and `FunctionObject0` vtables plus startup diagnostics, OS-version strings, registry keys, DAT/resource paths, display-mode notice text, mutex names, error formatting strings, and patcher launch literals.
