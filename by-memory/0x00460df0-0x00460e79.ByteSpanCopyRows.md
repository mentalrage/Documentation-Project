# 0x00460df0-0x00460e79 Byte Span Copy Rows

## Status

- Disposition: reconstructable NexusTK render/support code.
- Entity kind: free helper.
- Likely source file: [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) `SoftwareBlend16` or neighboring alpha-mask/span utility source.
- Confidence: strong for exact boundary, sole caller, callee, block/tail split, row stepping, and scalar byte-copy behavior; medium-high for final source-facing helper name/signature.
- Rebuild handling: `source-authored`.

## Address Range

`0x00460df0-0x00460e79` (`sub_460DF0`, size `0x89`, 63 decoded instructions).

The preceding `0x00460dee-0x00460df0` and following `0x00460e79-0x00460e80` bytes are alignment padding.

## Behavior

Copies byte spans row-by-row. The helper receives a source row pointer, source row pitch, destination row pointer, destination row pitch, byte width, and row count.

For each span it splits the width into `width / 8` eight-byte blocks and a `width % 8` scalar tail. When the block count is positive it calls [UID:00020G][0x00461000-0x0046104b.ByteSpanCopy8Blocks](by-memory/0x00461000-0x0046104b.ByteSpanCopy8Blocks.md), then advances both row pointers past the copied block bytes. It copies the remaining tail bytes with a byte loop and advances source/destination by their row pitches for each row.
