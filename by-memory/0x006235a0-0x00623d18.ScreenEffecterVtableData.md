# 0x006235a0-0x00623d18 Screen Effecter Vtable Data

## Range

- Address range: `0x006235a0-0x00623d18`
- Entity kind: `vtable-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and virtual method shapes must be reconstructed; the concrete vtable bytes and complete-object-locator pointers are compiler-emitted from those declarations.

## Summary

This exact `.rdata` child contains the `ScreenEffecter` family complete-object-locator pointers and vtables, starting at the base `ScreenEffecter` COL pointer and ending immediately before the effect-resource string/constant tail. It excludes the preceding `ScreenDimmer`/`ScreenFadeOut` vtable island and the following `ScrollPane` COL pointer.

## Reconstruction Notes

- Treat this data as compiler output caused by the `render/Effects.cpp` class declarations and virtual method implementations, not as hand-authored fixed-address data.
- Overlay and filter subclasses have the same four-view shape used by pane-derived classes: primary view, embedded `Pane`-like view at `+0x04`, and two additional adjusted views at `+0xa4` and `+0xa8`.
- Several constructor starts remain raw/non-function-object in IDA, but the vtable stores and surrounding bytes make them source-owned constructor bodies rather than padding or third-party/runtime code.
