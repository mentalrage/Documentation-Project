## Summary

This helper grows or inserts into the 4-byte archive-index vector used by `MonsterImageLib::LoadMonsterArchives`. It is source-owned support code for `MonsterImageLib`, but final C++ remains blank because the exact source-level helper name and field names are not yet at the `95/95` reconstruction bar.

The working object shape is a three-pointer vector state: `begin`, `end`, and `capacity_end`. The helper computes the insertion index from `insertPos - begin`, allocates a larger 4-byte-entry buffer when needed, writes the supplied entry, moves the old prefix/suffix around the insertion point, replaces the vector storage through `0x004e6df0`, and returns the inserted element pointer in the updated storage.

## Behavior

- Computes the insertion index as `(insertPos - begin) >> 2`.
- Computes current length from `(end - begin) >> 2` and calls `0x00421500` on the `0x3fffffff` length limit.
- Chooses a new capacity using `capacity + capacity / 2` when it fits, clamping upward to the new length.
- Allocates 4-byte-entry storage through `0x00421520`.
- Writes `*entry` at the insertion index.
- Uses `_memmove_0` to copy either the whole old range for append-at-end or prefix and suffix ranges for middle insertion.
- Calls [UID:00022R][0x004e6ae0-0x004e70e9.ImageLibVectorSupportHelpers](by-memory/0x004e6ae0-0x004e70e9.ImageLibVectorSupportHelpers.md) helper `0x004e6df0` to replace/free the old vector storage.
- Returns `begin + insertion_index` after the storage replacement.
