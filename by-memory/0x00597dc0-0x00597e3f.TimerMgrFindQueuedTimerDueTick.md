## Behavior

Scans the embedded TimerMgr queue from newest logical entry backward, looking for a scheduled event whose owner pointer and event id match the two arguments. If a match is found, it returns the event's due tick. If no entry matches, it returns `0`.

The helper operates on the TimerMgr/TimerMgrTimerQueue layout where the queue slot array is reached through the embedded queue root, `this[4]` is the logical start index, and `this[5]` is the queue count. Each located queue record is a [UID:0001VX][ScheduledTimerEvent](by-type/by-struct/ScheduledTimerEvent.md): `record[0]` is owner, `record[1]` is event id, and `record[2]` is due tick.
