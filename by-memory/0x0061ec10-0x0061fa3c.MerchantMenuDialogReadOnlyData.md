# 0x0061ec10-0x0061fa3c Merchant/Menu Dialog Read-Only Data

## Range

- Address range: `0x0061ec10-0x0061fa3c`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and merchant/menu resource literals must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains merchant dialog, text menu, server/client item menu, spell menu, argumented item-input, and object-image control/button vtables plus merchant/menu resource strings. It ends before the `Message` vtable at `0x0061fa3c`.
