## Function

| Range | Current/proposed name | Notes |

| `0x004ba540-0x004ba6ad` | `CompositePixels16` | Clips a caller-supplied rectangle to the active GrafPort bounds, then walks the 16-bit pixel buffer. ## Evidence Notes

- IDA MCP lookup on 2026-05-25 reports `sub_4BA540` size `0x16d`.
- IDA MCP caller checks report three direct callers: [UID:0000HU][BowGaugeObjectPane](by-file/BowGaugeObjectPane.md) paint at `0x00538ce5`, [UID:0000ON][TextEditPane](by-file/TextEditPane.md) draw at `0x00590960`, and `TextEditPane::InvalidateTextRegion` at `0x005917a3`.
- IDA MCP decompilation shows the body reading GrafPort-like state: visible/enabled byte at `this + 0x71`, clip/bounds via `0x004b96c0`, stride at `this + 0x28`, pixel buffer at `this + 0x20`, origin fields at `this + 0x2c` and `this + 0x30`, and palette index at `this + 0x7c`.
- Callees are lower-level drawing/geometry support: `0x004b96c0` clip bounds, `0x004b7cc0` rectangle intersection, `0x004b7eb0` empty-rect test, `0x00543d40` palette lookup, and `0x00542ac0` palette-entry conversion.
- Local Ghidra bridge recheck on 2026-06-06 confirms export `004ba540.json`: address `0x004ba540`, size `365` (`0x16d`), `__thiscall` signature with a RECT-like `int *` argument, three unconditional callers (`0x00538c50`, `0x00590810`, `0x00591740`), and the same six callees including `__security_check_cookie`.
- Local Ghidra bridge `containing 0x004ba540` reports the function start at `0x004ba540` and the next function at `0x004ba6b0`; the documented exclusive end `0x004ba6ad` follows from the exported `0x16d` size, leaving a three-byte gap before the tiled-background helper.
- The decompiled loop computes the clipped width as `right - left`, height as `bottom - top`, and destination pointer as `pixelBuffer + (((top - originY) * stride - originX) + left) * 2`, then advances each row by `stride * 2`.
- The scalar tail writes the palette-derived color for zero 16-bit pixels and bitwise-inverts nonzero 16-bit pixels. The vector path processes eight 16-bit pixels per iteration with the same zero-pixel mask and nonzero-invert semantics.
