## Behavior

The body is a compact scalar-deleting destructor wrapper:

- `ecx` is the object pointer, saved in `esi`.
- It first calls `0x004f4a90`, the non-deleting `LObject` cleanup body.
- It reads the delete flags from `[ebp+8]`.
- If bit `0` is clear, it returns the object pointer without freeing.
- If bit `0` is set and bit `2` is clear, it calls `0x004f4ac0` to free the object storage, then returns the original pointer.
- If bit `2` is set, it takes the guard/no-op path through `0x0041b6a0` and returns without calling the delete wrapper.
