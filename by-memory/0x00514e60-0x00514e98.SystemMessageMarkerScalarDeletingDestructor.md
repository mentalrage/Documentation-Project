# 0x00514e60-0x00514e98 - System Message Marker Scalar Deleting Destructor

## Status

- Confidence: strong for function behavior and marker-message vtable use.
- Related file doc: [UID:0000OE][SystemMessagePanes](by-file/SystemMessagePanes.md)

## Covered Range

| Range | Behavior | Notes |
| --- | --- | --- |
| `0x00514e60-0x00514e98` | scalar deleting destructor | Calls `LObject` cleanup for a tiny marker object and conditionally deletes storage when scalar-delete flags allow. |

## Evidence Notes

- IDA MCP confirms the function at `0x00514e60` with size `0x38`.
