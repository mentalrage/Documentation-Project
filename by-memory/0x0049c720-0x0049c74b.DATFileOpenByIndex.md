# DATFile OpenByIndex

## Role And Evidence

Exact index-based opener at `[0x0049c720,0x0049c74b)`. It binds a caller-supplied mapped archive and row index, sets the absolute payload cursor, computes size from the following boundary row, and returns that size. It bypasses name lookup but uses the same packed-record semantics as Open.
