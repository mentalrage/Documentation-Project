## Behavior

Reads a one-byte multibyte string length, copies that many bytes from the Decoder input stream into a 260-byte stack scratch buffer, appends a byte NUL, converts the scratch bytes to UTF-16 with `MultiByteToWideChar(0, 0, ...)`, and writes a wide NUL terminator after the converted text. If the conversion produces more wide characters than caller capacity permits, the method clears the destination and invalidates the Decoder.

The method clears the output buffer and optional count on entry, checks valid flag `+0x11`, verifies the one-byte length and payload span fit inside input limit `+0x08`, advances cursor `+0x0c` after copying the multibyte payload, and writes optional `*outChars` to the number returned by `MultiByteToWideChar` when present.
