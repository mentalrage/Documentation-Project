# 0x00624138-0x00624168 ScrollPane Scrollbar Constant Data

## Range

- Address range: `0x00624138-0x00624168`
- Entity kind: `constant-data`
- Disposition: reconstructable source-declared constants.

## Summary

This exact child contains four source-declared three-entry `const int` arrays after the `ScrollVolumePane` vtable family and before the `SCRBUTT2.EPF` resource literal. Generic layout consumes all four. Generic and specialized scrollbar paint, hit-test, and part-rectangle code additionally share the current/classic part-extent arrays.
