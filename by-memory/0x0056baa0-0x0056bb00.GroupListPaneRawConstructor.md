## Behavior

The raw constructor uses `dword_67AB24`, calls the same setup helpers used by text-edit panes, then calls `sub_58DCE0` with the fixed viewport dimensions `0x91 x 0x54`, flags `0x80, 0, 0, 1, 6`, and the resource/context pointer returned by `sub_4B60B0`.

After base construction it installs:

| Object offset | Vtable |
| --- | --- |
| `+0x00` | `0x00624214` |
| `+0xa0` | `0x0062428c` |
| `+0xa4` | `0x006242bc` |

The constructor-shaped raw island exactly mirrors the inline child construction inside `GroupPane` (`0x0056c4c0`) and `GroupPane2` (`0x0056c770`): both allocate a `0x174`-byte child, call `sub_4B60B0`, call `sub_58DCE0` with the same `145, 84, 145, 84, 128, 0, 0, 1, 6, resource, 1, 0` argument pattern, install the same three `GroupListPane` vtables, store the child at parent dword `+0xf8`, enable it through `sub_5446B0`, and position/update it with `sub_58EA80`.
