## Behavior

This helper builds the multi-field clan-change request packet used by [UID:000027][ClanChangeInputDialog](by-class/ClanChangeInputDialog.md).

Observed packet layout:

```text
byte 0: opcode 0x4b
byte 1: clan subtype 10
byte 2: action 2
byte 3: byte length of first converted string
...     first converted ANSI string bytes
next:   byte length of second converted string
...     second converted ANSI string bytes
next:   byte length of third converted string
...     third converted ANSI string bytes
tail:   big-endian uint16 value
```

The three wide-string arguments are converted with `WideCharToMultiByte(CP_ACP, 0, ..., wcslen(...), localBuffer, 256, 0, 0)`. Each converted length must be below `0x100`; otherwise the compiler range-check failure path is used. The body writes scalar packet fields through [UID:0001HZ][0x00575380-0x00575abb.PacketBufferHelpers](by-memory/0x00575380-0x00575abb.PacketBufferHelpers.md), copies converted string payloads through [UID:0001BH][0x00516220-0x00516238.MemmoveWrapper](by-memory/0x00516220-0x00516238.MemmoveWrapper.md), and queues the completed packet through [UID:0001HU][0x00574bb0-0x00574c13.QueueAndSendPacket](by-memory/0x00574bb0-0x00574c13.QueueAndSendPacket.md) using [UID:0001P0][0x0067a7ec-0x0067a7f0.g_packetSender](by-memory/0x0067a7ec-0x0067a7f0.g_packetSender.md).
