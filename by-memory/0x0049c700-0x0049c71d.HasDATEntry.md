## Behavior

`HasDATEntry_49C700` checks whether the global [UID:0000QQ][g_pDATFileMgr](by-global/g_pDATFileMgr.md) can resolve a named DAT entry:

1. Reads `g_pDATFileMgr` storage at `0x0067ab40`.
2. Loads the inner `_DATFileMgr` pointer at offset `+0x04`.
3. Calls `_DATFileMgr::FindEntryByName(entryName, nullptr)` at `0x0049cad0`.
4. Returns true when the lookup result is non-null/nonzero.

It intentionally does not return the resolved archive container or entry index; it is an existence probe for higher-level resource loaders.
