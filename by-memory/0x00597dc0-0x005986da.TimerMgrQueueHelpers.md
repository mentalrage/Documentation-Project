## Behavior Notes

- `0x00597dc0` is not a generic container lookup. The only IDA caller currently found is `0x0050eb90`, which queries event id `2` for a `TimerHandler` subobject, compares the queued due tick with the current timer tick at `g_pTimerMgr + 0x18`, then cancels/reschedules through the normal `TimerMgr` helpers.
- `0x00597eb0` and `0x00597f20` operate on queue records by logical slot index and slot-capacity masks. The three-reverse pattern in `0x00597f20` matches a rotate primitive used to move newly inserted timer records without rebuilding the full queue.
- `0x005980f0` uses the same large-allocation convention as MSVC containers: allocations at or above `0x1000` bytes reserve extra space, align the returned pointer, and store the raw allocation pointer immediately before the aligned address.
- `0x00598290` and `0x00598480` operate directly on queue-local slot state. The code behavior is queue-local and should stay with `TimerMgrTimerQueue` declarations even if call sites are scheduler-facing.
- `0x00597fe0` and `0x00598090` show the lifecycle split: the embedded queue destructor releases queued records and slot/root allocations, while the TimerMgr scalar deleting destructor ends the multimedia timer period, destroys that queue, clears the singleton, and performs base cleanup.
