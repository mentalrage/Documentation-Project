## Behavior Notes

- `0x00597dc0` is not a generic container lookup. The only IDA caller currently found is `0x0050eb90`, which queries event id `2` for a `TimerHandler` subobject, compares the queued due tick with the current timer tick at `g_pTimerMgr + 0x18`, then cancels/reschedules through the normal `TimerMgr` helpers.
- `0x00597eb0` and `0x00597f20` operate on queue records by logical slot index and slot-capacity masks. The three-reverse pattern in `0x00597f20` matches a rotate primitive used to move newly inserted timer records without rebuilding the full queue.
- `0x005980f0` uses the same large-allocation convention as MSVC containers: allocations at or above `0x1000` bytes reserve extra space, align the returned pointer, and store the raw allocation pointer immediately before the aligned address.
- `0x00598290` and `0x00598480` operate directly on queue-local slot state. The code behavior is queue-local and should stay with `TimerMgrTimerQueue` declarations even if call sites are scheduler-facing.
- `0x00597fe0` and `0x00598090` show the lifecycle split: the embedded queue destructor releases queued records and slot/root allocations, while the TimerMgr scalar deleting destructor ends the multimedia timer period, destroys that queue, clears the singleton, and performs base cleanup.

## Source-Structure Decision

Keep this whole tail cluster in `util/TimerMgr.cpp` with [UID:0000F1][TimerMgr](by-class/TimerMgr.md), [UID:0000F2][TimerMgrTimerQueue](by-class/TimerMgrTimerQueue.md), and likely [UID:0000F0][TimerHandler](by-class/TimerHandler.md). The queue is an embedded scheduler-specific container, not a reusable STL-like project class. Do not move the queue helpers into caller modules such as UI panes, sound code, or map objects just because those callers schedule timers.

## Boundary and Decompiler Caveats

- IDA decompilation of the queue slots contains deep pointer chains from unrecovered iterator/container scaffolding. Treat the typed pointer noise as decompiler artifact; the stable fields are `slotEntries`, `slotCapacity`, `startIndex`, and `count`.
- 2026-05-31 IDA MCP split pass confirmed all child function starts/sizes through `lookup_funcs`, all caller sets through `callers`, and the intervening spans as `0xcc` alignment padding. No child page contains C++ reconstruction code because final helper names and exact source shape remain below the `95+` reconstruction gate.
- Do not merge this helper tail with [UID:0000P7][WaitableTimer](by-file/WaitableTimer.md) or [UID:0000OU][TimerPane](by-file/TimerPane.md). The tail ends at `0x005986d9`; `TimerPane` begins at `0x005986e0`, and WaitableTimer is a separate lower-level timer wrapper.
