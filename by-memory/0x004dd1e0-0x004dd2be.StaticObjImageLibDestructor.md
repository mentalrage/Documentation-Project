## Behavior

This is the ordinary non-deleting destructor for `StaticObjImageLib`. It cleans the static-object record table, the `TILEC` archive catalog, the tile-class table, and singleton state before delegating to the base `LObject` cleanup:

1. Restore the [UID:0001YX][StaticObjImageLibVtable](by-type/by-vtable/StaticObjImageLibVtable.md) at `this + 0x00`.
2. Call the small allocation/context helper at `0x00516030`.
3. If the static-object pointer table at `this + 0x0c` is non-null, iterate `this + 0x10` entries.
4. For each static-object record pointer, inspect its `+0x08` cache-chain pointer. If a chain is present, clear the record's `+0x08` link and free each chained node through `0x00516170`, following each node's `+0x08` next pointer. If the chain is absent, free the record pointer itself through `0x00516170`.
5. Free the static-object pointer table through `0x00516170`.
6. Load the tile-catalog/archive table pointer from `this + 0x04`, call `0x00516030`, free its payload pointer at catalog offset `+0x08` when present, then free the catalog object through `0x00516170`.
7. Free the tile-class table at `this + 0x08` through `j_j_j___free_base` at `0x005c7799`.
8. Clear [UID:0000SD][g_pStaticObjImageLib](by-global/g_pStaticObjImageLib.md) at `0x0069b448`.
9. Call the base `LObject` cleanup at `0x004f4a90`.

Unlike the scalar deleting destructor at `0x004e6990`, this body does not test delete flags or call `operator delete(this)`.
