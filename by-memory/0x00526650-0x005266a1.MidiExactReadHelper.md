## Behavior

Reads an exact caller-requested byte count from the private MIDI document source. If `document->datFileSource` / `this + 0x14` is set, the helper reads through the embedded `DATFile` member at `this + 0x18` using its virtual read slot `+0x20`. Otherwise it reads from the Win32 file handle at `this + 0x2c` through `ReadFile`.

The helper reports failure when the read call itself fails or when the resulting byte count does not match the requested length. The DATFile branch seeds the local byte count to the requested length before dispatch because that branch has no separate `ReadFile` out-count write.
