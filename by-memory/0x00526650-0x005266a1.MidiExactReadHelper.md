## Address Range

`0x00526650-0x005266a1`.

IDA models this exact range as `sub_526650`, size `0x51`.

## Behavior

Reads an exact caller-requested byte count from the MIDI document source. If the document is using the object/memory-backed adapter at `this + 0x18`, it dispatches through that adapter. Otherwise it reads from the Win32 file handle at `this + 0x2c` through `ReadFile`.

The helper reports failure when the read cannot produce the requested byte count.

- IDA `lookup_funcs` confirms `sub_526650` at `0x00526650-0x005266a1`.

- IDA live disassembly shows a direct data/call reference to imported `ReadFile` at `0x0052667d`.
- Parent page analysis records the short-read failure behavior and the adapter/file dual-source design.
