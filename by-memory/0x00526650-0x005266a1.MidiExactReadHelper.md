## Behavior

Reads an exact caller-requested byte count from the MIDI document source. If the document is using the object/memory-backed adapter at `this + 0x18`, it dispatches through that adapter. Otherwise it reads from the Win32 file handle at `this + 0x2c` through `ReadFile`.

The helper reports failure when the read cannot produce the requested byte count.
