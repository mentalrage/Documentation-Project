# JsonCpp Legacy Reader Raw Lexical Helpers `0x0042acdf-0x0042ae90`

## Status

- Disposition: ignored for NexusTK source reconstruction.
- Entity kind: raw/unmodeled third-party JsonCpp lexer helper code plus alignment padding.
- Likely owner: [UID:0000KI][JsonCpp](by-file/JsonCpp.md), legacy `Json::Reader` support in `json_reader.cpp`.
- Confidence: strong for JsonCpp ownership and non-product disposition; medium for final per-function names because IDA has not modeled these as functions.

## Range Role

This range sits between the [UID:0000X0][0x004298f0-0x0042acdf.JsonCppDocumentParseFrontEnds](by-memory/0x004298f0-0x0042acdf.JsonCppDocumentParseFrontEnds.md) and the first modeled [UID:0000X2][0x0042ae90-0x0042edeb.JsonCppReaderBuilderIsland](by-memory/0x0042ae90-0x0042edeb.JsonCppReaderBuilderIsland.md). IDA does not currently create function objects or external caller xrefs for the code starts in this span, but the disassembly matches JsonCpp legacy `Json::Reader` lexical helpers from the staged `b299d3581f4dc670734f1fe1a34fce1282337802` source snapshot.

The observed helpers advance `current_`/`end_`-style pointers, scan C-style comments, C++-style comments, double-quoted strings, and numeric tokens, then return boolean scanner success where the upstream helper does.

## Evidence

- IDA MCP `lookup_funcs` reports `sub_42AB40` ending at `0x0042acdf`, no function objects at `0x0042ace0`, `0x0042ad30`, `0x0042ad70`, or `0x0042adb0`, and the next modeled function `sub_42AE90` starting at `0x0042ae90`.
- IDA MCP byte/disassembly audit shows the span is executable code separated by `0xcc` alignment, not empty padding.
- `0x0042ace0` scans until `'*'` followed by `'/'`, then returns whether `'/'` was consumed, matching `Json::Reader::readCStyleComment()`.
- `0x0042ad30` scans until LF or CR, consumes optional CRLF, and returns true, matching `Json::Reader::readCppStyleComment()`.
- `0x0042ad70` scans through backslash escapes until a closing double quote and returns whether the terminator was found, matching `Json::Reader::readString()`.
- `0x0042adb0` scans decimal digits, an optional fractional portion, and an optional exponent with `+`/`-`, matching `Json::Reader::readNumber()`.
- Source comparison: the staged JsonCpp file `src/lib_json/json_reader.cpp` contains these legacy `Reader` helpers near lines 403, 412, 428, and 450 in the same behavioral family.
- IDA caller checks for the raw helper starts currently return no external callers. Treat that as an IDA modeling caveat, not product ownership evidence.
