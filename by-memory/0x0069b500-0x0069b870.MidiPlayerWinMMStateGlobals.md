## Covered Data

This range stores the WinMM MIDI stream handle, prepared MIDI header buffers, reset/playback coordination state, static MIDI document storage beginning at `0x0069b828`, and the adjacent static string/storage tail through `0x0069b86f`.

Important anchors include:

| Address | Current IDA name | Role |
| --- | --- | --- |
| `0x0069b500` | `hms` | WinMM MIDI stream handle. |
| `0x0069b504` | `puDeviceID` | MIDI stream open device-id storage. |
| `0x0069b508-0x0069b83f` | multiple `dword_69B...` names | Buffer/header, playback, and document state documented in the global MIDI page. |
| `0x0069b840-0x0069b86f` | `dword_69B840` and tail storage | Static string/object storage cleaned by the MIDI static destructor wrapper. |
