## Behavior

This helper handles server responses for the older `OptionPane` dialog.

- Payload byte `0x21` (`'!'`) opens a localized alert/dialog using string/resource id `61` and a dialog allocation size of `624`.
- Payload byte `0x23` (`'#'`) copies five option bytes from payload offsets `+1..+5` into the old pane fields at `this + 0x1cc..0x1d0`.
- After storing those bytes, it updates option controls `5`, `4`, `7`, `8`, and `3` by fetching controls from the dialog child list and calling the radio/check helper at `0x00496110`.
