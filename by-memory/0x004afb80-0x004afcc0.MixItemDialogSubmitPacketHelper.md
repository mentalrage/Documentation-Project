## Behavior

The helper builds a variable-length mix packet:

1. Reads the selected mix-list row storage from `this + 0x1fc`, child selector `5`, row storage offset `+0x108`.
2. Gets the row count through the list count helper at `0x004f3bd0`.
3. If the count is positive, writes opcode byte `0x6b`.
4. Writes the selected-row count as a single byte.
5. Iterates rows through the list item-by-index helper at `0x004f3dc0`, writes each row item id byte from row `+0x00`, and conditionally appends one quantity byte from row `+0x208` when item metadata offset `+0x1ec` is set.
6. Sends only the accumulated packet length through `g_packetSender` / `QueueAndSendPacket`; the helper does not include the spare zero bytes left by scalar packet byte writers.
7. Calls close/dismiss helpers `0x0049eb90` and `0x0049dad0`.

If the count is `<= 0`, packet construction and send are skipped but the same close/dismiss pair still runs. The body has no local row-count or quantity range guard; any cap is enforced by the list/UI construction and selection flow outside this helper.
