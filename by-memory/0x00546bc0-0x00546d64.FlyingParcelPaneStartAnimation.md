## Signature Notes

Observed calling shape is `thiscall` with four stack arguments and no meaningful return value. The first argument is stored as a byte at `this+0xf9`; the next two byte arguments are stored at `this+0xfb` and `this+0xfa`; the fourth byte/flag is stored at `this+0xfc` and also selects parcel-versus-letter screen rectangles.

## Behavior

Starts a flying parcel/letter animation. It removes or detaches the current helper object from the layer/manager, stores the animation payload fields, builds the screen rectangle for either the old rendering mode or the normal mode, refreshes/positions the pane and owned helper, invalidates the pane rectangle, then schedules the tertiary timer handler at `this+0xa4`.

Two rendering-mode branches are present:

- When `byte_66DA97 == 1`, the method calls `sub_57A5C0(dword_67A7D0, 200, 100)`, detaches the helper through `sub_556CE0(dword_67A7CC, this+0x100, 0)`, chooses one of two hard-coded rectangle groups around `0x276..0x2eb`, increments `this+0xac` by `0x1e`, and schedules a `100` ms timer.
- Otherwise, it detaches the helper through `sub_556CE0`, builds a smaller rectangle based on the first byte argument with a fallback when the value is greater than `4`, and schedules a `10` ms timer.
