## Behavior

`Thread::DispatchRequest(int messageId, int arg1, int arg2)` packs a 24-byte `ThreadMessage` with no result event, enqueues it through `m_messageQueue`, releases the primary wake semaphore, and returns the `ReleaseSemaphore(m_waitHandles[0], 1, NULL)` result.
