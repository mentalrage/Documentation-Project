# 0x00553c10-0x00554635 - Connection Closed And Reconnect Dialogs

## Status

- Confidence: strong
- Current owners: `ConnectionClosedDialog`, `ReconnectDialog`, with an interleaved `CopyWindow` constructor/callback island.
- Likely source file: [UID:0000N0][ReconnectDialog](by-file/ReconnectDialog.md)
- IDA evidence: targeted boundary checks on 2026-05-23 and caller/decompilation rechecks on 2026-05-25 and 2026-05-26.

## Covered Ranges

| Range | Current entity | Notes |
| --- | --- | --- |
| `0x00553c10-0x00553cbf` | `ConnectionClosedDialog` constructor variant | Sets the connection-closed singleton/global, installs the three `ConnectionClosedDialog` vtables, and initializes the base dialog with resource text id `154`. |

## Evidence Notes

- IDA confirms the connection/reconnect starts and `CopyWindow` callbacks as real functions. The `CopyWindow` constructor at `0x005544c0` remains raw constructor-shaped code, not an IDA-modeled function.
- 2026-05-28 IDA MCP confirms `0x00553c10-0x00553cbf` as a real constructor-shaped function called from `0x00508ffc`; it calls the shared dialog initializer, assigns `dword_67AB54`, and installs `ConnectionClosedDialog` primary/secondary/tertiary vtables.
- 2026-05-28 IDA MCP confirms the prior end address missed the final `retn 4` byte at `0x00554634`; this aggregate now ends at `0x00554635`.
- `ConnectionClosedDialog::OnReconnectClicked` calls `ReconnectDialog::InitiateReconnect`.
- `ReconnectDialog` calls packet-sender helpers, reads `g_pConfig` server address/port, and updates reconnect globals.
- IDA MCP callers on 2026-05-25 show `ReconnectDialog::OnButtonClick` at `0x00554210` calls [UID:0001HW][0x00574d40-0x00574e44.SendPositionUpdate](by-memory/0x00574d40-0x00574e44.SendPositionUpdate.md), the queued position/status upload helper in the `CashShopRequest` send cluster.
- IDA `callers` on 2026-05-25 shows the helper at `0x00553e60` is called from `0x00553ca8`, `0x00553d55`, and `0x005543bb`.
- 2026-05-26 IDA MCP reconfirmed the same `0x00553e60` callers and kept the function name as the stale debug symbol rather than a useful original name.
- 2026-06-01 IDA MCP byte review confirms `0x00553e60` has size `0xd6`, so the helper ends at `0x00553f36`; `0x00553e5b-0x00553e60` and `0x00553f36-0x00553f40` are `0xcc` alignment padding around it.
- Current `simroot_v2/class_ConnectionClosedDialog.cpp` emits `InitializeConnectionState()` as a call-site name for this helper but does not emit the helper body in the active source view.
- The `CopyWindow` island at `0x005544c0-0x0055454b` should remain documented under [UID:0001FV][0x005544c0-0x0055454b.CopyWindow](by-memory/0x005544c0-0x0055454b.CopyWindow.md) despite living inside this broader address neighborhood.

## Disposition

Keep both dialog classes together in a network/session-recovery source file. They are UI classes, but their behavior is primarily connection recovery rather than generic alert display.
