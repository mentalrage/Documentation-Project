## Range Role

This range is the system-dependent IJG memory backend selected by the observed binary. It is stock `jmemnobs.c`, the no-backing-store backend recommended by `jpeg-6b/makefile.vc` for Windows NT/95 style builds.

The backend uses CRT `malloc`/`free`, reports all requested memory as available, raises `JERR_NO_BACKING_STORE` if backing-store use is requested, returns zero from `jpeg_mem_init`, and has a no-op `jpeg_mem_term`.

This child remains separate from [UID:0000VW][0x00405060-0x00405c77.LibJpegMemoryManager](by-memory/0x00405060-0x00405c77.LibJpegMemoryManager.md) / `jmemmgr.c`. The memory manager installs and calls these hooks, but `jmemnobs.c` is the distinct system-dependent backend source file. The target ends at `0x00406ed1`; `0x00406ed1-0x00406ee0` is padding before [UID:00045N][0x00406ee0-0x004075b7.LibJpegDecompressCoefficientController](by-memory/0x00406ee0-0x004075b7.LibJpegDecompressCoefficientController.md) / `jdcoefct.c`.
