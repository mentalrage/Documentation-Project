## Range Role

This range is the system-dependent IJG memory backend selected by the observed binary. It matches `jmemnobs.c`, the no-backing-store backend recommended by `jpeg-6b/makefile.vc` for Windows builds.

The backend uses CRT `malloc`/`free`, reports all requested memory as available, raises `JERR_NO_BACKING_STORE` if backing-store use is requested, returns zero from `jpeg_mem_init`, and has a no-op `jpeg_mem_term`.
