## Behavior Summary

The constructor creates a `DialogPane` over the main menu, stores the active singleton, installs `StaffsDialogPane` vtables, queries event flags, loads `STAFF.EPF`, adds a background image control and close button, creates a scrolled text control from `STAFFS` or `STAFFS2`, positions the dialog, shows it under `g_pMainMenuPane`, and starts the slide-open animation.

`OnDialogAction` only handles action id `1`, where it slides and closes the dialog.
