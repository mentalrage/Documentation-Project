# 0x004a60a0-0x004a60cb MSVC Int64 Runtime Helpers

## Status

- Disposition: ignored third-party/runtime support.
- Entity kind: runtime helper pair.
- Rebuild handling: `third-party/runtime`.
- Owner: MSVC compiler/runtime support, not NexusTK source.
- Confidence: medium-high. IDA labels `0x004a60c0` as a Microsoft Visual C runtime helper; `0x004a60a0` is an adjacent helper-shaped body with no direct xrefs in the current IDB.

## Covered Ranges

| Range | IDA state | Behavior |
| --- | --- | --- |
| `0x004a60a0-0x004a60c0` | raw helper-shaped body, not modeled as a function | Splits one 32-bit input into `0x55555555` and `0xAAAAAAAA` bit masks and writes the parts to two output pointers. |
| `0x004a60c0-0x004a60cb` | `unknown_libname_12`, IDA modeled function | Returns whether either half of a 64-bit argument is non-zero by OR-ing the low and high dwords. |

## Evidence

- IDA MCP `lookup_funcs` on 2026-05-27 reports no function at `0x004a60a0`, but raw disassembly shows a complete `push ebp` / `retn` helper body from `0x004a60a0-0x004a60c0`.
- IDA MCP `lookup_funcs 0x004a60c0` reports `unknown_libname_12` size `0xb`.
- IDA MCP decompilation labels `0x004a60c0` as `Microsoft VisualC 14/net runtime` and decompiles it as `HIDWORD(a1) | a1`.
- IDA MCP `xrefs_to` reports no current direct xrefs to either helper start.
- Raw bytes show one `0xcc` byte before this helper pair and five `0xcc` bytes after it before [UID:00013X][0x004a60d0-0x004a6a76.ErrorWrappers](by-memory/0x004a60d0-0x004a6a76.ErrorWrappers.md).
