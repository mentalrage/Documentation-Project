## Behavior

This helper appends a narrow byte range into an already-initialized SSO-7 wide string object. The caller passes the destination string object in the object register and a half-open narrow range on the stack. For each input byte, the helper sign-extends the byte, writes one 16-bit code unit, keeps the destination terminated, and advances the source pointer until it reaches the end pointer. The binary convention also cleans a third stack argument, but the body never reads it; caller windows prove that value is an internal tag/context artifact rather than a stable source-facing parameter.

The destination layout matches the early `SimpleUString` SSO-7 family:

- current length at offset `0x10`;
- current capacity at offset `0x14`;
- inline storage while capacity is below `8`;
- heap storage through the pointer at offset `0x00` once capacity is at least `8`.

If the existing capacity is sufficient, it writes the widened byte at `length * 2`, writes the following 16-bit terminator, and increments the stored length. If the append requires growth, it computes a new capacity from `(length + 1) | 7`, applies the usual 1.5x growth check, caps at `0x7ffffffe`, allocates `(capacity + 1) * 2` bytes through the nearby wide-string allocator at `0x00423d00`, copies the old content with `_memmove`, appends the widened byte and terminator, and frees the old heap storage with the aligned-allocation validation path when needed.
