## Behavior

This helper recognizes an `/lgi` LG Internet/Channel i launcher startup mode. It copies the process command line into a local wide buffer, finds the first slash, then accepts either the exact UTF-16 `/lgi` token at `0x00616ec4` or the `/lgi ` prefix at `0x00616ed0`.

The accepted path calls the wide loader slot at `dword_69BE30` with the UTF-16 `chigamec.dll` string at `0x00616f1c`, resolves the ANSI export string `WaitForSessionParameter` at `0x00616f38` through `GetProcAddress`, and invokes the returned function pointer with a stack session block at `[ebp-0xce8]`. A nonzero return code formats the Channel i DLL error string at `0x00616f50` before aborting.

On a zero session-API return, the helper reads the session block fields as host, port, and two small credential/session strings. It copies the host bytes from `[ebp-0xca8]` into a stack buffer, converts them to wide text at `param_1 + 0x2915c4` with `MultiByteToWideChar`, then either resolves alphabetic host names with `gethostbyname` or parses dotted numeric addresses with `_strtok_s`.

The success path writes the resulting address bytes to `param_1 + 0x2915b4`, stores the session port from `[ebp-0xc88]` to `param_1 + 0x2916c4`, copies two session strings from `[ebp-0xce8]` and `[ebp-0xcc8]` to `param_1 + 0x28d9e0` and `param_1 + 0x28da20`, sets `param_1 + 0x2916ca` to `1`, and forces the state byte at `param_1 + 0x28de28` to `5`.

Invalid command-line data, DNS failure, invalid IP tokenization, and session DLL errors abort through localized Channel i/LG Internet dialogs and the common `PostQuitMessage`/`__loaddll` termination path.
