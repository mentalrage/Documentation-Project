## Address Range

`0x00490200-0x0049050a`, ending before the exported start at `0x00490510`.

IDA does not currently model this start as a function, but live IDA disassembly decodes a normal stack-frame prologue at `0x00490200`.

## Behavior

This helper recognizes an `/lgi`-style LG Internet launcher/session startup mode, dynamically resolves `WaitForSessionParameter`, loads or interacts with the launcher support DLL, waits for browser/session parameters, resolves a requested server host, and stores session credential and connection target data into the startup-state block.

It aborts through the common message-box/quit path when the launcher data is invalid.

## Evidence

- IDA live disassembly shows calls to `GetCommandLineW`, `_wcsncmp`, `GetProcAddress`, `MultiByteToWideChar`, `_isalpha`, `gethostbyname`, `_strcpy_s`, `_strtok_s`, `MessageBoxW`, and `PostQuitMessage`.
- IDA string search confirms `WaitForSessionParameter` at `0x00616f38`, with an xref from `0x004902bb` inside this range.
- IDA string inventory around `0x00616fd7` includes `LG Internet Channeli`, matching the launcher family indicated by the legacy report.
- The same local string island contains `NWind`, referenced from `0x004904e2`, which is inside this helper.
