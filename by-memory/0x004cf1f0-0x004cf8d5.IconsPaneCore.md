## Behavior Summary

The constructor registers the singleton and derives the icon-strip mode from config byte `g_pConfig + 0x28de32`: zero means full icon strip, nonzero means reduced. The paint path starts at icon index `0` in full mode or `6` in reduced mode, draws 20-pixel-wide frames until x reaches `160`, and uses frame `index + 8` for the selected pressed icon.

The mouse handler uses event type `0` for drag/move while captured, `1` for mouse down/capture, `3` for mouse up/click action, and `4` for hover tooltip. Tooltip ids are `202..209`. Click action dispatch is skipped if the input-lock byte at `dword_67A764 + 1008` is set.
