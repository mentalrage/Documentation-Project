## Behavior

`MiniMapDownloader` is a singleton worker for direct minimap `.mnm` downloads. The constructor writes the singleton after base initialization and before starting the worker; both destructor paths clear the same global before thread-base teardown completes.

The task handler treats message `0` as the direct minimap download command. It passes the task block to `DownloadMinimapFile_453AA0`, then frees the task block with `sub_5C7526`. Nonzero message ids are delegated to the shared thread handler at `0x00596920`.

The download helper expects the task block to begin with a map id. It rejects ids `>= 1000000`, formats a three-digit folder from `mapId / 1000`, builds `https://s3.amazonaws.com/kru-downloads/tk/minimaps/%03d/<code>.mnm`, opens the URL with `INTERNET_FLAG_RELOAD`, applies five 3000 ms WinInet options, requires HTTP status `200`, opens the output path through the imported CreateFileW-like wrapper at `dword_69BE34`, streams data through `InternetQueryDataAvailable`, `InternetReadFile`, and `WriteFile`, logs `Downloading : %d\n` with `OutputDebugStringW`, and deletes the partial file through `dword_69BE60` if the read/write loop does not complete cleanly.
