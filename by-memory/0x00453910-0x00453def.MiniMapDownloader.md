# 0x00453910-0x00453def MiniMapDownloader

## Status

- Disposition: reconstructable NexusTK project code.
- Entity kind: minimap download worker class plus file download helper.
- Current Wave3 owners: [UID:00008D][MiniMapDownloader](by-class/MiniMapDownloader.md) and `DownloadMinimap_453AA0`.
- Likely source module: [UID:0000LE][MiniMap](by-file/MiniMap.md), likely `map/MiniMapDownloader.cpp`.
- Confidence: strong for boundaries and feature ownership.

## Evidence

- IDA MCP confirms all starts and sizes listed above.
- IDA MCP `callers` reports `DownloadMinimap_453AA0` has direct caller `0x00453a16` inside `MiniMapDownloader::OnThreadTask`.
- IDA MCP `callees` for `0x00453a00` list `0x00453aa0` and raw delete.
- Generated source shows the constructor calls the shared `FileDownloader::StartThread(this)` worker launch helper after installing the `MiniMapDownloader` vtable.
- Recovered helper source builds the `https://s3.amazonaws.com/kru-downloads/tk/minimaps/` URL and writes the downloaded payload to the caller-provided path.

## Ownership Decision

Keep this cluster in the minimap feature source family. The call to [UID:0000JC][FileDownloader](by-file/FileDownloader.md)'s `StartThread` is a shared launch helper and does not make `MiniMapDownloader` part of the generic downloader file.
