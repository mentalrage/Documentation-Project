## Behavior

Reads a two-byte UTF-16 element count from the Decoder stream, using byte-order flag `+0x10` to choose manual high-byte-first assembly or native little-endian `word ptr` load. It then copies `count * 2` bytes from the input buffer to the caller wide buffer, optionally reports the element count, advances the cursor, and writes a wide NUL terminator.

The method clears the destination and optional count on entry. It clears valid flag `+0x11` when the count field, payload span, or destination capacity check fails.
