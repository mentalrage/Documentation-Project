## Behavior

This method loads one category array from the parsed item-shop JSON root. It maps `categoryIndex` values `0..10` to one of the persisted category keys:

| Index | JSON key |
| ---: | --- |
| 0 | `main` |
| 1 | `usable_items` |
| 2 | `weapons` |
| 3 | `mounts` |
| 4 | `face` |
| 5 | `head` |
| 6 | `mantle` |
| 7 | `necklaces` |
| 8 | `coats` |
| 9 | `shoes` |
| 10 | `specialty_sets` |

It looks up the category array, copies each array element to a temporary JsonCpp value, allocates a 0xc0-byte category entry, sets the category id, calls [UID:0002E4][0x00421a40-0x00421fd8.FittingRoomCatalogEntryFromJson](by-memory/0x00421a40-0x00421fd8.FittingRoomCatalogEntryFromJson.md), appends the entry pointer to a pending vector, then inserts the finished vector into category lookup storage at `this + 0x220`.
