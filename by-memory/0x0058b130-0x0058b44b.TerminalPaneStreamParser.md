# 0x0058b130-0x0058b44b TerminalPane Stream Parser

## Status

- Confidence: strong for range and terminal ownership, medium for final source name.
- Covered file/module: [UID:0000OI][TerminalPane](by-file/TerminalPane.md)
- Current Wave3 state: real IDA function, not emitted as an active `TerminalPane` method in `class_TerminalPane.cpp`.
- Recommended source name: `TerminalPane::ParseTerminalStream` or a private `OnTerminalStreamData` callback.

## Function Role

This function is the byte-stream parser for the pre-login terminal/modem pane. It is referenced through a data/vtable slot at `0x0062da80`, has no ordinary direct callers in IDA, and processes the packet buffer passed by the terminal/network layer.

The parser tracks a small terminal state field, recognizes terminal escape and telnet negotiation bytes, responds to telnet option negotiation, and finalizes the terminal connection path when the state reaches the login handoff branch.

## Behavior Notes

- Iterates over an input buffer using the packet length at `a2 + 0x10` and data pointer at `a2 + 0x0c`.
- Handles BEL (`0x07`) by writing a bell byte to stderr.
- Handles ESC (`0x1b`) and returns early for the `%I\n</RunRegistry=` sequence.
- Handles telnet IAC (`0xff`) negotiation, including option `0x18`, and sends terminal-type response text including `dumb`.
- On the final state branch, sends a `baram` packet, calls [UID:0001HW][0x00574d40-0x00574e44.SendPositionUpdate](by-memory/0x00574d40-0x00574e44.SendPositionUpdate.md), closes/hides the terminal pane, and transitions into the normal login/game UI path.
