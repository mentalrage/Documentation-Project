# 0x004f5b20-0x004f5c73 MAPI Send Mail Helper

## Status

- Disposition: reconstructable NexusTK project code.
- Entity kind: standalone Win32/MAPI helper function.
- Likely source file: unresolved utility or application-support module.
- Confidence: strong for boundary and imported API role; low for final source ownership and caller set.

## Behavior

This helper dynamically loads `MAPI32.DLL`, resolves `MAPISendMail`, converts caller-provided strings through local string conversion helpers, builds stack-local MAPI message and recipient/file descriptor structures, calls `MAPISendMail`, frees converted strings, and unloads the library.

The function appears to send a client-generated email through the user's configured MAPI provider. No direct caller xref has been confirmed yet, so source ownership should stay unresolved until caller discovery improves.

## Observed API Use

| API/string | Role |
| --- | --- |
| `LoadLibraryA("MAPI32.DLL")` | Loads MAPI dynamically instead of importing it through the executable import table. |
| `GetProcAddress(..., "MAPISendMail")` | Resolves the send-mail entry point. |
| `FreeLibrary` | Releases `MAPI32.DLL` before returning. |
| [UID:000249][0x00599440-0x005995a7.PlatformStringConversionHelpers](by-memory/0x00599440-0x005995a7.PlatformStringConversionHelpers.md) | Local string conversion/allocation and free helpers used for MAPI structure fields. |

## Evidence

- 2026-05-28 IDA raw disassembly identifies a complete function-shaped body at `0x004f5b20-0x004f5c73`.
- The body references string literals `MAPI32.DLL` and `MAPISendMail`, calls `LoadLibraryA`, `GetProcAddress`, invokes the resolved function pointer, then calls `FreeLibrary`.
- It allocates or converts up to five input strings, conditionally builds an attachment/file descriptor block, and frees converted strings before returning.
- 2026-05-28 IDA MCP xrefs show five calls from this helper to `0x00599440` and five cleanup calls to `0x005994b0`; those helpers are now documented at [UID:000249][0x00599440-0x005995a7.PlatformStringConversionHelpers](by-memory/0x00599440-0x005995a7.PlatformStringConversionHelpers.md).
- `0x004f5b1e-0x004f5b20` and `0x004f5c73-0x004f5c80` are compiler/linker alignment padding around this helper.

## Reconstruction Notes

- Confirm the caller before assigning this helper to a final source file. Candidate ownership could be an application support, support/contact, crash/reporting, or shell-integration source file rather than the in-game mail system.
- Do not confuse this with NexusTK in-game mail packet handling; this function uses Win32 MAPI and the local user's mail client.
- Raw assembly and final C++ converted code are pending.
