# 0x004f5b20-0x004f5c73 MAPI Send Mail Helper

## Status

- Disposition: reconstructable NexusTK project code.
- Entity kind: standalone Win32/MAPI helper function.
- Likely source file: [UID:0000ML][PlatformApi](by-file/PlatformApi.md) or a neighboring platform/shell support helper.
- Confidence: strong for boundary and imported API role; medium for final feature caller/source split.

## Behavior

This helper dynamically loads `MAPI32.DLL`, resolves `MAPISendMail`, converts caller-provided strings through local string conversion helpers, builds stack-local MAPI message and recipient/file descriptor structures, calls `MAPISendMail`, frees converted strings, and unloads the library.

The function appears to send a client-generated email through the user's configured MAPI provider. No direct caller xref has been confirmed yet, so source ownership should stay unresolved until caller discovery improves.

## Evidence

- The body references string literals `MAPI32.DLL` and `MAPISendMail`, calls `LoadLibraryA`, `GetProcAddress`, invokes the resolved function pointer, then calls `FreeLibrary`.
