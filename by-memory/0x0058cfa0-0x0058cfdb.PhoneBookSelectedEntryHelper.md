## Function Role

This method copies the selected phone-book contact's name and phone number into caller-provided wide-character buffers, then returns the contact row's leading flag byte. The only modeled caller is the edit path in [UID:0000AD][PhoneBookDialog](by-class/PhoneBookDialog.md), which passes two stack buffers and two capacities of `0x40` wide characters.

Observed binary layout:

`entryFlags` is intentionally neutral.
