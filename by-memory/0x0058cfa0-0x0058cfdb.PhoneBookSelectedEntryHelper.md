# 0x0058cfa0-0x0058cfdb PhoneBook Selected Entry Helper

## Status

- Confidence: strong for range and phone-book ownership.
- Covered file/module: [UID:0000MJ][PhoneBookDialog](by-file/PhoneBookDialog.md)
- Current Wave3 state: current `simroot_v2/class_PhoneBookListPane.cpp` emits this as `PhoneBookListPane::GetSelectedEntryData`, while `PhoneBookDialog::OnCommand` still calls it through a polluted `ChattingColorListPane` cast.
- Recommended source name: `PhoneBookListPane::GetSelectedEntryData`.

## Function Role

This helper copies the selected phone-book entry name and number into caller-provided wide-character buffers, then returns the entry flag/status byte.

## Layout Evidence

The selected entry payload has this observed shape:

```text
+0x000  flag/status byte
+0x002  name, wchar_t[64]
+0x082  number, wchar_t[64]
```

The decompiled body obtains the selected list entry through the shared list accessor at `0x004f3dc0`, copies `entry + 1` and `entry + 65` as wide strings, and returns `*(uint8_t*)entry`.

## IDA MCP Evidence

Checked on 2026-05-26:

- `lookup_funcs 0x0058cfa0` reports `sub_58CFA0`, size `0x3c`, ending at `0x0058cfdc`.
- `xrefs_to 0x0058cfa0` reports one direct code reference at `0x0058cd8c` inside `PhoneBookDialog::OnCommand`.
- `callers 0x0058cfa0` reports only `sub_58CCD0`, the current IDA function for `PhoneBookDialog::OnCommand`.

## Ownership Decision

Keep this helper with the terminal phone-book feature, either as `PhoneBookListPane::GetSelectedEntryData` or as file-local phone-book list-model support. Do not migrate it as chat/color-list code.
