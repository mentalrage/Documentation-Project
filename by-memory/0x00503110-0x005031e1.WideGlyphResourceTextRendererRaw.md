## Behavior

The helper receives `this` in `ecx`, a UTF-16 string pointer, two coordinate arguments, and a one-byte style/index argument. It initializes a small source rectangle of `9x11`, initializes a destination rectangle from the caller coordinates, then walks the UTF-16 string one code unit at a time.

For each character:

- stops at NUL;
- skips space (`0x20`) and slash (`0x2f`);
- computes a glyph/resource offset as `((codeUnit + style * 10) - 47) * 99 + *(this + 0x220)`;
- writes that computed resource pointer/index into the local render descriptor;
- dispatches through [UID:0000TN][SurfaceRenderCallbackTable](by-global/SurfaceRenderCallbackTable.md);
- advances the destination rectangle by `9` pixels before the next character.

void RenderWideGlyphResourceText(const wchar_t* text,
                                 int left, int top,
                                 int bottomOrRight,

    RenderDescriptor descriptor;
    Rect source;
    Rect target;

    InitializeRenderDescriptor(&descriptor);
    MakeRect(&source, 0, 0, 9, 11);
    MakeRect(&target, left, top, left + 9, bottomOrRight + 11);

    for (; *text; ++text)
    {
        const wchar_t ch = *text;
        if (ch != L' ' && ch != L'/')

            dword_69B3E8(&descriptor, &source, &target, 1, 0, 0);

        OffsetRect(&target, 9, 0);
    }
}
