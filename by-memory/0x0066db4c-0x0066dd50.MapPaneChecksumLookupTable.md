# 0x0066db4c-0x0066dd50 MapPane Checksum Lookup Table

## Summary

- Address range: `0x0066db4c-0x0066dd50`
- Entity kind: checksum/CRC-style lookup table with leading alignment bytes
- Disposition: reconstructable project data
- Rebuild handling: `source-declared/generated-binary`

This range contains four leading zero bytes followed by a 512-byte 16-bit lookup table beginning at `dword_66DB50`. The table is used by map/profile/checksum-style helpers around `0x00507c90`, `0x0050c040`, and `0x005139xx`.
