## Behavior

This method writes the current `MapPane` tile buffer as a compressed local map-cache file. If the tile buffer pointer is absent, the method skips filesystem work and immediately refreshes the monster image-library cache state through [UID:0001PN][0x0069b440-0x0069b444.g_pMonsterImageLib](by-memory/0x0069b440-0x0069b444.g_pMonsterImageLib.md).

When tile storage exists, the method resolves the user's Documents folder with `SHGetFolderPathW`, creates `NexusTK` and `NexusTK\Maps` beneath it, accepts `ERROR_ALREADY_EXISTS` (`183`) for both directory-creation calls, then formats `TK%06d.cmp` with the current map id. It opens the path through the wide API file-open dispatch entry in write-binary mode, writes the `CMAP` signature, writes the current width and height as two little-endian 16-bit fields, compresses `6 * width * height` bytes of tile storage with the bundled zlib `compress` wrapper, writes the compressed payload, closes the stream, frees the old tile buffer, clears the tile buffer pointer, releases the local compressed buffer, and finally calls the monster image-library cache-clear helper.

The save helper is paired with [UID:0002QJ][0x00504b90-0x00504df1.MapPaneLoadCompressedMapFile](by-memory/0x00504b90-0x00504df1.MapPaneLoadCompressedMapFile.md). The load side expects the same path family, `CMAP` signature, width/height header, and zlib-compressed `6 * width * height` payload.
