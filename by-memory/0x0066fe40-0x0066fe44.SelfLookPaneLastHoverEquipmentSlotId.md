# 0x0066fe40-0x0066fe44 SelfLookPane Last Hover Equipment Slot Id

## Summary

- Address range: `0x0066fe40-0x0066fe44`
- Entity kind: initialized word global plus alignment bytes
- Disposition: reconstructable project data
- Rebuild handling: source-declared/global state
- Confidence: strong for address, owner, xrefs, and hover-slot role; medium for exact original source spelling

This small global stores the last accepted `SelfLookPane` equipment slot id for the mouse-move/hover branch. It initializes to `0xffff`, with two zero alignment bytes before the next wide delimiter string. The cache prevents the branch from repeatedly cancelling and re-arming the same one-second timer while the cursor stays over the same equipment slot.

## Evidence

- IDA MCP byte read at `0x0066fe40` returns `ff ff 00 00`, followed by the UTF-16 `SpelledPane` whitespace delimiter at `0x0066fe44`.
- IDA MCP xrefs to `0x0066fe40` are limited to `SelfLookPane::OnMouseClick` / mouse event handling at `0x00568cb0-0x0056934a`: compare at `0x005692c7`, write at `0x00569310`.
- The owning branch calls `SelfLookPane::HitTestSlot` at `0x005692aa` with the event coordinates, rejects `0xffff`, then accepts only returned ids `7..20` (`lea eax,[ecx-7]`; `cmp ax,0x0d`; `ja`).
- If the accepted slot id differs from `word_66FE40`, the branch removes pending callbacks from the pane timer subobject through `0x00597600`, then schedules a new timer through `0x005975e0` with `(slotId, 1000, mouseY, mouseX)`.
- Regardless of whether the slot changed, the branch writes the accepted id back to `word_66FE40`, sets the per-slot state byte at `this + 0x1655 + slotId`, and invalidates/redraws through the pane virtual slot at `+0x20`.
- `SelfLookPane::HitTestSlot` (`0x0056a300-0x0056a373`) iterates slot ids `0..20`, asks `0x00569ed0` for each slot rectangle/color record, calls point-in-rect at `0x004b7e80`, returns the matching id in `AX`, and returns `0xffff` when no slot is hit.

## Reconstruction Notes

Declare the first word as a source-owned `SelfLookPane` global or file-static. Do not merge the two trailing zero bytes into the variable; they are alignment before the next documented UTF-16 delimiter at `0x0066fe44`.

The name should be treated as an accurate migration name, but not proof of original symbol spelling. The raw behavior is stronger than the spelling: a no-slot sentinel initialized to `0xffff`, a cached `7..20` equipment slot id, timer reset only when the hovered slot changes, and per-slot state update before redraw.
