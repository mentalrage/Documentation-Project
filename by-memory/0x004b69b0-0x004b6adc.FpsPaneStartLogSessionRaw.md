## Behavior

This raw body resets an FPS logging session. It stores the current tick count, sets min FPS to `300.0`, max FPS to `0.0`, initializes the sample count and sum, clears accumulated object counters, optionally creates a new `FPSDATA-*` file, writes the new-client/start lines, and clears [UID:0000PY][g_fpsDebugActive](by-global/g_fpsDebugActive.md).
