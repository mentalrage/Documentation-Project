## Behavior

`PatchPane2::SendDownloadRequest` formats the current request path using the pattern `%d/%d/%s`, combines the current patch version/pass/file name state, and queues an HTTP/file download request through [UID:0000RQ][g_pMiscWorkThread](by-global/g_pMiscWorkThread.md).

This is the request producer used by the constructor and by the main work-thread loop when advancing to the next file or pass.

The IDA-backed state use matches [UID:0001VJ][PatchPane2Layout](by-type/by-struct/PatchPane2Layout.md): `+0x26c` contributes the formatted leaf/path, `+0x274/+0x278` hold the file-name vector, `+0x280` is the current vector index, and `+0x28c/+0x290` are the two version/path number components.

## Detailed Flow

1. Reads the current file-name index at owner `+0x280` and selects an entry from the string/vector range beginning at owner `+0x274`.
2. Formats a request suffix with pattern `%d/%d/%s` using owner `+0x28c`, owner `+0x290`, and the current selected file-name string.
3. Calls [UID:00022D][0x004b32d0-0x004b3344.PatchPane2DownloadPathJoinHelper](by-memory/0x004b32d0-0x004b3344.PatchPane2DownloadPathJoinHelper.md) to copy the selected base/path string and append the formatted suffix.
4. Queues the resulting request through the global misc-work thread object.
5. Cleans up temporary string objects before returning.
