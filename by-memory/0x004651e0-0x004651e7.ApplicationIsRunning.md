## Behavior

`Application::IsRunning` returns the one-byte running/active flag stored at Application object offset `0x838`, now best source-facing as `m_isRunning`.

The flag is application lifecycle state, not a caller-local helper result. Current IDA MCP evidence ties the same byte to constructor initialization at `0x00463511`, BaramApp foreground write `0x004669f5`, BaramApp background write `0x00466a9d`, and two ScreenPane `HandleMessage` predicate routes at `0x00556dab` and `0x00556e36`.
