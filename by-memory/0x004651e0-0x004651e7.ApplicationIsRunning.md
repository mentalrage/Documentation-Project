## Behavior

`Application::IsRunning` returns the one-byte running/active flag stored at Application object offset `0x838`.

The flag is application lifecycle state, not a caller-local helper result. Existing constructor and Baram activation/deactivation pages show the same offset is initialized and later toggled by foreground/background transitions.
