## Behavior

This is an RGB565 row/span half-blend helper. It divides each row into four-pixel blocks, dispatches the block body to [UID:0000YG][0x00460c10-0x00460c8c.HalfBlendSpan16Blocks](by-memory/0x00460c10-0x00460c8c.HalfBlendSpan16Blocks.md) `HalfBlendSpan16Blocks`, then handles the scalar tail with the RGB565 half-blend identity:

```text
((a >> 1) & 0x7bef) + ((b >> 1) & 0x7bef) + (a & b & 0x0821)
```

The body advances source and destination row pointers by caller-supplied pitches and repeats for the row count.

## Reconstructed C++ Candidate

```cpp
static inline uint16_t HalfBlendRgb565(uint16_t a, uint16_t b)
{
    return static_cast<uint16_t>(((a >> 1) & 0x7bef) +
                                 ((b >> 1) & 0x7bef) +
                                 (a & b & 0x0821));
}

void Rgb565HalfBlendSpanRaw(uint16_t* dst, int dstPitchBytes,
                            const uint16_t* src, int srcPitchBytes,
                            int widthPixels, int rowCount)
{
    const int blockPixels = (widthPixels / 4) * 4;
    const int tailPixels = widthPixels - blockPixels;

    if (blockPixels > 0)
        HalfBlendSpan16Blocks(dst, dstPitchBytes, src, srcPitchBytes,
                              blockPixels / 4, rowCount);

    dst += blockPixels;
    src += blockPixels;

    for (int y = 0; y < rowCount; ++y)
    {
        for (int x = 0; x < tailPixels; ++x)
            dst[x] = HalfBlendRgb565(dst[x], src[x]);

        dst = reinterpret_cast<uint16_t*>(reinterpret_cast<unsigned char*>(dst) + dstPitchBytes);
        src = reinterpret_cast<const uint16_t*>(reinterpret_cast<const unsigned char*>(src) + srcPitchBytes);
    }
}
```

The candidate keeps byte pitches because the assembly adds the pitch arguments directly to the 16-bit pointers at the end of each row.
