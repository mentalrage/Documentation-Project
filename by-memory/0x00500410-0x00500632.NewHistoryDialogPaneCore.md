## Behavior Summary

The constructor creates a full-screen [UID:00003T][DialogPane](by-class/DialogPane.md), writes [UID:0000RS][g_pNewHistoryDialog](by-global/g_pNewHistoryDialog.md), installs three `NewHistoryDialogPane` vtable pointers, adds a `HISTORYN.EPF` background image with `HISTORYN.PAL`, adds a [UID:0000CJ][ScrolledTextControlPaneForMadeBy](by-class/ScrolledTextControlPaneForMadeBy.md) for the `MADEBY` text resource, loads the dialog resource, sets focus mode, and shows the dialog over `g_pMainMenuPane`.

The key and mouse handlers close the dialog on common dismissal input.
