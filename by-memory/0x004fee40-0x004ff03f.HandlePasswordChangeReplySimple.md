## Behavior

Parses a simpler password/account reply packet shape. It reads the result byte at packet offset `+1`, clears the active modal/dimmer through `dword_69AE08`, maps nonzero result codes `3` through `8` to dialog state/focus value `5`, decodes a length-prefixed ANSI message from offsets `+2/+3`, converts it to UTF-16, and displays it with `AlertPane`. For result zero it performs the same message display path and then closes/dismisses the dialog through `sub_49EB90` and `sub_49DAD0`.
