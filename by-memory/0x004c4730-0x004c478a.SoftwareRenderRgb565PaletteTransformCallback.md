## Range And Behavior

| Range | IDA function | Behavior |
| --- | --- | --- |
| `0x004c4730-0x004c478a` | `sub_4C4730`, size `0x5a` | Splits an RGB565 pixel into 5/6/5-bit channels, looks channels up through `dword_69B3D8` / `dword_69B3DC` using an intensity index, masks to 5/6/5 widths, and repacks RGB565. |
