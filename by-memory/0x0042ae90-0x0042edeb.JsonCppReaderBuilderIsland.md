# JsonCpp Reader/Builder Island `0x0042ae90-0x0042edeb`

## Status

- Confidence: strong for JsonCpp ownership; high for current upstream snapshot candidate `b299d3581f4dc670734f1fe1a34fce1282337802`; medium-low for per-function names.
- Proposed owner: [UID:0000KI][JsonCpp](by-file/JsonCpp.md)
- Disposition: third-party static library code; exclude from NexusTK product source modules.
- Evidence basis: read-only IDA MCP function-list, lookup, caller/callee, string, and string-xref checks on 2026-05-25 plus staged JsonCpp source comparison. `wave3.py` was not executed for this pass.

## Range Role

This is the current first IDA-modeled JsonCpp parser/builder island. It contains a reader/parser family, string/number/member helper functions, and builder/settings helpers tied to `Json::CharReaderBuilder` / writer-builder RTTI evidence. The immediately preceding raw/unmodeled lexical-helper span is tracked separately as [UID:0000X1][0x0042acdf-0x0042ae90.JsonCppLegacyReaderRawLexicalHelpers](by-memory/0x0042acdf-0x0042ae90.JsonCppLegacyReaderRawLexicalHelpers.md).

The range is not yet a proven complete JsonCpp library span. It is an address-grounded island for source matching and library classification. Exact upstream names should be assigned only after comparing against the staged JsonCpp source candidates.

## Evidence

- IDA string xrefs tie `0x0042ae90`, `0x0042b120`, `0x0042b730`, and `0x0042bfc0` to canonical JsonCpp parser diagnostics.
- IDA string xrefs tie `0x0042d380`, `0x0042db90`, and `0x0042def0` to builder/settings names such as `collectComments`, `allowDroppedNullPlaceholders`, and `allowSpecialFloats`.
- IDA callers show `0x0042d2e0` calls `0x0042db90`, and `0x0042d7f0` calls [UID:0000XC][0x004417e0-0x00441d24.JsonCppValidReaderKeys](by-memory/0x004417e0-0x00441d24.JsonCppValidReaderKeys.md).
- IDA callees show the parser entry calls the local object/array/string helper family and JsonCpp value/string support functions outside this island.
- RTTI-ish strings elsewhere identify `Json::CharReaderBuilder`, `Json::StreamWriterBuilder`, `Json::FastWriter`, and `Json::StyledWriter`, supporting third-party JsonCpp ownership for this island.

## Ownership Decision

Keep this island with [UID:0000KI][JsonCpp](by-file/JsonCpp.md) and the proposed `third_party/jsoncpp/` source tree. Cash-shop, fitting-room, and downloader modules may consume parsed JSON, but they should not own these parser/builder helpers.

Do not use the common builder strings in this range alone as proof of the exact JsonCpp release. Later source/IDA comparison found `Unable to parse token length` present in the binary, `reader error` absent, static-object `Value::nullSingleton()` behavior present, and later `1.7.5+` reader changes absent. Current evidence favors official upstream commit `b299d3581f4dc670734f1fe1a34fce1282337802`, between tags `1.7.4` and `1.7.5`.
