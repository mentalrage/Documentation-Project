## Behavior

`BuildFieldMapPath` copies a wide source path stem into a destination buffer:

- scans backward from the end of the wide source string for the last `'.'`;
- if a dot is found, copies the portion before that dot;
- if no dot is found, copies the whole source string;
- for an empty source string, copies zero bytes and writes only the wide NUL terminator;
- terminates the destination string and returns zero.

The helper is not a complete path normalizer. It does not inspect path separators, validate capacity, allocate storage, append an extension, or touch global state. The FieldMapPane constructor passes its incoming source path and `this + 0xf8` destination buffer, appends the wide `.EPF` suffix, and then calls the wide API dispatch helper to finish the path used by the map frame load.
