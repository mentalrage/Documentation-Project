## Behavior

This helper projects one loaded frame-table record into a caller-provided draw/metrics record.

IDA decompilation on 2026-06-01:

```c

{
  _DWORD *v3;

  if ( a2 < 0 || a2 >= *a1 )
  {
```

## Structure Notes

Confirmed table observations:

| Offset | Meaning |
| --- | --- |
| table `+0x00` | 16-bit frame count. |
| table `+0x08` | pointer to 24-byte frame-record array. |

| frame record `+0x10` | payload/image pointer or id copied to output `+0x04`. |

The decompiler expression `v3[10] - v3[5]` is now resolved at the disassembly level: `0x004d163b` reads `[edx+0x28]`, then `0x004d163e` subtracts `[edx+0x14]`. This matches [UID:0000UN][EPFArchiveMetadataTable](by-item/EPFArchiveMetadataTable.md)'s one-extra-record sentinel model. Final field names remain provisional, but the relation is a deliberate boundary-record size/span calculation rather than a generated indexing mistake.
