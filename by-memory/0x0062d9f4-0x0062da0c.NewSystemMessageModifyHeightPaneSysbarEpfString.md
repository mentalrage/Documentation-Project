## Summary

Exact UTF-16 `SYSBAR.EPF` literal used by `NewSystemMessageModifyHeightPane::OnPaint` to draw the newer system-message resize grip. IDA also labels `0x0062d9f8` as `SBAR.EPF`, but byte evidence shows that name is a tail label inside the longer `SYSBAR.EPF` source literal.

- 2026-06-12 A004 live IDA MCP `make_signature_for_range` on `0x0062d974-0x0062da10` returned UTF-16 `SYSBAR.EPF` from `0x0062d9f4` through the terminator at `0x0062da06`, followed by alignment through `0x0062da0c`.
- `entity_query`/`search_text` render the interior label `aSbarEpf` at `0x0062d9f8`, proving `SBAR.EPF` is a tail label, not a separate source literal.
- Existing system-message read-only-data evidence records the `SYSBAR.EPF` ref at `0x00588527`.
- [UID:00009B][NewSystemMessageModifyHeightPane](by-class/NewSystemMessageModifyHeightPane.md) maps `0x00588500-0x0058855b` as the paint routine that draws the resize grip using `SYSBAR.EPF` and `invenbut.pal`.
