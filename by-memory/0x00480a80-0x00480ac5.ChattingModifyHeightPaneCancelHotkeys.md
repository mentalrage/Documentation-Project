## Boundary

IDA models `sub_480A80` as `0x00480a80-0x00480ac5`, size `0x45`. The following `0x00480ac5-0x00480ad0` bytes are `0xcc` alignment before the line-count layout helper.

## Behavior

This helper reads a byte through `**(event + 12)` and checks for key values `0x2f`, `0x30`, or `0x42`. When one of those values is seen, it cancels an active drag by clearing `this + 0x58`, restores the stored rectangle at `this + 0x60` through a virtual layout call on the owner pane at `this - 0xa0`, and then invalidates or refreshes the owner rectangle at `this - 0xa0 + 0x44`.

The function always returns `0`, so it appears to be a side-effect-only input filter.
