# 0x0067ab4c-0x0067ab50 g_pMidiPlayer

## Summary

- Address range: `0x0067ab4c-0x0067ab50`
- Entity kind: global pointer
- Proposed name: `g_pMidiPlayer`
- Disposition: reconstructable NexusTK global data
- Confidence: strong for address and singleton role

This four-byte `.data` slot stores the active [UID:00008A][MidiPlayer](by-class/MidiPlayer.md) singleton used by application, main-menu, sound-status, and audio-control paths.

## Evidence

- Existing global documentation [UID:0000RM][g_pMidiPlayer](by-global/g_pMidiPlayer.md) identifies `0x0067ab4c` as the active MIDI singleton pointer.
- IDA MCP reports 18 direct refs to `0x0067ab4c`.
- `MidiPlayer` documentation records constructor/destructor ownership, while consumer refs include main-menu and sound-status paths such as [UID:00019J][0x004f69a0-0x004f6a31.CloseMainMenuDialogSingletons](by-memory/0x004f69a0-0x004f6a31.CloseMainMenuDialogSingletons.md), `0x00525dc0`, `0x00525eb0`, `0x00526570`, and `0x0057bf70` family users.
