## Behavior

This raw body is a non-deleting `PhotoPane` cleanup/destructor path that IDA does not model as a function start. It:

- preserves `esi` and treats `ecx` as the `PhotoPane` object;
- installs the three `PhotoPane` vtable pointers at `this + 0x0`, `this + 0xa0`, and `this + 0xa4`;
- destroys or releases the embedded cached `GrafPort`/surface subobject at `this + 0xf8` via `sub_4B8D20`;
- restores `ecx` to the containing `PhotoPane` object and tail-jumps to `0x00549ae0`, the `PhotoPane` non-deleting destructor that resets the object to `PictureViewPane` vtables and chains to pane teardown.

This is separate from the scalar deleting destructor at `0x005499c0-0x00549a22`, which performs the same embedded-surface teardown through a normal IDA-modeled function and conditionally frees object storage.
