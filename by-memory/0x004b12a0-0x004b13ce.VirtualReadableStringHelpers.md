## Behavior Summary

`0x004b12a0` is a by-value ANSI `ReadString(int count)` helper. The x86 ABI passes a hidden return-object pointer followed by the signed count and returns with `retn 8`. The function constructs directly into the hidden result, obtains position and size through File slots `+0x14/+0x1c`, clamps only counts larger than the available bytes, obtains the ANSI buffer through the current `SetLengthAnsiAndDetach` source API, reads through slot `+0x20`, resets/finalizes buffer state through `LockAnsiBuffer`, and unwinds the hidden result only when construction succeeded.

`0x004b1340` is `bool File::ReadLine(StringBaseW &line)`. It takes an explicit wide output reference, constructs a temporary ANSI string, calls ANSI `ReadLine` through slot `+0x24`, and only on success obtains the ANSI text, converts/assigns the wide destination, and destroys the conversion temporary. It always destroys the ANSI temporary and returns the virtual result.

The source-facing names are inferred but behaviorally complete. No raw vtable indexing, hidden-result parameter, EH label, offset, or decompiler temporary belongs in the emitted source.
