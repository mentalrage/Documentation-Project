# 0x00453820-0x00453904 WideStringMap Node Support

## Status

- Entity kind: shared helper function island
- Disposition: reconstructable NexusTK project support code
- Proposed owner: shared wide-string map/tree utility used by minimap and metadata code
- Rebuild handling: `source-authored`
- Confidence: strong for function boundaries and behavior; medium for final source-module name
- Evidence basis: IDA MCP `py_eval`, `decompile`, callers, and local historical report notes on 2026-05-27.

## Covered Functions

| Range | Proposed name | Notes |
| --- | --- | --- |
| `0x00453820-0x00453839` | `CreateWideStringMapSentinel` | Allocates a `0x2c`-byte node, self-links the first three pointer slots, and sets the sentinel/color flags word at `+0x0c` to `0x0101`. |
| `0x00453840-0x0045385d` | `CreateWideStringMapNodeFromHeader` | Allocates a `0x2c`-byte node and initializes the three link fields from the owner/header node. |
| `0x00453860-0x004538e8` | `DestroyWideStringMapNodes` | Recursively walks child links until the sentinel flag at `+0x0d`, frees heap-backed wide-string payload storage, resets the inline string fields, and frees each node. |
| `0x004538f0-0x00453904` | `FreeWideStringMapNode` | Thin wrapper around the shared deallocator at `0x005c7526`. |

## Behavior

This is the shared tree/list support island for a small-string wide-character keyed map. It is not a `MiniMapDialog` method even though nearby minimap code calls it.

The sentinel constructor initializes a self-linked node with sentinel/color flags. The cleanup routine treats offset `+0x0d` as the sentinel marker, recursively destroys the right/child chain at slot `+0x08`, advances through the left/next slot, and releases the UTF-16 small-string payload when the node capacity at `+0x24` is heap-backed.
