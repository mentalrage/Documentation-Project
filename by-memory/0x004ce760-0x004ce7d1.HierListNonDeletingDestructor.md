## Behavior

Runs the non-deleting destructor body for a `HierList`. It reinstalls the `HierList` vtable for destructor state, walks the base [UID:000079][List](by-class/List.md) rows, deletes each nested child list recorded in the row header, clears the child-list pointer, and then destroys the base list storage.

Step order:

1. Enter the destructor body at `0x004ce760`; the first bytes match an EH-aware destructor prologue.
2. Store the `HierList` vtable pointer `0x0061b344` back to `this + 0x00`.
3. Iterate from row index `0` while the index is below the base list count at `this + 0x0c`.
4. Fetch each row through the base list element accessor pattern.
5. Read the nested child-list pointer from [UID:0001UQ][HierListNode](by-type/by-struct/HierListNode.md) offset `+0x04`.
6. When the child list is non-null, dispatch its scalar deleting destructor and clear the row's child-list pointer.
7. After all rows are cleaned, call the base `List` non-deleting destructor at `0x004f30e0`.
8. Return without freeing `this`; object deallocation is handled by [UID:0002IM][0x004cedb0-0x004cee52.HierListScalarDeletingDestructor](by-memory/0x004cedb0-0x004cee52.HierListScalarDeletingDestructor.md) when the deleting-destructor flag requests it.
