## Behavior

Runs the non-deleting destructor body for a `HierList`. It iterates through the list rows, reads each node's child-list pointer at node offset `+0x04`, calls that child list's scalar deleting destructor when present, clears the child pointer, and finally destroys the base `List` storage.

## Evidence

- IDA MCP `py_eval` confirmed an IDA function object at `0x004ce760-0x004ce7d1`, size `0x71`.
- The function has exception-frame setup bytes at entry and loops over `this[3]`, the base list count field.
- Existing IDA caller checks found no direct modeled caller for this body; [UID:0002IM][0x004cedb0-0x004cee52.HierListScalarDeletingDestructor](by-memory/0x004cedb0-0x004cee52.HierListScalarDeletingDestructor.md) duplicates the teardown and applies delete-flag handling.

## Confidence And Caveats

The destructor role and range are strong. The exact original source relationship between this body and the scalar deleting wrapper still needs final C++ audit before adding reconstruction code.
