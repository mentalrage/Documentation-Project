## Behavior

`MemoryMan::AllocateBufferMemory(size_t size)` calls `malloc(size)` and returns the allocated block when the CRT allocation succeeds. On allocation failure, the source-level behavior is `throw new Win32Error;`: the binary allocates an 8-byte (`0x8`, Verified with int_convert.py) [UID:0000G7][Win32Error](by-class/Win32Error.md) object through the project global `operator new` wrapper, constructs it through [UID:0002HJ][0x004a60d0-0x004a60f5.Win32ErrorConstructor](by-memory/0x004a60d0-0x004a60f5.Win32ErrorConstructor.md), and throws the resulting pointer through `_CxxThrowException`.

If `new Win32Error` construction unwinds, the compiler cleanup funclet frees the raw exception allocation through the paired delete wrapper. That cleanup is MSVC exception support for the source expression and is not a separate handwritten source call.
