## Behavior

This constructor shares the same base/timer initialization pattern as the primary Motion animation constructor, then stores an explicit phase/frame byte, motion type, duration, and optional sound/effect override. It sets the frame flag byte for motion types `1` and `2`, otherwise uses the provided phase/control byte.

The sound/effect mapping largely matches the primary constructor but uses distinct ids for some higher cases: `23 -> 314` and `24 -> 315` in this alternate path. Motion type `16` again depends on the feature flag under `dword_67A7C8`; when disabled, the stored value is `-1`. If the caller-provided override argument is absent, the constructor stores `-1`.
