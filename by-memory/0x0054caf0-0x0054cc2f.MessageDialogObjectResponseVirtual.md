## Behavior Summary

The handler reads an action/event byte stream from the caller object at offset `+0x0c`.

- If the first byte is `0x2f`, it returns handled without sending a packet.
- If the first byte is not `0x30`, it returns false.
- For byte `0x30`, it reads a subcommand byte at payload `+2`, a 32-bit value at payload `+3`, touches payload `+7`, parses an [UID:0000M6][ObjectStatusBlob](by-file/ObjectStatusBlob.md) at payload `+8`, then reads two 16-bit values after the parsed blob and fixed trailing fields.
- It builds a 10-byte outgoing packet with opcode `0x3a`, the subcommand byte, the 32-bit value, the two 16-bit values, and a zero terminator, then queues it through [UID:0000Q5][g_packetSender](by-global/g_packetSender.md).

This is reconstructable project behavior, not compiler glue.
