# 0x00517090-0x005170d0 StringMenuItem Measure Text

## Status

- Entity kind: virtual class method.
- Owner: [UID:0000E8][StringMenuItem](by-class/StringMenuItem.md).
- Likely source file: [UID:0000MN][PopupMenuControls](by-file/PopupMenuControls.md).

## Behavior

Measures the string-menu-item label and returns item dimensions:

- scans the inline UTF-16 label at `this + 0x18` for length;
- calls text measurement helper `0x004ba9a0`;
- writes height `14` and width `measuredTextWidth + 24` to the caller-provided size result.

## Evidence

- IDA `lookup_funcs 0x00517090` reports start `0x00517090` and size `0x40`.
- IDA `xrefs_to 0x00517090` reports the `StringMenuItem` vtable slot at `0x0061ebc0`.
- IDA decompile shows the label scan, `sub_4BA9A0`, output `*a2 = 14`, and `a2[1] = measured + 24`.
