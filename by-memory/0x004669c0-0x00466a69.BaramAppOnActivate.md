## Behavior

`BaramApp::OnActivate` is the foreground transition handler for the game-client specialization of `Application`. It exits immediately when the transition guard byte at `this + 0x83a` is set. Otherwise it resumes timer/event ownership through `dword_67A754`, restores the map pane/window path when `dword_67A93C` is clear and [UID:0000S7][g_pScreenPane](by-global/g_pScreenPane.md) / `dword_67A7CC` is present, resumes the keyboard/background helper through `dword_67AB48`, and resumes sound/music state through `dword_67A7D0`, `dword_67A7C8`, and `dword_67AB4C`.

The visible app-state write is `*(g_pApplication + 0x838) = 1`, followed by `sub_557470(dword_67A7CC)` and `ShowWindow(*(g_pApplication + 0x828), 9)`. The audio resume tail is not contiguous with this app-lifecycle range: the local function jumps from `0x00466a62` to `0x0057a480`, which IDA includes in the decompilation but which sits in the audio-helper neighborhood.
