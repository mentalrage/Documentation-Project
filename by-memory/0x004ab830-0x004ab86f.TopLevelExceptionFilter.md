# 0x004ab830-0x004ab86f TopLevelExceptionFilter

## Status

- Disposition: reconstructable NexusTK project code
- Entity kind: Windows unhandled-exception filter callback
- Likely source module: [UID:0000J8][ExceptionHandler](by-file/ExceptionHandler.md)
- Confidence: strong for behavior and ownership.

## Behavior

`TopLevelExceptionFilter` is the callback installed by `ExceptionHandler::ExceptionHandler` through `SetUnhandledExceptionFilter`. IDA decompilation shows it:

- reads [UID:0000QN][g_pCrashTarget](by-global/g_pCrashTarget.md);
- restores saved keyboard-repeat settings through [UID:0000KJ][KeySpeedMgr](by-file/KeySpeedMgr.md) when that singleton is live;
- skips normal report generation when byte `[g_pCrashTarget + 4]` is set to `1`;
- otherwise calls the crash-report writer at [UID:00014G][0x004ab870-0x004abd10.ExceptionCrashReportWriter](by-memory/0x004ab870-0x004abd10.ExceptionCrashReportWriter.md);
- chains to the previous top-level filter stored at object offset `+8` when present;
- returns `0` when there is no active target, reporting is suppressed, or no previous filter exists.

## Evidence

- IDA MCP confirms the function at `0x004ab830` with size `0x3f`, ending at `0x004ab86f`.
- IDA caller evidence reports no direct code callers, which matches a Windows callback installed by pointer.
- IDA callee evidence shows only [UID:00014G][0x004ab870-0x004abd10.ExceptionCrashReportWriter](by-memory/0x004ab870-0x004abd10.ExceptionCrashReportWriter.md) and the [UID:0000KJ][KeySpeedMgr](by-file/KeySpeedMgr.md) restore method.
- `simroot_v2/class_ExceptionHandler.cpp` calls `SetUnhandledExceptionFilter(TopLevelExceptionFilter)` from the constructor but does not emit this callback body.

## Ownership Notes

This is source-level crash handling infrastructure, not a generic C runtime helper. Keep it with [UID:0000J8][ExceptionHandler](by-file/ExceptionHandler.md); [UID:0000II][Crasher](by-file/Crasher.md) only affects the suppress-report flag before deliberately raising an exception.
