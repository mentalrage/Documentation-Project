## Behavior

This helper skips the executable path, tokenizes the remaining command line on spaces with `_wcstok_s`, and requires exactly five non-null tokens before accepting the parse. The first token must case-insensitively match UTF-16 `/Bixel` at `0x006171d0`; the remaining four tokens are host, port, payload string 1, and payload string 2.

For host tokens beginning with an ASCII digit, it splits on `.` and parses the first four decimal octets with the Visual C wide decimal integer helper at `0x005cea43` (`_wtol` / wide decimal parse), storing the low byte of each octet into `m_startupAddress[4]` at `config + 0x2915b4`. Missing required octets quietly return; extra octets are ignored after the fourth write. For nonnumeric host tokens, it copies the wide host into `m_startupHostName[128]` at `config + 0x2915c4` through the project memmove wrapper at `0x00516220`, converts it to a `0x80` ANSI scratch buffer with `WideCharToMultiByte`, range-checks the byte count, calls `gethostbyname`, and copies four resolved address bytes into `m_startupAddress[4]`.

On success it parses the port token with the same wide decimal helper and writes normal startup port storage at `config + 0x2916c4`, sets `m_startupReady` at `config + 0x2916ca` to `1`, sets `m_startupConnectionMode` at `config + 0x28de28` to `5`, and converts the two trailing wide payload tokens into mode-dependent launcher payload slots at `config + 0x28d9e0` and `config + 0x28da20` with a `0x3f` byte output cap plus explicit NUL termination in each `0x40` slot.

Malformed token streams or selector mismatches format the UTF-16 message `이 버전의 바람의 나라는 Bixel 전용입니다. 입력정보에 오류가 있습니다.` and show it through `MessageBoxW`, followed by `PostQuitMessage(0)` and `__loaddll(0)`.
