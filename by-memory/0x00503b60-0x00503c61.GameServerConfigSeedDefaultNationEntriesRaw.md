# 0x00503b60-0x00503c61 - GameServerConfig Seed Default Nation Entries Raw

## Covered Range

| Range | IDA status | Role |

| `0x00503b60-0x00503c61` | valid code, no IDA function record | Resizes/seeds two default nation-entry records using string-table ids `0x9f` and `0xa0`. |

## Behavior

The helper ensures the nation-entry backing array has room for two `0x44` byte records, preserving the overlapping old prefix and freeing the old buffer when necessary. It then writes record ids `1` and `2`, copies two localized wide labels through string-table lookup helper `sub_4F0350`, and stores those labels into the `+0x02` label field of each [UID:0001UP][GameServerNationEntry](by-type/by-struct/GameServerNationEntry.md).

## IDA Evidence

- `lookup_funcs` reports `0x00503b60` as not a function, but byte decoding shows a normal function-shaped body beginning at `push ebp`.
- The body allocates `0x88` bytes, exactly two `0x44` records.
- It initializes the first word of each record to `-1` when allocating, then writes ids `1` and `2`.
- It calls `sub_4F0350` with ids `0x9f` and `0xa0`, then calls `wcscpy_s` into the record label slots.
- The body returns at `0x00503c60`, so the exact exclusive range is `0x00503b60-0x00503c61`; `0x00503c61-0x00503c70` is `0xcc` padding.

## Open Questions

- The final source name depends on what the two localized ids `0x9f` and `0xa0` represent in the original resource/string table.
