## Behavior

Scroll callback used when the embedded scroll pane changes position. The method receives the old scroll word and new scroll word. If they match, it returns the new value without changing object state.

When the value changes, it reads the embedded scroll child from `this + 0x11c`, stores the new list scroll position at `this + 0x108`, and compares the child current-value word at `scrollPane + 0xfe`. If the child already holds the new value, it skips the child invalidation. Otherwise it writes the new word to `scrollPane + 0xfe` and calls the child vtable slot `+0x20` with `scrollPane + 0x44`.
