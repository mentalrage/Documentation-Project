# 0x00421310-0x004216cb Early SimpleUString And Adjacent Helper Island

## Status

- Address range: `0x00421310-0x004216cb`
- Entity kind: mixed helper island / aggregate
- Disposition: mixed reconstructable project helpers, source-declared/generated-binary thunks, and runtime/STL helpers
- Likely owners: [UID:0000OB][StringUtil](by-file/StringUtil.md), [UID:0000JE][FittingRoom](by-file/FittingRoom.md), [UID:0000NY][SpecializedButtonPanes](by-file/SpecializedButtonPanes.md), and MSVC/Dinkumware runtime support
- Confidence: strong that this is not one `SimpleUString`-owned range; medium-high for the exact child split.

This page keeps the historical `SimpleUStringSso7` filename/UID as an aggregate anchor, but the middle of the range is no longer treated as `SimpleUString` code. IDA MCP confirms that only `0x00421310-0x00421362` and `0x00421590-0x004216cb` are the early UTF-16 SSO-7 string helpers. The intervening functions are pane destructor thunks, fitting-room entry cleanup helpers, a checkbox control-type helper, and MSVC vector/allocation support.

## Evidence

- IDA MCP function inventory on 2026-05-30 reports exact starts/ends at `0x00421310`, `0x00421370`, `0x00421380`, `0x004213e2`, `0x004213ed`, `0x004213f8`, `0x00421403`, `0x00421410`, `0x00421480`, `0x004214c0`, `0x004214d0`, `0x00421500`, `0x00421510`, `0x00421520`, and `0x00421590`.
- IDA byte audit confirms every intra-range gap listed above is `0xcc` alignment padding.
- `simroot_v2/class_SimpleUString.cpp` emits only the `0x00421310` clear helper and `0x00421590` counted wide helper from this range.
- `simroot_v2/class_FittingRoomListPane.cpp` and historical Wave2 notes identify the `0x00421380` / `0x004214d0` helpers as fitting-room selection/cart entry cleanup support.
- IDA data refs tie `0x00421410` to `FittingRoomListPane` vtables, `0x00421480` to scroll-pane-family vtables, and `0x004214c0` to checkbox/control vtables.
- IDA decompilation of `0x00421500`, `0x00421510`, and `0x00421520` matches MSVC/Dinkumware vector/runtime support, not NexusTK-authored string code.

## Ownership Decision

Keep this as an aggregate map only. Do not use the full `0x00421310-0x004216cb` range as proof that the middle functions belong to `SimpleUString` or `StringUtil`. For source reconstruction:

- `0x00421310` and `0x00421590` remain under [UID:0000D9][SimpleUString](by-class/SimpleUString.md) / [UID:0000OB][StringUtil](by-file/StringUtil.md).
- `0x00421380`, `0x00421410`, and `0x004214d0` belong to fitting-room list/selection cleanup.
- `0x00421480` and the nearby adjustor thunks are generated scroll-pane destructor support.
- `0x004214c0` belongs to [UID:000022][CheckBoxTextControlPane](by-class/CheckBoxTextControlPane.md).
- `0x00421500`, `0x00421510`, and `0x00421520` are MSVC/STL runtime/vector support and should not be ported as NexusTK-owned code.
