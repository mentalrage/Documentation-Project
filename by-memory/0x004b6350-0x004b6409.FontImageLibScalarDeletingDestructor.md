# 0x004b6350-0x004b6409 FontImageLib Scalar Deleting Destructor

## Status

- Entity kind: scalar deleting destructor.
- Owner: `FontImageLib`.
- Rebuild handling: `compiler/linker-generated` wrapper around source-authored destructor semantics.
- Evidence: IDA MCP `lookup_funcs` reports `sub_4B6350` size `0xb9`; the byte at `0x004b6408` is the final byte of `retn 4`.
- C++ reconstruction status: reconstructable only as destructor semantics; do not hand-port the scalar-deleting wrapper itself unless matching compiler output is intentionally modeled.

## Behavior

This function is the scalar deleting destructor entry used by the `FontImageLib` vtable. It performs the same cleanup as the ordinary destructor and optionally frees the object depending on the compiler-supplied deleting-destructor flag.

Observed cleanup:

- restores the `FontImageLib` vtable while destructing;
- iterates over both font slots;
- for any loaded slot DATFile pointer, calls the DATFile deleting destructor path;
- frees the shared scratch buffer at `this + 0x80014` when present;
- clears `g_pFontImageLib` at `0x0067ab24`;
- calls the base/object destructor;
- conditionally invokes delete/free for `this` based on the deleting-destructor flag;
- returns with `retn 4`.

## Classification Notes

The underlying destructor behavior must be represented in source, but the scalar-deleting wrapper shape is MSVC-generated. Reconstruction should normally define the class destructor and let the compiler emit the deleting destructor, rather than writing a source-level function that imitates this wrapper.
