# 0x00622f54-0x006230c8 Region/Menu Pane Read-Only Data

## Range

- Address range: `0x00622f54-0x006230c8`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and menu string literals must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains the `Region` complete-object locator and vtable, right-click/vote menu pane vtables, and short menu command strings. It starts immediately after the preceding `Baram` string terminator and ends before the `RingBuffer` complete-object-locator pointer.
