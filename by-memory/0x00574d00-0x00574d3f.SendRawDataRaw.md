## Behavior

The raw body matches the generated `CashShopRequest::SendRawData(uint32_t size, void* data)` behavior:

1. Saves `this` from `ecx`.
2. Calls the shared allocator manager getter at `0x00516030`.
3. Reads `size` from `[ebp+8]`.
4. Allocates exactly `size` bytes through `0x00516050`.
5. Copies `size` bytes from `[ebp+0x0c]` into the allocated buffer through `0x00516220`.
6. Calls [UID:0001JY][0x00596620-0x005969b0.CashShopRequestWaitDispatch](by-memory/0x00596620-0x005969b0.CashShopRequestWaitDispatch.md) at `0x00596960` with request code `0x0e`, request field `size`, and request field `buffer`.

This differs from [UID:0001HU][0x00574bb0-0x00574c13.QueueAndSendPacket](by-memory/0x00574bb0-0x00574c13.QueueAndSendPacket.md), which appends a trailing zero and dispatches request code `8` with payload pointer first and size second. This raw helper dispatches request code `0x0e` and does not append a terminator.
