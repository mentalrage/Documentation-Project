## Behavior

This method resolves a glyph record from a lazily loaded font slot, returns glyph metrics, and optionally decodes the glyph image into a caller-provided drawing/tile context.

Observed flow:

- calls `FontImageLib::EnsureFontSlotLoaded` at `0x004b60c0`;
- indexes the slot glyph pointer table at `slot + 8 + 4 * uint16(glyphId)`;
- falls back to glyph id `63` if the glyph pointer is null;
- treats glyphs with `right - left == 0` as missing and also falls back to glyph id `63`;
- reads `FontGlyphRecord` fields:
  - `record + 0x00`: advance;
  - `record + 0x02`: top;
  - `record + 0x04`: left;
  - `record + 0x06`: bottom;
  - `record + 0x08`: right;
- writes an optional bounds rectangle through helper `0x004b7c50`;
- writes the optional advance output from `record + 0x00`;
- initializes the optional tile/drawing context with `0x00458500`;
- calls `FontImageLib::DecodeGlyphBitmap` at `0x004b61e0` when decode output is requested.
