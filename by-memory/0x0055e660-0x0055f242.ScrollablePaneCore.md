## Behavior Summary

This cluster implements the active `ScrollablePane` body around owned horizontal and vertical [UID:0000CM][ScrollPane](by-class/ScrollPane.md) children. The constructor creates a horizontal `ScrollPane(1)` and vertical `ScrollPane(0)`, initializes content/viewport rectangle state, and leaves destructor/default virtual handling to the later [UID:0001H6][0x005654ec-0x00565608.ScrollablePaneVirtualDefaults](by-memory/0x005654ec-0x00565608.ScrollablePaneVirtualDefaults.md) cluster. The layout path toggles scrollbar visibility, computes high/low-resolution scrollbar bounds, and shrinks the content rectangle around enabled bars.

Layer membership and input helpers keep the owned scrollbar children synchronized with the base pane. Add/remove paths attach or detach enabled scrollbar children alongside the base pane; mouse/key dispatch gives the child scrollbars first chance to consume input before falling back to owner behavior; the update path temporarily intersects the visible region with the content region while the scroll update hook runs.

Do not document this as one broad `0x0055e660-0x00565608` contiguous class range. The intervening corridor contains mixed `TextEditPane` scrollbar code, and the later default/destructor cluster is already split into its own exact page.
