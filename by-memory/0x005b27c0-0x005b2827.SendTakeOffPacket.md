## Behavior

This helper sends a two-byte take-off/equipment-removal packet when the active dialog/input gate byte is not positive:

- packet opcode `0x1f` / decimal `31`;
- selector byte supplied as the helper argument;
- length `2`;
- sender global [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) / `dword_67A7EC`.

The function checks [UID:0000PQ][g_activeDialogCount](by-global/g_activeDialogCount.md) / `byte_69B380` before sending.

## IDA Evidence

- `TakeOffInputPane::ProcessUnequipCommand` calls this helper fourteen times for the all-equipment path.
- `SelfLookPane::OnMouseClick` also calls this helper for equipment-slot clicks, so the helper is not exclusively a `TakeOffInputPane` method.
