## Behavior

This helper sends a two-byte take-off/equipment-removal packet when the active dialog/input gate byte is not positive:

- packet opcode `0x1f` / decimal `31` (Verified with `int_convert.py`);
- one-based equipment selector byte supplied as the helper argument;
- length `0x2` / decimal `2` (Verified with `int_convert.py`);
- sender global [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) / `dword_67A7EC`.

The function checks [UID:0000PQ][g_activeDialogCount](by-global/g_activeDialogCount.md) / `byte_69B380` before sending.

The B006 source-quality recheck resolves the best current source-facing signature as `void SendTakeOffPacket(char equipmentSlotSelector)`. The local stack shape is a 128-byte packet scratch buffer plus compiler security-cookie storage (`sub esp, 0x84`); `packet[2] = 0` is a local scratch terminator and is not sent. The second byte is the selector, not a subtype, string byte, or length-prefixed field.

Valid selectors proven by the TakeOff table and caller constants are `1,2,3,4,6,7,8,13,14,16,20,21,22,23`.
