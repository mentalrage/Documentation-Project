# 0x004a78f0-0x004a7978 EventDispatcher Find Handler Iterator

## Behavior

This helper scans the dispatcher handler-record vector through a `TreeItor<EventHandler*>`-style iterator and searches for a matching enabled handler.

Observed behavior from IDA MCP:

- Builds a stack `HandlerFindFunc` predicate with the requested handler value.
- Reads the vector begin/end pair from the iterator's tree object and computes a 28-byte record count.
- Skips records whose byte at record offset `0x18` is set.
- Compares the stored handler field at record offset `0x14` through `HandlerFindFunc::IsMatch`.
- On match, writes the found record index to iterator offset `0x08` and returns true.
- Returns false when no enabled matching record exists.
- 2026-05-31 recheck: IDA MCP `lookup_funcs` reports `sub_4A78F0` size `0x89`; decompilation still shows the enabled-record scan, `record + 0x14` predicate call, byte `+0x18` skip, and iterator `+0x08` index write.
