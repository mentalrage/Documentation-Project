Observed flow:

- clamps the requested line count to a maximum of `50`;
- then clamps to a minimum of `4`;
- updates the chat back-pane viewport through `dword_67ADD0`, using rectangle `(9, 700 - 13 * count, 816, 720)`;
- refreshes the back pane's current rectangle;
- updates the display pane visible row count through [UID:0002EW][0x0047fbd0-0x0047fc6b.ChattingPaneSetVisibleRowCount](by-memory/0x0047fbd0-0x0047fc6b.ChattingPaneSetVisibleRowCount.md);

- stores that handle rectangle at `this + 0x100`.
