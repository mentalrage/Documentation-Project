# 0x00554a20-0x00554adb - Region Raw Rectangle Helpers

## Status

- Disposition: reconstructable source helper cluster inside [UID:0001FW][0x00554680-0x00554b38.RegionAndMotionRect](by-memory/0x00554680-0x00554b38.RegionAndMotionRect.md).
- Rebuild handling: source-authored rectangle/dirty-region helper logic; compiler emits the local stack-cookie checks and `0xcc` alignment.
- Likely owner: [UID:0000N3][Region](by-file/Region.md), with final names still provisional because IDA has no function objects for three of the four starts.
- Confidence: strong for bytes and behavior; medium-high for source naming because `Motion`/`Region` helper names are still mixed.

## Covered Range

| Range | IDA status | Behavior |
| --- | --- | --- |
| `0x00554a20-0x00554a3c` | raw function-shaped bytes | Intersects this object's stored rect at `this + 4` with another object's stored rect at `arg + 4`; third output argument is zero. |
| `0x00554a3c-0x00554a40` | padding | Four `0xcc` bytes. |
| `0x00554a40-0x00554a56` | raw function-shaped bytes | Tests whether an external rect contains/interacts with this object's stored rect through `sub_4B7F30`. |
| `0x00554a56-0x00554a60` | padding | Ten `0xcc` bytes. |
| `0x00554a60-0x00554a9b` | IDA function `sub_554A60` | Copies another object's stored rect to a stack `RECT`, then checks containment against this object's stored rect through `sub_4B7F30`. |
| `0x00554a9b-0x00554aa0` | padding | Five `0xcc` bytes. |
| `0x00554aa0-0x00554adb` | raw function-shaped bytes | Copies another object's stored rect to a stack `RECT`, then calls `sub_4B7ED0` with this object's stored rect. |

## Behavior Notes

- All four helpers operate on the same object layout used by the broader Region/Motion rectangle island: vptr/base at `+0x00`, rectangle storage at `+0x04`.
- `0x00554a20` is a raw object-to-object intersection wrapper over `sub_4B7CC0(this + 4, arg + 4, 0)`.
- `0x00554a40` is a raw wrapper over `sub_4B7F30(arg, this + 4)`.
- `0x00554a60` and `0x00554aa0` copy `*(arg + 4)` into stack storage before calling their lower-level rectangle predicate helpers, matching object-to-object wrappers around raw `RECT` primitives.
- The stack-cookie checks in `0x00554a60` and `0x00554aa0` are compiler support, not source-level control flow.
