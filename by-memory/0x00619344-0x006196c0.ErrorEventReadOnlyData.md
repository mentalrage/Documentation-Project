# 0x00619344-0x006196c0 Error/Event Read-Only Data

## Range

- Address range: `0x00619344-0x006196c0`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: `source-declared/generated-binary`

## Summary

This `.rdata` span contains the Error hierarchy vtables, error message format strings, WinInet/import helper constants, and Event/EventDispatcher vtables. It replaces the error/event portion of the old unchecked `0x006192c6-0x0061a5c4` UNKNOWN row.

## Observed Contents

- Exact [UID:0002ND][0x00619344-0x00619448.ErrorHierarchyVtableData](by-memory/0x00619344-0x00619448.ErrorHierarchyVtableData.md) child for `Error`, `Win32Error`, `DIError`, `DDError`, `DSError`, `ErrorMessage`, `FileError`, `WSAError`, `InternetError`, `InternetConnectionError`, and `MyError`.
- Error format strings such as `Win32Error`, `CTInputError`, `CTDrawError`, `CTSoundError`, `WSAError`, and `WININET.DLL`.
- Vtables for `Tree<EventHandler*>`, `EventDispatcher`, `HandlerFindFunc`, `TreeItor<EventHandler*>`, `EventHandler`, `Event`, and `EventMan`.

## Evidence

- IDA MCP `py_eval` on 2026-05-28 reports 46 named items in this exact range before the `ExceptionHandler` vtable.
- IDA MCP on 2026-05-31 verified exact error hierarchy vtable child [UID:0002ND][0x00619344-0x00619448.ErrorHierarchyVtableData](by-memory/0x00619344-0x00619448.ErrorHierarchyVtableData.md) with named vtable bases, slot dwords, constructor/store xrefs, and the `0x00619448` wide-string boundary.
- Representative xrefs include Error hierarchy code at `sub_4A60D0-0x004a6a10` and Event/EventDispatcher code around `sub_4A6A80`, `sub_4A7D80`, and `sub_4A7E00`.
