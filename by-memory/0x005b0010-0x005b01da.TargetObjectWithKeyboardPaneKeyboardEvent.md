## Role

Handles keyboard input for the target-dispatch selector. The method normalizes the event key byte through the shared `std::ctype<char>::do_narrow` facet, rejects events with low modifier/state bits set at `event + 0x10a`, then dispatches through a jump table for cancel, dispatch-mode, self-target, previous/up, and next/down keys. It updates `dword_69BF2C` as the saved target id, clears or sets `LivingObjectPane` highlights, forwards cancel as Escape to the line-input base, and enters the target-dispatch map-state helper for Tab/`v` when the config gate allows it.
