## Behavior

This helper draws a single `NewOptionPane` option button or page-arrow entry.

Observed flow:

1. Computes an option-entry record pointer with stride `0x98` bytes (`152 * itemIndex + this`).
2. Checks the entry page/state byte at record offset `0x18c` against the current page byte at `this + 0x12b9`, allowing entries marked `-1`.
3. Switches on the entry type byte at record offset `0x178`.
4. Draws the appropriate button frame with the tile/frame helper at `0x004b9980`.
5. Draws the entry label from record offset `0xf8` twice with colors `6` and `0x80`, offset by one pixel for the caption effect.
