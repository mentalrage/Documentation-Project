## Behavior

This confirmed action sends board/article delete requests after the user accepts the delete confirmation alert.

The documented packet shape is opcode `0x3b`, subcommand `0x05`. The action handles both single-delete and multi-delete paths: a single selected entry is serialized directly, while a multi-delete list emits one delete packet per selected entry. The method also updates the active player/delete context and then processes the bulletin queue.
