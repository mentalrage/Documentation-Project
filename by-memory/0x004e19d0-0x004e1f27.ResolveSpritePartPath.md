## Behavior

The helper first formats `<base>0.EPF` and probes it through [UID:0000T0][HasDATEntry_49C700](by-global/HasDATEntry_49C700.md). If numbered archives exist, it counts consecutive `<base>%d.EPF` shards, opens each shard through temporary `DATFile` objects, reads each archive header, sums record counts, tracks maximum header metrics, allocates one merged metadata table, copies each raw record into a 24-byte packed record, normalizes the rectangle fields, rebases payload start/end offsets by the owning DAT payload base, appends a zero-rectangle terminal sentinel, closes and destroys temporary readers, frees temporary arrays, and returns the merged table pointer.

If the numbered probe fails, it formats `<base>.EPF`, opens that single archive when present, reads the same header/record format, allocates `24 * (recordCount + 1)` record storage, normalizes/rebases the records, appends the terminal sentinel, closes the temporary reader, and returns the table pointer. If neither form exists, the helper returns null.
