If the numbered probe fails, it formats `<base>.EPF`, opens that single archive when present, reads the same header/record format, allocates `24 * (recordCount + 1)` record storage, normalizes/rebases the records, appends the terminal sentinel, closes the temporary reader, and returns the table pointer.
