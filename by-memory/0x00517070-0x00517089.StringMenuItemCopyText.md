# 0x00517070-0x00517089 StringMenuItem Copy Text

## Status

- Entity kind: class method.
- Owner: [UID:0000E8][StringMenuItem](by-class/StringMenuItem.md).
- Likely source file: [UID:0000MN][PopupMenuControls](by-file/PopupMenuControls.md).

## Behavior

Copies the inline label buffer at `this + 0x18` into a caller-provided wide-character destination buffer using `wcscpy_s`.

## Evidence

- IDA `lookup_funcs 0x00517070` reports start `0x00517070` and size `0x19`.
- IDA decompile returns `wcscpy_s(Destination, SizeInWords, this + 12)` where `this` is typed as `wchar_t *`; that is byte offset `+0x18`.
