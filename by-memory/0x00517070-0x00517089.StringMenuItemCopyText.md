## Behavior

Copies the inline label buffer at `this + 0x18` into a caller-provided wide-character destination buffer using `wcscpy_s`, then returns the CRT `errno_t` result from that copy.

Historical pre-Gate-2B IDA typed the receiver as `const wchar_t *`, so the old decompiler output printed `this + 12`. The persisted type now identifies `const StringMenuItem *this` and decompiles the field as `this->m_text`; the instruction stream still uses `lea eax, [ecx+18h]`, making the byte offset independently unambiguous. The method does not null-check the receiver or destination, does not mutate the menu item, does not allocate, does not validate the string, and relies on the caller-supplied `sizeInWords` argument for destination bounds.
