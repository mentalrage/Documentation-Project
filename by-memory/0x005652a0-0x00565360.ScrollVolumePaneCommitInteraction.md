## Behavior

1. Reads the current input/cursor point through `dword_67A754` using the cursor helper at `0x004a9090`.
2. Fetches the pane origin with `0x005447c0`, then subtracts that origin from the cursor point to convert the coordinates into the pane-local system.
3. Treats `(-1000, -1000)` as the no-position sentinel only when both coordinates match the sentinel value.
4. If the active interaction part at `this+0x104` is part `2` (the thumb), dispatches directly to [UID:0001H5][0x00565360-0x00565488.ScrollVolumePaneNotifyValueChange](by-memory/0x00565360-0x00565488.ScrollVolumePaneNotifyValueChange.md).
5. Otherwise hit-tests the local point with [UID:0001H3][0x00564e30-0x00565006.ScrollVolumePaneHitTestPart](by-memory/0x00564e30-0x00565006.ScrollVolumePaneHitTestPart.md); only a result matching `this+0x104` is allowed to notify the value-change helper.
6. Clears any stale highlighted part at `this+0x103`: if the byte is not `0xff`, it computes that part's rectangle through `0x00565010`, invalidates it through the pane vtable slot at `+0x20`, then writes `0xff` back to `this+0x103`.
