## Evidence Notes

- Wave3 method ranges and IDA MCP function extents agree.
- IDA MCP reports scheduler insertion callers in the `0x004b6d00`/`0x004b6d30` wrapper neighborhood.
- IDA MCP on 2026-05-24 shows `0x004b6d00` and `0x004b6d20` are broad frame-handler wrappers. Generated WorldMap names for these addresses should not be used for source ownership.
- IDA MCP on 2026-05-25 confirms `FrameMgr` uses the shared [UID:0000KR][LinkedList](by-file/LinkedList.md) helpers: constructor calls `CreateListNode`, insertion calls `CreateListNodeWithPayload`, and destructor directly calls `0x00457430` list-state cleanup.
