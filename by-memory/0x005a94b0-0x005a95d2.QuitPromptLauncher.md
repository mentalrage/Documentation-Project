## Behavior

The launcher is the shared entry point for the in-game quit prompt.

| Branch | Condition | Effect |
| --- | --- | --- |
| Modal prompt | `byte_66DA97 == 1` | Allocates the larger `0x270`-byte modal [UID:0000BG][QuitDialog](by-class/QuitDialog.md) path, using localized string id `3` and the alert/dialog pane family. |
| Typed prompt duplicate guard | `byte_66DA97 != 1` and [UID:0000S1][g_pQuitInputPane](by-global/g_pQuitInputPane.md) is non-null | Returns without constructing another typed quit prompt. |
| Typed prompt creation | `byte_66DA97 != 1` and [UID:0000S1][g_pQuitInputPane](by-global/g_pQuitInputPane.md) is null | Allocates the `0x108`-byte [UID:0000BH][QuitInputPane](by-class/QuitInputPane.md), initializes it through the input-pane base setup, publishes the singleton, and installs the three `QuitInputPane` vtable views. |
| Typed prompt fallback clear | adjusted construction result is null | Clears `dword_69BF5C` after the inherited/base-adjusted null path so the singleton does not retain a bad prompt pointer. |

Both prompt variants use localized string id `3`; the mode byte selects the visual form, not the semantic quit action.
