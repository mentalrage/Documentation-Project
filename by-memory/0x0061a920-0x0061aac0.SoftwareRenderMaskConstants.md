## Summary

This exact child range contains repeated packed RGB555/RGB565 mask and blend constants consumed by the software-render callback families. The table begins at `xmmword_61A920` after the `GrafPort` diagnostic string and ends before `CachedHashTable` RTTI at `0x0061aac0`.

## Reconstruction Notes

Regenerate these constants as static masks or vector constants in the shared software-render source. Do not attach them to `GrafPort` merely because the table sits in the same `.rdata` neighborhood as the `GrafPort` vtable and diagnostic string.
