## Behavior

This `ChattingBackPane` virtual method updates the chat background pane's visible/active state, alpha-like field, and draw-color state from the chat handle/global state rooted at `dword_67ADE0`.

Observed flow:

- reads `*(dword_67ADE0 + 0x114)` as a mode/state value;
- requires that state to be nonzero and `*(dword_67ADE0 + 0x118)` to be nonzero before enabling the active branch;
- when active and state equals `1`, writes `0.7f` (`0x3f333333`) to `this + 0x90`;
- when active and state is any other nonzero value, writes `0.3f` (`0x3e99999a`) to `this + 0x90`;
- calls [UID:0002V7][0x005446b0-0x005446d4.PaneSetMode](by-memory/0x005446b0-0x005446d4.PaneSetMode.md) with mode `2` and the [UID:000162][0x004b95e0-0x004b969f.GrafPortDrawStateAccessors](by-memory/0x004b95e0-0x004b969f.GrafPortDrawStateAccessors.md) color-state setter with value `0x80` in the active branch;
- otherwise calls `PaneSetMode(this, 1)` and the same `this + 0x74` draw-color setter with value `0`;
- finally calls [UID:0000TN][SurfaceRenderCallbackTable](by-global/SurfaceRenderCallbackTable.md) slot `dword_69B3FC` with `this` and `this + 0x44`, invalidating or refreshing the pane rectangle.
