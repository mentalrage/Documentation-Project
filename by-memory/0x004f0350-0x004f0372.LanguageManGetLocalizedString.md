## Behavior

This method returns a pointer to a localized UTF-16 string from the table loaded from `str.res`. The method treats the stack argument as a signed string id, rejects negative ids, rejects ids greater than or equal to `m_stringCount`, and returns the static fallback literal `L"Invalid String ID"` at `0x0061ca20` for rejected ids. In-range ids return `m_strings[stringId]`.
