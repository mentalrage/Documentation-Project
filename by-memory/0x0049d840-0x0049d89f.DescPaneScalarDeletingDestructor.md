# 0x0049d840-0x0049d89f DescPane Scalar Deleting Destructor

## Status

- Disposition: reconstructable NexusTK project code
- Entity kind: scalar deleting destructor
- Owner class: [UID:00003Q][DescPane](by-class/DescPane.md)
- Likely source module: [UID:0000IS][DescPane](by-file/DescPane.md)
- Confidence: strong.

## Behavior

The scalar deleting destructor restores all three `DescPane` vtables, clears [UID:0000QR][g_pDescPane](by-global/g_pDescPane.md), destroys the `Pane` base through `0x00544580`, and optionally frees object storage according to the MSVC deleting-destructor flags.

The object-free path is skipped when the scalar-delete flag bit is clear or the vector-delete flag bit `4` is set.
