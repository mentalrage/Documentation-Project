# 0x004708d0-0x00470953 AdviseConnectionPoint

## Scope

- Range: `0x004708d0-0x00470953` half-open.
- Entity kind: browser/OLE free helper.
- Direct owner: [UID:0000HV][Browser](by-file/Browser.md).
- Parent inventory: [UID:0000ZF][0x0046f010-0x004710b8.BrowserOleLegacyAndHelpers](by-memory/0x0046f010-0x004710b8.BrowserOleLegacyAndHelpers.md).

`AdviseConnectionPoint` is the browser module helper that locates `IConnectionPointContainer`, finds a connection point for an event IID, calls `Advise`, and releases temporary COM interfaces.

## IDA Evidence

- 2026-06-10 B001-024 live IDA MCP reports `sub_4708D0` at `0x004708d0-0x00470953`.
- Direct callers are `0x00469910` in BrowserWindow setup, `0x0046b898` in BrowserControlPane setup, and `0x00470cc3` in BrowserThread host initialization.
- Decompilation returns `E_INVALIDARG` for a null source interface, queries `IConnectionPointContainer` using GUID data at `0x00613140`, calls `FindConnectionPoint`, calls `Advise`, releases the connection point and container, and returns the HRESULT.
- [UID:0000HV][Browser](by-file/Browser.md) already lists this as a shared browser COM helper, not a class method.

## Reconstruction Notes

Attach to the Browser file/module. The helper is file-level browser OLE support shared by BrowserWindow, BrowserControlPane, and BrowserThread.
