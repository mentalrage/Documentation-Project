## Behavior

This helper looks up the expected minimap file version/hash string for a map id:

- treats `this + 0x48` as the manager-owned [UID:0000IP][DATIndexVector](by-file/DATIndexVector.md) hash-index subobject;
- passes the incoming 32-bit map id by address to [UID:0000XX][0x00457580-0x00457613.DATIndexVectorFindNodeByKey](by-memory/0x00457580-0x00457613.DATIndexVectorFindNodeByKey.md);
- compares the returned node pointer against the manager's list sentinel at `this + 0x4c`;
- returns null when the id is not present;
- otherwise returns the node payload at `node + 0x0c`, currently a `wchar_t*` buffer copied from the minimap hash-list entry.

IDA types the parameter as `char` because the stack frame only needs the address of the first argument byte, but callers push a full map id dword and `FindNodeByKey` hashes four bytes. Treat the argument as a 32-bit key until stronger type evidence appears.
