## Observed Bytes

IDA raw disassembly at `0x00462120-0x00462160` initializes an empty owning alpha surface:

| Address | Operation |
| --- | --- |
| `0x00462120-0x00462123` | Saves `esi` and copies `this` from `ecx`. |

| `0x00462155` | Calls `RectBounds` initializer `0x004b7c50` for zero bounds. |
| `0x0046215d-0x00462160` | Returns `this`. |
