# 0x00631660-0x00631850 LibJpeg 6b Message Pointer Table

## Summary

- Address range: `0x00631660-0x00631850`
- Entity kind: third-party static pointer table
- Disposition: reconstructable third-party static-embed data.
- Rebuild handling: regenerated by compiling/linking IJG libjpeg 6b `jerror.c`; do not recreate as NexusTK product source data.
- Parent: [UID:0000KN][LibJPEG](by-file/LibJPEG.md)

This exact `.rdata` child is the IJG libjpeg standard message table installed by the error-manager initializer at `0x00401000`. It contains 124 pointer-sized entries in the current binary, from `0x006707d4` through `0x00671a34`, and ends immediately before the libjpeg read-only table island at `0x00631850`.

The half-open range is `0x1f0` / 496 bytes, exactly 124 four-byte pointers. The table indices are `0..123`; the `last_jpeg_message` value `123` written by `jpeg_std_error` is the final valid index, not the number of messages.
