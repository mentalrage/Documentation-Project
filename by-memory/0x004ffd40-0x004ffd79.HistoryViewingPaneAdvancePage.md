# 0x004ffd40-0x004ffd79 - HistoryViewingPane Advance Page

## Status

- Confidence: strong for function boundary and owner.
- Owner: [UID:000066][HistoryViewingPane](by-class/HistoryViewingPane.md) / [UID:0000JW][HistoryViewingPane](by-file/HistoryViewingPane.md).
- Disposition: private reconstructable helper for the pre-login story/history viewer.

## Behavior

This helper advances the full-screen story/history viewer page index. If the current frame/page field at offset `+0xf8` is below the total frame-count field at `+0xfc`, it clamps the first advance to page `3` and then increments on later advances. After updating, it invalidates/redraws through the pane virtual at vtable offset `0x20` on the embedded pane subobject at offset `+0x44`.
