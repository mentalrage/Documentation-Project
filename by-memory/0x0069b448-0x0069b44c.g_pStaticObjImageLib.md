# 0x0069b448-0x0069b44c - g_pStaticObjImageLib

- Disposition: reconstructable NexusTK project global data.
- Confidence: strong for exact address, size, owner, lifecycle writes, startup/shutdown use, and direct consumer reads; final source-facing alias confidence remains below the final-code threshold.
- Entity kind: 4-byte global singleton pointer in `.data`.
- IDA name: `dword_69B448`.
- Canonical global doc: [UID:0000SD][g_pStaticObjImageLib](by-global/g_pStaticObjImageLib.md), currently `80/88` and reconstructable, so the parent attachment gate is satisfied.

The static file image carries the sentinel value. Runtime construction publishes the meaningful pointer, and destruction/cleanup paths clear it back to null.

## Evidence Notes

- Live IDA MCP on 2026-06-05 reports item head `0x0069b448`, size `4`, segment `.data`, name `dword_69B448`, bytes `ff ff ff ff`, and 13 direct xrefs.
- `0x004dcf60-0x004dd1d8` is the singleton constructor body. It stores `this` at `0x004dcfa3`, clears the slot on the constructor guard/fallback path at `0x004dcfaa`, installs the `StaticObjImageLib` vtable, parses static-object table data, and loads the modern `TILEC.EPF` / `TILEC.TBL` path or the legacy `TILEC.EPD` / `TILEC.TBD` path.
- IDA callers show `0x004dcf60` has one direct startup caller at `0x004f607b` inside `0x004f5fb0-0x004f6490`.
- `0x004dd1e0-0x004dd2be` is the ordinary destructor body and clears `dword_69B448` at `0x004dd29b` after freeing static-object records, tile catalog/cache state, tile-class data, and base image-library state.
- `0x004e5c00-0x004e5c0b` is a tiny cleanup helper whose whole body is `dword_69B448 = 0`.
- `0x004e6990-0x004e6aa6` is the scalar deleting destructor body and clears `dword_69B448` at `0x004e6a5e` before conditional object deletion.
- `0x004f6490-0x004f66a5` is called by `_WinMain@16` at `0x004f5e8e`; its shutdown sweep reads `dword_69B448` at `0x004f65e2` and invokes the singleton deleting destructor when non-null.
- Touched state: five direct lifecycle writes/clears and eight direct reads. The reads are concentrated in map/static-object setup, `StaticObjectPane`, photo composition, and application shutdown paths.
- This slot stays distinct from the neighboring effect-object singleton at `0x0069b44c`, new-human singleton at `0x0067a760`, monster/riding singletons at `0x0069b440`/`0x0069b444`, and the static object gameplay/cache globals documented separately.
