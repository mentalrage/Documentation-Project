# 0x0061c364-0x0061c5a4 IME Pane Read-Only Data

## Range

- Address range: `0x0061c364-0x0061c5a4`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and string literals must be reconstructed; vtables are compiler-emitted from those class definitions.

## Summary

This `.rdata` span contains the vtables and mode/status strings for the IME pane family. It starts at `IMEStatusPane` and ends immediately before the `InputMan` vtable at `0x0061c5a4`.
