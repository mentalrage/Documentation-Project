## Behavior

Loads a DAT-backed EPF/EPD resource index by resource name and appends a 44-byte layout-name record to the image-layout registry list at object offset `+0x0c`.

IDA MCP decompilation on 2026-05-31 shows this method:

- initializes a DAT-file reader, opens the wide resource name, and reads an 8-byte header into four `uint16` values;
- reads a 4-byte table offset, seeks to that table, and allocates `24 * (entryCount + 1)` bytes for [UID:0000VB][ResourceLayoutEntry](by-item/ResourceLayoutEntry.md) rows;
- reads each raw table row as four signed 16-bit bounds plus two 32-bit offsets;
- calls the rectangle initializer at `0x004b7c50` with reordered `left, top, right, bottom` arguments;
- converts pixel and encoded-mask offsets into absolute data pointers by adding the DAT payload base plus `0x0c`;
- appends a zero-bounds sentinel entry whose offsets point at the table boundary, allowing later mask-size calculation for the last real entry;
- copies the resource name into a 16-wide-character buffer and appends the 44-byte [UID:0001VT][ResourceLayoutNameRecord](by-type/by-struct/ResourceLayoutNameRecord.md) through the registry [UID:000079][List](by-class/List.md) vtable slot `+0x18`;
- returns `listCount - 1` after the append, which matches the lazy-load callers that immediately use the returned slot index to fetch the newly registered record.
