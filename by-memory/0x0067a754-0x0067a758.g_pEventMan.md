# 0x0067a754-0x0067a758 g_pEventMan

## Summary

- Address range: `0x0067a754-0x0067a758`
- Entity kind: global data pointer
- Current IDA name: `dword_67A754`
- Proposed source name: `g_pEventMan`
- Disposition: reconstructable project global
- Confidence: strong

This four-byte zero-initialized `.data` global stores the process-wide `EventMan` singleton. It is used by the Win32 message bridge, pane/list input helpers, cursor-position helpers, and event dispatch wrappers.

## Storage And Lifetime

| Address | Initial value | Role |
| --- | --- | --- |
| `0x0067a754` | `0x00000000` | `EventMan*` singleton pointer |

Observed lifetime anchors:

- `EventMan::EventMan` initializes this singleton during application startup.
- `EventMan` destruction/scalar-deleting paths clear this pointer.
- `Main_WndProc` and UI helper paths read it for cursor/mouse/keyboard/event dispatch and cursor-position queries.
