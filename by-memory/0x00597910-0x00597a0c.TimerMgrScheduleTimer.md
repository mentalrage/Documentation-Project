## Behavior

Schedule builds a five-dword [UID:0001VX][ScheduledTimerEvent](by-type/by-struct/ScheduledTimerEvent.md) record from owner, timer/event id, due tick, and two payload arguments. The due tick is computed as the delay argument plus `m_currentTick`. It scans the queue from logical start until it finds the first existing event with a later due tick, then calls [UID:0002L7][0x00598480-0x005986d9.TimerMgrTimerQueueInsertTimer](by-memory/0x00598480-0x005986d9.TimerMgrTimerQueueInsertTimer.md) to insert the new record at the sorted position. After insertion, it refreshes `m_nextDueTick` from the queue's first logical event and returns that value.
