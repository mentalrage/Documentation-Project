## Behavior

This helper loads a Standard MIDI File document from the selected source and prepares the per-track parsing state consumed by the stream-fill helper. It opens the source, validates the `MThd` header, reads byte-swapped format/track-count/division fields, allocates the track table, walks each `MTrk` chunk, allocates each 0x400-byte track buffer, records the file offsets and remaining track lengths, reads initial data, decodes the first delta value for each track, and seeks to the end of each track before checking the next chunk.

On parse or allocation failure, it closes the active source and releases any global-memory handles and track buffers that were already allocated.
