## Summary

This `.rdata` span contains help-pane and item-help pane vtables plus item stat, class, and requirement strings. It covers the help and item-description UI data before the `HierList`/hour pane block.

- Vtables for `SimpleHelpTextPartPane<HelpPane>`, `HelpPane`, `SimpleHelpPane`, `SimpleHelpPane2`, `WillBeChangedItemPane`, `WillBeChangedSpellPane`, and `ItemHelpPane`.
