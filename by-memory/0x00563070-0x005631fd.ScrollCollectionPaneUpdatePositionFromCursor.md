## Behavior

This helper maps cursor coordinates to a new scrollbar position:

- reads the old position at object offset `+0xfe`;
- computes the thumb rectangle through `0x00562bf0` for region `2`;
- samples the shared cursor/input global and pane origin twice, ignoring the `(-1000, -1000)` sentinel;
- adjusts the pane bounds from `this + 0x44` according to orientation `this + 0xfc`;
- converts cursor movement into vertical or horizontal scroll position using drag offsets at `this + 0x108` / `this + 0x10c`;
- clamps the computed position against the max range at `this + 0x100`;
- compares the computed position to the old `+0xfe` value; and
- when the position changes, retrieves the owning pane through vtable slot `+0x1c` and calls `CollectionPane::OnScrollPositionChanged` at `0x0056fa90`.
