# 0x0067a768-0x0067a770 CRT Stdio Scan Options Storage

## Summary

- Address range: `0x0067a768-0x0067a770`
- Entity kind: CRT local stdio-options storage
- Disposition: ignored for NexusTK source reconstruction
- Rebuild handling: emitted/provided by compatible MSVC CRT/UCRT support code
- Confidence: strong

This eight-byte zero-initialized slot is the second local stdio-options storage block used by CRT formatted scanning helpers. It is returned by `sub_443980` and initialized by `__scrt_initialize_default_local_stdio_options`, which sets the local scanf-family option bit.

## Layout

| Range | Current IDA name | Initial value | Use |
| --- | --- | --- | --- |
| `0x0067a768-0x0067a770` | `unk_67A768` | all zero bytes | Storage returned by `sub_443980`, consumed by `__stdio_common_vsscanf`, `__stdio_common_vswscanf`, and related CRT wrapper glue. |

## Evidence

- IDA MCP byte review reports eight zero bytes in `.data`.
- `sub_443980` at `0x00443980` decompiles to `return &unk_67A768`.
- `__scrt_initialize_default_local_stdio_options` calls both [UID:00028H][0x0067a730-0x0067a738.CrtStdioOptionsStorage](by-memory/0x0067a730-0x0067a738.CrtStdioOptionsStorage.md) and `sub_443980`, then ORs this storage with option bit `2`.
- CRT wrapper callers at `0x00443a30`, `0x004944c0`, and `0x004944f0` load this option pair before forwarding to common scanf/wscanf implementations.

## Reconstruction Notes

Do not model this slot as game source state. It should be produced by compatible runtime support for secure formatted scanning helpers.
