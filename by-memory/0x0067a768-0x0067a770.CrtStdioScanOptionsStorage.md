# 0x0067a768-0x0067a770 CRT Stdio Scan Options Storage

## Summary

- Address range: `0x0067a768-0x0067a770`
- Entity kind: CRT local stdio-options storage
- Disposition: ignored for NexusTK source reconstruction
- Rebuild handling: `third-party/runtime`
- Confidence: strong for bytes, xrefs, runtime ownership, and wrapper behavior

This eight-byte zero-initialized slot is the second local stdio-options storage block used by CRT formatted scanning helpers. It is returned by `sub_443980` and initialized by `__scrt_initialize_default_local_stdio_options`, which sets the local scanf-family option bit.

## Layout

| Range | Current IDA name | Initial value | Use |
| --- | --- | --- | --- |
| `0x0067a768-0x0067a770` | `unk_67A768` | all zero bytes | Storage returned by `sub_443980`, consumed by `__stdio_common_vsscanf`, `__stdio_common_vswscanf`, and related CRT wrapper glue. |

## Evidence

- IDA MCP on 2026-06-05 reports the binary as `NexusTK.exe`, base `0x00400000`, MD5 `4247e04e20b65d6414c7238aa8ff5515`, with `.data` at `0x0066d000-0x0069d000` and `rw-` permissions.
- A current IDA MCP byte audit reports `0x0067a768-0x0067a770` is eight bytes, all `00`, with no nonzero offsets.
- A current IDA MCP xref audit over the span reports the only direct data xref is to `0x0067a768` from `sub_443980` at `0x00443980`; there are no direct xrefs to interior bytes `0x0067a769-0x0067a76f`.
- `sub_443980` at `0x00443980` decompiles to `return &unk_67A768`, making it the CRT local scanf-option accessor.
- `___scrt_initialize_default_local_stdio_options` at `0x005c8a7e` calls [UID:00028H][0x0067a730-0x0067a738.CrtStdioOptionsStorage](by-memory/0x0067a730-0x0067a738.CrtStdioOptionsStorage.md)'s accessor `sub_41B9A0`, ORs that formatted-output option storage with `4`, then calls `sub_443980` and ORs this formatted-input storage with `2`.
- IDA MCP callers for `sub_443980` are `sub_443A30` at `0x00443a30`, `sub_4944C0` at `0x004944c0`, `sub_4944F0` at `0x004944f0`, and `___scrt_initialize_default_local_stdio_options` at `0x005c8a7e`.
- `sub_443A30` decompiles as a variadic narrow `sscanf` wrapper: it calls `sub_443980`, reads the 64-bit option pair, and forwards to `__stdio_common_vsscanf`.
- `sub_4944C0` and `sub_4944F0` both call `sub_443980`, OR the low option word with `1`, and forward to the narrow/wide scanf-family CRT implementations; `sub_4944F0` uses `__stdio_common_vswscanf`.
- The adjacent boundaries are documented: [UID:0001OW][0x0067a764-0x0067a768.ActiveMapPaneSingleton](by-memory/0x0067a764-0x0067a768.ActiveMapPaneSingleton.md) ends immediately before this storage, and [UID:00028N][0x0067a770-0x0067a79c.JsonCppStaticValueData](by-memory/0x0067a770-0x0067a79c.JsonCppStaticValueData.md) starts at the next named dword.
