## Behavior

The main destructor:

- restores the `SimpleListPane` primary and secondary vtable pointers;
- reads the list item state and iterates the stored entry count;
- obtains each entry slot through the shared list-pane helper;
- frees non-null heap-backed entry buffers and clears each slot;
- calls the shared `ListPane` base destructor path;
- if requested by delete flags, runs ordinary delete or sized delete.
