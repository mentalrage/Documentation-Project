## Notes

This span is the lower-level default/config construction core. It should not be treated as profile-file code just because `LoadUserProfileData` calls `InitializeUserDataDefaults`.

The immediately preceding [UID:00021Z][0x0048e310-0x0048e479.ConfigRawTableHelpers](by-memory/0x0048e310-0x0048e479.ConfigRawTableHelpers.md) page covers raw config-table helper bodies that belong with this same source family but were omitted from active generated output.

The immediately following [UID:000220][0x0048f400-0x00491b28.RegistryCommandLineParsers](by-memory/0x0048f400-0x00491b28.RegistryCommandLineParsers.md) page covers command-line/session parser helpers that sit between default initialization and registry persistence.

The 2026-05-25 IDA MCP recheck confirms `InitializeUserDataDefaults` seeds the 30-row [UID:0001V1][MacroHotkeyRecord](by-type/by-struct/MacroHotkeyRecord.md) table: slot ordinals live at `g_pConfig + 0x28f2ec + i * 0x108`, action state `2` at `+0x28f2f0 + i * 0x108`, and default key text `a..z, A..D` at `+0x28f2f4 + i * 0x108`.

IDA confirms every listed start as a function. The two entry helpers have no direct caller xrefs in IDA because they are used as vector-constructor/destructor callbacks and by generated cleanup paths.
