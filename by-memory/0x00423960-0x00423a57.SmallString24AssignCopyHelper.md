## Behavior

Assigns bytes from a C string into a 24-byte small-string object. The object uses inline storage at offset `0`, length at offset `+0x10`, capacity at offset `+0x14`, and treats capacity below `0x10` as inline.

The helper first measures the source length. If the new length fits the existing capacity, it selects the inline buffer or heap pointer, updates the length field, copies the bytes with `memmove`, writes the terminating zero byte, and returns.

If the new length exceeds the current capacity, the helper rejects lengths above `0x7fffffff`, computes a rounded capacity with `length | 0x0f`, considers 1.5x growth from the old capacity, caps at `0x7fffffff`, and allocates `capacity + 1` bytes through [UID:0000WN][0x0041b6d0-0x0041b9a0.MsvcStringSupportHelpers](by-memory/0x0041b6d0-0x0041b9a0.MsvcStringSupportHelpers.md).
