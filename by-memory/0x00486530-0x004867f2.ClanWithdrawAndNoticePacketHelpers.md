## Raw Code Pattern

Short request helpers write `{ 0x4b, subtype, 0 }` and send three bytes. Amount helpers write `{ 0x4b, subtype, 1 }`, append a dword through `sub_5753f0`, and send seven bytes. Item helpers write `{ 0x4b, subtype, 1 }`, append one byte and one word, and send six bytes. The subtype `13` helper converts a single wide string and sends `length + 3` bytes.
