## Behavior

The first four helpers match the clan withdraw-money and withdraw-item subtype pairings implied by [UID:00021C][0x00484f70-0x0048540b.ClanStatusPacketDispatcher](by-memory/0x00484f70-0x0048540b.ClanStatusPacketDispatcher.md): incoming subtype `11` opens [UID:00002O][ClanWidMoneyInputDialog](by-class/ClanWidMoneyInputDialog.md), and subtype `12` opens [UID:00002N][ClanWidItemDialog](by-class/ClanWidItemDialog.md).

The final subtype `13` helper has a larger local packet buffer and sends opcode `0x4b`, subtype `13`, and one length-prefixed converted string. IDA currently shows no inbound xrefs to the raw start; keep its final name provisional.

## Raw Code Pattern

Short request helpers write `{ 0x4b, subtype, 0 }` and send three bytes. Amount helpers write `{ 0x4b, subtype, 1 }`, append a dword through `sub_5753f0`, and send seven bytes. Item helpers write `{ 0x4b, subtype, 1 }`, append one byte and one word, and send six bytes. The subtype `13` helper converts a single wide string and sends `length + 3` bytes.
