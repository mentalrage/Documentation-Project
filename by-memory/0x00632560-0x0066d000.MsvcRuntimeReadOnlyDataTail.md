# 0x00632560-0x0066d000 MSVC Runtime Read-Only Data Tail

## Range

- Address range: `0x00632560-0x0066d000`
- Entity kind: `runtime/compiler-data`
- Disposition: ignored compiler/runtime data.
- Rebuild handling: regenerate via the selected MSVC-compatible compiler, linker, CRT, and STL; do not port as handwritten NexusTK code.

## Summary

This `.rdata` tail contains MSVC compiler/runtime function metadata, C++ standard-library exception and locale vtables, system-error strings, API-set thunk names, CRT assertion/math/locale/string tables, and other CRT/STL read-only data. It begins at `funcs_4149B4` and runs to the end of IDA's `.rdata` segment.
