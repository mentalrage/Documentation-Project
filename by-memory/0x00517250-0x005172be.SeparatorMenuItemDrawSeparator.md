# 0x00517250-0x005172be SeparatorMenuItem Draw Separator

## Status

- Entity kind: virtual class method.
- Owner: [UID:0000CY][SeparatorMenuItem](by-class/SeparatorMenuItem.md).
- Likely source file: [UID:0000MN][PopupMenuControls](by-file/PopupMenuControls.md).

## Behavior

Draws a centered separator line using the shared menu-item bounds rectangle:

- clears a drawing-context byte at `a2 + 0x70`;
- selects palette/color slot `128`;
- computes a narrow rectangle from left/right bounds and vertical midpoint;
- calls the rectangle draw callback through `dword_69B3FC`.

- IDA decompile reads rectangle dwords at `this + 0x04`, `+0x08`, `+0x0c`, and `+0x10` and builds the separator line rectangle.
