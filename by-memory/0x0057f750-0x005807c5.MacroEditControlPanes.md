## IDA MCP Evidence

Rechecked on 2026-05-24 and refreshed on 2026-05-25:

- IDA recognizes all listed function starts from `0x0057f750` through `0x00580770`.
- `0x0057f7b0` and `0x0057fa80` decompile as vtable-reset/base-teardown helpers, not as row paint/input behavior.
- `xrefs_to` shows no current direct references to `0x0057f7b0` or `0x0057fa80`, so they may be retained helper bodies used only through unwind/vtable metadata or currently-unrecovered calls.
- `xrefs_to` maps the `0x00580640-0x00580686` run to vtable data slots. The decompilation confirms each `0x0b`-byte adjustor thunk tail-calls the matching scalar deleting destructor after subtracting `40` or `41` dwords from `this`.
- Exact helper/thunk pages now document the reviewed support ranges: [UID:0001IL][0x0057f7b0-0x0057f7ce.SpellMacroEditControlPaneTeardownHelper](by-memory/0x0057f7b0-0x0057f7ce.SpellMacroEditControlPaneTeardownHelper.md), [UID:0001IM][0x0057fa80-0x0057fa9e.NewMacroEditControlPaneTeardownHelper](by-memory/0x0057fa80-0x0057fa9e.NewMacroEditControlPaneTeardownHelper.md), and [UID:0001IN][0x00580640-0x00580686.MacroEditControlPaneVtableThunks](by-memory/0x00580640-0x00580686.MacroEditControlPaneVtableThunks.md).
- `0x005805e0` decompiles as the integrated row sync path: when the bound macro record is text mode, it leaves edit forwarding mode, copies up to 64 units from the embedded editor into `record + 8`, and calls the deactivate path.
- 2026-05-25 IDA MCP decompilation confirms the integrated edit control's saved record is [UID:0001V1][MacroHotkeyRecord](by-type/by-struct/MacroHotkeyRecord.md): state at record `+4`, editable/display payload at record `+8`, and row ordinal at record `+0`.
- `OnKeyEvent` writes state `1` for text macro mode, or state `2`/`3` for alphabetic key bindings depending on the active general-purpose panel tab; `SyncEditControl` copies embedded editor text back only when state is `1`.
- 2026-05-25 IDA MCP decompilation of `GeneralPurposePanel::GeneralPurposePanel` confirms child index `2` is the inventory pane and child index `3` is the spell inventory pane. `OnKeyEvent` therefore maps spell-tab key bindings to [UID:0001V1][MacroHotkeyRecord](by-type/by-struct/MacroHotkeyRecord.md) state `2` / `.usr` `S`, and inventory/item-tab key bindings to state `3` / `.usr` `I`.
