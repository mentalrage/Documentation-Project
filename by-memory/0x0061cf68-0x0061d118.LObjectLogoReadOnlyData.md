# 0x0061cf68-0x0061d118 LObject/Logo Read-Only Data

## Range

- Address range: `0x0061cf68-0x0061d118`
- Entity kind: `mixed-rdata index`
- Disposition: reviewed non-reconstructable standalone aggregate; the source-owner pages and future exact children carry the rebuild work.
- Rebuild handling: index-only linker layout over source-declared/generated-binary vtables, callback data, logo resource literals, and MAPI lookup literals.
- Autogen status: intentionally non-reconstructable as a standalone page. This is a mixed `.rdata` span whose front belongs to [UID:0000KV][LObject](by-file/LObject.md) and whose startup-logo tables/literals belong mostly to [UID:0000O4][StartupLogoPanes](by-file/StartupLogoPanes.md), with MAPI literals consumed by [UID:00022V][0x004f5b20-0x004f5c73.MapiSendMailHelper](by-memory/0x004f5b20-0x004f5c73.MapiSendMailHelper.md) / [UID:0000ML][PlatformApi](by-file/PlatformApi.md).

## Summary

This `.rdata` span contains the `LObject` base vtable, the `LogoPane` and `LogoPlayerPane` vtable families, a `PlainMemberFunctionObject0<LogoPane>` callback table, startup-logo/Bink resource strings, the `"%s corrupted"` error text used by the logo movie constructor, and Win32 MAPI dynamic-lookup strings. It begins immediately after the Layer/Input/List read-only-data span and ends at the `BaramApp` vtable. Batch 012 treats the physical range as a coverage/index page rather than one source-level reconstruction unit because it crosses `LObject`, startup-logo, resource, and PlatformApi ownership.
