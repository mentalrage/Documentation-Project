## Reconstruction Notes

Keep this as a shared alpha-mask blitter rather than copying it into each image library caller. The caller set proves that several image-library render paths consume the helper, while the implementation operates entirely on the alpha-surface layout and an encoded source-frame payload.

Candidate source-level shape:

```cpp
void DrawEncodedAlphaFrame(
    AlphaMaskSurface& dst,
    const RectBounds& dstRect,
    const EncodedFrame& frame,
    const Point& srcOrigin,
    int alphaEndY,
    unsigned char alphaEnd,
    int alphaStartY,
    unsigned char alphaStart,
    int blendMode);
```

The `EncodedFrame` field names remain provisional. The verified behavior is: skip encoded source rows above the clipped start, walk zero-terminated signed run tokens per row, draw only negative-token runs, clip each run horizontally, and use mode `0` replace, mode `1` add, and mode `2` subtract.
