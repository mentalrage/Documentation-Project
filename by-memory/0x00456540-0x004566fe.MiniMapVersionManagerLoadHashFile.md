## Behavior

This method loads the persisted minimap hash cache from `%APPDATA%\NexusTK\MiniMap\mnmhs.hs` and replays it into `UpdateHashList` without saving it back to disk.

It calls `SHGetFolderPathW`, builds `%s\NexusTK`, `%s\NexusTK\MiniMap`, and `%s\NexusTK\MiniMap\mnmhs.hs`, tolerates preexisting directories through the `ERROR_ALREADY_EXISTS` path, opens the cache with `rb`, reads a one-byte version-string length, reads the version string, calculates the remaining file length, reads the remaining wide hash-list text, calls `UpdateHashList(versionText, hashListText, false)`, and frees both temporary buffers.
