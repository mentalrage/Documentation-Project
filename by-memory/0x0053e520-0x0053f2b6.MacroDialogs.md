## Ownership And Behavior

[UID:0000KY][MacroDialogs](by-file/MacroDialogs.md) is the source owner for this range. The file page groups this aggregate with [UID:0001E1][0x00541b30-0x00542265.IntegrateMacroDialog](by-memory/0x00541b30-0x00542265.IntegrateMacroDialog.md) and [UID:0001IK][0x0057f750-0x005807c5.MacroEditControlPanes](by-memory/0x0057f750-0x005807c5.MacroEditControlPanes.md), which cover the integrated macro dialog and macro row controls outside this contiguous island.

The first class group is the older [UID:00007I][MacroDialog](by-class/MacroDialog.md) option dialog. Its constructor and `SaveMacros` method are opened from [UID:0000M7][OptionPane](by-file/OptionPane.md) / [UID:00009V][OptionPane](by-class/OptionPane.md), but the implementation belongs with the macro source family rather than being folded into `OptionPane.cpp`.

The second group is [UID:0000DP][SpellMacroDialog](by-class/SpellMacroDialog.md), which owns spell-specific macro setup. It is still part of this macro dialog source family because the dialog construction, confirmation handler, vtable family, and edit-control relationship match the macro-row editor cluster rather than spell inventory rendering.

The third group is [UID:000094][NewMacroDialog](by-class/NewMacroDialog.md), the newer paged macro setup dialog. Its methods perform page command handling, active-control selection, page save, and page load against [UID:000095][NewMacroEditControlPane](by-class/NewMacroEditControlPane.md) rows. The row data ultimately corresponds to [UID:0001V1][MacroHotkeyRecord](by-type/by-struct/MacroHotkeyRecord.md) profile storage, but this range owns only the UI editing behavior.
