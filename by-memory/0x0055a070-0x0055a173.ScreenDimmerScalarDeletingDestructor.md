# 0x0055a070-0x0055a173 ScreenDimmer Scalar Deleting Destructor

## Status

- Address range: `0x0055a070-0x0055a173`
- Entity kind: scalar deleting destructor wrapper
- Direct owner: [UID:0000C8][ScreenDimmer](by-class/ScreenDimmer.md) class layout/destructor emission
- Rebuild handling: compiler/linker-generated wrapper around the source destructor. Document for binary coverage, but do not hand-port as separate source.

## Behavior

Runs the same `ScreenDimmer` teardown path as the non-deleting destructor, then conditionally frees heap storage when the delete flag has bit `1` set and bit `4` clear. The guard path references `0xfc` / 252 bytes as the `ScreenDimmer` object size (Verified with int_convert.py).

## Raw Evidence

- 2026-06-11 IDA MCP `analyze_funcs` reports `sub_55A070` at `0x0055a070-0x0055a173`, 76 decoded instructions and fourteen basic blocks.
- Xrefs come from the two ScreenDimmer adjustor thunks and the primary vtable data slot at `0x00623484`.
- Callees include modal/list removal, pane detach/unregister helpers, root/back-pane rectangle helper, `Pane` teardown, `OperatorDeleteWrapper`/delete helper at `0x004f4ac0`, guard check, and security-cookie check.

## Boundaries

The previous thunk ends at `0x0055a067`, followed by nine `0xcc` bytes before this wrapper. The wrapper ends at `0x0055a173`; the `ScreenFadeOut` scalar deleting destructor starts at `0x0055a180`.
