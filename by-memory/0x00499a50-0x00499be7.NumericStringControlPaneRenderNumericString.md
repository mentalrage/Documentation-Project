## Behavior

- Reads the control bounds, sets draw color slot `0`, and invokes the shared draw callback at `0x0069b3fc` to clear/fill the bounds.
- Reads the owned wide string at offset `+0x108`, measures UTF-16 length, and computes text width as `9 * length`.
- Uses alignment mode at offset `+0x10c`: mode `1` right-aligns to the right edge, mode `2` centers, and other values start at the left edge.
- Builds an initial 9-by-11 glyph rectangle and iterates the string one UTF-16 code unit at a time.
- For `'-'`, loads `FONTSYMB.EPF` and draws with palette `FONTSYMB.PAL`.
- For space and slash, skips drawing while still advancing the cursor.
- For all other code units, draws the glyph through the loaded `9X11FONT.BIN` handle at offset `+0x114`, using the color/style byte at offset `+0x110`.
- Advances the glyph rectangle by 9 pixels after each code unit.
