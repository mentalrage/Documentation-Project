# 0x00671a74-0x00672eb4 Zlib 1.1.4 Data Messages And Tables

## Summary

- Address range: `0x00671a74-0x00672eb4`
- Entity kind: third-party zlib data strings/tables
- Disposition: reconstructable third-party static-embed data
- Rebuild handling: restored by compiling/linking zlib 1.1.4
- Confidence: strong

This range contains the `.data` side of the linked zlib 1.1.4 library: version/error strings, status pointer tables, inflate diagnostics, fixed-tree tables, and inflate bit masks. It ends at `0x00672eb4`, before the CRT/Dinkumware runtime tail now owned by [UID:00028F][0x00672eb4-0x006738c0.MsvcDinkumwareRuntimeMutableData](by-memory/0x00672eb4-0x006738c0.MsvcDinkumwareRuntimeMutableData.md).

## Evidence

- 2026-06-06 live IDA range audit reported the former mixed `.data` range as `5296` bytes and identified the last `0x70` bytes as CRT/Dinkumware runtime data, giving the clean zlib/runtime split point at `0x00672eb4`.
- Live start bytes at `0x00671a74` are `31 2e 31 2e 34 00 00 00 74 1a 67 00`, proving the `1.1.4` string, three alignment bytes, and immediate self-pointer slot.
- Live xrefs to the zlib version string come from `0x004142c0`, `0x00414390`, and `0x00415950`; the version-pointer slot at `0x00671a7c` is referenced at `0x004145b4`.
- Live xrefs tie the first diagnostic string group to the zlib inflate initializer at `0x00415a80`; the packed `0x00671af0-0x00671b18` pointer table is referenced by zlib error/status helpers at `0x004145a0` and `0x00414820`.
- Live xrefs tie the inflate descriptor/table block to `0x00416010`, block/code diagnostics and masks to `0x00417cc0`, `0x00418a50`, and `0x00419a90`, and tree-builder diagnostics to `0x00419220` and `0x00419790`.

- The former tail bytes at `0x00672eb4-0x00672f24` were split to [UID:00028F][0x00672eb4-0x006738c0.MsvcDinkumwareRuntimeMutableData](by-memory/0x00672eb4-0x006738c0.MsvcDinkumwareRuntimeMutableData.md) because their xrefs come from runtime support at `0x005c5eec`, `0x0060c482`, `0x005c6ebd`, `0x005c6f20`, `0x005c755c`, and `0x005c8a00`.
