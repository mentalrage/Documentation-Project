## Range Role

This range bridges the earlier [UID:0000WY][0x00424630-0x00428b4b.JsonCppValueCore](by-memory/0x00424630-0x00428b4b.JsonCppValueCore.md) and the [UID:0000X0][0x004298f0-0x0042acdf.JsonCppDocumentParseFrontEnds](by-memory/0x004298f0-0x0042acdf.JsonCppDocumentParseFrontEnds.md). ## Evidence

- IDA MCP `lookup_funcs` identifies the first modeled function as `??0big_integer@__crt_strtox@@QAE@XZ` at `0x00428b50`, confirming the CRT numeric-conversion fragment.
- IDA MCP decompilation of `0x00428b70` references `assert json failed` and `in Json::Value::setComment(): Comments must start with /`, then copies the supplied comment text.
- IDA MCP decompilation of `0x00428d70` and `0x00429090` shows path-syntax processing over `[`, `%`, `.`, decimal digits, and `std::string`-style temporaries. This matches JsonCpp `Json::Path` / `PathArgument` support rather than product logic.
- IDA MCP decompilation of `0x00429830` references `ConstIterator to Iterator should never be allowed.`, a JsonCpp iterator diagnostic.
- Direct xrefs from product code go to the neighboring JsonCpp document parse front ends at `0x004298f0` and `0x00429b30`; this support island is reached through JsonCpp value/path/iterator internals.
