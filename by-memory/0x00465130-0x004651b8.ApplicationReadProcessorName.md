## Behavior

Reads the CPU processor-name registry value and stores it into the `Application` object's wide-string field at `this + 0x1c`.

Observed flow:

- closes the registry key with `RegCloseKey`;
- assigns the queried wide string into the Application field at `this + 0x1c` through the SimpleUString assignment helper at `0x00582d20`.
