## Behavior

The helper loads a named resource into a temporary buffer, decodes it as RGBA8 PNG data, and converts it into an `EPFTileContext`-style destination:

- constructs a DAT/file reader object through the `0x0049c130` family;
- opens/reads the wide resource path argument into a memory buffer;
- calls LodePNG memory decode front end `0x00443b40`;
- `0x00443b40` decompiles as a wrapper over `0x00443a60(..., 6, 8)`, matching `lodepng_decode32` / RGBA8 in-memory decode behavior;
- initializes the destination through the `EPFTileContext` allocation helper at `0x00458490`, now source-described as `AllocateRgb16PixelsWithAlpha`, using decoded width/height;
- converts decoded RGBA pixels into RGB565 destination pixels;
- converts alpha as `32 - int(alpha / 255.0f * 32.0f)` into the destination `EPFTileContext::alphaData` / alpha plane at `+0x08`;
- frees the temporary file buffer and decoded RGBA buffer;
- finalizes the destination through [UID:000200][0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels](by-memory/0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels.md);
- tears down the temporary DAT/file reader object before returning.

## EPFTileContext Field Notes

B004's EPFTileContext source-quality pass identifies this helper as one of the direct producers for the optional 16-bit `alphaData` plane. The allocation helper at `0x00458490` should be read as `AllocateRgb16PixelsWithAlpha`: it allocates the primary 16-bit pixel plane and a second `2 * width * height` alpha plane. This alpha plane is distinct from the encoded transparency mask byte stream at `EPFTileContext+0x24`.

## Ownership Decision

Assign this helper to [UID:0000K3][ImageLoaders](by-file/ImageLoaders.md). The helper belongs with the same `EPFTileContext` image decode wrapper group as ZPF/FPF, raw FPF, JPF, BMP, raw JPEG, and the newly split PNG-file helper. The DAT/file reader calls are input plumbing; the owned policy is PNG decode plus tile-context conversion. It should not be owned by `DATFile`, `LodePNG`, `ResourceLayoutTable`, or `ImageFrameTable`.
