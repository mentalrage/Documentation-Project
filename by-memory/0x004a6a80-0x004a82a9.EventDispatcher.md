## Reconstruction Notes

- This range should map to `ui/core/EventDispatcher.cpp`.
- `ApplicationHelper_4A6C40` is likely a local helper or scheduler object in this source neighborhood even though it is called by the application message loop. Treat `ApplicationHelper_4A6C40.cpp` as a generated owner name, not a final source-file name.
- Its use of [UID:0000HR][BlackHole](by-file/BlackHole.md) does not make `BlackHole` an `EventDispatcher` class; the helper only drains the shared deferred deletion queue before timer dispatch.
- Helper functions under the traversal region should be named after the event tree/list/vector concepts before any C++ rewrite.
- Generated one-class files for `Tree<EventHandler*>`, `TreeItor<EventHandler*>`, and `HandlerFindFunc` are support types for this module, not separate feature modules.
- The non-contiguous `0x00597580` destructor once linked here is now resolved as [UID:0001K7][0x00597580-0x005975c3.TimerHandlerDestructor](by-memory/0x00597580-0x005975c3.TimerHandlerDestructor.md). Do not migrate it as `EventDispatcher.cpp` code.
