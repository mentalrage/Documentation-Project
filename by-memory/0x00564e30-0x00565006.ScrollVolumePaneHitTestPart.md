## Behavior

This helper maps a screen-space mouse point to one of the volume slider's five logical parts:

- converts the input point through cursor/screen-position helpers into the pane-local coordinate space;
- iterates known slider part ids `0..4`;
- builds each candidate rectangle from pane bounds, current value, max range, enabled state, drag override state, and thumb metrics;
- uses the shared [UID:00015S][0x004b7c30-0x004b7f87.RectGeometryHelpers](by-memory/0x004b7c30-0x004b7f87.RectGeometryHelpers.md) containment helper; and
- returns the first matching part id, or `-1` when the point is outside all slider parts.

The part ids match [UID:0001W2][ScrollVolumePaneLayout](by-type/by-struct/ScrollVolumePaneLayout.md): `0` top edge/arrow, `1` track above thumb, `2` thumb, `3` track below thumb, `4` bottom edge/arrow, and `0xff` as the no-part sentinel used by highlight/active fields.
