## Behavior

Builds and sends an opcode `0x0e` chat packet from a wide-character input string supplied as the single argument:

| Step | Evidence | Meaning |
| --- | --- | --- |
| packet byte `0` | `sub_575380(0x0e, packet)` | chat opcode |
| packet byte `1` | `sub_575380(0, packet+1)` | default chat subtype |
| conversion | `WideCharToMultiByte(..., arg, wcslen(arg), local[256], 0x100, ...)` | converts the wide text argument to a multibyte payload |
| length/payload | `sub_575380(length, packet+2)` and `sub_516220(packet+3, text, length)` | length-prefixes and copies the converted text |
| send | `sub_574BB0(dword_67A7EC, packet, length+3)` | queues/sends the packet |

Range-check failure paths guard converted text length `>= 0x100` and final packet length `>= 0x12c`.

More detailed raw flow from the 2026-06-06 instruction pass:

- Calls `sub_516030` before writing the packet fields, preserving the returned packet/context pointer in `edi` for the later payload copy.
- Writes opcode `0x0e` at stack packet byte `0` and subtype `0` at byte `1` through `sub_575380`.
- Measures the UTF-16 input with an inline word loop rather than a direct `wcslen` import, then passes the signed 16-bit character count into `WideCharToMultiByte(0, 0, input, count, localBytes, 0x100, 0, 0)`.
- NUL-terminates the converted local byte buffer, writes the converted byte count into packet byte `2`, copies the payload to `packet + 3` through `sub_516220`, appends a final packet NUL at `packet[length + 3]`, and sends exactly `length + 3` bytes through `sub_574BB0`.
- Reads [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) / `dword_67A7EC` at `0x005b38a5` immediately before the final send and does not write persistent global or object state.
