# `0x00421230-0x0042125d` Wide Format Wrapper 32

## Reclassification Audit

2026-06-24 B001 implementation applies the accepted source-quality correction for [UID:00030V]. The old `StringUtil` route was a reasonable shared-helper hypothesis when the page only knew the fitting-room plus macro caller mix, but current MCP session `80de0a67` and local UCRT header evidence resolve the source shape as MSVC/UCRT secure wide-format support. ## Behavior

The helper builds a variadic argument list, obtains the local stdio printf-options storage through `0x0041b9a0`, then forwards to `___stdio_common_vswprintf_s` with a null locale and fixed destination capacity `0x20`. The `0x20` literal is a destination element count: the generated helper formats into a 32-wide-character buffer. The return value is the CRT formatting result when nonnegative and `-1` when the backend result is negative.

The source-facing operation is ordinary secure wide formatting into the caller's local fixed-size destination buffer. The helper is not fitting-room-private, not macro-dialog-private, and not a project-authored `StringUtil` API.
