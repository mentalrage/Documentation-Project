## Constructor Context

This is the shared base constructor used by the menu-item family. The derived constructors [UID:0002J6][0x00516ff0-0x00517070.StringMenuItemConstructor](by-memory/0x00516ff0-0x00517070.StringMenuItemConstructor.md) and [UID:0002JB][0x005171b0-0x0051721d.SeparatorMenuItemConstructor](by-memory/0x005171b0-0x0051721d.SeparatorMenuItemConstructor.md) perform the same base setup pattern before installing their final vtables. The key class-level distinction is the shared two-byte state storage: the base and string constructors seed `m_enabled = true` and `m_selected = false`, while the separator constructor clears the same word and is best modeled as `m_enabled = false` with `m_selected` left false.

The preceding bytes are not part of this constructor. `0x00516ee8-0x00516ef0` is eight `0xcc` padding bytes, `0x00516ef0-0x00516eff` is a separate 15-byte method-shaped `MenuPane` thunk that loads `[ecx+0xfc]`, reads the item vtable, and tail-jumps through slot `+0x0c`, and `0x00516eff-0x00516f00` is one more `0xcc` byte. That thunk needs its own support coverage pass and should not be merged into this constructor range.

## Reconstruction Notes

A final reconstruction should preserve the observed order:

1. Construct the inherited `LObject` state.
2. Install the base `MenuItem` vtable.
3. Initialize the shared bounds rectangle to `{0, 0, 0, 0}`.
4. Set `m_enabled = true` and `m_selected = false`. The binary coalesces the adjacent bytes into `word ptr [this+0x14] = 1`; source should not introduce a separate state-word assignment unless a later declaration audit proves that exact source member.

Do not model the SEH registration, security cookie, construction-unwind helper, handler address `0x00603199`, or vtable write as handwritten source behavior. `LObject::LObject`, `InitRectBounds(&m_bounds, 0, 0, 0, 0)`, `m_enabled`, and `m_selected` are the current high-probability source model, backed by [UID:0001V5][MenuItemLayouts](by-type/by-struct/MenuItemLayouts.md) and the sibling accessor/setter/draw evidence.
