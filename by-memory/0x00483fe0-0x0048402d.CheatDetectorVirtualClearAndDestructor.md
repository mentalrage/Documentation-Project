## Behavior

`0x00483fe0` is a vtable slot that sets `al = 1` and returns with `retn 0x0c`, consuming three explicit caller arguments. `0x00483ff0` is a cleanup helper that clears singleton storage `0x0067ab3c` and returns. `0x00484000` is the scalar deleting destructor wrapper: it calls base teardown at `0x00597580`, clears singleton storage `0x0067ab3c`, optionally frees `0x20` bytes through `0x005c7526` when the delete flag bit is set, returns the receiver, and consumes the delete-flags argument with `retn 4`.

Final source should express the ordinary virtual check, singleton clear, and destructor semantics in the owning class. The scalar deleting destructor wrapper and padding are compiler output and should not be hand-written application logic unless a binary-compatible thunk layer is explicitly required.
