## Reconstruction Notes

This range must not become one forced C++ struct or one generated source object. The linker placed unrelated module-scope dwords adjacent in `.data`: a chat input singleton, paired opcode `0x2d` command-state slots, and a function-key debounce baseline.

Leave `AUTOGEN_PARENT_UID` blank and `RECONSTRUCTABLE:FALSE` for this mixed aggregate. Exact child pages should carry reconstructable state and assignment only where both the child and the direct proposed parent clear the corrected `85/85` gate.

`0x0069bf74` currently has only IDA read xrefs in the inspected image, so the final update site for the debounce baseline remains open. Do not infer one without a later xref, trace, or source-layout proof.
