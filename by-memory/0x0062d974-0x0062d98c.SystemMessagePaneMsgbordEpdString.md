Exact UTF-16 `MSGBORD.EPD` literal used by the system-message pane family for message-board tile/resource layout. IDA also labels `0x0062d978` as `GBORD.EPD`, but byte evidence shows that name is a tail label inside the longer `MSGBORD.EPD` source literal.
