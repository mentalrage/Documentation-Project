# 0x0062d418-0x0062d5ac Startup Window Read-Only Data

## Range

- Address range: `0x0062d418-0x0062d5ac`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declaration and update/notice resource strings must be reconstructed; vtable is compiler-emitted.

## Summary

This `.rdata` span contains startup/update notice window class/title strings, `StartupWindow` vtable data, update/news/minimap URLs, and notice-window PCX resource names. It ends before `StdioFile`.
