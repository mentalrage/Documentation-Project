## Behavior

Writes a 32-bit value at the current cursor when the encoder is valid and has room for the four payload bytes plus the final terminator. If the byte-order flag is set, writes the most-significant byte through least-significant byte; otherwise writes the native little-endian dword directly. On insufficient capacity, clears the valid/writable flag.
