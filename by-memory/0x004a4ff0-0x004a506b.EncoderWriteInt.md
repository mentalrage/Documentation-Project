## Behavior

Writes a 32-bit value at the current cursor when the encoder is valid and has room for the four payload bytes plus the final terminator. If the byte-order flag is set, writes the most-significant byte through least-significant byte; otherwise writes the native little-endian dword directly. On insufficient capacity, clears the valid/writable flag.

## Source-Quality Notes

`Encoder::WriteInt` is an ordinary source-authored writer method, not compiler glue. It takes a 32-bit value, checks the writable flag at `+0x11`, reserves four payload bytes plus one trailing byte for [UID:00013K][0x004a55e0-0x004a5621.EncoderFinalize](by-memory/0x004a55e0-0x004a5621.EncoderFinalize.md), and writes either a big-endian byte sequence when `+0x10` is nonzero or a direct native x86 little-endian dword when `+0x10` is zero.

Best source-facing signature:

```cpp
void Encoder::WriteInt(unsigned int value);
```

`uint32_t` is behaviorally equivalent, but `unsigned int` is the safer first-draft spelling for a mid-2000s C++ codebase that may not have used `<stdint.h>` consistently. The source result is `void`; failure is reported by the sticky writable/valid flag and later [UID:00013K][0x004a55e0-0x004a5621.EncoderFinalize](by-memory/0x004a55e0-0x004a5621.EncoderFinalize.md), not by a return value.
