## Behavior

This helper sends the lower-slot drop-all item packet when the player/client state is not in the busy gate:

- reads [UID:0000QK][g_pCollectionData](by-global/g_pCollectionData.md) through historical IDA alias `dword_67A748`;
- checks byte `+0x3ec0` (`+16064`, Verified with int_convert.py) and returns without sending when it is nonzero;
- writes opcode `0x08` (`8`, Verified with int_convert.py), the signed byte parameter from `[ebp+8]`, and mode byte `1`;
- terminates the local packet buffer with a zero byte;
- sends length `0x03` / 3 bytes (Verified with int_convert.py) through [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) / `dword_67A7EC`.

The sibling raw helper [UID:0003FL][0x005b4af0-0x005b4b6c.SendDropItemPacketRaw](by-memory/0x005b4af0-0x005b4b6c.SendDropItemPacketRaw.md) uses the same opcode and mode byte `0`, while this helper uses mode byte `1` for the all-items variant.
