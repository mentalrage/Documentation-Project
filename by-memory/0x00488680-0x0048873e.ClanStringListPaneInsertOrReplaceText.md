## Behavior

The helper keeps the clan join/enlist string lists unique while preserving list-pane insertion behavior:

1. Reads the current row count through [UID:000194][0x004f3a50-0x004f4a77.ListPane](by-memory/0x004f3a50-0x004f4a77.ListPane.md) count helper `0x004f3bd0`.
2. Iterates row indices from zero to the current count and retrieves each row string through `0x004f3dc0`.
3. Compares the stored wide string against the incoming wide string with the inline two-WCHAR-at-a-time compare sequence.
4. If a matching row exists, removes that one row through `0x004f3d60(this, index, 1)`.
5. If no match exists, uses the old row count as the insertion index.
6. Copies the input string into a local `0x20` / 32-WCHAR destination (Verified with int_convert.py), then inserts it through `0x004f3c00(this, index, destination)`.
