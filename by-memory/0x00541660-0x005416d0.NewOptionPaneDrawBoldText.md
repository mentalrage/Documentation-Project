## Behavior

This helper draws a wide string twice at nearly the same position to produce the option-pane bold/shadow section-header effect.

Observed flow:

1. Set the GrafPort background-color field to `0x80` / decimal `128` (Verified with int_convert.py) through the shared [UID:000162][0x004b95e0-0x004b969f.GrafPortDrawStateAccessors](by-memory/0x004b95e0-0x004b969f.GrafPortDrawStateAccessors.md) accessor at `0x004b9680`.
2. Move the draw cursor to `(x, y)` with [UID:000162][0x004b95e0-0x004b969f.GrafPortDrawStateAccessors](by-memory/0x004b95e0-0x004b969f.GrafPortDrawStateAccessors.md) `0x004b9600`.
3. Walk the null-terminated wide string to derive the text length, then draw it with [UID:00016C][0x004ba9a0-0x004bad66.GrafPortTextRunHelpers](by-memory/0x004ba9a0-0x004bad66.GrafPortTextRunHelpers.md) subrange `0x004bab70`.
4. Move the cursor to `(x + 1, y)`.
5. Draw the same text again.

In `NewOptionPane::OnPaint`, the callers pass the page-zero section headers `Show Effects`, `Listen to`, `Semi-trans`, and `System`.
