# 0x00460fa0-0x00460ffe Byte Span Fill 8-Byte Blocks

## Behavior

Fills eight-byte blocks across one or more rows with a repeated byte value. It expands the byte to a repeated 64-bit pattern, writes `_QWORD` blocks, advances by row pitch, and emits `emms`.
