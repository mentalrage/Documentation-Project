# 0x00460fa0-0x00460ffe Byte Span Fill 8-Byte Blocks

## Status

- Disposition: reconstructable NexusTK render/support code.
- Entity kind: free helper.
- Likely source file: [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) `SoftwareBlend16` or neighboring alpha-mask/span utility source.
- Confidence: strong for boundary and behavior.
- Rebuild handling: `source-authored`.

## Behavior

Fills eight-byte blocks across one or more rows with a repeated byte value. It expands the byte to a repeated 64-bit pattern, writes `_QWORD` blocks, advances by row pitch, and emits `emms`.
