# 0x00460fa0-0x00460ffe Byte Span Fill 8-Byte Blocks

## Status

## Address Range

`0x00460fa0-0x00460ffe` (`sub_460FA0`, size `0x5e`, 43 decoded instructions).

The preceding `0x00460f99-0x00460fa0` and following `0x00460ffe-0x00461000` bytes are alignment padding.

## Behavior

Fills eight-byte blocks across one or more rows with a repeated byte value. The helper receives a destination row pointer, destination row pitch, fill byte, eight-byte block count, and row count.

It expands the fill byte into a repeated 64-bit pattern, loads that pattern into `mm1`, writes qword blocks across each row, advances by destination pitch between rows, restores the saved integer registers, and emits `emms`.
