## Behavior

Paints the employee item property dialog's selected item image:

- initializes two `EPFTileContext` locals through `EPFTileContext::Initialize()`;
- runs inherited `DialogPane::OnPaint()` / focus-paint setup;
- sets draw and text colors to `143` (`0x8f`);
- looks up `SELLITEM.EPF` and renders it with `SELLITEM.PAL`;
- reads the selected [UID:0001UD][EmployeeRecord](by-type/by-struct/EmployeeRecord.md) pointer from `m_itemRecord` at `this + 0x280`;
- reads `m_itemIconRect` from `this + 0x270`;
- calls `GetItemGlyphBounds(m_itemRecord->itemImageId, &itemGlyphContext.bounds)` before the fixed-slot draw;
- builds a 44-by-44 destination rectangle from `m_itemIconRect.left/top`;
- renders the item sprite with `g_pItemObjImageLib->DrawItemImageIn43x43Slot`, using target-context record fields `itemImageId` at `+0x004` and `itemPaletteFlags` at `+0x006`.
