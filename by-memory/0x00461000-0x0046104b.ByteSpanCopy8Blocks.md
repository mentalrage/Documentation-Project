## Address Range

The preceding `0x00460ffe-0x00461000` and following `0x0046104b-0x00461050` bytes are alignment padding.

## Behavior

Copies eight-byte source blocks into destination blocks across one or more rows. The helper receives a source row pointer, source row pitch, destination row pointer, destination row pitch, eight-byte block count, and row count.

It converts the block count into a byte count, saves the integer register set, copies each qword with `movq` from source to destination, advances source/destination by eight bytes inside a row, advances source/destination by their row pitches between rows, restores registers, and emits `emms`.

The decompiler's pointer return is not treated as a source contract. The only caller discards `eax` after the call and reloads its saved block count; the helper should be modeled as a void block-copy side-effect helper until final source prototypes are audited.

## Behavioral Pseudocode

This is evidence-oriented pseudocode, not final reconstruction C++:

```text
ByteSpanCopy8Blocks(src, srcPitch, dst, dstPitch, blockCount, rowCount):
    byteCount = blockCount << 3;
    for each row while rowCount > 0:
        srcCursor = src;
        dstCursor = dst;
        end = dst + byteCount;
        while (dstCursor < end):
            copy qword from srcCursor to dstCursor;
            srcCursor += 8;
            dstCursor += 8;
        src += srcPitch;
        dst += dstPitch;
```
