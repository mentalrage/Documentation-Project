## IDA MCP Evidence

Checked on 2026-05-23: IDA confirms starts at `0x0057b490` and `0x0057bb30`. The constructor at `0x00579a30` calls `0x0057b490` during initial audio setup.

Additional IDA MCP checks on 2026-05-24 confirmed the callback starts at `0x0057b630`, `0x0057b730`, `0x0057b750`, and `0x0057b7a0`. `SoundManager::ReinitializeAudioDriver` passes these addresses directly to `AIL_set_file_callbacks`.

IDA MCP import checks on 2026-05-25 confirm the underlying middleware boundary: `mss32` supplies the `_AIL_*` functions used by this range, while the project-owned code here configures the driver, registers callbacks, and bridges DAT/loose file readers into Miles. The shipped local runtime files are staged in [UID:0001QX][README](by-meta/obtained_thirdparty_files/README.md).
