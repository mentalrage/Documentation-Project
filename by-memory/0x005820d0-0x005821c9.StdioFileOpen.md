## Behavior

`Open` prepares a loose-filesystem reader for a wide-character path:

| Step | Evidence |
| --- | --- |
| Stat the path | Calls the platform dispatch entry `dword_69BE18(path, statBuffer)`, documented as `_wstat64i32` by [UID:0000TQ][WideApiDispatchTable](by-global/WideApiDispatchTable.md). |
| Throw on stat failure | If the stat call returns `-1`, allocates a `FileError` object, constructs it with the same path, and throws it through `__CxxThrowException`. |
| Open in binary-read mode | Calls the platform dispatch entry `dword_69BE14(path, L"rb")`, documented as `_wfopen` by [UID:0000TQ][WideApiDispatchTable](by-global/WideApiDispatchTable.md). |
| Store handle | Writes the returned `FILE*` to `this[1]`, object offset `+0x04`. |
| Cache size | Copies the local stat-buffer size field into `this[2]`, object offset `+0x08`. |
| Throw on open failure | If `_wfopen` returns null, constructs and throws `FileError` for the same path. |
| Return | On success, the binary leaves the opened `FILE*` in `EAX`; all direct callers ignore it, so source-facing formal C++ uses `void Open(const wchar_t *path)`. |
