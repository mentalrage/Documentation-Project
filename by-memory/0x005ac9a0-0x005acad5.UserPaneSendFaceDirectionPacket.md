### Summary

This target is a raw no-function/no-route `LivingObjectPane` helper body. The best current source/search alias is `SendFaceDirectionPacket(unsigned char direction)`, but the behavior is more specific than a face-only packet: it builds and sends a fixed nine-byte opcode `0x32` movement/facing-history packet, then updates the local movement-history ring.

The sent packet contains the caller direction byte, a movement-history write-index tag, the ObjectPane movement-state byte at `this+0x1a0` (`m_objectState[0x98]`), the current tile X/Y serialized as big-endian words, and a trailing sent `0x32` marker.
