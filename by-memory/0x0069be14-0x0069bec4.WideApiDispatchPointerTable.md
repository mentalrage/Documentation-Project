# Wide API Dispatch Pointer Table

## Summary

- Address range: `0x0069be14-0x0069bec4`
- Entity kind: platform API dispatch pointer table
- Disposition: reconstructable platform-support data
- Rebuild handling: `source-declared/generated-binary`
- Confidence: strong for range and table ownership; medium for complete final symbol naming

This range is the main body of the client-wide wide-character Windows/CRT API dispatch table up to, but not including, the separately documented `SendMessageW` slot at `0x0069bec4-0x0069bec8`. The table is initialized by the real platform initializer at `0x0041a280` and consumed by file I/O, windowing, registry, IME, thread/event, locale, message dispatch, and platform helper code.

## Evidence

- [UID:0000TQ][WideApiDispatchTable](by-global/WideApiDispatchTable.md) documents the full `0x0069be14-0x0069bed0` dispatch table. This page covers the main body up to, but not including, [UID:0001Q1][0x0069bec4-0x0069bec8.g_browserControlKeyCallback](by-memory/0x0069bec4-0x0069bec8.g_browserControlKeyCallback.md), the separately documented `SendMessageW` slot with stale generated browser/transport aliases.
- IDA decompilation of [UID:0000WD][0x0041a280-0x0041a4a8.WideApiDispatchInit](by-memory/0x0041a280-0x0041a4a8.WideApiDispatchInit.md) writes `_wfopen` to `dword_69BE14`, `_wstat64i32` to `dword_69BE18`, `sub_599570` to `dword_69BE1C`, and many neighboring `*W` Win32 function pointers through `0x0069bec0`.
- Representative consumers include `StdioFile::Open`, `PathExistsViaStat`, thread/event helpers, IME paths, file/resource loaders, window/message paths, and registry/platform helper calls.
- The following `0x0069bec4-0x0069bec8` dword is documented separately because generated output gave it browser/transport aliases, but IDA MCP now proves it is the `SendMessageW` dispatch entry in the same platform API table.

## Rebuild Notes

Keep this table with `PlatformApi` / `UniAPIInit` source. Consumer modules should call named dispatch entries instead of declaring local `dword_69BE**` globals.
