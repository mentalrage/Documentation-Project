## Signature And Behavior

- Observed signature shape: `void __thiscall sub_4BA6B0(GrafPort *this, const RectLike *clip, const TileRectRecord *tileData, wchar_t *paletteName)`.
- The helper constructs a temporary saved region, copies `this + 0x84` into it, applies the caller clip rectangle to `this + 0x84`, and restores the saved region before cleanup.
- `tileData[4..7]` provide the source tile rectangle; the width is `tileData[6] - tileData[4]` and the height is `tileData[7] - tileData[5]`. Non-positive tile dimensions skip the blit loops and fall through to cleanup.
- Visible GrafPort bounds at `this + 0x44..0x50` determine the column and row counts. The destination rectangle starts from the current visible origin, advances by tile width across each row, then advances by tile height for the next row.
- Each tile blit reads the GrafPort byte at `this + 0x70`, resolves the palette name through `sub_543D70(dword_67A7E0, paletteName)`, and calls [UID:0000TN][SurfaceRenderCallbackTable](by-global/SurfaceRenderCallbackTable.md) entry `dword_69B3E8` with the source rect, source offset, destination rect, GrafPort flag byte, palette handle, and zero blend/option argument.
