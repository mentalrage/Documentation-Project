# 0x005974f0-0x0059756e ThreadMan Scalar Deleting Destructor

## Behavior

The scalar deleting destructor restores the `ThreadMan` vtable, terminates and closes the worker thread handle, destroys the watch-list object, clears [UID:0000SH][g_pThreadMan](by-global/g_pThreadMan.md), destroys the `LObject` base, and applies the normal MSVC deleting-destructor flag byte.

When `flags & 1` is clear, the wrapper returns the object after cleanup. When `flags & 1` is set and `flags & 4` is clear, it frees the object through [UID:000197][0x004f4ac0-0x004f4b00.OperatorDeleteWrapper](by-memory/0x004f4ac0-0x004f4b00.OperatorDeleteWrapper.md). When `flags & 4` is set, it takes the compiler/runtime guard branch that pushes size `0x14` and `this`, calls `@_guard_check_icall_nop@4`, and returns without the normal delete-wrapper call.

This shares core cleanup behavior with the raw non-deleting destructor start in [UID:0001K1][0x00596d20-0x00596e0b.ThreadManRawMessageWrappers](by-memory/0x00596d20-0x00596e0b.ThreadManRawMessageWrappers.md).
