## Behavior

Handles parcel alert mouse interaction through the secondary-vtable view. The callback receives the secondary subobject pointer, so decompiler offsets must be normalized by subtracting `0xa0` to reach the owning `ParcelPane`. The source-facing signature is `bool ParcelPane::OnMouseEvent(const PaneMouseEvent& event)`.

The event object is read as a small input record: type byte at `event + 4`, x coordinate at `event + 8`, and y coordinate at `event + 12`. The source C++ uses the established local names `event.type`, `event.x`, and `event.y`; the raw event values remain documented as `0`, `1`, and `3`.

The method behaves as a two-slot mouse state machine:

| Input event category | Behavior |
| --- | --- |
| move/hover (`event type 0`) | First hit-tests owner bounds at normalized `+0x44`. If outside, non-animating left/right states at `+0xfc/+0xfd` are reset to idle and the callback returns false. If inside, it checks the right button rect at `+0x110` before the left button rect at `+0x100`: right hit idles the left state unless it is animating and sets right hover unless it is pressed; left hit idles the right state unless it is animating and sets left hover unless it is pressed. Inside-pane/no-slot-hit returns true and leaves states unchanged. |
| press (`event type 1`) | If outside owner bounds, returns false. If inside the right rect, sets `m_rightButtonState` / `+0xfd` to pressed state `2`; if inside the left rect, sets `m_leftButtonState` / `+0xfc` to pressed state `2`. It returns true for any cursor position inside the pane, even when neither slot rect is hit. |
| release/action (`event type 3`) | If outside owner bounds, returns false. Inside bounds, clears both visual state bytes to idle, then left hit sets left hover and, when `m_leftParcelCount` / `+0xf9` is nonzero, sends literal packet byte `0x41` through [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) and [UID:0001HU][0x00574bb0-0x00574c13.QueueAndSendPacket](by-memory/0x00574bb0-0x00574c13.QueueAndSendPacket.md) with size `1` and sets `m_leftSlotAcknowledged` / `+0x120`. Right hit sets right hover and, when `m_rightSlotActionEnabled` / `+0xfb` is true and [UID:0000QG][g_pBulletinSession](by-global/g_pBulletinSession.md) is null, performs `new BulletinSession(1, 0, true)` through [UID:00001D][BulletinSession](by-class/BulletinSession.md) / [UID:0000ZH][0x00471150-0x00471ff1.BulletinSessionCore](by-memory/0x00471150-0x00471ff1.BulletinSessionCore.md) and sets `m_rightSlotAcknowledged` / `+0x121`. |
| other event values | Return false. |

The visual state bytes feed [UID:0002KI][0x005469e0-0x00546aab.ParcelPaneGetButtonFrameIndex](by-memory/0x005469e0-0x00546aab.ParcelPaneGetButtonFrameIndex.md), which maps states `0..3` to `ALERTBTN` frame indices or live animation-frame bytes.
