## Behavior

This is a repeated opcode `0x4b` packet-helper strip. The even-numbered short helpers write `{ 0x4b, subtype, 0 }` and send length `3`. The string helpers write `{ 0x4b, subtype, 1 }`, convert one wide string to multibyte, write the byte length, copy the converted payload, range-check against `0x100` conversion length and `0x80` packet length, and send `length + 4` bytes.

The cluster ends immediately before [UID:00010F][0x00486330-0x0048652d.SubmitClanChangeHelper](by-memory/0x00486330-0x0048652d.SubmitClanChangeHelper.md), which sends subtype `10` action `2` with the multi-field clan-change payload.
