## Behavior

`IMECompositionPane::OnPaint()` paints the active IME composition popup:

1. Clears inherited GrafPort/Pane draw-blit mode byte `this+0x70`, represented in source as `m_drawMode = 0`.
2. Uses `SetDrawColor(143)` and fills the inherited bounds rectangle at `this+0x44` / `m_bounds`.
3. Uses `SetDrawColor(128)` and frames the same bounds through `DrawRectFrame(&m_bounds)`.
4. Uses `SetTextColor(128)`, moves the text cursor to `m_bounds.left + 2, m_bounds.bottom - 2`, scans `compositionText` until its UTF-16 nul terminator, and draws exactly that counted run through `DrawWideText`.
5. Builds a local `RectBounds` caret rectangle with `left = compositionCursorX`, `top = 2`, `right = compositionCursorX + 1`, and `bottom = GetLineHeight() + 2`.
6. Sets draw color `128` again and fills the one-pixel-wide caret rectangle.
