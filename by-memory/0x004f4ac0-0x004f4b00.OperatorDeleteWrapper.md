# 0x004f4ac0-0x004f4b00 Operator Delete Wrapper

## Status

- Confidence: strong from live IDA MCP.
- Entity kind: global deallocation operator wrapper.
- Proposed owner: [UID:0000L7][MemoryMan](by-file/MemoryMan.md)
- Related helper family: [UID:0000T8][MemoryAllocationHelpers](by-global/MemoryAllocationHelpers.md)

## Behavior

This wrapper calls [UID:0001BC][0x00516030-0x00516036.GetMemoryMan](by-memory/0x00516030-0x00516036.GetMemoryMan.md), passes the returned object in `ecx`, and then calls [UID:0001BF][0x00516170-0x00516184.FreeBufferMemory](by-memory/0x00516170-0x00516184.FreeBufferMemory.md) for the supplied block.

The wrapper has SEH/security-cookie scaffolding but no project-specific logic beyond routing deletes through the MemoryMan helper family.
