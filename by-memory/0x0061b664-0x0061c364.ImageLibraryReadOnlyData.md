## Summary

This `.rdata` span contains image-library vtables, `ProtectedArray` template vtables for image info records, DAT/resource table file names, EPF/EPD asset names, and image-loader error strings. It is source-owned data required by the image library and resource loading subsystem.

## Observed Contents

- Vtables for `MapTileImageLib`, `HumanImageLib`, `MonsterImageLib`, `RidingImageLib`, `StaticObjImageLib`, `EffectObjImageLib`, `ItemObjImageLib`, `LightObjImageLib`, and `NewHumanImageLib`.
- `ProtectedArray` vtables for head/body/coat/weapon/face/accessory/hair/helmet/mantle/necklace/shoe/effect/item/light info records.
- `_AUTOBUF<unsigned char>` vtable data at `0x0061b864-0x0061b874`, physically embedded among image/resource string data but owned by shared template support.
- DAT/table filenames such as `headtable.txt`, `headsptable.txt`, `swordtable.txt`, `speartable.txt`, `bowtable.txt`, `fantable.txt`, `shieldtable.txt`, and `arrowtable.txt`.
- Asset names and error strings for tile, human, monster, riding, static object, effect, item, light, and new-human image loading.
