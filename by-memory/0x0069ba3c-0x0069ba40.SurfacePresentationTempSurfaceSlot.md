# Surface Presentation Temporary Surface Slot

## Summary

- Address range: `0x0069ba3c-0x0069ba40`
- Entity kind: global-data pointer slot
- Disposition: reconstructable source-declared data
- Rebuild handling: `source-declared/generated-binary`
- Confidence: medium for role, strong for range and DirectDraw surface xrefs

`dword_69BA3C` is a temporary DirectDraw-style surface/object pointer used inside the shared surface presentation initializer at `0x00558840`.

## Evidence

- IDA MCP `py_eval` reports the item as a four-byte `.data` dword initialized to `0xffffffff`.
- Xrefs are all inside `sub_558840` / [UID:0001G6][0x00557140-0x00559aef.SurfacePresentation](by-memory/0x00557140-0x00559aef.SurfacePresentation.md) surface presentation code at `0x00558a53`, `0x00558a90`, `0x00558aa5`, and `0x00558ae6`.
- IDA disassembly shows the function passes `&dword_69BA3C` into a DirectDraw-style vtable call, reads the created object, passes it to a second vtable call, and then passes it with the object at `this+0x100`.
- The preceding slots are `g_pPowerDialog` and `g_pVoteMenuPane`; the following block begins packet-transform state, so this dword is a standalone render/surface global.

## Rebuild Notes

Keep the declaration with the shared `Surface`/presentation module until final rendering source placement is recovered. It is not a dialog singleton despite being physically adjacent to dialog slots.
