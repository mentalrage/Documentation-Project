# 0x004710e0-0x0047110e InlineIsEqualGUID

## Scope

- Range: `0x004710e0-0x0047110e`
- Entity kind: external SDK/header-inline helper emitted in codegen
- Source-facing identity: Windows SDK `guiddef.h` `InlineIsEqualGUID(REFGUID, REFGUID)` or the equivalent `IsEqualGUID` / `IsEqualIID` caller spelling.
- Current raw IDA name: `sub_4710E0`
- Historical descriptive name: `BrowserGuidCompareHelper`
- Disposition: ignored/non-emitting SDK helper evidence, not NexusTK-authored Browser product logic.
- Rebuild handling: BrowserWindow, BrowserControlPane, and Browser `QueryInterface` caller pages should use the SDK/header GUID equality helper; this page must not emit a standalone Browser-local helper.
- Confidence: very strong for exact bytes, range, caller set, helper semantics, Browser source-use context, and SDK-inline identity; below final audit because the exact original SDK/macro spelling is not proven.

This body compares two 16-byte COM GUID/IID values as four `unsigned long` values and returns `1` when all four dwords match or `0` on the first mismatch. The five direct callers are Browser-family `QueryInterface` implementations, but caller locality is source-use evidence, not ownership evidence. The helper body matches the Windows SDK GUID equality inline closely enough that the previous Browser-authored-helper classification is now rejected.

## SDK/Header Inline Evidence

- Local Windows Kits `guiddef.h` defines `InlineIsEqualGUID(REFGUID rguid1, REFGUID rguid2)` as four `unsigned long` comparisons and returns an `int`.
- `IsEqualIID`, `IsEqualCLSID`, and `IsEqualGUID` are standard wrapper spellings around the same GUID equality concept.
- The observed body has no Browser-specific state, policy, fields, globals, or side effects. It is the source-equivalent header-inline predicate emitted into the Browser caller region because the caller code performs COM `QueryInterface` IID comparisons.
- A handwritten Browser helper that duplicates `guiddef.h` exactly is possible but lower probability than SDK/header-inline emission, so it is rejected as the source-facing owner model.
