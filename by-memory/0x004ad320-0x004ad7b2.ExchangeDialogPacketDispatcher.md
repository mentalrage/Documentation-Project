# 0x004ad320-0x004ad7b2 ExchangeDialog Packet Dispatcher

## Behavior

This function handles server exchange packets. IDA MCP confirms it as a real function at `0x004ad320` with size `0x493`, ending at `0x004ad7b2`.

The handler reads the packet payload pointer from the incoming event object, rejects packets whose opcode byte is not `0x42`, then dispatches on the subcommand byte:

| Subcommand | Observed behavior |
| --- | --- |
| `1` | Constructs an `AddItemWithCountDialog`-style item-count dialog using the exchange id at `this+0x1cc`. |
| `2` | Updates one offered-item list row. The packet supplies side, slot/key, item id, color, and a multibyte item name converted to wide text. |
| `3` | Updates money display for the local or remote side; zero local amount clears local exchange amount state. |
| `4` | Shows cancellation/termination alert text, closes existing exchange alert state, closes the exchange dialog, and closes active add-item dialog state if present. |
| `5` | Updates ready/confirm state and may show an exchange confirmation alert. |
