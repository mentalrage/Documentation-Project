These accessors are concrete old-human image-library instantiations of the reusable `ProtectedArray<T>` template. `HumanImageLib::HumanImageLib` uses the `HairInfo` accessor while parsing hair-color data and uses the `Acc2Info` accessor while parsing accessory draw flags. The larger caller set from `sub_4D9180` and orphan `0x004d58bd-0x004d696a` composition code proves the same protected-array fallback access pattern is also used during old-human draw/composition preparation.

The direct source parent is [UID:0000MU][ProtectedArray](by-file/ProtectedArray.md), because the emitted bodies are template accessor code generated from the reusable fallback-array declaration. [UID:0000JY][HumanImageLib](by-file/HumanImageLib.md) remains the concrete field/caller owner for these instantiations, not the direct template-source parent.
