# 0x0061c5a4-0x0061c7a8 Interface Effect Read-Only Data

## Range

- Address range: `0x0061c5a4-0x0061c7a8`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and resource literals must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains the `InputMan`, `InterfaceEfx`, and `InterfaceEfxMgr` vtables plus interface-effect resource names. It ends at the `InventoryPane` vtable at `0x0061c7a8`.

## Evidence

- IDA MCP `py_eval` on 2026-05-28 reports `??_7InputMan@@6B@`, `??_7InterfaceEfx@@6B@`, and `??_7InterfaceEfxMgr@@6B@` vtables in this range.
