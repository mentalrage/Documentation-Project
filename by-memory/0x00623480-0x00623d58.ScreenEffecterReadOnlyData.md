# 0x00623480-0x00623d58 Screen Effecter Read-Only Data

## Range

- Address range: `0x00623480-0x00623d58`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and effect resource literals must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains the screen dimmer/fade-out complete-object-locator pointers/vtables and the screen visual-effecter family: overlay/image effecters, filter effecters, wave/flip/earthquake/water/lake effecters, and their small resource strings/constants. It starts at the `ScreenDimmer` complete-object-locator pointer and ends before the `ScrollPane` complete-object-locator pointer.
