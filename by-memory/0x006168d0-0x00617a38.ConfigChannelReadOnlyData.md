## Summary

This `.rdata` span starts with the `Config` vtable and continues through registry keys, channel/ISP integration strings, multi-server configuration names, and option key strings. The final `0x006179ec-0x00617a38` tail is now split as [UID:00035G][0x006179ec-0x00617a38.ConnStatusPanePrimaryVtableData](by-memory/0x006179ec-0x00617a38.ConnStatusPanePrimaryVtableData.md), because IDA shows that block is `ConnStatusPane` primary vtable data rather than Config/channel literal data.

The range remains reconstructable because the vtable and string constants must be represented by source declarations/literals in the rebuilt configuration modules. It remains unassigned because no exact child split currently separates the `Config` vtable, registry/default option literals, and historical channel/ISP helper strings, and the aggregate itself is below the current parent-attachment threshold.
