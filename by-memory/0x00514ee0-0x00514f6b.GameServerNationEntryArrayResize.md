## Behavior

The helper is a positive-count resize. It exits unchanged when `count <= 0` or when `count == m_count`. When resizing, it allocates a new `GameServerConfig::NationEntry[count]` dynamic array, default-initializes each new record's `nationId` to `-1`, copies `min(oldCount, count)` complete records from the old dynamic array with `_memmove`, frees the old dynamic array, then stores the new pointer and count.

The source-facing body is best written as `ProtectedArray<GameServerConfig::NationEntry>::Resize(int count)`.
