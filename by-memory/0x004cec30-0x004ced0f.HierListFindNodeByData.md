## Behavior

Recursively searches a `HierList` tree for a row whose caller payload bytes match the supplied payload.

For each row in the current list, the helper calls the base list accessor at `0x004f32b0`, compares the requested payload against row `+0x08` for `elementSizeWithHierarchyOverhead - 11` bytes, and returns the matched row pointer on success.
