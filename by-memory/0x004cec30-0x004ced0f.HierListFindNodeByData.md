## Behavior

Recursively searches a `HierList` tree for a row whose caller payload bytes match the supplied payload.

For each row in the current list, the helper calls the base list accessor at `0x004f32b0`, compares the requested payload against row `+0x08` for `elementSizeWithHierarchyOverhead - 11` bytes, and returns the matched row pointer on success. The comparison uses a dword loop followed by byte-tail checks, so it is an exact byte comparison rather than a pointer comparison.

When a row matches, the optional first out parameter receives the owning `HierList` object and the optional second out parameter receives the actual zero-based row index. This index is consumed by [UID:0002IC][0x004ce860-0x004ce9ad.HierListInsertBefore](by-memory/0x004ce860-0x004ce9ad.HierListInsertBefore.md), [UID:0002ID][0x004ce9b0-0x004ceafc.HierListInsertAfter](by-memory/0x004ce9b0-0x004ceafc.HierListInsertAfter.md), and [UID:0002IE][0x004ceb00-0x004ceb45.HierListRemoveNode](by-memory/0x004ceb00-0x004ceb45.HierListRemoveNode.md).

When the current row has a child list at node `+0x04`, the helper recurses into that child list with the same payload and out parameters. It returns the descendant match if the recursive call succeeds; otherwise it continues scanning the current list. If no match is found, it returns `0`.
