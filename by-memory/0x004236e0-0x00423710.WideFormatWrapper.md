## Behavior

This is a thin variadic wide-format wrapper for a fixed `0x104` wide-character destination bound. It prepares a `va_list`, passes a null locale, obtains the process-local CRT stdio option storage through [UID:0000WO][0x0041b9a0-0x0041b9de.CrtStdioCommonSprintfGlue](by-memory/0x0041b9a0-0x0041b9de.CrtStdioCommonSprintfGlue.md), and delegates to `__stdio_common_vswprintf_s`.

The wrapper returns the CRT formatting result on success and normalizes any negative result to `-1`. The fixed `0x104` count matches path-sized formatting use in fitting-room cache-path construction and other UI/resource/screenshot path assembly code, so source reconstruction should express this as a shared formatting helper or direct secure-format call rather than as a fitting-room category helper.
