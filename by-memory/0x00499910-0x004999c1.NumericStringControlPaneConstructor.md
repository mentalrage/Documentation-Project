## Source Construction And Failure Semantics

- `ControlPane(8, bounds)` is the source-level base initializer. The three NumericStringControlPane vptr stores are compiler output and are not handwritten.
- `m_text` uses the accepted one-pointer wide StringBase representation. Default member construction accounts for `InitializeEmptyWide`; the body call `AssignWideLiteral(text)` accounts for the second string helper without inventing an SSO layout.
- The loader call is exactly `LoadDatFileBuffer(L"9X11FONT.BIN", 99, &glyphBufferSize)`. A local non-null `int *` out parameter preserves the binary; passing `NULL` is rejected. The decompiler's reuse of the fourth argument stack slot as `&a5` is optimizer storage reuse, not an `int *` constructor parameter.
- `glyphBufferSize` is not read after the call. `m_numericGlyphs` receives the returned `char *`; the 99-byte zero prefix supports the helper's packed-glyph indexing.
- There is no constructor-side null check, fallback resource, retry, free, or exception branch. Ownership transfers to the class and [UID:00011N][0x004999d0-0x00499a4e.NumericStringControlPaneDestructor](by-memory/0x004999d0-0x00499a4e.NumericStringControlPaneDestructor.md) performs the only guarded source-level release.
