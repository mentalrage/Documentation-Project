# 0x00460f10-0x00460f99 Byte Span Subtract Rows

## Status

- Disposition: reconstructable NexusTK render/support code.
- Entity kind: free helper.
- Likely source file: [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) `SoftwareBlend16` or neighboring alpha-mask/span utility source.
- Confidence: strong for exact boundary, sole caller, callee, block/tail split, row stepping, and wrapping byte-subtract behavior; medium-high for final source-facing helper name/signature.
- Rebuild handling: `source-authored`.

## Address Range

`0x00460f10-0x00460f99` (`sub_460F10`, size `0x89`, 63 decoded instructions).

The preceding `0x00460f09-0x00460f10` and following `0x00460f99-0x00460fa0` bytes are alignment padding.

## Behavior

Subtracts source bytes from destination bytes row-by-row. The helper receives a source row pointer, source row pitch, destination row pointer, destination row pitch, byte width, and row count.

For each span it splits the width into `width / 8` eight-byte blocks and a `width % 8` scalar tail. When the block count is positive it calls [UID:00020I][0x004610a0-0x004610ee.ByteSpanSubtract8Blocks](by-memory/0x004610a0-0x004610ee.ByteSpanSubtract8Blocks.md), then advances both row pointers past the completed block bytes. It subtracts each remaining tail byte from the destination with normal byte wrapping semantics and advances source/destination by their row pitches for each row.
