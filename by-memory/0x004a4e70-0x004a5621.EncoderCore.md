## Writer Semantics

- Constructor writes flags word `0x0101`, so new instances default to nonzero byte-order and valid/writable state.
- The ordinary destructor at [UID:00013E][0x004a4ea0-0x004a4ea7.EncoderDestructor](by-memory/0x004a4ea0-0x004a4ea7.EncoderDestructor.md) restores the `Encoder` vtable and returns. B010 reanalysis confirms the source body is empty: it does not free, detach, reset buffer state, or implement scalar deleting destructor logic.
- Nonzero byte-order at `+0x10` writes scalar values big-endian; zero byte-order writes scalar values by direct native little-endian stores.
- The valid/writable byte at `+0x11` gates writer methods. Writers return without mutation when it is clear.
- Capacity checks reserve one trailing byte for `Finalize` to append a final NUL. Failed capacity checks clear the valid/writable byte and do not write partial data.
- [UID:00013F][0x004a4ec0-0x004a4ef1.EncoderWriteByte](by-memory/0x004a4ec0-0x004a4ef1.EncoderWriteByte.md) now records the simplest writer instance of this rule: one payload byte plus one reserved terminator byte, one caller at `0x0058e57b`, no callees, and no ownership transfer to the TextEditPane serializer.

- [UID:00013H][0x004a4ff0-0x004a506b.EncoderWriteInt](by-memory/0x004a4ff0-0x004a506b.EncoderWriteInt.md) now records the 32-bit scalar writer instance of this rule: four payload bytes plus one reserved terminator byte, one caller at `0x0058e58b`, no callees, default big-endian marker bytes `6b 6f 6e 67` for value `0x6b6f6e67`, and no ownership transfer to the TextEditPane serializer.
- `Initialize` attaches caller-owned storage, stores capacity, resets cursor, and sets valid/writable to `1`.
