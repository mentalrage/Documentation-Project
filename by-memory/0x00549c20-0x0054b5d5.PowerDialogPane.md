## Behavior Summary

This range implements a power configuration dialog opened by server packet case `0x46`. The constructor/initializer parses a packet entry table, creates seven header/image buttons, creates four scrollable power lists, fills row totals for a 5x5 grid, sorts each list, attaches the dialog to the UI root, and stores the power-dialog singleton.

The dialog methods then support:

- apply-all threshold submission through opcode `0x4c`, subcommand `1`;
- selected-slot submission through opcode `0x4c`, subcommand `2`;
- `POWER.EPF` background drawing and grid text drawing;
- list row drawing with a color swatch and label;
- drag/click selection across four sibling embedded list panes.

## Source Ownership Notes

`0x00549c20` is the important ownership correction. Generated Wave3/simroot evidence names it under `PowerListPane`, but the body installs `PowerDialogPane` vtables and builds the dialog shell. Keep the `0x0054b000+` list methods as `PowerListPane` in the same original source file, not as a separate original `.cpp` unless later evidence shows reuse outside this dialog.

Normalize the singleton at `0x0069ba34` to `g_pPowerDialog`. The generated `g_activePowerListPane` name is a downstream symptom of the same bad constructor owner.
