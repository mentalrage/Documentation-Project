## Behavior

This function lazily opens a numbered `DATA/MON%d.DAT` archive and builds the cached bounds bucket used by monster projection/render bounds.

Observed flow:

1. Search the `+0x3c` bounds-bucket cache for `archiveIndex`.
2. If no bucket is cached, format `DATA/MON%d.DAT` and construct a DAT container/reader for that archive.
3. Insert the open archive reader into the `+0x1c` open-archive cache.
4. Allocate a 0x0c-byte [UID:0001VA][MonsterArchiveBoundsBucket](by-type/by-struct/MonsterArchiveBoundsBucket.md), insert it into the `+0x3c` bounds-bucket cache, and read its 8-byte header.
5. Allocate `(entryCount + 1) * 0x18` bytes for [UID:0001VB][MonsterArchiveBoundsEntry](by-type/by-struct/MonsterArchiveBoundsEntry.md) rows.
6. Read each entry's four 16-bit bounds values and two 32-bit payload offsets, convert the offsets to pointers by adding the archive payload base, and write a zero-bounds sentinel entry.
7. Return the cached bucket pointer.
