# 0x00615560-0x00615570 CheatDetector Vtable Data

## Range

- Address range: `0x00615560-0x00615570`
- Entity kind: `vtable-data`
- Disposition: reconstructable source-declared/generated-binary vtable.

## Summary

This 16-byte `.rdata` island is the `CheatDetector` RTTI-adjacent word and two-slot vtable between the chatting constants and the clan pane/dialog read-only data. It should be produced from the `CheatDetector` class declaration in the rebuilt source rather than hand-authored as raw bytes.
