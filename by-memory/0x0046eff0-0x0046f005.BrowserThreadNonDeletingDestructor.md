# 0x0046eff0-0x0046f005 BrowserThread Non-Deleting Destructor

## Scope

- Range: `0x0046eff0-0x0046f005`

This is the ordinary non-deleting `BrowserThread` destructor body immediately before `BrowserThread::RunMessageLoop`. It reinstalls the `BrowserThread` vtable, clears the global browser-thread singleton, and tail-calls the base `Thread` destructor.
