## Behavior

The scalar deleting destructor restores the [UID:0001X7][ChangeManVtable](by-type/by-vtable/ChangeManVtable.md), destroys the sorted registration list if present, clears [UID:0000QI][g_pChangeMan](by-global/g_pChangeMan.md), destroys the `LObject` base, and optionally frees object storage depending on the MSVC deleting-destructor flags.

The flag check skips object free when the low delete bit is clear or the vector-delete bit is set.
