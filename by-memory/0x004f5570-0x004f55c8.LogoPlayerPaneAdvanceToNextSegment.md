# 0x004f5570-0x004f55c8 LogoPlayerPane Advance To Next Segment

## Behavior

This method handles user-requested skipping from the first startup movie segment to the next segment. It checks the skip guard at `+0x110` and current video progress through the `VideoPlayerPane` state pointer at `+0xfc`; if the pane is still eligible to advance, it computes the second segment pointer from the AUTOBUF base plus the saved first-segment size, marks the guard, and calls `0x005c0110` to open the next memory-backed Bink segment.

The second segment pointer is `autobufData + 4 + firstSegmentSize`, where `autobufData` is read from `+0x104` and `firstSegmentSize` from `+0x114`. The remaining byte count passed as the third argument is `autobufCount - firstSegmentSize - 4`, with `autobufCount` read from `+0x108`.

If the second segment opens, it tail-calls the owner virtual at vtable slot `+0x48`, matching the playback/start path. If opening fails, it tail-calls [UID:0001EA][0x00544460-0x00545086.PaneCore](by-memory/0x00544460-0x00545086.PaneCore.md)'s `0x00544690` mark-for-deletion helper. The guard is set before the open attempt, so a failed skip still prevents repeated reopen attempts.
