## Behavior

This method paints the compact IME status label frame, background, and current `statusText[256]` text for the lower-right mode indicator. The paint sequence is:

1. Clear the inherited GrafPort draw/blit mode byte at `this+0x70`.
2. Select draw color `0x8f` and fill the inherited pane bounds at `this+0x44`.
3. Select draw color `0x80` and draw a rectangle frame around the same bounds.
4. Select text color `0x80`.
5. Move the text cursor to `m_bounds.left + 2` and `m_bounds.bottom - 2`.
6. Count the null-terminated UTF-16 `statusText` buffer at `this+0xf8` and draw exactly that many wide characters.
