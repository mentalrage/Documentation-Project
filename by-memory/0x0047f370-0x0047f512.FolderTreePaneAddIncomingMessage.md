## Behavior

This helper inserts a cloned/owned chat message into the chat display list at `this + 0x130`, updates scroll state, optionally scrolls to the newest message, and enforces a maximum of 1000 stored messages.

Both display-mode branches:

- read a UI/chat state byte through `0x004a90b0(dword_67A754, &flags)`;
- call virtual slot `+0x0c` on the incoming `ColorStringChattingMessage`-like argument to obtain an owned message pointer;
- insert that pointer into the list through vtable slot `+0x18` with index/position `1`;
- check `sub_544A00(this)` and bit `0x04` of the state byte before auto-scrolling;
- trim the oldest entry when the list count at `list + 0x0c` exceeds `1000`.

When trimming, the helper fetches index `0` through list vtable slot `+0x10`, deletes the returned message object if present, removes one element at index `0` through list vtable slot `+0x1c`, and refreshes scrollbars. The non-`byte_66DA97` branch additionally adjusts the scroll position after trimming when needed, using the current scroll value from `0x0055e950`.

void AddIncomingMessage(const ColorStringChattingMessage &message)
{
    unsigned char flags = 0;
    ReadChatUiFlags(g_pMainUiState, &flags);

    ColorStringChattingMessage *owned = message.Clone();
    m_messages->Insert(1, owned);

    SyncScrollbars();

    if (!IsUserScrolling() && (flags & 0x04) == 0) {
        const int page = GetScrollPageSize(0);
        const int max = GetScrollMax(0);
        SetScrollRange(0, page, max);
    }

    if (m_messages->GetCount() > 1000) {
        delete m_messages->GetAt(0);
        m_messages->RemoveAt(0, 1);
        SyncScrollbars();
    }
}
