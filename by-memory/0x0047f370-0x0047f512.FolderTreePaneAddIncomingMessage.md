## Behavior

This helper inserts a cloned/owned chat message into the chat display list at `this + 0x130`, updates scroll state, optionally scrolls to the newest message, and enforces a maximum of 1000 stored messages.

Both display-mode branches:

- read a UI/chat state byte through `0x004a90b0(dword_67A754, &flags)`, where [UID:00028L][0x0067a754-0x0067a758.g_pEventMan](by-memory/0x0067a754-0x0067a758.g_pEventMan.md) documents `dword_67A754` as the process `EventMan` singleton;
- call virtual slot `+0x0c` on the incoming `ColorStringChattingMessage`-like argument to obtain an owned message pointer;
- insert that pointer into the list through vtable slot `+0x18` with index/position `1`;
- check `sub_544A00(this)` and bit `0x04` of the state byte before auto-scrolling;
- trim the oldest entry when the list count at `list + 0x0c` exceeds `1000`.

When trimming, the helper fetches index `0` through list vtable slot `+0x10`, deletes the returned message object if present, removes one element at index `0` through list vtable slot `+0x1c`, and refreshes scrollbars. The current-layout branch calls `sub_55E990` only inside the auto-scroll and trim paths. The fallback/old-layout branch calls `sub_55E990` immediately after insertion and additionally adjusts the scroll position after trimming when needed, using the current scroll value from `0x0055e950`.
