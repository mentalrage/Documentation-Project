## Behavior

Hit-tests a scrollbar-local point and returns the scroll part under that point. It computes rectangles for arrow buttons, page-track segments, and the thumb using the same geometry rules as [UID:0002D7][0x0041e4f0-0x0041e777.FittingRoomScrollPaneGetPartRect](by-memory/0x0041e4f0-0x0041e777.FittingRoomScrollPaneGetPartRect.md), then checks the input point with the rectangle point-test helper.

Observed return values align with:

- `0`: leading arrow/end cap
- `1`: page area before thumb
- `2`: thumb
- `3`: page area after thumb
- `4`: trailing arrow/end cap
- `0xff`: no part hit

The helper accounts for horizontal and vertical orientation through `this + 0xfc`, scroll range/current value through `this + 0xfe` and `this + 0x100`, and dragging offset state at `this + 0x108`.

```cpp
ScrollPart FittingRoomScrollPane::HitTestPart(int x, int y) const
{
    for (int part = LeadingButton; part <= TrailingButton; ++part) {
        Rect bounds;
        GetPartRect(part, bounds);
        if (bounds.Contains(x, y))
            return static_cast<ScrollPart>(part);
    }

    return NoPart;
}
```
