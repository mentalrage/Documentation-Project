## Behavior

This helper restores the `SimpleListPane` vtables, walks the primary list-entry state at `this + 0x130`, reads the entry count at `[*(this + 0x130) + 0x0c]`, frees each non-null heap-backed entry buffer, clears each slot to null, then calls the shared `ListPane` non-deleting cleanup at `0x004f3b60`.

It is the non-deleting cleanup body used before the scalar deleting destructor thunk family at `0x00573c38-0x00573d15`.

## Boundary Notes

IDA models `0x00573a00` as `sub_573A00`, size `0x98`. The bytes `0x005739f6-0x00573a00` and `0x00573a98-0x00573aa0` are `0xcc` padding. The raw copied-text append helper begins at `0x00573aa0`, but current IDA does not model that successor as a function.
