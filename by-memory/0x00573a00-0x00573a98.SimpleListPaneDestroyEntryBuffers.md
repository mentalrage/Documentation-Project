# 0x00573a00-0x00573a98 SimpleListPane Destroy Entry Buffers

## Status

- Disposition: reconstructable NexusTK project code.
- Entity kind: destructor core / helper.
- Owner class: [UID:0000D8][SimpleListPane](by-class/SimpleListPane.md).
- Likely source module: [UID:0000NQ][SimpleListPane](by-file/SimpleListPane.md).
- Parent aggregate: [UID:000241][0x00573a00-0x00573c38.SimpleListPaneDestructorAndEntryHelpers](by-memory/0x00573a00-0x00573c38.SimpleListPaneDestructorAndEntryHelpers.md).
- Confidence: strong for boundary and behavior.

## Behavior

This helper restores the `SimpleListPane` vtables, walks the primary list-entry state at `this + 0x130`, frees each non-null heap-backed entry buffer, clears each slot to null, then calls the shared `ListPane` non-deleting cleanup at `0x004f3b60`.

It is the non-deleting cleanup body used before the scalar deleting destructor thunk family at `0x00573c38-0x00573d15`.

## Boundary Notes

IDA models `0x00573a00` as `sub_573A00`, size `0x98`. The next bytes are alignment through `0x00573a9f`, followed by the raw copied-text append helper at `0x00573aa0`.

## Evidence

- IDA MCP `lookup_funcs` reports `0x00573a00` as a function of size `0x98`.
- IDA decompilation reads `this + 0x130`, loops `*(list + 0x0c)` entries, obtains each entry through `0x004f3dc0`, frees non-null heap buffers through `0x00516030` / `0x00516170`, clears the slot, then calls `0x004f3b60`.
- Raw disassembly confirms vtable stores to `0x00624c64`, `0x00624cec`, and `0x00624d1c` before the cleanup loop.
