## Behavior

This raw helper constructs an opcode `0x26`/decimal `38` password-change style packet with four UTF-16 input strings. It computes wide-string lengths, converts each field to a bounded multibyte string with `WideCharToMultiByte`, writes byte-length fields through `sub_575380`, copies payload bytes with `sub_516220`, appends a terminating zero, and sends the finished packet through `dword_67A7EC` via `sub_574BB0`.

The helper is similar to [UID:0002QC][0x004fe9e0-0x004febe2.SendPasswordChangeRequest](by-memory/0x004fe9e0-0x004febe2.SendPasswordChangeRequest.md), but includes one additional input argument.
