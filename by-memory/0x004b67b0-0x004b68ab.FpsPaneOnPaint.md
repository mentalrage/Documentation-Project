## Behavior

`FpsPane::OnPaint` increments the frame counter, formats the current FPS value as UTF-16 `L"%5.1f FPS"`, copies the pane bounds, clears/fills those bounds, and draws the FPS text twice for the visible offset overlay effect.

Exact behavior order:

1. Increment `m_frameCount` at owner offset `+0xf8`.
2. Format `m_currentFps` at owner offset `+0x100` as UTF-16 `L"%5.1f FPS"`, with the float promoted to a `double` for the varargs format helper.
3. Copy the inherited Pane bounds from `this +0x44` into a local `RectBounds`.
4. Set active draw/fill color `0`.
5. Fill/clear the local bounds through SurfaceRenderCallbackTable slot `0x0069b3fc`.
6. Set text/palette color state to `128`, move to `(1,13)`, and draw the formatted UTF-16 string.
7. Set text/palette color state to `14`, move to `(0,12)`, and draw the same UTF-16 string again.
8. Release the temporary wide string before returning.

The first text pass is the offset pass at `(1,13)` using color `128`; the second pass is at `(0,12)` using color `14`. Documentation may describe this as an overlay/shadow effect, but it must preserve this exact draw order and coordinates.
