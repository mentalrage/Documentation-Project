## Behavior

This raw helper inserts a copied wide-string entry at a caller-supplied index. It computes the UTF-16 source string length, allocates `(length + 1) * sizeof(wchar_t)`, initializes and copies the buffer with `_wcscpy_s`, then calls the shared `ListPane` insert helper at `0x004f3c00` with the index from the first stack argument.

## Boundary Notes
