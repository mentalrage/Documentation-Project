## Behavior

The helper receives `this` in `ecx` and one stack argument. It decrements the stack argument and only constructs a local resource rectangle/descriptor when the decremented value is zero. It chooses resource id `0x00a6` when [UID:0000SW][g_useEpfAssets](by-global/g_useEpfAssets.md) is `1`, otherwise resource id `0x00ad`, and calls `sub_4B7C50` with `(0, 0, resourceId, 0x10)`.

After the optional descriptor setup, the helper dispatches through the receiver vtable slot `+0x20`, passing the local descriptor pointer.
