## Behavior

Startup code at `0x00419ff0` constructs this object with `sub_421590(&dword_66DE18, &word_60DB20, 0)` and registers the static destructor at `0x0060c2a0`. The destructor tests the large-string capacity guard, frees `dword_66DE18` when needed, then resets `dword_66DE28 = 0`, `dword_66DE2C = 7`, and clears the first word of the string storage.

`MetaMan::FindEntry` and `MetaMan::LoadStatValues` pass this object into the direct metadata lookup helper before trying the caller-provided table name. The practical behavior is alias-aware lookup with fallback, even though the literal source string for this global remains uncertain.
