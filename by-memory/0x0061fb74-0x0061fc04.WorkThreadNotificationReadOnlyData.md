# 0x0061fb74-0x0061fc04 Work Thread/Notification Read-Only Data

## Range

- Address range: `0x0061fb74-0x0061fc04`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and notification literals must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains the compiler-emitted table and literal island for `MiscWorkThread`, its three local notification classes, the monitor/condition synchronization primitives, and the `MSGHandler` vtable tail. The physical range also includes several MSVC RTTI complete-object-locator dwords immediately before following vtable labels, so the source reconstruction should model the owning classes and literals rather than hand-port the mixed bytes as one standalone object. It ends immediately before the `MusicControlDialog` vtable label at `0x0061fc04`.
