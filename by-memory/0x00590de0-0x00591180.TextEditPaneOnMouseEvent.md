## Behavior

This method handles mouse selection and drag state for the editor. If editor flag bit zero is clear it returns handled immediately. Otherwise it reads pointer payload coordinates in the established `y` then `x` order, dispatches five event kinds, converts points to text positions, tracks click timing and repeated clicks, updates the zero-initialized static selection anchor at `0x0069be04`, moves the selection endpoints, and invokes the selection autoscroll helper while intentionally ignoring its bool result.

The body uses TextEditPane helpers for hit testing and navigation (`0x0058f690`, `0x0058f1b0`, `0x0058f0d0`, `0x0058f2a0`), double/triple-click expansion (`0x0058f9a0`, `0x0058fa00`), B005-owned file-local word boundary and member autoscroll helpers (`0x00594b50`, `0x00594cb0`), capture state (`0x005449d0`, `0x005449f0`, `0x00544a00`), IME composition completion (`0x004e9490`), and rectangle testing (`0x004b7e80`).

### Event Cases And State

- Cursor move returns false without capture. With capture, it performs the first hit test, expands through file-local `FindWordBoundary` for repeated-click state one or through the line helper for larger counts, chooses the opposite saved endpoint as the anchor, adjusts hit-part value two past the character, updates the selection, invokes bool `AutoScrollSelectionToPoint(y,x)`, ignores that return, and returns true.
- Left-button down and double-click share the content-rectangle gate. The strict repeated-click predicate is `messageTime < m_lastClickTime + 500` together with equal text offset; equality at exactly 500 milliseconds is not repeated. The method stores time, offset, and hit part before later selection work.
- A one-character prior selection routes its format run and format record to `TextEditObject::OnMouseEvent(Event *,bool,unsigned int)` when the object is non-null and the clicked offset remains inside the selected half-open range. There are no extra format-index, list, or Event null guards.
- Shift retains the existing active endpoint according to `m_selectionReversed`. A repeated click increments the repeat count and saves a word range for count one or a line range for larger counts. A non-repeated click clears the count and uses the clicked offset as the anchor.
- The press path completes IME composition before capturing the mouse, and capture occurs only for left-button down, not double-click. A second independent hit test then applies the same repeated-click range adjustment before selection/autoscroll.
- Left-button up releases capture only when present and returns `g_useEpfAssets != 1`; right-button down clears the selection and returns true; every unknown event returns false.
