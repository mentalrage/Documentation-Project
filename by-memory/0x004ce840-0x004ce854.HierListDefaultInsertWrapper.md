## Source Form Decision

The accepted source-facing reconstruction is:

```cpp
void HierList::InsertFirst(const void *parentPayload, const void *payload)
{
    InsertBefore(parentPayload, NULL, payload);
}
```

This page is a source-authored wrapper method, not padding, not a compiler-generated thunk name, and not a private raw-only helper. The normal frame, two explicit caller arguments, fixed null sibling/reference argument, class-local call into the three-argument insert-before core, and `retn 8` stack cleanup match a two-argument `__thiscall` wrapper. The wrapper is not equivalent to the core `InsertBefore`; it intentionally hides the sibling/reference parameter and fixes it to null.

`InsertFirst` is an inferred source-facing name rather than recovered original-symbol proof. It is preferred because [UID:0002IC][0x004ce860-0x004ce9ad.HierListInsertBefore](by-memory/0x004ce860-0x004ce9ad.HierListInsertBefore.md) uses a null sibling/reference as `-1`, then inserts at `index + 1`, which yields slot `0` in the selected root or parent child list. The method pairs with [UID:0002IA][0x004ce7e0-0x004ce839.HierListTailInsertWrapper](by-memory/0x004ce7e0-0x004ce839.HierListTailInsertWrapper.md) / `InsertLast`, and follows the local `List`/`HierList` naming style of `InsertAt`, `InsertBefore`, `InsertAfter`, `Append`, and `GetElementAt`.

Rejected alternatives:

- `DefaultInsertWrapper`: useful as a stable by-memory label, but not a plausible source-facing method name.
- A two-argument `InsertBefore(parentPayload, payload)`: mechanically possible, but it hides the absent reference payload and makes "before what" ambiguous.
- `InsertAtHead`: behaviorally accurate, but less consistent with the concise local API style than `InsertFirst`.
- `Append`, `InsertLast`, or other tail-oriented names: contradicted by the null-reference path inserting at slot `0`.
- Leaving formal C++ blank: no longer justified because the wrapper's behavior, source shape, parameter roles, and accepted inferred source name are documented enough for first-draft emission.
