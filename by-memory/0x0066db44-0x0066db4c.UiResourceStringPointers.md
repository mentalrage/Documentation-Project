# 0x0066db44-0x0066db4c UI Resource String Pointers

## Summary

- Address range: `0x0066db44-0x0066db4c`
- Entity kind: initialized pointer data
- Disposition: reconstructable project data
- Rebuild handling: `source-declared/generated-binary`
- Confidence: strong for pointer targets and consumers; medium for final source owner grouping

This range contains two initialized pointers into `.rdata`: a wide resource filename pointer for `STAFF.EPF` and an ANSI string pointer for `CMAP`.

## Evidence

- IDA pointer inspection resolves `0x0066db44` to the `STAFF.EPF` wide string in the main-menu read-only data range.
- IDA data xrefs from `0x004ffaa0` repeatedly load `off_66DB44`, matching the `StaffsDialogPane` constructor path that loads the staff dialog background resource.
- IDA pointer inspection resolves `0x0066db48` to the `CMAP` string, with direct data xrefs from `0x00504b90` and `0x00504e00`.

## Reconstruction Notes

- Keep the `STAFF.EPF` pointer with the staff dialog resource/source context unless a later pass proves it is part of a shared resource-pointer table.
- Keep the `CMAP` pointer with map/profile support once the two `0x00504xxx` helpers are named.
- Final source may not need explicit pointer globals if the compiler generated them from local `static` string references.
