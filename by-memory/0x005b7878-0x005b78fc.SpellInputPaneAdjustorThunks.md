## Behavior

The second thunk for each class decompiles as a `this - 41 dwords` adjustment followed by a tail call to the owning scalar deleting destructor. For example, IDA decompiles `0x005b7899` as a call to `0x005b7cf0(this - 41, flags)`, matching the secondary-subobject destructor shape used by the input-pane inheritance layout.

The first thunk in each pair is the sibling vtable adjustor for the same owning scalar deleting destructor and decompiles as `this - 40 dwords`.

IDA MCP `xrefs_to` on 2026-05-26 reports only vtable/data refs for the thunk starts, landing at `0x0062f490`, `0x0062f4c0`, `0x0062f634`, `0x0062f664`, `0x0062f6c0`, `0x0062f6f0`, `0x0062f1d4`, `0x0062f204`, `0x0062f51c`, `0x0062f54c`, `0x0062f5a8`, and `0x0062f5d8`. IDA MCP `callers` reports no ordinary callers for the scalar deleting destructors, matching vtable-only destructor dispatch.
