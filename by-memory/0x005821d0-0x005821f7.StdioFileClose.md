## Behavior

`Close` is a reusable virtual close operation, distinct from the destructor:

| Step | Evidence |
| --- | --- |
| Null-handle guard | If the `FILE*` field at object offset `+0x04` is zero, returns `false`. |
| Close stream | Calls `_fclose(*(FILE **)(this + 4))` when a handle is present. |
| Clear cached size | Writes zero to object offset `+0x08` after the `_fclose` call. |
| Return status | Returns whether `_fclose` returned zero. |

IDA decompilation:

```c
bool __thiscall sub_5821D0(int this)
{
  int result; // eax

  if ( !*(_DWORD *)(this + 4) )
    return false;
  result = fclose(*(FILE **)(this + 4));
  *(_DWORD *)(this + 8) = 0;
  return result == 0;
}
```

The observed body clears the cached size at `+0x08` but does not clear the `FILE*` field at `+0x04`. Preserve that as binary behavior until a final source pass proves whether the original source intentionally left the handle field untouched or whether this is a compiler/decompiler artifact around a source-level close helper.
