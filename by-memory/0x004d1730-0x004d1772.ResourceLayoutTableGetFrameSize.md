## Behavior

Returns the bucket-wide frame width and height stored in the 44-byte [UID:0001VT][ResourceLayoutNameRecord](by-type/by-struct/ResourceLayoutNameRecord.md).

IDA MCP decompilation on 2026-05-31 shows the same lazy-load pattern as the other accessors:

- `FindResourceIndex(resourceName)`;
- fallback to `LoadResourceIndex(resourceName)` when absent;
- `List::GetElementAt(index)` through the registry vtable slot `+0x10`;
- writes the 16-bit values at record offsets `+0x22` and `+0x24` to caller-provided output pointers.
