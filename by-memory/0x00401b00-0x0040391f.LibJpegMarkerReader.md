## Range Role

This range is the retained IJG libjpeg 6b marker-reader source file, `jdmarker.c`, compiled into the static libjpeg island. It owns decompression marker parsing after the decompression public API creates the decompressor and before the input controller/master controller consumes scan data.

The half-open start remains `0x00401b00`. It follows [UID:0000VQ][0x004011b0-0x004019e3.LibJpegDecompressApiFrontEnd](by-memory/0x004011b0-0x004019e3.LibJpegDecompressApiFrontEnd.md), alignment at `0x004019e3-0x004019f0`, retained raw `jdapistd.c` buffered-image output code at `0x004019f0-0x00401af2`, and alignment at `0x00401af3-0x00401b00`. That predecessor tail is not marker-reader code.

The repaired half-open end is `0x0040391f`. The previous endpoint `0x004038c7` was only the exclusive end of the modeled `save_marker` body. Live disassembly shows alignment at `0x004038c7-0x004038d0`, raw retained `jpeg_set_marker_processor` code at `0x004038d0-0x0040391e`, one-byte alignment at `0x0040391f`, and [UID:0000VS][0x00403920-0x004048e2.LibJpegCompressApiFrontEnd](by-memory/0x00403920-0x004048e2.LibJpegCompressApiFrontEnd.md) starting with `jpeg_CreateCompress`.
