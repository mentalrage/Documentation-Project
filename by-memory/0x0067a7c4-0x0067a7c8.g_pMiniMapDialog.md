# 0x0067a7c4-0x0067a7c8 g_pMiniMapDialog

## Summary

- Address range: `0x0067a7c4-0x0067a7c8`
- Entity kind: global pointer
- Proposed name: `g_pMiniMapDialog`
- Disposition: reconstructable NexusTK global data

This four-byte zero-initialized global stores the active `MiniMapDialog` singleton pointer. The constructor writes it, the destructor/clear helper resets it, and packet/hotkey paths use it to close or avoid constructing a duplicate minimap dialog.
