static const unsigned short MIDI_TRACK_MAX = 12;

static void StartSelectedMidiFile(const wchar_t *path)
{
    wcscpy_s(g_midiCurrentPath, MIDI_TRACK_PATH_CHARS, path);

    if (g_midiDocumentLoaded != 0) {
        MidiPlayer_ResetStream(MIDI_RESET_SKIP_REOPEN);
    }

    if (MidiStreamOpenAndPrimeBuffers() == 0) {
        g_midiDocumentLoaded = 1;
    }

    if (g_midiRestartPending != 0) {
        midiStreamRestart(g_hMidiStream);
        g_midiRestartPending = 0;
        ApplyMidiVolume(g_midiVolumeScale);
        return;
    }

    if (g_midiStreamRunning != 0) {
        MidiPlayer_ResetStream(0);
    }

    if (g_midiDocumentLoaded == 0) {
        g_midiStreamRunning = 0;
    } else {
        g_midiStreamState = 0;
        if (midiStreamRestart(g_hMidiStream) == 0) {
            g_midiStreamRunning = 1;
            ApplyMidiVolume(g_midiVolumeScale);
            return;
        }
    }

    ApplyMidiVolume(g_midiVolumeScale);
}

void MidiPlayer::SelectTrack(unsigned short trackId)
{
    wchar_t configuredName[MIDI_TRACK_PATH_CHARS];
    wchar_t trackPath[MIDI_TRACK_PATH_CHARS];

    if (g_pConfig->m_midiEnabled == 0) {
        return;
    }
    if (m_playbackEnabled == 0) {
        return;
    }
    if (trackId > MIDI_TRACK_MAX) {
        return;
    }
    if (trackId == m_selectedTrackId) {
        return;
    }

    m_selectedTrackId = MIDI_TRACK_NONE;
    MidiPlayer_ResetStream(0);
    m_selectedTrackId = trackId;

    ConfigGetStringPreference(g_pConfig, (unsigned char)trackId, configuredName, MIDI_TRACK_PATH_CHARS);
    if (configuredName[0] != 0) {
        swprintf(trackPath, L"Midi\\%s", configuredName);
        g_midiAllowEndReplay = 0;
        StartSelectedMidiFile(trackPath);
    }

    if (g_midiStreamRunning == 0) {
        ConfigSetStringPreference(g_pConfig, (unsigned char)trackId, L"");
        swprintf(configuredName, L"%d.mid", trackId);
        g_midiAllowEndReplay = 1;
        StartSelectedMidiFile(configuredName);
    }

## Reconstruction Notes

These helpers belong with `MidiPlayer.cpp` because the select method reads object offsets `+0x04` and `+0x08`, manipulates the selected-track sentinel, and directly coordinates the WinMM MIDI state owned by [UID:0000T9][MidiPlayerWinMMState](by-global/MidiPlayerWinMMState.md). The source-quality shape is now `void MidiPlayer::SelectTrack(unsigned short trackId)` plus private file-scope `StartSelectedMidiFile(const wchar_t *path)`.

`SelectTrack` first gates on `g_pConfig->m_midiEnabled` (`g_pConfig + 0x84c`), `m_playbackEnabled`, `trackId <= 12`, and `trackId != m_selectedTrackId`. It clears the selected track to `-1`, resets the current stream, stores the requested id, reads the selector string through the Config MIDI track-path helper, tries `Midi\\%s` with `g_midiAllowEndReplay` / `g_midiFillReplayMode` clear, and falls back to `%d.mid` with the mode set if playback is still not running.

`StartSelectedMidiFile` copies the selected path to `g_midiCurrentPath`, resets an already loaded document through [UID:00041O][0x00526460-0x00526569.MidiPlayerResetStream](by-memory/0x00526460-0x00526569.MidiPlayerResetStream.md) with skip-reopen flag `0x00010000`, calls `MidiStreamOpenAndPrimeBuffers`, sets `g_midiDocumentLoaded` on success, handles `g_midiRestartPending`, resets any still-running stream, restarts playback, sets `g_midiStreamRunning`, and calls [UID:00041K][0x00525f40-0x0052609a.MidiPlayerRawVolumeAndStreamLocalHelpers](by-memory/0x00525f40-0x0052609a.MidiPlayerRawVolumeAndStreamLocalHelpers.md)'s `ApplyMidiVolume(g_midiVolumeScale)`.

The first-draft C++ intentionally uses source-facing stand-ins `ConfigGetStringPreference`, `ConfigSetStringPreference`, `MidiPlayer_ResetStream`, `MidiStreamOpenAndPrimeBuffers`, and `ApplyMidiVolume`. These names should be normalized with the wider Config/MidiPlayer declaration pass, but they are preferable to raw `sub_` names for code generation.

Shared constants `MIDI_RESET_SKIP_REOPEN`, `MIDI_TRACK_PATH_CHARS`, and `MIDI_TRACK_NONE` are now emitted by [UID:0002B1][0x0069b500-0x0069b870.MidiPlayerWinMMStateGlobals](by-memory/0x0069b500-0x0069b870.MidiPlayerWinMMStateGlobals.md) at generation position `0`. This page keeps only the track-selection-specific `MIDI_TRACK_MAX` constant so generated `MidiPlayer.cpp` does not receive duplicate definitions.

Rejected generated or historical aliases:

- `m_selectedDeviceId` / `m_currentDeviceId` for `this+0x08`: rejected because the field is compared and stored as a requested MIDI track id; the WinMM device id is global stream-open storage at `0x0069b504`.
- `g_pApplication->midiEnabled`: rejected because the target reads `g_pConfig + 2124`, verified as `0x84c`.
- `g_midiUseLooseFile`: rejected as a final name for `0x0069b510`; the value is passed into stream-fill paths, so use `g_midiAllowEndReplay` or `g_midiFillReplayMode` until the exact role is validated.
- `g_midiStreamOpen`: rejected for `0x0069b514`; reset/document-release behavior supports `g_midiDocumentLoaded`.
- `g_midiSelectedPath`: rejected for `Destination`; the current state-map name is `g_midiCurrentPath`.
