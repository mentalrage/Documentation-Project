# 0x00526100-0x00526332 MidiPlayer Track Selection Helpers

## Status

- Confidence: strong for behavior; medium for final function names.
- Entity kind: sparse helper cluster.
- Proposed owner: [UID:0000LD][MidiPlayer](by-file/MidiPlayer.md)
- Related state: [UID:0000T9][MidiPlayerWinMMState](by-global/MidiPlayerWinMMState.md)

## Covered Ranges

| Range | Entity | Notes |
| --- | --- | --- |
| `0x00526100-0x00526233` | select MIDI track helper | Validates config/music state and requested track id, resets the active stream, resolves the track filename from DAT/config paths, then calls the start helper. |
| `0x00526240-0x00526332` | start selected MIDI file helper | Copies the selected filename, resets an existing stream when needed, opens/primes playback through `0x00525920`, restarts the stream, updates running flags, and reapplies volume. |

## Evidence

- IDA MCP `lookup_funcs` reports `0x00526100` size `0x133` and `0x00526240` size `0xf2`.
- `0x00526100` is called from `0x00512fb2`, a higher-level game/client path that selects MIDI music.
- `0x00526240` is only called from `0x00526100`.
- Both helpers call [UID:0001CF][0x00525b10-0x0052664b.MidiPlayerAndWinMMHelpers](by-memory/0x00525b10-0x0052664b.MidiPlayerAndWinMMHelpers.md); `0x00526240` also calls [UID:0001CE][0x00525920-0x00525b0d.MidiStreamOpenAndPrimeBuffers](by-memory/0x00525920-0x00525b0d.MidiStreamOpenAndPrimeBuffers.md).
- 2026-06-01 IDA MCP `lookup_funcs` rechecked `0x00526100` as `sub_526100`, size `0x133`, and `0x00526240` as `sub_526240`, size `0xf2`.
- 2026-06-01 IDA MCP `callers` reports a single external caller for `0x00526100` at `0x00512fb2`; `0x00526240` is called only by `0x00526100` at `0x005261c8` and `0x0052621c`.
- 2026-06-01 IDA MCP decompilation confirms the select helper checks config music state at `g_pConfig + 2124`, object playback state at `this + 4`, requested track id `<= 12`, and selected-track field at `this + 8`; it resets the active stream, resolves configured and fallback track paths, and calls the start helper.
- 2026-06-01 IDA MCP decompilation confirms the start helper copies the selected path into `Destination`, optionally resets/reopens the stream through `0x00526460` and `0x00525920`, restarts WinMM playback with `midiStreamRestart`, updates stream-running/restart state, and reapplies volume through `0x00525ff0`.
- 2026-06-01 IDA MCP `get_bytes 0x00526332 size 14` confirms the end padding before `MidiPlayer::StopPlayback` is all `0xcc`.
