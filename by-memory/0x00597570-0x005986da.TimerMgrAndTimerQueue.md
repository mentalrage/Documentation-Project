## Boundary Notes

- The timer cluster is immediately followed by `TimerPane` at `0x005986e0`; do not extend the `TimerMgr` range into `TimerPane`.
- 2026-05-26 IDA MCP recheck reconfirmed `0x00597570` as a modeled 9-byte function that writes `TimerHandler::vftable`; it is not a ThreadMan tail despite adjacency to `0x005974f0-0x0059756e`.
- `0x00597610-0x00597645` was previously documented as sound-manager timer wrappers because sound callers use these helpers. IDA shows they are generic `TimerHandler` wrappers forwarding to `g_pTimerMgr`, not sound-owned code.
- `0x00597580` was previously documented as an `EventDispatcher` destructor and `0x00597600` as `InterfaceEfx::RemoveFromUpdateScheduler`; both are now resolved as generic `TimerHandler` destructor/wrapper code.
- `0x00597780` decompiles through an IDA name/address oddity (`sub_60C270`), but the instruction addresses are `0x00597780+` and the body operates on the static `TimerMgr` instance at `0x0069b3ac`.
