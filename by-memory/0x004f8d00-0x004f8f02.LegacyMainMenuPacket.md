## Behavior Summary

The helper parses inbound payload fields, copies a short byte string, performs shared packet/session checks, may open a localized alert and request exit, queues an outbound opcode `0x10` packet containing the copied string plus the main-menu layout flag, deletes the active screen dimmer if present, and requests a `Meta.dat` synchronization through [UID:0000RL][g_pMetaMan](by-global/g_pMetaMan.md). The accepted source-facing helper name is `HandleLegacyMainMenuPacket`: transfer-only, reconnect-only, meta-only, and login-redirect names were rejected because the sole caller is the `MainMenuPane::OnServerMessage` case-3 route and the body combines all of those side effects.

The accepted source-facing helper is `HandleLegacyMainMenuPacket` because current MCP `1017-1018` proves the only inbound route is `MainMenuPane::OnServerMessage` case `3` and no second xref or transfer-helper route exists.
