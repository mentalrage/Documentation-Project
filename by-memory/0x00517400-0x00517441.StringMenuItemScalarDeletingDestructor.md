# 0x00517400-0x00517441 StringMenuItem Scalar Deleting Destructor

## Status

- Entity kind: scalar deleting destructor.
- Owner: [UID:0000E8][StringMenuItem](by-class/StringMenuItem.md).
- Likely source file: [UID:0000MN][PopupMenuControls](by-file/PopupMenuControls.md).

## Behavior

Compiler deleting-destructor wrapper for `StringMenuItem`:

- restores the base `MenuItem` vtable before cleanup;
- runs base cleanup through `0x004f4a90`;
- conditionally frees `this` through `0x004f4ac0` depending on the scalar-delete flag.

No separate heap label buffer cleanup is present because the string label is inline at `this + 0x18`.

- IDA `lookup_funcs 0x00517400` reports start `0x00517400` and size `0x41`.
- IDA decompile shows the vtable reset, base cleanup call, and conditional delete flag test.
- Bytes at `0x00517441` are `0xcc` alignment padding before the adjacent `MenuDialogFactoryHelpers` island.
