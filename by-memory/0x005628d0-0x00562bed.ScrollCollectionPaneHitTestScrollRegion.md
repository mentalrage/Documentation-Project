## Behavior

This helper tests a pane-local point against the themed scrollbar parts `0..4` and returns the matching `ScrollCollectionPart` or `kScrollCollectionPartNone` / `0xff`.

It:

- loops through the five candidate part ids `kScrollCollectionPartLeading` through `kScrollCollectionPartTrailing`;
- reads the current cursor position through `g_pEventMan->GetCursorPosition(&cursor)` and pane screen offset through `GetScreenOffset(&origin)` on each iteration;
- treats origin `(-1000, -1000)` as an invalid/sentinel screen-offset state and uses an empty rectangle;
- converts the cursor into pane-local coordinates, starts from `m_bounds`, and branches on `m_orientation`;
- uses `m_scrollSkinIndex`, `kScrollPanePartExtentBySkin`, `m_scrollPosition`, `m_scrollRange`, `m_scrollEnabled`, `m_thumbDragActive`, and `m_thumbDragOffset` to compute leading, page-before-thumb, thumb, page-after-thumb, and trailing rectangles;
- keeps page-before/page-after empty when the scroll range is disabled/unavailable, while still producing the contracted thumb rectangle for the disabled thumb case; and
- calls `PointInRect(localY, localX, &rect)` before advancing to the next part.

The helper is part of the same input/update cycle as [UID:0001GV][0x00562e80-0x00562fb0.ScrollCollectionPaneHighlightRawHelpers](by-memory/0x00562e80-0x00562fb0.ScrollCollectionPaneHighlightRawHelpers.md) and [UID:0001GW][0x00562fb0-0x00563070.ScrollCollectionPaneUpdateDragScroll](by-memory/0x00562fb0-0x00563070.ScrollCollectionPaneUpdateDragScroll.md): input code calls it to decide the initial active part, the drag/update helper calls it again to test whether the current cursor is still over the active non-thumb part, and highlight helpers invalidate rectangles computed by the adjacent geometry helper.
