## Behavior

This status-pane handler responds to the IME open-status event. It rejects any Event whose type byte at Event `+0x04` is not `0x0b` / decimal `11` (`kEventImeOpenStatus`) and returns `false` for those records. For accepted type-11 records, it reads the open-status payload at Event `+0x08`; payload value `1` selects the `IME` status label, and any other value selects the `ENG` status label.

The emitted source intentionally preserves the binary's exact `SetText` count constants: `SetText(L"IME", 4)` for open status and `SetText(L"ENG", 6)` otherwise. These counts are source-unusual for the short labels, but they are direct body constants and must not be normalized to apparent string lengths.
