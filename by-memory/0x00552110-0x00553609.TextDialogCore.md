## Behavior Notes

- The constructor reads dialog type/id, object data, price/state fields, optional body text, button caption, and input metadata from the packet.
- It builds either normal or high-resolution layouts using `DLGMSG5`, `DLGMSG51`, or `DLGMSG6` resource families.
- It composes EPF image controls, image buttons, optional [UID:0000M3][ObjectImageControlPane](by-file/ObjectImageControlPane.md), [UID:0000O8][StaticTextControlPane](by-file/StaticTextControlPane.md), and [UID:0000OM][TextEditControlPane](by-file/TextEditControlPane.md).
- Action `1` reads the text-edit child, builds an opcode `0x3a` packet with typed text payload, queues/sends it, and closes the dialog.
- Actions `2`, `3`, and `4` call shared previous/next/current dialog packet helpers before closing.
