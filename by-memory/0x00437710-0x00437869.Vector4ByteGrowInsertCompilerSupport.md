## Behavior

The function is the out-of-line full-capacity path generated for a vector whose element width is four bytes. It accepts a vector-header receiver, an insertion position, and one four-byte source value. It computes the old size and insertion index, selects a larger checked capacity, allocates replacement storage, moves the prefix, writes the inserted value, moves the suffix, releases old storage, and commits the new `begin`, `end`, and `capacityEnd` pointers.

The allocation path is embedded in this specialization rather than delegated to a product allocator helper. Small allocations use the returned block directly. Large allocations reserve additional space, align the usable vector storage to 32 bytes, and retain the raw allocation base immediately before the aligned pointer so later vector destruction can validate and free it. Length/capacity failure follows the linked MSVC vector runtime support instead of a NexusTK feature error path.

Prefix and suffix relocation use four-byte element arithmetic and overlap-safe movement. The body has no feature-state reads, product globals, resource strings, protocol constants, virtual dispatch, or feature-specific callees. Its only semantic operation is generic vector growth and insertion.
