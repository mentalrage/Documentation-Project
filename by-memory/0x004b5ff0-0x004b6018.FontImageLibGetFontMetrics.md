## Behavior

This method ensures a requested font slot is loaded, then returns fixed metric values through optional output pointers.

Observed behavior from live IDA:

- calls [UID:0002HS][0x004b60c0-0x004b61d9.FontImageLibEnsureFontSlotLoaded](by-memory/0x004b60c0-0x004b61d9.FontImageLibEnsureFontSlotLoaded.md) with the requested font id before returning metrics;
- writes `0x000c` to the first optional `int16` output pointer when it is non-null;
- writes `0x000c` to the second optional `int16` output pointer when it is non-null;

- does not read the loaded slot metrics that `EnsureFontSlotLoaded` stores, so this helper reports a fixed 12-by-12 text cell even though the loader records archive metrics separately.
