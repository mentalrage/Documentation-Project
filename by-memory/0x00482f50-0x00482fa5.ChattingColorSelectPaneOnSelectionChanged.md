## Behavior

This virtual selection handler delegates to the base list selection update, then notifies the owning [UID:00001T][ChattingColorPane](by-class/ChattingColorPane.md). If the owner has a valid selector pointer, it copies the selected entry's value from `selector+0x134` into owner state at `owner+0x2a8`, then refreshes both color-list child panes when both pointers are available.

This mirrors the raw owner-side helper [UID:0002G1][0x00482c60-0x00482c9f.ChattingColorPaneSyncColorListSelectionHelperRaw](by-memory/0x00482c60-0x00482c9f.ChattingColorPaneSyncColorListSelectionHelperRaw.md), but here the call is vtable-owned by `ChattingColorSelectPane`.

Approximate shape:

```cpp
void ChattingColorSelectPane::OnSelectionChanged(int selectedIndex, bool notify)
{
    ListPane::OnSelectionChanged(selectedIndex, notify);

    if (m_owner->m_categoryPane == NULL)
        return;

    m_owner->m_currentCategory = m_owner->m_categoryPane->selectedValue;
    if (m_owner->m_firstColorList != NULL && m_owner->m_secondColorList != NULL) {
        m_owner->m_firstColorList->RefreshForCurrentCategory();

    }
}
```
