## Ownership Decision

This is a real startup/update-notice source neighborhood. The main class methods and notice helpers should migrate with [UID:0000O5][StartupWindow](by-file/StartupWindow.md). The curl callback is project-owned StartupWindow/libcurl glue, not libcurl source. The string helpers may later move to a shared string utility if broader callers are found, but current xrefs tie them to `StartupWindow::RunUpdateCheck`.

The callback at `0x00581b80` uses `strlen` for incoming data length and then returns `elementSize * elementCount`. Treat it as a text-response append callback for the observed update/minimap metadata URLs, not as a binary-safe generic curl sink.

Do not move `LoadPcxImage` into this file. StartupWindow consumes the PCX loader, while [UID:0000K3][ImageLoaders](by-file/ImageLoaders.md) owns the loader implementation.
