## Ownership Decision

This is a real startup/update-notice source neighborhood. The main class methods and notice helpers should migrate with [UID:0000O5][StartupWindow](by-file/StartupWindow.md). The curl callback is project-owned StartupWindow/libcurl glue, not libcurl source. The string helpers may later move to a shared string utility if broader callers are found, but current xrefs tie them to `StartupWindow::RunUpdateCheck`.

The callback at `0x00581b80` uses `strlen` for incoming data length and then returns `elementSize * elementCount`. Treat it as a text-response append callback for the observed update/minimap metadata URLs, not as a binary-safe generic curl sink.

Do not move `LoadPcxImage` into this file. StartupWindow consumes the PCX loader, while [UID:0000K3][ImageLoaders](by-file/ImageLoaders.md) owns the loader implementation.

## Behavior Summary

- Constructor: stores the live singleton pointer, writes the `StartupWindow` vtable, forces [UID:0000SW][g_useEpfAssets](by-global/g_useEpfAssets.md), stores the startup `HINSTANCE`, and clears the asset-loaded/result flags.
- `RunUpdateCheck`: registers `BaramNoticeWnd_Class`, creates a centered 500 by 430 notice window, embeds a `BrowserWindow` at `http://www.nexustk.com/news/news.asp`, reads `HKCU\Software\KRU\NexusTK\updvr`, fetches `https://s3.amazonaws.com/kru-downloads/tk/update/nexustk.ver`, parses `version` and `minimap`, optionally fetches `https://s3.amazonaws.com/kru-downloads/tk/minimaps/HashList.txt`, and returns the update/continue decision after the message loop or auto-update decision.
- `UpdateCheckWindowProc`: handles keyboard accept/cancel, first-paint PCX loading/drawing, mouse hit-test state transitions, cursor updates, the top web-link rectangle, and `WM_USER + 11` result posting for update/close.
- String helpers: `0x00581e40` implements find-from-offset on the response buffer; `0x00581f50` extracts a bounded ANSI substring; `0x00581cf0` converts an ANSI range into a UTF-16 small string.
- Destructor: releases the browser/notice images when initialized, clears `dword_69BAC8`, and optionally frees the object.
