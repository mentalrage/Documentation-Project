## Behavior And Ownership

This aggregate covers the server-provided and client-side item action menu dialogs. The server path parses packet-provided action rows and serializes the selected row through opcode `0x39`. The client path builds local item actions from inventory/context state and sends the selected action through the same dialog-family packet shell.

Keep this aggregate with [UID:0000KF][ItemMenuDialogs](by-file/ItemMenuDialogs.md), not with the generic item-dialog pages. The code is modal item-menu UI: it constructs dialog controls, owns server/client row-list widgets, references the merchant/menu dialog vtable family, and is constructed by [UID:000238][0x00517450-0x00517d23.MenuDialogFactoryHelpers](by-memory/0x00517450-0x00517d23.MenuDialogFactoryHelpers.md) for item-menu packet subtypes.

The current aggregate stops before [UID:0001BQ][0x0051c470-0x0051ca3c.ClientItemMenuItemList](by-memory/0x0051c470-0x0051ca3c.ClientItemMenuItemList.md) because that client row-list island already has an exact page and begins after the `0x0051c46d-0x0051c470` padding. The server row-list island remains inside this aggregate and is also split to [UID:0001BP][0x0051ae90-0x0051b87a.ServerItemMenuItemList](by-memory/0x0051ae90-0x0051b87a.ServerItemMenuItemList.md) for detailed raw-helper evidence.
