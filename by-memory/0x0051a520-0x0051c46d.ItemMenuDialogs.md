## Behavior And Ownership

This aggregate covers the server-provided and client-side item action menu dialogs. The server path parses packet-provided action rows and serializes the selected row through opcode `0x39`. The client path builds local item actions from inventory/context state and sends the selected action through the same dialog-family packet shell.

For the client-side path, B006 resolves the local inventory lookup dependency as [UID:0003U9][0x005a3870-0x005a3889.UserPaneGetInventorySlotAddress](by-memory/0x005a3870-0x005a3889.UserPaneGetInventorySlotAddress.md). Client item menu rows resolve local inventory slot records, not a standalone item metadata table. Keep server menu action bytes and row `actionId` semantics separate from the local inventory slot selector; do not globally rename server-provided menu action fields to inventory slots.

Keep this source family with [UID:0000KF][ItemMenuDialogs](by-file/ItemMenuDialogs.md), not with the generic item-dialog pages. The code is modal item-menu UI: it constructs dialog controls, owns server/client row-list widgets, references dedicated item-menu vtables, and is constructed by [UID:000238][0x00517450-0x00517d23.MenuDialogFactoryHelpers](by-memory/0x00517450-0x00517d23.MenuDialogFactoryHelpers.md) for item-menu packet subtypes `4` and `5`.
