## Source-Structure Decision

Do not reconstruct these as handwritten cleanup functions. They are `atexit` wrappers for static `PoolAllocator` objects. Source reconstruction should express the concrete static pools and their normal destructor behavior.

The wrapper strip remains `CANONICAL_OWNER:NONE` and non-emitting because it spans object-pane, `Motion`, and string-buffer pool owners. [UID:0000MM][PoolAllocator](by-file/PoolAllocator.md) owns allocator mechanics, while exact static storage children and consuming class/file docs own the source-level declarations.

All D01-D18 rows remain `RECONSTRUCTABLE:FALSE` with blank CPP/H. Score remains `86/91`; source is the owning static declaration, not a handwritten cleanup function.
