## Behavior

This method starts or finalizes an FPS diagnostics logging session. The start path initializes timing/statistics fields, optionally creates a `FPSDATA-*.txt` file with a `***NEW_CLIENT***` marker, clears [UID:0000PY][g_fpsDebugActive](by-global/g_fpsDebugActive.md), shows the FPS pane, and schedules a one-second timer. The finalize path appends elapsed time, FPS min/max/average, object-count averages, hides the pane, and removes it from the update scheduler.
