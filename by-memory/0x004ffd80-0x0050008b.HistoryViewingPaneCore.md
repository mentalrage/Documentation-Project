## Behavior Summary

The constructor initializes the `Pane` base, writes [UID:0000R3][g_pHistoryViewingPane](by-global/g_pHistoryViewingPane.md), stores the requested EPF/EPD resource name, queries the EPF library for total frames, sets full-screen bounds against `g_pRootPane`, installs cursor management, and schedules the first update.

Input handlers advance the displayed frame/page or mark the pane for deletion after the last page. `OnDraw` asks `g_pEPFLib` for the current frame and renders it to the pane using `NPAL4.PAL`.
