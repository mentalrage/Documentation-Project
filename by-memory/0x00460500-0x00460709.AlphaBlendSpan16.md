## Behavior

This is an RGB565 row/span blend dispatcher. It splits each row into four-pixel blocks and a scalar tail. When `alpha32 == 16`, it uses the half-blend path: blocks go to [UID:0000YG][0x00460c10-0x00460c8c.HalfBlendSpan16Blocks](by-memory/0x00460c10-0x00460c8c.HalfBlendSpan16Blocks.md), and the scalar tail uses the RGB565 half-blend identity:

```text
((src >> 1) & 0x7bef) + ((dst >> 1) & 0x7bef) + (src & dst & 0x0821)
```

For other weights, it calls [UID:0000YF][0x00460b00-0x00460c0a.AlphaBlendSpan16Blocks](by-memory/0x00460b00-0x00460c0a.AlphaBlendSpan16Blocks.md) with source-side weight `32 - alpha32`, then handles the scalar tail with RGB565 channel masks `0xf81f` and `0x07e0`, shifts weighted sums by 5, and writes the blended destination word.

Source and destination row pointers advance by caller-supplied byte pitches.
