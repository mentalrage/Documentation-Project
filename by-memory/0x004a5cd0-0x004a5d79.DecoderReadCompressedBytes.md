## Behavior


After the call, it advances cursor `+0x0c` by the compressed length. If the produced size exceeds the original output capacity, or if any input bounds check fails, it clears valid flag `+0x11`. On success it optionally stores the produced size through `[ebp+0x10]`.

The body does not visibly branch on the zlib return value; the documented success/failure gate in this raw code is the output-size check plus input availability.
