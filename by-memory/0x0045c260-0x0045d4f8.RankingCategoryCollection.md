## Purpose

This range implements the ranking category/event collection embedded in `RankingDialog`. The source-authored methods parse ranking opcode `0x7d` response packets, maintain the selected category id, expose indexed/selected record lookups, and populate each category record's user-entry vector. The tail of this range contains project-specific vector support for 688-byte `RankingCategoryRecord` entries and 76-byte user-row entries.

## Layout Facts

- The collection object is used at `RankingDialog + 0x26c`.
- IDA access patterns show three vector pointers at collection offsets `+0x00`, `+0x04`, and `+0x08`.
- `SetSelectedCategoryId` at `0x0045ce30` and `GetSelectedCategoryId` at `0x0045ce60` access the selected category id at collection offset `+0x0c`.
- The constructor at `0x0045c260` only zeroes the three vector pointers. It does not initialize `+0x0c`; current generated source that writes `selectedCategoryId = -1` inside this constructor is not supported by IDA disassembly.
- Category records are copied and indexed with stride `0x2b0` / 688 bytes.
- User-entry vectors are copied and indexed with stride `0x4c` / 76 bytes. The per-record user-entry vector begins at record offset `+0x258` / 600 bytes.
