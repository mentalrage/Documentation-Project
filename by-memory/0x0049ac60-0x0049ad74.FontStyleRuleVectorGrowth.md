# 0x0049ac60-0x0049ad74 FontStyle Rule Vector Growth

## Status

- Confidence: strong for compiler/vector-support behavior.
- Source reconstruction status: ignore as handwritten product source; regenerate from normal container append code.
- Caller owner: [UID:00005C][FontStyle](by-class/FontStyle.md)
- Likely source file: [UID:0000JI][FontStyle](by-file/FontStyle.md)
- IDA function: `sub_49AC60`, size `0x114`

## Function Role

This helper is the slow path used when `FontStyle::Configure` appends a 16-byte rule record and the rule vector has no spare capacity.

IDA decompilation shows a vector insert/growth routine over 16-byte records:

- compute current count and capacity from the vector triplet;
- reject growth beyond `0x0fffffff` records;
- allocate a larger backing range through `0x0049ba30`;
- copy the inserted 16-byte record as one `OWORD`;
- move/copy existing records around the insertion point;
- free the old allocation with the same large-allocation validation pattern used by MSVC containers;
- update begin, end, and capacity pointers.
