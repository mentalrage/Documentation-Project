## Behavior

This helper plays the optional loose startup-logo Bink payload selected by [UID:0000SW][g_useEpfAssets](by-global/g_useEpfAssets.md):

1. Stores the current client window handle in the startup-logo Bink global state.
2. Constructs a stack `StdioFile` helper.
3. Chooses UTF-16 `LOGO.PAK` when [UID:0000SW][g_useEpfAssets](by-global/g_useEpfAssets.md) / historical `byte_66DA97` is `1`; otherwise chooses UTF-16 `LOGO.PAD`.
4. Probes the chosen path through the shared path-exists wrapper and returns through local cleanup when the media file is absent.
5. Opens the chosen file, constructs a stack `_AUTOBUF<unsigned char>`, and reads the remaining file payload into the buffer.
6. Treats the first payload dword as the first Bink segment size; the first Bink stream begins at `buffer + 4`.
7. Stores `buffer + 4 + firstSegmentSize` as `g_startupLogoBinkNextSegment` and `payloadSize - firstSegmentSize - 4` as remaining payload-length storage. [UID:00022U][0x004f5ae0-0x004f5b1e.TryAdvanceStartupLogoBinkSegment](by-memory/0x004f5ae0-0x004f5b1e.TryAdvanceStartupLogoBinkSegment.md) consumes only the next-segment pointer.
8. Queries the current sound backend through the existing audio object path and, when present, calls `BinkSetSoundSystem(BinkOpenMiles, soundSystem)`.
9. Opens the first stream with `BinkOpen(buffer + 4, 0x04080000)`; `0x04080000` is 67633152 (Verified with int_convert.py).
10. Opens a Bink buffer for the stored window and the active stream dimensions.
11. On `BinkBufferOpen` failure, shows `Bink Error`, closes the Bink stream, frees the payload buffer, and destroys local helpers.
12. On success, installs the temporary startup-logo window procedure at `0x004f59d0` with `SetWindowLongA(..., GWL_WNDPROC, ...)`, sets the playback-loop flag, pumps messages, and renders frames until the stream reaches the final frame or the loop flag is cleared.
13. Restores the previous window procedure, closes the active Bink stream, deletes the optional teardown callback object at `0x0069b470` through compiler-lowered deleting-dtor slot semantics with flag `1`, frees the `_AUTOBUF` payload, and destroys the stack `StdioFile`.
