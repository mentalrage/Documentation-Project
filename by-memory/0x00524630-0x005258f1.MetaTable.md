## Behavior Summary

`MetaTable` stores one metadata table's compressed payload and decoded lookup tree. `MetaMan` creates tables from `Meta.dat` and from server packet payloads. `MetaTable::DecompressAndValidateData` validates payloads before lookup, while the provisional [UID:0001CC][0x00524870-0x00524c54.MetaTableMaterializeRows](by-memory/0x00524870-0x00524c54.MetaTableMaterializeRows.md) turns decoded bytes into [UID:0001V7][MetaTableRowNode](by-type/by-struct/MetaTableRowNode.md) records.

The destructor and `ResetData` both use `DestroyMetaTableTreeNodes_5258B0` to free tree nodes and row value storage.
