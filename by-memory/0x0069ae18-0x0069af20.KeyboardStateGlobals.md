## Behavior

The application/event-dispatch code snapshots Win32 keyboard state into `KeyState`, watches the low bit of `KeyState[0x91]`, and uses `dword_69AF18` / `dword_69AF1C` while handling keyboard shortcuts and dispatch-side input state.

At source level this is reconstructable as a 256-byte keyboard-state snapshot plus two companion dispatch/cache fields. Do not lock final names until the owner module and the meaning of `dword_69AF1C` are confirmed from its non-keyboard consumers.
