## Function

IDA models this function as `sub_517D80`, size `0x13f`, ending at `0x00517ebf`. Current generated `source-3/simroot_v2/class_MerchantDialogPane.cpp` still omits it and emits only the raw constructor-shaped body at `0x00517d30`.

The function is a shared vtable virtual for merchant/NPC menu row action strings:

- It reads the candidate action string pointer from argument object offset `+0x0c`.
- A string beginning with `/` is accepted immediately and returns `1`.
- A string not beginning with ASCII `0` is rejected and returns `0`.
- For a `0...` encoded action string, it extracts an action byte, a 32-bit value, skips through a variable text segment, reads two 16-bit values, and packs a 10-byte outbound payload.
- The outbound payload begins with encoded `':'`, then the action byte, a 4-byte encoded value, and two encoded 16-bit values. The local buffer is null-terminated after the 10 sent bytes.
- The function sends the 10-byte payload through the shared packet sender at [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) via helper `0x00574bb0`, then returns `1`.
