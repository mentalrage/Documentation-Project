## Behavior

This method handles `AddMixingItemDialog` confirm/cancel actions.

Observed action split:

- Action code `1`: process selected picker rows.
- Action code `2`: dismiss/close the dialog without adding rows.

For action code `1`, the method:

1. Fetches the selected row storage from child selector `3`.
2. Copies up to 256 selected row handles/entries through the list selection helper.
3. Iterates the selected rows and resolves the selected local inventory slot through `dword_67A748` / [UID:0003U9][0x005a3870-0x005a3889.UserPaneGetInventorySlotAddress](by-memory/0x005a3870-0x005a3889.UserPaneGetInventorySlotAddress.md) using the row payload inventory slot byte.
4. When the slot record indicates stackable/quantity handling and multiple rows are selected, calls the owner `MixItemDialog` add-item callback directly through `0x004afe40`.
5. Otherwise reads item id, item number, style/category byte, and wide display name from the selected row payload.
6. Fetches the parent mix-list storage from the owner dialog child selector `5`.
7. If the item metadata maximum quantity at offset `+0x1e8` is `<= 1`, builds a row payload with quantity `1`, copies the selected display text, and appends it to the parent mix list through `0x004f3c50`.
8. If the maximum quantity is greater than `1`, allocates a 24-byte double-parameter member-function callback object for `MixItemDialog::AddItem`, then constructs a `NumberInputDialog` at `0x00530640` with resource string id `218` and the item maximum quantity.
9. After each processed selection, calls the shared close/dismiss helpers at `0x0049eb90` and `0x0049dad0`.

For action code `2`, the method only calls the same close/dismiss helpers.
