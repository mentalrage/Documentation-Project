## Behavior

This method draws the living object in the map pane. It reads the pane's current standing/elevation value, sprite-state block, animation direction/frame, color/effect state, marker fields, and the active map/render mode. It dispatches through the human-image render path for player/human-style objects and through the monster/object image path for non-human sprites.

After the main sprite draw, the method optionally draws selection or overlay markers. The marker path consults `dword_67A764` map state and [UID:0003CC][0x00620c10-0x00620c64.ObjectOverlayFrameIndexTables](by-memory/0x00620c10-0x00620c64.ObjectOverlayFrameIndexTables.md) overlay rows, selects a four-piece frame/color set from the current marker index and map overlay mode, disables the render-port draw/blit mode byte at `GrafPort+0x70`, then emits four `GrafPort::DrawRectFrame` passes around the sprite with `RectBounds::Inset(1, 1)` between the later passes.

Historical correction: older wording placed the overlay table near `0x00620b90`. B001's 2026-06-26 MCP rework proved `0x00620b90` is UTF-16 `BGAUGE.EPF` / `BGAUGE.pal`, not the marker table. The actual rows consumed here are `0x00620c10`, `0x00620c2c`, and `0x00620c48`; decimal immediate bases `6425616`, `6425644`, and `6425672` convert to `0x620c10`, `0x620c2c`, and `0x620c48` respectively (Verified with int_convert.py). IDA reports no direct data xrefs to those row bases because the decompiler exposes them as immediate base constants; [UID:0003CC][0x00620c10-0x00620c64.ObjectOverlayFrameIndexTables](by-memory/0x00620c10-0x00620c64.ObjectOverlayFrameIndexTables.md) remains the table owner and this method is a consumer.
