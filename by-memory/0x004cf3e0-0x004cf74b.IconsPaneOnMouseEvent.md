## Behavior

This mouse handler manages icon-strip capture, pressed state, hover tooltips, and click actions.

| Event type | Behavior |
| --- | --- |
| `0` | drag/move while captured; updates pressed/highlight state |
| `1` | mouse down/capture over an icon |
| `3` | mouse up; dispatches the selected icon action when input is not locked |
| `4` | hover tooltip; localized tooltip ids are `202..209` |

Click action dispatch is skipped if the input-lock byte at `dword_67A764 + 1008` is set.
