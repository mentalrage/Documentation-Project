## Behavior

This mouse handler manages icon-strip capture, pressed state, hover tooltips, and click actions.

| Event type | Behavior |
| --- | --- |
| `0` | drag/move while captured; updates pressed/highlight state |
| `1` | mouse down/capture over an icon |
| `3` | mouse up; dispatches the selected icon action when input is not locked |
| `4` | hover tooltip; localized tooltip ids are `202..209` |

Click action dispatch is skipped if the input-lock byte at [UID:0000PR][g_activeMapPane](by-global/g_activeMapPane.md) / `dword_67A764 + 0x3f0` is set. `0x3f0` is decimal `1008` (Verified with int_convert.py). ## Event Flow

| Event type | Live IDA behavior |
| --- | --- |
| `0` | If the pane has capture, hit-tests the current cursor position and sets highlight on only when the hit icon still equals the stored selected index. |
| `1` | Bounds-checks the cursor against the pane rectangle, hit-tests the icon strip, stores the selected icon index at `+0xfc`, captures input, and highlights the selected icon. |
| `3` | If captured, hit-tests again; when the released icon equals the stored selected index and the input-lock byte is clear, dispatches the selected action, clears highlight, resets `+0xfc` to `-1`, and releases capture. |
