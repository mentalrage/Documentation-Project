# 0x004652e0-0x004652fc Application CopyProcessorName

## Scope

- Entity kind: class method / accessor-copy helper

## Behavior

Copies the Application processor-name wide-character buffer addressed at `Application + 0x428` into a caller-supplied wide-character buffer through `wcscpy_s`.

This is the copy-side accessor for the processor-name state populated by [UID:0002JW][0x00465130-0x004651b8.ApplicationReadProcessorName](by-memory/0x00465130-0x004651b8.ApplicationReadProcessorName.md). The exact layout relationship between the broader processor-name owner documented at `Application + 0x1c` and this concrete copy source at `Application + 0x428` still needs a final `Application` layout reconciliation.
