## Behavior

`InitializeOleSupport` is a static initializer-table entry. It calls `OleInitialize(0)` during process startup and registers the paired OLE teardown thunk with `atexit`.

The registered shutdown thunk at `0x0060c0f0` writes the anonymous-namespace `AutoInit` vtable pointer into the static object slot at `off_66D42C`, then jumps to `OleUninitialize`. The vtable is documented separately at [UID:0001X0][AutoInitVtable](by-type/by-vtable/AutoInitVtable.md).

This is the missing initialization-side evidence for [UID:00000Q][AutoInit](by-class/AutoInit.md). The active class method at `0x00470300` is the scalar deleting destructor for the same small OLE lifetime helper, while `0x0060c0f0` is the static-object shutdown path used by `atexit`.
