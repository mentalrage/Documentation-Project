# 0x004b9820-0x004ba24a Surface Paint Helpers

## Status

- Confidence: medium-strong for a shared surface/paint helper cluster; exact original source split is still open.
- Likely source file: [UID:0000OC][Surface](by-file/Surface.md), with some helpers possibly belonging to [UID:0000JR][GrafPort](by-file/GrafPort.md) or pane subclasses after a layout pass.
- Current Wave3 owners are scattered across `FolderTreePane`, `RankingUserListPane`, `MapPane`, and `FittingRoomDownloadControlPane`.

## Evidence Notes

- IDA MCP confirms the exact function extents in this range.
- 2026-06-01 IDA MCP `lookup_funcs` reconfirms `0x004b9820` size `0x98`, `0x004b98c0` size `0x2e`, `0x004b98f0` size `0x1c`, `0x004b9910` size `0x6e`, `0x004b9980` size `0x31`, `0x004b99f0` size `0x73`, and `0x004b9a70` size `0x7da`. The final large helper ends at `0x004ba24a` exclusive, and `0x004ba250` begins [UID:000167][0x004ba250-0x004ba444.SurfaceSpriteBlitHelper](by-memory/0x004ba250-0x004ba444.SurfaceSpriteBlitHelper.md).
- 2026-06-01 IDA MCP `callers` reports broad shared use for `UpdateSurfaceInfo`, `EndPaint`, `LineTo`, and `RenderTileFrame`; `UpdateSurfaceInfo` callers include surface blit helper `0x004ba250`, visible-tile redraw `0x005051c0`, presentation `0x00557140`, screenshot paths, tile drawing, and pane/render paths.
- 2026-06-01 IDA MCP `callees` confirms the small line/sprite/tile wrappers dispatch through shared callbacks and helper routines, while the large scroll/copy function calls rectangle initialization, region dirtying, memory copy/clear helpers, and security-cookie support.
- 2026-06-01 IDA MCP `decompile` confirms `UpdateSurfaceInfo`/`EndPaint` as paint lifecycle helpers, `LineTo` as a global line-delta callback wrapper, `DrawSprite` and `RenderTileFrame` as render callback wrappers, `ForwardToTileFrameBlitHelper` as the nested offset-rectangle forwarding helper, and `ScrollPixelBuffer` as a long 16-bit buffer scroll/copy/clear routine that emits dirty rectangles.
- Wave3 imports the named helpers with good manual grades, but owner names appear caller-biased.
- `UpdateSurfaceInfo` has 28 direct IDA callers across unrelated pane/render paths, making a narrow `FolderTreePane` source-file owner unlikely.
- IDA MCP decompilation of `0x004b99f0` shows a compact forwarding helper: it initializes a temp rectangle from caller x/y offsets plus fields at `a3 + 0x10..0x1c`, then calls `dword_69B3E8`.
