# 0x0061e5b4-0x0061e704 MapName/MiniMap Button Read-Only Data

## Range

- Address range: `0x0061e5b4-0x0061e704`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and map UI resource literals must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains the generated vtable islands for `MapNamePane` and
`MiniMapButtonPane`, followed by nearby map/minimap resource strings and the
RTTI complete-object-locator dword immediately before the next protected-array
vtable. The page is intentionally parentless because the physical range crosses
two source-owner candidates: map-name pane code and minimap-button code. It ends
cleanly before the `ProtectedArray<GameServerConfig::NationEntry>` vtable at
`0x0061e704`, while the protected-array COL dword at `0x0061e700` remains a
boundary artifact inside this physical range.

The vtables are reconstructable through source class declarations and virtual
method definitions rather than hand-authored data. The short literals remain
source literals, but exact ownership between `MapNamePane`, `MiniMapButtonPane`,
and a higher-level map UI resource owner is still unresolved.
