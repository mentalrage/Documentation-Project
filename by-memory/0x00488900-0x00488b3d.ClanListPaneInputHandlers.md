## Behavior

This range completes the list-pane virtual handler island between [UID:00010I][0x00488610-0x004888f0.ClanListPaneVirtuals](by-memory/0x00488610-0x004888f0.ClanListPaneVirtuals.md) and [UID:00010J][0x00488b40-0x00488fa0.ClanNameInputDialogCore](by-memory/0x00488b40-0x00488fa0.ClanNameInputDialogCore.md). The previous documented range ended with `ClanJoinListPane`'s simple selected-row action at `0x004888d0`; this page covers the adjacent event/action handlers that IDA places in `ClanJoinListPane` and `ClanEnlistListPane` vtables.

`sub_488900` first delegates to the inherited list-pane event handler at `0x004f4300`. If the base handler consumes the event, it returns `true`. Otherwise it narrows the event key through `std::ctype<char>::do_narrow`, checks `this + 0x134` for a valid selected row, obtains the selected row text through `0x004f3dc0`, and sends the join-list selection packet via [UID:00021G][0x00485590-0x00485682.SendClanJoinListSelectionPacket](by-memory/0x00485590-0x00485682.SendClanJoinListSelectionPacket.md) only when the key is Enter (`0x0d`).

`sub_488970` is a small selected-row action for `ClanEnlistListPane`. It reads the selected row index at `this + 0x134`, resolves the row text with `0x004f3dc0`, and calls [UID:00021K][0x00485960-0x00485abe.ClanSubtype6PacketHelpers](by-memory/0x00485960-0x00485abe.ClanSubtype6PacketHelpers.md) helper `0x004859d0`, which sends opcode `0x4b`, subtype `6`, action `1` with a length-prefixed selected name.

`sub_4889A0` is the larger enlist-list event handler. It follows the same base-handler and selected-row pattern as `sub_488900`. Enter sends the selected row through helper `0x004859d0`. Key code `0x84` builds an inline packet header `{ 0x4b, 6, 3 }`, converts the selected wide row text to a multibyte buffer, appends length and payload, sends the packet through `sub_574bb0(dword_67A7EC, ...)`, and then calls helper `0x00485960`, the subtype `6`, action `0` refresh/open request.

bool ClanJoinListPane::OnEvent(const UIEvent& event) {
    if (ListPane::OnEvent(event)) {
        return true;
    }

    char key = narrowEventKey(event);
    if (m_selectedIndex < 0) {
        return false;
    }
