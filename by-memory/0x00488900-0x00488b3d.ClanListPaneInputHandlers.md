## Behavior

This range completes the list-pane virtual handler island between [UID:00010I][0x00488610-0x004888f1.ClanListPaneVirtuals](by-memory/0x00488610-0x004888f1.ClanListPaneVirtuals.md) and [UID:00010J][0x00488b40-0x00488fa0.ClanNameInputDialogCore](by-memory/0x00488b40-0x00488fa0.ClanNameInputDialogCore.md). The previous documented range ended with `ClanJoinListPane`'s simple selected-row action at `0x004888d0`; this page covers the adjacent event/action handlers that IDA places in `ClanJoinListPane` and `ClanEnlistListPane` vtables.

The `0x00488900` handler first delegates to the inherited list-pane event handler at `0x004f4300`. If the base handler consumes the event, it returns `true`. Otherwise it narrows the event key through `std::ctype<char>::do_narrow`, checks object offset `+0x134` for a valid selected row, obtains the selected row text through `0x004f3dc0`, and sends the join-list selection packet via [UID:00021G][0x00485590-0x00485682.SendClanJoinListSelectionPacket](by-memory/0x00485590-0x00485682.SendClanJoinListSelectionPacket.md) only when the key is Enter (`0x0d`).

The `0x00488970` helper is a small selected-row action for `ClanEnlistListPane`. It reads the selected row index at object offset `+0x134`, resolves the row text with `0x004f3dc0`, and calls [UID:00021K][0x00485960-0x00485abe.ClanSubtype6PacketHelpers](by-memory/0x00485960-0x00485abe.ClanSubtype6PacketHelpers.md) helper `0x004859d0`, which sends opcode `0x4b`, subtype `6`, action `1` with a length-prefixed selected name.

The `0x004889a0` handler is the larger enlist-list event handler. It follows the same base-handler and selected-row pattern as `0x00488900`. Enter sends the selected row through helper `0x004859d0`. Key code `0x84` builds an inline packet header `{ 0x4b, 6, 3 }`, converts the selected wide row text to a multibyte buffer, appends length and payload, sends the packet through [UID:0001HU][0x00574bb0-0x00574c13.QueueAndSendPacket](by-memory/0x00574bb0-0x00574c13.QueueAndSendPacket.md) using [UID:0001P0][0x0067a7ec-0x0067a7f0.g_packetSender](by-memory/0x0067a7ec-0x0067a7f0.g_packetSender.md), and then calls helper `0x00485960`, the subtype `6`, action `0` refresh/open request.

The event handlers load [UID:0002B5][0x0067adc4-0x0067adec.UiChatClanSingletonSlots](by-memory/0x0067adc4-0x0067adec.UiChatClanSingletonSlots.md) slot `0x0067ade4` before calling the Clan packet helpers. The shared list behavior comes from [UID:000194][0x004f3a50-0x004f4a77.ListPane](by-memory/0x004f3a50-0x004f4a77.ListPane.md): selected-row index at object offset `+0x134`, selected-entry retrieval at `0x004f3dc0`, and base key/event handling at `0x004f4300`.

The inline action `3` packet writes a zero byte after the copied payload, but the queued length is `convertedLength + 4`, so the terminator byte is stack-buffer padding rather than part of the sent packet.
