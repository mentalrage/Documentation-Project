## Ownership Decision

This is the core bulletin-board dialog cluster. It should migrate as a board/article dialog module under `ui/dialogs/`, with `WebBoardDialog` cross-referenced as a browser-backed board variant.

The exact source root remains intentionally unresolved. [UID:0000HT][BoardDialogs](by-file/BoardDialogs.md) currently lists several plausible final files, including `BoardDialogs.cpp`, `ArticleDialogs.cpp`, `BulletinSession.cpp`, `WebBoardDialog.cpp`, and `NewPredefinedFormArticleDialog.cpp`; its `PROPOSED_RECONSTRUCTION_PATH` is blank for that reason.
