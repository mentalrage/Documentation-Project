# DATFile Scalar Deleting Destructor

## Disposition

`[0x0049d280,0x0049d2cc)` is the compiler-generated scalar deleting wrapper selected by DATFile's vtable. It invokes ordinary destruction and conditionally frees the 0x14-byte object according to the hidden delete flag.

## No-Code Proof

The human source is the virtual `DATFile::~DATFile()` declaration and exact ordinary destructor body. Explicit vtable writes, hidden delete flags, and operator-delete dispatch are MSVC lowering, not a separate source method. The exact four-byte `0xcc` boundary `[0x0049d2cc,0x0049d2d0)` separates the next class wrapper.
