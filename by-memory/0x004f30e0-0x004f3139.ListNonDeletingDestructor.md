## Behavior

This function tears down a [UID:000079][List](by-class/List.md) object without handling delete flags. It restores the `List` vtable, frees the backing buffer through the memory manager/free helper, stores zero back into the buffer field, and destroys the `LObject` base.

It is called by [UID:00000W][BlackHole](by-class/BlackHole.md) destructors, but it is not unique BlackHole behavior.

2026-06-19 B008 source-quality reanalysis pairs this body directly with [UID:000191][0x004f3060-0x004f30d5.ListConstructor](by-memory/0x004f3060-0x004f30d5.ListConstructor.md). 2026-06-26 B011 reanalysis resolves the remaining C++ blocker: in source terms this is ordinary `List::~List()`.
