## Behavior Notes

- The constructor builds the `DLGNC` account/password form and configures a result callback, request-pending flag, status-alert pointer, and modal input behavior.
- Submit reads account/password controls `2` and `3`, sends a registration request through [UID:00008I][MiscWorkThread](by-class/MiscWorkThread.md), marks the request pending at primary object offset `+0x270`, opens a pending alert at `+0x274`, and starts a 30-second timer.
- Cancel invokes the result handler stored at primary object offset `+0x26c` with an empty value and closes the dialog.
- The web command opens `http://www.nexon.com/KR/Page/NX.aspx?URL=Login/Register`.
- The response handler accepts only `NCAu` (`0x4e634175`) packets while the pending byte is set, clears timer/alert state, then routes result state `0` through the success callback and states `1..5` to localized message ids `228..232`.
