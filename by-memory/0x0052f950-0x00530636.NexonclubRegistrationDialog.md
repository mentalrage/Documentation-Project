## Behavior Notes

- The constructor builds the `DLGNC` account/password form and configures a result callback, request-pending flag, status-alert pointer, and modal input behavior.
- Submit reads account/password controls, sends a registration request through [UID:00008I][MiscWorkThread](by-class/MiscWorkThread.md), marks the request pending, opens a pending alert, and starts a 30-second timer.
- Cancel invokes the result handler with an empty value and closes the dialog.
- The web command opens `http://www.nexon.com/KR/Page/NX.aspx?URL=Login/Register`.
- The response handler checks pending state and server result codes, then either returns the account text through the callback or shows localized status alerts.
