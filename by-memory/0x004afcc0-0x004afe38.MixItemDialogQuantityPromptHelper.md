## Behavior

The helper adds a selected item to the owning `MixItemDialog` selection list. It fetches the owner mix-list pane through child selector `5`, looks up item metadata through `g_pCollectionData` / historical `dword_67A748`, and chooses between direct insertion and a quantity prompt. Non-stackable items are copied directly into the mix list with count `1`; stackable items allocate a double-parameter callback object and construct a `NumberInputDialog` so the user can choose a quantity up to the item's maximum stack count.
