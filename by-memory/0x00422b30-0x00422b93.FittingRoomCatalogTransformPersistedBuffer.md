## Behavior

This helper applies the reversible transform used for the local `ItemShop.jbn` cache. For each byte in the buffer, it computes the byte index modulo the encode-key length, XORs the byte with the encode key, then XORs the result with the decode key at the same key index.

The constructor initializes the two key strings as:

- `CASHEncodeDecodeByChris`
- `sirhCyBedoceDedocnEHSAC`

The transform is symmetric because it applies the same two XOR key streams in the same order. Calling it on encoded bytes decodes them, and calling it on decoded bytes encodes them again.
