# 0x004657d0-0x00467406 Password Guard And Fatal Error

## Status

- Disposition: reconstructable NexusTK project code
- Entity kind: password-protection helpers, fatal dialog helper, and `PasswordError` constructor/vtable helpers
- Current Wave3 owners: [UID:0000MG][PasswordGuard](by-file/PasswordGuard.md), [UID:0000A8][PasswordError](by-class/PasswordError.md), and recovered global helpers
- Likely source modules: [UID:0000MG][PasswordGuard](by-file/PasswordGuard.md), [UID:0000J5][Error](by-file/Error.md), and possibly `app/FatalError.cpp`
- Confidence: strong for function behavior, medium for final source split.

## Covered Range

| Range | Current symbol | Notes |
| --- | --- | --- |
| `0x004657d0-0x00465827` | `SetProtectedPasswordToken` | Copies the active password into a 32-wide-char global buffer and XOR-obfuscates it with an incrementing seed loaded from `word_66D410`. |
| `0x00465890-0x00465ae2` | `ValidateChatInputOrThrowPasswordError` | Decodes the token using the same `word_66D410` seed, searches outbound input, loads `PASS_ENG.STR`, and throws `PasswordError` on a match. |
| `0x00465cb0-0x00465ce0` | `FatalError` | Shows owner-window `Error` message box, posts quit, and deliberately breaks execution. |
| `0x00467160-0x00467181` | `PasswordError::PasswordError` | Calls `MyError` constructor and installs `PasswordError` vtable. |
| `0x00467300-0x00467338` | `PasswordError::ScalarDeletingDestructor` | Destroys `MyError` base and optionally frees `this`. |
| `0x00467400-0x00467406` | `PasswordError::GetErrorDescriptor` | Returns descriptor data at `0x006125bc`; generated output currently mislabels this as a vtable-pointer return. |

## Evidence

- Wave3 global summaries identify the password token cache and outbound text validator behavior.
- Generated source shows `PASS_ENG.STR`, `DATFile::Open`, `DATFile::ReadLineRaw`, `MultiByteToWideChar`, and `throw new PasswordError(message)`.
- IDA MCP confirms all ranges in the table as real functions.
- IDA caller evidence for `ValidateChatInputOrThrowPasswordError` includes many text input submitters, consistent with a shared guard used by chat/social commands.
- IDA resolves `PasswordError::vftable` to `0x006125a8`; the `0x00467400` helper returns the adjacent descriptor pointer at `0x006125bc`, not the vtable itself.
- IDA MCP xrefs show the password guard seed at [UID:000275][0x0066d408-0x0066d414.DisplayStartupAndPasswordGuardGlobals](by-memory/0x0066d408-0x0066d414.DisplayStartupAndPasswordGuardGlobals.md): `SetProtectedPasswordToken` loads `word_66D410` at `0x004657e5`, and `ValidateChatInputOrThrowPasswordError` loads it at `0x004658d2`.
- IDA decompilation shows both token transform loops apply `*p++ = seed++ ^ ch`, confirming `word_66D410 = 0xd544` is the initial XOR seed.

## Ownership Decision

Use `PasswordGuard.cpp` for the password-token globals and validation helper. Keep the `PasswordError` class in [UID:0000J5][Error](by-file/Error.md), because the rest of its implementation and base hierarchy are in the `0x004a67a0+` error wrapper cluster.

Treat `FatalError` as an app/error helper until caller review decides whether it belongs in `app/Application.cpp`, `util/Error.cpp`, or a tiny fatal-dialog source.

## Open Questions

- Identify all callers of `SetProtectedPasswordToken`.
- Decide the final source name for the seed currently stored at `word_66D410`; `g_passwordProtectSeed` is descriptive but not yet original-name evidence.
- Decide whether `FatalError` is app-owned or utility-owned.
- Determine whether the password guard was originally named after chat input, login/session protection, or password privacy.
