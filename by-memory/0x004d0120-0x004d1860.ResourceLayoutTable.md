## Behavior Summary

`LoadResourceIndex` constructs a `DATFile`, opens the requested resource name, reads an 8-byte header and a 4-byte record-table offset, then seeks to that table. Each raw entry is read as top, left, bottom, right, pixel offset, and encoded-mask offset. The loader writes normalized `ResourceLayoutEntry` rows, makes the offsets absolute by adding `DATFile::GetDataBase() + 0xc`, appends a zero-bounds terminal entry whose offsets point to the table boundary, and appends a 44-byte `ResourceLayoutNameRecord` to the list.

`LookupLayoutEntry` is the central call target. If the resource is not already present, it loads it, obtains the bucket, and maps the requested row into an `EPFTileContext`. The encoded mask size is computed as `nextEntry.pixelData - currentEntry.encodedMaskData`, so the sentinel row is part of normal size calculation for the last real entry.
