## Behavior

This raw wrapper copies each ciphertext block into the destination, optionally rebuilds the AES-128 key schedule when a key pointer is supplied, decrypts the destination block through `0x00461c10`, then XORs the decrypted block with the current chaining block.

The chaining pointer is initialized from the supplied IV pointer when present, otherwise from the stored global at `0x0067a930`. After each block, the chaining pointer advances to the previous ciphertext block.

The tail path mirrors the encrypt wrapper: when `length & 0x0f` is nonzero, it copies a final partial block, zero-fills to 16 bytes, decrypts the block, and leaves the raw output block in place.
