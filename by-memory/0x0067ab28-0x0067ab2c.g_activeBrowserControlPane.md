# 0x0067ab28-0x0067ab2c g_activeBrowserControlPane

## Status

- Disposition: reconstructable active browser-control global pointer.
- Entity kind: active pane/control pointer.
- Proposed owner: [UID:0000HV][Browser](by-file/Browser.md) / [UID:000015][BrowserControlPane](by-class/BrowserControlPane.md), with application and surface/presentation consumers.
- Global doc: [UID:0000PO][g_activeBrowserControlPane](by-global/g_activeBrowserControlPane.md)
- Confidence: strong for address, size, and active browser-control role; medium for final exported name/source split.

## Storage

`0x0067ab28-0x0067ab2c` is the four-byte `.data` item IDA names `dword_67AB28`.

Generated browser output names the storage as `DAT_0067ab28` or `g_activeBrowserControlPane`. Browser code reads and writes it as an active `BrowserControlPane` slot. IDA xrefs also show application and presentation users, but decompilation shows those are consumers that coordinate accelerator handling, active-surface synchronization, and browser window redraw.

## Evidence

- IDA MCP `py_eval` reports the data item at `0x0067ab28` as `dword_67AB28`, size `4`, in `.data`.
- IDA reports 24 direct xrefs.
- Browser-neighborhood refs include `0x0046adc1`, `0x0046ae4a`, `0x0046b58d`, `0x0046b594`, `0x0046ba13`, `0x0046c575`, `0x0046d3e4`, `0x0046e964`, `0x00470210`, and `0x00470493`.
- Application/setup refs include `0x00464d7b`, `0x00464e67`, and `0x004660cd`; `0x0046c550` is reached from the message loop and uses `dword_67AB28 + 0x120` as the hosted browser active object for accelerator translation.
- Presentation and screenshot refs include `0x005571f6`, `0x005572b3`, `0x00557315`, `0x00557339`, `0x005579a5`, `0x00557cdb`, `0x0055801a`, `0x005584b4`, `0x00558571`, `0x005585dd`, and `0x00558601`; decompilation shows calls to `sub_46bfd0(dword_67AB28, surface)` and redraws through the hosted HWND at `dword_67AB28 + 0x11c`.

## Disposition

Treat this as the active `BrowserControlPane*` global. The declaration probably belongs with browser-control source, but it cannot be file-local if the reconstructed source keeps direct consumers in application and surface modules; use a browser header declaration or accessor in the rebuilt structure.
