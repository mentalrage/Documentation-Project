## Behavior

Both helpers are thin default-codepage conversion wrappers used by the ref-counted string family. They pass binary code page `0`, expressed in source as `CP_ACP`, and flags `0`, so conversion uses the process default ANSI code page rather than UTF-8 or a resource-specific code page. They are project-facing StringBase helpers, not import thunks: each has its own executable body, caller set, argument order, and source role.

`MultiByteToWideDefaultCp` (`0x005151b0`, historical IDA alias `sub_5151B0`) converts an ANSI/default-codepage byte range into a caller-supplied wide buffer:

```text
MultiByteToWideChar(CP_ACP, 0, sourceBytes, sourceByteCount, destinationWide, destinationCharCapacity)
```

`WideCharToMultiByteDefaultCp` (`0x005151d0`, historical IDA alias `sub_5151D0`) converts a UTF-16 range into a caller-supplied ANSI/default-codepage buffer:

```text
WideCharToMultiByte(CP_ACP, 0, sourceWide, sourceCharCount, destinationBytes, destinationByteCapacity, NULL, NULL)
```

Neither helper allocates, frees, touches globals, or adds validation; buffer sizing, terminators, and string-header length updates are handled by the `0x00582500+` callers.

## Signature Notes

- Source-facing signature for `0x005151b0`: `static int MultiByteToWideDefaultCp(wchar_t *dst, int dstCount, const char *src, int srcCount)`. IDA type equivalent: `int __cdecl MultiByteToWideDefaultCp(LPWSTR dst, int dstCount, LPCCH src, int srcCount)`.
- Source-facing signature for `0x005151d0`: `static int WideCharToMultiByteDefaultCp(char *dst, int dstCount, const wchar_t *src, int srcCount)`. IDA type equivalent: `int __cdecl WideCharToMultiByteDefaultCp(LPSTR dst, int dstCount, LPCWCH src, int srcCount)`.
- `dstCount` is the caller-provided destination capacity: wide-character capacity for `MultiByteToWideDefaultCp`, byte capacity for `WideCharToMultiByteDefaultCp`.
- `srcCount` is the caller-provided input length: byte count for ANSI/default-codepage input and UTF-16 code-unit count for wide input.
- The return value is the Win32 API conversion count forwarded directly to the caller. It is not a `bool`, `void`, HRESULT, allocation result, or terminator-inclusive size.
