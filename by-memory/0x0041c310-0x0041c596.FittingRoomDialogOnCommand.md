## Behavior

Handles fitting-room dialog command IDs. The method closes/removes the dialog for command `0`, rotates the preview image for commands `3` and `4`, resets or reapplies appearance state for commands `5` and `6`, selects fitting-room category/slot buttons for commands `7` through `16`, and refreshes the list pane after state-changing commands.
