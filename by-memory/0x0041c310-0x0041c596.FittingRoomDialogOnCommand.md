## Behavior

`FittingRoomDialog::OnCommand` handles the fitting-room dialog's close, preview rotation, appearance reset/current buttons, and category-button commands. Commands that change the active appearance or category share a common refresh path: the method gets child `2` from the child container at dialog offset `+0x1fc` and calls [UID:0002DI][0x0041f100-0x0041f219.FittingRoomListPaneResetScrollPosition](by-memory/0x0041f100-0x0041f219.FittingRoomListPaneResetScrollPosition.md) on that list pane.

The close path is a deferred pane-deletion request, not a direct dialog-manager destroy. Command `0` loads [UID:00028K][0x0067a74c-0x0067a750.g_pApplicationCleanupQueue](by-memory/0x0067a74c-0x0067a750.g_pApplicationCleanupQueue.md) and queues this dialog through [UID:0000Z1][0x00469180-0x004691fa.BlackHoleQueuePaneForDeferredDeletion](by-memory/0x00469180-0x004691fa.BlackHoleQueuePaneForDeferredDeletion.md).
