## Behavior

This helper copies a counted UTF-16 source buffer into the early `SimpleUString` SSO-7 layout. It behaves like an assignment or constructor helper over an already-initialized object:

- reads current capacity from `this + 0x14`;
- uses inline storage when capacity is below `8`, otherwise uses the heap pointer at `this + 0x00`;
- if the requested length fits, writes length, copies `length * 2` bytes, and writes a UTF-16 terminator;
- if the requested length exceeds capacity, grows capacity using `length | 7` plus a 1.5x growth check, capped at `0x7ffffffe`;
- allocates `(newCapacity + 1) * 2` bytes, with the same 32-byte aligned large-allocation scheme used elsewhere;
- frees the old heap buffer only when the previous capacity was `>= 8`.

void SimpleUString::Assign(const wchar_t* source, unsigned int length)
{
    unsigned int oldCapacity = m_capacity;
    wchar_t* oldStorage = oldCapacity >= 8 ? m_heapBuffer : m_inlineBuffer;

    if (length <= oldCapacity) {
        m_length = length;
        memmove(oldStorage, source, length * sizeof(wchar_t));
        oldStorage[length] = 0;
        return;
    }

    if (length > 0x7ffffffe) {
        ThrowStringTooLong();
    }

    unsigned int newCapacity = length | 7;
    unsigned int grown = oldCapacity + (oldCapacity >> 1);
    if (newCapacity < grown && oldCapacity <= 0x7ffffffe - (oldCapacity >> 1)) {
        newCapacity = grown;
    }
    if (newCapacity > 0x7ffffffe) {
        newCapacity = 0x7ffffffe;
    }

    wchar_t* newStorage = AllocateWideStringStorage(newCapacity + 1);
    m_capacity = newCapacity;
    m_length = length;
    memmove(newStorage, source, length * sizeof(wchar_t));
    newStorage[length] = 0;

    if (oldCapacity >= 8) {
        FreeWideStringStorage(oldStorage, oldCapacity + 1);
    }

    m_heapBuffer = newStorage;
}
