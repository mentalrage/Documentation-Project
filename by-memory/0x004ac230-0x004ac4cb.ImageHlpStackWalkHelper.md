## Behavior

This helper emits the symbol-aware call-stack section of `BCrash.nfo` after the report writer has resolved ImageHlp entry points. IDA decompilation shows it:

- prints the call-stack header when a file handle is available;
- initializes an x86 `STACKFRAME`-style local record from the exception `CONTEXT` EIP/ESP/EBP fields;
- calls the stored `StackWalk` function pointer with machine type `332` (`IMAGE_FILE_MACHINE_I386`);
- emits each address/frame pair;
- calls the stored `SymGetSymFromAddr` function pointer and prints `symbol+offset` when symbols resolve;
- falls back to [UID:00014I][0x004abfa0-0x004ac035.ExceptionLogicalAddressHelper](by-memory/0x004abfa0-0x004ac035.ExceptionLogicalAddressHelper.md) for module/logical-address text when symbols do not resolve;
- emits an extra executable-relative offset line when the resolved module matches the normalized client executable path.
