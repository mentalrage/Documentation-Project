## Behavior

`ApplyLegacyStatusPayload` applies the old bitflagged status payload and returns `false` to the router. Router case `8` at `0x005bdf24` returns this method result, and the target tail emits `xor al, al; retn 4`.

The payload parser is cursor-based. The initial cursor is `2`. When `flags & 0x40` is present, the full-status section reads nation at `packet+2`, raw spirit at `packet+4`, class at `packet+6`, full status-row dwords at `packet+7` and `packet+11`, compact attribute bytes at `packet+15`, `packet+16`, and `packet+19`, and two 16-bit tail words at `packet+26` and `packet+28`, then advances the cursor to `31`. The `0x20` section reads two dwords from the current cursor and advances it by eight bytes. The `0x10` section then reads two dwords from the current cursor.

Changed fields invalidate the matching status rectangles. The spirit path compares the raw packet spirit byte against the current field before clamping the stored value into `[-1, 3]`; a change invalidates the spirit rectangle and either invalidates the existing [UID:0000F4][TotemFrame](by-class/TotemFrame.md) or constructs a new `TotemFrame`. The constructor publishes `g_pTotemFrame`, so this call site should not be documented as a direct global assignment.

The formal C++ is first-draft source-shaped code from the accepted B004 UID00049B report. It supersedes only the stale B002-era body details for this target; B002's owner, split, router-caller, and padding conclusions remain valid.
