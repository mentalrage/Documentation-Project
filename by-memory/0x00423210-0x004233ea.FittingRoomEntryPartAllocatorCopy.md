## Behavior

This helper grows a begin/end/capacity vector of 6-byte fitting-room entry-part records and inserts one new record at the requested position. The only live direct caller is the fitting-room item parser path that appends a parsed part record when the current part-vector storage is full.

The vector triplet uses:

- begin pointer at vector slot `0x00`;
- end pointer at vector slot `0x04`;
- capacity pointer at vector slot `0x08`;
- fixed record stride of six bytes, copied as one dword plus one word.

On growth, the helper computes the insertion index and current size by dividing pointer deltas by six, rejects the `0x2aaaaaaa` element limit through the vector-too-long helper at `0x00421500`, chooses `max(size + 1, capacity + capacity / 2)` when that growth is safe, allocates `newCapacity * 6` bytes, copies the inserted record into its new slot, copies the pre-insert and post-insert ranges around it, frees the old backing storage with the usual aligned-allocation validation path, updates begin/end/capacity, and returns the inserted-record pointer.
