# 0x005729e0-0x00573232 - LookPane Packet And Entry Vector Helpers

## Status

- Completion: 76
- Confidence: strong for range contents and mixed-owner split; medium for final source-facing helper names.
- Disposition: reconstructable NexusTK project code, but the island mixes raw unmodeled helper starts with IDA-modeled functions and does not have a single safe autogen parent.
- Primary owners: [UID:0000CV][SelfLookPane2](by-class/SelfLookPane2.md) and [UID:0000DK][SpelledPane](by-class/SpelledPane.md).
- Source-placement expectation: keep the packet/update helpers with `SelfLookPane2`; keep the entry-vector insertion helper with `SpelledPane` entry storage unless later IDA evidence changes the caller/owner picture.

## Evidence Notes

- IDA MCP `py_eval` on 2026-05-28 shows the first three raw starts build stack packet buffers with repeated calls to `0x00575380` and then call `0x00574bb0`.
- `0x00572fd0` has direct code xrefs from `0x0056bdbc` and `0x0056c26d`, both inside the SpelledPane/list-entry area.
- The preceding bytes `0x005729c3-0x005729e0` are not normal code; they are a compiler switch/jump-table tail and alignment after `sub_5728a0`.
- The following bytes `0x00573232-0x00573240` are alignment before the `LineIterator` destructor.
- 2026-06-01 live IDA MCP `lookup_funcs` reports `0x005729e0`, `0x00572a60`, `0x00572ae0`, and `0x00572b60` as `Not a function`; `0x00572f30` is `sub_572F30` size `0x9f`, `0x00572fd0` is `sub_572FD0` size `0x262`, and the next function at `0x00573240` is `sub_573240` size `0x7`.
- 2026-06-01 live IDA MCP `callers`/`xrefs_to` confirms `0x00572fd0` is called from `0x0056bdbc` in `sub_56BCA0` and `0x0056c26d` in `sub_56C0E0`, both inside the [UID:0000DK][SpelledPane](by-class/SpelledPane.md) entry add/parse path; no direct callers were reported for the raw starts or `0x00572f30`.
- 2026-06-01 live IDA MCP `callees` for `0x00572f30` confirms dispatch into `sub_56BCA0`, `sub_56BE20`, parser/string helpers, and text/update helpers; `callees` for `0x00572fd0` confirms vector insert/copy support through `sub_573880`, allocation, throw, and helper routines.
- 2026-06-01 byte sweep confirms raw helper bodies at `0x005729e0-0x00572a54`, `0x00572a60-0x00572ad4`, `0x00572ae0-0x00572b54`, and `0x00572b60-0x00572f1f`; `0xcc` alignment at `0x00572a54-0x00572a60`, `0x00572ad4-0x00572ae0`, `0x00572b54-0x00572b60`, and `0x00573232-0x00573240`; and a modeled function body at `0x00572fd0-0x00573232`.
