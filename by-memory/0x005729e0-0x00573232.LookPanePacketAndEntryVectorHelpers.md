# 0x005729e0-0x00573232 - LookPane Packet And Entry Vector Helpers

## Status

- Completion: 35
- Confidence: medium.
- Disposition: reconstructable NexusTK project code, but the island mixes raw unmodeled helper starts with IDA-modeled functions.
- Primary owners: [UID:0000CV][SelfLookPane2](by-class/SelfLookPane2.md) and [UID:0000DK][SpelledPane](by-class/SpelledPane.md).
- Source-placement expectation: keep the packet/update helpers with `SelfLookPane2`; keep the entry-vector insertion helper with `SpelledPane` entry storage unless later IDA evidence changes the caller/owner picture.

## Evidence Notes

- IDA MCP `py_eval` on 2026-05-28 shows the first three raw starts build stack packet buffers with repeated calls to `0x00575380` and then call `0x00574bb0`.
- `0x00572fd0` has direct code xrefs from `0x0056bdbc` and `0x0056c26d`, both inside the SpelledPane/list-entry area.
- The preceding bytes `0x005729c3-0x005729e0` are not normal code; they are a compiler switch/jump-table tail and alignment after `sub_5728a0`.
- The following bytes `0x00573232-0x00573240` are alignment before the `LineIterator` destructor.
