# 0x00520b70-0x00520bab SharedDialogDefaultScalarDestructor

## Status

- Disposition: compiler-generated shared dialog scalar deleting destructor glue; do not reconstruct as handwritten NexusTK source.
- Entity kind: shared scalar deleting destructor body reached by dialog-family vtable slots and adjustor thunks.
- Current generated owner: partly `PursuitMessageDialogPane`, but vtable refs and thunk refs prove shared dialog ownership.
- Rebuild handling: ignored standalone binary artifact. The rebuilt source should express the owning dialog classes and base destructor declarations; the compiler should emit any equivalent scalar deleting destructor wrapper.
- Confidence: strong for exact boundary, flag behavior, broad shared ownership, and ignored rebuild handling.

## Behavior

The wrapper saves `this`, calls the shared dialog/base destructor at `0x0049d9f0`, then interprets the scalar deleting destructor flag argument:

- no `flags & 1`: return the object without freeing it;
- `flags & 1` and no `flags & 4`: pass the object to delete helper `0x004f4ac0`, then return it;
- `flags & 4`: call the guard/check helper path with size `0x278`, then return it.

The body does not restore a class-specific vtable. That makes it shared default destructor glue for many dialog/menu classes rather than source-authored behavior for one class.
