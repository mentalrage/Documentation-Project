## Behavior Summary

- Installs [UID:0001XR][ImageLibVtable](by-type/by-vtable/ImageLibVtable.md) at `+0x00`.
- Calls the allocator/memory-manager accessor at `0x00516030`.
- Reads [UID:0001US][ImageLibLayout](by-type/by-struct/ImageLibLayout.md) offset `+0x0c`, the 20-byte [UID:000079][List](by-class/List.md) pointer.
- Iterates the list count at the `List` object offset `+0x0c`.
- Retrieves each 44-byte [UID:0001VT][ResourceLayoutNameRecord](by-type/by-struct/ResourceLayoutNameRecord.md) through the list virtual `GetElementAt` slot.
- Releases non-null row payload pointers at record offset `+0x28` through `0x00516170`, then writes the returned pointer back to the row.
- Destroys the list through its virtual destructor with delete flag `1`, clears the object `+0x0c` list pointer, and clears [UID:0000QU][g_pEPFLib](by-global/g_pEPFLib.md) / `dword_67A744`.
- Chains to `LObject` cleanup at `0x004f4a90`.
- If `(flags & 1) != 0` and `(flags & 4) == 0`, deletes the object through `0x004f4ac0`.
