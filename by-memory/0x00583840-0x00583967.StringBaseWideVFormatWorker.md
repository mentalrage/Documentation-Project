## Behavior

This worker formats UTF-16 text into the pointer-backed ref-counted string buffer. It starts with a capacity estimate of `wcslen(format) + 64`, obtains CRT formatting options through `0x0041b9a0`, ensures a unique wide buffer with enough capacity, and retries when `__stdio_common_vsnwprintf_s` reports truncation/failure.

After a successful format, it detaches shared storage when needed, copies the wide characters to private storage, releases the old storage, and stores the final character count using `wcslen`.
