## Behavior

This helper searches an event-dispatcher handler-record vector for the first enabled record whose handler field matches the requested handler value. The caller passes the handler value and a `TreeItor<EventHandler*>`-style iterator object.

The local IDA decompilation shows the helper:

1. Builds a two-dword stack [UID:000060][HandlerFindFunc](by-class/HandlerFindFunc.md) predicate with the expected handler value at predicate offset `+0x04`.
2. Reads the iterator's tree pointer at iterator offset `+0x04`.
3. Reads the handler-record vector begin/end pair from the tree object at `tree + 0x04` and `tree + 0x08`.
4. Computes the record count as `(end - begin) / 28`.
5. Scans records in `0x1c`-byte strides.
6. Skips records whose disabled byte at record offset `+0x18` is nonzero.
7. Calls `HandlerFindFunc::IsMatch` with `record + 0x14`, the stored handler field.
8. On match, writes the found record index to iterator offset `+0x08` and returns `true`.
9. Returns `false` if the vector is empty or no enabled matching record is found.
