## Behavior

Computes a 32-bit hash over a NUL-terminated UTF-16 string:

- scans the string length in 16-bit code units;
- seeds the hash from the first code unit shifted left by seven bits;
- for each code unit, multiplies the rolling value by `0x0f4243`, then XORs the current code unit;
- XORs the final string length into the hash result.
