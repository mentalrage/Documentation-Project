# JsonCpp Document Parse Front Ends `0x004298f0-0x0042acdf`

## Status

- Confidence: strong for JsonCpp ownership; medium-low for exact upstream version and per-function names.
- Proposed owner: [UID:0000KI][JsonCpp](by-file/JsonCpp.md)
- Disposition: third-party static library code; exclude from NexusTK product source modules.
- Evidence basis: read-only IDA MCP function-list, lookup, caller/callee, and product-caller checks on 2026-05-25. `wave3.py` was not executed for this pass.

## Range Role

This range contains JsonCpp document construction and parse front-end helpers used by product code, plus parse-support helpers that bridge into the first JsonCpp reader/parser island.

It is documented separately from [UID:0000WY][0x00424630-0x00428b4b.JsonCppValueCore](by-memory/0x00424630-0x00428b4b.JsonCppValueCore.md), the adjacent [UID:0000WZ][0x00428b4b-0x004298f0.JsonCppValuePathIteratorAndCrtNumericSupport](by-memory/0x00428b4b-0x004298f0.JsonCppValuePathIteratorAndCrtNumericSupport.md) island, and the following [UID:0000X1][0x0042acdf-0x0042ae90.JsonCppLegacyReaderRawLexicalHelpers](by-memory/0x0042acdf-0x0042ae90.JsonCppLegacyReaderRawLexicalHelpers.md) because product code directly calls `0x004298f0` and `0x00429b30`, while most value/path/lexer helpers are reached indirectly through parsed value operations or are retained third-party library code.

## Parser Call Chain

IDA callee checks currently show:

- `0x00429c40` calls the first reader/parser island at `0x0042ae90` and local parser support helpers.
- `0x0042a770` is called from the first parser island and calls `0x0042aaf0` / `0x0042ab40`.

## Ownership Decision

Keep this range with [UID:0000KI][JsonCpp](by-file/JsonCpp.md) and `third_party/jsoncpp/`. Product code should call into this range through a parser/reader API, while fitting-room, downloader, and cash-shop modules should own only URLs, buffers, cache policy, and catalog interpretation.

Do not merge `0x004298f0` or `0x00429b30` into [UID:0000JE][FittingRoom](by-file/FittingRoom.md) or [UID:0000I1][CashShopVersionRequest](by-file/CashShopVersionRequest.md), even though those modules call them.
