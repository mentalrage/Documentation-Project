## Behavior

This method loads per-part sprite descriptor files for every row already present in `m_partEntries`. It builds each descriptor path by combining the part row name at row offset `+0x04` with the UTF-16 `.DSC` suffix, opens that DAT entry, reads a 23-byte header, and then reads a 4-byte descriptor count.

For positive descriptor counts, the loader:

1. Allocates `32 * descriptorCount` bytes for 0x20-byte `NewHumanPartFrameDescriptor` rows.
2. Stores the descriptor count at part row offset `+0x34`.
3. Stores the descriptor array pointer at part row offset `+0x3c`.
4. Reads each descriptor's four fixed dwords at descriptor offsets `+0x00`, `+0x04`, `+0x08`, and `+0x0c`.
5. Accumulates descriptor `+0x0c` into a per-part total and stores that total at part row offset `+0x38`.
6. Reads count-driven primary and secondary 2-byte arrays into packed descriptor fields.
7. Allocates a motion-count-sized sequence table for every descriptor.
8. Reads populated motion-indexed sequence slots and their 9-byte frame rows.
9. Calls the DAT close helper in the same positive-count branch observed in the binary.

The method's explicit close is only in the positive descriptor-count branch. The formal C++ preserves that explicit source shape and relies on DATFile cleanup for the non-positive branch, matching the decompiled local object cleanup path.
