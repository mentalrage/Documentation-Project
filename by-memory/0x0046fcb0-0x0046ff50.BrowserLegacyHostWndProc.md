# 0x0046fcb0-0x0046ff50 Browser Legacy Host WndProc

## Scope

- Range: `0x0046fcb0-0x0046ff50` half-open.
- Entity kind: browser host window procedure plus compiler switch table.
- Direct owner: [UID:0000HV][Browser](by-file/Browser.md).
- Parent inventory: [UID:0000ZF][0x0046f010-0x004710b8.BrowserOleLegacyAndHelpers](by-memory/0x0046f010-0x004710b8.BrowserOleLegacyAndHelpers.md).

The modeled function `0x0046fcb0-0x0046fe47` is a browser-host `WndProc`-style helper. The child includes the associated compiler switch table bytes through the padding before `BrowserControlPaneOld::BrowserControlPaneOld` at `0x0046ff50`.

## IDA Evidence

- 2026-06-10 B001-024 live IDA MCP reports `sub_46FCB0` at `0x0046fcb0-0x0046fe47`; the following bytes at `0x0046fe47-0x0046ff50` contain switch/table data and padding.
- The only direct xref to the function body is data/code setup from the BrowserThread host initialization path at `0x00470ab5`, consistent with a window-class procedure.
- Decompilation obtains Browser object state from `GetWindowLongA(hwnd, -21)` and falls back to `dword_67AB8C`, the BrowserThread current-host/global bridge documented by [UID:0000QO][g_pCurrentBrowserHost](by-global/g_pCurrentBrowserHost.md) and exact storage page [UID:0002AD][0x0067ab88-0x0067ab90.BrowserThreadHostGlobals](by-memory/0x0067ab88-0x0067ab90.BrowserThreadHostGlobals.md).
- It handles `WM_PAINT` with `BeginPaint`/`EndPaint`.
- It handles keyboard messages `WM_KEYDOWN`, `WM_KEYUP`, `WM_SYSKEYDOWN`, and `WM_SYSKEYUP`, queries browser COM interfaces, forwards accelerator messages, special-cases Tab/Escape/F4-style keys, and otherwise falls back through `dword_69BE50`.
- The helper is a file-level/static browser callback rather than a direct class method because its entry signature is the Win32 window-procedure shape and ownership is established by BrowserThread host registration, not by a class vtable slot.

## Reconstruction Notes

Reconstruct as a static/free browser host window procedure in the browser module. Its source parent is the Browser file/module, not the broad mixed aggregate and not a single class page.
