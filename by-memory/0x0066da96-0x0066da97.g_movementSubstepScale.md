# 0x0066da96-0x0066da97 g_movementSubstepScale

## Summary

- Address range: `0x0066da96-0x0066da97`
- Entity kind: initialized one-byte movement scale global
- Disposition: reconstructable project data
- Rebuild handling: `source-declared/generated-binary`
- Proposed source symbol: [UID:0002CF][g_movementSubstepScale](by-global/g_movementSubstepScale.md)
- Confidence: strong for movement/interpolation role; medium for final source name

This byte is a separate initialized movement interpolation scale between `g_screenWidth` and `g_useEpfAssets`. It is not a boolean flag: sampled xrefs use it as a divisor and subframe multiplier. With the initial value `1`, map-object and player movement use four substeps per direction vector; if raised, the same code would use `4 * g_movementSubstepScale` subframes and shorter timer intervals.
