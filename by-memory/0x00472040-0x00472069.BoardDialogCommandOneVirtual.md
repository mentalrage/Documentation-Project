## Behavior

The callback receives the secondary-interface `this` pointer and an event/action object. It loads the command string pointer from `event + 0x0c`, checks whether the first byte is ASCII `'1'` (`0x31`), and returns false when the command does not match.

When the command is `'1'`, it loads the primary vptr from `[ecx - 0xa0]`, adjusts `ecx` back to the primary dialog object with `this - 0xa0`, replaces the stack argument with the command string pointer, loads the primary vtable slot at `+0x5c`, and tail-jumps to that virtual slot. This is a generic secondary-interface command bridge, not `BoardListDialog`-only logic.
