## Behavior Notes

- `0x004fe9e0` takes current password, old/new-password field data, converts them from UTF-16 to multibyte strings, writes packet field lengths with `sub_575380`, copies field payloads with `sub_516220`, then sends the packed buffer with `sub_574BB0(dword_67A7EC, buffer, size)`.
- `0x004febf0` is reached through `sub_4FE530` when the packet type at `**(a2 + 12)` is `2`. It reads the result code at packet offset `+1`, maps several result codes to dialog focus/action states through virtual slot `+0x58`, decodes the server message at offsets `+2/+3`, and displays the message with `AlertPane`.
- `0x004fee40` performs the same broad reply-handling pattern with a smaller result-code mapping. Current generated Wave3/simroot output has been seen grouping this address with `RankingDialog`; IDA behavior and local address context do not support ranking ownership.
- `0x004fe790` is probably an older or alternate account/password packet builder. It has the same string-conversion and network-send pattern as `0x004fe9e0`, includes one additional UTF-16 input, and writes the same opcode `0x26`; current IDA xrefs did not show a caller, so final naming should remain conservative.
