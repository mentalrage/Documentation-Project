## Behavior

Overrides base element swapping to preserve hierarchy links after two rows exchange positions. It delegates to the base [UID:000079][List](by-class/List.md) swap routine, then repairs the first swapped row and the second swapped row as separate one-element ranges.

Step order:

1. Save the first index in `esi`, the second index in `edi`, and the `HierList` object in `ebx`.
2. Call base `List::SwapElements(indexA, indexB)` at `0x004f34b0`.
3. Call `UpdateHierarchy(indexA, indexA, 0)`.
4. Call `UpdateHierarchy(indexB, indexB, 0)` and return that helper's result.

The method deliberately repairs both index positions even if the base swap is a no-op for equal indices. The `clear` argument is always `0`, so the helper rewrites parent links to current row pointers rather than clearing them.
