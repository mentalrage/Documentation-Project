| `0x004eff30-0x004eff5d` | `KeySpeedMgr::RestoreSystemKeyboardSettings` | Restores saved keyboard delay when `delay <= 3` using `SPI_SETKEYBOARDDELAY` (`0x17`) and restores saved speed when `speed <= 31` using `SPI_SETKEYBOARDSPEED` (`0x0b`), both with `SPIF_UPDATEINIFILE`. |
