| Offset | Value |
| --- | --- |
| `+0x00` | word opcode `0x011b` |
| `+0x02` | byte subcommand `0x63` |
| `+0x03` | first caller byte |
| `+0x04` | second caller byte |
| `+0x05` | zero terminator in stack local; the send length is five bytes, so this byte is not sent |

The second helper receives a byte pointer, reads bytes at `input+1` through `input+5`, stores them into five `OptionPane` state fields, and enables/disables five child controls by passing `value == 0` into `sub_496110`.
