## Behavior

The first helper is an old `OptionPane` packet sender adjacent to the local three-byte [UID:0001DQ][0x0053e380-0x0053e3c1.OptionPaneSendOptionPacket11B](by-memory/0x0053e380-0x0053e3c1.OptionPaneSendOptionPacket11B.md) body. It writes:

| Offset | Value |
| --- | --- |
| `+0x00` | word opcode `0x011b` |
| `+0x02` | byte subcommand `0x63` |
| `+0x03` | first caller byte |
| `+0x04` | second caller byte |
| `+0x05` | zero terminator in stack local; the send length is five bytes, so this byte is not sent |

The second helper receives a byte pointer, reads bytes at `payload+1` through `payload+5` through the one-byte packet reader at `0x00575470`, stores them into five `OptionPane` state fields, and updates five two-state radio groups by passing `value == 0` to [UID:0000BI][RadioGroupControlPane](by-class/RadioGroupControlPane.md)'s `SetSelectedIndex` helper at `0x00496110`. This is not a widget enable/disable path; the callee invalidates old/new option rectangles and writes the selected-index state.
