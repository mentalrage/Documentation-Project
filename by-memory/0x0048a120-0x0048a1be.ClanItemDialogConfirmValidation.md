## Behavior

This virtual callback enables or disables the confirm action based on two pieces of dialog state:

- control id `5` exposes selected item/list state; the function reads through offset `+0x108` and checks the selected row/index at `+0x134` against `-1`;
- control id `6` supplies a text value copied into a 128-wide-character stack buffer through [UID:0002OA][0x00498c10-0x00498c1f.TextEditControlPaneReadText](by-memory/0x00498c10-0x00498c1f.TextEditControlPaneReadText.md), and the first wide character must be nonzero.

If both conditions pass, the function calls the control id `1` object virtual at vtable offset `0x4c`; otherwise it calls the same object virtual at vtable offset `0x50`. The exact source-level names of those enable/disable virtuals are still open.

2026-06-17 B002 role correction: this is not the actual deposit/withdraw submit callback. It sends no packet and closes no dialog; it only updates whether control id `1` can be used. The actual submit behavior remains in the derived `ClanDepItemDialog` and `ClanWidItemDialog` paths.
