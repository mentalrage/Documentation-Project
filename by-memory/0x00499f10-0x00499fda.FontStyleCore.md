## Constructor Behavior

The constructor initializes a 0x20-byte style object:

- `rulesBegin`, `rulesEnd`, and `rulesCapacity` are set to null.
- enabled byte at `+0x00` is set to `1`.
- float fields at `+0x04` and `+0x08` are set to `0.2f`.
- scalar fields at `+0x0c` and `+0x10` are set to `1` and `0x80`.

## Rule Lookup Behavior

The `0x00499f60` helper computes the current rule count from the vector triplet at offsets `+0x14/+0x18/+0x1c`. When the requested index is in range, it copies the selected 16-byte rule record into the caller-provided output buffer; out-of-range indexes leave the output unchanged and return the count. Live xrefs show two code references from the HelpPane text draw path at `0x004c6723` and `0x004c67b3`.

## Configure Behavior

`Configure(firstValue, secondValue, selector, fourthValue)` builds a 16-byte rule record and appends it to the vector triplet at object offset `+0x14`:

- `firstValue` is stored at rule offset `+0x00`.
- `secondValue` is stored at rule offset `+0x04`.
- the byte-sized `selector` argument is stored at rule offset `+0x08` low byte in the IDA decompilation.
- `fourthValue` is stored at rule offset `+0x0c`.
- when `rulesEnd != rulesCapacity`, the record is written inline and `rulesEnd` advances by 16 bytes.
- when full, it calls the vector growth helper at `0x0049ac60` with the vector triplet, insertion pointer, and rule address.

## Ownership Notes

This range is not a static text control method even though most callers pass the resulting object to static/help text constructors.
