## Behavior

This helper tears down the dispatcher handler/modal list at dispatcher offset `0x20`.

Observed behavior from IDA MCP:

- Reads the sentinel head pointer.
- Resets the sentinel to an empty self-linked node (`head->next = head`, `head->prev = head`).
- Clears the list count stored at owner offset `+0x04` from the list wrapper.
- Walks the old node chain and frees each 12-byte list node.
- Frees the sentinel node itself at the end.
- 2026-05-31 recheck: IDA MCP `lookup_funcs` reports `sub_4A7D00` size `0x43`; decompilation confirms the sentinel self-link reset, wrapper count clear, node-chain free loop, and final sentinel free.
