## Evidence Notes

- IDA data inspection reports a two-byte item at `0x0066da94` with value `0x0400`.
- IDA xrefs show broad layout/render usage. Startup code reads this word with [UID:0001OI][0x0066da98-0x0066da9a.g_screenHeight](by-memory/0x0066da98-0x0066da9a.g_screenHeight.md), dialog layout clamps right edges against it, and `GrafPort::UpdateRenderRegion` reads it when deciding how to size a DirectDraw backing surface.
- The byte at `0x0066da96` is a neighboring movement interpolation scale documented separately as [UID:00027F][0x0066da96-0x0066da97.g_movementSubstepScale](by-memory/0x0066da96-0x0066da97.g_movementSubstepScale.md). The byte at `0x0066da97` is documented separately as [UID:0001OH][0x0066da97-0x0066da98.g_useEpfAssets](by-memory/0x0066da97-0x0066da98.g_useEpfAssets.md).
