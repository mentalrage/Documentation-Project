## Behavior

`IMEPane::SetFocusPane` maintains the root focus pane list used by text controls. It initializes the local `focusPaneCount` from `focusPaneList.GetCount()`, scans `focusPaneList` backward from that local count minus one, removes the first existing entry that matches the supplied `Pane *`, then appends the pane again only when the `focused` flag is true and the pane pointer is non-null. Complete-object offset `+0x110` is `focusPaneList.m_count` (`focusPaneList` at `+0x104` plus `List::m_count` at `+0x0c`), not a separate `IMEPane::focusPaneCount` member. This preserves the binary's remove-before-append behavior and keeps the last focused text-entry pane at the end of the list for candidate/composition positioning.
