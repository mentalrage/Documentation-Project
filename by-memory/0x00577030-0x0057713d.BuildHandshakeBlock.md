## Behavior

The helper:

- Calls the project allocation/memory manager context helper `0x00516030`.
- Copies the caller-owned seed block into `g_handshakeSeedBytes` at `0x0069ba40` with `0x00516220`.
- Stores the seed size in `g_packetTransformStride` at `0x0069ba5c`.
- Saves original seed byte `6`, then mutates seed byte `6` using seed bytes `1`, `2`, `6`, `7`, and constants `0x12` / `0x59`.
- Mutates seed byte `3` using seed bytes `0`, saved original byte `6`, seed byte `7`, and constant `0x31`.
- Copies the mutated seed block into four consecutive windows of `g_packetXorTablePrimary` at `0x0069ba64 + stride * 0`, `+ stride * 1`, `+ stride * 2`, and `+ stride * 3`.
- Restores `g_handshakeSeedBytes[3]` to ASCII `c` (`0x63`) and `g_handshakeSeedBytes[6]` to ASCII `t` (`0x74`).
- Frees the supplied caller block with `0x00516170`.
