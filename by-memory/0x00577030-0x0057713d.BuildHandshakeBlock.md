# 0x00577030-0x0057713d Build Handshake Block

- Disposition: reconstructable NexusTK project code

## Covered Range

| Range | Current name | Notes |

| `0x00577030-0x0057713d` | `BuildHandshakeBlock` | Builds the primary packet transform seed table from a supplied handshake block. |

IDA MCP confirms `0x00577030` as a function start with size `0x10d`.

## Behavior

The helper:

- Calls the memory manager setup helper.
- Copies the supplied seed block into `g_handshakeSeedBytes` at `0x0069ba40`.
- Stores the seed size in `g_packetTransformStride` at `0x0069ba5c`.
- Mutates bytes 6 and 3 from other seed bytes and constants.
- Copies the resulting seed block four times into `g_packetXorTablePrimary` at `0x0069ba64`.
- Restores `g_handshakeSeedBytes[3]` to `c` and `g_handshakeSeedBytes[6]` to `t`.
- Frees the supplied seed block.

## Callers

IDA MCP confirms two direct callers:

- `0x005747e0` `Socket::Socket`, which seeds the table from the literal `UrkcnItni` during socket construction.
- `0x00575e60` `Socket::HandleSocketCommand`, command `14`, which rebuilds the handshake/primary table from caller-supplied data.

## Ownership Decision

This is packet transform/key-table setup code. It should be documented with [UID:0000M9][PacketTransform](by-file/PacketTransform.md), while the constructor and command-dispatch call sites remain owned by [UID:0000NS][Socket](by-file/Socket.md).
