## Behavior

The helper is gated by byte field `this + 0xfc`, the style/fade-enabled byte copied by `HelpPane::HelpPane` from the optional style record into `this + 0xfc`. When enabled, it compares the float at `this + 0x100` against `0.0f` and the shared `1.0f` constant at `0x006104b4`, transitions the base pane mode through [UID:0002V7][0x005446b0-0x005446d4.PaneSetMode](by-memory/0x005446b0-0x005446d4.PaneSetMode.md) with values `1` or `3`, and copies style/coordinate dwords from `this + 0x108/+0x10c` to `this + 0x11c/+0x120`.

The second half repeats the mode/fade logic for the embedded `HelpPane::SimpleHelpTextPartPane` at `this + 0x124` when `this + 0x220` points at an enabled style record. It reads the child fade float from `[this + 0x220] + 8`, calls [UID:0002V7][0x005446b0-0x005446d4.PaneSetMode](by-memory/0x005446b0-0x005446d4.PaneSetMode.md) on `this + 0x124` with state values `1` or `3`, and writes the accepted child opacity to `this + 0x1b4`.
