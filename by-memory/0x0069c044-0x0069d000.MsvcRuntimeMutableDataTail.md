# MSVC Runtime Mutable Data Tail

## Summary

- Address range: `0x0069c044-0x0069d000`
- Entity kind: runtime/global-data tail inside IDA `.data`
- Disposition: ignored for NexusTK-owned reconstruction
- Rebuild handling: `third-party/runtime`
- Confidence: strong for range boundary and runtime ownership; medium for any finer internal runtime substructure names

This range is the final initialized writable-data tail in the IDA `.data` segment. It is not empty padding: the image bytes are initialized to `0xff` throughout, but IDA reports many named anchors and xrefs from MSVC CRT, STL, startup, locale, thread-local, security-failure, stdio, heap, timezone, and file/environment runtime support paths.

## Evidence

- IDA MCP `py_eval` on 2026-05-28 reports `.data` as `0x0066d000-0x0069d000` and this child span as `0x0069c044-0x0069d000`, size `4028`.
- Byte audit reports `byte_counts=FF:4028`.
- The same IDA audit reports `198` named or referenced anchors inside the span.
- Representative anchors include:
  - `0x0069c044` / `0x0069c048`, referenced by runtime static initialization and cleanup tables.
  - `0x0069c050 stru_69C050`, referenced from `std::_Init_locks` style lock setup around `0x005c5efd-0x005c5f83`.
  - `0x0069c110-0x0069c170`, referenced from `std::locale`, facet, and `ios_base` runtime support.
  - `0x0069c1a0-0x0069c1a4`, referenced from CRT atexit/static-initialization support.
  - `0x0069c1d0-0x0069c26c`, written by a runtime API-pointer initialization routine around `0x005c6f74-0x005c743b`.
  - `0x0069c2e8-0x0069c400`, referenced by `___report_gsfailure` and security-failure context handling.
  - `0x0069c604-0x0069c660`, referenced by `__scrt_common_main_seh`, startup locks, TLS, and runtime list state.
  - `0x0069c750-0x0069ca08`, referenced by ACRT/stdio/file/environment and lock support, including `lpCriticalSection` with heavy stdio-lock xrefs.
  - `0x0069cd08+`, referenced as timezone, heap, file, locale, and multibyte runtime storage.
- The previous documented range ends at [UID:0001Q4][0x0069bf98-0x0069c044.SnowLookupDescriptorStorage](by-memory/0x0069bf98-0x0069c044.SnowLookupDescriptorStorage.md) and the IDA `.data` segment ends at [UID:0001Z8][0x0066d000-0x0069d000.DataSection](by-memory/0x0066d000-0x0069d000.DataSection.md), so this page closes the section tail without inventing NexusTK source ownership.

## Rebuild Notes

Do not port this as handwritten NexusTK source data. A compatible compiler, linker, CRT, STL, and runtime support library should regenerate equivalent mutable runtime state from the selected toolchain and linked libraries.

The rebuilt project may still require source declarations and dependency choices that cause the runtime to be linked, but this range itself should be treated like the earlier MSVC runtime mutable-data docs rather than copied byte-for-byte into project source.
