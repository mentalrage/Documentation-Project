## Behavior

This helper releases heap/vector storage embedded inside a `0xb4` byte fitting-room dialog item/selection entry. IDA models the object as dword-indexed:

- `this[42]` (`+0xa8`) = begin pointer;
- `this[43]` (`+0xac`) = end pointer;
- `this[44]` (`+0xb0`) = capacity pointer.

When the begin pointer is non-null, it computes the byte span from begin to capacity, masks the span to dword alignment, and uses the normal free path for spans below `0x1000`. Large spans use the stored aligned-allocation header at `begin[-1]`; invalid headers route to `_invalid_parameter_noinfo_noreturn`. The helper then frees storage through `0x005c7526` and zeroes begin/end/capacity. A null begin pointer returns without touching the other two fields.
