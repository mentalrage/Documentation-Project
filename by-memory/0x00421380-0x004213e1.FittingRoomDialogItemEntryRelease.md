## Behavior

This helper releases heap/vector storage embedded inside a `0xb4` byte fitting-room dialog item/selection entry. IDA models the object as dword-indexed:

- `this[42]` (`+0xa8`) = begin pointer;
- `this[43]` (`+0xac`) = end pointer;
- `this[44]` (`+0xb0`) = capacity pointer.

When the begin pointer is non-null, it checks whether the capacity span is at least `0x1000` bytes after masking to dword alignment. Large spans use the stored aligned-allocation header at `begin[-1]`; invalid headers route to `_invalid_parameter_noinfo_noreturn`. The helper then frees storage through `0x005c7526` and zeroes begin/end/capacity.

void FittingRoomDialogItemEntry::ReleaseStorage()
{
    if (m_valuesBegin == 0) {
        return;
    }

    void* storage = m_valuesBegin;
    unsigned int capacityBytes =
        (reinterpret_cast<unsigned char*>(m_valuesCapacity) -
         reinterpret_cast<unsigned char*>(m_valuesBegin)) & 0xfffffffc;

    if (capacityBytes >= 0x1000) {
        void* raw = reinterpret_cast<void**>(m_valuesBegin)[-1];
        if (reinterpret_cast<unsigned char*>(m_valuesBegin) -
                reinterpret_cast<unsigned char*>(raw) - 4 > 0x1f) {
            _invalid_parameter_noinfo_noreturn();
        }
        storage = raw;
    }

    FreeMemory(storage);
    m_valuesBegin = 0;
    m_valuesEnd = 0;
    m_valuesCapacity = 0;
}
