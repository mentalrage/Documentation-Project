## Exact Behavior

1. When `g_pConfig->m_musicSourceMode == 1`, post main-window message `0x407`, which the application dispatcher routes to next-track playback.
2. Independently, when `m_musicSourceMode == 0` and `g_pSoundManager->m_zonePlaylistActive` at SoundManager `+0x10a9` is true, post message `0x408`, which routes to the next active zone-playlist track.

Both posts use `g_pApplication->GetMainWindowHandle()` and zero `wParam`/`lParam`. The conditions must not be collapsed into an `else` chain beyond what the comparisons inherently imply, and the callback must not synchronously call playback methods; asynchronous `PostMessageA` is observed behavior.
