# 0x00630f8c-0x0063104c MenuVariety Resource And Label Strings

## Summary

- Address range: `0x00630f8c-0x0063104c`
- Entity kind: UTF-16 menu artwork filenames and selector labels
- Disposition: reconstructable source literals
- Parent: [UID:0000L8][MenuVarietyPanes](by-file/MenuVarietyPanes.md)
- Rebuild handling: `source-authored`

This exact child contains the `MENUVAR` artwork/palette filenames and the in-game menu selector labels from `Userlook` through `Quit`. It is split from [UID:0002Z4][0x00630edc-0x0063104c.UserStatusMenuResourceStrings](by-memory/0x00630edc-0x0063104c.UserStatusMenuResourceStrings.md) because `0x00630f8c` is the first menu-variety literal after the status HUD literal run.

`AUTOGEN_PARENT_UID` is [UID:0000L8][MenuVarietyPanes](by-file/MenuVarietyPanes.md), not a single class page, because `MENUVAR.EPF`/`MENUVAR.PAL` are drawn by [UID:000081][MenuVarietyPane](by-class/MenuVarietyPane.md), while the selector labels are constructed by [UID:000082][MenuVarietySelectPane](by-class/MenuVarietySelectPane.md). The file parent clears `86/85`, and this child clears the `85/85` routing gate.
