## Behavior

This constructor initializes a pool-backed timer-driven Motion animation object. It calls the base-object constructor at `0x004f4a80`, initializes the embedded timer handler at `this + 0x04` through `0x00597570`, stores the owner pointer at `this + 0x08`, stores the motion type at `this + 0x0c`, and records timing/frame fields in the packed bytes and duration dword.

The constructor maps the motion type to a default sound/effect id. Known values include `2 -> 709`, `4 -> 406`, `8 -> 403`, `9 -> 312`, `10 -> 313`, `11 -> 300`, `12/23 -> 301`, `13 -> 302`, `14/24 -> 303`, `15 -> 304`, `16 -> 305` when the feature flag under `dword_67A7C8` is enabled, `17 -> 306`, `18 -> 307`, `19 -> 308`, `20 -> 309`, `21 -> 310`, and `22 -> 311`. For the special `27` and `28` cases it sets the phase byte to `2`, sets a direction/flag byte, and calls owner virtual slots near `+116` or `+120`.
