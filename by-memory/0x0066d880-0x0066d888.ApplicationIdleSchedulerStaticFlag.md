# 0x0066d880-0x0066d888 Application Idle Scheduler Static Flag

## Summary

- Address range: `0x0066d880-0x0066d888`
- Entity kind: initialized global flag plus alignment
- Disposition: reconstructable project data
- Rebuild handling: `source-declared/generated-binary`
- Confidence: medium

This span contains a one-byte initialized flag used by the application idle scheduler, followed by zero padding before the key translation tables.

## Layout

| Range | Current IDA name | Initial value | Notes |

| `0x0066d881-0x0066d888` | padding/unused bytes | `0` | Alignment before `EventMan` key translation table storage. |

## Evidence

- IDA xrefs to `byte_66D880` are `0x004a6c4f`, `0x004a6c77`, and `0x004a6c92`.
- The referenced code is the documented application idle work scheduler.
- The following bytes are all zero until the key translation table at `0x0066d888`.

## Reconstruction Notes

- Keep it separate from `EventMan` key maps because the direct xrefs are from the idle scheduler, not keyboard event construction.
