## Address Range

`0x0048f4d0-0x0048f6cb`, ending immediately before the exported start at `0x0048f6d0`.

IDA does not currently model this start as a function, but live IDA disassembly decodes a normal stack-frame prologue at `0x0048f4d0`.

## Behavior

This helper parses host and port data from the process command line, accepts hostnames or dotted IPv4-like input, resolves hostnames with Winsock, stores the resulting endpoint into the startup-state block, and aborts startup through the common localized message-box/quit path when validation fails.

On success it writes the resolved address bytes to `param_1 + 0x2915b4`, the parsed port to `param_1 + 0x2916c4`, sets `param_1 + 0x2916ca` to `1`, and forces the state byte at `param_1 + 0x28de28` to `5`.

## Evidence

- Legacy Wave2 report records `FUN_0048f4d0` as `0x0048f4d0 .. 0x0048f6ca`, with no live Wave2 method/global resolution.
- IDA live disassembly shows calls to `GetCommandLineW`, `_wcsstr`, `_wcschr`, `WideCharToMultiByte`, `gethostbyname`, `WSAGetLastError`, `MessageBoxW`, and `PostQuitMessage`.
- The outgoing call mix is command-line parsing, DNS lookup, localized error text retrieval, and hard startup abort handling, matching a source-authored launcher/bootstrap helper.
