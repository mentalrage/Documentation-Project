## Behavior

This helper parses host and port data from the process command line. It searches the command line for the UTF-16 markers at `0x00616970` (`"IP"`) and `0x00616978` (`"PO"`), advances past the marker prefix, and treats `&` as the terminator for each field.

On the success path it copies the host substring to `param_1 + 0x2915c4`, terminates it, converts it through `WideCharToMultiByte`, resolves it with `gethostbyname`, copies four resolved address bytes into `param_1 + 0x2915b4`, parses the port substring through the Visual C runtime integer converter, writes the parsed port to `param_1 + 0x2916c4`, sets `param_1 + 0x2916ca` to `1`, and forces the state byte at `param_1 + 0x28de28` to `5`.

Missing `IP`/`PO` markers or missing the first field terminator route to a localized Unitel-only-version message through `off_66D468`, `sub_4673E0`, `sub_4651D0`, `MessageBoxW`, `PostQuitMessage`, and `__loaddll`. A DNS lookup failure formats the `Unitel Relay` lookup-failure string at `0x00616980` with the host and `WSAGetLastError` result before the same message-box/quit path. A missing port-field terminator branches directly to `PostQuitMessage`/`__loaddll`, and an oversized ANSI conversion trips `___report_rangecheckfailure`.
