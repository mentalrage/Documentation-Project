## Behavior

This helper decodes a raw PCX byte buffer into temporary RGB565 pixels, constructs a `DIBitmap`, validates the DIB bits pointer, copies decoded rows into the top-down DIB using the DIB's aligned stride, frees the temporary decoded pixel buffer, and returns the `DIBitmap*`. If decode fails, dimensions are invalid, decoded pixels are absent, or DIB creation fails, it returns null after cleanup.

- The temporary decoded pixel buffer is freed before returning the constructed bitmap.
