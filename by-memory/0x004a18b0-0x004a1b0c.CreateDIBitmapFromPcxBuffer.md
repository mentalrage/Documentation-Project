## Behavior

This helper decodes a raw PCX byte buffer into temporary RGB565 words, constructs a `DIBitmap`, validates the DIB bits pointer, copies decoded rows into the top-down DIB using the DIB's aligned stride, frees the temporary decoded pixel buffer, and returns the `DIBitmap*`. If decode fails, dimensions are invalid, decoded pixels are absent, or DIB creation fails, it returns null after cleanup.

RGB565 describes the decoder's packing expression. The inlined DIBitmap constructor creates a one-plane 16-bpp `BI_RGB` DIB with no bitfield masks; under Win32 that header convention does not explicitly declare RGB565. The factory nevertheless copies the decoder's 16-bit words unchanged. Preserve both facts rather than silently changing the decoder name or inventing `BI_BITFIELDS` masks.
