## Behavior

The method takes an unsigned byte mode/state code. It returns immediately when `this + 0xb5` already equals the incoming value. When the mode changes, it stores the new byte and invokes the primary pane vtable slot `+0x20`, passing `this + 0x44`. The callback side effect is consistent with a bounds/dirty/redraw notification after a mode change, but the final virtual name is still unresolved.

This is the same helper called by [UID:00022N][0x004c6eb0-0x004c6f89.HelpPaneFadeStateUpdate](by-memory/0x004c6eb0-0x004c6f89.HelpPaneFadeStateUpdate.md) when `HelpPane` and its embedded text-part pane transition between mode/state values `1` and `3`.
