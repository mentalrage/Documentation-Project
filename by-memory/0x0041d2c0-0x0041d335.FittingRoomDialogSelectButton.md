## Behavior

`FittingRoomDialog::SelectButton` updates which fitting-room category button is visually selected.

The method initializes old and new button pointers to null. If the previously selected command id stored at dialog offset `+0x788` is positive, it asks the dialog child container at offset `+0x1fc` for that child and keeps the returned [UID:000055][FittingRoomTextButtonControlPane](by-class/FittingRoomTextButtonControlPane.md). If the incoming command id is positive, it performs the same child lookup for the new button. The incoming command id is then stored back at offset `+0x788` even when it is zero or negative, which lets the caller clear the selected-button state.

When an old button exists, the method calls [UID:0002SC][0x00424020-0x004242e4.FittingRoomTextButtonControlPane](by-memory/0x00424020-0x004242e4.FittingRoomTextButtonControlPane.md) selected-state helper with `false`, then invalidates that button through virtual slot `+0x20` with argument `0`. When a new button exists, it calls the same selected-state helper with `true` and invalidates the new button through the same virtual slot.
