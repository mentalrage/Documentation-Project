# 0x00615570-0x006164f4 Clan Read-Only Data

## Range

- Address range: `0x00615570-0x006164f4`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable NexusTK source-declared/generated-binary data.
- Rebuild handling: `source-declared/generated-binary`

## Summary

This `.rdata` span contains clan UI pane/dialog vtables and clan bank/dialog resource strings. It replaces a clan-owned section of the old unchecked `0x00613ab0-0x0061929c` UNKNOWN row.

## Observed Contents

- Vtables for `ClanStatusPane`, `ClanInfoListPane`, `ClanStringListPane`, `ClanJoinListPane`, `ClanEnlistListPane`, clan name/money/input dialogs, `ClanItemDialog`, `ClanDepItemDialog`, `ClanWidItemDialog`, `ClanItemListPane`, `ClanBankPane`, and `ClanBankItemListPane`.
- Clan resource strings such as `AN1.EPF`, `AN2.EPF`, `AN3.EPF`, `ANBUT.EPF`, `LAN1.EPF`, `LAN2.EPF`, `LAN3.EPF`, `ANBAN1.PAL`, and `ANBAN1.EPF`.
- Format/control strings near the end of the span, ending at `aSD_0` before collection-dialog data begins.
