## Behavior

`ChangeMan::UnregisterObject` removes every registration whose owner pointer or listener pointer equals the supplied object. It walks the registration list backward so removals do not invalidate unvisited indices.

This broad cleanup path is used by object teardown code, including `BackPane` destructor paths that must clear subscriptions before destroying UI objects.

void ChangeMan::UnregisterObject(void *object)
{
    for (int index = m_changeList->Count() - 1; index >= 0; --index) {
