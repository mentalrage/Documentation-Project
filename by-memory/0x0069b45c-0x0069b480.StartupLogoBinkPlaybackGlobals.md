# 0x0069b45c-0x0069b480 StartupLogoBinkPlaybackGlobals

## Summary

- Address range: `0x0069b45c-0x0069b480`
- Entity kind: startup-logo Bink playback global-data cluster
- Current IDA names: `dword_69B45C`, `dword_69B460`, `hWnd`, `byte_69B46C`, `dword_69B470`, `dword_69B474`, `dword_69B478`
- Static image value pattern: initialized `0xff` bytes / `0xffffffff` dwords
- Disposition: reconstructable NexusTK startup media state, with two unreferenced reserved slots
- Confidence: strong for the referenced fields and source owner; medium for final field names and reserved-slot purpose

This `.data` span stores process globals used only by the startup-logo Bink playback loop and its temporary window procedure. It is documented as a single feature-local cluster because the live xrefs all point back into [UID:00022T][0x004f5710-0x004f5ac7.StartupLogoBinkPlaybackLoop](by-memory/0x004f5710-0x004f5ac7.StartupLogoBinkPlaybackLoop.md) and [UID:00022U][0x004f5ae0-0x004f5b1e.StartupLogoBinkMidpointRestart](by-memory/0x004f5ae0-0x004f5b1e.StartupLogoBinkMidpointRestart.md).
