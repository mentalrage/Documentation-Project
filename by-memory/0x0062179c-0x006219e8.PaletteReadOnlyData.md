# 0x0062179c-0x006219e8 Palette Read-Only Data

## Range

- Address range: `0x0062179c-0x006219e8`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared data with compiler-emitted vtables.
- Rebuild handling: source class declarations and palette filename literals must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains `DLPalette` and `PaletteLib` vtables plus the wide-string palette filename table used by map, tile, body/equipment, monster, item, effect, riding, and accessory resources. It ends before the core `Pane` vtable. The source-owned constants attach to [UID:0000MA][Palette](by-file/Palette.md); vtables are compiler-emitted from reconstructed `DLPalette` and `PaletteLib` declarations.
