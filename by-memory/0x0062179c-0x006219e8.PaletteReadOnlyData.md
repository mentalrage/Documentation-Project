# 0x0062179c-0x006219e8 Palette Read-Only Data

## Range

- Address range: `0x0062179c-0x006219e8`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared data with compiler-emitted vtables.
- Rebuild handling: source class declarations and palette filename literals must be reconstructed; vtables are compiler-emitted.
- Current MCP lookup disposition: `0x0062179c`, `0x006217ac`, `0x006217b8`, `0x006217c4`, `0x006217d8`, `0x006219d0`, and successor `0x006219e8` are data starts, not function starts. `sub_543700` at `0x00543700` is the `0x3e2`-byte PaletteLib constructor and `sub_544210` at `0x00544210` is the `0x18f`-byte slot loader.

## Summary

This `.rdata` span contains `DLPalette` and `PaletteLib` vtables plus the wide-string palette filename literals used by map, tile, body/equipment, monster, item, effect, riding, and accessory resources. It ends before the core `Pane` vtable. The source-owned constants attach to [UID:0000MA][Palette](by-file/Palette.md); vtables are compiler-emitted from reconstructed `DLPalette` and `PaletteLib` declarations, while the filename literals are emitted by DLPalette/PaletteLib use sites, primarily `PaletteLib::PaletteLib`.
