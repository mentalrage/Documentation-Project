## Behavior

This helper selects a [UID:0001UW][LightInfo](by-type/by-struct/LightInfo.md) record by index, falls back to the embedded default record at `this + 0x14` when the index is out of range, and writes a rectangle describing the light frame's local bounds.

When the selected record has a generated frame pointer at `LightInfo + 0x18`, the output rectangle is:

```text
left   = -radiusX
top    = -radiusY
right  =  radiusX + 1
bottom =  radiusY + 1
```

If the selected record has no generated frame, the helper writes an empty `0,0,0,0` rectangle. IDA shows the rectangle write is delegated to `sub_4B7C50`, the shared four-integer rectangle setter used throughout the client.
