## Behavior

The constructor takes the movie path as its first stack argument and a completion callback object as its second stack argument. It builds the `VideoPlayerPane` base, installs the three `LogoPlayerPane` vtable pointers at offsets `+0`, `+0xa0`, and `+0xa4`, constructs the embedded `_AUTOBUF<unsigned char>` object at `+0x100`, stores the completion callback at `+0x10c`, clears the skip/advanced flag at `+0x110`, reads the segmented movie payload into the AUTOBUF, stores the first segment size at `+0x114`, and opens the first in-memory Bink segment through `0x005c0110`.

The payload contract is direct byte parsing: after the file helper fills the embedded AUTOBUF, the constructor reads `*(uint32_t *)autobuf.data` as the first segment size, stores that value at `this + 0x114`, and calls the Bink helper with `autobuf.data + 4` and the first segment size. If the first segment cannot be opened, the constructor allocates and throws the file error path using the wide format string `L"%s corrupted"`.
