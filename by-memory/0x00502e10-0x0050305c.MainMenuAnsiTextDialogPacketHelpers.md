## Packet Behavior

- Subtype `1`: reads a two-byte URL/blob length, preserves the URL bytes and length, reads a second two-byte ANSI text length, converts up to `999` wide characters through `MultiByteToWideChar`, allocates `632` bytes, and constructs a `UrlAlertPane` with constructor flag `1`.
- Subtype `2`: uses the same counted URL/text parse shape and constructs `UrlAlertPane` with constructor flag `0`.
- Subtype `3`: calls the packet string reader at `0x00575a90`, assigns the resulting string object into [UID:00029T][0x0069b3d0-0x0069b3d4.MainMenuTextUrlStaticString](by-memory/0x0069b3d0-0x0069b3d4.MainMenuTextUrlStaticString.md), then destroys the temporary string object.
- Other subtype values return success without constructing a dialog or updating the static string.
