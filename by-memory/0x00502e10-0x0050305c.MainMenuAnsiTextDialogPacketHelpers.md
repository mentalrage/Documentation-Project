## Packet Behavior

- Subtype `1`: reads a counted URL/blob field plus counted ANSI text, converts the text to wide characters, allocates `632` bytes, and constructs `UrlAlertPane` with exit-after-open flag `1`.
- Subtype `2`: same parse shape, but constructs `UrlAlertPane` with exit-after-open flag `0`.
- Subtype `3`: calls [UID:0001HZ][0x00575380-0x00575abb.PacketBufferHelpers](by-memory/0x00575380-0x00575abb.PacketBufferHelpers.md) `PacketReadString_575A90` through the packet-buffer helper cluster, assigns the decoded string into `dword_69B3D0`, then destroys the temporary string.
- Other subtype values return success without constructing a dialog.

```cpp
bool HandleAnsiTextDialogPacket_502E30(const unsigned char* payload)
{
    unsigned char kind = payload[1];
    int cursor = 2;

    if (g_pScreenDimmer)
        g_pScreenDimmer->ScalarDeletingDestructor(1);

    if (kind == 1 || kind == 2) {
        unsigned short urlLength = PacketReadU16BE(payload + cursor);
        const char* urlBytes = (const char*)payload + cursor + 2;
        cursor += urlLength + 2;

        unsigned short textLength = PacketReadU16BE(payload + cursor);
        wchar_t text[1000];
        int chars = MultiByteToWideChar(0, 0, (const char*)payload + cursor + 2,
                                        textLength, text, 999);
        if (chars >= 1000)
            __report_rangecheckfailure();
        text[chars] = 0;

        new UrlAlertPane(kind == 1, g_pMainMenuPane, text, urlBytes, urlLength);
        return true;
    }

    if (kind == 3) {
        LObject temp;
        PacketReadString_575A90(&temp, payload, &cursor);
        dword_69B3D0 = temp;
        return true;
    }

    return true;
}
```
