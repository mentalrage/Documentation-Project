## Behavior

This method handles dragging the chat-height handle. It first requires `*(dword_67ADE0 + 0x118)` to be enabled; otherwise it returns `0`.

Observed event handling:

- event subtype byte at `event + 4` controls the branch;
- subtype `1` starts a drag when the mouse point at `event + 8/+12` is inside the handle rectangle at `this - 0x5c`; it sets `this + 0x58` to `1` and stores the start Y coordinate at `this + 0x5c`;
- subtype `0` while dragging previews the handle rectangle by clamping `currentRectTop + mouseDeltaY` to `50..650` and moving the rectangle to `(792, clampedY - startY, 807, clampedY - startY + 15)`;
- subtype `3` while dragging commits the new height, clamps the same `50..650` value, converts it to `visibleLineCount = (710 - clampedY) / 13`, clamps that count to at least `4`, then updates:
  - the chat back-pane viewport through [UID:000105][0x004806d0-0x00480739.BackPaneViewportRectHelper](by-memory/0x004806d0-0x00480739.BackPaneViewportRectHelper.md);
  - the chat display visible-row count through [UID:0002EW][0x0047fbd0-0x0047fc6b.ChattingPaneSetVisibleRowCount](by-memory/0x0047fbd0-0x0047fc6b.ChattingPaneSetVisibleRowCount.md);
  - the handle rectangle to `(792, 693 - 13 * count, 807, 708 - 13 * count)`;
  - the config/storage field at `dword_67A7C8 + 2678392`.

The method returns `1` only when it consumes a drag start, preview, or commit event. Other cases return `0`.
