## Behavior

This helper loads an EPF/EPD frame metadata table from DAT-backed image resources. The first argument is either a direct resource path or is ignored in merge mode. The second argument selects between:

- direct mode, where the function opens the supplied resource path once;
- merge mode, where the function maps a numeric resource family to a fixed EPF prefix, scans numbered files such as `<prefix>0.EPF`, and merges all present shards into one output table.

The in-memory result is a small table header plus an allocated array of 24-byte frame records. Each record receives rectangle/bounds data and two payload-offset fields rebased by the DAT entry data pointer. The array ends with a zero-bounds sentinel whose payload fields point at the final archive data/table boundary.

## Direct Resource Mode

IDA decompilation shows this path when `mergeMode == 0`:

- constructs a DAT file object on the stack;
- opens the caller-supplied resource path through the DAT file API;
- allocates a 12-byte table/header object;
- reads the first 8 bytes of the archive metadata into that header;
- reads a 4-byte record-table offset;
- obtains the DAT payload base through the DAT file data-pointer helper;
- seeks to the record-table offset;
- allocates `(count + 1) * 24` bytes for frame records;
- loops over `count` archive records, reading four signed 16-bit coordinate values and two 32-bit payload fields;
- calls the rectangle initializer at `0x004b7c50` for the bounds block;
- adds the payload base to both payload fields;
- writes a terminal zero rectangle and terminal payload offset;
- closes the DAT file object and returns the table pointer.
