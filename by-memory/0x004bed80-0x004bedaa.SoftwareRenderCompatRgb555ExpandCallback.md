# 0x004bed80-0x004bedaa SoftwareRenderCompatRgb555ExpandCallback

## Status

- Disposition: reconstructable NexusTK project code.
- Entity kind: RGB555 color conversion callback.
- Callback slot: `dword_69B400`.
- Containing family: [UID:00016J][0x004bb8d0-0x004c069e.SoftwareRenderCompatCallbacks](by-memory/0x004bb8d0-0x004c069e.SoftwareRenderCompatCallbacks.md).

## Range And Behavior

| Range | IDA function | Behavior |
| --- | --- | --- |
| `0x004bed80-0x004bedaa` | `sub_4BED80`, size `0x2a` | Expands one RGB555 pixel into three byte channels: low/red component `pixel << 3`, middle component `(pixel >> 2) & 0xf8`, and high component `(pixel >> 7) & 0xf8`. |

The function stores the expanded channels through caller-provided byte pointers. IDA MCP decompilation/disassembly on 2026-06-06 resolved it as a no-callee leaf helper. The following `0x004bedaa-0x004bedb0` interval is six bytes of `0xcc` alignment.

## Evidence

- No ordinary direct code callers were reported; this function is installed through the surface callback table rather than called as a normal helper.
- Data refs are recorded at `0x00558710` and `0x00558bda`, matching raw initializer-neighborhood and [UID:0001G6][0x00557140-0x00559aef.SurfacePresentation](by-memory/0x00557140-0x00559aef.SurfacePresentation.md) callback-table setup.
- The function is source-authored render conversion code, not compiler glue or padding.

## Assignment Decision

Assigned to [UID:0000OC][Surface](by-file/Surface.md). The child already clears `86/90`, and Surface clears `88/85` as the direct parent for callback-table dispatch. The decisive evidence is that this leaf is installed in callback slot `dword_69B400`, has no ordinary code callers or callees, and has only target refs at `0x00558710` plus the Surface initializer reference at `0x00558bda`. [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) is rejected as direct parent despite the pure RGB555 formula because its own page scopes that parent to stateless helpers called by callback bodies, while this address is an exported Surface callback-table slot.
