## Behavior Summary

- Returns without drawing while the effect data load/suspend byte `byte_69B420` is set.
- Resolves a four-byte [UID:0001UA][EffectPixMapInfo](by-type/by-struct/EffectPixMapInfo.md) remap from object offset `+0x50` using `frameIndex`, falling back to the remap at `+0x58`.
- Initializes a frame context, then calls [UID:0000UX][LoadFrameDrawRecord_004D1600](by-item/LoadFrameDrawRecord_004D1600.md) against the archive metadata table at object offset `+0x5c`.
- Selects palette category `11` through the palette library and dispatches through the shared surface/image draw callback.
- When alpha is positive, passes a small alpha parameter block to the draw callback.
- When an overlay target is supplied, scales overlay strength by `32.0`, rounds it, and calls [UID:0000UH][DrawEncodedAlphaFrame_00462F20](by-item/DrawEncodedAlphaFrame_00462F20.md).
