## Evidence

- `resources/exported_data/master_function_list.json` lists function starts throughout this island: `0x0048f400`, `0x0048f4d0`, `0x0048f6d0`, `0x0048fca0`, `0x00490200`, `0x00490510`, `0x00490810`, `0x00490b10`, `0x004910d0`, `0x00491450`, `0x00491790`, and `0x004918e0`.
- 2026-05-30 IDA MCP `lookup_funcs` confirms IDA-modeled functions at `0x0048fca0` (`sub_48FCA0`, size `0x550`), `0x00490b10` (`sub_490B10`, size `0x5b0`), and `0x004918e0` (`sub_4918E0`, size `0x248`). The other starts are not IDA functions but live IDA disassembly decodes real code prologues at those addresses.
- Direct PE byte review of `E:\NTK\Resources\NexusTK\NexusTK.exe` shows `RegistryConfig::InitializeDefaults` returns at `0x0048f3f0`, followed by `0x0f` bytes of `0xcc` padding before the first helper at `0x0048f400`.
- Direct PE byte review shows the last helper returns at `0x00491b27`, followed by eight `0xcc` alignment bytes before `RegistryConfig::SaveToRegistry` at `0x00491b30`.
- Export summaries and live IDA string/call checks identify this island as application command-line parsing, login/session/connection setup, hostname resolution, and launcher modes such as `/lgi`, `/KWG`, `/GameBill`, `/Bixel`, `Mihosoft`, Thrunet, and LG Internet.
- `RegistryConfig::LoadOrInitialize` already parses command-line startup state, so this island most likely belongs near `config/RegistryConfig.cpp` rather than the later registry save/load body or the preceding collection dialog code.
- IDA MCP caller checks show this island calls the ignored MSVC COM/CRT helper page at [UID:000221][0x004941e0-0x00494519.MsvcComAndFormattingHelpers](by-memory/0x004941e0-0x00494519.MsvcComAndFormattingHelpers.md), especially `sub_48FCA0` and `sub_490B10`.
- IDA string/xref checks confirm `thrunet.clsURLCHK` at `0x00616e60` is referenced from `0x0048ffcb`, `WaitForSessionParameter` at `0x00616f38` is referenced from `0x004902bb`, and wide literal `/host:` at `off_617994` is referenced from `0x00491947`.
