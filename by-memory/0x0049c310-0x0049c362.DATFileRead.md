# DATFile Read

## Role And Evidence

Exact virtual read body at `[0x0049c310,0x0049c362)`. A negative signed count selects the cached full payload size. Reads that would cross the next record boundary return zero without copying; successful reads copy from mapped base plus the absolute cursor, advance the cursor, and return the byte count as `size_t`.

## ABI And Ownership

The signed `int count` branch is observed binary behavior and must not be normalized to unsigned source. Mapped storage remains owned by DATFileContainer; this method performs no allocation or ownership transfer.
