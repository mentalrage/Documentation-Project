## Behavior

`DeserializeEmployeeRecord` parses one variable-length employee/shop item record from a packet byte buffer into a `0x41c`-byte [UID:0001UD][EmployeeRecord](by-type/by-struct/EmployeeRecord.md).

For a nonzero record id:

- reads big-endian `employeeItemId` with `PacketBufferReadUInt32BE(packet)` into output `+0x000`;
- reads big-endian `itemImageId` with `PacketBufferReadUInt16BE(packet + 4)` into output `+0x004`;
- reads `itemPaletteFlags` from packet byte `+0x006` into output `+0x006`;
- reads the byte-counted name length at packet `+0x007`, copies the name bytes through `GetMemoryMan()->MemmoveWrapper`, and converts them to the UTF-16 `name[256]` buffer at output `+0x008` with `MultiByteToWideChar(CP_ACP, ...)`;
- appends a `(%d%%)` suffix with `swprintf_s`/`wcscat_s` when the following percent byte is not `0xff`;
- clears `statusText[0]` at output `+0x20a`;
- reads big-endian `priceValue`, `editablePriceValue`, and the provisional `dataField3` / `serverDataField3` trailing dword at output `+0x40c`, `+0x410`, and `+0x414`;
- returns the consumed byte count as `nameLength + 21`.

For a zero record id:

- reads big-endian `fallbackItemId` at output `+0x418`;
- clears `itemImageId` at output `+0x004`;
- returns `8`.
