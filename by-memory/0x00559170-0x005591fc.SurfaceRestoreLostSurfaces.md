const int kRestoreLostSurfaceMaxAttempts = 10000;

bool RestoreSurfaceWithRetry(IDirectDrawSurface *surface)
{
    if (surface == 0)

## Behavior Summary

`ScreenPane::RestoreLostSurfaces` restores three DirectDraw surface pointers owned by the root ScreenPane/GrafPort object. It uses only COM vtable calls on `IDirectDrawSurface`-style pointers; there are no static internal helper callees.

- It reads the pointer at byte offset `+0x18`. If the pointer is non-null and `IsLost()` returns exactly `DDERR_SURFACELOST` (`-2005532222` / `0x887601C2`), the method calls `Restore()` once. It does not retry this surface.
- It reads the pointer at byte offset `+0x100`. If the pointer is non-null and `IsLost()` returns a negative HRESULT, the method calls `Restore()` until success or until `10000` failed attempts. If all `10000` attempts fail, the method returns immediately and skips `+0x108`.
- It reads the pointer at byte offset `+0x108`. If the pointer is non-null and `IsLost()` returns a negative HRESULT, the method calls `Restore()` until success or until `10000` failed attempts. If all attempts fail here, the method simply falls through to return.
- The observed body therefore has asymmetric behavior: one-shot restore for `+0x18`, retry-with-early-return for `+0x100`, and retry-with-fallthrough for `+0x108`.
