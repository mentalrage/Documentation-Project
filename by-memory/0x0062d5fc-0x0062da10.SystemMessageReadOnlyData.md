# 0x0062d5fc-0x0062da10 System Message Read-Only Data

## Range

- Address range: `0x0062d5fc-0x0062da10`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: reconstruct the system-message classes, resource filename literals, and dialog ownership; vtables are compiler-emitted.

## Summary
