## Summary

This `.rdata` span contains the system-message pane vtable family, the neighboring forced-inform message dialog vtables, staff-dialog resource filenames, and status-bar resource filenames. It intentionally crosses source-owner boundaries: most of the system-message vtables rebuild through `social/SystemMessagePanes.cpp`, while the forced-inform vtables and `DLGSTAFF` resource tail belong with `login/ForcedInformMessageDialog.cpp` unless later string xrefs split individual literals more narrowly. It ends before the terminal/phone dialog vtable island.
