## Exact Behavior

The method performs one scalar read, not a bulk-entry or container read:

1. Calls virtual `GetSize()` and logically shifts the unsigned result right by one to obtain the validation key.
2. Calls virtual `Read()` for exactly eight bytes into a local stack buffer.
3. Passes the mutable bytes, validation key, and caller-provided float storage to `DecodeTableValue`.
4. Returns the decoder's full-register integer result directly: `1` for a validated value or `0` for failure.

The wrapper performs no floating-point arithmetic or numeric integer-to-float conversion. The shared decoder writes the recovered 32-bit payload bits directly into the float object through its untyped output-storage contract. On decoder failure, `outValue` remains untouched while the local eight-byte buffer has still been decoded in place and then goes out of scope.
