## Behavior

This helper decodes a raw in-memory JPEG buffer into an `EPFTileContext`-style destination. Unlike [UID:0002TL][0x004d07b0-0x004d09a7.DecodeJpfImageToTileContext](by-memory/0x004d07b0-0x004d09a7.DecodeJpfImageToTileContext.md), it does not consume a `JPF` wrapper signature and receives the JPEG byte pointer and byte length directly.

IDA MCP decompilation on 2026-06-03 shows the helper:

- initializes IJG libjpeg decompression with the client error handler at `0x004e4ee0`;
- creates the decompressor with version `62` and struct size `432`;
- configures the memory JPEG source at `0x004e7030` with the caller-supplied buffer and length;
- reads the JPEG header, starts decompression, and uses output color mode value `2`;
- allocates the destination tile context from JPEG output width/height;
- reads scanlines and converts 24-bit RGB triples to 16-bit RGB565-like pixels;
- finishes and destroys the JPEG decompressor;
- finalizes the tile context through [UID:000200][0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels](by-memory/0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels.md).
