## Behavior

This helper handles exchange ready/confirm packet state.

Observed behavior:

- reads a ready/confirm byte from `packet+2`;
- sets the remote-ready flag at `this+0x272` when the byte is nonzero;
- resets the local/remote state word at `this+0x270` when the byte is zero;
- calls the shared button-state update helper when both sides are not ready;
- decodes a packet message string from `packet+4`;
- closes any active `g_pExchangeAlertPane`;
- allocates and constructs a new `ExchangeAlertPane`;
- closes the current exchange dialog after creating the alert.
