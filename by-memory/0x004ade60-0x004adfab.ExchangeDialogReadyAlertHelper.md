## Behavior

This helper handles exchange ready/confirm packet state.

Observed behavior:

- reads the ready-side/status byte from `packet+2`;
- sets the peer/remote ready-confirmed byte at `this+0x272` when `packet+2` is nonzero;
- writes `0x0100` to the packed local ready-state word at `this+0x270` when `packet+2` is zero, clearing byte `+0x270` and setting byte `+0x271`;
- calls the generic DialogPane selected-control refresh wrapper at `0x0049fe20`, which invokes `ExchangeDialog::UpdateButtonStates` through the virtual slot, when both sides are not ready;
- decodes a counted CP_ACP packet message string from `packet+4`, with byte length from `packet+3`;
- closes any active `g_pExchangeAlertPane`;
- allocates and constructs a new `ExchangeAlertPane`;
- runs the DialogPane slide/animation close helper at `0x0049eb90`, then closes the current exchange dialog through the generic close/remove helper at `0x0049dad0`.
