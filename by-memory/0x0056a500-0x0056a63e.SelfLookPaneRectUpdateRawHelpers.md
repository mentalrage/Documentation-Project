## Behavior

These helpers update a rectangle-like self-look state block from packet data. Both helpers are raw `thiscall`-style bodies that receive the packet pointer as the single stack argument, use [UID:0001HZ][0x00575380-0x00575abb.PacketBufferHelpers](by-memory/0x00575380-0x00575abb.PacketBufferHelpers.md) packet readers, accept only mode byte `0` or `1`, and return `0` after either applying or skipping the update.

The first helper at `0x0056a500` appears to load two leading 16-bit packet fields before the selected-object check. It decodes the payload into a `0x44`-byte stack temporary, copies four XMM-sized chunks plus the final dword into `this+0x108..0x148`, then calls the pane virtual at vtable slot `+0x20` with `this+0x44`. The second helper at `0x0056a5c0` is the in-place variant: it verifies the same selected object key, then decodes from `packet+6` directly into `this+0x108` and invalidates the same rectangle.

The mode byte controls which decoder is used: mode `0` calls `0x004d1fa0`, and mode `1` calls `0x004d2640`. Final source names for those two decoder helpers are still open, so this page keeps behavior-oriented names rather than emitting final C++.
