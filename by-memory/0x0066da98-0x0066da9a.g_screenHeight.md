## Evidence Notes

- IDA data inspection reports a two-byte item at `0x0066da98` with value `0x0300`.
- IDA xrefs show broad layout/render usage. Startup code reads this word with [UID:0001OG][0x0066da94-0x0066da96.g_screenWidth](by-memory/0x0066da94-0x0066da96.g_screenWidth.md), dialog layout clamps bottom edges against it, and screen-pane construction passes the width/height pair into backing setup.
- [UID:00027F][0x0066da96-0x0066da97.g_movementSubstepScale](by-memory/0x0066da96-0x0066da97.g_movementSubstepScale.md) and [UID:0001OH][0x0066da97-0x0066da98.g_useEpfAssets](by-memory/0x0066da97-0x0066da98.g_useEpfAssets.md) are neighboring one-byte globals between the width and height words, but neither byte belongs to the height storage.
