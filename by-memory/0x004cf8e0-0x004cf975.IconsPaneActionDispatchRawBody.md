# 0x004cf8e0-0x004cf975 IconsPaneActionDispatchRawBody

## Status

- Disposition: retained raw old-HUD action dispatcher with embedded jump table.
- Entity kind: raw/unmodeled dispatch helper body plus local switch table.
- Likely source owner: [UID:0000JZ][IconsPane](by-file/IconsPane.md) / [UID:00006B][IconsPane](by-class/IconsPane.md), or a small shared old-HUD action helper adjacent to [UID:0000OF][TabPane](by-file/TabPane.md).

## Behavior

The raw body first reads [UID:0000PR][g_activeMapPane](by-global/g_activeMapPane.md) / `dword_67A764` and checks byte `+0x3f0` (`+1008`). If that lock byte is set, it returns without dispatching. Otherwise it switches on the incoming action id:

| Case | Target | Meaning evidence |
| --- | --- | --- |
| `0` | `0x005a4db0` | Older Wave2 notes name this `SetInputControllerMode2AndRefresh_5A4DB0`. |
| `1` | `0x005a4e40` | Older Wave2 notes name this `SetInputControllerMode3AndRefresh_5A4E40`. |
| `2` | `0x005a4f70(0)` | Sends/stores opcode-style action with extra value `0`. |
| `3` | `0x005a5010(dword_67A748)` | Shared player/client-state action using [UID:0000QK][g_pCollectionData](by-global/g_pCollectionData.md) / `dword_67A748`. |
| `4` | `0x005a50a0` | Ensures the normal bulletin session; see [UID:0000HX][BulletinSession](by-file/BulletinSession.md). |
| `5` | `0x005a5110(dword_67A748)` | Shared player/client-state action using [UID:0000QK][g_pCollectionData](by-global/g_pCollectionData.md). |
| `6` | `0x005a5340` | Older Wave2 notes name this `SendOpcode43MinusOneRequest_5A5340`. |
| `7` | `0x005a5a80` | Neighboring UI/session action helper. |

This action mapping matches the click-action switch embedded in [UID:00016Z][0x004cf1f0-0x004cf8d5.IconsPaneCore](by-memory/0x004cf1f0-0x004cf8d5.IconsPaneCore.md) `IconsPane::OnMouseEvent` at `0x004cf6d8-0x004cf712`, including the same `dword_67A764 + 1008` input-lock gate.

The downstream action helpers are also shared with [UID:0000EB][TabPane](by-class/TabPane.md) `HandleInputEvent` at `0x004cfa10`, which calls the same mode/tab/session helpers for tab actions. This makes the raw body a plausible old-HUD shared action-dispatch helper physically emitted between `IconsPane` and `TabPane`, but current IDA still has no caller to its entrypoint.

## Evidence Notes

- IDA MCP reports no function object at `0x004cf8e0` and no direct code/data xrefs to the entrypoint.
- IDA MCP disassembly shows normal function-shaped bytes beginning with `push ebp; mov ebp, esp`, followed by an eight-case indirect jump through the local table at `0x004cf954`.
- IDA MCP `xrefs_to` finds only internal refs from the jump at `0x004cf8ff` and the jump table to the case labels; it does not find external callers.
- `simroot_v2` should be treated only as a lead source here. The stronger evidence is IDA's raw byte layout plus the duplicate action switch already present in the IDA-modeled `IconsPane::OnMouseEvent`.
- 2026-05-28 IDA MCP recheck still reports `0x004cf8e0`, `0x004cf952`, `0x004cf954`, and `0x004cf975` as `Not a function`; the neighboring modeled functions are `sub_4CF870` ending at `0x004cf8d5` and `sub_4CF980` starting at `0x004cf980`.
- 2026-05-28 IDA `py_eval` scan across loaded segments found no dword equal to `0x004cf8e0`, so no obvious untyped callback/action table points at this raw entry in the current IDB.
- 2026-05-28 IDA MCP `xrefs_to` for downstream helper targets shows calls from the live `IconsPane` handler at `0x004cf6df..0x004cf712`, this raw body at `0x004cf906..0x004cf949`, and several `TabPane`/shared UI paths such as `0x004cfa61`, `0x004cfa7a`, and `0x004cfa93`.
