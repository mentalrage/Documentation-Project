## Behavior

This handler processes chat packet byte `10` as routed by [UID:0002EU][0x0047f890-0x0047f8c9.ChattingPaneChatPacketRouter](by-memory/0x0047f890-0x0047f8c9.ChattingPaneChatPacketRouter.md). It reads a subtype at `packet + 1`, decodes an embedded length-prefixed multibyte text payload, converts that payload to UTF-16 with `MultiByteToWideChar`, optionally rewrites bracketed display strings, and forwards accepted messages to [UID:0002EQ][0x0047f280-0x0047f36f.FolderTreePaneAddChattingMessage](by-memory/0x0047f280-0x0047f36f.FolderTreePaneAddChattingMessage.md).

The function always returns `0`. Rejected subtypes also return `0`, so the return value is not an accept/reject result.

Current-layout branch when `byte_66DA97 == 1`:

- Accepted subtype bytes are `0`, `4`, `5`, `11`, `12`, `17`, and `18`; other subtype bytes return without insertion.
- Normal subtype payloads start at `packet + 2`. The handler reads a 16-bit length with `0x00575480`, copies from `packet + 4` with `0x00516220`, appends a zero byte, and converts with `MultiByteToWideChar`.
- Subtype `18` reads two additional values from `packet + 2` and `packet + 6` via `0x005754c0`, then starts the text payload at `packet + 10`. It forwards color pair `253`/`254` and passes the two decoded values as the final `AddChattingMessage` arguments.
- Subtype `0` checks for a `"` marker followed by a space. When the expected `") "`, `"("`, and `"\" "` pieces are present, it rewrites the output with a format equivalent to `%s%s"%s` before insertion.
- Subtype `11` performs the same shape of rewrite for `"] "` and emits a `]` marker.
- Subtype `12` performs the same shape of rewrite for `"> "` and emits a `>` marker.
- Color pairs are read from a palette/config object rooted at `dword_67A7C8`: subtype `4` uses offsets `2678404/2678405`, subtype `0` uses `2678406/2678407`, subtype `11` uses `2678408/2678409`, subtype `12` uses `2678410/2678411`, and subtypes `5`/`17` use `2678412/2678413`.

Old-layout branch when `byte_66DA97 != 1`:

- Accepted subtype bytes are `0`, `4`, `5`, `11`, `12`, and `17`; other nonzero/nonlisted subtype bytes return without insertion.
- The text length is read from `packet + 2`, and the text bytes start at `packet + 4`.
- Subtypes `0` and `11` share fixed color pair `1`/`143`.
- Subtype `4` uses fixed color pair `143`/`1`.
- Subtype `5` uses fixed color pair `143`/`12`.
- Subtype `12` uses fixed color pair `250`/`143`.
- Subtype `17` uses fixed color pair `143`/`5`.

Both branches enforce a `0x8000` byte/character limit before writing terminators. Range failures call `___report_rangecheckfailure`.
