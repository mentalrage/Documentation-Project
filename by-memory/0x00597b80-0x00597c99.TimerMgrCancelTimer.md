## Behavior

This method walks the timer queue backward and removes queued events whose owner pointer equals the supplied `TimerHandler` owner and whose event/timer id equals the supplied id. It removes each matching one-entry range through [UID:0002L6][0x00598290-0x00598471.TimerMgrTimerQueueSpliceTimerRange](by-memory/0x00598290-0x00598471.TimerMgrTimerQueueSpliceTimerRange.md).
