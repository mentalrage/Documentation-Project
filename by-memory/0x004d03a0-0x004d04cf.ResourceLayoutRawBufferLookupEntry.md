## Behavior

Parses a raw in-memory resource-layout buffer and optionally fills an [UID:00004I][EPFTileContext](by-class/EPFTileContext.md)-like output for the first entry. This helper does not take a `this` pointer; IDA reports it as `__stdcall`.

IDA MCP decompilation on 2026-05-31 shows:

- copies the first 8 header bytes and a 4-byte table offset from the caller-provided buffer;
- allocates `24 * (entryCount + 1)` bytes for [UID:0000VB][ResourceLayoutEntry](by-item/ResourceLayoutEntry.md) rows;
- reads one table row from `buffer + tableOffset + 12`;
- initializes a rectangle with the same `0x004b7c50` helper used by the DAT-backed loader;
- converts pixel and encoded-mask offsets relative to `buffer + 12`;
- if an output pointer is supplied, writes pixel pointer, row stride, bounds, encoded-mask size, and mask pointer in the same field pattern used by `ResourceLayoutTable::LookupLayoutEntry`.

This appears to be a raw-buffer companion to the DAT-backed resource-layout loader, likely used when the EPF/EPD payload has already been materialized in memory.
