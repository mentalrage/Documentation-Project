# 0x004d03a0-0x004d04cf ResourceLayoutRawBufferLookupEntry

## Status

- Entity kind: free helper / static helper
- Disposition: reconstructable NexusTK project code, but final owner remains open.
- Rebuild handling: `source-authored`
- Parent aggregate: [UID:000174][0x004d0120-0x004d182e.ResourceLayoutTable](by-memory/0x004d0120-0x004d182e.ResourceLayoutTable.md)
- IDA function: `sub_4D03A0`, `0x130` bytes, ending at IDA exclusive end `0x004d04d0`.

## Behavior

Parses a raw in-memory resource-layout buffer and optionally fills an [UID:00004I][EPFTileContext](by-class/EPFTileContext.md)-like output for the first entry. This helper does not take a `this` pointer; IDA reports it as `__stdcall`.

IDA MCP decompilation on 2026-05-31 shows:

- copies the first 8 header bytes and a 4-byte table offset from the caller-provided buffer;
- allocates `24 * (entryCount + 1)` bytes for [UID:0000VB][ResourceLayoutEntry](by-item/ResourceLayoutEntry.md) rows;
- reads one table row from `buffer + tableOffset + 12`;
- initializes a rectangle with the same `0x004b7c50` helper used by the DAT-backed loader;
- converts pixel and encoded-mask offsets relative to `buffer + 12`;
- if an output pointer is supplied, writes pixel pointer, row stride, bounds, encoded-mask size, and mask pointer in the same field pattern used by `ResourceLayoutTable::LookupLayoutEntry`.

This appears to be a raw-buffer companion to the DAT-backed resource-layout loader, likely used when the EPF/EPD payload has already been materialized in memory.

## Boundary Evidence

IDA enumerates this function between `LookupLayoutEntry` and `CopyEntryTileContext`. The bytes from `0x004d039e` to `0x004d03a0` are two `0xcc` alignment bytes; the function runs from `0x004d03a0` through IDA exclusive end `0x004d04d0`.

## Open Questions

- Caller set has not yet been audited, so final source-file owner and original helper name remain open.
- It currently remains attached only to the ResourceLayout aggregate documentation, not to a class, because the calling convention is not a class method.
- The function only parses/fills one entry in the decompiled form; confirm caller expectations before writing final C++.
