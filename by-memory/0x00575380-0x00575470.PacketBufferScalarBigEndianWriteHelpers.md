This callback supersedes only those historical score/readiness limits; UID0000M8 ownership, scalar-family boundaries, SelfSave/Clan/BlockListen consumers, and movement ABI evidence remain unchanged.
- [UID:0003U6][0x005a2e00-0x005a36f0.UserPaneProcessMovement](by-memory/0x005a2e00-0x005a36f0.UserPaneProcessMovement.md), retained UID0003UX, and retained UID0003UY all use the raw value-first source ABI: value first, destination pointer second. Destination-first generated examples are wrapper-style history, not raw-call proof.
- Blocked opcode `0x69` uses value-first UInt16BE writes for map X/Y and sends six bytes. Waypoint opcode `0x06` mixes scalar and cursor writers while sending 16 bytes. Normal opcode `0x32` sends nine bytes and, after the exact 16-bit write/overwrite sequence, sends zero at byte eight.
- The packet status byte is inherited `m_objectStatus.m_displayStatusByte`; status tagging uses `AllowsMovementStatusTag` plus the Config bit. Old movement-state/movement-speed and trailing-`0x32` interpretations are rejected without changing the helper family's score or source route.
