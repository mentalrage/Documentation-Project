## Behavior

This helper sends a short diagnostic text record through the normal packet-send path. IDA decompilation shows it:

- gets the MemoryMan singleton/context before building the stack packet buffer;
- measures the input text with `strlen`;
- rejects strings longer than `0xFFF` bytes after the `len - 1` check;
- writes packet fields `0x42`, `1`, a two-byte big-endian length, the source bytes, and a trailing zero byte;
- sends exactly `length + 5` bytes from the stack buffer through the active packet sender global.

The accepted payload shape is:

| Offset | Writer | Meaning |
| --- | --- | --- |
| `0` | `0x00575380(0x42, packet)` | diagnostic packet opcode |
| `1` | `0x00575380(1, packet+1)` | diagnostic text subtype |
| `2..3` | `0x005753a0(length, packet+2)` | ANSI byte length |
| `4..length+3` | `0x00516220(packet+4, text, length)` | copied diagnostic bytes |
| `length+4` | `0x00575380(0, packet+length+4)` | local trailing terminator included in send length |

Empty strings are rejected because the unsigned `length - 1` test fails. Accepted strings therefore have byte length `1..0xFFF`, and the queued packet length is `length + 5`.
