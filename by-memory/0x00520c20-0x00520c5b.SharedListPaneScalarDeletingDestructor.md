## Behavior

The wrapper saves `this`, calls the shared list cleanup helper at `0x004f3b60`, then interprets the scalar deleting destructor flag argument:

- no `flags & 1`: return the object without freeing it;
- `flags & 1` and no `flags & 4`: pass the object to the delete helper at `0x004f4ac0`, then return it;
- `flags & 4`: call the guard/check helper path with complete-object size `0x15c` / 348 bytes (Verified with `int_convert.py`), then return it.

The body does not restore a class-specific vtable and has no handwritten logic beyond emitted scalar-dtor flag handling.
