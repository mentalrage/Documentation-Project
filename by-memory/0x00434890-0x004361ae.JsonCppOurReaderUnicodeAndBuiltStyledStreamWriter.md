# JsonCpp OurReader Unicode And BuiltStyledStreamWriter

## Address Range

- `0x00434890-0x004361ae`
- Entity kind: third-party functions and one raw helper body.
- Disposition: ignored for NexusTK-owned reconstruction.
- Rebuild handling: `third-party/runtime`.

## Summary

This range continues the statically embedded JsonCpp reader/writer implementation after [UID:0000X9][0x004345f0-0x00434887.JsonCppNumberTokenParseHelper](by-memory/0x004345f0-0x00434887.JsonCppNumberTokenParseHelper.md). It covers `OurReader` unicode/error/comment helpers from `json_reader.cpp`, then `BuiltStyledStreamWriter` stream serialization helpers from `json_writer.cpp`.

The code should be supplied by the staged JsonCpp source snapshot, not rewritten as NexusTK product code. The immediately adjacent padding bytes are tracked in `by-memory/-ignored.md`; the following [UID:0001ZT][0x004361b0-0x00439df9.MsvcStlIostreamTemplateSupport](by-memory/0x004361b0-0x00439df9.MsvcStlIostreamTemplateSupport.md) support span is now classified as MSVC/Dinkumware STL/iostream template support.

## Evidence

- IDA MCP `py_eval` on 2026-05-27 lists the modeled functions from `0x00434890` through `0x00436177`; it also shows the raw `0x00436180` helper body followed by two `0xcc` bytes before `sub_4361B0`.
- IDA bytes for `0x00434887-0x00434890` are `cc cc cc`, confirming padding between [UID:0000X9][0x004345f0-0x00434887.JsonCppNumberTokenParseHelper](by-memory/0x004345f0-0x00434887.JsonCppNumberTokenParseHelper.md) and this range.
- IDA strings in this range include `additional six characters expected to parse unicode surrogate pair.`, `expecting another \\u token to begin the second half of a unicode surrogate pair`, `Bad unicode escape sequence in string: four digits expected.`, `Bad unicode escape sequence in string: hexadecimal digit expected.`, and `Line %d, Column %d`.
- Writer-side strings and behavior match upstream `json_writer.cpp`: object/array delimiters, comma/space handling, `writeArrayValue`, `isMultineArray`, `writeIndent`, `writeWithIndent`, comment-before/comment-after output, and `hasCommentForValue`.
- Source comparison uses [UID:0001QX][README](by-meta/obtained_thirdparty_files/README.md) staged `jsoncpp-b299d3581f4dc670734f1fe1a34fce1282337802`, specifically `src/lib_json/json_reader.cpp` and `src/lib_json/json_writer.cpp`.
