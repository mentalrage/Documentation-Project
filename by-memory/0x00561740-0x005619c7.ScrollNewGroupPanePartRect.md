## Geometry Details

### Horizontal Orientation

Horizontal mode is selected when `m_orientation != 0`. It uses `bounds.bottom - bounds.top` as `thumbExtent`.

- Part `0` / leading: copies `bounds` and sets `right = left`, producing a zero-width leading edge rectangle.
- Part `4` / trailing: copies `bounds` and sets `left = right`, producing a zero-width trailing edge rectangle.
- Enabled/range path requires `m_scrollEnabled != 0` and `m_scrollRange > 0`.
- Enabled/range thumb position is:
  - `thumbLeft = bounds.left + m_scrollPosition * (bounds.right - bounds.left - thumbExtent) / m_scrollRange`
  - `thumbRight = thumbLeft + thumbExtent`
- Part `2` returns `left = thumbLeft`, `right = thumbRight`.
- Part `1` returns the full bounds with `right = thumbLeft`.
- Part `3` returns the full bounds with `left = thumbRight`.
- Disabled or zero-range part `2` returns the middle track rectangle with `left += thumbExtent` and `right -= thumbExtent`.
- Disabled or zero-range parts `1` and `3` are zeroed to `(0,0,0,0)`.

Do not import the FittingRoom first-draft endcap shape here. This target's live disassembly collapses horizontal endcaps to edge-line rectangles instead of fixed-width arrow rectangles.

### Vertical Orientation

Vertical mode is selected when `m_orientation == 0`. It uses `kScrollPanePartExtentBySkin[m_scrollSkinIndex]` as the fixed extent.

- Part `0` / leading: copies `bounds` and sets `bottom = top`, producing a zero-height leading edge rectangle.
- Part `4` / trailing: copies `bounds` and sets `top = bottom`, producing a zero-height trailing edge rectangle.
- Enabled/range path requires `m_scrollEnabled != 0` and `m_scrollRange > 0`.
- Non-drag thumb top is `bounds.top + m_scrollPosition * (bounds.bottom - bounds.top - thumbExtent) / m_scrollRange`.
- Drag override path is active when `m_thumbDragActive != 0`: it computes `thumbTop = bounds.top + localCursorY - m_thumbDragOffset.y` and clamps it to `[bounds.top, bounds.bottom - thumbExtent]`.
- Part `2` returns `top = thumbTop`, `bottom = thumbTop + thumbExtent`.
- Part `1` returns the full bounds with `bottom = thumbTop`.
- Part `3` returns the full bounds with `top = thumbTop + thumbExtent`.
- Disabled or zero-range part `2` returns the middle track rectangle with `top += thumbExtent` and `bottom -= thumbExtent`.
- Disabled or zero-range parts `1` and `3` are zeroed to `(0,0,0,0)`.
