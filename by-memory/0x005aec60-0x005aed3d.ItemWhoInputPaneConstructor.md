## Behavior

This constructor builds the line-input base for the item "who" target prompt, installs the `ItemWhoInputPane` vtables, stores the item/action byte at object offset `+0x108`, and initializes the saved item target.

Initialization uses the current local player object as the fallback target. If the client option byte at `dword_67A7C8 + 2678380` is enabled, it copies the alternate saved target from `dword_69BF20`; otherwise it keeps `dword_69BF24`. The chosen object is looked up through the map pane, rejected if it is not a usable living target, highlighted, and its object id is written back to `dword_69BF24`.
