## Signature And Behavior

`void InventoryPane::GetSlotRect(short slot, RectBounds *bounds) const` writes the display rectangle for one zero-based visible slot. The binary loads only the low word of the first stack argument, zero-extends it for the range check, and sign-extends it for accepted-coordinate arithmetic:

- invalid indices below zero or at least 15 produce `(-1,-1,-1,-1)`;
- list mode maps 15 rows to `left=30`, `right=160`, `top=46+13*slot`, and `bottom=59+13*slot`;
- grid mode maps a 3x5 layout using `row=slot/3`, `column=slot%3`, `left=40+45*column`, `right=75+45*column`, `top=40+41*row`, and `bottom=75+41*row`.

The helper reads dword `InventoryPane::m_viewMode` at object offset `+0xfc`, writes only the caller-provided `RectBounds`, and has no independent resource, packet, allocation, receiver-write, or output-pointer null-guard side effect. Invalid, list, and grid paths select four edge locals and converge on exactly one free `InitRectBounds` call. The former valid-path `RectBounds::SetLTRB` draft is superseded because `SetLTRB` is a distinct real function and is not called by this body.
