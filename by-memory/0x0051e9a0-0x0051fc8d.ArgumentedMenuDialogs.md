## Ownership Decision

This is the argumented item-menu sibling of the text menu dialog family. It is packet-driven dialog UI, not generic popup-menu infrastructure. The list pane is owned by the dialog feature because it depends on the dialog's command type, owner id, selected item data, and description text slot. The helper functions at `0x0051f450`, `0x0051f510`, and `0x0051f640` should stay with the argumented menu/input dialog source family even though current Wave3 ownership is incomplete.
