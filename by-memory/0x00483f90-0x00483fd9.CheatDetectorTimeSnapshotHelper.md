## Behavior

The helper captures current system time, stores that 64-bit timestamp into `this + 0x08` / `this + 0x0c`, reads a timer/global value from `dword_67AB80 + 0x18`, stores that value into `this + 0x10`, writes the timer value to the first out-parameter, and writes the captured 64-bit timestamp to the second out-parameter.

The range starts after ten bytes of `0xcc` padding following the constructor and ends before seven bytes of `0xcc` alignment before the always-true virtual function at `0x00483fe0`.
