## Packet Layout Evidence

IDA MCP decompilation and raw disassembly show all three helpers build a ten-byte local packet and call [UID:0001HU][0x00574bb0-0x00574c13.QueueAndSendPacket](by-memory/0x00574bb0-0x00574c13.QueueAndSendPacket.md) through [UID:0000Q5][g_packetSender](by-global/g_packetSender.md). The packet fields are written through [UID:0001HZ][0x00575380-0x00575abb.PacketBufferHelpers](by-memory/0x00575380-0x00575abb.PacketBufferHelpers.md).

| Offset/source | Writer | Meaning in this helper family |
| --- | --- | --- |
| constant `0x3a` | `WriteByteZ_575380` / `sub_575380` | Dialog/message response opcode. |
| `this + 0x26c` | `WriteByteZ_575380` / `sub_575380` | Dialog type/subtype byte preserved from the pane state. |
| `this + 0x270` | `WriteUInt32BEZ_5753F0` / `sub_5753F0` | Dialog/session/object id dword. |
| `this + 0x274` | `WriteUInt16BEZ_5753A0` / `sub_5753A0` | Dialog state word preserved from the pane state. |
| `this + 0x276` | `WriteUInt16BEZ_5753A0` / `sub_5753A0` | Current page/index word; previous decrements it, next increments it, current sends it unchanged. |
| `dword_67A7EC` | `sub_574BB0` | Shared packet sender global used to queue the ten-byte packet. |

Each helper writes a trailing zero into the local packet buffer before sending; IDA reports the send size as `10`.

## Caller Evidence

IDA caller checks show these helpers are not private to `TextDialog`:

- `MessageDialog` and `MessageDialogLarger` action handlers call all three navigation forms.
- `MenuQuestionDialog` and `MenuQuestionDialogLarger` action handlers call the same helper family.
- `TextDialog::HandleDialogAction` calls previous/next/current helpers.
- `TextDialog::SendRegionSelectionPacket` calls the current helper when the supplied region name is invalid.
