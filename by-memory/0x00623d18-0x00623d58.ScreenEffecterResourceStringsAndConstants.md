# 0x00623d18-0x00623d58 ScreenEffecter Resource Strings And Constants

## Range

- Address range: `0x00623d18-0x00623d58`.
- Size: `0x40` / 64 bytes. Verified with `int_convert.py`.
- Entity kind: `resource-string/constant-data`.
- Rebuild handling: source-owned runtime effecter resource literals and numeric constants for [UID:0000IZ][Effects](by-file/Effects.md).
- Containing aggregate: [UID:00026C][0x00623480-0x00623d58.ScreenEffecterReadOnlyData](by-memory/0x00623480-0x00623d58.ScreenEffecterReadOnlyData.md).

## Evidence

Existing IDA-backed docs decode `0x00623d18-0x00623d40` as UTF-16LE `CAUST.EPF` followed by `CAUST.PAL`. The remaining `0x00623d40-0x00623d58` bytes hold the documented effecter constants `0x3f666666`, zero padding, `0x3fd0000000000000`, and `0x401921fb54442d11`.

The resource and constant xrefs remain in the runtime effecter code, not the generic UI dim/fade overlay code: the broad aggregate records water/caustic string refs around `0x0055b660`, `0x0055b6f8`, and `0x0055b715`, and constant refs at `0x0055b814`, `0x0055b9f6`, and `0x0055b3fa`. [UID:0001GE][0x0055a260-0x0055c1ff.ScreenEffecterRuntimeCluster](by-memory/0x0055a260-0x0055c1ff.ScreenEffecterRuntimeCluster.md) identifies the relevant users as the `WaterFilterEffecter`, wave, lake, and related runtime effecter paths under [UID:0000IZ][Effects](by-file/Effects.md).

B002's 2026-06-17 WaterFilterEffecter pass confirms `0x00623d2c` is the exact `L"CAUST.PAL"` literal passed by [UID:0001GF][0x0055b5d0-0x0055b698.WaterFilterEffecterUpdateCausticEffect](by-memory/0x0055b5d0-0x0055b698.WaterFilterEffecterUpdateCausticEffect.md) to [UID:00016A][0x004ba6b0-0x004ba81d.GrafPortDrawTiledBackground](by-memory/0x004ba6b0-0x004ba81d.GrafPortDrawTiledBackground.md). The constructor also preloads/resolves the same palette resource into the WaterFilterEffecter caustic palette field.

The next dword at `0x00623d58` is the `ScrollPane` complete-object-locator pointer and is intentionally excluded from this child.

## Assignment

Assign this exact child to [UID:0000IZ][Effects](by-file/Effects.md). This child clears `85/90`, and the direct file parent clears `89/85`, so the strict child/direct-parent gate is satisfied. It is not routed through [UID:0001YO][ScreenEffecterVtableFamily](by-type/by-vtable/ScreenEffecterVtableFamily.md) because this tail is resource and constant data rather than vtable-family data.
