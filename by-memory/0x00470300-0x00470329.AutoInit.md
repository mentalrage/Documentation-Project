## Behavior

`AutoInit::ScalarDeletingDestructor` resets the vtable, calls `OleUninitialize`, and optionally deletes the object when the scalar-deleting flag bit is set.

This is the virtual/scalar teardown side of a larger OLE lifetime pattern. The ordinary destructor body at `0x0046efe0` performs the same vtable reset and `OleUninitialize` call without the delete flag. The normal startup initializer at `0x00419ee0` calls `OleInitialize(0)` and registers the static shutdown thunk at `0x0060c0f0` through `atexit`.

## Reconstruction Notes

- This may be a platform/OLE helper or browser COM helper, but it is no longer missing initializer evidence. The confirmed initialization path is a startup initializer table entry, not a normal heap constructor call.
- Treat this function as the virtual/delete wrapper for the same destructor body documented in [UID:0000ZE][0x0046efe0-0x0046efeb.AutoInitNonDeletingDestructor](by-memory/0x0046efe0-0x0046efeb.AutoInitNonDeletingDestructor.md).
