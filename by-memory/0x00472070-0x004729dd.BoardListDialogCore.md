## Behavior

The constructor at `0x00472070` is a large board-category dialog initializer. It calls the `DialogInSession` constructor with mode/count arguments, stores primary and secondary `BoardListDialog` vtables at object offsets `0x0`, `0xa0`, and `0xa4`, reads packet data through byte-stream helpers, converts board names with `MultiByteToWideChar`, sets the dialog title through `0x0049db30`, allocates a 332-byte `BoardListPane`, and creates/adds several command controls.

`sub_472870` is the primary command dispatcher. Command id `1` selects/opens the current board by calling `sub_4728A0`; command id `2` closes or pops the dialog through the bulletin-session dialog-stack helper at `0x004a0f40`.

It writes through global packet/session pointer `dword_67A7EC`, marks the session object at `this + 0x270` active, stores this dialog at `dword_67A748 + 0x214` when the global exists, then calls `0x004a12b0`.

`sub_4729A0` updates button enabled state from board selection state. It obtains controls `1` and `3` through the control container at `this + 0x1fc`, asks `0x004f3e20` for current selection count/state, and tail-jumps through control virtual slots `+0x4c` or `+0x50`.
