- IDA MCP decompilation of `0x0041a580` computes `100 * this[2] / this[1]` when dword `+0x04` is nonzero and returns zero otherwise.
- IDA MCP callers/xrefs report one direct caller for `0x0041a580`: [UID:000050][FittingRoomDialog](by-class/FittingRoomDialog.md) at `0x0041cbbc`.
- The `HandleFittingAction` call passes `ecx = selected/request pointer + 4`, stores the returned byte in the preview/progress child at `+0x108`, refreshes the child when the percent changes, and treats values `>= 100` as completion/overflow.

- 2026-05-31 IDA MCP recheck confirms function sizes: `sub_41A550` size `0x14`, `nullsub_15` size `0x1`, `sub_41A580` size `0x12`, `sub_41A5A0` size `0x14`, and `nullsub_16` size `0x1`.
- 2026-05-31 IDA MCP xrefs confirm only `0x0041a580` has a direct code xref, from `0x0041cbbc` inside [UID:0002CT][0x0041cb70-0x0041cd38.FittingRoomDialogHandleFittingAction](by-memory/0x0041cb70-0x0041cd38.FittingRoomDialogHandleFittingAction.md).
