| Range | Role |
| --- | --- |
| `0x0041a550-0x0041a564` | Initializes/resets the 12-byte progress state by clearing byte `+0x00`, dword `+0x04`, and dword `+0x08`, then returning the receiver. |

| `0x0041a5a0-0x0041a5b4` | Duplicate initializer/reset body for the same 12-byte progress state shape. |
| `0x0041a5c0-0x0041a5c1` | One-byte no-op helper paired with the duplicate initializer/reset body. |

- Live callee scans report no callees for all five helpers.
- Live caller/xref scans report exactly one direct code xref in the island: the percent helper is called at `0x0041cbbc` inside [UID:0002CT][0x0041cb70-0x0041cd38.FittingRoomDialogHandleFittingAction](by-memory/0x0041cb70-0x0041cd38.FittingRoomDialogHandleFittingAction.md). The two reset helpers and two no-op helpers have no direct callers/xrefs in the current database.
- The live caller context loads the child control with id `7`, loads the request pointer from [UID:000050][FittingRoomDialog](by-class/FittingRoomDialog.md) offset `+0x704`, passes request offset `+0x04` as the progress-state receiver, stores the returned percent byte into child offset `+0x108`, invalidates the child when that byte changes, and treats values at or above `100` as terminal progress.
- Existing [UID:0001UI][FittingRoomDownloadProgressState](by-type/by-struct/FittingRoomDownloadProgressState.md) documents the same 12-byte layout: active byte at `+0x00`, total/denominator dword at `+0x04`, and current/numerator dword at `+0x08`.
