## Behavior Summary

These late virtuals are part of `ScrollablePane` even though they are far from the main `0x0055e660` constructor/layout cluster. The intervening addresses contain mixed `TextEditPane` scrollbar methods, so avoid documenting one broad `0x0055e660-0x00565608` class range as if it were contiguous ownership.

The scalar deleting destructor at `0x00565510-0x0056559a` is the source-bearing destructor wrapper for the `ScrollablePane` base: it tears down owned vertical/horizontal `ScrollPane` children, chains through the base `Pane` cleanup, and optionally frees storage based on the deleting-destructor flag. The two leading functions at `0x005654ec` and `0x005654f7` are vtable adjustor thunks into that destructor, not separate handwritten source methods.

The default virtuals define the base class contract for derived scrollable panes: content width/height default to zero, scroll range/offset outputs default to zeroed values, and `IsScrollable` returns true. Derived panes override these where they have real content extents.
