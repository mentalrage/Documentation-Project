## Behavior

The helper accepts a wide string from the selected clan-list row, computes its character length, writes packet header `{ 0x4b, 2, 1 }`, converts the wide string to a multibyte string, stores the multibyte length, appends the multibyte payload, and sends `length + 4` bytes through `dword_67A7EC`.

Range checks fail through `___report_rangecheckfailure` if the converted string reaches `0x100` bytes or if the final packet length reaches `0x80` bytes.

```cpp
int SendClanJoinListSelectionPacket(const wchar_t* clanName) {
    unsigned char packet[0x80];
    char name[0x100];

    const int chars = static_cast<int>(wcslen(clanName));
    WriteByte(packet[0], 0x4b);
    WriteByte(packet[1], 2);
    WriteByte(packet[2], 1);

    const int bytes = WideCharToMultiByte(0, 0, clanName, chars, name, sizeof(name), nullptr, nullptr);
    if (bytes >= 0x100 || bytes + 4 >= 0x80) {
        report_rangecheckfailure();
    }

    name[bytes] = 0;
    WriteByte(packet[3], bytes);
    memcpy(packet + 4, name, bytes);
    packet[bytes + 4] = 0;
    return QueueAndSendPacket(g_packetSender, packet, bytes + 4);
}
```
