## Behavior

Subtracts eight-byte source blocks from destination blocks across one or more rows using MMX `psubb`. The helper receives a source row pointer, source row pitch, destination row pointer, destination row pitch, eight-byte block count, and row count.

It converts the block count into a byte count, saves the integer register set, loads each destination qword, subtracts the source qword with `psubb`, stores the qword back to destination, advances source/destination by eight bytes inside a row, advances source/destination by their row pitches between rows, restores registers, and emits `emms`.
