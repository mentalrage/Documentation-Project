## Behavior And State Summary

- `ReleaseSurface` conditionally calls `IDirectDrawSurface::Release` through vtable slot `+0x08` on GrafPort `m_ddSurface` at `+0x18` and clears the pointer. It has no DirectX-global/device guard and does not free software backing.
- `SetSurfacePixelData` stores a borrowed `void *` into embedded `EPFTileContext::pixelData` at GrafPort `+0x20`.
- `SetSurfaceRowStride` stores logical `int rowStridePixels` at GrafPort `+0x28`; this is pixel count, not byte pitch.
- `GetOrigin` copies bounds left/top at `+0x2c/+0x30` into accepted `Point` x/y fields and returns the caller's output pointer in EAX.
- `SetOrigin` calls OffsetRect with `-(left+x)` and `-(top+y)`, producing absolute `left=-x`, `top=-y` while preserving width/height; historical OffsetViewOrigin wording is incorrect.
- `SetClipRegion` copies caller Region state into receiver-owned `m_clipRegion` at `+0x54`; `GetClipRegion` copies that state out; `SetClipRect` replaces it from caller RectBounds through Region SetRect.
- `DisableDrawing` and `EnableDrawing` write false/true to `m_drawEnabled` at `+0x71` without changing adjacent mode byte `+0x70`.
