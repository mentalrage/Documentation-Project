## Family Pattern

The two money submitters (`0x00488fe0` and `0x004890b0`) convert the submitted text to a numeric amount and send seven-byte packets:

- deposit money: `{ 0x4b, 0x04, 0x01, amount32 }`;
- withdraw money: `{ 0x4b, 0x0b, 0x01, amount32 }`.

The four name submitters (`0x00489180`, `0x004892b0`, `0x004893e0`, `0x00489510`) convert a submitted wide string to a multibyte buffer and send length-prefixed packets:

- expel name: subtype `0x07`;
- summon name: subtype `0x08`;
- appear name: subtype `0x09`;
- change name: subtype `0x0a`;
- all use action `0x01`, length byte at packet offset `+3`, and converted bytes starting at `+4`.

The raw constructor-shaped bodies between submitters all call [UID:00010J][0x00488b40-0x00488fa0.ClanNameInputDialogCore](by-memory/0x00488b40-0x00488fa0.ClanNameInputDialogCore.md), install derived vtables, and return `this`. IDA does not define those raw starts as functions and reports no xrefs to them, so the exact child constructor pages keep a reachability caveat.
