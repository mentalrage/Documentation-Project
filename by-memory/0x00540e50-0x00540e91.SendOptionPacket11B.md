# 0x00540e50-0x00540e91 - SendOptionPacket11B

## Status

- Confidence: strong for packet behavior and shared helper role.
- Related global: [UID:0000TL][SendOptionPacket11B_540E50](by-global/SendOptionPacket11B_540E50.md)
- Related file: [UID:0000M7][OptionPane](by-file/OptionPane.md)

## Behavior

This helper builds and queues a three-byte option packet:

| Offset | Value |
| --- | --- |
| `+0x00` | word opcode `0x011b` |
| `+0x02` | caller-provided option code |

The packet is sent through [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) by calling the common queue/send path at `0x00574bb0` with length `3`.
