## Behavior

This virtual paint method draws the three visible chat handle button regions from `CHATBUTT.EPF` with palette `CHATBUTT.PAL`:

- left button rectangle `(0, 4, 19, 21)`;
- middle-right button rectangle `(630, 4, 649, 21)`;
- right button rectangle `(649, 4, 668, 21)`.

Tile indices are derived from the current per-button paint-state indices at `this + 0x11c`, `+0x120`, and `+0x124`, then offset by the enabled/toggled bytes at `this + 0x111`, `+0x114`, and `+0x118`.

After drawing, the method writes a rendered-state snapshot:

- valid byte at `this + 0x0f8`;
- option bytes/dwords into `this + 0x0f9..0x10c`.

This snapshot is what `OnMouseEvent` compares before requesting repaint.
