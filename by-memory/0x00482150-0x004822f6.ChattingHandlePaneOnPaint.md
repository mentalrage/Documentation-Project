## Behavior

This virtual paint method initializes one stack `EPFTileContext` and one stack `RectBounds`, switches the pane into draw mode 0, and draws the three visible chat handle button regions from `CHATBUTT.EPF` with palette `CHATBUTT.PAL`:

- left button rectangle `(0, 4, 19, 21)` with frame `3 * m_leftButtonPaintState + (!m_chatTargetPending ? 9 : 0)`;
- middle-right button rectangle `(630, 4, 649, 21)` with frame `3 * m_modeButtonPaintState + (m_chatHandleModeIndex ? 1 : 10)`;
- right button rectangle `(649, 4, 668, 21)` with frame `3 * m_secondaryButtonPaintState + (m_secondaryChatEnabled ? 2 : 11)`.

This snapshot is what `OnMouseEvent` compares before requesting repaint.
