## Constructor And Dialog Layout

Existing owner pages describe `0x0053f2c0-0x0053f800` as the feature-specific constructor. It builds the friend-list editor dialog, selects the old/new asset mode, creates two columns of text edit controls, and preloads the 20 saved friend-name strings from config storage.

Observed source-level traits from linked IDA-backed docs:

- Feature assets are `FRIEND.EPF`/`FRIEND.PAL` in the EPF path and `FRIEND.EPD`/`NPAL8.PAL` in the fallback path.
- The fixed control model is 20 editable friend-name slots, not a generic dialog list.
- Constructor call sites are recorded as `0x0053e115`, `0x005a7112`, and `0x005bd151`; the corresponding containing caller functions are documented in the file page as dialog/menu flows at `0x0053ddb0`, `0x005a5bd0`, and `0x005bd000`.
- Adjacent `0x0053f940` starts [UID:0001DT][0x0053f940-0x0053fe87.ProfileDialog](by-memory/0x0053f940-0x0053fe87.ProfileDialog.md), so this page must remain a separate friend-list feature aggregate.

## OK Path Data Flow

`FriendListDialog::OnOkButton` is the write-back path for the dialog. Existing IDA-backed docs tie it to the friend-name sync protocol:

1. Iterate the 20 text controls.
2. Read each edited string and store it into the config string table beginning at `g_pConfig + 2691552`.
3. Save the updated settings.
4. Check [UID:0000PG][byte_66DEE0](by-global/byte_66DEE0.md) / `g_friendNameListSyncEnabled`.
5. If enabled, call [UID:0001HX][0x00574e50-0x0057536b.BuildAndSendFriendNameListSync](by-memory/0x00574e50-0x0057536b.BuildAndSendFriendNameListSync.md), formerly generated under the misleading inventory-data name; [UID:0000UP][FriendNameListSyncOpcodes](by-item/FriendNameListSyncOpcodes.md) documents it as the outbound opcode `0x77` friend/name-list upload helper.
6. Close the dialog after the save/send decision.

The packet helper reads the same 20 config slots, deduplicates nonempty names, emits a count byte, and serializes 13-byte name records. This proves the dialog, config storage, global flag, and packet helper are one social feature chain.
