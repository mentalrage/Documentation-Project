## Behavior

Destroys the embedded timer queue. It drains the queue count/start bookkeeping, frees each allocated scheduled-event record, frees the slot pointer array with the same MSVC aligned-allocation guard used by other container helpers, then frees the root/sentinel allocation and clears the root pointer.
