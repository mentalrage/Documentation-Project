# 0x0067a878-0x0067a934 AesMutableStateAndKeySchedule

## Summary

- Entity kind: AES mutable state / key schedule storage

This `.data` span stores the mutable AES/CBC scratch state used by the AES helper island at `0x00461790-0x00462114`: current block/key pointers, expanded AES-128 round keys, and CBC chaining state.

The current IDA-backed view of `0x0067a878-0x0067a934` is zero-filled. The range lies in the virtual tail of `.data`, so runtime wrappers overwrite the pointer fields and key expansion overwrites the schedule buffer before use.
