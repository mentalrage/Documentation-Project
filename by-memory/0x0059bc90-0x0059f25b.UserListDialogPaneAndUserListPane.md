## Behavior Summary

The aggregate covers the social user-list dialog family. `UserListDialogPane` builds high/low resolution layouts, creates five `UserListPane` children, parses incoming user-list rows, updates bucket/category counts, sorts by name or status, and processes selected-user/source updates. Keyboard handling changes categories with paging keys and supports selected-name copy behavior. Control handling closes the dialog, changes sort/category state, opens `PartySearchEditPane`, and toggles hidden-user visibility.

`PartySearchEditPane` is a user-list command subdialog for hunters-list/party-search settings. Its action handler toggles a checkbox state or sends opcode `0x84` using the shared packet helpers. `UserListPane` owns the row list behavior: fixed-size user-record rendering, selection notification, whisper/direct-message launch for the selected row, and double-click source/message actions.
