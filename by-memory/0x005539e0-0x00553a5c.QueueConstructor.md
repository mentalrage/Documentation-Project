## Behavior

`Queue::Queue` constructs the `LObject` base, installs the `Queue` vtable, stores the fixed slot byte size at `+0x04`, stores the slot count/wrap limit at `+0x08`, allocates `slotSize * slotCount` bytes through the client memory manager, and clears both read/write indices.

The current generated source reverses the field names for the first two arguments. IDA arithmetic shows `+0x04` is the byte stride and `+0x08` is the wrap limit.
