## Behavior

This confirmed action sends mail delete requests after the user accepts the delete confirmation alert.

The method reads the mail context pointer from `this+0x26c` and the multi-delete flag from `this+0x270`. When multi-delete is enabled, it resolves the selected-row list through the mail context provider at `context+0x1fc`, virtual slot `+0x10`, node id `7`, then enumerates up to 256 selected entries with `sub_4F3E80` and sends one delete packet per row. When multi-delete is not enabled, it serializes one packet from the active selected mail pointer at `context+0x270` and the stored reply/delete id at `context+0x274`.

Each packet uses opcode `0x3b`, subcommand `0x05`, two 16-bit ids, and `sub_574BB0(dword_67A7EC, packet, 6)`. After packet serialization, the action stores the mail context into `dword_67A748+0x214` when the player-data global is present, then calls the mail/bulletin queue refresh helper with `ECX` loaded from `context+0x270`.
