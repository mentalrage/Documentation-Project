## Behavior

Overrides base insertion to preserve hierarchy links. It records the old count, delegates to the base insert-at routine, then calls [UID:0002IL][0x004ced10-0x004ceda4.HierListUpdateHierarchy](by-memory/0x004ced10-0x004ceda4.HierListUpdateHierarchy.md) for the shifted trailing range when insertion occurs before existing elements.

Step order:

1. Save the insertion index in `ebx` and load the old `List` count from `this + 0x0c`.
2. Call the base [UID:00022S][0x004f3140-0x004f35fd.ListCoreMethods](by-memory/0x004f3140-0x004f35fd.ListCoreMethods.md) insert method at `0x004f32e0` as `List::InsertAt(index, count, source)`.
3. If the old count was less than or equal to the insertion index, return immediately; appending at or past the old tail does not shift existing nodes.
4. If old rows were shifted, compute the repair start as `index + count` and the repair end as `newCount - 1`.
5. Call [UID:0002IL][0x004ced10-0x004ceda4.HierListUpdateHierarchy](by-memory/0x004ced10-0x004ceda4.HierListUpdateHierarchy.md) with clear flag `0`, so shifted child-list owner links and child node parent links point at their new row addresses.

The inserted row bytes are supplied by the caller. This method repairs only the old rows shifted behind the inserted block; initialization of the inserted hierarchy row is handled by the insertion helpers that build the source row.
