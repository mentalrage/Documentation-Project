## Behavior

This virtual deleting destructor performs the `ItemObjImageLib` cleanup and then conditionally frees `this` according to the incoming destructor flags.

The body restores the `ItemObjImageLib` vtable, restores the embedded `ProtectedArray<ItemInfo>` vtable at `this + 0x04`, frees the item-info entry buffer at `this + 0x0c`, clears [UID:0000RA][g_pItemObjImageLib](by-global/g_pItemObjImageLib.md), runs the base `LObject` cleanup helper, and calls the object delete helper only when the scalar-delete flag is set and the no-delete/vector flag is clear.
