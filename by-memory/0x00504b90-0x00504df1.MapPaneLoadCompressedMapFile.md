## Behavior

This method tries to load the per-map `.cmp` cache file from the user's Documents folder. It creates or accepts the `NexusTK` and `NexusTK\Maps` directories, formats `TK%06d.cmp` from the supplied map id, checks that the file exists, opens it with the `StdioFile` wrapper, validates the `CMAP` signature and cached width/height, and then reads the remaining compressed payload into a local `_AUTOBUF<unsigned char>`.

When the file is valid, it first allocates and zeroes the receiver's tile storage, reads the compressed payload, computes the expected output byte count as `6 * width * height`, and calls bundled zlib `uncompress` into the receiver's tile buffer. When the file is missing or the header/dimensions fail validation, it allocates the same zeroed storage instead. Earlier Documents/directory failures preserve the prior receiver state; older broad "failure resets storage" wording is superseded.
