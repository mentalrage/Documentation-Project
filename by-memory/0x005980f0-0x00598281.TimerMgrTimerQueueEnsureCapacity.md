## Behavior

Ensures the queue slot pointer array has capacity for the requested number of additional entries. It doubles capacity until enough open slots exist and the capacity is at least eight, allocates a new pointer array, preserves the wrapped ring layout around the current start index, zeroes newly opened holes, frees the previous slot array with MSVC aligned-allocation validation, then updates the queue pointer and capacity.

This function reallocates the slot pointer array, not the 20-byte scheduled-event records themselves.
