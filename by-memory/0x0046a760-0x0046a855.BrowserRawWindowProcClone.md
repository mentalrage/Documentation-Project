# 0x0046a760-0x0046a855 Browser Raw Window Proc Clone

## Scope

- Range: `0x0046a760-0x0046a855`
- Entity kind: raw function-like browser window procedure plus switch tables
- Current owner: browser-adjacent code, exact class/function owner open
- Disposition: retained raw WndProc clone; behavior is reconstructable, but current reachability is unproven
- Rebuild handling: source-authored browser/Win32 message behavior, but likely not a required separate live WndProc unless later constructor/table evidence points at this raw start
- Completion: 65%
- Confidence: medium overall; strong for range, behavior, and current unreferenced status; weak for final owner/reachability

## Behavior

The bytes at `0x0046a760` form a complete `LRESULT CALLBACK`-style function body even though IDA has not created a function record there.

- Uses the `/GS` security cookie prologue/epilogue.
- Handles `WM_PAINT` with `BeginPaint` and `EndPaint`, then returns `0`.
- Handles `WM_SYSCOMMAND` by consuming command classes `0xF000`, `0xF010`, `0xF020`, `0xF030`, and `0xF060`.
- Delegates other messages to `DefWindowProcA`.
- Unlike [UID:00020V][0x0046a630-0x0046a6ea.BrowserWindowHostWndProc](by-memory/0x0046a630-0x0046a6ea.BrowserWindowHostWndProc.md), this body does not test `GetWindowLongA(hwnd, GWL_USERDATA)` before dispatch.
