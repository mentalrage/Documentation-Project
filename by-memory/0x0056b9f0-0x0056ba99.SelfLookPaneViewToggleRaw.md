## Behavior

This helper toggles a SelfLookPane view/cache byte and then reattaches or redraws the pane against the main UI layer contexts. It has a normal stack-cookie prologue but no IDA-modeled function object; `ecx` is the `SelfLookPane` instance and there is no stack packet argument in this body.

The first action flips `this+0x233c`: a previous zero becomes `1`, and any non-zero value becomes `0`. After that it calls three pane virtuals. The first call is vtable slot `+0x38`; the second call is slot `+0x2c` with a stack rectangle and a zero flag; the third call is slot `+0x30` with the same stack rectangle, zero, [UID:00028J][0x0067a740-0x0067a744.g_pBackPane](by-memory/0x0067a740-0x0067a744.g_pBackPane.md) / `dword_67A740`, and [UID:0000T6][MainUiLayerSlots](by-global/MainUiLayerSlots.md) slot `dword_69B368`. It then invalidates `this+0x44` through vtable slot `+0x20`.

The trailing branch depends on `this+0x2328`. When that field is zero, the three dword stores at `this+0x16fc`, `this+0x1704`, and `this+0x1708` overlap the exact class layout rather than four independent members: together they clear the fourteen visible equipment hover bytes for slots `7..20` and the first wide character of `m_identityLine1`. Source represents that as a bounded `memset` plus `m_identityLine1[0] = L'\0'`. When the field equals `2`, it calls `sub_55E990` on the [UID:000074][LegendPane](by-class/LegendPane.md) child at `this+0x104`; that callee is represented as `RefreshScrollState()`. Other non-zero modes skip both branches but still return through compiler cookie handling.

Nearby modeled `SelfLookPane` view methods confirm the meaning of the `this+0x2328` mode field used by this raw helper. `0x00567200` stores mode `0` and refreshes both `LegendPane` and `SpelledPane`; `0x00567280` stores mode `1` and refreshes the legend child; `0x00567380` stores mode `2`, refreshes the `SpelledPane` and `LegendPane` children, attaches the legend pane to `dword_69B368`, and invalidates `this+0x44`. This makes the raw helper's mode-zero cache clear and mode-two `sub_55E990` branch source-local `SelfLookPane` view/cache logic rather than an isolated generic UI helper.
