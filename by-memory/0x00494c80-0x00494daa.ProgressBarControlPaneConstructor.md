## Behavior

1. Builds the inherited `ControlPane` base with control type `22` and the incoming bounds pointer.
2. Installs the primary, secondary, and tertiary `ProgressBarControlPane` vtable views at object offsets `+0x00`, `+0xa0`, and `+0xa4`.
3. Clamps the lower/range-start argument: negative values become `0`; values above `30000` become `30000`.
4. If object offset `0xf8` differs from the clamped lower value, it raises current field `0xfa` to that lower value when current is smaller, calls the inherited refresh/invalidation helper for the pane rectangle at object offset `0x44`, then stores the lower field and dispatches vtable slot `+0x20`.
5. Clamps the upper/range-end argument by the same `0..30000` rule.
6. If object offset `0xfc` differs from the clamped upper value, it lowers current field `0xfa` when current is above the new upper value, dispatches vtable slot `+0x20`, stores the upper field, and dispatches the same slot again.
7. If current field `0xfa` is nonzero after range setup, it writes `0` and dispatches vtable slot `+0x20` with the pane rectangle at object offset `0x44`.
8. Returns the receiver with `retn 0x0c`.
