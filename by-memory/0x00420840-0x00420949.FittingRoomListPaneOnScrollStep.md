## Behavior

Handles continuous scroll-step actions for the embedded list/scroll control. Direction `1` decrements the current scroll index and clamps to zero; direction `2` increments and clamps to the scrollbar maximum. When the value changes, the method mirrors the value into the list pane, invalidates the scroll child if needed, updates the list scroll bar, invalidates the list pane, and schedules a repeat timer with a `50` ms interval.
