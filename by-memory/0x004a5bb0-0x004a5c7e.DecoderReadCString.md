## Behavior

Scans the input stream from the current cursor until it finds a NUL byte, copies the non-NUL multibyte bytes into a temporary heap buffer, adds a scratch NUL terminator, advances cursor by `byteLength + 1`, converts the temporary multibyte string into the caller's UTF-16 output with `MultiByteToWideChar(0, 0, ...)`, frees the temporary buffer, validates the produced wide length against caller capacity, writes a wide terminator, and optionally stores the produced count.

The method clears the output buffer and optional count on entry. It clears valid flag `+0x11` when the scan reaches past the input limit without finding a terminator or when the produced wide length exceeds caller capacity.
