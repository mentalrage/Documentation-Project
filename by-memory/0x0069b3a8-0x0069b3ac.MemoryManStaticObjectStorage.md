# 0x0069b3a8-0x0069b3ac MemoryMan Static Object Storage

## Status

- Disposition: reconstructable source-declared static object storage.
- Entity kind: static/global class instance storage.
- Confidence: strong for address, constructor, destructor/reset thunk, and owner.
- Proposed owner: [UID:0000L7][MemoryMan](by-file/MemoryMan.md).

## Interpretation

This dword is the static `MemoryMan` object constructed by [UID:0000WA][0x00419f70-0x00419f86.MemoryManStaticInitializer](by-memory/0x00419f70-0x00419f86.MemoryManStaticInitializer.md). The reset thunk at [UID:0001O7][0x0060c260-0x0060c26a.MemoryManAtexitResetThunk](by-memory/0x0060c260-0x0060c26a.MemoryManAtexitResetThunk.md) passes the same address into the MemoryMan reset tail.

The source rebuild should declare the static `MemoryMan` object in the MemoryMan source family and let compiler static-lifetime code emit the startup/atexit glue.

## Evidence

- IDA MCP decompilation of `0x00419f70` loads `ecx = &dword_69B3A8`, calls the MemoryMan constructor at [UID:0001B9][0x00516000-0x0051600f.MemoryManConstructor](by-memory/0x00516000-0x0051600f.MemoryManConstructor.md), and registers the reset thunk.
- IDA MCP decompilation of `0x0060c260` loads `ecx = &dword_69B3A8` and jumps to the MemoryMan reset tail.
- Existing owner docs in [UID:0000L7][MemoryMan](by-file/MemoryMan.md), [UID:00007U][MemoryMan](by-class/MemoryMan.md), and [UID:0000RH][g_pMemoryMan](by-global/g_pMemoryMan.md) already identify this static object.
