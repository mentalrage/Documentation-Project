## Behavior

The function takes an attachment registry/list-owner object as `this` and the destroyed attached object as its argument.

| Attached object type | Registry action |
| --- | --- |
| `2` | Search list at registry `+0x170`; remove the matching object with delete/remove flag `1`. |
| `4` | Search list at registry `+0x174`; remove the matching object with delete/remove flag `1`. |
| `6` | Clear registry slot `+0x1d8`. |
| `7` | Clear registry slot `+0x1dc`. |
| `8` | Clear registry slot `+0x1e0` only when [UID:0000SW][g_useEpfAssets](by-global/g_useEpfAssets.md) / `byte_66DA97` is `1`. |
| `9` | Clear registry slot `+0x1e4`. |
