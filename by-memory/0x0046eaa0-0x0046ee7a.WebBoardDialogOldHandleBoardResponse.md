## Behavior Notes

- The handler reads byte-length-prefixed fields from the old web-board response payload after the leading packet byte.
- It copies the URL field into `szUrl`, copies the selected navigation target into `MultiByteStr`, and copies the query/cookie data field into a 256-byte buffer.
- It scans the query/cookie data for `=` and `&`, extracts the value between them into a 128-byte cookie buffer, then calls `InternetSetCookieA(szUrl, "domain", value)`.
- On first use, it initializes the old WebBoardDialog escape table using `byte_67ACB0` as the guard and `byte_67ACB8[256]` as the lookup table. The old table marks non-printable/out-of-range bytes and the old reserved URL character sets documented at [UID:000214][0x0046ee80-0x0046efda.WebBoardDialogOldUrlEscapeHelper](by-memory/0x0046ee80-0x0046efda.WebBoardDialogOldUrlEscapeHelper.md) and [UID:000278][0x0066d430-0x0066d468.BrowserUrlEscapeCharacterSets](by-memory/0x0066d430-0x0066d468.BrowserUrlEscapeCharacterSets.md).
- It percent-escapes marked boardinfo bytes through the `%%%2X` format path, copies unmarked bytes directly, terminates the 1024-byte output buffer, then calls `InternetSetCookieA(szUrl, "boardinfo", escapedValue)`.
- Before navigation, it converts `szUrl` to UTF-16, copies it into the embedded browser-control state at offset `+300`, clears the following word at offset `+810`, converts the selected navigation target to UTF-16, and calls `0x0046bd30` with the browser-control pointer at `this[155]`.
- Successful paths return `1`; oversized conversions/copies branch to the compiler range-check failure path.
