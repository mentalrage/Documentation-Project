## Behavior

This method handles browser notification payloads delivered through the `0x42726f73` / `Bros` channel. The argument is a notification block whose channel is read from `Block+0x08` and whose payload pointer is read from `Block+0x0c`.

When the payload state at `payload+0x04` is `0`, the handler sets the ScreenPane byte at `+0x511` to `1` and returns handled. When the payload state is `1`, it clears `+0x511`, closes the legacy browser dialog singleton if [UID:0002AE][0x0067ab90-0x0067aba4.BrowserAndWebBoardDialogSingletons](by-memory/0x0067ab90-0x0067aba4.BrowserAndWebBoardDialogSingletons.md) `dword_67AB90` is non-null, and, if the payload string at `payload+0x08` is not empty, allocates a `0x270`-byte alert pane using [UID:00012W][0x0049feb0-0x004a0686.AlertPaneCore](by-memory/0x0049feb0-0x004a0686.AlertPaneCore.md) with parent/context [UID:00028J][0x0067a740-0x0067a744.g_pBackPane](by-memory/0x0067a740-0x0067a744.g_pBackPane.md) and the shared [UID:0001OC][0x00613a18-0x00613a1e.DialogOkButtonString](by-memory/0x00613a18-0x00613a1e.DialogOkButtonString.md) `OK` button label. Other payload states return the carried high byte from the stack argument as IDA currently models it; non-`Bros` channels return `0`.
