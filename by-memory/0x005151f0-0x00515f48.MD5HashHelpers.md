## Behavior Notes

- The MD5 context layout appears to be `state[4]`, `bitCount[2]`, a 64-byte block buffer, and final digest storage.
- The wrappers initialize the standard MD5 state constants: `0x67452301`, `0xefcdab89`, `0x98badcfe`, and `0x10325476`.
- `Md5Update` converts byte length into bit count, preserves partial blocks, and routes full 64-byte blocks through `Md5Transform`.
- `Md5Final` appends the static MD5 padding table near `0x0066ddd8`, appends the 8-byte bit count, copies out the digest, and zeroes the context.
- Hex-returning wrappers allocate their return strings with `_strdup`; existing callers free those strings after use.
- `Md5StreamHex` returns a fixed fallback literal when the input stream is null. The literal should be preserved until all callers are audited.
