## Behavior

This helper blends two packed RGB565 pixels at once. `a1` and `a2` are 32-bit values containing two adjacent 16-bit RGB565 pixels, and `a3` is a 0..32 blend weight. The function computes the inverse weight as `32 - a3`, masks the packed green lanes and packed red/blue lanes separately, applies the two weights, shifts the accumulated values back down by five, and recombines the packed result.

Unlike [UID:00016M][0x004c6050-0x004c60c7.BlendRgb565Pixel](by-memory/0x004c6050-0x004c60c7.BlendRgb565Pixel.md), which returns one 16-bit blended RGB565 color, this helper performs the same weighted blend across two pixels in one 32-bit register.
