# 0x0061a8b8-0x0061a920 GrafPort SurfaceDesc String Data

## Range

- Address range: `0x0061a8b8-0x0061a920`.
- Entity kind: `diagnostic-string-data`.
- Disposition: reconstructable source-declared string literal.
- Rebuild handling: `source-declared/generated-binary`.
- Owner: [UID:0000JR][GrafPort](by-file/GrafPort.md).
- Containing `.rdata` aggregate: [UID:00025F][0x0061a7e0-0x0061aad4.FrameGrafPortReadOnlyData](by-memory/0x0061a7e0-0x0061aad4.FrameGrafPortReadOnlyData.md).

## Summary

This exact child range contains the UTF-16 diagnostic format string used by `GrafPort::UpdateRenderRegion` while reporting DirectDraw surface dimensions:

`surfaceDesc.dwWidth : %d, surfaceDesc.dwHeight : %d`

The string starts at `aSurfacedescDww` and ends at its UTF-16 null terminator immediately before the software-render mask constants at `0x0061a920`.

## IDA Evidence

- 2026-06-03 IDA MCP `py_eval` decodes `0x0061a8b8-0x0061a920` as the UTF-16 string `surfaceDesc.dwWidth : %d, surfaceDesc.dwHeight : %d`.
- IDA MCP xref scan reports the direct reference from `0x004b9464` inside [UID:000160][0x004b8bf0-0x004bb8c4.GrafPort](by-memory/0x004b8bf0-0x004bb8c4.GrafPort.md), specifically the `GrafPort::UpdateRenderRegion` body at `0x004b8e20`.
- The next named item at `0x0061a920` is `xmmword_61A920`, which starts the shared software-render constant table.
- 2026-06-07 IDA MCP `py_eval` reconfirmed the decoded UTF-16 string, the leading dword `0x0061a8b8 -> 0x00750073`, the tail dword before the terminator at `0x0061a91c`, and the next constant-table dword `0x0061a920 -> 0x000003e0`.
- The 2026-06-07 xref pass reconfirmed a single code reference from `0x004b9464` inside `GrafPort::UpdateRenderRegion` (`0x004b8e20-0x004b94e1`). Broader xrefs to `UpdateRenderRegion` are ordinary callers or vtable/data refs to the function, not owners of this literal.

## Reconstruction Notes

Regenerate this data as a normal wide string literal in `GrafPort`/surface-update diagnostics. Do not model it as a standalone binary blob.
