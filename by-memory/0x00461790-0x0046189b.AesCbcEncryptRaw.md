# 0x00461790-0x0046189b AesCbcEncryptRaw

## Behavior

This raw wrapper copies an initial 16-byte block from input to output, optionally rebuilds the AES-128 key schedule when a key pointer is supplied, and then processes `ceil(length / 16)` blocks.

For each full block it XORs the input block with the current chaining block, copies the result into the output block, sets `0x0067a878` to that output block, calls the AES block encrypt helper at `0x004619c0`, and advances the chaining pointer to the encrypted output block.

If `length & 0x0f` is nonzero after the loop, the tail path copies a final partial block, zero-fills the remaining bytes to a 16-byte block, and encrypts it.
