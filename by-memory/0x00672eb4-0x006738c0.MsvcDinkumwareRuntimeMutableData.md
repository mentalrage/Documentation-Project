# 0x00672eb4-0x006738c0 MSVC/Dinkumware Runtime Mutable Data

## Summary

- Address range: `0x00672eb4-0x006738c0`
- Entity kind: MSVC CRT/Dinkumware mutable runtime state
- Disposition: ignored for NexusTK source reconstruction
- Rebuild handling: emitted/provided by the compatible MSVC runtime and compiler support
- Confidence: strong for runtime ownership; medium for every anonymous slot's exact CRT field name

This range is mutable runtime support data after the zlib 1.1.4 `.data` table island and before compiler-generated RTTI. It includes a Dinkumware copyright/runtime lead-in, the MSVC stack-cookie global, CRT option and startup slots, thread-local storage state, locale/ctype buffers and pointer clusters, and console-output runtime state. It is compiler/runtime material, not NexusTK product-owned global state.
