## Ownership Decision

This neighborhood is a real chat UI block, not an arbitrary address span. It groups the chat display, handles, selector popups, color picker, and colored chat message object.

The `FolderTreePane` subset should remain explicitly marked as a boundary question for chat-message ownership. Its methods are chat-specific in behavior, but current Wave3 and earlier Wave2 records attach them to `FolderTreePane`. The real filesystem tree-control core is now documented separately in [UID:0000JG][FolderTreePane](by-file/FolderTreePane.md), and these chat methods should not be migrated into that source without a focused ownership review.
