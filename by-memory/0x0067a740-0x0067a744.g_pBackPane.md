# 0x0067a740-0x0067a744 g_pBackPane

## Summary

- Address range: `0x0067a740-0x0067a744`
- Entity kind: global data pointer
- Current IDA name: `dword_67A740`
- Proposed source name: `g_pBackPane`
- Disposition: reconstructable project global
- Confidence: strong for BackPane ownership; medium for final source-facing name

This four-byte zero-initialized `.data` global stores the process-wide root/backdrop `BackPane` pointer. Many pane and dialog constructors read it as their parent/context pointer. Some generated code has misleading aliases such as `g_pReconnectServer`; those names should be replaced when confidence is high enough.

## Storage And Lifetime

| Address | Initial value | Role |
| --- | --- | --- |
| `0x0067a740` | `0x00000000` | current root `BackPane*` / pane parent context |

Observed lifetime anchors:

- `0x00467878` inside `BackPane::BackPane` stores the constructed root pane pointer into `dword_67A740`.
- `0x0046787f`, `0x0046793d`, `0x00467a50`, and `0x00467ad4` clear it through constructor-null/destructor/singleton-clear paths.
- Broad UI constructor xrefs push or move this global as a parent/context argument into pane/dialog construction helpers.
