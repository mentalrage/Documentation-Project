## Boundary And Padding

## Behavior Summary

- Rejects work while the global draw-suspend byte is set.
- In legacy mode, opens `TILEC.TBD` to clamp out-of-range static-object ids to zero.
- Looks up the [UID:0001W8][StaticObjEntry](by-type/by-struct/StaticObjEntry.md) from `this+0x0c` using `staticObjectId - 1`.
- Uses entry byte `+0x05` as the layer/tile-id count and walks tile ids from the end of the inline list at `+0x0c`.
- Resolves each tile frame through `LoadFrameDrawRecord_4D1600`, selects palette slot `1` through `PaletteLib`, and dispatches through [UID:0000TN][SurfaceRenderCallbackTable](by-global/SurfaceRenderCallbackTable.md).
- Applies highlight/translated-clip behavior using configuration/map state, and calls [UID:0000UH][DrawEncodedAlphaFrame_00462F20](by-item/DrawEncodedAlphaFrame_00462F20.md) when the caller supplied an overlay mask output.
- IDA MCP 2026-06-01 decompilation confirms the legacy `TILEC.TBD` clamp path: when `byte_66DA97 != 1`, the function opens `TILEC.TBD`, reads a 32-bit count, and clamps out-of-range static-object ids to zero.
- IDA MCP 2026-06-01 decompilation confirms the main render loop walks the inline tile-id list from the last layer toward the first, advances the destination Y position by `word_66DAA0` per layer, loads each tile frame through `0x004d1600`, and skips empty frame records.
- IDA MCP 2026-06-01 decompilation confirms the palette/render path resolves palette slot `1`, calls the surface render callback at `dword_69B3E8`, temporarily swaps a target-surface field for translated/highlight rendering, and calls `0x00462f20` only when the optional overlay-mask output pointer is non-null.
