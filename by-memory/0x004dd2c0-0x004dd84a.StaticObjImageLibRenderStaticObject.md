## Behavior Summary

- Initializes a local frame/tile draw record before testing the shared image-library load-error/render-suspend byte. If that byte is set, the method returns the low byte of the initialized local record pointer instead of returning a normalized false value.
- In legacy mode, opens `TILEC.TBD` to clamp out-of-range static-object ids to zero.
- Returns `0` for invalid object paths: resolved id zero, id outside `staticObjCount`, or null static-object entry.
- Looks up the [UID:0001W8][StaticObjEntry](by-type/by-struct/StaticObjEntry.md) from `this+0x0c` / `staticObjEntries` using `staticObjectId - 1`.
- Uses `StaticObjEntry::layerCount` at entry byte `+0x05` and walks `StaticObjEntry::tileIds` from the end of the inline list at `+0x0c`.
- Resolves each tile frame through `LoadFrameDrawRecord_4D1600`, applies `TileClassEntry::tileFrameId` and `TileClassEntry::allowPaletteFilter`, selects palette slot `1` through `PaletteLib`, and dispatches through [UID:0000TN][SurfaceRenderCallbackTable](by-global/SurfaceRenderCallbackTable.md).
- Applies highlight/translated-clip behavior using configuration/map state, and calls [UID:0000UH][DrawEncodedAlphaFrame_00462F20](by-item/DrawEncodedAlphaFrame_00462F20.md) when the caller supplied an overlay mask output.
- IDA MCP 2026-06-01 decompilation confirms the legacy `TILEC.TBD` clamp path: when `byte_66DA97 != 1`, the function opens `TILEC.TBD`, reads a 32-bit count, and clamps out-of-range static-object ids to zero.
- IDA MCP 2026-06-01 decompilation confirms the main render loop walks the inline tile-id list from the last layer toward the first, advances the destination Y position by `word_66DAA0` per layer, loads each tile frame through `0x004d1600`, and skips empty frame records.
