## Behavior

The callback receives `this` in `ecx`. It reads the owner dialog pointer at `this + 0x26c`, calls the alert virtual slot at `+0x18` to close/hide the alert, then asks the owner's session field at `owner + 0x270` for the dialog below the owner by calling `0x004a1250`.

It fetches control id `7` from the returned dialog's control container at `+0x1fc`, follows the selected-control payload through `+0x108`, reads the selected 16-bit article id at `+0x14c`, and calls article navigation helper `0x004751c0` with that id, limit `0x7fff`, and a mode/layout offset from `byte_66DA97`: `-0x14` for mode `1`, otherwise `-0x10`.

If the alert flag at `this + 0x270` is `1`, it calls `0x004a10e0` on the owner's session with argument `0` to pop/close the session dialog.
