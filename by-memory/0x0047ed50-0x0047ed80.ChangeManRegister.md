## Behavior

`ChangeMan::Register` builds a 16-byte [UID:0001TV][ChangeManEntry](by-type/by-struct/ChangeManEntry.md) on the stack and inserts it into the sorted registration list.

| Entry offset | Stored value |
| --- | --- |
| `0x00` | owner pointer |
| `0x04` | listener pointer |
| `0x08` | scope/all-messages byte |
| `0x0c` | message type/filter value |

The public caller path is [UID:000198][0x004f4b30-0x004f4b4c.ApplicationRegisterChangeListener](by-memory/0x004f4b30-0x004f4b4c.ApplicationRegisterChangeListener.md), which supplies the application wrapper `this` pointer as the owner argument and then forwards the listener, message, and scope/filter byte.

void ChangeMan::Register(void *owner, ChangeListener *listener, int messageType, bool allMessages)
{
    ChangeManEntry entry;
    entry.owner = owner;
    entry.listener = listener;
    entry.allMessages = allMessages;
    entry.messageType = messageType;
