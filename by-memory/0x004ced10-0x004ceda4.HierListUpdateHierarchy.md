## Behavior

Repairs parent pointers in an inclusive range of `HierList` rows after insert, remove, or swap operations. For each row, it finds the [UID:0001UQ][HierListNode](by-type/by-struct/HierListNode.md), checks whether the node owns a child list, updates the child list's owner pointer, and then walks every child node so its parent pointer agrees with the row's current address.

Step order:

1. Return immediately when `startIndex > endIndex`.
2. For each row index from `startIndex` through `endIndex`, call base `List::At(index)` at `0x004f32b0` to get the `HierListNode`.
3. Read `node + 0x04` as the optional child `HierList*`.
4. If the node has no child list, skip to the next row.
5. Set `childList + 0x14` to either the current node pointer or null, depending on whether `clearFlag == 1`.
6. Read the child list count from `childList + 0x0c`.
7. For each child row, call base `List::At(childIndex)` on the child list and write either the current parent node or null to the child node's `+0x00` parent field.
8. Continue through the inclusive range and return the first index after the processed range.

The helper assumes callers pass valid row ranges. There is no local null guard after `List::At(this, index)`; the surrounding insert/remove/swap wrappers compute ranges from known valid indices/counts.
