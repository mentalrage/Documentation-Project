# 0x0067a7d8-0x0067a7dc g_pMiniMapDownloader

## Summary

- Address range: `0x0067a7d8-0x0067a7dc`
- Entity kind: global pointer
- Proposed name: `g_pMiniMapDownloader`
- Disposition: reconstructable NexusTK global data

This four-byte zero-initialized global stores the active `MiniMapDownloader` worker singleton pointer. It is set by the worker constructor and cleared by destructor/clear helper paths.
