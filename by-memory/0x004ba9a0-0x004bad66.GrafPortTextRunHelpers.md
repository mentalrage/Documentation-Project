## Evidence Notes

- IDA MCP on 2026-05-25 confirms the function starts/sizes for every covered function and reports broad caller sets for `MeasureTextWidth`, `MeasureStringWidth`, `GetLineHeight`, `DrawWideText`, and `DrawOutlinedText`.
- IDA MCP lookup on 2026-06-01 confirms exact boundaries: `0x004ba9a0` size `0xc7` ending at `0x004baa67`, `0x004baa70` size `0x2e` ending at `0x004baa9e`, `0x004baaa0` size `0x25` ending at `0x004baac5`, `0x004baad0` size `0x42` ending at `0x004bab12`, `0x004bab20` size `0x4c` ending at `0x004bab6c`, `0x004bab70` size `0x158` ending at `0x004bacc8`, and `0x004bacd0` size `0x97` ending at `0x004bad67`. The page filename uses the project convention's last-byte-style suffix for the aggregate end.
- The `0x004ba9a0` decompile constructs a [UID:0000E7][StringIter](by-class/StringIter.md) over the caller-provided length, reads the GrafPort font id at `this[69]`, calls the `dword_67AB24` FontImageLib glyph-measure helper for each glyph, accumulates advances, and destroys the iterator before returning the total width.
- The `0x004baa70` decompile is the null-terminated overload: it computes `wcslen(text)` and forwards to `0x004ba9a0`.
- The `0x004baaa0` decompile calls the `dword_67AB24` FontImageLib metrics helper with `this[69]` and returns the line-height/metric value.
- The `0x004baad0` decompile is a standalone visible-count cleanup helper that trims trailing spaces, tabs, and carriage returns from a proposed count.
- The `0x004bab20` decompile packages GrafPort foreground/background color bytes from the receiver state and calls [UID:00016I][0x004bb5e0-0x004bb7df.GrafPortDrawGlyph](by-memory/0x004bb5e0-0x004bb7df.GrafPortDrawGlyph.md).
- The `0x004bab70` decompile optionally computes and invalidates a text bounding rectangle when draw mode is `0` or `2`, then iterates a UTF-16 run and calls the glyph drawer once per glyph.
- The `0x004bacd0` decompile saves the active foreground color, draws the text four times at one-pixel offsets with the background color, restores the original color/cursor state, and draws the main text run.
- The `DrawWideText` decompile reads draw-state fields from the receiver at offsets matching GrafPort state: foreground/background colors, current draw mode, current X/Y, and font/style id. It calls `FontImageLib::GetFontMetrics`, `MeasureTextWidth`, `StringIter`, and the glyph drawer.
