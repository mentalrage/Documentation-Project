# IJG libjpeg Compress API Front End `0x00403920-0x004048e2`

## Status

- Confidence: strong for public API/source-file identity.
- Proposed owner: [UID:0000KN][LibJPEG](by-file/LibJPEG.md)
- Source files: `jpeg-6b/jcapimin.c`, `jpeg-6b/jcapistd.c`, `jpeg-6b/jcparam.c`, and `jpeg-6b/jdatadst.c`
- Evidence basis: obtained official `jpegsrc.v6b.tar.gz` source comparison plus read-only IDA MCP decompile/callee checks on 2026-05-25. `wave3.py` was not executed.

## Range Role

This range is the compression-side public/front-end API used by the retained JPEG screenshot writer. It is third-party IJG code, while [UID:00018N][0x004efbc0-0x004efe94.JpegScreenshotWriter](by-memory/0x004efbc0-0x004efe94.JpegScreenshotWriter.md) owns the NexusTK RGB565-to-RGB row conversion and screenshot file policy. The adjacent stock `jpeg_write_raw_data` function is documented separately as [UID:0000VT][0x004048f0-0x004049bb.LibJpegCompressRawDataApi](by-memory/0x004048f0-0x004049bb.LibJpegCompressRawDataApi.md), and the shared abort/destroy/table helpers immediately after that are [UID:0000VU][0x004049c0-0x00404a5c.LibJpegCommonApi](by-memory/0x004049c0-0x00404a5c.LibJpegCommonApi.md).
