## Behavior

This helper loads an 8-bit BMP/DIB payload into a paletted tile-context-style destination.

IDA MCP decompilation on 2026-06-03 shows the helper:

- clears/resets the destination through `sub_458500`;
- initializes a palette helper through `sub_542CD0`;
- validates the BMP `BM` signature;
- validates `biBitCount == 8`;
- marks the destination as paletted/8-bit by writing `1` at destination offset `+0x00`;
- reads width from the BMP info header and signed height from the BMP info header;
- allocates the destination context with positive height through `sub_4583D0`;
- loads the palette through `sub_543020`;
- copies pixel rows from `bfOffBits`;
- copies negative-height BMP data as top-down contiguous data and positive-height BMP data as bottom-up rows.

## Signature And Layout Notes

Working source-facing signature:

```cpp
void Decode8BitBmpToTileContext(const unsigned char* bmpBuffer, EPFTileContext* destination);
```

The pointer naming remains provisional, but the documented decompilation and caller path support a two-argument free helper: a file-buffer pointer for the BMP/DIB payload and a destination tile context. The destination is a byte/palette-mode [UID:0000XY][0x00457a60-0x00458610.EPFTileContext](by-memory/0x00457a60-0x00458610.EPFTileContext.md): the helper releases old buffers through `0x00458500`, writes mode/control value `1` at destination offset `+0x00`, and allocates byte-sized primary pixels through `0x004583d0`.

The BMP field interpretation is the standard file-header plus info-header layout:

| Field | Evidence role |
| --- | --- |
| signature at `+0x00` | Must be `BM`; otherwise the helper exits after destination reset/palette setup. |
| `bfOffBits` at `+0x0a` | Supplies the first pixel row copied into the tile-context primary buffer. |
| width at info-header `+0x12` | Passed as the destination width/stride to the byte allocation helper. |
| signed height at info-header `+0x16` | Negative values are treated as already top-down; positive values are copied bottom-up. |
| `biBitCount` at info-header `+0x1c` | Must be `8`; other bit depths are rejected by this helper. |
