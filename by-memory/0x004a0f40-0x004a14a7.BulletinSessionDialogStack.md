## Evidence

- IDA MCP lookup on 2026-06-06 confirms the stack helper sizes: `0x7c`, `0x111`, `0xfc`, `0x52`, and `0x17`.
- IDA MCP decompilation confirms all five helpers operate through the `DialogSession` list pointer at `+0xf8` and active index byte at `+0xfc`, matching the constructor/destructor documented by [UID:000131][0x004a0d80-0x004a15f8.DialogSessionCore](by-memory/0x004a0d80-0x004a15f8.DialogSessionCore.md) and [UID:0001U5][DialogSessionLayouts](by-type/by-struct/DialogSessionLayouts.md).
- `0x004a0f40` closes the active dialog when the active index is not `0xff`, iterates the tracked list, destroys entries, frees the list object, clears `+0xf8`, and invalidates the pane.
- `0x004a0fc0` removes dialogs above the active index, hides the previous active dialog, inserts the new dialog, increments `+0xfc`, applies layout/parenting, opens the dialog, and starts first-dialog animation when the new active index is zero.
- `0x004a10e0` closes and removes the active dialog, decrements `+0xfc`, restores the previous dialog when one remains, or destroys the remaining list/session state when the stack becomes empty.
- `0x004a1250` linearly searches the tracked list for a target dialog and returns the previous list entry, or null when the target is absent or first.
- `0x004a1390` returns the indexed tracked-list entry by dispatching through the list accessor slot.
- IDA MCP callers show the helper fanout is shared, not BulletinSession-specific: `PushDialog` has fifteen direct call sites in the `0x00471150` BulletinSession packet/dialog core, while `PopCurrentDialog`, `CloseAllDialogs`, and `FindPreviousDialog` are also reached from board, article, mail, and alert handlers.
- The helpers operate on `DialogSession` fields `+0xf8` and `+0xfc`, matching the constructor/destructor at `0x004a0d80` and `0x004a0e70`, so the final owner is `DialogSession`, not `BulletinSession`.
