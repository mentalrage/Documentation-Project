# 0x004a0f40-0x004a14a7 DialogSession Stack Helpers

## Status

- Entity kind: historical memory page for shared session stack helpers.
- Covered class: [UID:00003U][DialogSession](by-class/DialogSession.md)
- Likely source file: [UID:0000IU][DialogSession](by-file/DialogSession.md)
- Confidence: strong for helper behavior; previous `BulletinSession` ownership is now superseded.

## Covered Ranges

| Range | Current IDA name | Proposed owner | Notes |
| --- | --- | --- | --- |
| `0x004a0f40-0x004a0fbc` | `sub_4A0F40` | `DialogSession::CloseAllDialogs` | Closes and destroys all dialogs in the session stack, then invalidates the session pane state. |
| `0x004a0fc0-0x004a10d1` | `sub_4A0FC0` | `DialogSession::PushDialog` | Pushes a new dialog, deactivates the previous one, lays out and opens the new dialog. |
| `0x004a10e0-0x004a11dc` | `sub_4A10E0` | `DialogSession::PopCurrentDialog` | Closes current dialog, reactivates previous dialog, or tears down the session when empty. |
| `0x004a1250-0x004a12a2` | `sub_4A1250` | `DialogSession::FindPreviousDialog` | Finds the dialog below a target dialog. |
| `0x004a1390-0x004a13a7` | `sub_4A1390` | `DialogSession::GetDialogAtIndex` | Returns a dialog pointer from the stack list by index. |

The wider physical area includes neighboring dialog/base helpers. This page is retained for old cross-links; the fuller source-level range is [UID:000131][0x004a0d80-0x004a15f8.DialogSessionCore](by-memory/0x004a0d80-0x004a15f8.DialogSessionCore.md).

## Evidence

- IDA MCP `xrefs_to` shows `PushDialog`, `PopCurrentDialog`, and `GetDialogAtIndex` called directly from the `BulletinSession` core at `0x00471150-0x00471ff1`.
- IDA MCP `xrefs_to` also shows `CloseAllDialogs` and `FindPreviousDialog` called from board/mail/article dialog and alert action handlers.
- The helpers operate on `DialogSession` fields `+0xf8` and `+0xfc`, matching the constructor/destructor at `0x004a0d80` and `0x004a0e70`, so the final owner is `DialogSession`, not `BulletinSession`.
