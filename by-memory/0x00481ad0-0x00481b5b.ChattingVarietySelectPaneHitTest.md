## Behavior

This private member hit-tests the six chat-mode selector rows used by `ChattingVarietySelectPane`. For `itemIndex` `0..5`, it obtains a `RectBounds` with left `0`, right `67`, top `itemIndex * 16 + 6`, and bottom `itemIndex * 16 + 22`, then returns the first signed row containing `(mouseY, mouseX)`. If no row matches, it returns signed `-1` (`0xff` in `AL`).

The six rows correspond to the chat-mode selector popup used for Talk, Shout, Whisper, Group, Clan, and Color.

The point test is half-open: `left <= mouseX < right` and `top <= mouseY < bottom`. Therefore shared row boundaries select only the following row, and the bottom/right edge is outside.
