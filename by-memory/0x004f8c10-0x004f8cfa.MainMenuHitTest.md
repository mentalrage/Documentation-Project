## Behavior Summary

The helper takes the `MainMenuPane` owner pointer plus the mouse coordinates in the raw point-helper order `mouseY, mouseX`. It reads the menu item count byte at `this + 0xf9`; this byte is now resolved as `m_menuItemCount`. If the count is non-positive, it returns the signed-byte sentinel `-1`. Otherwise it loops from index `0` through `count - 1`, computes the same menu item rectangle family used by [UID:00019M][0x004f8b90-0x004f8c07.ComputeMenuItemRect](by-memory/0x004f8b90-0x004f8c07.ComputeMenuItemRect.md), and returns the first index whose rectangle contains the coordinate. The paired selected/current menu byte at `this + 0xfa` is not modified here, but `OnMouseEvent`, keyboard navigation, paint, and activation use it as `m_selectedMenuItemIndex`.

| Layout branch | Coordinates |
| --- | --- |
| `g_useEpfAssets == 1` / historical `byte_66DA97` | left `781`, top `493 + 41 * index`, right `972`, bottom `532 + 41 * index` |
| legacy branch | left `467`, top `299 + 30 * index`, right `640`, bottom `329 + 30 * index` |

Each raw loop iteration builds a local four-dword rectangle with `sub_4B7C50`, calls `sub_4B7E80(mouseY, mouseX, rect)`, and returns the current index on the first positive containment result. If no item matches, it returns `-1`.

The raw binary duplicates the rectangle formula from [UID:00019M][0x004f8b90-0x004f8c07.ComputeMenuItemRect](by-memory/0x004f8b90-0x004f8c07.ComputeMenuItemRect.md), including the otherwise unnecessary `index == -1` rectangle path. B007 recorded the byte-for-byte fallback: an exact body may inline the same constants instead of calling `ComputeMenuItemRect`. B012 reanalysis treats the duplicate formula as likely compiler inlining or source-level factoring evidence and uses the cleaner source-quality first draft `HitTestMenuItem(...){ ComputeMenuItemRect(...); PointInRect(...); }`. If a later whole-file reconstruction proves the original helper was manually duplicated, keep that alternate body under historical assumptions rather than deleting this source-quality direction.

This is the missing body behind the generated `HitTestMenuItem` prototype in `source-3/simroot_v2/class_MainMenuPane.cpp`, but the behavior above is based on IDA/Ghidra evidence rather than generated source authority.
