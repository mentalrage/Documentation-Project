## Behavior

The helper writes zero to the dword pointed at by `ecx`, returns `ecx`, and immediately falls into alignment padding. Documentation-only semantics are `mov dword ptr [ecx], 0; mov eax, ecx; ret`; this is not a source-facing function name or a C++ helper to emit.
