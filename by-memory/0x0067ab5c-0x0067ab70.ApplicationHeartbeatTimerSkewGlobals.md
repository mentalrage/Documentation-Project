# 0x0067ab5c-0x0067ab70 ApplicationHeartbeatTimerSkewGlobals

## Summary

- Address range: `0x0067ab5c-0x0067ab70`
- Entity kind: application timing globals and MSVC local-static guards
- Rebuild handling: source-declared/generated-binary static/global storage
- Disposition: reconstructable NexusTK application data
- Proposed owner: [UID:0000HG][Application](by-file/Application.md), supporting [UID:0000YT][0x00466ca0-0x004670ad.CheckTimerSkewAndSendHeartbeat](by-memory/0x00466ca0-0x004670ad.CheckTimerSkewAndSendHeartbeat.md)

This split child covers only the timing state used by the application message-loop heartbeat and timer-skew helper. It is separated from the preceding reconnect-dialog singleton slots and the following message-loop/wheel counters because every dword in this range is touched by the heartbeat helper at `0x00466ca0`.

## Evidence

- Live IDA MCP recheck on 2026-06-07 reported all five dwords initialized as `0xffffffff`.
- [UID:0000YT][0x00466ca0-0x004670ad.CheckTimerSkewAndSendHeartbeat](by-memory/0x00466ca0-0x004670ad.CheckTimerSkewAndSendHeartbeat.md) is the only function cluster touching all five slots.
- `dword_67AB5C` is refreshed from `GetTickCount()` at `0x00466ec9` and initialized at `0x00467068`.
- `dword_67AB64` is refreshed at `0x00466f54` and initialized at `0x0046709b`.
- `dword_67AB6C` is checked at `0x00466dde` and set to `1` at `0x00466e85` after the skew report is sent.
- `dword_67AB60` and `dword_67AB68` are MSVC local-static guard dwords read at `0x00466cce`/`0x00466cdf` and passed to `_Init_thread_header`/`_Init_thread_footer` at `0x00467047`/`0x00467063` and `0x0046707a`/`0x00467096`.
- Boundary check: predecessor `0x0067ab58` is the reconnect-dialog singleton slot; successor `0x0067ab70` starts message-loop counters written by `ApplicationRunMessageLoop`.
