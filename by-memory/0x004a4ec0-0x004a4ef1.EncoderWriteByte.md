## Behavior

Writes one byte at the current cursor when the encoder is valid and has room for the byte plus final terminator. If capacity is insufficient, clears the valid/writable flag.

Exact behavior:

- Source-facing signature: `void Encoder::WriteByte(unsigned char value)`.
- If valid/writable byte `+0x11` is zero, returns immediately without touching the output buffer or write cursor.
- Reads cursor `+0x0c`, computes `writePos + 2`, and requires capacity `+0x08` to be at least that value. The extra byte is reserved for [UID:00013K][0x004a55e0-0x004a5621.EncoderFinalize](by-memory/0x004a55e0-0x004a5621.EncoderFinalize.md), which appends the trailing NUL.
- On overflow, writes zero to valid/writable byte `+0x11`, returns, and does not write partial data.
- On success, writes the caller byte to `m_outputBuffer[writePos]` through buffer pointer `+0x04`, then increments `m_writePos` by one.
- The binary does not add null-buffer guards, return-status logic, allocation, growth, clamping, exceptions, or any byte-order handling for this one-byte writer.
