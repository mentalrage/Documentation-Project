## Proof Packet Notes

`SendScreenshotProofPacket_558240`:

- Calls [UID:0000L6][MD5](by-file/MD5.md) stream helper `0x00515570` to produce a 32-byte hex digest of the saved screenshot file contents.
- Materializes the exact 32-character key `w-pu6a4Es*5pA@eg+tetayAp6us6EcrE` as local `char proofMask[36]`. IDA stores the 32 literal bytes plus NUL as one 33-byte pooled item `[0x006232e0,0x00623301)`; C++ aggregate initialization supplies three additional zero-initialized local bytes at indices `33..35`. The helper XORs only digest/mask indices `0..31`.
- Builds opcode `0x83` with [UID:0000M8][PacketBuffer](by-file/PacketBuffer.md) byte writer `0x00575380`.
- Copies the first 13 masked digest bytes, writes the first random byte as `(rand() % 10) - 26`, writes the remaining 15 random bytes as `rand() % 255`, copies the remaining 19 masked digest bytes, stores a local zero at byte 49, and queues exactly 49 bytes through `CashShopRequest::QueueAndSendPacket` at `0x00574bb0`. The local terminator is not sent.
- Frees the heap digest string returned by the MD5 helper.

2026-06-01 IDA decompilation and the 2026-07-24 instruction-level recheck of `0x00558240` confirm the proof shape: it copies the 32-character XOR literal into local `char proofMask[36]`, whose NUL occupies index `32` and whose indices `33..35` are three additional zero-initialized bytes; it then calls `0x00515570(Stream)`, XORs only the 32 bytes at indices `0..31`, starts opcode `0x83` through `0x00575380`, copies 13 bytes, writes the asymmetric 1+15 random padding described above, copies 19 remaining bytes, stores a local zero terminator, queues 49 bytes through `0x00574bb0(dword_67A7EC, packet, 49)`, and frees the digest allocation.
