## Behavior Notes

- Both capture functions call `SHGetFolderPathW` with CSIDL `5`, then create `NexusTK` and `NexusTK\ScreenShots` under the user's Documents folder.
- Both capture functions use `_time64` and `_localtime64_s` to build timestamped `TK_yyyymmddhhmmss.bmp/png` filenames.
- Both functions temporarily swap the active surface id to the screenshot surface id at offset `0x108`, refresh surface metadata with `0x004b9820`, optionally call the render/surface flush helper at `0x0046bfd0`, then call `0x004b98c0` and restore the previous surface id.
- The BMP path writes a `BM` file header and a 40-byte info header directly, then writes 16-bit rows bottom-up.
- The PNG path converts the 16-bit source surface into an RGBA8 heap buffer and calls `0x00443e40`, now matched to stock LodePNG `lodepng_encode32_file`.
- Both paths format a saved-file chat/status message through `0x00559af0`, temporarily clear the chat/meta suppression byte at `g_pMetaMan + 2336`, and call the chat-message append path at `0x0047f280`.
- Both paths reopen the saved file in binary-read mode and call `SendScreenshotProofPacket_558240`.

## Proof Packet Notes

`SendScreenshotProofPacket_558240`:

- Calls [UID:0000L6][MD5](by-file/MD5.md) stream helper `0x00515570` to produce a 32-byte hex digest of the saved screenshot file contents.
- XORs the 32 digest bytes with fixed key string `w-pu6a4Es*5pA@eg+tetayAp6us6EcrE`.
- Builds opcode `0x83` with [UID:0000M8][PacketBuffer](by-file/PacketBuffer.md) byte writer `0x00575380`.
- Copies the first 13 masked digest bytes, inserts 16 random pad bytes, copies the remaining 19 masked digest bytes, terminates the packet, and queues 49 bytes through `CashShopRequest::QueueAndSendPacket` at `0x00574bb0`.
- Frees the heap digest string returned by the MD5 helper.

2026-06-01 IDA decompilation of `0x00558240` confirms the proof shape: it copies the XOR key string into a local buffer, calls `0x00515570(Stream)`, XORs 32 digest bytes, calls `0x00516030`, starts opcode `0x83` through `0x00575380`, copies 13 bytes, fills 16 random pad bytes using `_rand`, copies 19 remaining bytes, writes a zero terminator, queues 49 bytes through `0x00574bb0(dword_67A7EC, packet, 49)`, and frees the digest allocation.

2026-06-01 IDA `xrefs_to` confirms data references from the proof helper to the XOR key constants at `0x006232e0`, `0x00623300`, and `0x006232f0`.
