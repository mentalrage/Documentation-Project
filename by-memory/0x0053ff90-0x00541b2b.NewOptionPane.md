## 2026-06-19 OnVolumeChanged Support Evidence

B001's support pass for [UID:0001H5][0x00565360-0x00565488.ScrollVolumePaneNotifyValueChange](by-memory/0x00565360-0x00565488.ScrollVolumePaneNotifyValueChange.md) disassembled `0x00540490-0x005404c7` as `NewOptionPane::OnVolumeChanged(unsigned char volumeType, int oldValue, int newValue)`. The helper returns immediately if `oldValue == newValue`; otherwise, nonzero `volumeType` changes write the pane-side music value to `this+0x12bc`, zero `volumeType` changes write the pane-side sound value to `this+0x12c0`, then it calls `ApplyVolumeSettings` at `0x005403b0` and invalidates the NewOptionPane bounds. This confirms that ScrollVolumePane owns the horizontal thumb/value math while NewOptionPane owns option-policy storage, refresh, and invalidation after the callback.
