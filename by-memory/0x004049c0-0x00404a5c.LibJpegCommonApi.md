# IJG libjpeg Common API `0x004049c0-0x00404a5c`

## Status

- Confidence: strong for `jpeg-6b/jcomapi.c` source-file ownership.
- Proposed owner: [UID:0000KN][LibJPEG](by-file/LibJPEG.md)
- Disposition: third-party static IJG libjpeg code; exclude from NexusTK product files.
- Evidence basis: read-only IDA MCP decompile/function-list checks and source comparison against `jpegsrc.v6b.tar.gz` on 2026-05-25. `wave3.py` was not executed for this pass.

## Range Role

This range is IJG libjpeg's common API helper module shared by compression and decompression objects. It owns abort/reset and table-allocation helpers, not product-level image policy.

## Function Mapping

| Address/range | Stock IJG function | Evidence |
| --- | --- | --- |
| `0x004049c0-0x004049f8` | `jpeg_abort` | Calls memory-manager pool release and resets object state to `CSTATE_START` or `DSTATE_START`; source anchor `jcomapi.c:29`. |
| `0x00404a00-0x00404a1f` | `jpeg_destroy` | Releases all pools and clears the memory manager pointer; source anchor `jcomapi.c:69`. |
| `0x00404a20-0x00404a3c` | `jpeg_alloc_quant_table` | Allocates and zeroes a quantization-table struct; source anchor `jcomapi.c:86`. |
| `0x00404a40-0x00404a5c` | `jpeg_alloc_huff_table` | Allocates and zeroes a Huffman-table struct; source anchor `jcomapi.c:98`. |

## Evidence Notes

- `jpeg_destroy_decompress` at `0x00401290` and `jpeg_destroy_compress` at `0x004039f0` are thin wrappers around `0x00404a00`.
- `jpeg_read_header`, `jpeg_finish_decompress`, `jpeg_finish_compress`, and table parsing/initialization paths reach this common helper family through public or vtable-controlled IJG flows.

## Ownership Decision

Keep this range in `third_party/libjpeg/jcomapi.c`. Do not attach these helpers to NexusTK image loaders, screenshot writers, or DAT/resource files.
