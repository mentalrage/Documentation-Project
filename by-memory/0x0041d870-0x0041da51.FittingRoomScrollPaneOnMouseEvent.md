## Behavior

Handles mouse input for the fitting-room scrollbar. The method takes a mouse-event record whose event kind is stored at `event + 4`, with cursor coordinates at `event + 8` and `event + 12`.

Observed event behavior:

- Event kind `1` acts like mouse-down. The method checks whether the event point lies in the scrollbar pane rect, verifies that scrolling is enabled and that the scrollable range is positive, hit-tests the scrollbar part, captures mouse input, marks the active part, starts a repeat timer, and invalidates the scrollbar.
- Event kind `3` acts like mouse-up/cancel. If a scrollbar part is active, it releases capture/timer state, invalidates the previous hot/pressed part, clears the active drag/pressed byte, clears the dragging flag, and invalidates the pane.
- Event kind `0` returns handled only when an active part is already present, then invalidates the pane.
- Other event kinds return not handled.

IDA decompilation names the receiver as `this`, but most object-field accesses subtract `0xa0` before accessing pane state. Treat this as a vtable/secondary-base dispatch artifact: the logical `FittingRoomScrollPane` base is `this - 0xa0` in the current decompiler output.

bool FittingRoomScrollPane::OnMouseEvent(const MouseEvent& event)
{
    const int x = event.x;
    const int y = event.y;

    if (event.kind == MouseEventKind::MouseUp) {
        if (m_activePart != NoPart) {
            ReleaseCapture();
            StopRepeatTimer();
            InvalidatePart(m_hotPart);
            m_activePart = NoPart;
            m_dragging = false;
            Invalidate(m_bounds);
            return true;
        }
        m_dragging = false;
        return false;
    }

    if (event.kind != MouseEventKind::MouseDown) {
        if (event.kind == MouseEventKind::Move && m_activePart != NoPart) {
            Invalidate(m_bounds);
            return true;
        }
        return false;
    }

    if (!PointInRect(x, y, m_bounds))
        return false;
    if (!m_enabled || m_scrollRange <= 0)
        return false;
    if (m_activePart != NoPart)
        return true;

    const ScrollPart part = HitTestPart(x, y);
    if (part == NoPart)
        return true;

    CaptureMouse();
    if (part == ThumbPart) {
        InvalidatePart(m_hotPart);
        InvalidatePart(ThumbPart);
        m_hotPart = ThumbPart;
        m_dragOffset = Point(x - thumbRect.top, y - thumbRect.left);
    }

    m_activePart = part;
    ProcessActivePart();
    StartRepeatTimer(200);
    Invalidate(m_bounds);
    m_dragging = true;
    return true;
}
