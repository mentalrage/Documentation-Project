# 0x00430040-0x00430092 JsonCpp Generic String Append Helper

## Status

- Disposition: ignored for NexusTK source reconstruction; third-party JsonCpp writer support
- Entity kind: generic string/vector append helper, likely `StyledWriter::pushValue`-style support
- Current generated owners: false starts under `ClanBankItemListPane` and `ExchangeMoneyEditControlPane`
- Confidence: strong for excluding current feature owners; strong for JsonCpp writer-family ownership; medium for exact upstream method name

## Behavior

IDA MCP defines one real function at `0x00430040`, size `0x52`. The function appends or stores string data through a small-buffer-aware destination:

- if the state byte at `this+0x48` is set, it appends through the vector/list-style path at `this+4`;
- if the destination list is full, it calls the growth helper at `0x00437470`;
- otherwise it copies/appends through `0x0041d3b0` and advances the current pointer by `0x18`;
- when the state byte is clear, it appends/copies raw string data into storage at `this+0x10`, using inline versus heap storage based on the source length at `Src+0x14`.

This matches JsonCpp writer support where `StyledWriter::pushValue` appends either to a temporary child-value vector or directly to the document string, depending on the active `addChildValues_` state. The immediately preceding [UID:0000X4][0x0042f3f0-0x00430040.JsonCppLegacyWriterCore](by-memory/0x0042f3f0-0x00430040.JsonCppLegacyWriterCore.md) calls this helper only from the `StyledWriter::writeValue`-style body at `0x0042f870`; the following [UID:0000X6][0x00430092-0x00431d50.JsonCppWriterTailAndOurReaderPrelude](by-memory/0x00430092-0x00431d50.JsonCppWriterTailAndOurReaderPrelude.md) continues the same third-party writer family.
