## Behavior

IDA MCP defines one real function at `0x00430040`, size `0x52`. The function appends or stores string data through a small-buffer-aware destination:

- if the state byte at `this+0x48` is set, it appends through the vector/list-style path at `this+4`;
- if the destination list is full, it calls the growth helper at `0x00437470`;
- otherwise it copies/appends through `0x0041d3b0` and advances the current pointer by `0x18`;
- when the state byte is clear, it appends/copies raw string data into storage at `this+0x10`, using inline versus heap storage based on the source length at `Src+0x14`.

This matches JsonCpp writer support where `StyledWriter::pushValue` appends either to a temporary child-value vector or directly to the document string, depending on the active `addChildValues_` state. The immediately preceding [UID:0000X4][0x0042f3f0-0x00430040.JsonCppLegacyWriterCore](by-memory/0x0042f3f0-0x00430040.JsonCppLegacyWriterCore.md) calls this helper only from the `StyledWriter::writeValue` body at `0x0042f870`; staged `json_writer.cpp` places `StyledWriter::pushValue` immediately after `StyledWriter::isMultineArray` and before `StyledWriter::writeIndent`, matching the binary boundary before the source-bearing writer continuation [UID:00037Z][0x00430092-0x00431c00.JsonCppWriterTailAndScalarHelpers](by-memory/0x00430092-0x00431c00.JsonCppWriterTailAndScalarHelpers.md). The old [UID:0000X6][0x00430092-0x00431d50.JsonCppWriterTailAndOurReaderPrelude](by-memory/0x00430092-0x00431d50.JsonCppWriterTailAndOurReaderPrelude.md) page remains as a non-emitting split index for that writer child and the following reader child.

The source-level identity is `Json::StyledWriter::pushValue(JSONCPP_STRING const&)` from staged `source-3/third_party_embeds/jsoncpp/src/lib_json/json_writer.cpp` line 539. The source body is the two-way `addChildValues_ ? childValues_.push_back(value) : document_ += value` helper. The binary's callees are implementation artifacts for those source operations: `0x0041d3b0` is the consumed SSO-15 string copy helper documented by [UID:0002CZ][0x0041d3b0-0x0041d431.SmallStringStorageAssign](by-memory/0x0041d3b0-0x0041d431.SmallStringStorageAssign.md), `0x00437470` grows the child-value storage, and `0x0043f3f0` appends source bytes into `document_`.
