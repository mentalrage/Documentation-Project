# 0x004b5760-0x004b57dd Shared Simple String Entry Vector Destructor

## Status

- Disposition: non-emitting compiler/template destructor helper for 12-byte string-entry vectors.
- Entity kind: emitted vector destructor/body for records whose first field is a `SimpleUString`/string handle and whose remaining 8 bytes are caller-owned metadata.
- Direct parent: intentionally blank by structure. The physical body is shared by `SpelledPane` member-vector destruction and `FolderTreePane::FindFirstVisibleChild` EH cleanup for a local directory-entry vector, and no single source class/file owns both source-level vector instances.

The best current source-layout inference is a common source-level record-vector pattern used in two owners:

- `SpelledPane` owns a member vector at `this+0x178` / 376 bytes (Verified with `tools\int_convert.py`) whose insert/copy/erase/destructor support appears around `0x00572fd0`, `0x00573880`, `0x00573900`, and this helper.

Those source-level vectors should be reconstructed in their owning classes/functions. This exact by-memory item remains only an audit page for the shared emitted destructor body and should be represented in [UID:0000VN][-ignored](by-memory/-ignored.md).
