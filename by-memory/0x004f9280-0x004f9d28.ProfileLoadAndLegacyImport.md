### Importer Behavior

The importer builds `users\\<player>.cfg` under the current directory, opens it read-only, and scans quoted UTF-16 fields through a 512-wide scratch buffer. It reads ten 128-wide profile-text values, ten 128-wide legacy-shortcut values, twenty friend names, and one 256-wide selected-profile value. Only the selected-profile copy receives truncation at index 255. An open failure is a no-op; successful migration closes the stream and deletes the legacy file. The current source-facing field is `m_friendNames`, not the superseded `m_profileStringSlots`.

### Loader Behavior And Exact Failure Semantics

The loader first calls `RegistryConfig::InitializeUserDataDefaults()` through the one narrow runtime-derived cast, then accesses all profile storage directly through `Config`. It creates the Documents `NexusTK` and `users` directories, tries the Documents `.usr` path, falls back to the current-directory `.usr`, and invokes the file-local importer when both modern paths miss.

The modern stream has eight groups in order: ten length-prefixed profile-text values; ten legacy shortcut characters; twenty length-prefixed friend names; one length-prefixed selected-profile value; optional block/listen vector rows; optional twenty compact shortcut pairs; optional macro rows; and optional two target-option rows. Exact original edge behavior is intentional:

- A profile-text length over `0x7f` returns without `fclose`.
- Selected-profile length is trusted and is not bounded before read or terminator write.
- Optional vector, macro, and target-option counts and row lengths are not clamped.
- Any successfully read compact-section dword enables exactly twenty rows; its numeric value is ignored.
- Macro `T/S/I` map to states `1/2/3`; unknown type leaves the default state. A macro length `>=0x80` leaves its payload unread and desynchronizes the following stream.
- `fread` return values are ignored except for optional section-presence/count reads.
- Migration uses `(shortcut.isSpellMode != 1) + 2`, so only byte value exactly one produces state two.
