# 0x0041a670-0x0041b69f FileDownloader Dispatch

## Status

- Disposition: reconstructable NexusTK project code.
- Entity kind: `FileDownloader` construction/destruction and HTTP download dispatch cluster.
- Current Wave3 owners: [UID:00004W][FileDownloader](by-class/FileDownloader.md), `DownloadMinimapFile_41A750`, `DownloadCashShopVersion_41AA00`, and `DownloadCashShopCatalog_41AE20`.

## Evidence

- IDA MCP confirms all listed starts and sizes.
- IDA MCP decompilation for `0x0041b110` shows the exact message switch: `10000` -> `0x0041a750`, `10001` -> `0x0041ae20`, and `10002` -> `0x0041aa00`.
- IDA MCP `callers` shows each download helper is called from `0x0041b110` in the current database.
- Generated `simroot_v2` source shows WinINet use, HTTP status checks, three-second timeout options, progress byte counters, and helper-specific request destruction behavior.
- IDA MCP xrefs for `0x0067a738` on 2026-05-25 show five direct writes, all in the FileDownloader constructor/destructor family. The constructor-unwind write reaches [UID:0000WK][0x0041b2f0-0x0041b2fb.ClearFileDownloaderRequestGlobal](by-memory/0x0041b2f0-0x0041b2fb.ClearFileDownloaderRequestGlobal.md) through the raw unwind block at `0x005f670e`.
- IDA MCP decompilation of fitting-room request callers shows `dword_67A738` passed into `0x0041b180`, `0x0041b200`, and `0x0041b270`; those helpers allocate request payloads and enqueue downloader messages `10000`, `10001`, and `10002` through the same thread queue.

## Ownership Decision

Treat `0x0041b110` as the shared download dispatcher. Keep the dispatcher in [UID:0000JC][FileDownloader](by-file/FileDownloader.md), while cross-linking feature semantics to [UID:0000LE][MiniMap](by-file/MiniMap.md), [UID:0000I1][CashShopVersionRequest](by-file/CashShopVersionRequest.md), and [UID:0000JE][FittingRoom](by-file/FittingRoom.md).

The downloader request submission helpers at `0x0041b180`, `0x0041b200`, and `0x0041b270` remain a boundary case. They are adjacent to the small cash-shop payload class, but live caller evidence passes the FileDownloader-lifetime singleton [UID:0000QH][g_pCashShopRequest](by-global/g_pCashShopRequest.md) / `dword_67A738`. Keep them cross-linked instead of forcing a final owner from adjacency alone.
