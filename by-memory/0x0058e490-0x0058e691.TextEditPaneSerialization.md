## Signature And Data Flow

Current decompiler shape is `void *__fastcall sub_58E490(TextEditPane *this, int unused_edx, uint16_t *outSize)`. The `edx` parameter is unused by the body. The return value is an allocated buffer containing the finalized encoded stream, and `*outSize` receives the byte count from the `Encoder` finalization helper.

Data flow is table/list driven:

- `this+0x134` supplies the first raw byte payload size from its `+0x0c` word and writes that payload before the delimiter byte.
- `this+0x138` and `this+0x13c` supply record counts multiplied by `16`, then each serialized block is length-prefixed through `EncoderWriteShort`.
- `this+0x140` supplies a count multiplied by `4`, also length-prefixed through `EncoderWriteShort`.
- The stream writes delimiter byte `0`, then the integer constant `0x6b6f6e67` (`"kong"` little-endian), before the three sized secondary payloads.
- The stack output buffer is `32768` bytes, but the Encoder is initialized with a `32766` byte writable window. After finalize, the function allocates exactly `Size` bytes through the shared allocator helpers and copies `Size` bytes from the stack buffer.
