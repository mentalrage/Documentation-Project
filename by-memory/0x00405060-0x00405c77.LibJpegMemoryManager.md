## Range Role

This range implements IJG libjpeg's system-independent pooled memory manager. It is statically linked third-party support code.

The backend calls that actually allocate/free memory are outside this range at [UID:0000W1][0x00406e50-0x00406ed1.LibJpegNoBackingStoreMemoryBackend](by-memory/0x00406e50-0x00406ed1.LibJpegNoBackingStoreMemoryBackend.md). The gap `0x00405c80-0x00406e4f` is not memory-manager code and should not be included in this range; it contains later decompression controller/support code in the libjpeg island.

The range starts at `0x00405060` with `jinit_memory_mgr`, after input-controller padding at `0x0040505b-0x0040505f`. It ends at `0x00405c77`; `self_destruct` returns at `0x00405c76`, `0x00405c77-0x00405c7f` is padding, and [UID:0000VX][0x00405c80-0x004063c8.LibJpegDecompressMaster](by-memory/0x00405c80-0x004063c8.LibJpegDecompressMaster.md) starts `jdmaster.c` at `0x00405c80`.
