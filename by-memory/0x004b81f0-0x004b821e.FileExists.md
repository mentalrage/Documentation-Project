## Behavior

`FileExists` probes a wide path by opening it through the wide API dispatch table in read-binary mode:

- calls `dword_69BE14(path, L"rb")`;
- returns `false` if the open call fails;
- closes the returned stream with `fclose`;
- returns `true` on successful open/close.

This is an existence probe, not a data loader. It deliberately has no seek/read/write path and does not report errors; successful `_wfopen` is enough to return true.
