## Behavior

The EventDispatcher constructor and event-routing method snapshot Win32 keyboard state into the 256-byte buffer, watch the low bit of virtual-key index `0x91`, and cache that bit at `0x0069af18` so the route method can detect toggle changes. The same route method uses that change, plus live `VK_LSHIFT` and `VK_CONTROL` checks, to gate shortcut behavior and the adjacent [UID:0002AW][0x0069af20-0x0069af21.KeyboardChordGateFlag](by-memory/0x0069af20-0x0069af21.KeyboardChordGateFlag.md).
