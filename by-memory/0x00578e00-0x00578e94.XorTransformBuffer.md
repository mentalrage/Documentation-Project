# 0x00578e00-0x00578e94 XOR Transform Buffer

## Status

- Disposition: reconstructable NexusTK project code
- Entity kind: global packet transform helper
- Current Wave3 owner: recovered global `XorTransformBuffer`
- Likely source module: [UID:0000M9][PacketTransform](by-file/PacketTransform.md)
- Shared state: [UID:0000TG][PacketTransformGlobals](by-global/PacketTransformGlobals.md)
- Confidence: strong for behavior and call relationships.

## Covered Range

| Range | Current name | Notes |
| --- | --- | --- |
| `0x00578e00-0x00578e94` | `XorTransformBuffer` | Applies repeated-key XOR over dword blocks plus one to three trailing bytes. |

IDA MCP confirms `0x00578e00` as a function start with size `0x94`.

## Behavior

The helper:

- Iterates over `len >> 2` four-byte blocks.
- XORs each source dword with `keyWords[index % step]` and writes the result to the destination.
- Handles `len & 3` trailing bytes using the next key word.
- Returns the last calculated low byte/value, which callers currently ignore.

`src` and `dst` may alias. Both `Socket::TransformFramePayload` and `Socket::BuildEncryptedPacket` use in-place calls after the first transform pass.

## Signature Caveat

IDA decompiles `0x00578e00` as a byte-returning helper taking integer-address source, destination, key pointer, and stride arguments. Current `simroot_v2` remains inconsistent:

- `recovered/XorTransformBuffer_00578E00.cpp` defines `std::uint8_t XorTransformBuffer(std::uint32_t* src, std::uint32_t* dst, std::uint32_t len, int keyPtr, std::uint32_t step)`;
- `class_Socket.cpp` declares it as `extern void XorTransformBuffer(...)`;
- `Socket::BuildEncryptedPacket` passes byte pointers for payload and key arguments.

Normalize the helper prototype before source migration. The behavior is byte-buffer oriented even though the fast path processes full dwords.

The key pointer arguments are dword-oriented: command `13` fills `g_packetTransformLut` at `0x0066fe58` as 256 dwords, and the primary/alternate table pointers passed from Socket point at [UID:0000TG][PacketTransformGlobals](by-global/PacketTransformGlobals.md) rather than packet-buffer cursors.

## Ownership Decision

This is the shared XOR primitive for inbound and outbound packet transforms. It should live under [UID:0000M9][PacketTransform](by-file/PacketTransform.md), not [UID:0000M8][PacketBuffer](by-file/PacketBuffer.md). The Socket methods that sequence the transform passes remain [UID:0000NS][Socket](by-file/Socket.md) methods.
