## Behavior

The helper:

- Takes arguments in source ABI order: `source`, `destination`, `length`, `keyData`, and `keyWordCount`.
- Iterates over `length >> 2` four-byte blocks.
- Selects the current key word with `blockIndex % keyWordCount`.
- XORs one source dword with the selected key dword and writes the result to the destination.
- Handles `length & 3` trailing bytes using the next key word.
- Has no semantic source-level return value; all six callers ignore the residual `EAX` byte/value inferred by the decompiler.

`source` and `destination` may be the same buffer. Both [UID:0001I3][0x00578b20-0x00578c40.SocketTransformFramePayload](by-memory/0x00578b20-0x00578c40.SocketTransformFramePayload.md) and [UID:0001I4][0x00578c40-0x00578df1.SocketBuildEncryptedPacket](by-memory/0x00578c40-0x00578df1.SocketBuildEncryptedPacket.md) use in-place calls after their first transform pass. The first-draft body reads each full four-byte group before writing that group, preserving the observed same-buffer use.
