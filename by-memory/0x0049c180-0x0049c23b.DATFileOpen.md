# DATFile Open

## Role And Evidence

Exact virtual Open body at `[0x0049c180,0x0049c23b)`. It resolves a name through the global DAT manager, throws the Error-owned `FileError` when lookup fails, binds the mapped container/current 17-byte row, sets the absolute payload cursor, and derives payload size from the following boundary row. The manager lookup at `0x0049cad0` establishes the reader-to-manager API boundary.

## Ownership And Interactions

This is DATFile source, not DATFileMgr source. `DATEntryLocation`, `DATEntryRecord`, `DATFileContainer`, `g_pDATFileMgr`, and `FileError` are compile-visible dependencies supplied by DATFileMgr/Error headers.

## Historical Assumptions

The final row is a payload boundary and its name bytes are not guaranteed empty. Raw 17-byte pointer arithmetic is expressed through the packed record type.
