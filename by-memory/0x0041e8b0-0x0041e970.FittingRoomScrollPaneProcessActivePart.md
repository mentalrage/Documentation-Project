## Behavior

Processes the current active scrollbar part. If the active part is the thumb (`2`), it forwards the cursor point to [UID:0002D9][0x0041e970-0x0041eb24.FittingRoomScrollPaneUpdateThumbDragScroll](by-memory/0x0041e970-0x0041eb24.FittingRoomScrollPaneUpdateThumbDragScroll.md). For non-thumb parts, it verifies that the cursor still hits the active part and then applies a line/page scroll action. After action processing, it invalidates any stale hot part rectangle and clears the hot part byte.

This helper is called from mouse-down/drag setup and timer repeat paths.

void FittingRoomScrollPane::ProcessActivePart()
{
    Point cursor = localCursorPosition();

    if (m_activePart == ThumbPart) {
        UpdateThumbDragScroll(cursor.x, cursor.y);
        return;
    }

    if (HitTestPart(cursor.x, cursor.y) == m_activePart)
        ApplyScrollPart(m_activePart);

    if (m_hotPart != NoPart) {
        InvalidatePart(m_hotPart);
        m_hotPart = NoPart;
    }
}
