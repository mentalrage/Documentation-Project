# 0x0041b9a0-0x0041b9de CRT Stdio Common Sprintf Glue

## Status

- Disposition: ignored for NexusTK source reconstruction
- Entity kind: CRT/UCRT secure formatted-output wrapper
- Current IDA names: `sub_41B9A0`, `sub_41B9B0`
- Confidence: strong for runtime/library ownership.

## Covered Range

| Range | IDA name | Role |
| --- | --- | --- |
| `0x0041b9a0-0x0041b9a6` | `sub_41B9A0` | Returns local stdio options storage at `0x0067a730`. |
| `0x0041b9b0-0x0041b9de` | `sub_41B9B0` | Varargs wide secure formatting wrapper around `__stdio_common_vswprintf_s`; returns `-1` on negative runtime result. |

## Evidence

- IDA MCP decompilation of `0x0041b9a0` returns `&unk_67A730`.
- IDA MCP decompilation of `0x0041b9b0` obtains the local stdio options pointer, forwards `Buffer`, `BufferCount`, `Format`, and `va_list` to `__stdio_common_vswprintf_s`, and normalizes negative results to `-1`.
- The wrapper has broad caller fan-in, including fitting-room/cash-shop code and many later UI formatting sites. This matches MSVC secure-formatting glue rather than feature-owned source.

## Reconstruction Notes

Use normal secure wide formatting APIs at source level. Do not model this as a NexusTK helper unless the final build intentionally vendors CRT glue.
