## Evidence

- 2026-06-15 live IDA MCP session `a003_objectlist_dispatch_20260615` rechecked the helper pair. `lookup_funcs` reports `sub_41B9A0` at `0x0041b9a0`, size `0x06`, `0x0041b9a6` as non-function padding/alignment before `sub_41B9B0`, and `sub_41B9B0` at `0x0041b9b0`, size `0x2e` / 46 bytes. Decimal conversion for `0x2e` / 46 was verified with `tools/int_convert.py`.
- Current decompilation of `0x0041b9a0` returns `&unk_67A730`; xrefs include the secure formatting wrapper, other CRT formatting wrappers, and `___scrt_initialize_default_local_stdio_options`.
- Current decompilation of `0x0041b9b0` obtains local stdio options through `sub_41B9A0`, forwards `Buffer`, `BufferCount`, `Format`, locale `0`, and `va_list` to `__stdio_common_vswprintf_s`, and uses `cmovs` to return `-1` for negative results. Its broad caller fan-in exceeds the first 100 xrefs and spans startup/UI formatting sites, matching CRT glue rather than feature source.
- 2026-06-17 B001 PhoneBook source-quality pass adds [UID:0001JL][0x0058dcb0-0x0058dcd3.PhoneBookFormattedWriteHelper](by-memory/0x0058dcb0-0x0058dcd3.PhoneBookFormattedWriteHelper.md) as another local-stdio-options/common-format-backend wrapper. That helper calls `sub_41B9A0`, forwards to `sub_5D2208`, has no PhoneBook-specific state, and is best treated as an `fwprintf`-style wide `FILE*` runtime wrapper.
- IDA MCP decompilation of `0x0041b9a0` returns `&unk_67A730`.
- IDA MCP decompilation of `0x0041b9b0` obtains the local stdio options pointer, forwards `Buffer`, `BufferCount`, `Format`, and `va_list` to `__stdio_common_vswprintf_s`, and normalizes negative results to `-1`.
- The wrapper has broad caller fan-in, including fitting-room/cash-shop code and many later UI formatting sites. This matches MSVC secure-formatting glue rather than feature-owned source.
