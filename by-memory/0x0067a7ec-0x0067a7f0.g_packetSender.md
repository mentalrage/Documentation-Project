## Storage And Lifetime

This four-byte global holds the client-wide outbound packet sender object. The final source-facing type remains unresolved because generated code uses it as a `CashShopRequest*` in many feature packet builders, while [UID:0001HS][0x005747e0-0x00574ad8.SocketLifecycle](by-memory/0x005747e0-0x00574ad8.SocketLifecycle.md) and the Socket destructor family are the observed initialization/shutdown owners. Some generated packet-send paths also use the `g_pCashShopRequest` name for this address; live IDA must win over that alias because the real [UID:0000QH][g_pCashShopRequest](by-global/g_pCashShopRequest.md) storage is `0x0067a738`. Current `simroot_v2/class_Thread.cpp` also shows the queue post primitive at `0x00596960` as `Thread::DispatchRequest`, so the pointed-to object should be treated as a network/request-thread sender until layout cleanup proves a concrete type.
