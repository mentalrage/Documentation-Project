## Behavior

The method looks up an existing object by id in the map object list. For live/avatar-style object types it updates the player or existing object status, recenters the map when the object is the local player, clears stale overlay panes attached to the local object, and records status blobs. For ground item objects it removes any existing pane and constructs an `ItemObjectPane`-style object using the item object factory path. New or updated panes are inserted back into the object list and refreshed in the map view.
