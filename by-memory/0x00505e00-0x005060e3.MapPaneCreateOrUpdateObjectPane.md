## Behavior

The method receives tile coordinates, an object id, a movement/action byte, and a 68-byte [UID:0000M6][ObjectStatusBlob](by-file/ObjectStatusBlob.md). It first searches the `MapPane` object list for an existing pane with the same id through [UID:0002CD][0x00532370-0x00532443.ObjectListFindByObjectId](by-memory/0x00532370-0x00532443.ObjectListFindByObjectId.md). Status types other than `0`, `1`, and `2` return null.

Status type `2` is the item-object path. Any existing pane for the id is detached through [UID:0002QP][0x00506170-0x005061d3.MapPaneDetachObjectPane](by-memory/0x00506170-0x005061d3.MapPaneDetachObjectPane.md), then an [UID:00006V][ItemObjectPane](by-class/ItemObjectPane.md) is allocated from the static pool described by [UID:0000TI][PoolAllocatorStaticInstances](by-global/PoolAllocatorStaticInstances.md) and constructed by [UID:0001D7][0x00537b40-0x005380af.ItemAndFlyingObjectPanes](by-memory/0x00537b40-0x005380af.ItemAndFlyingObjectPanes.md). The item id is looked up through [UID:0000RA][g_pItemObjImageLib](by-global/g_pItemObjImageLib.md); if the image-library row yields a valid descriptor, the helper at `0x0050a940` receives half-tile pixel offsets from [UID:0000T7][MapTilePixelDimensions](by-global/MapTilePixelDimensions.md) to attach or refresh the item visual.

Status types `0` and `1` are living-object paths. If the object id matches the active local object stored at `MapPane +0x418`, the method removes any duplicate entry from `MapPane +0x424`, recenters through [UID:0002QM][0x005059d0-0x00505bf8.MapPaneRecenterAndSendPosition](by-memory/0x005059d0-0x00505bf8.MapPaneRecenterAndSendPosition.md), updates the active [UID:00007B][LivingObjectPane](by-class/LivingObjectPane.md), normalizes one status value from `2` to `5` in the local-avatar branch, copies the full status blob into the active-object state area, clears three attached overlay panes, clears the active-object transient flag at offset `292`, clears `MapPane +0x3f0` when set, and refreshes its timer through the LivingObjectPane core.

For nonlocal living objects, an existing pane is updated through [UID:0001DE][0x0053a110-0x0053d818.LivingObjectPaneCore](by-memory/0x0053a110-0x0053d818.LivingObjectPaneCore.md) and moved to the new tile coordinates without reinserting it. If no pane exists, the method allocates a LivingObjectPane from the static pool, constructs it with the incoming status blob, starts or refreshes its timer, updates screen bounds through the MapPane object-position helper at `0x00506980`, and inserts the new pane through [UID:0002C9][0x005314a0-0x00531c10.ObjectListTypeDispatchInsertCategorize](by-memory/0x005314a0-0x00531c10.ObjectListTypeDispatchInsertCategorize.md) / `ObjectList::AddObjectPane`.
