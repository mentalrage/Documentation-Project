## Behavior

This island is the higher-level Standard MIDI File loader and WinMM stream-buffer filler paired with [UID:00023B][0x00526650-0x005270d5.MidiFileReaderAndSMFParserHelpers](by-memory/0x00526650-0x005270d5.MidiFileReaderAndSMFParserHelpers.md).

The load helper clears the document header fields, opens the source through either the memory/object adapter or Win32 file handle path, checks the `MThd` header, byte-swaps MIDI format/track-count/division fields, allocates one 40-byte record per track, checks `MTrk` chunks, allocates 0x400-byte track buffers, records track file offsets and remaining byte counts, reads initial data, decodes the first delta value, and seeks to the end of each track before processing the next one. On failure it closes the active source and unlocks/frees any allocated track buffers and the table.

The stream-fill helper is called by the MIDI stream open/callback paths. It uses parser scratch globals (`dword_69B870`, `dword_69B874`, `dword_69B878`, `dword_69B87C`, and `xmmword_69B880`) to resume partially emitted events, choose the next track with the lowest pending delta, parse the next event, encode it into the caller's stream buffer, and return negative status codes for parse error, end of stream, or output-buffer exhaustion.
