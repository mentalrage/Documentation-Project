The formal block intentionally contains a covered-by marker rather than a
standalone declaration. This is the same source-use-literal policy used by
other exact `.rdata` pages whose immediate references are already explained by
method source.

the two private MetaMan persistence methods, with the compiler/linker pooling
the identical literal into one `.rdata` object. The final empty-wide code unit
is generated by the old-MSVC map insertion path behind the accepted

separate named source-level object.
