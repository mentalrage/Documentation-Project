## Behavior

`LineIterator::ReadNextLine` returns the next UTF-16 line slice from the iterator's backing buffer and advances the current offset.

Observed layout:

| Offset | Meaning |
| --- | --- |
| `+0x00` | vtable |
| `+0x04` | inferred `m_text`: source wide-character buffer pointer |
| `+0x08` | inferred `m_length`: source length in wide characters |
| `+0x0c` | inferred `m_offset`: current offset in wide characters |

The method starts at `m_text + m_offset`, scans until newline character `0x000a` or end of buffer, updates `m_offset` after each consumed UTF-16 code unit, and constructs the output string from the old pointer through the new pointer. When a newline is encountered, the end pointer is after that newline; any delimiter trimming is downstream parser/string behavior.

`0x000a` is decimal 10 and `+0x0c` is offset 12 (Verified with int_convert.py).
