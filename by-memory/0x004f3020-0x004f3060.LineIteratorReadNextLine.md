## Behavior

`LineIterator::ReadNextLine` returns the next UTF-16 line slice from the iterator's backing buffer and advances the current offset.

| Offset | Meaning |

| `+0x04` | source wide-character buffer pointer |

| `+0x0c` | current offset in wide characters |

The method starts at `source + offset * 2`, scans until newline character `0x000a` or end of buffer, updates offset after each consumed character, and constructs the output string from the old pointer through the new pointer.
