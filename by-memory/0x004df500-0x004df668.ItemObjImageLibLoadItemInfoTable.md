## Corrected Classification

This page was originally named `LightInfoTableLoader`. Live IDA recheck shows that name is incorrect. The helper loads the `0x14`-byte [UID:0001UT][ItemInfo](by-type/by-struct/ItemInfo.md) `ItemInfo` table used by [UID:00006W][ItemObjImageLib](by-class/ItemObjImageLib.md) `ItemObjImageLib`, not the `0x1c`-byte [UID:0001UW][LightInfo](by-type/by-struct/LightInfo.md) `LightInfo` rows used by [UID:000076][LightObjImageLib](by-class/LightObjImageLib.md) `LightObjImageLib`.

The key ownership signals are:

- The selected resource names are `ITEM.TBL` at `0x0061c260` and `ITEM.TBD` at `0x0061c274`; both literals are also referenced by [UID:0002SD][0x004dec30-0x004dee1b.ItemObjImageLibConstructor](by-memory/0x004dec30-0x004dee1b.ItemObjImageLibConstructor.md) `ItemObjImageLib::ItemObjImageLib`.
- The helper uses full `ItemObjImageLib` object offsets: count at `this+0x08`, entry buffer at `this+0x0c`, and fallback row at `this+0x14`.
- The row stride is `0x14`, matching [UID:0001UT][ItemInfo](by-type/by-struct/ItemInfo.md) `ItemInfo`; `LightObjImageLib` uses a different constructor at `0x004df7e0`, `LIGHT.TBL`, and `0x1c`-byte [UID:0001UW][LightInfo](by-type/by-struct/LightInfo.md) `LightInfo` records.

## Behavior

The helper opens the current item metadata table, reads a row count, resizes the embedded protected item row array if needed, and copies each source row into either the matching table slot or the fallback slot.

Observed row-load order:

1. Read table count with `sub_49C4A0`.
2. If `count > 0` and it differs from the current count at `this+0x08`, allocate `count * 0x14` bytes, preserve existing rows with `_memmove`, free old storage, and update `this+0x08` / `this+0x0c`.
3. For each row, read fields into stack storage:
   - `+0x00` through `sub_49C4A0`.
   - `+0x04` through `sub_49C4A0`.
   - `+0x08` through `sub_49C4F0`.
   - `+0x0c` through `sub_49C4A0`.
   - `+0x10` as a boolean collapsed from a final `sub_49C4A0` integer result.
4. Copy the 16-byte leading row body plus the final dword/byte flag into the selected `ItemInfo` slot.
5. Destroy the local DAT stream/path object with `sub_49C160`.
