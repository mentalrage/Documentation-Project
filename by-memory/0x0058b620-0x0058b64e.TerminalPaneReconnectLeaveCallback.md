# 0x0058b620-0x0058b64e TerminalPane Reconnect Leave Callback

## Status

- Confidence: strong for range and callback role.
- Covered file/module: [UID:0000OI][TerminalPane](by-file/TerminalPane.md)
- Current Wave3 state: real IDA function, not emitted as an active `TerminalPane` method in `class_TerminalPane.cpp`.
- Recommended source name: `TerminalPane::OnReconnectOrLeave`.

## Function Role

This is the member callback installed by `TerminalPane::OnDisconnect` for the reconnect/leave alert. The callback chooses between restarting the terminal/reconnect flow and leaving through the application shutdown path.

## Behavior Notes

- Nonzero decision argument calls the terminal timer/restart helper at `0x005975e0` using the adjusted terminal-pane subobject at `this + 0xa4`.
- Zero decision argument calls the application leave/shutdown helper at `0x00464e40` through the global application pointer.
- The function has no ordinary direct callers because it is stored into a callback object by `TerminalPane::OnDisconnect`.

## IDA MCP Evidence

Checked on 2026-05-26:

- `lookup_funcs 0x0058b620` reports `sub_58B620`, size `0x2f`, ending at `0x0058b64f`.
- `xrefs_to 0x0058b620` reports a data reference at `0x0058b56d` inside `TerminalPane::OnDisconnect`.
- `callers 0x0058b620` reports no direct code callers.
- Decompilation shows the two-branch reconnect/leave dispatch described above.

## Ownership Decision

Keep this as `TerminalPane` source logic in `login/TerminalPane.cpp`. It should not be treated as an independent global helper just because it is callback-referenced rather than directly called.
