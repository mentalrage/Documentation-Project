## Behavior

The helper receives a `NewPredefinedFormArticleDialog`-family `this` pointer in `ecx`. It saves that pointer on the stack, loads the session/dialog-stack field at `this + 0x270`, and calls [UID:000132][0x004a0f40-0x004a14a7.BulletinSessionDialogStack](by-memory/0x004a0f40-0x004a14a7.BulletinSessionDialogStack.md) helper `0x004a1250`, which is documented as the previous-dialog lookup helper.

The returned dialog object is then used to reach its control container at `+0x1fc`. The helper requests control id `7`, follows the control payload pointer through `+0x108`, reads a 16-bit value at `+0x14c`, computes the layout/mode offset from `byte_66DA97`, and calls article navigation helper `0x004751c0` with:

- selected 16-bit item value from `[control_payload + 0x14c]`;
- hard limit `0x7fff`;
- mode/layout offset `-0x14` when `byte_66DA97 == 1`, otherwise `-0x10`.

The same callee pattern appears in transfer-reply alert callbacks, where existing IDA-backed documentation describes `0x004751c0` as the shared article navigation packet helper.
