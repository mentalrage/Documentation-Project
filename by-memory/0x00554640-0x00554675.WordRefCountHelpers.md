## Behavior Notes

- The initializer writes `1` to the first word of the object and returns `ecx`.
- The increment helper is a four-byte `inc word ptr [ecx]; retn` raw helper.
- The release helper decrements the same word, compares it to zero as a signed word, returns while the count is still positive, and otherwise pushes `ecx` into `sub_5C7526`.
- IDA decompiles `sub_5C7526` as a CRT free wrapper that forwards the block pointer to `j_j___free_base`; the extra pushed constant is stack-cleaned by the caller and does not change the decompiled one-argument free wrapper behavior.
- The `push 2; push ecx; call sub_5C7526; add esp, 8` release form resembles a deallocation helper called with an ignored extra flag/size argument, not a normal C++ method call. Treat the source shape as a small lifetime helper until an owning type is found.
