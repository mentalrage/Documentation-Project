Live IDA shows this body is `MapPane`-owned even though it embeds nation-table setup:

1. Calls the [UID:0001EA][0x00544460-0x00545086.PaneCore](by-memory/0x00544460-0x00545086.PaneCore.md) constructor path with a zero layer/container flag.
2. Stores the live pane into [UID:0000PR][g_activeMapPane](by-global/g_activeMapPane.md), then installs the primary and adjusted `MapPane` vtables documented by [UID:0002SQ][0x0061e71c-0x0061e7a0.MapPaneVtableData](by-memory/0x0061e71c-0x0061e7a0.MapPaneVtableData.md).

4. Clears selection, movement, cached-coordinate, and viewport state fields; stores the input tile dimensions into the `MapPane +0x404` and `MapPane +0x408` family; and computes the backing rectangle from [UID:0000T7][MapTilePixelDimensions](by-global/MapTilePixelDimensions.md) as `(tileWidth * (columns + 2), tileHeight * (rows + 2))`.
5. If [UID:0000Q3][g_objectNationMap](by-global/g_objectNationMap.md) is not allocated, opens [UID:0001RL][sobj-tbl](by-resource/sobj-tbl.md), reads [UID:0000Q4][g_objectRecordCount](by-global/g_objectRecordCount.md), allocates `count + 1` bytes, seeds slot zero to `0`, and stores the second one-byte field from each record into the compact map.
6. Registers the pane with the root/back-pane application state through the change-listener wrapper using message tag `1735356263`.
7. Copies root/back-pane bounds, allocates a `0x28`-byte [UID:0000YL][0x00462170-0x00462e03.AlphaMaskSurface](by-memory/0x00462170-0x00462e03.AlphaMaskSurface.md)-style selection/overlay surface sized from the current viewport rectangle, and stores it at `MapPane +0x3e0`.
8. Allocates an `88`-byte [UID:0000JP][GameServerConfig](by-file/GameServerConfig.md) nation-table object through [UID:0000T8][MemoryAllocationHelpers](by-global/MemoryAllocationHelpers.md), installs the `GameServerConfig` and protected-array vtables, sets capacity `10`, clears count/data fields, and stores [UID:0000Q1][g_gameServerNationTable](by-global/g_gameServerNationTable.md).
9. Clears the later map-state fields at the `MapPane +0x4c8` family, clears byte flags near `MapPane +0x90c` and `MapPane +0x90e`, and zeroes the effect-list pointer/count/capacity fields at `MapPane +0x100`, `MapPane +0x0f8`, and `MapPane +0x0fc`.
