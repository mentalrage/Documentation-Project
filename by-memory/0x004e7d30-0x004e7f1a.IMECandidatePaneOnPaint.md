## Behavior

`IMECandidatePane::OnPaint` draws the candidate-list popup. It fills the pane bounds with palette/color index `143`, draws the frame with index `128`, sets default text color `128`, then iterates `visibleCandidates` and draws every visible candidate string. For each row it moves the draw cursor to local X `1` and the row baseline. If the row index equals `selectedCandidateRow`, it fills a one-pixel-inset row rectangle, temporarily switches text color to `143`, draws the selected string, and restores text color `128`.

The target source-level row step is `GetLineHeight() + 2`. The selected row rectangle is:

- `left = 1`
- `top = row * (GetLineHeight() + 2) + 2`
- `right = bounds.right - bounds.left`
- `bottom = top + GetLineHeight() + 1`

The target does not use `candidateAnchorX` or `candidateAnchorY`; those fields are populated by [UID:00018B][0x004e7930-0x004e7b6c.IMECandidateShowCandidateList](by-memory/0x004e7930-0x004e7b6c.IMECandidateShowCandidateList.md) when sizing and positioning the popup.
