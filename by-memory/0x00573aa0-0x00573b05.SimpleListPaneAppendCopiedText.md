## Behavior

This raw helper appends a copied wide-string entry to the simple list. It calls the shared item-count helper at `0x004f3bd0` to obtain the append index, computes the source string length, allocates `(length + 1) * sizeof(wchar_t)`, initializes the allocation through `0x00516050`, copies the text with `_wcscpy_s`, then inserts the copied pointer through the shared `ListPane` insert helper at `0x004f3c00`.
