## Range And Behavior

| Range | IDA function | Behavior |
| --- | --- | --- |
| `0x004bede0-0x004bee35` | `sub_4BEDE0`, size `0x55` | Splits an RGB555 pixel into 5-bit channels, looks channels up through `dword_69B3D8` / `dword_69B3DC` using an intensity index, and repacks RGB555. |
