## Behavior Summary

The constructor opens `L"str.res"` through `DATFile`, then reads up to 1024 bytes per line until CR, LF, EOF, or line-limit. Byte `0x11` is converted to CR before `MultiByteToWideChar(0, 0, ...)`. Each converted line is separately heap-allocated and then copied from a temporary 1024-entry pointer array into the final string table.

The lookup helpers use the same object layout:

- `+0x4`: `wchar_t** strings`
- `+0x8`: `int stringCount`

Out-of-range ids return or copy `L"Invalid String ID"`.
