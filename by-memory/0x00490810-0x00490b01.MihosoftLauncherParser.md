## Behavior

This helper skips the executable path, tokenizes the remaining command line on spaces with `_wcstok_s`, and requires at least three tokens before accepting the parse. The first token must case-insensitively match the UTF-16 `Mihosoft` selector at `0x00617048`; the next two tokens are interpreted as host and port. Additional tokens below the loop cap are ignored.

For host tokens beginning with an ASCII digit, it splits on `.` and parses the first four decimal octets with the Visual C wide decimal integer helper at `0x005cea43`, storing the low byte of each octet into `param_1 + 0x2915b4`. For nonnumeric host tokens, it copies the wide host into `param_1 + 0x2915c4` through the `memmove` wrapper at `0x00516220`, converts it to an ANSI scratch buffer with `WideCharToMultiByte`, calls `gethostbyname`, and copies four resolved address bytes into `param_1 + 0x2915b4`.

On success it parses the port token with the same wide decimal helper and writes it to `param_1 + 0x2916c4`, sets `param_1 + 0x2916ca` to `1`, and sets state byte `param_1 + 0x28de28` to `5`.

Malformed token streams or selector mismatches format the UTF-16 message `이 버전의 바람의 나라는 전용 클라이언트입니다. 입력정보에 오류가 있습니다.` and show it through `MessageBoxW`, followed by `PostQuitMessage(0)` and `__loaddll(0)`. DNS failure uses the host-specific UTF-16 format string `이 버전의 바람의 나라는 전용 클라이언트입니다. 입력정보 "%s" 에 오류가 있습니다.` before the same exit path.
