## Summary

This is the modeled mouse handler for the ranking event scrollbar. It handles mouse-enter/leave, button press, drag tracking, release/reset, hover invalidation, and scroll-position changes.

The function is installed through the secondary control/event vtable. IDA decompilation shows the handler receives a subobject pointer and normalizes the full `RankingEventScrollPane` object as `ecx - 0xa0`.

For reconstruction, this should be implemented as a real `RankingEventScrollPane` virtual input handler, not as generated local struct declarations or an omitted scoped marker. The exact event type names are still open, but the event byte values and state transitions are IDA-confirmed.

## Behavior

Observed event cases:

| Event byte | Behavior |
| --- | --- |
| `0` | If active/pressed part `+0x104` is not `0xff`, invalidates the pane rectangle and returns true; otherwise returns false. |
| `1` | If the point is inside the pane and scrolling is enabled, hit-tests scrollbar part rectangles, records active part, may capture a drag anchor, starts the local scheduler/effect, invalidates affected rectangles, and updates scroll position for thumb/track interactions. |
| `3` | If an active part exists, releases local interaction state, stops the local scheduler/effect, clears active/hover state, invalidates affected rectangles, clears drag flag `+0xfb`, and returns true. |

Important helper calls:

- `0x0045a400` hit-tests the mouse point against part codes `0..4`.
- `0x0045a710` computes the dirty rectangle for a part before invalidation.
- `0x0045ac10` converts a drag/track point into a new scroll position and tells the owning event list pane to refresh.
- `0x005975e0` starts the local scheduler/effect after a press; `0x00597600` stops it on cancel/reset.
