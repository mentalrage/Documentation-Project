- IDA MCP recheck on 2026-06-06 again reports `sub_4A0D40` at `0x004a0d40` size `0x11` and `sub_4A0D60` at `0x004a0d60` size `0x11`.
- IDA MCP decompilation shows `0x004a0d40` reads `dword_69AE04` / [UID:0000R9][g_pItemHelpPane](by-global/g_pItemHelpPane.md), null-checks it, and calls its first vtable slot with literal argument `1`.
- IDA MCP decompilation shows `0x004a0d60` reads `dword_69AE00` / [UID:0000S9][g_pSimpleHelpPane](by-global/g_pSimpleHelpPane.md), null-checks it, and calls its first vtable slot with literal argument `1`.
- IDA MCP disassembly on 2026-06-06 shows both functions are seven-instruction null-checked virtual dispatch wrappers: `mov ecx, <singleton>`, `test ecx, ecx`, conditional return, load first vtable dword, `push 1`, and `call dword ptr [eax]`.
- IDA MCP `callers` on 2026-06-06 reports `0x004a0d40` callers at `0x004ed0b2` and `0x004ed8fd` inside `sub_4ECB50`, plus `0x0051b34d` (`sub_51B2C0`) and `0x0051f7ad` (`sub_51F720`), matching item/menu tooltip replacement flows.
- IDA MCP `callers` on 2026-06-06 reports the `0x004a0d60` caller at `0x00568e1c` inside `sub_568CB0`, matching shared simple-help cleanup before replacement.
- IDA MCP `callees` on 2026-06-06 reports no static callees for either helper because both calls are first-vtable-slot indirect dispatches.
- IDA MCP byte review on 2026-06-06 confirms `0x004a0d51-0x004a0d60` is fifteen `0xcc` bytes. The bytes immediately after `0x004a0d71` are also `0xcc`, closing the range before the next modeled code.
