## Signatures And Parameter Roles

Both helpers are namespace/free PacketBuffer routines. They have no object receiver and do not read a PacketBuffer instance or Socket state.

| Helper | Source shape | Parameter roles |
| --- | --- | --- |
| `PacketBufferReadAnsiString16` | free helper returning caller output | `StringBase *out` receives the converted caller string; `const unsigned char *packet` is the raw packet byte base; `int *cursor` is an in/out byte offset. |
| `PacketBufferReadAnsiBytes16` | free helper returning caller output | `StringBase *out` is caller-provided ANSI string storage; `const unsigned char *packet` is the raw packet byte base; `int *cursor` is an in/out byte offset. |

The `16` suffix names the two-byte length prefix width. It does not mean UTF-16 payload text. The packet payload bytes are ANSI/default-codepage bytes; only `PacketBufferReadAnsiString16` converts the temporary ANSI string into the caller's default/wide `StringBase` facade.

## Behavior

Both helpers decode a two-byte big-endian payload length from `packet[*cursor]` and `packet[*cursor + 1]`, advance the cursor past the length prefix, copy `length` payload bytes from `packet + *cursor`, then advance the cursor by the payload length.

`PacketBufferReadAnsiString16`:

- creates a local ANSI `StringBase` temporary;
- copies the payload span into that temporary through the bounded ANSI copy helper at `0x00582a50`;
- advances the caller cursor by the payload length;
- transfers/converts the temporary into the caller-provided output through the `0x00582830` `InitializeWideFromAnsiString` path;
- releases the temporary through `0x00582b30`;
- returns the caller output pointer.

`PacketBufferReadAnsiBytes16`:

- copies the payload span directly into the caller-provided ANSI `StringBase` storage through `0x00582a50`;
- advances the caller cursor by the payload length;
- returns the caller output pointer.

Both helpers are scalar packet field readers. They do not mutate packet-transform key tables, socket object state, feature-specific packet-handler state, or global game state.
