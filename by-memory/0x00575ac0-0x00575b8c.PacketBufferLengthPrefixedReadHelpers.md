## Covered Range

This file documents two adjacent two-byte length-prefixed packet readers found while splitting the former `0x00575abb-0x00575cb0` UNKNOWN row. IDA MCP confirms the first function is not referenced by direct code xrefs, while the second is called from `MainMenuPane` and `MapPane` packet handlers.

| Range | Current name | Notes |
| --- | --- | --- |
| `0x00575ac0-0x00575b42` | `sub_575AC0` | Reads a big-endian 16-bit length, copies that many bytes from `base + *cursor + offset`, advances the cursor, constructs/copies into an `LObject`-style string object, and destroys the temporary. |
| `0x00575b50-0x00575b8c` | `sub_575B50` | Reads a big-endian 16-bit length, copies the byte span into caller-provided storage through `sub_582A50`, advances the cursor, and returns the storage pointer. |

Internal `0xCC` padding at `0x00575b42-0x00575b50` is alignment between the two helpers, not source logic.
