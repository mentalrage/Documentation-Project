## Behavior

The code supports both horizontal and vertical orientation:

- orientation flag at `this + 0xfc`;
- part-size/table index at `this + 0xf8`;
- current position at `this + 0xfe`;

- enable/visible gate at `this + 0x102`;
- current hot/pressed part bytes around `this + 0x103` and `this + 0x104`;
- drag offset point at `this + 0x108`.

Part IDs line up with the geometry helper:
