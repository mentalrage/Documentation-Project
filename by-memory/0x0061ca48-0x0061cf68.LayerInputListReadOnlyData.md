# 0x0061ca48-0x0061cf68 Layer/Input/List Read-Only Data

## Range

- Address range: `0x0061ca48-0x0061cf68`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.

## Summary
