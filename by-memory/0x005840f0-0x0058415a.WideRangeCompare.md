## Behavior

This function compares two UTF-16 ranges. It receives begin/end byte addresses for the left range and begin/end pointers for the right range, compares up to the shorter character count, and returns `-1`, `0`, or `1` based on the first differing character or final length difference.

The return behavior matches a lexicographic wide-string range comparison:

- return `-1` when the left range sorts before the right range;
- return `1` when the left range sorts after the right range;
- return `0` when both ranges have the same length and content.

Observed calling shape:

```text
int WideRangeCompare(const wchar_t *lhsBegin,
                     const wchar_t *lhsEnd,
                     const wchar_t *rhsBegin,
                     const wchar_t *rhsEnd);
```

The implementation computes both character counts by subtracting begin from end and shifting by one, compares UTF-16 words in a tight loop, and only uses the final length comparison when all shared-prefix code units match.
