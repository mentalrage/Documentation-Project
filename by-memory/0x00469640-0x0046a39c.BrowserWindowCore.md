## Reconstruction Notes

- This is browser COM-host code, not generic windowing code.
- The `Invoke` switch tables and alignment bytes begin immediately after this function at `0x0046a39c`; those bytes are compiler-generated table data for the source-level switch and are tracked in [UID:0000VN][-ignored](by-memory/-ignored.md).
- Later thunks and navigation helpers for this class live in the `0x00470dd0-0x004710b7` part of the browser helper cluster.
