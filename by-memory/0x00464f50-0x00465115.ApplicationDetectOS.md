## Behavior

Detects and records the host Windows version/WOW64 state into the `Application` object.

Observed state writes:

- clears the WOW64 flag byte at `this + 0x18`, then sets it from `IsWow64Process(GetCurrentProcess(), &flag)` when `kernel32!IsWow64Process` is available;
- writes a 32-bit internal OS code at `this + 0x10`;
- writes a wide OS label into the SimpleUString-like field at `this + 0x854`;
- returns the string-buffer pointer through the `sub_584540` getter after assignment.
