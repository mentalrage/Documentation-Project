## Notes

The function writes the same profile layout consumed by `LoadUserProfileData`: fixed wide-string groups, simple wide-string objects, the dynamic string vector, compact shortcuts, 30 [UID:0001V1][MacroHotkeyRecord](by-type/by-struct/MacroHotkeyRecord.md) rows, and trailing flag pairs.

IDA MCP decompilation on 2026-05-25 and 2026-05-31 confirms the macro/hotkey row writer uses state at `g_pConfig + 0x28f2f0 + i * 0x108`, emits `T`/`S`/`I` for states `1`/`2`/`3`, and writes wide text from `g_pConfig + 0x28f2f4 + i * 0x108`.

IDA MCP `callers 0x0050aba0` on 2026-05-31 confirms seven currently visible callers from UI/settings paths: `0x005047f0`, `0x0053ddb0`, `0x0053ecf0`, `0x0053f0a0`, `0x0053f830`, `0x00541fa0`, and `0x005424b0`. That caller spread supports a shared profile-storage helper rather than ownership by one dialog class.

The emitted binary layout is documented in [UID:0001QL][client_profile_storage](by-meta/client_profile_storage.md), with the target `RegistryConfig` offsets in [UID:0001VR][RegistryConfigUserProfileBlock](by-type/by-struct/RegistryConfigUserProfileBlock.md).
