## Behavior

The constructor configures a small alert dialog around the active text-edit pane. It resolves localized string id `0xf1` through `sub_4F0350(dword_67A750, 0xf1)`, passes the result, `dword_67A740`, button table `off_622F44`, and literal `L"No"` into [UID:00012W][0x0049feb0-0x004a0686.AlertPaneCore](by-memory/0x0049feb0-0x004a0686.AlertPaneCore.md) / `sub_49FEB0`, then installs the three `CopyWindow` vtable pointers at offsets `+0x00`, `+0xa0`, and `+0xa4`.

`OnAccept` calls [UID:0000Q7][g_pActiveTextEditPane](by-global/g_pActiveTextEditPane.md)'s current target through `TextEditPane::SelectAll` at `0x00590520`, then clears the active text edit global. `OnCancel` only clears that global.
