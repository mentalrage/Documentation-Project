## Behavior

This helper decodes a compressed `ZPF` wrapper into an `EPFTileContext`-style tile context.

IDA MCP decompilation on 2026-06-03 shows the helper:

- clears/resets the destination tile context through `sub_458500`;
- validates the outer `ZPF` signature with `_strncmp`;
- reads the compressed payload length from the wrapper header;
- initializes an `AUTOBUF<unsigned char>`-style temporary buffer and allocates space for decompression output;
- inflates the compressed payload through `sub_414390`;
- clears the destination context again before consuming the decompressed payload;
- validates the decompressed inner `FPF` signature and version word `1`;
- allocates the destination tile context using dimensions from the inner FPF header at `+0x10` and `+0x12`;
- copies 16-bit pixel data from the FPF body offset at `+0x18`;
- finalizes the context through [UID:000200][0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels](by-memory/0x00458560-0x00458585.EPFTileContextNormalizePostDecodePixels.md).
