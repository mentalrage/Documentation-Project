## Summary

This `.rdata` span contains image-library vtables, `ProtectedArray` template vtables for image info records, DAT/resource table file names, EPF/EPD asset names, and image-loader error strings. It is source-owned data required by the image library and resource loading subsystem. The corrected end is the dword before the `IMEStatusPane` RTTI complete-object locator at `0x0061c360`.
