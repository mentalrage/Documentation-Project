## Behavior

This method applies a vertical flip over a rectangular source/destination span. It copies the source rectangle into local rectangle state, obtains current drawing/surface state from global render context `dword_67A764`, then walks each source scanline from top to bottom while moving the destination Y coordinate upward from the bottom of the target area. Each iteration calls the shared blit helper `0x004ba250` with a one-row source rectangle and the corresponding inverted one-row destination rectangle.

The hard-coded `384` screen-height term in the destination-Y calculation matches a vertical flip against the client render height used by the surrounding pixel-effect methods.
