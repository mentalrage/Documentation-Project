# 0x005435b0-0x00543665 ApplyPaletteEntryMovesToCollection

## Address Range

- Range: `0x005435b0-0x00543665`, start inclusive and end exclusive.
- Size: `0xb5` bytes.
- Entity kind: NexusTK-owned palette helper function.
- Rebuild handling: `source-authored`.
- IDA name at review time: `sub_5435B0`.
- Current direct parent: [UID:0000MA][Palette](by-file/Palette.md) Palette.

## Behavior

This helper applies DLPalette entry-move tables across every object in a list-like collection. For each collection entry, it retrieves the entry through vtable slot `+0x10`, treats the returned wrapper's first dword as the underlying `DLPalette *`, then applies each byte-pair move from that palette object's table.

Each move pair is:

| Byte | Role |
| --- | --- |
| first byte | destination palette index |
| second byte | source palette index |

For every pair, the helper saves the 16-bit palette entry at the source index, shifts intervening entries in the native color table at offset `+0x2c`, and stores the saved entry at the destination index. This is the collection/list form of [UID:0001E5][0x00542fa0-0x00543020.DLPaletteApplyPaletteEntryMoves](by-memory/0x00542fa0-0x00543020.DLPaletteApplyPaletteEntryMoves.md) `DLPalette::ApplyPaletteEntryMoves`; it duplicates/applies the same DLPalette entry-move kernel across collection entries and should not be merged with the single-palette method.
