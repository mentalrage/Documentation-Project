## Behavior

This is the general item sprite draw path. It resolves the item frame through the current `ITEM.EPF` path, prepares palette/render state from the `ItemInfo` row and caller `paletteFlags`, dispatches the low-level surface render callback, and optionally emits overlay/highlight mask output through the alpha-frame helper when `overlayMask` is non-null.

Current B003 reanalysis gives the source-facing flow:

1. If the shared image-library load/error guard at `0x0069b420` is set, return without drawing.
2. Initialize a stack `EPFTileContext` through `EPFTileContext::InitTileContext`.
3. Compute the frame entry as `static_cast<unsigned short>(itemId + 0x4000)`.
4. Use `m_itemInfos.m_entries[index]` when the computed entry is in range; otherwise use the inline default/fallback `ItemInfo` row at object `+0x14`.
5. If `PaletteLib::IsPaletteFilterEnabled(g_pPaletteLib)` is true and `ItemInfo::allowPaletteFilter` is false, skip the color draw while still allowing the optional overlay-mask pass.
6. Resolve `ITEM.EPF` through `ResourceLayoutTable::LookupLayoutEntry(g_pEPFLib, L"ITEM.EPF", entryIndex, &tileContext)`.
7. Resolve the draw palette with `PaletteLib::GetSlotPalette(g_pPaletteLib, 10, itemInfo.paletteSlot, paletteFlags >> 5)`.
8. Select a stack `SurfaceSpriteBlitOptions`-style record or pass null options:
   - no alpha and no palette flags: null options, caller `dstRect`;
   - no alpha with palette flags: kind `2`, palette/tint byte at `+0x08`, secondary byte zeroed at `+0x1c`, caller `dstRect`;
   - alpha with no palette flags: kind `1`, float alpha at `+0x04`, resolved frame rectangle;
   - alpha with palette flags: kind `3`, float alpha at `+0x04`, palette/tint byte at `+0x08`, no write to secondary byte `+0x1c`, resolved frame rectangle.
9. Dispatch through slot 2 `g_pfnBlitSprite` / `SurfaceSpriteBlitProc` at `0x0069b3e8` with `drawOwner` as the render receiver in `ecx`, the local `EPFTileContext`, source/destination `RectBounds`, mode `1`, palette pointer, and nullable options pointer.
10. If `overlayMask` is non-null, call `AlphaMaskSurface::DrawEncodedAlphaFrame` at `0x00462f20` with the same source context, the resolved frame rectangle as source origin, `dstRect[3]`/`dstRect[1]` as alpha ramp end/start Y, `static_cast<unsigned char>(overlayStrength * 32.0f + 0.5f)` as the end alpha, start alpha `0`, and blend mode `1` add.

The method is part of the item-image module, not a UI-pane helper. UI callers supply destination rectangles, item ids, palette/tint bits, and optional overlay state, but the method owns the item-specific row lookup, palette slot `10` policy, EPF resource choice, and optional overlay integration.
