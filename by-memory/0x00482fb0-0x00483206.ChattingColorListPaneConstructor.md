## Behavior

This constructor builds one of the two color swatch lists embedded in the chat color dialog. It constructs the base `ListPane` with 18-pixel swatch cells, installs `ChattingColorListPane` vtables, stores the owning [UID:00001T][ChattingColorPane](by-class/ChattingColorPane.md) pointer at `this+0x14c`, stores the primary/secondary color-table mode flag at `this+0x150`, and appends 80 color entries.

The two direct constructor callers are both inside [UID:0002FX][0x004824e0-0x00482b01.ChattingColorPaneConstructor](by-memory/0x004824e0-0x00482b01.ChattingColorPaneConstructor.md):

| Caller | Mode argument | Owner field initialized |
| --- | --- | --- |
| `0x00482837` | `1` | first color-list child at owner `+0x270` |
| `0x0048295d` | `0` | second color-list child at owner `+0x274` |

When mode flag `a3` is false, the constructor zeros the first swatch value before adding the 80 list entries. That makes the two lists similar but not identical at index zero.
