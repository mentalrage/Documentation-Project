# 0x0062d02c-0x0062d418 Spell Inventory/Macro Read-Only Data

## Range

- Address range: `0x0062d02c-0x0062d418`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and spell/macro resource strings must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains spell inventory pane vtables, macro edit control pane vtables, and spell/macro resource and hotkey strings. It ends before `StartupWindow`/notice strings.

Parent handling: keep `AUTOGEN_PARENT_UID` blank.
