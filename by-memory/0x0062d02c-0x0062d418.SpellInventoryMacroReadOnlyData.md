# 0x0062d02c-0x0062d418 Spell Inventory/Macro Read-Only Data

## Range

- Address range: `0x0062d02c-0x0062d418`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and spell/macro resource strings must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains spell inventory pane vtables, macro edit control pane vtables, and spell/macro resource and hotkey strings. It ends before `StartupWindow`/notice strings.

## Observed Contents

| Address | Item | Notes |
|---|---|---|
| `0x0062d02c-0x0062d174` | spell inventory vtables | `SpellInventoryPane`, `NewSpellInventoryPane`, and `SpellInventoryPane2`. |
| `0x0062d17c-0x0062d1c2` | spell inventory strings | `spellinv.epd`, palette/resource fragments, and spell inventory EPF strings. |
| `0x0062d1e4-0x0062d3c4` | macro edit vtables | `SpellMacroEditControlPane`, `NewMacroEditControlPane`, and `IntegrateMacroEditControlPane`. |
| `0x0062d3cc-0x0062d410` | macro strings | `Ctrl+D`, `Spell`, `Item`, `Alt+D`, and single-character resource fragments. |

## Evidence

- IDA MCP `py_eval` on 2026-05-28 reports spell inventory and macro edit vtables in this range.
- Vtable xrefs point to `SpellInventoryPanes` and `MacroEditControlPanes` executable ranges.
- Resource strings have xrefs in spell inventory setup and macro edit control code, including `0x0057c488`, `0x0057d49b`, `0x0057fb80`, and `0x00580095`.
- The next named item at `0x0062d418` is `BaramNoticeWnd_Class`, used by the startup/update notice window.

## Reconstruction Notes

- The spell inventory and macro edit controls are physically adjacent here but should remain source-owned by their feature modules.
- The one-letter resource fragments should not be renamed until the surrounding UI loader code is rewritten.
