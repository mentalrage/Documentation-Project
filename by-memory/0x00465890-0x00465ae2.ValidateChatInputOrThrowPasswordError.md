## Behavior

Copies the protected token from `0x0067a940` into a 32-wide-character stack buffer, decodes that local copy with the same incrementing `word_66D410` XOR seed used by the setter, and checks whether the caller-supplied wide text contains the decoded password via `wcsstr`.

On the non-throwing path it clears the decoded stack copy before returning.
