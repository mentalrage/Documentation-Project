## Summary

This helper resets a 24-byte SSO-15 byte-string object. It releases heap storage when the capacity field at `+0x14` is at least `0x10`, applies the MSVC large-allocation header validation path for allocations of `0x1000` bytes or more, then restores the object to empty inline state by writing length `0`, capacity `15`, and a NUL byte at offset `0`.

The body is not FileDownloader code.
