# 0x004b99c0-0x004b99ee Surface Palette Callback Forwarder Raw

## Status

- Entity kind: raw source-shaped helper code inside the Surface paint helper neighborhood; IDA does not model it as a function.
- Disposition: reconstructable project code, but unassigned until the raw-entry liveness and final source name are better proven.
- Likely owner: shared Surface/GrafPort render helpers, adjacent to [UID:000165][0x004b9820-0x004ba24a.SurfacePaintHelpers](by-memory/0x004b9820-0x004ba24a.SurfacePaintHelpers.md).

IDA reports no function object at `0x004b99c0` or `0x004b99ee`; decompilation at `0x004b99c0` fails because the range is not function-modeled.

## Behavior

The raw helper preserves the incoming `ecx` object pointer in `esi`, asks the process palette service for a palette/color context using the fifth stack argument, then restores `ecx` and forwards the original first four stack arguments plus the resolved context through the alternate render callback slot.

Pseudocode shape, using provisional names:

```cpp
// Raw code at 0x004b99c0, not an IDA function.
return surfaceCallbacks->alternatePaletteBlit(
    this,
    arg1,
    arg2,
    arg3,
    arg4,
    PaletteLib_lookup(g_pPaletteLib, arg5));
```

Do not treat that C++ snippet as final reconstruction. The callback typedef, exact helper name, and the meaning/order of the stack arguments still need sibling callback comparison before this can be promoted to source output.
