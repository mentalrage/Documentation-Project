## Behavior

This is the public `DATFileMgr` wrapper form of the internal `_DATFileMgr::FindEntryByName` helper. It parallels [UID:00012C][0x0049be70-0x0049be7c.ForwardLoadDATFileIndex](by-memory/0x0049be70-0x0049be7c.ForwardLoadDATFileIndex.md), which forwards from the public wrapper object to the private manager object for archive loading.
