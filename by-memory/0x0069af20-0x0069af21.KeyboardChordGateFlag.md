# 0x0069af20-0x0069af21 KeyboardChordGateFlag

## Status

- Entity kind: global-data byte flag.
- Disposition: reconstructable NexusTK project global state.
- Rebuild handling: source-declared/generated-binary.
- Likely owner: application event/input dispatch module.
- Confidence: strong for address and flag use; medium for final source name.

## Storage

`0x0069af20` is a one-byte flag currently named `byte_69AF20` in IDA. The flag is updated from the application input/event dispatcher when Ctrl/Shift keyboard state changes.

Candidate source shape:

```cpp
static bool g_keyboardChordGate;
```

## Evidence

- IDA MCP byte review reports a named one-byte `.data` item at `0x0069af20`.
- All direct xrefs are from `0x004a7130`, which refreshes keyboard state, checks `GetAsyncKeyState(VK_LSHIFT)` and `GetAsyncKeyState(VK_CONTROL)`, and toggles this flag around shortcut dispatch.
- The range immediately follows the 256-byte keyboard-state buffer and companion dwords documented in `KeyboardStateGlobals`.
