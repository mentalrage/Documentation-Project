## Evidence

- IDA MCP confirms `0x00583210`, `0x00583280`, `0x00583720`, `0x00583840`, `0x005840f0`, and `0x005845b0` as real functions with exact child ranges now split above.
- `0x00583280` has broad caller fan-in from application startup/initialization, patching, browser, sound, VirusChecker, and UI helpers.
- `0x00583210` callers are SoundManager-style track-list/playback helpers.
- `0x005845b0` forwards stored and literal ranges into `0x005840f0`, and reads the stored length from the header field at data pointer minus eight bytes.
- `callers`/`callees` checks show the ANSI and wide format wrappers each funnel into their matching worker; `0x005840f0` has many callers and no callees, supporting utility comparator status.
- [UID:0001J3][0x005832f0-0x00584d7e.LObjectStringReleaseFormatAndMutation](by-memory/0x005832f0-0x00584d7e.LObjectStringReleaseFormatAndMutation.md) documents the shared release/format/mutation continuation that these wrappers call.
- Active generated source omits these methods; they are currently present in `class_SimpleUString.cpp.disabled`.
