# 0x00482400-0x004824e0 GetChatButtonAtPoint

## Status

- Confidence: strong for code range, switch-table tail, signature, and chat-handle ownership.
- Covered file/module: [UID:0000I5][Chatting](by-file/Chatting.md)
- Current generated sources: `recovered/GetChatButtonAtPoint_00482400.cpp` and call sites in `class_ChattingHandlePane.cpp`.
- Recommended source name: file-local `GetChatButtonAtPoint` or `ChattingHandlePane::HitTestButton`.

## Function Role

This helper hit-tests the four fixed regions used by [UID:00001V][ChattingHandlePane](by-class/ChattingHandlePane.md). It returns the button index `0..3`, or `-1` when the mouse coordinate is outside all regions.

The function code ends at `0x004824c9`, but the compiled switch jump table at `0x004824cc-0x004824e0` belongs to this helper and is included in the by-memory range.

## Signature Decision

The correct source-facing signature is coordinate based:

```cpp
static signed char GetChatButtonAtPoint(int mouseX, int mouseY);
```

Current `simroot_v2/recovered/GetChatButtonAtPoint_00482400.cpp` already has the correct shape. Current `simroot_v2/class_ChattingHandlePane.cpp` is wrong where it emits `GetChatButtonAtPoint(this, eventData)`.
