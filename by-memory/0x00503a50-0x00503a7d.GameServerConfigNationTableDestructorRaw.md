## Behavior

The body restores the `GameServerConfig` vtable, restores the embedded `ProtectedArray<GameServerConfig::NationEntry>` vtable, frees the dynamic entry backing buffer at object offset `0x0c`, clears [UID:0000Q1][g_gameServerNationTable](by-global/g_gameServerNationTable.md), and tail-jumps to the base cleanup routine.

## IDA Evidence

- `lookup_funcs` reports `0x00503a50` as not a defined function.
- Raw disassembly shows destructor-shaped code beginning at `0x00503a50`.
- The final instruction is a tail `jmp sub_4F4A90` beginning at `0x00503a78`; the jump bytes run through `0x00503a7c`, so the exact exclusive end is `0x00503a7d`.
- `0x00503a7d-0x00503a80` is `0xcc` padding before [UID:0002HX][0x00503a80-0x00503b58.GameServerConfigCopyNationEntryOrFallback](by-memory/0x00503a80-0x00503b58.GameServerConfigCopyNationEntryOrFallback.md).

## Boundary Notes

Older notes described this as `0x00503a50-0x00503a78`, but that truncated the tail-jump instruction. The corrected byte range is `0x00503a50-0x00503a7d`.
