## Function Role

IDA models this function as `sub_524870`, half-open range `0x00524870-0x00524c55`, size `0x3e5`. It lazily materializes the decompressed metadata table payload stored in `MetaTable::m_keyData` into a `std::map<SimpleUString, std::vector<SimpleUString>>`-style row map keyed by wide `SimpleUString` row names.

The helper:

- exits early when `m_keyData` is null;
- reads the decoded table row count as a big-endian/network-order 16-bit value from the start of `m_keyData` through `PacketBufferReadUInt16BE`;
- for each row, reads a multibyte row key, converts it to UTF-16 with `MultiByteToWideChar`, and assigns it to a local `SimpleUString`;
- reads the row's value count as a big-endian/network-order 16-bit value;
- for each value, reads a big-endian/network-order 16-bit length-prefixed multibyte string, converts it to UTF-16, and appends it to the row's `std::vector<SimpleUString>`-style value span;
- finds or inserts a [UID:0001V7][MetaTableRowNode](by-type/by-struct/MetaTableRowNode.md) for the row key, represented at source level as `m_rows[rowKey].push_back(valueText)`;
- frees the decoded payload buffer after successful materialization and sets `m_isLoaded` at `MetaTable +0x18`.

## Decoded Payload Shape

The body supports the current [UID:0001V6][MetaTableDecodedPayload](by-type/by-struct/MetaTableDecodedPayload.md) hypothesis:

```text
uint16be rowCount
repeat rowCount:
  uint8 keyByteLength
  char[keyByteLength] keyBytes
  uint16be valueCount
  repeat valueCount:
    uint16be valueByteLength
    char[valueByteLength] valueBytes
```

Both key and value byte strings are converted through `MultiByteToWideChar(0, 0, ...)`, so current evidence points to process ANSI code page payload strings rather than UTF-8 or UTF-16 table payload strings.

2026-05-31 IDA MCP recheck confirms the full parser loop: the function reads the 16-bit row count from `this[2]`, advances a byte cursor through one-byte row-key lengths, two-byte value counts, two-byte value lengths, and byte payload spans, converts each string through `MultiByteToWideChar(0, 0, ...)`, inserts or finds the row node, appends values, frees the decoded buffer, clears `this[2]`/`this[3]`, and sets the loaded/materialized flag at byte offset `+0x18`.

2026-06-27 B014 amendment corrects the 16-bit field endianness: `sub_575480` at `0x00575480` is the shared `PacketBufferReadUInt16BE` helper and returns `a1[1] + (a1[0] << 8)`.
