# 0x00553ac0-0x00553b05 Queue WriteSlot Raw

## Status

- Disposition: reconstructable NexusTK project code with raw-function boundary caveat
- Entity kind: raw method-shaped helper
- Owner class: [UID:0000BF][Queue](by-class/Queue.md)
- Likely source module: [UID:0000MW][Queue](by-file/Queue.md)
- Confidence: strong for behavior, class ownership, slot layout, and byte boundaries; medium-high for final method name because IDA still does not model the raw start as a function.

## Behavior

This helper writes one fixed-size record into the circular queue at `writeIndex`. It computes `buffer + writeIndex * slotSize`, copies `slotSize` bytes from the caller source pointer, then advances `writeIndex`, wrapping back to zero once it reaches `slotCount - 1`.

Layout evidence:

| Offset | Meaning |
| --- | --- |
| `+0x04` | slot byte size |
| `+0x08` | slot count/wrap limit |
| `+0x0c` | backing buffer |
| `+0x14` | write index |

## Boundary Notes

IDA does not currently model `0x00553ac0` as a function and reports no direct xrefs to this raw start. The bytes are aligned, method-shaped, and end at `retn 4` at `0x00553b02`.

2026-06-01 IDA MCP byte review corrects the end-exclusive range to `0x00553b05` because the `retn 4` instruction at `0x00553b02` is three bytes (`c2 04 00`). The following `0x00553b05-0x00553b10` span is `0xcc` alignment padding before [UID:0001FQ][0x00553b10-0x00553b55.QueueReadSlotRaw](by-memory/0x00553b10-0x00553b55.QueueReadSlotRaw.md).

## Evidence

- IDA MCP `lookup_funcs 0x00553ac0` reports `Not a function`.
- IDA MCP raw `disasm 0x00553ac0` shows slot copy through memory-manager copy helper `0x00516220`, write-index arithmetic, wrap to zero, and `retn 4`.
- `0x00553ac6` calls `sub_516030`, then `0x00553ade` calls [UID:0000L7][MemoryMan](by-file/MemoryMan.md)-owned copy helper `sub_516220` with destination `buffer + writeIndex * slotSize`, source argument, and copy size `slotSize`.
- `0x00553ae3-0x00553afd` implements wrap handling: compare `slotCount - 1` against `writeIndex`, store zero at `+0x14` when at/after the limit, otherwise store `writeIndex + 1`.
- `xrefs_to` and `callers` still report no direct references to the raw start, matching the compact raw-helper treatment in the queue cluster.
- Current `source-3/simroot_v2/class_Queue.cpp` omits this helper.
