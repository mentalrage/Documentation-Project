## Behavior

This range contains two raw helper-shaped routines after `MenuVarietyPane`'s tiny virtual helper and before the selector constructor.

The first routine at `0x005bc890-0x005bc8d6` accepts an index/state value and an output rectangle pointer. For state `0`, it builds the fixed menu button rectangle `left=0`, `top=0`, `right=0x3d`, `bottom=0x18` through `0x004b7c50`. For `-1` or other nonzero values, it writes an invalid rectangle using `-1` on all edges. It returns with `retn 8`.

The second routine at `0x005bc8e0-0x005bc96a` loops over two possible button states, builds the same rectangle shape for state `0` and an invalid rectangle for the other state, then calls `0x004b7e80` with the caller point/rectangle context. It returns the matching state byte, or `0xff` if no state matches.
