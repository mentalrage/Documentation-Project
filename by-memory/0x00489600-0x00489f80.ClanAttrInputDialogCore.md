## Behavior Notes

- The constructor calls the dialog base constructor with an empty wide string, then stores primary/secondary/tertiary vtables at `this+0x000`, `this+0x0a0`, and `this+0x0a4`.
- The packet payload supplies six `{ length, bytes }` strings beginning with the length byte at `packet+3`. Each string is copied to a local multibyte buffer, locally terminated, converted with `MultiByteToWideChar`, and wide-terminated. The first converted string is stored persistently at `this+0x26c`; the remaining converted strings are used while creating the visible labels/default text for the `DLGCLAN2.EPF` dialog.
- Persistent submitted-field storage is `this+0x26c`, `this+0x46c`, `this+0x66c`, and the 16-bit `this+0x86c` value. The OK handler updates `+0x46c/+0x66c/+0x86c` before dispatching the derived confirmation hook.
- Controls are fetched through the inherited control host pointer at `this+0x1fc`; control id `1` is OK, id `2` is Cancel, and ids `8`, `9`, and `10` are the required submitted fields.
- `OnInputEvent` reads [UID:0002B5][0x0067adc4-0x0067adec.UiChatClanSingletonSlots](by-memory/0x0067adc4-0x0067adec.UiChatClanSingletonSlots.md) slot `dword_67ADE4` (`g_pClanStatusPane`) and dispatches through the secondary view at `+0xa0` when the event byte at `event+4` is `3`.
