# 0x00460c90-0x00460d51 RGB565 Alpha Map MMX Blocks

## Status

- Disposition: reconstructable NexusTK render support code.
- Entity kind: free render helper.
- Likely source file: [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) `SoftwareBlend16`.
- Confidence: strong for exact boundary, sole caller, constants, row/block behavior, and padding; medium-high for final source-facing helper name/signature.
- Rebuild handling: `source-authored`.

## Address Range

`0x00460c90-0x00460d51`.

The following `0x00460d51-0x00460d60` bytes are alignment padding.

## Behavior

This is the four-pixel MMX block path for RGB565 alpha-map multiplication. The parent `sub_460410` helper computes a `width / 4` block count, calls this routine when that count is positive, advances the RGB565 row pointer by `blockCount * 8` bytes and the alpha-map pointer by `blockCount * 4` bytes, then handles the remaining pixels with the scalar tail.

The block helper receives an RGB565 row pointer, RGB565 row pitch, alpha-byte row pointer, alpha row pitch, block count, and row count. Each inner iteration loads four alpha bytes with `movd`, expands them to four words with `punpcklbw`, loads four RGB565 pixels with `movq`, independently scales/clamps the red, green, and blue components, and writes the packed RGB565 result back in place. Row advancement uses the two supplied pitches, and the helper exits through `emms`.
