## Behavior Summary

The helper computes a menu-item rectangle for the pre-login `MainMenuPane` menu. Index `-1` clears the output rectangle by passing four zero coordinates to the shared rectangle initializer. Otherwise the helper selects one of two coordinate families from [UID:0000SW][g_useEpfAssets](by-global/g_useEpfAssets.md), historically named `byte_66DA97` in IDA:

| Layout branch | Coordinates |
| --- | --- |
| `g_useEpfAssets == 1` | EPF/current layout: left `781`, top `493 + 41 * index`, right `972`, bottom `532 + 41 * index`; item height `39`, pitch `41`. |
| legacy branch | EPD/legacy layout: left `467`, top `299 + 30 * index`, right `640`, bottom `329 + 30 * index`; item height `30`, pitch `30`. |

The only behavioral callee is [UID:00015S][0x004b7c30-0x004b7f87.RectGeometryHelpers](by-memory/0x004b7c30-0x004b7f87.RectGeometryHelpers.md) helper `InitRectBounds` at `0x004b7c50`, which initializes the caller-supplied four-int `RectBounds`.
