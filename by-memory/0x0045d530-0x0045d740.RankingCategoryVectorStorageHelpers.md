## Purpose

This helper island contains teardown, allocation, and range-copy support for the ranking category collection and its embedded user-entry vectors. It is tightly coupled to the 688-byte `RankingCategoryRecord` layout and 76-byte `RankingUserEntry` layout, but the source-level reconstruction should probably represent these as containers rather than manually retaining every out-of-line helper.

## Reconstruction Notes

These helpers are most useful as layout evidence. They prove:

- `RankingCategoryRecord` owns an embedded vector-like user-entry member at offset `+0x258`.
- `RankingUserEntry` records are 76 bytes.
- `RankingCategoryRecord` records are 688 bytes.
- Copying a category record must deep-copy the embedded user-entry vector.

The final C++ should avoid fossilizing generated names like `sub_45D5F0`; use source-level containers and meaningful helper names only if an out-of-line helper is still needed after the class layout is stabilized.
