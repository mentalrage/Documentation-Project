## Behavior

The constructor initializes the embedded fitting-room item-shop catalog state:

- initializes the locale/name string at `this + 0x000`;
- creates and initializes category lookup storage at `this + 0x220`;
- clears the cache-loaded byte at `this + 0x24c`;
- initializes the encode and decode small-string buffers at `this + 0x250` and `this + 0x268`;
- copies the locale string and the two cache transform keys `CASHEncodeDecodeByChris` and `sirhCyBedoceDedocnEHSAC`;
- resolves the user Documents folder with `SHGetFolderPathW`;
- creates `Documents\NexusTK` and `Documents\NexusTK\ItemShop` when needed;
- stores the cache path as `Documents\NexusTK\ItemShop\ItemShop.jbn`;
- opens that cache in binary read mode, decodes it with [UID:0002E8][0x00422b30-0x00422b93.FittingRoomCatalogTransformPersistedBuffer](by-memory/0x00422b30-0x00422b93.FittingRoomCatalogTransformPersistedBuffer.md), and parses it with [UID:0002E9][0x00422740-0x00422919.FittingRoomDialogItemStateLoadEncodedStateBuffer](by-memory/0x00422740-0x00422919.FittingRoomDialogItemStateLoadEncodedStateBuffer.md).

If cache parsing succeeds, it sets the cache-loaded byte to `1`.
