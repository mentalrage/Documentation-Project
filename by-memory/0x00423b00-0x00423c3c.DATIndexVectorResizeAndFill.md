## Behavior

`DATIndexVector::ResizeAndFill` treats the requested logical count as paired 32-bit slots. It ensures capacity for `entryCount * 2`, fills the active range with the stored fill value, then updates `lastIndex` to `entryCount - 1` and stores the logical `entryCount`.
