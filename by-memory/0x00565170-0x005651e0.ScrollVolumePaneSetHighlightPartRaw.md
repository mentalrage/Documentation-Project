## Behavior

This raw helper updates the highlighted slider part byte at `this + 0x103`. If the previous highlighted part is not `0xff`, it computes that part rectangle through `0x00565010` and invalidates it through the pane virtual slot at `+0x20`. If the new part is not `0xff`, it computes and invalidates the new part rectangle. It then stores the new part code at `+0x103`.
