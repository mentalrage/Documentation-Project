## Behavior

This constructor builds the item picker used while adding items to an active mix dialog.

Observed flow:

1. Calls the `AddItemDialog` base constructor at `0x004ae4c0` with the constructor arguments `(0, 1)`.
2. Installs the `AddMixingItemDialog` primary, secondary, and tertiary vtables at object offsets `+0x00`, `+0xa0`, and `+0xa4`.
3. Stores the owning `MixItemDialog *` argument at object offset `+0x270`.
4. Fetches the current mix-list rows from the owner dialog control at `owner + 0x1fc`, child selector `5`, row-storage offset `+0x108`.
5. Fetches this picker dialog's available item rows from its own control at `this + 0x1fc`, child selector `3`, row-storage offset `+0x108`.
6. Iterates each already-selected mix row, compares the row payload item id byte against available picker rows, and removes any matching available row through the list remove helper.

The result is a normal `AddItemDialog`-style item picker with rows already present in the parent mix filtered out.
