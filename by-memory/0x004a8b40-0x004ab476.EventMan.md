## Evidence

- Live IDA MCP recheck on 2026-06-05 confirms every listed `EventMan` method boundary, including constructor `0x004a8b40-0x004a8f13`, timer tick `0x004aa200-0x004aa22b`, cursor dispatch `0x004aa3b0-0x004aa46b`, and scalar deleting destructor `0x004ab440-0x004ab476`; `0x004ab476-0x004ab480` is ten `CC` bytes.
- Live IDA MCP function scan on 2026-06-05 confirms the non-contiguous split: EventMan methods are interleaved with small gap neighbors, free IME/payload event factories at `0x004a9a40-0x004aa1b3`, and base `Event`/other event-layer helpers that are not class methods.
- Live IDA MCP read-only data check on 2026-06-05 confirms the EventMan data run begins at `0x006196b0`, with scalar deleting destructor slot `0x006196b4 -> 0x004ab440` and timer slot `0x006196b8 -> 0x004aa200`; following words belong to adjacent read-only data, not additional EventMan method slots.
- Live IDA MCP caller evidence on 2026-06-05 confirms the constructor has the single application-initialization caller at `0x0046463f`, `GetCursorPosition` has broad UI helper fan-in, `DispatchCursorEvent` is called by `ForwardCursorEvent` and `OnTimerTick`, and the scalar deleting destructor is vtable-only.
- Live IDA MCP callees on 2026-06-05 confirm `OnTimerTick` calls `DispatchCursorEvent` and the 20 ms timer scheduler at `0x005975e0`; `DispatchCursorEvent` constructs a stack `Event`, calls the dispatcher at `0x004a6ef0`, and tears the temporary event down; `HandleKeyRelease` constructs/tears down a key-release record and calls the UserPane spacebar-release gate without a dispatcher callee.
