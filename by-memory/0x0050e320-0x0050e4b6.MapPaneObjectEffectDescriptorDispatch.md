# 0x0050e320-0x0050e4b6 MapPane Object Effect Descriptor Dispatch

## Status

- Disposition: reconstructable NexusTK project code.
- Entity kind: MapPane helper function.
- Likely source module: [UID:0000L3][MapPane](by-file/MapPane.md)
- Confidence: strong for function boundary and MapPane ownership, medium for final source-facing name.

## Address Range

- Start: `0x0050e320`
- End: `0x0050e4b6`
- IDA name: `sub_50E320`
- Boundary evidence: IDA MCP reports a real function at `0x0050e320-0x0050e4b6`; raw bytes show `retn 0x10` at the end and ten `0xcc` bytes before the next `MapPane` packet-handler function at `0x0050e4c0`.

## Behavior

The helper receives a `MapPane`, object id, descriptor/resource id, effect argument, and a small flag. It:

- resolves an effect/descriptor record through `dword_69B44C` using `sub_4DE3E0`;
- looks up the target object through the `MapPane + 0x424` object list;
- checks two descriptor rectangles or bands from the resolved record;
- searches two object-owned child collections for a child whose `+0x148` field matches the resolved descriptor id and whose state passes [UID:00023H][0x00538bb0-0x00538bb7.LivingObjectPaneGetEntityId](by-memory/0x00538bb0-0x00538bb7.LivingObjectPaneGetEntityId.md);
- calls `sub_50EB90` when an existing child can be reused;
- otherwise calls `sub_50EA30` to create/apply a new object effect descriptor.

## Caller Evidence

IDA `xrefs_to 0x0050e320` reports callers at:

- `0x005116cc` inside `0x00511440-0x00511703`, a MapPane spawn/movement/chat packet handler.
- `0x00511d34` inside `0x00511c90-0x00511dae`, another MapPane object packet helper.
- `0x0053bac5`, a small object-pane neighborhood wrapper that forwards `dword_67A764` / `g_activeMapPane`.
- `0x005a2ee0`, a user/profile pane path that forwards to active `MapPane` when the new asset mode flag is enabled.

This is MapPane-facing behavior even though two callers are outside the main MapPane source range.

## C++ Reconstruction Sketch

```cpp
void MapPane::ApplyObjectEffectDescriptor(
    unsigned int objectId,
    int descriptorId,
    int effectArg,
    bool alternateBand)
{
    EffectDescriptor desc;
    g_effectDescriptorLib->GetDescriptor(descriptorId, &desc);

    ObjectPane* object = m_objectList.FindById(objectId);
    if (!object)
        return;

    ApplyOrCreateEffectForBand(object, desc.primary, effectArg, false, alternateBand);
    ApplyOrCreateEffectForBand(object, desc.secondary, effectArg, true, alternateBand);
}
```

The sketch captures the shape only. Exact type names and the `sub_50EA30` / `sub_50EB90` behavior need their own review before final source migration.
