It copies a 52-byte [UID:0001U8][EffectInfo](by-type/by-struct/EffectInfo.md) record from [UID:0000QT][g_pEffectObjImageLib](by-global/g_pEffectObjImageLib.md) through [UID:0002HA][0x004de3e0-0x004de420.EffectObjImageLibGetEffectInfo](by-memory/0x004de3e0-0x004de420.EffectObjImageLibGetEffectInfo.md), then looks up the target object in the MapPane object list at offset `0x424` through [UID:0002CD][0x00532370-0x00532443.ObjectListFindByObjectId](by-memory/0x00532370-0x00532443.ObjectListFindByObjectId.md).

If the target object is missing, the helper returns without side effects. If the object is present, the copied descriptor drives up to two child-effect passes:

- pass `0` uses descriptor fields that gate the target object's child collection at offset `0x174`;
- pass `1` uses descriptor fields that gate the target object's child collection at offset `0x170`.

Each pass is skipped when its descriptor count/length field is non-positive. When the descriptor's child-coordinate fields are nonnegative and the relevant collection has entries, the helper scans that collection from the last entry toward the first.
