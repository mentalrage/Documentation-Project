## Behavior

The handler is the string-argument variant of the spell-use prompt family. It belongs with the same source module as the numeric and slot spell input panes, but its payload is user-authored text rather than fixed-size numeric arguments.

Observed behavior from existing project docs:

- Reads the current [UID:000077][LineInputPane](by-class/LineInputPane.md) text buffer.
- Uses the constructor-stored spell slot/index at `this + 0x108`, documented by [UID:0001KU][0x005adf40-0x005adfcd.SpellStringInputPaneConstructor](by-memory/0x005adf40-0x005adfcd.SpellStringInputPaneConstructor.md), as the spell selector for the outgoing packet.
- Reads [UID:0000SG][g_pTextFilter](by-global/g_pTextFilter.md) and calls [UID:0000TK][SanitizeWideTextForChat](by-global/SanitizeWideTextForChat.md) so the user-entered spell argument is filtered before network serialization.
- Builds opcode `0x0f`, the shared spell-use opcode used by the string, numeric, target, and slot spell prompt family.
- Queues the packet through the broad outbound sender represented by [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) / [UID:0001HU][0x00574bb0-0x00574c13.QueueAndSendPacket](by-memory/0x00574bb0-0x00574c13.QueueAndSendPacket.md).
