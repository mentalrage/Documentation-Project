## Behavior

This constructor initializes the map-specific `ObjectList` container used by `MapPane`. It constructs the `LObject` base, installs the `ObjectList` vtable, stores padded grid dimensions, and allocates the flat lists, row-bucket tables, and global object-list tiers used by rendering, hit testing, map scrolling, object cleanup, and diagnostics.

Observed flow:

1. Call the `LObject` constructor at `0x004f4a80`.
2. Install the `ObjectList` vtable at `+0x00`.
3. Initialize the origin/min-coordinate sentinel fields `+0x04` and `+0x08` to `-30000`.
4. Store constructor arguments into `+0x0c` and `+0x10` as grid width/height.
5. Allocate two flat/cell `List` instances at `+0x14` and `+0x18` with capacity `(gridWidth + 4) * (gridHeight + 4) * 100`.
6. Allocate row-list pointer arrays at `+0x1c`, `+0x20`, and `+0x24` with `gridHeight + 4` entries, then allocate each row `List` with capacity `(gridWidth + 4) * 10`.
7. Allocate the wider `+0x28` row-list pointer array with `gridHeight + 12` entries, again using per-row capacity `(gridWidth + 4) * 10`.
8. Allocate global object-list tiers at `+0x2c`, `+0x30`, `+0x38`, `+0x3c`, and `+0x40` with capacity `(gridWidth + 4) * (gridHeight + 4) * 100`.
9. Allocate the alternate global list at `+0x34` only when the source-facing `g_useEpfAssets` flag is true; the raw IDA evidence is the `byte_66DA97 == 1` branch.
