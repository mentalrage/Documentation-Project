# 0x005270e0-0x005271a3 Midi Document Release

## Status

- Confidence: strong for modeled bounds, direct caller set, cleanup behavior, and field-offset map; medium for final source type and field names.
- Entity kind: internal MIDI document/resource cleanup helper.
- Proposed owner: [UID:0000LD][MidiPlayer](by-file/MidiPlayer.md) or adjacent MIDI document helper local to `audio/MidiPlayer.cpp`.

## Behavior

This helper releases the MIDI document/parser state used by the WinMM stream pipeline.

IDA MCP decompilation shows:

- If a stream/parser object at offset `0x18` is active, it checks and invokes the virtual cleanup/close method at that subobject.
- Otherwise, if the file handle at offset `0x2c` is valid, it closes that handle and stores `-1`.
- If the event/data table pointer at offset `0x10` is non-null, it walks each 40-byte entry and frees any global-memory block stored at entry offset `0x0c`.
- It then unlocks/frees the backing global-memory block and clears the pointer at offset `0x10`.
