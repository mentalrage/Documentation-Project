# 0x004f5fb0-0x004f6490 Application Startup

## Scope

- Range: `0x004f5fb0-0x004f6490`
- Entity kind: class method

- Disposition: reconstructable project code.

## Behavior

Constructs second-stage runtime and UI/image-library singletons after initial application setup. The method performs the startup work that belongs to the application shell: it runs [UID:0002H0][0x004639d0-0x00464a52.ApplicationInitialize](by-memory/0x004639d0-0x00464a52.ApplicationInitialize.md), constructs the idle watcher, initializes file/download and image-library singletons, activates the main window, tears down the loading dialog, builds main UI layer/context slots, attaches those slots to the screen/layer manager, starts the startup-logo playback path, and finally either constructs `LogoPane` or falls back directly to the terminal pane.

It also constructs the startup logo/player transition callback: after the startup-logo playback path at `0x004f5710`, it allocates a `PlainMemberFunctionObject0<BaramApp>`-style wrapper, initializes the local `LObject` shell, stores callback target [UID:0002Q0][0x004f5f50-0x004f5faf.BaramAppTerminalPaneCallbackFactory](by-memory/0x004f5f50-0x004f5faf.BaramAppTerminalPaneCallbackFactory.md) at wrapper slot `+8`, stores `this` at slot `+0x10`, then either constructs `LogoPane` or falls back directly to the terminal-pane callback path.
