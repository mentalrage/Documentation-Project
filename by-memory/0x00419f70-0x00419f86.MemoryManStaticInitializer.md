# 0x00419f70-0x00419f86 MemoryMan Static Initializer

## Status

- Confidence: strong from live IDA MCP.
- Entity kind: static/global initializer helper.
- Proposed owner: [UID:0000L7][MemoryMan](by-file/MemoryMan.md)
- Related singleton: [UID:0000RH][g_pMemoryMan](by-global/g_pMemoryMan.md)

## Behavior

This initializer constructs the process-global `MemoryMan` object at `dword_69B3A8` and registers the atexit reset thunk:

1. Loads `ecx = &dword_69B3A8`.
2. Calls [UID:0001B9][0x00516000-0x0051600f.MemoryManConstructor](by-memory/0x00516000-0x0051600f.MemoryManConstructor.md).
3. Registers [UID:0001O7][0x0060c260-0x0060c26a.MemoryManAtexitResetThunk](by-memory/0x0060c260-0x0060c26a.MemoryManAtexitResetThunk.md) through `_atexit`.

## Evidence

- Live IDA MCP `lookup_funcs` reports `0x00419f70` as a real function of size `0x16`, ending end-exclusive at `0x00419f86`.
- Live IDA MCP disassembly shows the constructor call at `0x00419f75` and `_atexit` registration at `0x00419f7f`.
- Live IDA MCP xrefs to `dword_69B3A8` include this initializer and the atexit reset thunk.

## Ownership Guidance

Treat this as compiler/static-initialization glue for the MemoryMan source family, not as feature code. It supports the original-source hypothesis that `MemoryMan.cpp` declared a process-global `MemoryMan` instance and a `g_pMemoryMan` pointer.
