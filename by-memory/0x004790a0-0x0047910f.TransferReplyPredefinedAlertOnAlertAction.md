## Behavior

IDA MCP decompilation on 2026-05-26 shows the same article-navigation acknowledgement shape as `TransferReplyAlert::OnConfirm` at `0x00478fe0`:

- reads the parent/session context from `this + 0x26c`;
- calls the alert virtual close/hide slot at vtable offset `0x18`;
- calls `0x004a1250` to find the previous dialog/session record;
- calls a list/control virtual with index `7` to fetch the active article-list entry;
- calls the article navigation packet helper `0x004751c0` with the selected item value, limit `0x7fff`, and a layout offset derived from `byte_66da97`;
- if the alert flag at `this + 0x270` is `1`, calls the session pop helper `0x004a10e0`.

The current `source-3/simroot_v2/class_TransferReplyPredefinedAlert.cpp` body instead describes text-edit/predefined-reply submission behavior. Treat that active body as incorrect generated data until Wave3 output is fixed.
