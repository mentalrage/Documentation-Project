# 0x00670294-0x006702c4 TimerPane Number Resource Strings

## Summary

- Address range: `0x00670294-0x006702c4`
- Entity kind: initialized UTF-16 resource strings
- Disposition: reconstructable project data
- Rebuild handling: source-declared static strings
- Confidence: strong

This range contains the two wide resource filenames used by `TimerPane::DrawDigit`.

## Layout

| Range | Current IDA name | String | Use |
| --- | --- | --- | --- |
| `0x00670294-0x006702aa` | `aNumberEpf` | `NUMBER.EPF` | Current/high-resolution EPF number atlas. |
| `0x006702ac-0x006702c2` | `aNumberEpd` | `NUMBER.EPD` | Legacy EPD number atlas. |
| `0x006702aa-0x006702ac`, `0x006702c2-0x006702c4` | terminators/alignment | zero bytes | UTF-16 NUL terminators/alignment. |

## Evidence

- [UID:0001RQ][timerpane-number-resources](by-resource/timerpane-number-resources.md) already records these resource names and their `TimerPane::DrawDigit` use.
- IDA MCP xrefs to `0x00670294` and `0x006702ac` come from `0x00598b6e` and `0x00598b7f` inside [UID:0001KB][0x005986e0-0x00598cbe.TimerPane](by-memory/0x005986e0-0x00598cbe.TimerPane.md).
- Raw bytes decode as UTF-16LE `NUMBER.EPF` and `NUMBER.EPD`.

## Reconstruction Notes

Keep these constants with [UID:0000OU][TimerPane](by-file/TimerPane.md) and [UID:0000F3][TimerPane](by-class/TimerPane.md). The branch between EPF and EPD follows the global asset-mode flag documented elsewhere.
