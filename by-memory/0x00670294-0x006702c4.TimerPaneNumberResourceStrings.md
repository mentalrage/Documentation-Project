# 0x00670294-0x006702c4 TimerPane Number Resource Strings

## Summary

- Address range: `0x00670294-0x006702c4`
- Entity kind: initialized UTF-16 resource strings
- Disposition: reconstructable project data
- Rebuild handling: source-declared static strings
- Confidence: strong

This range contains the two wide resource filenames used by `TimerPane::DrawDigit`.

## Layout

| Range | Bytes / value | Use |
| --- | --- | --- |
| `0x00670294-0x006702aa` | UTF-16LE `NUMBER.EPF`, including the NUL word | Newer EPF number atlas filename. |
| `0x006702aa-0x006702ac` | `00 00` | Padding before the second aligned wide string. |
| `0x006702ac-0x006702c2` | UTF-16LE `NUMBER.EPD`, including the NUL word | Legacy EPD number atlas filename. |
| `0x006702c2-0x006702c4` | `00 00` | Padding before [UID:00028B][0x006702c4-0x006702c8.UniAPIInitVtablePointerSlot](by-memory/0x006702c4-0x006702c8.UniAPIInitVtablePointerSlot.md). |

## Evidence

- 2026-06-06 live IDA byte sweep of `0x00670290-0x006702d0`: `8c 02 67 00 4e 00 55 00 4d 00 42 00 45 00 52 00 2e 00 45 00 50 00 46 00 00 00 00 00 4e 00 55 00 4d 00 42 00 45 00 52 00 2e 00 45 00 50 00 44 00 00 00 00 00 7c e5 62 00 57 00 01 00 1e 00 a7 00`.
- Live IDA UTF-16 decoding gives `NUMBER.EPF` at `0x00670294` and `NUMBER.EPD` at `0x006702ac`; each string is ten characters plus its NUL word.
- Live xrefs show exactly one direct data reference to `0x00670294`, from `0x00598b6e`, and exactly one direct data reference to `0x006702ac`, from `0x00598b7f`; the terminator/padding words at `0x006702aa` and `0x006702c2` have no direct references.
- Live decompilation/disassembly of `0x00598b40-0x00598bd5` shows the TimerPane digit draw helper branching on the client asset-mode flag at `0x0066da97`: the `== 1` branch passes `NUMBER.EPF`, and the other branch passes `NUMBER.EPD`. Both branches forward the requested digit or colon frame index unchanged to the resource layout loader before drawing.
- The preceding dword at `0x00670290` belongs to [UID:000289][0x00670268-0x00670294.StringBufferSentinelHeadersAndWhitespacePointer](by-memory/0x00670268-0x00670294.StringBufferSentinelHeadersAndWhitespacePointer.md); the following dword at `0x006702c4` starts [UID:00028B][0x006702c4-0x006702c8.UniAPIInitVtablePointerSlot](by-memory/0x006702c4-0x006702c8.UniAPIInitVtablePointerSlot.md).

## Reconstruction Notes

Keep these constants with [UID:0000OU][TimerPane](by-file/TimerPane.md) and [UID:0000F3][TimerPane](by-class/TimerPane.md). Rebuild them as static wide filename constants consumed only by the TimerPane digit draw path. The choice between EPF and EPD follows the existing client asset-mode flag, so the constants are documented as data rather than as independent behavior.
