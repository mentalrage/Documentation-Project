## Behavior

This helper dispatches an inventory/item slot use request after the caller has mapped a typed slot letter. It is called by [UID:0000FG][UseInputPane](by-class/UseInputPane.md) and by the macro/hotkey path for inventory-bound `.usr` records.

Observed behavior:

- accepts one slot selector and rejects selectors outside the local 52-slot range;
- indexes a large slot table from the `dword_67A748` player/client-state pointer;
- if the slot record has no target mode, sends the object action through [UID:0001LA][0x005af580-0x005af5ea.SendObjectActionPacket](by-memory/0x005af580-0x005af5ea.SendObjectActionPacket.md);
- if the slot can act on the current selected object, sends the same object action with the selected object id;
- otherwise constructs an [UID:00006X][ItemWhoInputPane](by-class/ItemWhoInputPane.md), stores the selected slot byte at `+0x108`, updates the current target context, and activates target selection.

## IDA Evidence

- IDA decompilation on 2026-05-27 shows a selector range check, slot-table indexing through `this[127 * slot + 315330]`, and target-mode branching from offset `+504` in the selected slot record.
- The no-target and direct-selected-target paths call `0x005af580`.
- The target-selection path allocates `268` bytes, constructs `ItemWhoInputPane` through `0x004f1c00`, installs three `ItemWhoInputPane` vtables, sets prompt text from `0x00630af0`, stores the selected slot byte at `+0x108`, and activates the target pane through `0x0057d0a0`.
- [UID:0001ML][0x005b5890-0x005b60c0.ThrowUseEatInputPanes](by-memory/0x005b5890-0x005b60c0.ThrowUseEatInputPanes.md) calls this helper after converting `a-z` to `1-26` or `A-Z` to `27-52` and validating against `dword_69AE0C + 0x284`.

## Naming Caveat

Current generated output names this helper `UseSpellSlot`, but existing macro/hotkey evidence resolves `.usr` state `3` / `I` from the inventory tab to this address. Until the paired `0x005a4530` helper is reviewed in the same level of detail, use neutral names such as `UseInventorySlotDispatch` or `DispatchItemUseSlot` in documentation.
