## Behavior

This `thiscall` helper sets or forwards the embedded text-edit state, then activates/invalidates the control through a shared `ControlPane` state helper. IDA decompilation reduces the body to:

```text
sub_498C00(this, 1, 1);
return sub_494C30(this);
```

`sub_498C00` forwards through the embedded editor pointer at `this + 0x10c`, and `sub_494C30` sets the shared `ControlPane` byte at `+0x102` before invalidating the pane rectangle through vtable slot `+0x20` when needed.
