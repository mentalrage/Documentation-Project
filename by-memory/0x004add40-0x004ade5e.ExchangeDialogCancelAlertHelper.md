## Behavior

This helper decodes a server-supplied exchange cancellation/termination message and closes the exchange UI path.

Observed behavior:

- reads message length from `packet+3`;
- copies message bytes from `packet+4`;
- converts the message to wide text with `MultiByteToWideChar(CP_ACP, ...)`;
- closes any active `g_pExchangeAlertPane`;
- allocates and constructs an `ExchangeAlertPane` with the decoded message;
- runs the DialogPane slide/animation close helper at `0x0049eb90`, then closes the current `ExchangeDialog` through the generic close/remove helper at `0x0049dad0`;
- closes active `AddItemDialog` state if `g_pAddItemDialog` / `dword_69B328` is set.

```cpp
void ExchangeDialog::HandleCancelAlertPacket(const unsigned char* packet)
{
    char text[256];
    wchar_t message[256];

    unsigned int length = packet[3];
    memmove(text, packet + 4, length);
    text[length] = 0;

    int converted = MultiByteToWideChar(CP_ACP, 0, text, length, message, 256);
    message[(unsigned char)converted] = 0;

    if (g_pExchangeAlertPane)
        g_pExchangeAlertPane->Close(1);

    new ExchangeAlertPane(message, this, g_szDialogOk, 0);

    this->SlideClose();
    CloseDialogPane(this);

    if (g_pAddItemDialog)
        CloseDialogPane(g_pAddItemDialog);
}
```
