## Class Behavior Summary

`DescPane` is a singleton-backed, reusable `Pane`-derived description display control. It stores:

- provider/source pointer at `+0xf8`;
- selected description index at `+0xfc`, initialized to `-1`;
- inherited pane bounds at `+0x44`, used by both the update helper and refresh method;
- inherited byte state at `+0x70`, cleared by refresh.

The raw constructor publishes the singleton at `0x0069adf8`; both destructor paths clear it. The update helper changes the provider/index pair only when needed and invalidates the pane via the primary vtable. `RefreshDescription` asks the provider object for text through vtable slot `+0x24` only when the provider is non-null and the selected index is not `-1`.
