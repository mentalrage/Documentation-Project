## Draw Flow

1. Returns immediately while the render-suspension flag `byte_69B420` is set.
2. Queries palette/filter state through the palette library global at `dword_67A7E0` and prepares a stack [UID:00004I][EPFTileContext](by-class/EPFTileContext.md).
3. In the legacy/non-EPF mode branch (`byte_66DA97 != 1`), opens `TILE.TBD`, reads a tile-count guard, and clamps invalid tile ids to `0`.
4. For tile id `0` or unresolved frame data, uses the fallback fill/rect callback at `dword_69B3FC` from [UID:0000TN][SurfaceRenderCallbackTable](by-global/SurfaceRenderCallbackTable.md), unless palette filtering suppresses the unresolved-frame path.
5. For drawable nonzero tiles, resolves frame metadata through `LoadFrameDrawRecord_4D1600` using object field `+0x04`, the merged metadata table loaded by the constructor.
6. Reads the decoded [UID:0001V3][MapTileRecord](by-type/by-struct/MapTileRecord.md) array at object field `+0x08`. Palette filtering requires record byte `+0x02` to be set before the draw proceeds.
7. Uses the record's low 15-bit field as the palette index for [UID:0000V4][PaletteSlotTable](by-item/PaletteSlotTable.md) slot `0` / `TILE.PAL`, then dispatches the actual tile blit through `dword_69B3E8`.
