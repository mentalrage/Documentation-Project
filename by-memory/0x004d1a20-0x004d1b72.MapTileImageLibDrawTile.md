## IDA Evidence

- `lookup_funcs 0x004d1a20` reports `sub_4D1A20` size `0x152`, so the half-open function range is `0x004d1a20-0x004d1b72`.
- Bytes at `0x004d1b72` are `0xcc` padding until the next function at `0x004d1b80`, confirming the end boundary.
- The method exits immediately while `byte_69B420` render suspension is active.
- It queries [UID:0000MB][PaletteLib](by-file/PaletteLib.md) state through `dword_67A7E0` and initializes an [UID:00004I][EPFTileContext](by-class/EPFTileContext.md) stack object.
- In the legacy/non-EPF branch (`byte_66DA97 != 1`) it opens `TILE.TBD`, reads a tile-count guard, and clamps out-of-range tile ids to `0`.
- Tile id `0` or an unresolved frame falls back to a solid `128` fill plus border/rect draw callback through `dword_69B3FC`, unless palette filtering is active and the unresolved-frame path returns early.
- Nonzero tile ids call `sub_4D1600` with the metadata table at object offset `+0x04` to populate the `EPFTileContext`.
- When palette filtering is disabled, drawing proceeds. When palette filtering is enabled, the high-bit flag decoded into [UID:0001V3][MapTileRecord](by-type/by-struct/MapTileRecord.md) byte `+0x02` must be set before drawing proceeds.
- The low 15-bit map-tile record field is passed to the palette lookup helper before the tile blit callback at `dword_69B3E8`.
- `xrefs_to 0x004d1a20` reports call sites at `0x00424441`, raw/unowned IDA code at `0x0050c3d7`, `0x0050d984`, and `0x005497d0`.
