## Ownership And Behavior

`EditablePaperPane` is the packet-opened paper document dialog used by `MapPane::HandlePacket`. Opcode `0x1b` constructs the pane in editable mode, while opcode `0x35` constructs the same class in read-only mode. The constructor installs the three-view class layout, records the mode at `+0x278`, and dispatches to the mode-specific parser before common control setup.

The editable parser records the paper id at `+0x26c`, stores dimensions at `+0x26e/+0x26f`, converts the multibyte payload to wide text, and feeds the shared paper setup path. The read-only parser omits the paper id, records the centered flag at `+0x27c`, and uses the same text-conversion and layout path. The save path reverses the editor line-break normalization, serializes opcode `0x23`, emits the paper id and text length, and sends the converted multibyte text back to the server.

The render pair uses `LINE001.EPD`: border drawing consumes frames `0..7`, and background fill consumes frame `8`. This ties the page to the UI dialog resource path rather than the text-dialog or text-pad families, which are documented separately by file-level pages.
