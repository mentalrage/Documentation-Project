## Behavior

Returns a pointer to an element in the fixed-width backing buffer. The method returns null when the backing buffer is absent, when the index is negative, or when the nonzero index is greater than or equal to the current count. Index zero is accepted whenever storage exists, even if `m_count <= 0`; this is the preserved source-facing behavior from the binary branch order.

When valid, the returned pointer is:

```text
m_data + index * m_elementSize
```
