## Role

This range is the merchant/NPC menu dialog factory island between the reusable popup-menu item classes and the `MerchantDialogPane` base. It dispatches packet menu subtype bytes to the concrete text, item, spell, and argumented menu dialog constructors, and also provides one-variant wrapper helpers that create the same dialogs when the subtype is already known by the caller.

The main dispatcher at `0x00517450` is called from packet/session paths that set a stack `MerchantDialogCreator` vtable before calling into this helper. The packet pointer argument is interpreted as:

- byte `+1`: menu dialog subtype selector.
- bytes `+2...`: concrete constructor payload.

## Reconstruction Sketch

```cpp
DialogPane *CreateMerchantMenuDialog(const unsigned char *packet)
{
    const unsigned char subtype = packet[1];
    const unsigned char *payload = packet + 2;

    switch (subtype) {
    case 0:
        return new TextMenuDialog(0, Rect(100, 100, 416, 455), payload, 0);
    case 1:
        return new TextMenuDialog(1, Rect(100, 100, 416, 455), payload, 0);
    case 2:
        return new TextInputMenuDialog(0, Rect(100, 100, 416, 328), payload, 2);
    case 3:
        return new TextInputMenuDialog(1, Rect(100, 100, 416, 328), payload, 2);
    case 4:
        return new ServerItemMenuDialog(Rect(100, 100, 525, 454), payload, 0);
    case 5:
        return new ClientItemMenuDialog(Rect(100, 100, 416, 455), payload, 0);
    case 6:
        return new ServerSpellMenuDialog(Rect(100, 100, 416, 455), payload, 0);
    case 8:
        return new ClientSpellMenuDialog(Rect(100, 100, 416, 455), payload, 0);
    case 10:
        return new ArgumentedMenuMenuDialog(Rect(100, 100, 416, 455), payload, 0);
    default:
        return NULL;
    }
}
```
