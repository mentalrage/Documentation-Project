## Behavior

This code computes the field-entry rectangle for an indexed field-map entry. The decompiled/generated shape is equivalent to:

- locate the 0x94-byte field-entry record at `this + 0x1f8 + index * 0x94`;
- measure the wide label at record offset `+8`;
- use the pane line height to derive a double-height entry extent;
- center the rectangle around `Point m_displayPosition` (`y` at `+0x00`, `x` at `+0x04`);
- write `RectBounds` fields in accepted `left/top/right/bottom` storage order after computing the same top/bottom/left/right values from the entry center.

This matches the rectangle math currently duplicated inline by `FieldMapPane::HandleMouseEvent` and `FieldMapPane::RenderFieldEntries`; it does not prove those live siblings call this raw helper.
