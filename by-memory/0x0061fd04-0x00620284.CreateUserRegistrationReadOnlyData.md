# 0x0061fd04-0x00620284 Create User/Registration Read-Only Data

## Range

- Address range: `0x0061fd04-0x00620284`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations, callback wrappers, URL/resource literals, and dialog strings must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains the newer create-user dialog vtables, callback wrappers, resource names, Nexonclub registration dialog data, and `NumberInputDialog` vtables. It ends before the `ObjectList` RTTI pointer.
