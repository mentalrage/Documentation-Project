## Behavior

The helper iterates the `ItemObjImageLib` item metadata table and refreshes the per-row byte at `ItemInfo+0x10` from resource/palette lookup results. It chooses the item archive by the same extended/legacy asset flag used by the ItemObj constructor and draw helpers:

- `byte_66DA97 == 1`: use `ITEM.EPF` through [UID:0000QU][g_pEPFLib](by-global/g_pEPFLib.md) `g_pEPFLib` / `dword_67A744`.
- otherwise: use `ITEM.EPD`. Both compiler-cloned branches use the same `g_pEPFLib` and `g_pPaletteLib`; only the resource-name literal differs.

For each item row:

1. Initializes a stack tile/context record through `sub_457A60`.
2. Calls [UID:0002KP][0x004d02f0-0x004d039e.ResourceLayoutTableLookupLayoutEntry](by-memory/0x004d02f0-0x004d039e.ResourceLayoutTableLookupLayoutEntry.md) `ResourceLayoutTableLookupLayoutEntry` / `sub_4D02F0` for `ITEM.EPF` or `ITEM.EPD` and the current row index.
3. If lookup succeeds, selects either the current `ItemInfo` row or the fallback row at `this+0x14`.
4. Resolves palette category `0x0a` through [UID:0000RW][g_pPaletteLib](by-global/g_pPaletteLib.md) `g_pPaletteLib` / `dword_67A7E0` and the row's `+0x04` palette field by calling [UID:0000A1][PaletteLib](by-class/PaletteLib.md) `PaletteLib::GetSlotPalette(10, itemInfo.paletteSlot, 0)`, which returns a [UID:00003Z][DLPalette](by-class/DLPalette.md) `DLPalette *`.
5. Calls [UID:000201][0x00458590-0x00458610.EPFTileContextPixelRangeTest](by-memory/0x00458590-0x00458610.EPFTileContextPixelRangeTest.md) `EPFTileContext::ContainsIndexedPixelInRanges(const DLPalette *palette) const` with the stack tile/context and the returned `DLPalette *`, then writes the returned byte to `ItemInfo+0x10`.

The helper does not parse `ITEM.TBL` / `ITEM.TBD` itself. That table-loading work belongs to [UID:0003LZ][0x004df500-0x004df668.ItemObjImageLibLoadItemInfoTable](by-memory/0x004df500-0x004df668.ItemObjImageLibLoadItemInfoTable.md).
