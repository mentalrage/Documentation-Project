# 0x00620c74-0x0062179c Option/Macro/Profile Read-Only Data

## Range

- Address range: `0x00620c74-0x0062179c`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: source class declarations and option/macro/profile UI literals must be reconstructed; vtables are compiler-emitted.

## Summary

This `.rdata` span contains option, macro, friend-list, profile, scroll-bar, integrated macro, and target-option dialog vtables plus the option/setup UI string table. It ends at the `DLPalette` vtable.
