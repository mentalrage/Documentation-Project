# 0x00672f24-0x006738c0 MSVC Runtime Mutable Data

## Summary

- Address range: `0x00672f24-0x006738c0`
- Entity kind: MSVC CRT/UCRT mutable runtime state
- Disposition: ignored for NexusTK source reconstruction
- Rebuild handling: emitted/provided by the compatible MSVC runtime and compiler support
- Confidence: strong for runtime ownership; medium for every unnamed slot's exact CRT field name

This range is mutable runtime support data adjacent to third-party zlib data and compiler-generated RTTI. It includes security-cookie state, CRT option/pointer slots, TLS state, locale buffers/tables, and console-output runtime state.
