## Behavior

Maps mouse coordinates to a visible fitting-room list slot. The method iterates slot indexes, computes each slot rectangle based on the current display mode, tests the input point against that rectangle, and returns the matching slot index. If no slot matches, it returns `0xffff`.

Current geometry:

- list mode uses one column of rows beginning at y `16`, height `20`, x range `2..160`, up to slot `0x1a`;
- grid mode uses six columns with horizontal stride `96`, vertical stride `112`, top-left base `(16,31)`, slot size about `54x54`, up to slot `0x12`;
- invalid slot indexes produce `-1` rectangles before point testing.
