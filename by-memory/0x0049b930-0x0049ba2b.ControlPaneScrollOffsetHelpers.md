## Behavior

The four helpers all operate on the same 16-bit fields:

- `this+0xfa`: current scroll/selection offset.
- `this+0xfc`: maximum/limit offset.
- vtable slot `+0x20`: refresh/invalidate after changing the offset.

The caller at `0x00497780` maps keyboard messages `0x80`/`0x81` to the one-step decrement helper, `0x82`/`0x83` to the one-step increment helper, `0x93` to the ten-step decrement helper, and `0x94` to the ten-step increment helper. The caller at `0x00497c60` maps hit/drag result cases `13`, `14`, `16`, and `17` to the same four helpers.

## C++ Reconstruction Sketch

```cpp
void ControlPane::SetScrollOffsetClamped(int nextOffset)
{
    if (nextOffset < 0) {
        nextOffset = 0;
    }
    if (nextOffset > m_scrollLimit) {
        nextOffset = m_scrollLimit;
    }

    m_scrollOffset = static_cast<short>(nextOffset);
    Invalidate(false);
}
```
