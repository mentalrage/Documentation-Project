## Behavior

This helper frees a three-field vector-like storage record. If the begin pointer is null, it returns without writes. Otherwise it computes the aligned byte span from the capacity/end pointer minus the begin pointer, validates the allocation header for large blocks, frees the selected allocation base, and clears all three storage fields.

For spans below `0x1000`, the begin pointer is passed directly to the shared heap-free wrapper at `0x005c7526`. For spans at or above `0x1000`, the helper reads the allocation base stored immediately before the begin pointer and verifies that the front padding is no more than `0x1f`; failed validation exits through `_invalid_parameter_noinfo_noreturn`.

## Signature And State Contract
