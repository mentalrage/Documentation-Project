## Behavior

This method handles pointer interaction for item target selection.

- Mouse event subtype `2` checks whether the click lands within the map pane, clears the current highlight, sends [UID:0001LA][0x005af580-0x005af5ea.SendObjectActionPacket](by-memory/0x005af580-0x005af5ea.SendObjectActionPacket.md) for the saved target, and closes the pane through the owning input flow.
- Mouse event subtype `1` converts local pane coordinates into map coordinates, hit-tests the map pane through [UID:0001AU][0x00506ce0-0x00506d15.GeneratedBackPaneHitTestMapPane](by-memory/0x00506ce0-0x00506d15.GeneratedBackPaneHitTestMapPane.md), updates highlight state when the hovered object changes, and writes the new object id into `dword_69BF24`.
- When auto-use behavior is enabled at `dword_67A7C8 + 2678362`, hover/change paths avoid immediate send/close; otherwise a confirmed or repeated target sends the object action and closes the prompt.
- Empty-map clicks are filtered through the map viewport rectangle helper before cancel/send behavior.
