## Exclusions And Caveats

- `0x00570053` is a bad generated method row for this class. IDA resolves the address inside a containing function at `0x00570030`, not a function start, and the decompiled body is unrelated to the swallow weather overlay.
- `0x005c2760` and `0x005c2840` are aligned raw code starts with no IDA function objects and no xrefs. Generated `class_BackPane.cpp` emits them as BackPane scroll-animation methods, but their field offsets and helper calls match `SwallowLayerPane`.
- Adjacent `0x005c29ec` and `0x005c29f7` are snow destructor thunks that forward to [UID:0001O0][0x005c1bd0-0x005c2a5a.SnowingLayerPane](by-memory/0x005c1bd0-0x005c2a5a.SnowingLayerPane.md), not swallow methods.
- The next large function at `0x005c2ac0` installs `WorldMapPane` vtables and belongs to [UID:0000PB][WorldMapPane](by-file/WorldMapPane.md), not weather.

## Evidence Notes

- IDA MCP confirms all listed core starts and the omitted helper starts on 2026-05-24.
- IDA raw disassembly confirms valid code bodies at `0x005c2760-0x005c2835` and `0x005c2840-0x005c292e`, but `lookup_funcs` reports `Not a function` for both starts and `xrefs_to` reports no references to either start.
- `xrefs_to 0x005c2930` reports calls from `0x005c25e2` in `SwallowLayerPane::OnTimerEvent` and from raw code at `0x005c291d`.
- `MapPane` weather setup at `0x0050db50` allocates 364 bytes and calls `0x005c2230` when weather type `3` is selected.
- Current simroot source shows timer messages `0x100` and `0x101`, two loaded frames from `SWALLOW.EPF` or `SWALLOW.EPD`, and global draw/clear callbacks.
