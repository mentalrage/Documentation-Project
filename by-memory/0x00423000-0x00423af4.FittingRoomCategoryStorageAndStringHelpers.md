## Range Role

This helper island sits between the fitting-room item-state JSON loader and the existing `0x00423b00` vector resize/fill helper. It contains category lookup insertion support, per-entry vector/string support, wide formatting, destroy/free helpers, and several shared helpers that have callers outside fitting-room.

It should not be left as an undocumented gap. It also should not be treated as entirely private fitting-room code: IDA caller evidence shows some helpers are shared by minimap/DAT/runtime-adjacent paths.

## Reconstruction Notes

This page is a first-pass aggregate, not a final split. Future work should split source-authored category lookup helpers from shared vector/string generated support. In final source, most allocation, vector growth, fill, and destroy helpers should probably be regenerated by the compiler/STL/container implementation once the owning structures are declared correctly.

Do not emit C++ from this aggregate yet. The final source likely needs declarations for category entry storage and lookup/tree/vector types in the fitting-room catalog state, while the compiler should regenerate much of the helper island from those declarations.
