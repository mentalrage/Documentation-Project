## Behavior

This helper mirrors the rectangle setup path in [UID:00022Z][0x00503060-0x005031e1.UnreferencedUiResourceTextHelpers](by-memory/0x00503060-0x005031e1.UnreferencedUiResourceTextHelpers.md) / the sibling helper at `0x00503060`, but writes into a caller-supplied `RectBounds` pointer instead of dispatching through a vtable. It decrements the first argument and, only when the adjusted value is zero, fills the second argument through [UID:00015S][0x004b7c30-0x004b7f87.RectGeometryHelpers](by-memory/0x004b7c30-0x004b7f87.RectGeometryHelpers.md) `0x004b7c50`.

The written rectangle is `(0, 0, 0x00a6, 0x10)` when [UID:0000SW][g_useEpfAssets](by-global/g_useEpfAssets.md) is `1`, or `(0, 0, 0x00ad, 0x10)` otherwise. The non-`1` state path returns without writing the caller's output rectangle.
