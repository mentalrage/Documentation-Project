## Behavior

The method receives an object pane pointer. It first calls the pane virtual slot `+0x28` to copy a 16-byte rectangle/bounds record into a local stack buffer, then passes that record to the `MapPane` virtual slot `+0x20` so the old map area is invalidated or refreshed before the pane leaves the scene.

After invalidation, the method removes the pane from `MapPane +0x424` through [UID:0002CA][0x00531c10-0x00532180.ObjectListTypeDispatchRemove](by-memory/0x00531c10-0x00532180.ObjectListTypeDispatchRemove.md). If the object's type byte at offset `0xf8` is not `5`, it calls the auxiliary ObjectPane cleanup helper at `0x004b97d0`; live decompilation of that helper frees an owned auxiliary buffer and releases a secondary object pointer when the global manager state allows it. The type-`5` path skips that auxiliary cleanup and goes straight to deletion.

The method finishes by calling the pane scalar deleting destructor with flag `1`. It returns the destructor-path result.
