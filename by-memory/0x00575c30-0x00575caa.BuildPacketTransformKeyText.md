## Behavior

1. `0x00575c38` calls `Md5StringHex(keyText)` to produce a heap 32-character lowercase hexadecimal digest.
2. `0x00575c40` hashes that first digest, producing a second independent heap digest.
3. `0x00575c58` performs the initial bounded secure write `sprintf_s(g_packetTransformKeyText, 1025, "%s", secondDigest)`.
4. `0x00575c5e` and `0x00575c64` free the first and second digest buffers immediately after that write.
5. The loop initializes an exact count of `0x1f` / 31. Each iteration hashes the entire current `g_packetTransformKeyText`, appends the 32-character digest with the bounded `"%s%s"` formatter call, frees the temporary digest, decrements the counter, and repeats.
6. Initial output length is 32 characters. Thirty-one appended 32-character digests produce exactly `32 + 31 * 32 = 1024` characters plus the terminating NUL in Socket's 1,025-byte allocation.

The loop does not duplicate the current string or append a copy of itself. It appends `Md5StringHex(currentKeyText)` at each stage, so every digest depends on the full chain built so far.
