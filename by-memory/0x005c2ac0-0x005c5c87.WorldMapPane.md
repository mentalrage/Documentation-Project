## Data Issue

Wave3 also lists a `WorldMapPane` method at `0x00590053`. IDA reports no function at that address; the previous function is `0x0058fef0-0x0058ffd2` and the next function is `0x00590130-0x00590137`. This is documented in [wave3_data_issues](../wave3_data_issues.md) and is excluded from this memory page.

Generated WorldMap output also emits frame wrappers at `0x004b6d00` and `0x004b6d20`. They are excluded from this page because they are [UID:00015M][0x004b6cb0-0x004b7112.FrameScheduler](by-memory/0x004b6cb0-0x004b7112.FrameScheduler.md) helpers.

## Ownership Decision

This range belongs to a separate `map/WorldMapPane.cpp` module with private helper storage classes. `MapPane` may create it, but should not own the implementation.
