## Behavior

Swaps two elements when the supplied indices differ. It allocates a temporary buffer of one `elementSize`, obtains element pointers through the virtual element-accessor slot, copies the first element into the temporary buffer, copies the second element over the first, copies the temporary bytes into the second, then releases the temporary buffer.
