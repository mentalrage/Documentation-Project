## Behavior

`ParseEntries` decodes an eight-byte buffer in place and returns a validated 32-bit parsed value:

1. Seeds a 27-entry table from fixed constants.
2. Mixes adjacent table entries with XOR.
3. Starts from `(0xfedcba98 - encodedKey) % 27`.
4. XOR-decodes eight header bytes while stepping backward modulo 27.
5. Reads the decoded halves as big-endian 32-bit values.
6. Validates the lower half against `encodedKey` using the `0x55555555` deinterleave mask.
7. Writes the deinterleaved value to `outValue` and returns true when validation succeeds.
