## Behavior

`DecodeTableValue` decodes exactly one eight-byte scalar unit. It does not parse an entry array, vector, outer DAT directory row, or persistent container.

1. Initializes one mutable local 27-dword table in exact source order: `75,25,31,29,26,9,12,12,83,73,19,17,29,23,6,29,9,6,8,27,28,1,30,29,3,5,9`.
2. For odd indices `1,3,...,25`, XORs the odd element with its predecessor and the following even element with that newly mixed odd element. This cumulatively mixes all 27 entries without a sentinel.
3. Computes the initial index with unsigned wraparound and remainder semantics: `(0xFEDCBA98u - validationKey) % 27u`.
4. XOR-mutates all eight caller bytes in place with the low byte of the selected mixed dword, stepping backward modulo 27 after each byte.
5. Assembles bytes `0..3` and `4..7` as two big-endian unsigned 32-bit words.
6. Computes selected differing bits as `(firstWord ^ secondWord) & 0x55555555u`.
7. Validates `secondWord ^ selectedBits` against the caller's key.
8. On success, writes `firstWord ^ selectedBits` to the supplied four-byte storage and returns full-register integer `1`.
9. On failure, returns full-register integer `0` without writing output. All eight input bytes remain decoded/mutated because validation occurs after mutation; there is no rollback.
