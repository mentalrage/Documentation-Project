## Behavior

`sub_46A510` translates keyboard messages through the active embedded browser object.

- Reads [UID:0000Q6][g_pActiveBrowserWindow](by-global/g_pActiveBrowserWindow.md).
- Queries the browser interface at active-window offset `+0x18` for the GUID stored at `0x006315c0`, likely `IID_IOleInPlaceActiveObject`.
- Only special-cases keyboard messages `WM_KEYDOWN`, `WM_KEYUP`, `WM_SYSKEYDOWN`, and `WM_SYSKEYUP`.
- For key `N`, Ctrl pressed, and Alt not pressed, skips browser accelerator forwarding and leaves the message for normal application handling.
- For Escape, calls the active browser pane close/activation helper through [UID:0000PP][g_activeBrowserPane](by-global/g_activeBrowserPane.md) / `dword_67AB84` and returns `0`.
- Otherwise calls the queried interface vtable at offset `+0x14`, matching `IOleInPlaceActiveObject::TranslateAccelerator(MSG*)`, then releases the interface through vtable offset `+0x08`.

## C++ Reconstruction Candidate

```cpp
bool BrowserWindowTranslateAccelerator(MSG* msg)
{
    if (!g_pActiveBrowserWindow)
        return true;

    IOleInPlaceActiveObject* activeObject = g_pActiveBrowserWindow->QueryInPlaceActiveObject();
    if (!activeObject)
        return true;

    bool handled = true;
    switch (msg->message) {
    case WM_KEYDOWN:
    case WM_KEYUP:
    case WM_SYSKEYDOWN:
    case WM_SYSKEYUP:
        if (msg->wParam == 'N' && GetKeyState(VK_CONTROL) && !GetKeyState(VK_MENU))
            break;
        if (msg->wParam == VK_ESCAPE) {
            BrowserPaneActivateItem(g_activeBrowserPane);
            handled = false;
            break;
        }
        handled = activeObject->TranslateAccelerator(msg);
        break;
    default:
        handled = activeObject->TranslateAccelerator(msg);
        break;
    }

    activeObject->Release();
    return handled;
}
```
