## Behavior

`sub_46A510` translates keyboard messages through the active embedded browser object.

- Reads [UID:0000Q6][g_pActiveBrowserWindow](by-global/g_pActiveBrowserWindow.md) / `dword_67AB94` and returns `1` if no active browser window is present.
- Reads the active-window member at offset `+0x18`, queries its vtable slot `+0x00` with the GUID data at `0x006315c0`, and returns `1` if the query fails or yields a null interface pointer.
- Switches on `MSG.message` and special-cases `WM_KEYDOWN` (`0x100`), `WM_KEYUP` (`0x101`), `WM_SYSKEYDOWN` (`0x104`), and `WM_SYSKEYUP` (`0x105`).
- For key `N` (`wParam == 0x4e`), Ctrl pressed (`GetKeyState(0x11)`) and Alt not pressed (`GetKeyState(0x12)`), skips browser accelerator forwarding and returns the initial value `1`.
- For Escape (`wParam == 0x1b`), calls the active browser pane close/activation helper through [UID:0000PP][g_activeBrowserPane](by-global/g_activeBrowserPane.md) / `dword_67AB84`, releases the queried interface, and returns `0`.
- Otherwise calls the queried interface vtable at offset `+0x14`, matching `IOleInPlaceActiveObject::TranslateAccelerator(MSG*)`, preserves that return value, then releases the interface through vtable offset `+0x08`.
