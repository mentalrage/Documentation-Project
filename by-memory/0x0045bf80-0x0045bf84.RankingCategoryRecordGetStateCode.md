## Behavior

Returns the 32-bit `m_stateCode` field stored at record offset `+0x08`. The method performs no mutation and has no callees, hidden output, or local variables.

The three observed state values have consistent UI behavior:

- state `0` enables the selected-category action and selects the first status glyph;

- state `2` disables the action and suppresses status-glyph drawing.
