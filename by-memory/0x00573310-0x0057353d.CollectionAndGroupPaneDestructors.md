## Behavior Summary

This range is a compact destructor island after the `GroupPane`/`CollectionPane` adjustor thunks and before the later `LineIterator`/look/group destructor helpers. It should be treated as four scalar deleting destructors, not as one handwritten helper routine. Each body represents source-level class teardown, while the nearby secondary and tertiary entries are compiler-generated adjustor thunks that belong to the multiple-vtable layout.

The first two destructors are collection-panel owned: `CollectionPane2` is the lightweight alternate inventory-frame pane, while `CollectionPane` owns the in-game collection summary panel and its `ScrollCollectionPane` child. The second two destructors are group-panel owned: `GroupPane2` and `GroupPane` are older/alternate group-list shells that share the `GroupListPane` child setup pattern. The shared memory island is a binary layout convenience; source reconstruction should split the emitted destructor declarations by their owning classes/files.
