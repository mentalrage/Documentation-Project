## Function Role

`DestroyMotionVector` releases the `Motion.tbl` entry vector owned by [UID:000092][NewHumanImageLib](by-class/NewHumanImageLib.md). It frees the vector storage when present and clears the `begin`, `end`, and `capacity` pointers.

This is a source-adjacent helper for the new-human image library, not a method on the unrelated runtime [UID:00008R][Motion](by-class/Motion.md) class.

## Observed Shape

```text
MotionEntryVector
  +0x00 begin
  +0x04 end
  +0x08 capacity

MotionEntry size: 0x42 bytes
```

For small allocations the helper frees `begin` directly. For large aligned allocations it validates the stored raw allocation pointer located immediately before `begin`, frees that raw pointer, then zeros the vector triplet. If `begin` is already null, the helper returns without touching the triplet.
