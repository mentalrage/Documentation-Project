## Behavior

Reads a two-byte multibyte byte count from the input stream, using byte-order flag `+0x10` to choose high-byte-first assembly or native little-endian `word ptr` load. It copies that many multibyte bytes into a large stack scratch buffer, NUL-terminates the scratch, converts it to UTF-16 with `MultiByteToWideChar(0, 0, ...)`, validates the produced wide length against caller capacity, writes a wide terminator, optionally stores the produced count, and advances cursor `+0x0c`.

The method clears the output buffer and optional count on entry. It clears valid flag `+0x11` when the count field, input payload span, or output capacity check fails.
