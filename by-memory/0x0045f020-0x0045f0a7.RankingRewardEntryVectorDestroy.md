## Behavior

This helper destroys the dialog-owned vector of 560-byte reward entries. Before freeing the outer reward-entry storage it iterates each entry and destroys the nested 520-byte reward-item vector at entry offset `+0x224` (`+548` decimal). It then frees the allocation using the same MSVC large-allocation header validation path used by the other ranking vector helpers and clears begin/end/capacity to zero.
