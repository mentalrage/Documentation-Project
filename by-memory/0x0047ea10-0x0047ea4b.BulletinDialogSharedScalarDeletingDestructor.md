# 0x0047ea10-0x0047ea4b BulletinDialog Shared Scalar Deleting Destructor

## Scope

- Range: `0x0047ea10-0x0047ea4b` half-open.
- IDA function: `sub_47EA10`, size `0x3b`.
- Entity kind: MSVC scalar deleting destructor wrapper shared by bulletin/board/article dialog vtable slots that do not require a more-derived destructor body.
- Semantic owner: [UID:00001C][BulletinDialog](by-class/BulletinDialog.md), with direct vtable use also observed from [UID:00000Z][BoardListDialog](by-class/BoardListDialog.md) and other `DialogInSession` descendants.
- Rebuild handling: compiler/linker-generated wrapper over source-level `BulletinDialog`/`DialogInSession` destruction. Do not emit this as handwritten C++.

## Behavior

The wrapper calls [UID:00003S][DialogInSession](by-class/DialogInSession.md) non-deleting cleanup at `0x004a1450`, checks scalar-delete flags, and conditionally frees object storage through `0x004f4ac0`. It returns `this`.

## Evidence

- 2026-06-10 B001-025 IDA MCP `lookup_funcs 0x0047ea10` reports `sub_47EA10` at `0x0047ea10` with size `0x3b`.
- IDA MCP decompilation shows `sub_4A1450(Block)`, scalar-delete flag test `(flags & 1) != 0 && (flags & 4) == 0`, storage free helper `0x004f4ac0`, and return of `this`.
- IDA MCP `xrefs_to 0x0047ea10` reports code references from adjustor thunks `0x0047e897` and `0x0047e8a2`.
- The same xref query reports vtable/data references at `0x00613ba8`, `0x00613c48`, `0x00613fb0`, and `0x0061443c`, proving the wrapper is shared by the bulletin/board/article dialog vtable family.
- [UID:0000ZP][0x0047e855-0x0047e947.DialogAndAlertDestructorAdjustorThunks](by-memory/0x0047e855-0x0047e947.DialogAndAlertDestructorAdjustorThunks.md) documents the secondary/tertiary adjustors targeting this wrapper.
- [UID:0001X5][BulletinDialogVtables](by-type/by-vtable/BulletinDialogVtables.md) and [UID:0001X4][BoardArticleDialogVtableFamily](by-type/by-vtable/BoardArticleDialogVtableFamily.md) document the related vtable family.

## Assignment Decision

Keep `AUTOGEN_PARENT_UID` blank.
