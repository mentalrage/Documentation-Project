| Key group | Required event kind | Behavior |
| --- | --- | --- |
| Enter (`13`) | special path only when `event+4 == 8` | Resolves `dword_69BF28` through `dword_67A764` and `sub_506970`; if a target object exists, clears the highlight helper and calls `sub_50B1B0(dword_67A764, target)` to interact with it. | Escape (`27`) and space (`32`) | special path only when `event+4 == 8` for capture cleanup | If a saved target resolves, clears its highlight, clears `byte_69BED9`, dismisses the capture pane, temporarily changes `event+8` to Escape, forwards to the base key handler, restores the original key, and returns `0`. |
| `v` (`118`) | none beyond no modifier bits | Forwards through [UID:0001LH][0x005afe70-0x005afeee.SelectObjectWithKeyboardPaneForwardTabKey](by-memory/0x005afe70-0x005afeee.SelectObjectWithKeyboardPaneForwardTabKey.md) only when the two mode bytes under `dword_67A7C8 + 0x28de62/0x28de63` allow the shortcut. |
