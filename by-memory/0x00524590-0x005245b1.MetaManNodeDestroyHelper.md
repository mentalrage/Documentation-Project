## Role

This helper destroys a metadata tree node owned by the `MetaMan` table-name map/tree. It first tears down the node payload string at `node + 0x10` through the adjacent small-string cleanup helper at `0x00524400`, then frees the 44-byte node allocation.

IDA shows exactly three callers inside the `MetaMan` range at `0x00523f3e`, `0x0052418c`, and `0x005243a3`. Those callers are the local red-black-tree insert/rollback helpers for the manager's table-name storage, which ties this routine to `MetaMan` tree cleanup rather than to generic allocator code.

The source-level role is old MSVC map/set helper glue emitted from [UID:000088][MetaMan](by-class/MetaMan.md) `std::map<SimpleUString, MetaTable *> m_tables`. It should not become a handwritten `MetaMan` method body in final source; the rebuilt source should express the map member and let the compiler/STL emit equivalent node cleanup.

## Behavior Details

- Calling convention: IDA currently models this as a `thiscall`-shaped helper taking a tree/context value in `ecx` and a node pointer on the stack.
- Node payload: the instruction at `0x00524597` computes `node + 0x10` and passes that address to the `0x00524400` small-string cleanup helper. `0x10` is 16 decimal (Verified with `tools/int_convert.py` and IDA MCP).
- Payload cleanup: `0x00524400` checks the small-string capacity at payload `+0x14`, frees heap storage only when capacity is at least 8, resets length at `+0x10` to zero, resets capacity at `+0x14` to 7, and writes a UTF-16 NUL at payload `+0x00`.
- Node free: the instruction at `0x005245a1` pushes `0x2c`, then `0x005245a3` pushes the node pointer and calls the free wrapper at `0x005c7526`. `0x2c` is 44 decimal and the function size `0x21` is 33 decimal (Verified with `tools/int_convert.py` and IDA MCP). Current MCP decompiles `0x005c7526` as a wrapper over `j_j___free_base(Block)`.
- Control flow: one basic block, no branches, no strings, no direct global access, and no return value used by callers.
- Final C++ should use the recovered `MetaMan` map/container member. Do not hand-author this cleanup helper as a standalone method in ordinary source.
