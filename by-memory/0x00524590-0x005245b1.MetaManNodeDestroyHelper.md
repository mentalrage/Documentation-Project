# 0x00524590-0x005245b1 - MetaMan Node Destroy Helper

## Status

- Confidence: strong for IDA function boundary, callers, and behavior; medium for final source-facing helper name.
- Entity kind: helper / tree-node cleanup.
- Likely owner: [UID:0000LC][MetaMan](by-file/MetaMan.md) and [UID:000088][MetaMan](by-class/MetaMan.md).
- Related ranges: [UID:0001C8][0x005227d0-0x00524581.MetaMan](by-memory/0x005227d0-0x00524581.MetaMan.md), [UID:0001CA][0x005245c0-0x0052462a.MetaTableRowFindByKey](by-memory/0x005245c0-0x0052462a.MetaTableRowFindByKey.md), [UID:0001CB][0x00524630-0x005258f1.MetaTable](by-memory/0x00524630-0x005258f1.MetaTable.md).
- Evidence basis: IDA MCP function, xref, and decompilation checks on 2026-05-28.

## Role

This helper destroys a metadata tree node owned by the `MetaMan`/`MetaTable` metadata subsystem. It first tears down the node payload at `node + 0x10` through the adjacent metadata value cleanup helper at `0x00524400/0x00524440`, then frees the 44-byte node allocation.

IDA shows callers inside the `MetaMan` range at `0x00523f3e`, `0x0052418c`, and `0x005243a3`, which ties this helper to metadata tree cleanup rather than to generic allocator code.

## Raw Behavior

```cpp
void DestroyMetaNode(void *owner, MetaNode *node)
{
    DestroyMetaValue(owner, &node->value);
    operator_delete_sized(node, 0x2c);
}
```

Final C++ should use the recovered metadata node/value types once the `MetaMan` and `MetaTable` layout pages are finalized.
