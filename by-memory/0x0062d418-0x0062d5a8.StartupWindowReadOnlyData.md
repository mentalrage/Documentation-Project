## Summary

This `.rdata` span contains startup/update notice window class/title strings, `StartupWindow` vtable data, update/news/minimap URLs, the registry value name for the stored update version, and notice-window PCX resource names. It ends before the `StdioFile` complete-object-locator pointer at `0x0062d5a8`.

Parent handling: attach this page to [UID:0000O5][StartupWindow](by-file/StartupWindow.md). The `std::stoi` exception literals remain noted as parse-path/runtime-adjacent strings, but they do not justify splitting the island away from the startup owner.
