## IDA MCP Evidence

- 2026-06-01 IDA function inventory reports 13 function starts in this child range; several were absent from the older aggregate table.
- `decompile 0x00582500` computes `strlen`, allocates a wide buffer with `0x00582e30`, converts through [UID:000236][0x005151b0-0x005151ef.DefaultCodepageConversionWrappers](by-memory/0x005151b0-0x005151ef.DefaultCodepageConversionWrappers.md), writes the UTF-16 terminator, and updates header length at `data[-2]`.
- `decompile 0x00582560` computes `wcslen`, allocates a wide buffer with `0x00582e30`, and copies raw UTF-16 bytes.
- `decompile 0x005825a0` allocates an ANSI buffer with `0x00582d80`, converts through the default codepage wide-to-ANSI wrapper, writes the terminator, and updates header length.
- `decompile 0x00582680` builds a temporary ANSI string from wide data, calls `0x005e1b76` with the converted bytes, then releases through `0x005832f0`.
- Caller checks show broad utility fan-in for `0x00582560`, including UI, profile/config, map/render, and local-player/name paths, supporting shared string ownership rather than feature ownership.
- Non-`0xcc` spans inside this child range are method-shaped helper code that IDA models as later function starts (`0x00582670`, `0x00582770`, `0x00582830`, `0x005828e0`, `0x00582950`, `0x00582980`, and `0x005829a0`), not uncovered padding.
