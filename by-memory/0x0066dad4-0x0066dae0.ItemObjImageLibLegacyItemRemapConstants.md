# 0x0066dad4-0x0066dae0 ItemObjImageLib Legacy Item Remap Constants

## UID00041S Fixed-Slot Consumer Closure - 2026-08-11

- [UID:00041S][0x004defc0-0x004df1d4.ItemObjImageLibDrawItemImageIn43x43Slot](by-memory/0x004defc0-0x004df1d4.ItemObjImageLibDrawItemImageIn43x43Slot.md) now emits the exact source use of all three constants. It first converts `itemId + 0x4000` to an unsigned 16-bit entry, then applies this group only when `g_useEpfAssets` is false.
- Entries in inclusive band `g_currentItemImageRemapFirstEntry` (`0x0a20`) through `g_currentItemImageRemapLastEntry` (`0x0a56`) add `0xff53`, reproducing the signed 16-bit legacy rebase. Entries outside that band but above `g_legacyItemImageMaxEntry` (`0x0972`) clamp to `0x0972`.
- UID00041S then uses the remapped entry for `ITEM.EPD` layout lookup, while current mode uses the unmodified entry for `ITEM.EPF`. ## Consumer Behavior

The direct consumers are:

- `0x004defc0`, `ItemObjImageLib::DrawItemImageIn43x43Slot`.
- `0x004df2c0`, `ItemObjImageLib::DrawItemImageScaled`.
- [UID:0000UQ][0x004df460-0x004df4f9.GetItemGlyphBounds](by-memory/0x004df460-0x004df4f9.GetItemGlyphBounds.md).

All three perform the same legacy/non-EPF item-entry remap:

- Start with `itemId + 0x4000`.
- If [UID:0000SW][g_useEpfAssets](by-global/g_useEpfAssets.md) equals `1`, use the computed entry unchanged and select the EPF resource path.
- If not in EPF/current mode and the computed entry is in `0x0a20..0x0a56`, add signed 16-bit immediate `0xff53`, mapping the current band down to the legacy-adjacent range after `0x0972`.
- If not in the remap band and the entry is above `0x0972`, clamp to `0x0972`.
- `GetItemGlyphBounds` then uses `ITEM.EPF` versus `ITEM.EPD` layout tables and centers the returned rectangle by half of [UID:0000T7][MapTilePixelDimensions](by-global/MapTilePixelDimensions.md).

## Evidence

- Live/prior docs and B002's PE reanalysis show each of `0x004defc0`, `0x004df2c0`, and `0x004df460` reads `0x0066dad4`, `0x0066dad8`, and `0x0066dadc`.
- No MapPane code reads these addresses.
- The helper pattern is specific to item-image entries: base `itemId + 0x4000`, `ITEM.EPF`/`ITEM.EPD` resource choice, `g_useEpfAssets` legacy/current branch, translated-band rebasing, and fallback clamp.
- The values are adjacent to but distinct from the MapPane map-tile remap group at [UID:0003ZM][0x0066dabc-0x0066dad4.MapPaneLegacyMapTileRemapConstants](by-memory/0x0066dabc-0x0066dad4.MapPaneLegacyMapTileRemapConstants.md).
