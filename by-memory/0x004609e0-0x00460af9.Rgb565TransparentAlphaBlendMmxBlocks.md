# 0x004609e0-0x00460af9 RGB565 Transparent Alpha Blend MMX Blocks

## Status

- Disposition: reconstructable NexusTK render support code.

- Rebuild handling: `source-authored`.

## Address Range

`0x004609e0-0x00460af9` (`sub_4609E0`, size `0x119`, 89 decoded instructions).

The following `0x00460af9-0x00460b00` bytes are alignment padding.

## Behavior

This is the MMX four-pixel/block path for transparent weighted RGB565 blending. The raw parent span body computes `width / 4` blocks, passes the source pointer, source pitch, destination pointer, destination pitch, a source-side weight of `32 - alpha`, block count, and row count, then advances both pointers by `blocks * 8` bytes and uses a scalar tail for the remaining pixels.

The helper repeats its byte weight argument into `qword_67A810`; it computes `32 - weight` into `qword_67A818`. The qword loop blends source and destination RGB565 channels with masks `0x001f001f001f001f` and `0x07e007e007e007e0`, preserves destination lanes where the source word is zero, advances eight bytes per block, advances by source/destination row pitches per row, and finishes with `emms`.
