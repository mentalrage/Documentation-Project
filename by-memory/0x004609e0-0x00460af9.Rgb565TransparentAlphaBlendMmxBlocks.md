# 0x004609e0-0x00460af9 RGB565 Transparent Alpha Blend MMX Blocks

## Status

- Disposition: reconstructable NexusTK render support code.
- Entity kind: free render helper.
- Likely source file: [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) `SoftwareBlend16`.
- Confidence: strong for boundary and behavior.
- Rebuild handling: `source-authored`.

## Address Range

`0x004609e0-0x00460af9`.

The following `0x00460af9-0x00460b00` bytes are alignment padding.

## Behavior

This is the MMX four-pixel/block path for transparent weighted RGB565 blending. It builds repeated source and inverse weights in globals `qword_67A810` and `qword_67A818`, blends source and destination RGB565 components with masks `0x1f001f001f001f` and `0x07e007e007e007e0`, and preserves the destination where the source pixel is zero.
