## Ownership Decision

This is map weather rendering support. The base class may deserve a separate `WeatherLayerPane.cpp`, while `RainingLayerPane` may stay in `RainingLayerPane.cpp` or fold into a broader weather-layer source family. Do not move this code into generic render solely because it draws graphics; lifetime and construction are driven by map weather state.

Attach this aggregate to [UID:0000P8][WeatherLayerPane](by-file/WeatherLayerPane.md) as the weather-layer source-family parent until final split evidence is stronger. Do not emit a single C++ body for the aggregate yet: source migration needs to decide whether rain remains a separate `RainingLayerPane.cpp` or a private concrete class beside the weather base.
