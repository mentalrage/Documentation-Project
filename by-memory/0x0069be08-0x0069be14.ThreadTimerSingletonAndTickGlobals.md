# Thread And Timer Singleton/Tick Globals

## Summary

- Address range: `0x0069be08-0x0069be14`
- Entity kind: global-data cluster
- Disposition: reconstructable project data
- Rebuild handling: `source-declared/generated-binary`
- Confidence: strong for `ThreadMan` and `TimerMgr` roles; medium for final source names

This twelve-byte cluster contains the active `ThreadMan` pointer and timer tick mirror globals.

## Layout

| Range | Current IDA name | Role |
| --- | --- | --- |
| `0x0069be08-0x0069be0c` | `dword_69BE08` | active `ThreadMan` singleton pointer |
| `0x0069be0c-0x0069be10` | `dword_69BE0C` | timer tick baseline/mirror |
| `0x0069be10-0x0069be14` | `dword_69BE10` | current timer tick mirror |

## Evidence

- IDA xrefs for `dword_69BE08` come from `ThreadMan` construction/clear/destruction paths, including [UID:0001K0][0x00596bf0-0x00596d13.ThreadManConstructor](by-memory/0x00596bf0-0x00596d13.ThreadManConstructor.md), [UID:0001K4][0x005974e0-0x005974eb.ClearThreadManSingleton](by-memory/0x005974e0-0x005974eb.ClearThreadManSingleton.md), and [UID:0001K5][0x005974f0-0x0059756e.ThreadManScalarDeletingDestructor](by-memory/0x005974f0-0x0059756e.ThreadManScalarDeletingDestructor.md).
- [UID:0000F1][TimerMgr](by-class/TimerMgr.md) records `dword_69BE0C` and `dword_69BE10` as timer tick mirror globals written during timer initialization/refresh.
- IDA decompilation of `0x00597e40` writes both tick globals from `timeGetTime`-style timer setup; `0x005977b0` updates `dword_69BE10` while dispatching due timers.

## Rebuild Notes

Keep `dword_69BE08` with `ThreadMan` source and the two tick globals with `TimerMgr`. The physical adjacency is not enough to merge these modules.
