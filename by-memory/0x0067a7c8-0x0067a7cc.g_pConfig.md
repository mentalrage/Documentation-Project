# 0x0067a7c8-0x0067a7cc g_pConfig

## Status

- Address range: `0x0067a7c8-0x0067a7cc`
- Entity kind: global pointer
- Proposed name: `g_pConfig`
- Disposition: reconstructable NexusTK global data
- Parent: [UID:0000IE][Config](by-file/Config.md)

This four-byte zero-initialized global stores the active configuration object pointer. IDA evidence shows that the base `Config` constructor publishes the pointer, startup promotes the object to the `RegistryConfig` runtime layout, and teardown paths clear the slot before object destruction completes. The declaration remains base-typed as `Config *g_pConfig`; the profile/macro storage belongs to Config even though RegistryConfig methods default and persist it. Former derived-cast source wording is superseded.
