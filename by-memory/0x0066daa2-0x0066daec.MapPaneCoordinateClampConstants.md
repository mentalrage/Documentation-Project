# 0x0066daa2-0x0066daec MapPane Coordinate Clamp Constants

## Summary

- Address range: `0x0066daa2-0x0066daec`
- Entity kind: initialized coordinate/constants data
- Disposition: reconstructable project data
- Rebuild handling: source-declared static coordinate/remap constants
- Parent: [UID:0000L3][MapPane](by-file/MapPane.md)
- Confidence: strong for the live value/xref map; medium for final source split because the referenced constants are shared by MapPane and item-image helpers

This range is a small initialized data island between the global tile-dimension words and the shared empty `SimpleUString`. The referenced constants split into a MapPane tile-coordinate clamp group and an item-image remap group used when `byte_66DA97` selects the legacy/non-EPF path.
