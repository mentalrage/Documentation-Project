# 0x0066daa2-0x0066daec MapPane Coordinate Clamp Constants

## Summary

- Address range: `0x0066daa2-0x0066daec`
- Entity kind: initialized coordinate/constants data
- Disposition: reconstructable project data
- Rebuild handling: `source-declared/generated-binary`
- Confidence: medium for `MapPane` coordinate ownership; low for final symbol names and the unreferenced leading constants

This range is a small initialized data island between the global tile-dimension words and the shared empty `SimpleUString`. The referenced tail constants are consumed by map/object coordinate adjustment helpers and by three new/old rendering-path helpers that branch on `byte_66DA97`.
