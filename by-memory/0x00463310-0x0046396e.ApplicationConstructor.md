5. Copies default dimensions/settings from `word_66DA98` and `word_66DA94` into object offsets `0xa60` and `0xa64`.

8. Stores constructor/runtime state fields including object offset `0x20`, offset `0x24 = 0`, active message-handler pointer at `0x844`, byte flag `0x838 = 1`, pointer/table value `unk_612730` at `0xa70`, several status bytes/dwords around `0x828-0x84f`, and `0x848 = -1`.
