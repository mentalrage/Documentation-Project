- Parameter confidence: medium-high for shape, medium for final names. `a2` is the `HINSTANCE`/instance-handle candidate stored at object offset `0x20`; IDA disassembly of `_WinMain@16` at `0x004f5cb6-0x004f5cca` pushes `[ebp+hInstance]` as this argument. `Source` is copied to the `0x28` buffer; `a4` is the base path copied into the `0x228`, `0x428`, and `0x628` buffers before `.DAT` and `.SND` suffix construction.

## Behavior

Constructs the process-level `Application` singleton, initializes the application object layout, records startup timestamps and paths, sets default screen/version/OS state, initializes embedded strings/subobjects, records processor and executable path information, checks the startup DAT archive, and stores [UID:000294][0x0067ab1c-0x0067ab20.g_pApplication](by-memory/0x0067ab1c-0x0067ab20.g_pApplication.md).

## Constructor Phases

1. Calls `sub_4F4A80` before installing the Application vtables. This is likely base-class construction or shared object initialization, but the exact source name is still open.
2. Stores the active singleton pointer in [UID:000294][0x0067ab1c-0x0067ab20.g_pApplication](by-memory/0x0067ab1c-0x0067ab20.g_pApplication.md) / `dword_67AB1C`.
3. Initializes the embedded [UID:0001CN][0x00528d60-0x00528e55.MSGHandler](by-memory/0x00528d60-0x00528e55.MSGHandler.md) subobject at `this + 0x4`, then writes both Application vtable pointers at object offsets `0x0` and `0x4`.
4. Initializes string-like members at `this + 0x1c` and `this + 0x854`.
5. Copies default dimensions/settings from `word_66DA98` and `word_66DA94` into object offsets `0xa60` and `0xa64`.
6. Initializes the global timing baseline block [UID:000291][0x0067a980-0x0067a998.ApplicationTimingBaselines](by-memory/0x0067a980-0x0067a998.ApplicationTimingBaselines.md) from `timeGetTime`, `GetTickCount`, `_time64`, and `GetSystemTimeAsFileTime`, then clears the skew/report counter at `0x0067a994`.
7. Builds the global OS-version text buffer at `byte_67AAD8` using `GetVersionExW` and the labels `Win95`, `Win98`, `WinME`, `Win2K`, `WinXP`, or `Unknown`.
8. Stores constructor/runtime state fields including object offset `0x20`, offset `0x24 = 0`, active message-handler pointer at `0x844`, byte flag `0x838 = 1`, pointer/table value `unk_612730` at `0xa70`, several status bytes/dwords around `0x828-0x84f`, and `0x848 = -1`.
9. Calls [UID:0002H5][0x00464f50-0x00465115.ApplicationDetectOS](by-memory/0x00464f50-0x00465115.ApplicationDetectOS.md), which performs the detailed OS/WOW64 detection pass into Application fields.
10. Reads `ProcessorNameString` from `HKEY_LOCAL_MACHINE\HARDWARE\DESCRIPTION\System\CentralProcessor\0`, closes the key, and passes the buffer to `sub_582D20`.
11. Copies startup paths: `Source` to `this + 0x28`; `a4` to `this + 0x228`; `a4 + ".DAT"` to `this + 0x428`; `a4 + ".SND"` to `this + 0x628`; and wide literal `TestServer` to `this + 0x858`.
12. Allocates 8 bytes with `operator new` and conditionally calls `sub_49BD30` / `DATFileMgr::DATFileMgr`. The constructor passes the allocation in `ecx`; the public DAT manager constructor is documented as writing [UID:0001P6][0x0067ab40-0x0067ab44.g_pDATFileMgr](by-memory/0x0067ab40-0x0067ab44.g_pDATFileMgr.md), not as storing a DAT-manager pointer into the `Application` object.
13. Twice parses `GetCommandLineW()` to derive the executable directory, calls `SetCurrentDirectoryW` through dispatch-table slot `dword_69BEAC`, obtains the module filename through `GetModuleFileNameW` slot `dword_69BE74`, opens/creates `HKCU\Software\Nexon` through `RegCreateKeyExW` slot `dword_69BE94`, and writes `Barampath` through `RegSetValueExW` slot `dword_69BEA8`.
14. Checks `DATA/BARAMST.DAT` through [UID:00012C][0x0049be70-0x0049be7c.ForwardLoadDATFileIndex](by-memory/0x0049be70-0x0049be7c.ForwardLoadDATFileIndex.md). On failure it formats `File not found : %s` and calls the fatal/error display path at `0x00465cb0`.
