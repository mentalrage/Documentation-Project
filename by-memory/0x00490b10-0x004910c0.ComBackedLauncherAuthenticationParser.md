## Behavior

This helper is the COM-backed Excite Game launcher/authentication parser for the `RegistryConfig` startup parser island. It copies the process command line into a 1024-wide-character local buffer, skips the executable token with quote/space handling, and returns if no launcher command tail remains.

When a command tail exists, it calls `CoInitialize(0)`, replaces a launcher-auth COM holder stored through `config + 0x28d9e0`, creates the COM object with `CoCreateInstance`, runs it with `OleRun`, and query-acquires the launcher-auth interface using GUID data at `0x0061711c`. The `CoCreateInstance` call uses `IID_IUnknown` at `0x00616db0`, the provisional launcher-auth class GUID at `0x0061712c`, and CLSCTX value `0x17`.

After acquisition, the helper wraps the command tail in a `BSTR`, passes it through the COM object's launch-command method, retrieves endpoint/auth data through the COM wrapper helper at `0x004943a0`, and then normalizes the endpoint. Numeric endpoints are tokenized on the UTF-16 dot delimiter at `0x00612e38` and stored as four bytes at `config + 0x2915b4`. Nonnumeric endpoints are copied to `config + 0x2915c4`, converted with `WideCharToMultiByte(CP_ACP, ...)`, resolved with `gethostbyname`, and then copied as resolved address bytes to `config + 0x2915b4`.

Failure behavior is user-visible and must not be collapsed into a silent return. COM creation/acquisition failure uses the component-not-installed text at `0x0061713c`, posts quit, and follows the loader/failure path. DNS failure calls the ignored COM smart-pointer null-check helper at `0x00494000`, formats the Excite Game host/input failure string at `0x00617160`, and shows the localized message-box path.

On success, the helper calls the COM vtable slot represented by the decompiler as `+0x28`, stores the returned authentication token/context at `config + 0x2916c4`, writes `m_startupReady = 1` at `config + 0x2916ca`, writes `m_startupConnectionMode = 5` at `config + 0x28de28`, and cleans BSTR/holder state through `0x00494440` and the SEH cleanup chunk.
