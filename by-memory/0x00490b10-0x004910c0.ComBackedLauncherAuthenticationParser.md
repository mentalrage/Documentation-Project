## Behavior

This helper is a COM-backed launcher/authentication path. It reads the process command line, initializes COM, creates and runs a browser-supplied COM object, extracts either host or dotted-IP endpoint data, resolves hostnames when necessary, and stores the returned credential/token-like value and resolved connection state into the startup-state block.

On failure it follows the common localized message-box/quit path.
