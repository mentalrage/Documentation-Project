## Range Role

This range contains the stock zlib inflate API entry points, default allocator/free callbacks, and Adler-32 checksum helper. It sits between deflate workers and deflate tree helpers in the linked binary, but the source ownership is split across `inflate.c`, `zutil.c`, and `adler32.c`.

## Function Map

| Range | zlib 1.1.4 source | Role |
| --- | --- | --- |
| `0x004158b0-0x004158f2` | `inflate.c`: `inflateReset` | Resets inflate mode/state and calls `inflate_blocks_reset`. |
| `0x00415900-0x00415948` | `inflate.c`: `inflateEnd` | Frees block state, frees inflate state, and clears `z_stream.state`. |
| `0x00415950-0x00415a5e` | `inflate.c`: `inflateInit2_` | Version/stream-size check, default allocator setup, inflate-state allocation, window-bit handling, and block-state creation. |

| `0x00415eb0-0x00415ec3` | `zutil.c`: `zcalloc` | Default allocation callback around `calloc`. |
| `0x00415ed0-0x00415edc` | `zutil.c`: `zcfree` | Default free callback around CRT `free`. |
| `0x00415ee0-0x0041600e` | `adler32.c`: `adler32` | Standard chunked Adler-32 implementation using modulo `65521` and max chunk `5552`. |

## Evidence

- IDA decompilation of `0x00415950` checks zlib version string `1.1.4`, stream size `56`, installs `0x00415eb0` and `0x00415ed0` when allocators are missing, allocates a 24-byte inflate state, and calls `0x00417c20` to allocate block state. This matches stock `inflateInit2_`.
- IDA callees show `inflateReset` calls `0x00417ba0` (`inflate_blocks_reset`), `inflateEnd` calls `0x004189d0` (`inflate_blocks_free`), and `inflate` calls `0x00417cc0` (`inflate_blocks`).
- IDA decompilation of `0x00415eb0` returns `calloc(Count, Size)` and `0x00415ed0` calls CRT `free`, matching the generic `zcalloc`/`zcfree` branch in `zutil.c`.
- The `0x00415ee0` body matches stock `adler32.c` constants and chunking behavior.

## Ownership Decision

Keep these functions under `third_party/zlib/` as `inflate.c`, `zutil.c`, and `adler32.c` code. The allocator helpers are zlib callbacks, not NexusTK memory-management helpers.
