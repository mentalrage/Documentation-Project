## Behavior

The body is the ordinary non-deleting `_DATFileMgr` destructor equivalent:

- Writes the `_DATFileMgr` vtable back to offset `+0x00`.
- Iterates the archive-container pointer vector at offsets `+0x24` through `+0x28`.
- For each non-null archive container pointer, calls vtable slot 0 with delete flag `1`.
- Frees the archive-vector allocation using the same large-allocation base-pointer check seen in the modeled scalar deleting destructor.
- Clears vector begin/end/capacity at `+0x24`, `+0x28`, and `+0x2c`.
- Calls [UID:00012H][0x0049d190-0x0049d26c.DATFileResolverDestroy](by-memory/0x0049d190-0x0049d26c.DATFileResolverDestroy.md) on the embedded resolver/hash-table state at `this + 4`.
- Returns without conditionally freeing `this`.
