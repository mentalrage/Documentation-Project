- `ida_funcs` reports `sub_49B6C0` at `0x0049b6c0-0x0049b731`, size `0x71`.
- Primary vtable data cell `0x00618100` points to `0x0049b6c0`; RTTI cell `0x006180fc` names `TextEditControlPane`.
- A second primary vtable data cell `0x006181a4` also points to `0x0049b6c0`; RTTI cell `0x006181a0` names `StaticTextControlPane`. This documents a shared or reused deleting-destructor body and should not be mistaken for caller ownership by StaticTextControlPane.
- Decompilation writes `TextEditControlPane::vftable` at object offsets `0x0`, `0xa0`, and `0xa4`.
- The body reads `Block[67]` (`this + 0x10c`) as the embedded editor/control object pointer, calls its virtual deleting destructor with flag `1` when present, then clears `Block[67]`.
