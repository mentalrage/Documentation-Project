# 0x00556320-0x005563cd - VoteMenuPane Scalar Deleting Destructor

## Status

- Confidence: strong for function boundary, singleton clear, vtable stores, and deleting-destructor behavior.
- Proposed owner: [UID:0000FX][VoteMenuPane](by-class/VoteMenuPane.md).

## Behavior

The deleting destructor:

- restores the `VoteMenuPane` primary and secondary vtables;
- removes/destroys pane child state through the shared pane cleanup path;
- clears [UID:0000SP][g_pVoteMenuPane](by-global/g_pVoteMenuPane.md);
- calls the pane/base destructor path;
- optionally frees the object when the scalar-delete flag is set.
