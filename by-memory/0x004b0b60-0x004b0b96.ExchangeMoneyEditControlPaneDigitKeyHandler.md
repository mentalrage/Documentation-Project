## Behavior

This `thiscall` key-event handler accepts only a narrow digit-key event shape:

- event byte `+4` must equal `10`;
- event byte `+9` must equal `1`;
- UTF-16 key code at event offset `+0x0a` must be between `'0'` and `'9'`.

When the event passes all checks, it calls `0x00498d90` on the control and returns `1`. Otherwise it returns `0`. The called helper forwards through the embedded text-edit control pointer and invokes the child editor's secondary vtable slot `+8`, matching commit/hide or edit-state synchronization for accepted numeric input.
