## Behavior

Allocates or reallocates backing storage for an exact element count supplied as the stack argument. The byte count is `m_elementSize * elementCount`. If `m_data` is null it allocates through `GetMemoryMan()->AllocateBufferMemory(byteCount)`; otherwise it reallocates through `MemoryMan::ReallocateBufferMemory(m_data, byteCount)`. The returned pointer is stored back to `m_data` at `this + 0x10`.

This helper does not update the logical count field and does not use `m_pageSize`. It reserves exact element capacity only; page-rounded logical count changes remain handled by sibling methods such as [UID:0003JU][0x004f31d0-0x004f329f.ListSetCount](by-memory/0x004f31d0-0x004f329f.ListSetCount.md), [UID:0003K4][0x004f35a0-0x004f35db.ListReservePageCountRaw](by-memory/0x004f35a0-0x004f35db.ListReservePageCountRaw.md), and [UID:0003K5][0x004f35e0-0x004f35fd.ListPageCountForElementCountRaw](by-memory/0x004f35e0-0x004f35fd.ListPageCountForElementCountRaw.md).
