## Behavior

This raw constructor-shaped helper initializes the nested reward-item vector inside a 560-byte ranking reward entry and sets the symbol/frame byte to `0xff`.

Observed writes:

```text

this + 0x224 = 0
this + 0x228 = 0
this + 0x22c = 0
return this
```

The offsets match [UID:0001ZF][0x0045d7e0-0x0045db54.RankingRewardEntryParseAndAccessors](by-memory/0x0045d7e0-0x0045db54.RankingRewardEntryParseAndAccessors.md), where `+0x224` is the nested vector of 520-byte reward-item rows.
