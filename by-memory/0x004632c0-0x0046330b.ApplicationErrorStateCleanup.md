## Reconstruction Notes

Do not populate this page's formal C++ block. The body is an MSVC-generated deleting destructor wrapper for the concrete `_AUTOBUF<wchar_t>` artifact: it restores the vtable, frees `this+4`, calls the inherited `LObject` destructor body, and conditionally dispatches the delete wrapper based on the deleting-destructor flag byte. Hand-authoring this function as `ApplicationErrorState::~ApplicationErrorState` would encode the wrong source type and the wrong source abstraction.

The exact AUTOBUF header casing/API and static variable spelling remain project-wide source-quality questions. Best current names are `s_applicationErrorText`, `m_data` or `m_buffer` at `+0x04`, and `m_count` or `m_cch` at `+0x08`.
