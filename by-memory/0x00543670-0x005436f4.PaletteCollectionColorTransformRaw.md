## Behavior

The helper takes two collection-like objects and a float weight:

1. If the first collection count at `+0x0c` is not positive, it returns immediately.
2. It computes an integer strength byte from `(weight * 32.0f) + 0.5f`.
3. For each collection index, it calls the virtual item accessor at vtable slot `+0x10` on both collections.
4. It treats each returned item as a pointer to a palette object, walks 255 entries beginning at native-color table offset `+0x2e`, and calls `dword_69B408(baseColor, strength)` for each source color.
5. It writes transformed 16-bit colors into the paired destination palette table.

This is similar in shape to the runtime palette-filter table rebuild work in [UID:0001E9][0x00543f60-0x005440f0.PaletteLibPaletteFilterHelpers](by-memory/0x00543f60-0x005440f0.PaletteLibPaletteFilterHelpers.md), but no direct code xrefs to `0x00543670` were observed in the current IDA database.
