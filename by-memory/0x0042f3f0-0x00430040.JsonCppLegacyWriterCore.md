# JsonCpp Legacy Writer Core `0x0042f3f0-0x00430040`

## Status

- Disposition: ignored for NexusTK source reconstruction.
- Entity kind: statically linked third-party JsonCpp legacy writer code.
- Likely owner: [UID:0000KI][JsonCpp](by-file/JsonCpp.md), `src/lib_json/json_writer.cpp`.
- Confidence: strong for JsonCpp ownership and non-product disposition; medium for exact per-function source names where IDA has raw or jump-table regions.

## Range Role

This range follows the [UID:0000X3][0x0042e850-0x0042f3f0.JsonCppStreamWriterBuilderIsland](by-memory/0x0042e850-0x0042f3f0.JsonCppStreamWriterBuilderIsland.md) and contains the older `Json::Writer`, `Json::FastWriter`, and `Json::StyledWriter` implementation family. It ends immediately before the helper at [UID:0000X5][0x00430040-0x00430092.GenericStringAppendHelper](by-memory/0x00430040-0x00430092.GenericStringAppendHelper.md), which is now also classified as JsonCpp writer support rather than NexusTK feature code. The following [UID:0000X6][0x00430092-0x00431d50.JsonCppWriterTailAndOurReaderPrelude](by-memory/0x00430092-0x00431d50.JsonCppWriterTailAndOurReaderPrelude.md) continues the writer helper chain and crosses into the reader constructor prelude.

The functions serialize `Json::Value` trees into strings, including `null`, integer, unsigned integer, real, string, boolean, array, and object cases. They call JsonCpp value helpers for type inspection, member enumeration, array access, string extraction, numeric formatting, and quoted-string conversion.

## Evidence

- IDA MCP `lookup_funcs` and `py_eval` list the modeled functions and raw code starts in this span. No product feature classes own these function boundaries.
- IDA disassembly at `0x0042f3f0` writes `const Json::Writer::vftable`, and the raw constructor at `0x0042f400` writes `const Json::FastWriter::vftable`.
- IDA decompilation of `0x0042f460` clears a document string, calls `0x0042f4b0`, conditionally appends `"\n"`, and returns a string, matching `FastWriter::write`.
- IDA decompilation of `0x0042f4b0` switches on the JsonCpp value type byte and serializes null, integers, unsigned integers, real values, strings, booleans, arrays, and objects.
- IDA decompilation of `0x0042f800`, `0x0042f870`, `0x0042fc00`, and `0x0042fef0` matches `StyledWriter::write`, `writeValue`, `writeArrayValue`, and `isMultineArray` behavior, including comment handling, indentation, child-value collection, and array line-length tests.
- Source comparison: staged `json_writer.cpp` at the current best JsonCpp snapshot contains `Writer::~Writer`, `FastWriter::FastWriter`, `FastWriter::write`, `FastWriter::writeValue`, `StyledWriter::write`, `StyledWriter::writeValue`, `StyledWriter::writeArrayValue`, and `StyledWriter::isMultineArray` in this same order.
- The following helper [UID:0000X5][0x00430040-0x00430092.GenericStringAppendHelper](by-memory/0x00430040-0x00430092.GenericStringAppendHelper.md) is called only from `0x0042f870` in current IDA caller evidence and matches `StyledWriter::pushValue`-style behavior.

## Ownership Decision

Keep this range with [UID:0000KI][JsonCpp](by-file/JsonCpp.md) and `third_party/jsoncpp/src/lib_json/json_writer.cpp`. It is third-party writer/formatter code that should be obtained from the staged JsonCpp source, not reconstructed as NexusTK-owned source.

Do not migrate any functions in this range into exchange, clan-bank, fitting-room, cash-shop, or downloader modules. Product modules may call JsonCpp APIs, but they do not own the writer implementation.
