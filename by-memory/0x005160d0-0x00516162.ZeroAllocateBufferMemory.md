`MemoryMan::ZeroAllocateBufferMemory(size_t size)` calls `malloc(size)`, checks the result for null, zero-fills the successful allocation with `memset(buffer, 0, size)`, and returns the original allocation pointer. On allocation failure it constructs and throws a pointer to [UID:0000G7][Win32Error](by-class/Win32Error.md), matching the allocation-failure source shape accepted for [UID:0001BD][0x00516050-0x005160ce.AllocateBufferMemory](by-memory/0x00516050-0x005160ce.AllocateBufferMemory.md).

The helper performs raw byte initialization only. It has no caller-owned object construction, no element construction, no special size-zero branch, and no hidden free/copy path on success.
