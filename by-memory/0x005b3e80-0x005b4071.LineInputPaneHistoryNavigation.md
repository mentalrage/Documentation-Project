## Evidence Notes

- IDA decompilation shows two mode branches: mode `0` uses fallback recipient history, and mode `4` uses recent recipient history.
- The helper reads history data through `g_pUserPane`, writes the selected history entry into the embedded `TextEditPane`, and resets selection to the full text.
- The address sits in the chat-input neighborhood, but behavior is a reusable `LineInputPane` extension used by chat-style input panes.
