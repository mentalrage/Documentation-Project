## Behavior

`LoadIndexedDATSeries` is the repeated resource-startup helper used by `Application::Initialize` for numbered archive families:

1. Iterates indexes `0..98`.
2. Formats `L"%s%d.DAT"` into a local wide filename buffer.
3. Probes the loose archive file through `_wfopen_s(..., L"rb")`.
4. Stops the series when the next numbered file is absent.
5. Closes each successfully opened probe stream immediately.
6. Calls [UID:00012C][0x0049be70-0x0049be7c.ForwardLoadDATFileIndex](by-memory/0x0049be70-0x0049be7c.ForwardLoadDATFileIndex.md) on [UID:0000QQ][g_pDATFileMgr](by-global/g_pDATFileMgr.md) to load/index the same archive.
7. Formats `L"File not found : %s"` and calls the fatal error path at `0x00465cb0` if the DAT manager rejects a file that exists on disk.
8. Returns `1`.

The helper treats a missing next-numbered file as normal end-of-series, but treats an existing file that cannot be indexed as fatal startup failure.
