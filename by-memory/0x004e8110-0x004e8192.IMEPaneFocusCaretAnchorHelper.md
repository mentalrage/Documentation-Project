## Behavior

This helper refreshes the root IME pane's candidate/composition anchor from the last focused text-entry pane. When the focus-list count is positive, it fetches the last focus-list entry, asks that pane for caret and local/global geometry through text-entry/pane helpers, and writes the resulting anchor fields on the root IME pane. When no focus pane is recorded, it clears the cached anchor fields.
