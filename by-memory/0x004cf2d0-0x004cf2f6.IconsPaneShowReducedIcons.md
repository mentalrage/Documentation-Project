## Behavior

This method switches the icon strip to reduced display mode. It writes config byte `g_pConfig + 0x28de32` to `1`, clears `this + 0xf8`, and invalidates the pane bounds so the icon strip repaints.

Reduced mode makes paint and hit-test logic start at icon index `6`, leaving only the last two icon buttons visible.
