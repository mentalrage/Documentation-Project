## Behavior

This method loads `RIDINGS.DNA` into the `RidingImageLib` runtime definition arrays. It:

- constructs a local DAT/stdio-style reader object and opens `RIDINGS.DNA`;
- reads a 32-bit riding definition count;
- allocates a counted heap vector of 12-byte `RidingDefinition` records and stores the pointer at `this+0x04` and count at `this+0x08`;
- initializes the process-wide default riding definition table at `0x0069b430` with 21 8-byte bucket rows;
- seeds each default bucket with one 10-byte entry spanning frame range `0..30000` and a zero direction/flag byte;
- reads each file-backed riding definition as a 12-byte record:
  - `+0x00` dword riding id;
  - `+0x04` byte bucket count;
  - `+0x05` byte default bucket/index-like value;
  - `+0x06` word animation/group-like value;
  - `+0x08` pointer to allocated bucket rows;
- allocates `bucketCount` 8-byte child bucket rows through the shared outer table helper at `0x005289d0`;
- for each bucket, reads a 16-bit entry count at bucket offset `+0x04`, allocates `entryCount` 10-byte bucket entries through `0x00528be0`, then reads each entry in the observed order `+0x00`, `+0x02`, `+0x06`, `+0x04`, `+0x08`, `+0x09`;
- closes/destroys the local reader and returns its close/status helper result.
