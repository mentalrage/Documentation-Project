## Behavior

This raw helper compares an external state record against fields in the selector pane object. It returns `true` only when:

- byte `record + 0` is nonzero;
- byte `record + 1` equals `this + 0x111`;
- dword `record + 4` equals `this + 0x114`;
- byte `record + 8` equals `this + 0x118`;
- dword `record + 0x0c` equals `this + 0x11c`;
- dword `record + 0x10` equals `this + 0x120`;
- dword `record + 0x14` equals `this + 0x124`.
