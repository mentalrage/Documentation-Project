## Behavior Notes

`WieldInputPane::OnSubmitInput` validates the typed slot letter against the local inventory count before calling this helper. The special `-` case sends opcode `0x12` with selector `0` inline inside `OnSubmitInput`; best interpretation is a clear/unwield/no selected weapon selector path. This helper covers the normal validated slot path:

- Lowercase `a-z` maps to selectors `1-26`.
- Uppercase `A-Z` maps to selectors `27-52` by subtracting `0x26`.
- The normal mapped selector must be between `1` and the caller-side `g_activeUserStatusPane +0x284` inventory slot count.
- Sibling Wear behavior uses opcode `0x1e`, not `0x12`; any `0x18` wording for Wield is stale.
