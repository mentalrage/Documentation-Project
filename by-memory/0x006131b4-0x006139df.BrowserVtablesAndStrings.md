## Ownership Decision

This is browser module static data. It supports keeping the browser classes in one coherent [UID:0000HV][Browser](by-file/Browser.md) source module or a small browser folder rather than isolated class-first generated files.

The aggregate page is intentionally not attached to a single autogen parent yet. Most of the range is browser-family data, but `0x006135dc-0x00613730` is WebBoardDialog/WebBoardDialogOld vtable data and `0x0061373c` is AutoInit vtable data. Final source reconstruction should emit declarations in the owning class/source modules and let the compiler regenerate concrete vtables.
