## Evidence

- IDA `list_globals "*Browser*"` returns the browser vtable and RTTI symbol family starting at `0x006131b4`.
- IDA `strings "*Browser*"` returns the browser host/caption strings at `0x00613954`, `0x00613970`, and `0x006139cc`.
- Browser constructors and host setup functions reference these values from the browser code neighborhood, including `BrowserWindow`, `BrowserControlPane`, `BrowserControlPaneOld`, and `BrowserThread`.
- IDA xrefs from the `BrowserThread` vtable symbol include the ordinary destructor at [UID:000215][0x0046eff0-0x0046f005.BrowserThreadNonDeletingDestructor](by-memory/0x0046eff0-0x0046f005.BrowserThreadNonDeletingDestructor.md) and scalar deleting destructor at `0x004706f0`.
- IDA xrefs from `0x00613294-0x006132e4` point to the `BrowserWindow` UI-handler callback cluster at [UID:00020T][0x0046a3d0-0x0046a505.BrowserWindowDocHostUiHandlerStubs](by-memory/0x0046a3d0-0x0046a505.BrowserWindowDocHostUiHandlerStubs.md).
- IDA xrefs from `0x00613290` and `0x006132dc` point to [UID:000216][0x004710b8-0x004710cc.BrowserWindowReleaseAdjustorTailThunks](by-memory/0x004710b8-0x004710cc.BrowserWindowReleaseAdjustorTailThunks.md); BrowserPane sound vtable slots at `0x00613350`, `0x00613400`, `0x00613640`, and `0x006136f0` point to [UID:000217][0x004710d0-0x004710df.BrowserPanePlaySound](by-memory/0x004710d0-0x004710df.BrowserPanePlaySound.md).
- IDA xrefs from `0x006133e0-0x00613414` point to BrowserDialog virtual methods in [UID:00020X][0x0046ad10-0x0046b51d.BrowserDialogPaneVirtuals](by-memory/0x0046ad10-0x0046b51d.BrowserDialogPaneVirtuals.md).
