## Behavior

The helper builds a five-byte outbound packet:

1. Initializes a local 16-byte packet scratch buffer and cursor length to zero.
2. Writes opcode byte `0x0c` through the PacketBuffer cursor byte writer at `0x00575650`.
3. Appends the supplied object id through the PacketBuffer cursor 32-bit big-endian writer at `0x005756d0`.
4. Queues exactly five payload bytes through [UID:0001HU][0x00574bb0-0x00574c13.QueueAndSendPacket](by-memory/0x00574bb0-0x00574c13.QueueAndSendPacket.md), using [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) as the outbound sender.

The packet-buffer writer convention leaves a zero byte after the sent payload in the local scratch buffer, but the send length is still `5`: one opcode byte plus the four-byte object id.
