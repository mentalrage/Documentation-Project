# 0x00506380-0x005063db MapPane Opcode 0C Object Id Packet Helper

## Status

- Disposition: reconstructable NexusTK project code.
- Entity kind: small packet-send helper.
- Likely source module: [UID:0000L3][MapPane](by-file/MapPane.md)
- Confidence: strong for function boundary and packet construction, medium for final source-facing name.

## Address Range

- Start: `0x00506380`
- End: `0x005063db`
- IDA name: `sub_506380`
- Boundary evidence: IDA MCP reports `sub_506380` as a real function from `0x00506380-0x005063db`; raw bytes show a normal MSVC frame, local packet buffer, security-cookie check, and `retn 4`.

## Behavior

The helper builds a short outbound packet whose leading opcode is `0x0c`, appends one unsigned integer argument, and sends the assembled buffer through the connection/session object at `dword_67A7EC`.

IDA Hex-Rays decompilation on 2026-05-28:

```cpp
int __stdcall sub_506380(unsigned int value)
{
    int length;
    unsigned char packet[16];

    length = 0;
    sub_575650(12, packet, &length);
    sub_5756D0(value, packet, &length);
    return sub_574BB0(dword_67A7EC, packet, length);
}
```

The packet-buffer helper names are still provisional. Keep this as a packet helper until the `sub_575650` / `sub_5756d0` writer family is finalized.
