| `0x0055d9e0-0x0055de98` | `ScrollPane::GetScrollPartRect` | Computes rectangles for scrollbar button, track, and thumb parts in vertical/horizontal orientations. |

## Behavior

- Part `0` is the first button; part `4` is the second button.
- Part `1` is the track before the thumb; part `3` is the track after the thumb.
- Part `2` is the thumb itself.
- The function uses scrollbar orientation, style button size, current position, range, drag state, and EPF skin offset to compute output rectangles.
- Vertical and horizontal paths share the same part-id contract, so callers can request scrollbar subrectangles without duplicating orientation-specific geometry.
- `ScrollPane::OnDraw` calls this helper for each drawable scrollbar part, while text-edit scrollbar handlers use the same rectangles for hot/drag/cursor behavior. That caller mix supports generic scrollbar ownership rather than `TextEditPane` ownership.
