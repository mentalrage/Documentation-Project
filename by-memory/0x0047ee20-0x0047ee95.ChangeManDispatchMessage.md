# 0x0047ee20-0x0047ee95 ChangeMan DispatchMessage

## Behavior

`ChangeMan::DispatchMessage` lower-bounds the registration list by owner pointer and scans same-owner entries. For each matching entry, it dispatches when either the entry is registered for all messages or its stored message type matches `Message::m_type` at `message + 0x04`.

Matching listeners are called through virtual slot `+0x08` on the listener object with `(owner, message)`.

## Raw Code Evidence

IDA raw disassembly on 2026-05-30 confirms:

- `0x0047ee37` calls `sub_4F3780(m_changeList, &key)` to find the first owner entry.
- `0x0047ee4a` reads the current list count from `m_changeList + 0x0c`.
- `0x0047ee5b` calls the list vtable slot `+0x10` to fetch the current entry.
- `0x0047ee63-0x0047ee65` stops the scan when `entry.owner != owner`.
- `0x0047ee67-0x0047ee78` dispatches when `entry.scope == 1`, or when `entry.scope == 0` and `entry.messageType == message->m_type`.
- `0x0047ee7a-0x0047ee81` calls the listener virtual slot `+0x08` with `(owner, message)`.
- `0x0047ee84-0x0047ee8a` increments the index after either a callback or a skipped nonmatching message record.

## C++ Reconstruction Candidate

```cpp
void ChangeMan::DispatchMessage(void *owner, Message *message)
{
    ChangeManEntry key;
    key.owner = owner;

    int index = m_changeList->LowerBound(&key);
    if (index < 0)
        return;

    int count = m_changeList->Count();
    for (; index < count; ++index) {
        ChangeManEntry *entry = m_changeList->At(index);
        if (entry->owner != owner)
            break;

        if (entry->allMessages ||
            (!entry->allMessages && entry->messageType == message->m_type)) {
            entry->listener->OnChange(owner, message);
        }
    }
}
```

The callback method name and return type remain provisional. IDA proves the virtual slot offset and arguments, not the original interface name.
