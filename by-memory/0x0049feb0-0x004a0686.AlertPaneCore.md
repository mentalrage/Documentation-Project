## Behavior Summary

The constructor initializes `DialogPane`, installs three `AlertPane` vtables, computes a centered dialog rectangle from the supplied layout reference, measures and wraps message text, creates static or scrollable text controls, creates optional primary and secondary `TextButtonControlPane` controls, sets default selection, shows the dialog, inserts it into the modal event list, and runs a short slide-in animation.

`DismissDialog(int buttonId, int unused)` accepts button ids `1` and `2`, animates the pane out when visible, dispatches to the corresponding no-argument virtual button callback, and dismisses the pane through the pane manager. The unused second framework argument is ABI-proven by the `retn 8` epilogue.
