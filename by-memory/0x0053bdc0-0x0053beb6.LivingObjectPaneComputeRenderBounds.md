## Behavior

This method computes the screen-space rectangle occupied by the living object sprite. The live prototype recovered by MCP is `_DWORD *__thiscall(int this, _DWORD *)`: the second argument is the caller-supplied `RectBounds`/rectangle output buffer, and the return value is the same output pointer after the four rectangle fields are populated.

The body combines map/pane coordinate conversion with the selected image dimensions, standing/elevation adjustment, and current sprite frame information. It calls a MapPane coordinate helper, selects either `NewHumanImageLib::CalculateBounds`-style logic or `MonsterImageLib::ComputeRenderBounds`-style logic, applies `RectBounds::Offset`-style adjustment, then writes the final left/top/right/bottom-style rectangle values to the caller output.

The helper is part of the same vtable group as the neighboring draw methods, but it does not emit draw calls itself. Its output supports hit testing, invalidation, and redraw bounds around the object.
