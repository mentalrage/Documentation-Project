## IDA Evidence

- 2026-06-10 B001-024 live IDA MCP reports `sub_46F810` at `0x0046f810-0x0046fab6`, followed by switch/table bytes beginning at `0x0046fab6`.
- Vtable data ref `0x006138b4` points to the function body.

- Case `250` inspects URL text for `close()` and resource/redirect markers, posts Browser private message `0x500` to the BrowserThread, calls [UID:00001B][BrowserWindow](by-class/BrowserWindow.md) navigation helper `0x00470dd0`, and can cancel navigation.

- Case `263` copies/captures the current URL string and calls `PostBrowserNotification` at `0x00470f20`.
