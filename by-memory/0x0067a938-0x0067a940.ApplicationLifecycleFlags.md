# 0x0067a938-0x0067a940 ApplicationLifecycleFlags

## Summary

- Address range: `0x0067a938-0x0067a940`
- Entity kind: application lifecycle flags
- Proposed name: `ApplicationLifecycleFlags`
- Disposition: reconstructable NexusTK global data
- Confidence: medium for final field names, strong for application ownership

This pair of dwords stores process-level application state flags used by initialization, shutdown, exception handling, and input/window dispatch paths.

## Layout

| Range | Current IDA name | Provisional role |
| --- | --- | --- |
| `0x0067a938-0x0067a93c` | `dword_67A938` | Application phase/state code. |
| `0x0067a93c-0x0067a940` | `dword_67A93C` | Application initialized/running-mode gate. |

## Evidence

- `Application::Initialize` at `0x004639d0` writes `dword_67A938 = 1`, toggles `dword_67A93C`, and later tests `dword_67A93C` during startup setup.
- Application shutdown/startup-adjacent helpers write other `dword_67A938` phase values: `0x004f6700` writes `2`, `0x00504110` writes `3`, and `0x004f6490` writes `4`.
- `Main_WndProc` / input dispatch at `0x00465f20` reads `dword_67A93C` as a gate before some active-client handling.
- Exception/diagnostic code at `0x004ab870` reads `dword_67A938`, supporting the application-phase interpretation.
