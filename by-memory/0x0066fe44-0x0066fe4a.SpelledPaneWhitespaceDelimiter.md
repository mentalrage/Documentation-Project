# 0x0066fe44-0x0066fe4a SpelledPane Whitespace Delimiter

## Summary

- Address range: `0x0066fe44-0x0066fe4a`
- Entity kind: initialized UTF-16 delimiter string
- Disposition: reconstructable project data
- Rebuild handling: source-declared static string
- Confidence: strong

This range contains the UTF-16LE delimiter string `" \t"` used by the `SpelledPane` serialized-entry parser.

## Evidence

- Raw bytes are `20 00 09 00 00 00`, which decode as wide space, wide tab, NUL.
- IDA MCP xrefs to `asc_66FE44` come from `0x0056c174`, `0x0056c199`, `0x0056c1b1`, and `0x0056c1d1` inside [UID:0001HA][0x0056bb20-0x0056c3f1.SpelledPane](by-memory/0x0056bb20-0x0056c3f1.SpelledPane.md).
- The parser computes the delimiter string length, searches within a parsed line, and then extracts text around the delimiter.

## Reconstruction Notes

Represent this as a static wide delimiter string in the `SpelledPane` parse helper, not as a standalone global with the generated `asc_66FE44` name.
