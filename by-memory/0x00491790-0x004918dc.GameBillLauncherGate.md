## Address Range

`0x00491790-0x004918dc`, ending before the IDA-modeled `sub_4918E0` at `0x004918e0`.

IDA does not currently model this start as a function, but live IDA disassembly decodes a normal stack-frame prologue at `0x00491790`.

## Behavior

This is a small `/GameBill` startup-mode gate. When the expected command-line argument is present, it sets the startup-ready byte and launch state. Otherwise it aborts through the common message-box/quit path.

## Evidence

- Legacy Wave2 report records `FUN_00491790` as `0x00491790 .. 0x004918db`, with no live Wave2 method/global resolution.
- IDA live disassembly shows calls to `GetCommandLineW`, `_wcstok_s`, `__wcsicmp`, `MessageBoxW`, `PostQuitMessage`, and `__loaddll`.
- The legacy report records the only real success-side work as setting `param_1 + 0x2916ca` to `1` and state byte `param_1 + 0x28de28` to `5`.
