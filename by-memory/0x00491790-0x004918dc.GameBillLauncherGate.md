## Behavior

This is a small `/GameBill` startup-mode gate. It copies the full command line into a `0x400` wide-character stack buffer, skips the executable path by looking for a quote or space delimiter, then tokenizes the remaining argument tail on wide spaces with `_wcstok_s`.

The missing command-tail delimiter path is quiet: if the executable/tail skip helper cannot find a post-executable argument tail, the function returns without UI and without writing startup state. A first-token-null result after a tail is present is different and enters the failure UI. The first token must case-insensitively match UTF-16 `/GameBill` at `0x006173a8`; selector mismatch also enters the failure UI. The token collector records local token pointers with an eight-entry guard, and the token-cap case returns quietly before setting state.

On success the helper only marks the shared startup state: it writes word `1` to `m_startupReady` at `config + 0x2916ca` and byte `5` to `m_startupConnectionMode` at `config + 0x28de28`. It does not parse or write host, port, launcher payload, session id/key, launcher id, or authentication-token fields.

Failures format the byte-decoded UTF-16LE message `이 버전의 바람의 나라는 GameBill 전용입니다. 입력정보에 오류가 있습니다.` from `0x006173c0` into a 256-wide-character buffer through the `sub_41B9B0` `vswprintf_s` wrapper, show it with `MessageBoxW`, then call `PostQuitMessage(0)` and `__loaddll(0)`.
