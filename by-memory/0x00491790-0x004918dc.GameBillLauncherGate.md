## Behavior

This is a small `/GameBill` startup-mode gate. It copies the full command line into a `0x400` wide-character stack buffer, skips the executable path by looking for a quote or space delimiter, then tokenizes the remaining argument tail on spaces with `_wcstok_s`.

The first token must case-insensitively match UTF-16 `/GameBill` at `0x006173a8`. The token collector records up to seven token pointers; a missing first token or selector mismatch enters the failure path, while eight-or-more non-null tokens take the guarded early return without setting the startup state.

On success the helper only marks the shared startup state: it writes word `1` to `param_1 + 0x2916ca` and byte `5` to `param_1 + 0x28de28`. It does not parse host, port, or payload fields.

Failures format the UTF-16 message `이 버전의 바람의 나라는 GameBill 전용입니다. 입력정보에 오류가 있습니다.` into a 256-wide-character buffer through the `sub_41B9B0` `vswprintf_s` wrapper, show it with `MessageBoxW`, then call `PostQuitMessage(0)` and `__loaddll(0)`.
