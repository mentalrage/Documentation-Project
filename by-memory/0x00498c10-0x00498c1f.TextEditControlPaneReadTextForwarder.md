## Behavior

The function forwards a bounded UTF-16 text-copy request from the `TextEditControlPane` wrapper to its owned embedded `TextEditPane` object:

- loads the embedded editor pointer from wrapper offset `+0x10c`;
- forwards the caller-supplied destination buffer and maximum character count unchanged;
- tail-jumps to [UID:0002O9][0x0058e380-0x0058e3d7.TextEditPaneCopyWideText](by-memory/0x0058e380-0x0058e3d7.TextEditPaneCopyWideText.md), which copies at most the requested number of UTF-16 code units, null-terminates the destination, and returns the copied count.

The high caller fan-in shows this is a reusable UI text-control accessor, not clan-owned code. Clan dialogs use it only because their quantity/text controls are `TextEditControlPane` instances.
