# 0x00543450-0x005435a5 CloneDLPaletteList

## Address Range

- Range: `0x00543450-0x005435a5`, start inclusive and end exclusive.
- Size: `0x155` bytes.
- Entity kind: NexusTK-owned palette helper function.
- Rebuild handling: `source-authored`.

## Behavior

This helper builds a new list of cloned `DLPalette` objects from a source list. It allocates a destination `List(4, 10)`, walks the source list count at offset `+0x0c`, retrieves each source entry through the source list vtable slot `+0x10`, allocates a `556` byte `DLPalette` object, constructs the `LObject` base, installs the `DLPalette` vtable, copies the palette header block and count fields, optionally duplicates the remap/move byte-pair buffer, copies the `0x200` byte native color lookup table from offset `+0x2c`, and appends the new object through the destination list vtable slot `+0x18`.

The helper currently has no direct start xrefs in live IDA. Treat it as retained or dormant palette source-family code until a caller or source-order table proves liveness.
