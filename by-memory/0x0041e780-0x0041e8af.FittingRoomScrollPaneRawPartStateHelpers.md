## Behavior

This raw island contains two helper bodies that generated Wave/Wave2 notes previously treated as scroll-part state helpers. IDA does not currently define function objects at either start, but manual byte review shows normal prologue/epilogue code:

- `0x0041e780-0x0041e7f0`: compares a requested part with the current hot/highlight part byte at `this + 0x103`, invalidates the old and new part rectangles through [UID:0002D7][0x0041e4f0-0x0041e777.FittingRoomScrollPaneGetPartRect](by-memory/0x0041e4f0-0x0041e777.FittingRoomScrollPaneGetPartRect.md) and the virtual invalidate slot, then stores the new hot part.

```cpp
void FittingRoomScrollPane::SetHotPart(ScrollPart part)
{
    if (m_hotPart == part)
        return;

    InvalidatePart(m_hotPart);
    InvalidatePart(part);
    m_hotPart = part;
}

void FittingRoomScrollPane::BeginPartPress(ScrollPart part, int x, int y)
{
    if (part == ThumbPart) {
        Rect thumb;
        GetPartRect(ThumbPart, thumb);
        m_dragOffset = Point(x - thumb.left, y - thumb.top);
    }

    m_activePart = part;
    ProcessActivePart();
    StartRepeatTimer(200);
}
```
