## Summary

This `.rdata` span contains the `UserLookPane`, `MoreInfoPane`, and `ProfilePane` vtable family plus the user-look/profile resource filename literals used by the remote-character look/profile panel.

The range is attached to [UID:0000P0][UserLookPane](by-file/UserLookPane.md) because the file page, class pages, executable aggregate, and vtable-family page all place these three classes in `ui/panels/UserLookPane.cpp`. The vtables themselves are compiler-emitted, but the source declarations, local child-pane classes, and resource string uses must be rebuilt through the user-look source.
