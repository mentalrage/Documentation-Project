## Behavior

This helper initializes a destination alpha-surface view object from a source alpha surface and an optional clip rectangle.

Observed behavior:

- writes [UID:0001XT][IntAlphaSurfaceVtable](by-type/by-vtable/IntAlphaSurfaceVtable.md) / `off_6112EC` to the destination object at offset `+0x00`;
- clears destination pixel pointer, width, height, stride, and bounds state;
- initializes the destination bounds through the rectangle constructor helper at `0x004b7c50`;
- if no clip rectangle is supplied, copies the source view payload from source offsets `+0x14` through `+0x24`;
- if a clip rectangle is supplied, builds the source bounds from source width/height, intersects it through the rectangle-intersection helper at `0x004b7cc0`, and either emits an empty view or computes a clipped non-owning pixel pointer;
- always clears the destination ownership byte at `+0x24` before returning, so the constructed view does not own the source pixel buffer.

The clipped pointer calculation is:

```text
dest->pixels = source->pixels + clip.left + clip.top * source->stride
dest->width  = clip.right - clip.left
dest->height = clip.bottom - clip.top
dest->stride = source->stride
dest->ownsPixels = false
```
