## Behavior

This raw helper advances the `PatchPane2` download filename index and retry/pass counter. It is the standalone helper-shaped version of the same progression logic used by the main loop subtype `3`.

Observed behavior:

1. Computes `(vectorEnd - vectorBegin) / 4 - 1` from owner fields `+0x278` and `+0x274`.
2. If current index `+0x280` is below the final vector element, increments `+0x280` and returns.
3. Otherwise, checks retry/pass counter `+0x288`.
4. If the counter is below `0x0a`, resets `+0x280` to `0`, increments `+0x288`, and returns.
5. If the counter is already at or above `0x0a`, looks up localized language id `157` and exits through `PatchPane2::FinishAndExit` at `0x00548f80`.
