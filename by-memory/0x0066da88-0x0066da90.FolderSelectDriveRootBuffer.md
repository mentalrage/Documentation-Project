# 0x0066da88-0x0066da90 FolderSelect Drive Root Buffer

## Summary

- Address range: `0x0066da88-0x0066da90`
- Entity kind: initialized mutable wide-character buffer
- Disposition: reconstructable project data

This eight-byte buffer stores a temporary wide drive root string for folder selection. The initial bytes decode as `X:\\` plus terminator, and the constructor/helper rewrites the drive letter before probing available drives.
