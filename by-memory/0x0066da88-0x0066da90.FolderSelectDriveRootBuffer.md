- IDA xrefs to `asc_66DA88` are `0x004b183f`, `0x004b185b`, `0x004b1a8b`, and `0x004b1aaa`.
- At `0x004b183f`, the code writes the current drive letter into the first UTF-16 code unit before passing the buffer to folder/path helper calls.
- The active byte sequence is `58 00 3A 00 5C 00 00 00`, i.e. wide `X:\\`.
- 2026-06-03 IDA MCP xrefs rechecked `0x0066da88`: constructor references occur at `0x004b183f` and `0x004b185b`, and drive-list helper references occur at `0x004b1a8b` and `0x004b1aaa`.
- 2026-06-03 IDA MCP decompilation of `0x004b1a00` shows `asc_66DA88[0] = v2 + 65` for each available drive, followed by list-entry creation from that buffer and current-drive selection.
- 2026-06-10 A001 IDA MCP `xrefs_to 0x0066da88` reconfirms all four data xrefs: two inside `sub_4B1590` (`0x004b1590-0x004b18d6`) and two inside `sub_4B1A00` (`0x004b1a00-0x004b1b05`).
- 2026-06-10 decompilation of `0x004b1590` confirms the constructor gets logical drives, reads the current directory into a `0x104`-byte buffer, 260 decimal bytes (Verified with `int_convert.py`), loops over `0x20` drive slots, 32 decimal slots (Verified with `int_convert.py`), writes `asc_66DA88[0] = driveIndex + 0x41` where `0x41` is 65 decimal / `A` (Verified with `int_convert.py`), creates a list item from `asc_66DA88`, appends it to the drive list, and selects the current drive.
- 2026-06-10 decompilation of `0x004b1a00` confirms the standalone drive-list helper repeats the same `GetLogicalDrives` / `GetCurrentDirectoryA` / `asc_66DA88[0] = driveIndex + 0x41` / list-item creation sequence.
- 2026-06-10 disassembly distinguishes the write and read sites: `0x004b183f` and `0x004b1a8b` write `word ptr asc_66DA88, ax`; `0x004b185b` and `0x004b1aaa` push `offset asc_66DA88` into the list-entry constructor after allocating `0x118` bytes, 280 decimal bytes (Verified with `int_convert.py`).
- Neighboring bytes remain clean boundaries for this exact data item: the preceding `0x0066da80-0x0066da88` bytes are all zero, and the successor item begins at `0x0066da90` with `01 00 00 00 00 04 01 01`.
