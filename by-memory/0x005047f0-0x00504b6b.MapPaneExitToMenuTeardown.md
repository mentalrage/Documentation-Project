This method performs the client-side exit from an active map/session back toward the menu stack. It clears the application input/session byte at [UID:000294][0x0067ab1c-0x0067ab20.g_pApplication](by-memory/0x0067ab1c-0x0067ab20.g_pApplication.md), tears down map-owned child panes, saves the compressed map cache through [UID:0002QK][0x00504e00-0x00505075.MapPaneSaveCompressedMapFile](by-memory/0x00504e00-0x00505075.MapPaneSaveCompressedMapFile.md), disables ScreenPane presentation mode through [UID:00039S][0x00557820-0x00557838.ScreenPanePresentationModeFlagSetters](by-memory/0x00557820-0x00557838.ScreenPanePresentationModeFlagSetters.md) `ScreenPane::DisablePresentationMode()`, persists user settings through [UID:0001AV][0x0050aba0-0x0050b078.SaveUserSettings](by-memory/0x0050aba0-0x0050b078.SaveUserSettings.md), removes the gameplay UI singleton panes, optionally sends a one-byte `0x0b` session packet, drains the packet sender, and constructs the replacement main-menu pane.
