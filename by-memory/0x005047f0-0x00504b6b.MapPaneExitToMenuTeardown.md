## Behavior

This method performs the client-side exit from an active map/session back toward the menu stack. It clears the application input/session byte at [UID:000294][0x0067ab1c-0x0067ab20.g_pApplication](by-memory/0x0067ab1c-0x0067ab20.g_pApplication.md), tears down map-owned child panes, saves the compressed map cache through [UID:0002QK][0x00504e00-0x00505075.MapPaneSaveCompressedMapFile](by-memory/0x00504e00-0x00505075.MapPaneSaveCompressedMapFile.md), persists user settings through [UID:0001AV][0x0050aba0-0x0050b078.SaveUserSettings](by-memory/0x0050aba0-0x0050b078.SaveUserSettings.md), removes the gameplay UI singleton panes, optionally sends a one-byte `0x0b` session packet, drains the packet sender, and constructs the replacement main-menu pane.

The routine is mode-sensitive. The [UID:0000SW][g_useEpfAssets](by-global/g_useEpfAssets.md) flag selects the old and newer gameplay UI teardown paths so it removes the matching chat, status, menu, icon, connection-status, and message panes without touching inactive-mode-only panes.

- Removes or destroys active gameplay UI singleton panes according to the `g_useEpfAssets` mode path.
- Stops or resets [UID:0000RM][g_pMidiPlayer](by-global/g_pMidiPlayer.md) if it is present.

- Locks the packet sender, waits for the sender/request helper to drain, allocates `0x454` bytes for the replacement menu pane, constructs the main-menu/login/account pane set, then unlocks the packet sender.
