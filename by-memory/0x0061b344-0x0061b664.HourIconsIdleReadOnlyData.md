# 0x0061b344-0x0061b664 Hour/Icons/Idle Read-Only Data

## Range

- Address range: `0x0061b344-0x0061b664`
- Entity kind: `vtable/string-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: `source-declared/generated-binary`

## Summary

This `.rdata` span contains `HierList`, `HourPane`, `IconsPane`, `TabPane`, and `IdleWatcher` vtables plus time/icon resource strings, a small trailing word table, and the `ImageLib` RTTI/vtable tail immediately before the `MapTileImageLib` boundary. It replaces a UI-owned slice of the old broad UNKNOWN range.

## Observed Contents

- `HierList` vtable at `0x0061b344`.
- `HourPane` vtables and resource strings such as `%s%02d`, `TIME.EPF`, `TIME.PAL`, and `TIME.EPD`.
- `IconsPane` and `TabPane` vtables plus icon resource data.
- `IdleWatcher` vtables and word/off-table labels followed by the `ImageLib` RTTI/vtable at `0x0061b650-0x0061b660`.

## Evidence

- IDA MCP `py_eval` on 2026-05-28 reports 26 named items in this range.
- Representative xrefs include `sub_4CE730`, `sub_4CEE60`, `sub_4CF190`, `sub_4CF1F0`, `sub_4CF980`, and `sub_4CFE60`, matching the existing hour/icons/tab/idle watcher code clusters.
- The next named item at `0x0061b664` is `??_7MapTileImageLib@@6B@`.

## ImageLib Tail Recheck

Live IDA MCP on 2026-05-31 verified that the final 20 bytes of this range are an `ImageLib` RTTI/vtable island, not `IdleWatcher` data:

- `0x0061b650`: RTTI locator dword `0x006486d4` -> `??_R4ImageLib@@6B@`.
- `0x0061b654`: `ImageLib` vtable slot dword `0x004e64a0` -> scalar deleting destructor, with xrefs from `0x004d0009`, `0x004d009a`, and `0x004e64d1`.
- `0x0061b658`: inherited/shared slot dword `0x004f4b10`.
- `0x0061b65c`: null slot dword `0x0041b6c0` -> `nullsub_18`.
- `0x0061b660`: next RTTI locator dword `0x00648774` -> `??_R4MapTileImageLib@@6B@`.
- `0x0061b664`: next named item `??_7MapTileImageLib@@6B@`, outside this page's exclusive end.

This tail is tracked by [UID:0001XR][ImageLibVtable](by-type/by-vtable/ImageLibVtable.md). The broader page name still reflects the dominant UI/string contents in the range, but the rebuild handling should include the source-declared `ImageLib` vtable semantics.
