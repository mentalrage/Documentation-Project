## Behavior

This is the MMX four-pixel/block path for RGB565 transparent-shadow blits. The caller passes source pointer, source pitch, destination pointer, destination pitch, a four-pixel block count, and row count; the helper multiplies the block count by eight bytes and processes each row in qword chunks before advancing by the row pitches.

Source pixel value `0` preserves the destination lane, source pixel value `1` writes a half-bright destination shadow using mask `0xf7def7def7def7de`, and all other source pixels replace the destination. The scalar tail in the sole caller at `0x00460370` uses the same transparent/shadow/copy semantics with the word mask `0x7bef`.
