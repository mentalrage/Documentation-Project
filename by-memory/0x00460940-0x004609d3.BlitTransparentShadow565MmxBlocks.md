# 0x00460940-0x004609d3 Blit Transparent Shadow RGB565 MMX Blocks

## Status

- Disposition: reconstructable NexusTK render support code.
- Entity kind: free render helper.
- Likely source file: [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) `SoftwareBlend16`.
- Confidence: strong for boundary, caller, and behavior.
- Rebuild handling: `source-authored`.

## Address Range

`0x00460940-0x004609d3`.

The following `0x004609d3-0x004609e0` bytes are alignment padding.

## Behavior

This is the MMX four-pixel/block path for RGB565 transparent-shadow blits. Source pixel value `0` preserves the destination, source pixel value `1` writes a half-bright destination shadow using mask `0xf7def7def7def7de`, and all other source pixels replace the destination.

## Evidence

- IDA MCP `lookup_funcs`/`py_eval` reports function `sub_460940` at `0x00460940-0x004609d3`.
- IDA `XrefsTo(0x00460940)` reports a direct call from `0x00460399`, inside the RGB565 transparent-shadow helper documented in [UID:0000YD][0x0045fa00-0x004604f4.Rgb555565BlitHelpers](by-memory/0x0045fa00-0x004604f4.Rgb555565BlitHelpers.md).
- IDA decompilation shows MMX compares against zero and `0x0001`, half-brightens the destination for the sentinel, preserves destination for transparent pixels, and writes the combined block.
