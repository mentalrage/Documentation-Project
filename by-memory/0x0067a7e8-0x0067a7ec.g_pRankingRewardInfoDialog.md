# 0x0067a7e8-0x0067a7ec g_pRankingRewardInfoDialog

## Summary

- Address range: `0x0067a7e8-0x0067a7ec`
- Entity kind: global pointer
- Proposed name: `g_pRankingRewardInfoDialog`
