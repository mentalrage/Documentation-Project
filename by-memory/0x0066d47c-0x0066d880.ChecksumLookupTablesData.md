## Helper Use

- `0x0049bbf0-0x0049bc0c` updates a 16-bit accumulator from a word argument, using `(acc >> 8)` as the `word_66D480` index.
- `0x0049bc10-0x0049bc46` iterates a word buffer, repeatedly indexing `word_66D480` with the accumulator high byte and folding each input word.
- `0x0049bc50-0x0049bc6f` updates a 16-bit accumulator from a byte argument, using the same high-byte index into `word_66D680`.
- `0x0049bc70-0x0049bca8` iterates a byte buffer, indexing `word_66D680` and folding each input byte into the accumulator.
