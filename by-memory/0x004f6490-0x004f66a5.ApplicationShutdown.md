# 0x004f6490-0x004f66a5 Application Shutdown

## Scope

- Range: `0x004f6490-0x004f66a5`
- Entity kind: class method
- Owner: [UID:00000D][Application](by-class/Application.md)
- Parent aggregate: [UID:00019H][0x004f5f20-0x004f66fb.BaramAppAndApplicationStartup](by-memory/0x004f5f20-0x004f66fb.BaramAppAndApplicationStartup.md)
- Disposition: reconstructable project code.

## Behavior

Performs the second-stage application shutdown path, tearing down tracked map objects, UI/render managers, image-library singleton objects, input/network/sound/config state, and other manager globals.

The method begins by setting [UID:00028Z][0x0067a938-0x0067a940.ApplicationLifecycleFlags](by-memory/0x0067a938-0x0067a940.ApplicationLifecycleFlags.md) to phase `4`, then performs the outer shutdown pass for objects that were built during [UID:0002H7][0x004f5fb0-0x004f6490.ApplicationStartup](by-memory/0x004f5fb0-0x004f6490.ApplicationStartup.md): event/UI singletons, main UI layer/context slots, image-library singletons, the keyboard/input companion state, text-filter/chat globals, and a final tail jump into [UID:0002H1][0x00464a60-0x00464cc1.ApplicationCleanupResources](by-memory/0x00464a60-0x00464cc1.ApplicationCleanupResources.md).

The main UI slot teardown mirrors startup: if [UID:0001OX][0x0067a7cc-0x0067a7d0.g_pScreenPane](by-memory/0x0067a7cc-0x0067a7d0.g_pScreenPane.md) is present, each slot is first detached through helper `0x00556d20`; then the six slot objects are destroyed with deleting flag `1` and the globals are cleared where the shutdown body owns the clear.
