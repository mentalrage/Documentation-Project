## Behavior

The method scans the UTF-16 name buffer near object offset `+0x126`, computes the pointer to the final two wide characters before the terminator, and returns whether those characters compare equal to `L"GM"` through `_wcsicmp`.

The only direct code xref found in this pass is from `0x0050a552` inside a `MapPane` update/render helper. The caller uses this check when deciding whether a living-object visual/effect state should be cleared.

The caller relationship is consumer evidence only. `MapPane` asks an actor whether its visible name ends with the staff/GM suffix, but the accessed buffer and the owning class/file docs place the helper with `LivingObjectPane`.

The 2026-06-05 A003 live IDA refresh confirms the exact implementation shape:

- `ecx` is the `LivingObjectPane` receiver.
- The loop starts at `this + 0x12a`, advances by two bytes, and stops at the UTF-16 terminator.
- The comparison pointer is computed from base `this + 0x126`, which selects the last two UTF-16 code units before the terminator.
- The only callee is `__wcsicmp`, called with IDA string literal `aGm` / `L"GM"`.
- The method returns `setz al`, so the result is true only when `_wcsicmp` returns zero.
