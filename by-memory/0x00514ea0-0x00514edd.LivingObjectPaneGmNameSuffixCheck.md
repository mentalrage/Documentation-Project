## Behavior

The method scans the actor-owned UTF-16 name buffer, computes the pointer to the final two UTF-16 code units before the terminator, and returns whether those two code units compare equal to `L"GM"` through `_wcsicmp`.

The binary assumes the name string is long enough for this suffix test. Do not add a short-name guard, null receiver check, alternate case fold, or separate global constant in the reconstruction; those would change the observed source shape. The accepted source-shaped body is:

```cpp
bool LivingObjectPane::HasGMNameSuffix() const
{
    const wchar_t *end = m_nameBuffer + 2;
    while (*end != L'\0')
        ++end;

    return _wcsicmp(end - 2, L"GM") == 0;
}
```

`HasGMNameSuffix()` is the best current source-facing name because the routine is a boolean suffix predicate, not a full staff/GM authorization state. `IsGM()` and `IsGameMaster()` were rejected as overbroad because the code only compares the final two wide name characters. `m_nameBuffer` is the best current field direction for the actor-owned UTF-16 buffer at `this+0x126`; exact original member spelling remains unresolved.
