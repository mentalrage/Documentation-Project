## Behavior

The helper destroys a sentinel-owned intrusive list state passed in `ecx`:

- reads the first live node from `state->sentinel->next`;
- resets `sentinel->next` and `sentinel->prev` to the sentinel itself;
- sets `state->count` to zero;
- walks the old live-node chain, freeing each node as a 16-byte block through `sub_5C7526`;
- frees the sentinel node as the final 16-byte block.

Likely state layout:

```cpp
struct LinkedListState {
    ListNode* sentinel; // +0x00
    int count;          // +0x04
};
```
