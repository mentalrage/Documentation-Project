## Reconstruction Notes

Declare this singleton with [UID:0000IW][DirectX](by-file/DirectX.md). Font measurement and UI text paths that load `0x0067ab24` belong to `g_pFontImageLib`, not this slot.

Assignment decision: attach this exact memory slot to [UID:0000QS][g_pDirectX](by-global/g_pDirectX.md). The child is now `86/88`, the direct global parent is `88/86`, and the by-structure rules place process-wide singleton pointers in `by-global`. Do not attach this memory page directly to [UID:0000IW][DirectX](by-file/DirectX.md) or [UID:00003Y][DirectX](by-class/DirectX.md), which are both currently below the 85 completion gate.
