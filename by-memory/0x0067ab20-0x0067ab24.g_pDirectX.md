# 0x0067ab20-0x0067ab24 g_pDirectX

## Summary

- Address range: `0x0067ab20-0x0067ab24`
- Entity kind: global pointer
- Proposed name: `g_pDirectX`
- Disposition: reconstructable NexusTK global data
- Confidence: strong for address, owner class, and singleton role

This four-byte `.data` slot stores the active `DirectX` singleton pointer used by DirectDraw setup, surface management, and presentation helpers.

## Evidence

- `DirectX::DirectX` at `0x004a1b60` writes `dword_67AB20`.
- `DirectX::~DirectX`, the constructor-unwind clear helper at `0x004a1cc0`, and the scalar-deleting destructor clear the slot.
- IDA MCP reports 19 direct xrefs to `0x0067ab20`, including DirectX lifetime code and render/surface consumers.
- Existing docs identify this address as [UID:0000QS][g_pDirectX](by-global/g_pDirectX.md) and warn about adjacent [UID:0000QX][g_pFontImageLib](by-global/g_pFontImageLib.md) alias confusion at `0x0067ab24`.
