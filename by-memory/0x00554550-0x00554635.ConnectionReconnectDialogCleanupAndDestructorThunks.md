## Behavior

The two tiny bodies are out-of-line compiler instantiations of direct Singleton base destructors used only by constructor unwind actions. They are not startup/static cleanup functions, public/private class methods, or handwritten `Clear...Singleton` helpers. The four 11-byte entries are `this`-adjusting vtable thunks that tail-call the scalar deleting wrappers. The two scalar wrappers inline the same Singleton-base clear, invoke lower-base destruction, and honor the MSVC delete flag.

IDA's misleading `boost::exception::~exception`-shaped lower-base name is retained as historical tool provenance only. The surrounding class vtables, complete-object adjustments, global clears, wrapper refs, and allocation sizes identify this as dialog destructor ABI support, not Boost source.
