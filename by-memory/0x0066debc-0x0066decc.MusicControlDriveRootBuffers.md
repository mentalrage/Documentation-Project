# 0x0066debc-0x0066decc Music Control Drive Root Buffers

## Summary

- Address range: `0x0066debc-0x0066decc`
- Entity kind: mutable drive-root buffers
- Disposition: reconstructable project data
- Rebuild handling: `source-declared static buffers`
- Owner/emitter: [UID:0000LN][MusicControlDialog](by-file/MusicControlDialog.md)

This range contains the small `X:\\` and `X:` drive-root buffers used by `MusicControlDialog` when enumerating CD drives and populating the drive-selection control. The active references are confined to the constructor drive enumeration and the drive popup refresh helper, both inside the documented [UID:0001CP][0x00528e60-0x0052a535.MusicControlDialog](by-memory/0x00528e60-0x0052a535.MusicControlDialog.md) island.
