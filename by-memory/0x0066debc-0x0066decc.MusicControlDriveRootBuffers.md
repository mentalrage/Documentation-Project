# 0x0066debc-0x0066decc Music Control Drive Root Buffers

## Summary

- Address range: `0x0066debc-0x0066decc`
- Entity kind: mutable drive-root buffers
- Disposition: reconstructable project data
- Rebuild handling: `source-declared static buffers`
- Autogen parent: [UID:0000LN][MusicControlDialog](by-file/MusicControlDialog.md)
- Confidence: strong for `MusicControlDialog` ownership and buffer use; medium for the unreferenced trailing dword

This range contains the small `X:\\` and `X:` drive-root buffers used by `MusicControlDialog` when enumerating CD drives and populating the drive-selection control. The active references are confined to the constructor drive enumeration and the drive popup refresh helper, both inside the documented [UID:0001CP][0x00528e60-0x0052a535.MusicControlDialog](by-memory/0x00528e60-0x0052a535.MusicControlDialog.md) island.

## Layout

| Range | Initial bytes | Notes |
| --- | --- | --- |
| `0x0066debc-0x0066dec0` | `58 3a 5c 00` | ANSI root path buffer initialized to `X:\\`; the drive letter byte is rewritten before each `GetDriveTypeA` probe. |
| `0x0066dec0-0x0066dec8` | `58 00 3a 00 00 00 00 00` | UTF-16 `L"X:"` buffer plus an extra null word; the drive letter word is rewritten before the value is wrapped and inserted into the drive-selection control. |
| `0x0066dec8-0x0066decc` | `50 00 00 00` | Adjacent initialized dword with no direct refs in the current IDA pass; keep as a boundary tail before [UID:00027W][0x0066decc-0x0066dee0.LivingObjectPaneWordSlots_66DECC](by-memory/0x0066decc-0x0066dee0.LivingObjectPaneWordSlots_66DECC.md). |

## Evidence

- 2026-06-06 IDA MCP `decompile` for the constructor shows an `A` through `Z` loop that rewrites the ANSI root-path byte, calls `GetDriveTypeA`, and for CD-ROM drives rewrites the UTF-16 drive-label word before allocating a menu/control string and inserting it into control id `8`.
- 2026-06-06 IDA MCP `decompile` for the drive popup refresh helper shows the same `A` through `Z` loop and inserts the same UTF-16 drive labels into control id `8`, then appends a blank entry.
- 2026-06-06 IDA MCP `xrefs_to` reports the ANSI root buffer references at `0x00529304` and `0x00529309` in the constructor, plus `0x0052a061` and `0x0052a066` in the drive popup refresh helper.
- 2026-06-06 IDA MCP `xrefs_to` reports the UTF-16 label-buffer references at `0x0052931f`, `0x00529339`, `0x0052a078`, and `0x0052a095`.
- 2026-06-06 IDA MCP byte inspection confirms `0x0066debc-0x0066decc` as `58 3a 5c 00 58 00 3a 00 00 00 00 00 50 00 00 00`, with no direct refs to the `0x0066dec8-0x0066decc` tail.
- Boundary checks place [UID:00027U][0x0066deb0-0x0066debc.MonsterImageLibDefaultFrameRecord](by-memory/0x0066deb0-0x0066debc.MonsterImageLibDefaultFrameRecord.md) immediately before this range and [UID:00027W][0x0066decc-0x0066dee0.LivingObjectPaneWordSlots_66DECC](by-memory/0x0066decc-0x0066dee0.LivingObjectPaneWordSlots_66DECC.md) immediately after it.
