## Behavior

This raw island contains three slot-geometry helpers that IDA did not model as separate functions:

| Range | Current interpretation | Notes |
| --- | --- | --- |
| `0x00420950-0x00420a10` | slot icon/source rectangle helper | Switches on a small signed slot/category value and writes one of several fixed rectangles through the generic `SetRectLTRB` helper. |
| `0x00420a10-0x00420a8a` | slot bounds by index/mode | Computes a row/list-mode rectangle or a six-column grid rectangle for a given slot index, returning `-1` bounds for invalid slots. |
| `0x00420a90-0x00420b60` | hit-test across special slot rectangles | Iterates a small set of switch-derived rectangles and calls point-in-rect helper `0x004b7e80`; returns the matching slot index or `-1`. The final dword at `0x00420b5c` is part of the helper's jump table, not padding. |

These helpers belong with [UID:0002DP][0x00420b60-0x00420cf9.FittingRoomListPaneHitTestSlot](by-memory/0x00420b60-0x00420cf9.FittingRoomListPaneHitTestSlot.md) and [UID:0002DN][0x0041fcd0-0x004207ce.FittingRoomListPaneOnInputEvent](by-memory/0x0041fcd0-0x004207ce.FittingRoomListPaneOnInputEvent.md), not with a generic UI module.

## Raw Code Evidence

- IDA MCP function inventory has no function objects for starts `0x00420950`, `0x00420a10`, or `0x00420a90`, but byte/disassembly review shows normal x86 prologues and `retn 8` exits.
- `0x00420950` begins `push ebp; mov ebp, esp; movsx eax, word ptr [ebp+8]; inc eax; ... jmp ds:jpt_42095E[eax*4]`, then calls `0x004b7c50` with fixed rectangle constants.
- `0x00420a10` computes list-mode row rectangles using `slot * 20 + 16` and grid-mode cell rectangles using `slot / 6`, `slot % 6`, `0x60` horizontal stride, and `0x70` vertical stride.
- `0x00420a90` is security-cookie protected, loops candidate slots, generates a rectangle, calls `0x004b7e80`, and returns the matched `short` slot or `-1`; its jump-table data runs through `0x00420b60`.
- A 7-byte `0xcc` padding run at `0x00420949-0x00420950` separates this island from [UID:0002DS][0x00420840-0x00420949.FittingRoomListPaneOnScrollStep](by-memory/0x00420840-0x00420949.FittingRoomListPaneOnScrollStep.md).
