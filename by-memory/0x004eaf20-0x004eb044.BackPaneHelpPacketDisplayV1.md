## Behavior

This helper decodes a packet-backed help text:

- reads a masked position/id field from packet bytes `+1`;
- reads the text byte length from packet bytes `+3`;
- rejects empty or overlarge text lengths;
- converts up to 1023 bytes to UTF-16;
- gets the current BackPane/root bounds through [UID:000161][0x004b8e00-0x004b8e11.BackPaneGetBounds](by-memory/0x004b8e00-0x004b8e11.BackPaneGetBounds.md);
- closes an existing help popup singleton at `dword_69AE00` if present;
- allocates a 252-byte popup/help pane and positions it around the horizontal center of the BackPane bounds.
