## Behavior

`EndPaint` closes the active drawing access opened by `UpdateSurfaceInfo`. For DirectDraw-backed ports it calls `m_ddSurface->Unlock(NULL)`. It then clears the active row stride and pixel pointer fields so stale lock or software-buffer state is not reused after paint completion.
