## Exact Behavior

The method performs one scalar read, not a bulk-entry or container read:

1. Calls virtual `GetSize()` and logically shifts the unsigned result right by one to obtain the validation key.
2. Calls virtual `Read()` for exactly eight bytes into a local stack buffer.
3. Passes the mutable bytes, validation key, and caller-provided integer storage to `DecodeTableValue`.
4. Returns the decoder's full-register integer result directly: `1` for a validated value or `0` for failure.

The wrapper does not initialize `outValue`, inspect `Read`'s return value, allocate memory, retain the local bytes, or convert the decoded bit pattern. On decoder failure, `outValue` remains untouched while the local eight-byte buffer has still been decoded in place and then goes out of scope.
