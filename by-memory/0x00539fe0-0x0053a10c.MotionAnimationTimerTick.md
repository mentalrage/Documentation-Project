## Behavior

When invoked with the normal timer path, this method advances the packed current-frame byte unless the owner/object state near offset `+465` suppresses the last two frames. When the current frame reaches the trigger frame and a sound/effect id is present, it plays through the global sound manager using the helper chain at `0x0057a6c0` and `0x0057a5c0`.

If animation frames remain, it schedules the embedded timer handler through the global timer manager and updates the owner object's active-motion pointer at offset `+448`. If the animation has completed, it removes the Motion object from the owner's list at offset `+444`, clears the active pointer, and queues the object for deferred cleanup through `0x00469120`.

The method invalidates/refreshes the associated map/object state through `0x00506980` before returning success.
