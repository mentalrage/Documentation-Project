## Ownership Decision

This range is central `MapPane` gameplay code. It should not be split into generic UI files, although some render helper names still need refinement.

[UID:0000MK][PhotoPane](by-file/PhotoPane.md) is a packet/UI-created map companion, not part of this `MapPane` core range. Keep the constructor call here as ownership evidence while migrating the photo/viewer implementation under its own module.

Mark this aggregate reconstructable because it is NexusTK-owned MapPane source. Do not attach the aggregate to [UID:0000L3][MapPane](by-file/MapPane.md) yet and do not emit C++: the range still needs more exact child pages for the packet dispatcher, mouse handler, notify handler, render path, paint path, interaction helpers, and tile/object-grid helpers before the aggregate has final-source-quality structure.
