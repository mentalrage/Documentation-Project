## Behavior

This function handles server exchange packets. IDA MCP confirms it as a real function at `0x004ad320` with size `0x493`, giving code-body range `0x004ad320-0x004ad7b3`.

The handler reads the packet payload pointer from the incoming event object at `event+0x0c`, rejects packets whose opcode byte is not `0x42`, then dispatches on the subcommand byte. Invalid opcode returns `0`; opcode `0x42` returns `1` for recognized subcommands and for the default subcommand case.

| Subcommand | Observed behavior |
| --- | --- |
| `1` | Reads `packet+2`, allocates `0x274` bytes, and constructs an `AddItemWithCountDialog`-style picker through `0x004af040` using exchange id `this+0x1cc`. |
| `2` | Updates one offered-item list row. The packet supplies side, row key, item id, color, and a counted multibyte item name; the handler converts the name to wide text, selects control `5` or `8`, removes an existing row with the same key, and inserts the updated row record. |
| `3` | Updates the local or remote money display. The side byte selects control `6` or `9`; a zero local amount also calls [UID:00014K][0x004ac8a0-0x004ae4b6.ExchangeDialog](by-memory/0x004ac8a0-0x004ae4b6.ExchangeDialog.md)'s amount setter at `0x004ada20` with zero. |
| `4` | Decodes cancellation/termination alert text, closes any active [UID:0000QV][g_pExchangeAlertPane](by-global/g_pExchangeAlertPane.md), constructs a new exchange alert through [UID:00014V][0x004b0490-0x004b0ba5.ExchangeDialogTail](by-memory/0x004b0490-0x004b0ba5.ExchangeDialogTail.md), closes the exchange dialog, and closes active add-item dialog state if present. |
| `5` | Updates ready/confirm flags at `this-0xa0+0x270..0x272`, refreshes button state when both sides are not ready, and may decode an alert message, close an active exchange alert, construct a new alert, and close the exchange dialog. |
