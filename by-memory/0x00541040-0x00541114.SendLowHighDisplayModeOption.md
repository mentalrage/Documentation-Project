## Behavior

Applies the low/high display mode byte and sends the incremental option packet required by the server when persisted option bytes change. The helper:

- stores the requested low/high graphics/display byte to config offsets `0x28de58`, `0x28de5e`, and `0x28de5c`, with `+0x28de5e` also documented as the registry/UI `Shadow` mirror byte;
- calls `0x005040a0(dword_67A764)` when the requested mode is zero;
- compares config offsets `0x28de72` and `0x28de73` against the requested byte;
- returns without sending if both comparison bytes already match;
- otherwise builds a packet beginning with byte `0x1b`, appends subcommand bytes based on which comparison bytes differ, terminates the local buffer with zero, and sends through `0x00574bb0(dword_67A7EC, packet, length)`.
