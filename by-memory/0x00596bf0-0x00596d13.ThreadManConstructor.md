# 0x00596bf0-0x00596d13 ThreadMan Constructor

## Behavior

`ThreadMan::ThreadMan` constructs the `LObject` base, publishes [UID:0000SH][g_pThreadMan](by-global/g_pThreadMan.md), installs the `ThreadMan` vtable, checks debugger presence, allocates the watchdog list, and starts the manager worker thread.

Key field writes:

| Offset | Meaning |
| --- | --- |
| `0x04` | debugger-present flag |
| `0x08` | worker thread handle |
| `0x0c` | worker thread id |
| `0x10` | [UID:0001WB][ThreadManWatchRecord](by-type/by-struct/ThreadManWatchRecord.md) list |

The watch list is a [UID:000079][List](by-class/List.md) with 20-byte records and initial capacity `16`. The worker thread entry is [UID:0001K3][0x00597100-0x005971ad.ThreadManWorkerEntry](by-memory/0x00597100-0x005971ad.ThreadManWorkerEntry.md). If `CreateThread` fails, the constructor throws a `Win32Error` object.
