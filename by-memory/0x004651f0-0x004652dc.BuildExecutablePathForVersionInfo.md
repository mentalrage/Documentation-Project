# 0x004651f0-0x004652dc Build Executable Path For Version Info

## Scope

- Range: `0x004651f0-0x004652dc`
- Entity kind: file-local helper function
- Likely owner file: [UID:0000HG][Application](by-file/Application.md)
- Parent aggregate: [UID:0000YR][0x00463310-0x004679be.ApplicationLifecycle](by-memory/0x00463310-0x004679be.ApplicationLifecycle.md)
- Disposition: reconstructable project code.

## Behavior

Builds the executable path used by version-info readers.

Observed flow:

- copies `GetCommandLineW()` into a local `0x104`-wide-character buffer;
- if the command line starts with a quoted executable path, it scans for the closing quote; otherwise it scans to the first space;
- removes quote characters while copying into the caller-supplied destination;
- compares the last four wide characters against `.exe`;
- appends `.exe` with `wcscat_s` when the suffix is missing.
