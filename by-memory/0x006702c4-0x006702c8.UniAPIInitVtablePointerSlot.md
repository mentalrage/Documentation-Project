# 0x006702c4-0x006702c8 UniAPIInit Vtable Pointer Slot

## Summary

- Address range: `0x006702c4-0x006702c8`
- Entity kind: initialized vtable pointer slot
- Disposition: reconstructable generated-binary data
- Rebuild handling: compiler-emitted/static object vptr state
