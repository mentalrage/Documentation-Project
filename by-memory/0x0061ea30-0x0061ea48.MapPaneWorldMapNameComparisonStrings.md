# 0x0061ea30-0x0061ea48 MapPane World-Map Name Comparison Strings

## Range

- Entity kind: UTF-16 string literals.
- Decoded payloads: `wm`, `WM`, and `wm2`.
- Rebuild handling: `source-declared/generated-binary`
- Parent: [UID:0000L3][MapPane](by-file/MapPane.md)

## Summary

This exact child contains the MapPane-side lowercase/uppercase world-map name comparisons for `wm`, `WM`, and `wm2`. It was split out of [UID:0003IX][0x0061ea24-0x0061ea70.MapWorldPaletteResourceStrings](by-memory/0x0061ea24-0x0061ea70.MapWorldPaletteResourceStrings.md) because these three strings are used only by MapPane helper `sub_511DB0` in the current IDB, while adjacent `.PAL` and `WM2` have material WorldMapPane refs.

## Evidence

- IDA MCP `get_bytes` on 2026-06-12 C001 reports the exact UTF-16 sequence `wm`, `WM`, and `wm2` over `0x0061ea30-0x0061ea48`.
- IDA MCP `get_string` decodes `0x0061ea30` as `wm`, `0x0061ea38` as `WM`, and `0x0061ea40` as `wm2`.
- IDA MCP `xrefs_to` reports one direct ref for each string: `0x005121a1`, `0x005121e3`, and `0x00512223`, all inside `sub_511DB0`.
- IDA MCP `insn_query` over `0x00512180-0x00512380` shows `sub_511DB0` loading these literals with `mov ecx, offset aWm`, `mov ecx, offset aWm_0`, and `mov ecx, offset aWm2`, then comparing them against the local `WideCharStr`.
