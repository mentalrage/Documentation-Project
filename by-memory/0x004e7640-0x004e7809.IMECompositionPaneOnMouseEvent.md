{
    switch (event->type) {

            TranslateRectBounds(&dragBounds, 0, event->mouseY - compositionDragStartY);
            SetBounds(&dragBounds, 0);

            g_pIMEPane->focusCaretAnchorX = dragBounds.left;
            g_pIMEPane->focusCaretAnchorY = dragBounds.top;

        g_pIMEPane->focusCaretAnchorX = m_origin.x;

## Behavior

This method handles composition popup mouse/event behavior inside the pane-side IME UI. Event type `0` is the cursor/mouse-move case: while `compositionDragActive` is true, the method fetches the current bounds, translates them by the delta from the drag-start mouse coordinates, commits the new bounds, then updates `g_pIMEPane->focusCaretAnchorX/Y` from the moved rectangle left/top. Event type `1` is the left-button down case: if not already dragging and `PointInRect(event->mouseY, event->mouseX, &m_bounds)` succeeds, it starts dragging, records `compositionDragStartY`, `compositionDragStartX`, and `compositionDragSavedMode`, then temporarily changes Pane mode `2 -> 0` or `3 -> 1`. Event type `3` is the left-button up case: while dragging, it writes root focus anchors from inherited `m_origin`, restores the saved Pane mode with `Pane::SetMode`, clears `compositionDragActive`, and returns true. Other events return false.
