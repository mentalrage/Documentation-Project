## Behavior

This primary virtual paints the ranking-event scrollbar. It renders the track before and after the thumb with `SLIDEBG.EPF` / `SLIDEBG.PAL`, then renders the thumb/button with `SCRBUTT.EPF` / `BUTTON.PAL`.

The method:

- initializes a local EPF/tile context;
- obtains the pane clipping rectangle;
- exits or invalidates the whole clip when the scrollbar is not enabled or has no scrollable range;
- computes track segment rectangles for parts `1` and `3` through `0x0045a710`;
- intersects each segment with the clip rectangle before drawing;
- toggles pane draw/color state around invalidation and drawing calls;
- draws vertical and horizontal track variants with different EPF frame indexes;
- computes the thumb rectangle for part `2` and draws `SCRBUTT.EPF` frame `0` or `1` depending on whether part `2` is pressed.

This is source-authored UI rendering, not compiler glue. It should move with the private ranking dialog controls.
