- IDA MCP disassembly on 2026-05-27 shows the child-window message handler tail at `0x0046cfd0`, with `jpt_46CFDA` at `0x0046cfe4`, `byte_46CFEC` at `0x0046cfec-0x0046d04d`, and alignment padding through the next function start at `0x0046d050`.
