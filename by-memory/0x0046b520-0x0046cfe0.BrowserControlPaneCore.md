### Dispatch And WndProc Semantics

`BrowserControlPane::Invoke` handles the [UID:0001SJ][BrowserDispatchEventId](by-type/by-enum/BrowserDispatchEventId.md) family:

- `104`: no-op, returns `S_OK`.
- `250`: `BeforeNavigate2`-like event. Reads the URL from the event argument VARIANT; cancels internal `javascript:close();`, close-style, `res://`, and disallowed `http://` URLs when `m_allowedUrlPrefix` is configured.
- `251`: navigate-complete-like gate. If `m_cancelNavigateComplete` is nonzero, returns without cancellation; otherwise falls through to the `270` cancel path.
- `252`: stores the first top-level dispatch cookie/token.

- `263`: new-window-like event. Writes cancel `0`, calls `sub_49df20(g_activeBrowserPane)`, and returns `S_OK`.
- `270`: window-closing-like event; writes cancel `1`.
- Default: writes `0` to `g_pScreenPane/dword_67A7CC + 0x5b2`, calls vtable slot `+0x20` on the screen pane, and returns `DISP_E_MEMBERNOTFOUND` (`0x80020003`).
