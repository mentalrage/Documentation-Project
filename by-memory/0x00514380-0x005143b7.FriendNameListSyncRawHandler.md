## Behavior

This raw body duplicates the same friend/name-list sync handling seen in [UID:0000L3][MapPane](by-file/MapPane.md) case `0x6a`. It is not the currently proven live route.

1. Initialize a local cursor to `1`.
2. Read one byte from the packet buffer with `0x00575710`.
3. Store [UID:0000PG][byte_66DEE0](by-global/byte_66DEE0.md) to `readByte != 0`.
4. If the byte is nonzero, call [UID:0001HX][0x00574e50-0x0057536b.BuildAndSendInventoryData](by-memory/0x00574e50-0x0057536b.BuildAndSendInventoryData.md) through [UID:0000Q5][g_packetSender](by-global/g_packetSender.md).
5. Return success.
