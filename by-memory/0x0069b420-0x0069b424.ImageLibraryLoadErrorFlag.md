This four-byte `.data` slot is anchored by the first byte at `0x0069b420`. Live IDA shows that loaders preserve any prior nonzero state and set the byte when table/resource reads fail or return an unexpected field count. Renderers and draw helpers test the same byte and skip drawing while it is nonzero. The trailing three bytes are initialized, have no direct refs, and remain documented here as reserved/alignment bytes in the same source-level flag slot.
