## Function Summary

`0x004e9ee0` is an `InterfaceEfxMgr` trigger helper used by [UID:0000JQ][GeneralPurposePanel](by-file/GeneralPurposePanel.md). It checks the client interface-effect option flag at `g_clientStateBase + 2678366`; when the flag is enabled, it dispatches an input effect id to one of the persistent [UID:00006N][InterfaceEfx](by-class/InterfaceEfx.md) instances owned by the manager and calls `InterfaceEfx::Play` at `0x004e9950`.

Unhandled ids return without playing an effect. If the client option flag is disabled, the function also returns without playing an effect.
