## Behavior

This function constructs the full packet-opened power configuration dialog. It calls the `DialogPane` constructor with the `Power` title, installs `PowerDialogPane` vtables, creates header/image controls, creates four embedded [UID:0000AQ][PowerListPane](by-class/PowerListPane.md) controls, parses the server packet row data, converts row labels with `MultiByteToWideChar`, sorts the four list models, attaches the dialog, and stores [UID:0000S0][g_pPowerDialog](by-global/g_pPowerDialog.md).

Despite the current generated `PowerListPane::InitializeFromData` name, the function is not an embedded list method. The `PowerListPane` methods start at `0x0054b000`.
