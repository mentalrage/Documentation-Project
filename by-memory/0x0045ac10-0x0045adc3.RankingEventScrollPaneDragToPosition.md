## Summary

This helper converts a mouse/track point into a scrollbar position, clamps the result to the current range, and refreshes the owning `RankingEventListPane` when the value changes.

The helper uses:

- orientation byte `+0xfc` to choose horizontal versus vertical math;
- current position word `+0xfe`;
- max/range word `+0x100`;
- drag anchor point `+0x108`;
- the part-2/thumb rectangle from `0x0045a710`;
- the owner event-list pane reached through the virtual owner callback at vtable slot `+0x1c`.

When the computed position changes, it updates the event-list pane's scroll state, mirrors the value into the scrollbar child, calls the event-list refresh helper at `0x0045b080`, and invalidates the list pane rectangle.

This is local scrollbar behavior, not a generic renderer/helper. It should be reconstructed as a `RankingEventScrollPane` helper that talks back to its owning [UID:0000BN][RankingEventListPane](by-class/RankingEventListPane.md).

## Source-Shape Notes

Do not emit final C++ for this helper yet. The drag math is well understood, but final names for owner lookup, orientation, track-rectangle variables, and shared pane invalidation are still provisional.

The helper should eventually reconstruct as the scroll-thumb drag-to-position routine. It:

- snapshots the old `+0xfe` current position;
- obtains the thumb rectangle through [UID:0001ZB][0x0045a710-0x0045a98a.RankingEventScrollPaneGetScrollRegionRect](by-memory/0x0045a710-0x0045a98a.RankingEventScrollPaneGetScrollRegionRect.md);
- computes clamped horizontal or vertical drag position using orientation `+0xfc` and drag anchor at `+0x108`;
- converts the clamped point into a new scroll position using max range `+0x100`;
- recovers the owning [UID:0000BN][RankingEventListPane](by-class/RankingEventListPane.md) through primary vtable slot `+0x1c`;
- writes owner scroll word `+0x10c`, mirrors it to the child scroll pane word `+0xfe`, calls the list refresh helper `0x0045b080`, and invalidates the owner bounds.

Keep names such as `GetTrackStartBoundsForDrag`, `GetTrackEndBoundsForDrag`, and `GetOwnerEventListPane` as behavior labels only. They must not be copied into final C++ until the shared pane parent/owner API and orientation enum are documented strongly enough.
