# 0x0046ff50-0x00470159 BrowserControlPaneOld Constructor

## Scope

- Range: `0x0046ff50-0x00470159` half-open.
- Entity kind: class constructor.
- Owner: [UID:000016][BrowserControlPaneOld](by-class/BrowserControlPaneOld.md).
- Parent memory cluster: [UID:0000ZF][0x0046f010-0x004710b8.BrowserOleLegacyAndHelpers](by-memory/0x0046f010-0x004710b8.BrowserOleLegacyAndHelpers.md).
- Likely source file: [UID:0000HV][Browser](by-file/Browser.md).

## Summary

This constructor builds the legacy browser control pane, constructs its `MSGHandler` subobject, allocates the embedded COM-style `Browser` host object, copies the initial URL string into the `Browser` object, allocates/starts a `BrowserThread`, stores `g_pBrowserThread`, and stores the constructed `Browser` pointer at the control-pane object offset `+0x110`.

The range is reconstructable NexusTK project code, but no reconstructed C++ should be emitted yet. The Browser object layout and original declaration names are still incomplete, so writing final source would risk cementing decompiler-shaped field names.

## Signature Hypothesis

```cpp
BrowserControlPaneOld *BrowserControlPaneOld::BrowserControlPaneOld(const RECT_like *bounds, const wchar_t *url);
```

Confidence is medium/high for `BrowserControlPaneOld` ownership and the two logical arguments. The exact rectangle type/name and URL argument constness are still open.

## Behavior

- Calls the control-pane/base constructor at `0x004949e0` with style/id value `8` and the caller-supplied bounds pointer.
- Constructs the `MSGHandler` subobject through `0x00528d60` at `this + 0x108`.
- Installs four `BrowserControlPaneOld` vtable pointers across the primary and secondary subobjects.
- Clears the embedded browser pointer at `this + 0x110`.
- If the bounds pointer is null, calls `0x004b78d0` with zero rectangle inputs plus `word_66DA94/word_66DA98`.
- Allocates a `0x234` byte `Browser` object and installs five Browser vtable/interface pointers at offsets `+0x00` through `+0x10`.
- Initializes Browser fields at `+0x14`, `+0x18`, `+0x228`, `+0x22c`, and `+0x230`.
- Writes the Browser initialization word `0x0101` at Browser offset `+0x22c`.
- Allocates a heap copy of the input wide URL string and stores it at Browser offset `+0x228`.
- Allocates a `0x80` byte `BrowserThread` object, constructs its `Thread` base, stores it in `g_pBrowserThread`, installs the BrowserThread vtable, attaches the Browser pointer at thread offset `+0x68`, clears byte `+0x6c`, copies the bounds rectangle to `+0x70`, and starts the thread through `0x005965e0`.
