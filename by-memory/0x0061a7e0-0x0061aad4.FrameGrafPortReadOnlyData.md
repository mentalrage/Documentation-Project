# 0x0061a7e0-0x0061aad4 Frame/GrafPort Read-Only Data

## Range

- Address range: `0x0061a7e0-0x0061aad4`
- Entity kind: `vtable/table-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: `source-declared/generated-binary`

## Summary

This `.rdata` span contains frame manager/part-pane vtables, general-purpose panel vtables, the `GrafPort` vtable, a `SurfaceDesc` diagnostic format string, and shared software-render constants. It bridges frame scheduling/chrome data into the help-pane read-only data block. The major bounded vtable, string, and render-constant islands now have exact child pages; the parent still owns the isolated boundary dword at `0x0061a880` plus the `CachedHashTable` and successor `SimpleHelpTextPartPane` RTTI locator dwords at `0x0061aac0` and `0x0061aad0`.
