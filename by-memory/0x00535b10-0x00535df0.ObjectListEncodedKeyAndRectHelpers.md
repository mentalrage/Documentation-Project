## Behavior

The first three raw helpers are ObjectList bounds helpers. They read `ObjectListLayout` fields `+0x04`, `+0x08`, `+0x0c`, and `+0x10`, then call the global rectangle initializer at `0x004b7c50`. Interpreted with the current layout names, the first and third helpers produce:

```cpp
InitRectBounds(out, minX - 2, minY - 2, minX + gridWidth + 2, minY + gridHeight + 2);
```

The second helper uses the same left/top/right calculation but extends the bottom edge farther:

```cpp
InitRectBounds(out, minX - 2, minY - 2, minX + gridWidth + 2, minY + gridHeight + 10);
```

The raw helper at `0x00535bd0` encodes ObjectList category keys. The low 16 bits carry the list index or row index. Some categories also store an 8-bit subtype or row selector in bits `16..23`; other categories encode only a top-nibble class marker:

| Type byte | Encoded key shape |
| --- | --- |
| `0` | `index` |
| `1` | `0x10000000 | index` |
| `2` or `4` | `((subtype | 0x2000) << 16) | index` |
| `3` | `((subtype | 0x3000) << 16) | index` |
| `5` | `((subtype | 0x5000) << 16) | index` |
| `6` | `0x60000000 | index` |
| `7` | `0x70000000 | index` |
| `8` | `0xc0000000 | index` |
| `9` | `0x80000000 | index` |
| `10` | `0x90000000 | index` |
| `11` | `0xa0000000 | index` |
| other | `0xffffffff` |

`sub_535CE0` reverses that key format for the surrounding lookup helpers. It derives the object type from the top nibble for keys whose high nibble is `0..0x0b`, writes that type to the output byte, writes the low 16-bit index to the index output, and writes the byte at bits `16..23` only for types `2`, `3`, `4`, and `5`. For other decoded types it writes `0` to the subtype/row output.

## Reconstructed C++ Candidate

Names are provisional, but the packed-key semantics are now stable enough to preserve in source reconstruction:

```cpp
static unsigned int EncodeObjectListKey(unsigned char type, unsigned char subtype, unsigned short index)
{
    switch (type)
    {
    case 0: return index;
    case 1: return 0x10000000u | index;
    case 2:
    case 4: return ((subtype | 0x2000u) << 16) | index;
    case 3: return ((subtype | 0x3000u) << 16) | index;
    case 5: return ((subtype | 0x5000u) << 16) | index;
    case 6: return 0x60000000u | index;
    case 7: return 0x70000000u | index;
    case 8: return 0xc0000000u | index;
    case 9: return 0x80000000u | index;
    case 10: return 0x90000000u | index;
    case 11: return 0xa0000000u | index;
    default: return 0xffffffffu;
    }
}

static void DecodeObjectListKey(unsigned int key, unsigned char* typeOut, unsigned short* subtypeOut, unsigned int* indexOut)
{
    const unsigned char type = static_cast<unsigned char>(key >> 28);
    if (type <= 11)
        *typeOut = type;

    if (*typeOut == 2 || *typeOut == 3 || *typeOut == 4 || *typeOut == 5)
        *subtypeOut = static_cast<unsigned short>((key >> 16) & 0xff);
    else
        *subtypeOut = 0;

    *indexOut = static_cast<unsigned short>(key);
}
```
