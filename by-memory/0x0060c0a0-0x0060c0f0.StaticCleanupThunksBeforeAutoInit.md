# 0x0060c0a0-0x0060c0f0 Static Cleanup Thunks Before AutoInit

## Scope

- Address range: `0x0060c0a0-0x0060c0f0`
- Entity kind: static-lifetime cleanup thunks and alignment padding
- Rebuild handling: `compiler/linker-generated`
- Disposition: ignored as standalone source; source declarations/static objects should regenerate equivalent `atexit` cleanup thunks.
- Confidence: strong for boundaries and thunk behavior from IDA function/disassembly/decompilation evidence.

## Summary

This range contains three small `atexit` cleanup thunks followed by `0xcc` alignment bytes before the [UID:0001O6][0x0060c0f0-0x0060c100.AutoInitStaticShutdownThunk](by-memory/0x0060c0f0-0x0060c100.AutoInitStaticShutdownThunk.md). The thunks are registered from static initializer functions and dispatch to object/container teardown helpers. They should not become standalone handwritten source functions.
