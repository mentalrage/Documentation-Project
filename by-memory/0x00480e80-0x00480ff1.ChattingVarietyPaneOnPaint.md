## Behavior

This method draws the compact chat-mode button and its current mode label. It initializes a temporary render state, sets a drawing state with `0x004b9670`, loads `CHATVAR.EPF` through `0x004d02f0`, draws it with palette `CHATVAR.PAL`, reads the current mode from `*(dword_67A748 + 16052)`, chooses a label, and draws that label twice with a one-pixel offset for shadow/foreground text.

Mode labels observed in IDA:

- `0`: the default label through `off_615364`, likely Talk.
- `1`: `aSh`, likely Shout.
- `2`: `aWh`, likely Whisper.
- `3`: `Group`.
- `4`: `Clan`.

The selected label is horizontally centered using `wcslen(label)`, an assumed six-pixel glyph width, and the pane's stored rectangle fields.
