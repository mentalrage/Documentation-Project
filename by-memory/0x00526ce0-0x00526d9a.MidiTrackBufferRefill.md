## Behavior

Refills a raw MIDI track buffer from the source using the track cursor and remaining byte count. Unlike the byte-reader helper, this range performs buffer refill/reset work without directly returning one byte to the caller.

The helper receives the per-track record pointer as its stack argument and uses the reader/source context in `ecx`. It exits early with failure status if the track remaining-byte counter at record offset `+0x24` is zero. Otherwise it resets the track buffer read pointer from record offset `+0x0c` into `+0x10`, seeks the source to the track cursor at record offset `+0x20`, reads up to `0x400` bytes or the remaining-byte count, updates record offsets `+0x08`, `+0x20`, and `+0x24`, and returns success only when the backing read succeeds and reports a nonzero byte count.
