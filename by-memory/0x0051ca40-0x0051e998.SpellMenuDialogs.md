## Packet, Row, And State Model

- Shared spell-list context fields: `+0x14c` packet/menu subtype byte, `+0x150` object/menu id dword, `+0x154` menu option/list parameter word, `+0x158` owning dialog pointer.
- Server rows use size `0x202`: reserved word at `+0`, row name text at `+2`. Server selected/explicit sends serialize opcode `0x39`, context fields, string length, multibyte row name, and a trailing zero with total length `convertedNameLength + 9`.
- Client rows use size `0x204`: one-byte selected spell slot/action byte at `+0`, reserved word at `+2`, row name text at `+4`. Client selected/explicit sends serialize fixed length `9`: opcode `0x39`, context fields, selected spell slot/action byte, and trailing zero.
- Client construction reads the one-based spell-slot table through [UID:0000QK][g_pCollectionData](by-global/g_pCollectionData.md) / [UID:0001OR][0x0067a748-0x0067a74c.g_pCollectionData](by-memory/0x0067a748-0x0067a74c.g_pCollectionData.md): active byte at `g_pUserPane + slot * 0x148 + 0x13a834`, display name at `g_pUserPane + slot * 0x148 + 0x13a83c`, slot range `1..52`.
- Command ids in both dialog command handlers: `1` action and close after selected-send attempt, `2` request/previous through `0x00517ec0`, `3` close-only, all others return.
- Action-button helpers fetch child slot `1` for the action button and child slot `6` for the spell list, call shared [UID:0003U0][0x004f3bb0-0x004f3f20.ListPaneItemSelectionStorageHelpers](by-memory/0x004f3bb0-0x004f3f20.ListPaneItemSelectionStorageHelpers.md) helper `0x004f3e20`, and dispatch action-button virtual slot `+0x4c` or `+0x50`.
