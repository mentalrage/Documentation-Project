## Ownership Decision

These four classes should migrate together as spell menu UI. They are adjacent in memory, share the same dialog resources and layout policy, and differ mainly by whether rows come from server packet text or local player spell-table data.

The `ChattingColorListPane*` spelling in current generated `ClientSpellMenuDialog::UpdateActionButtonState` is a type/name pollution artifact. Do not use it to move spell menu code into the chat source family.

Destructor glue for the two spell list classes is outside this contiguous spell-menu range and shared with item menu list classes. Keep `0x00520ad1`, `0x00520adc`, and `0x00520c20` in shared compiler/list-pane destructor support docs.
