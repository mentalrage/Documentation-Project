## Behavior

The range contains three related algorithm families over ObjectList list tiers:

- Direct search helpers for fields `+0x38`, `+0x3c`, and `+0x40`. They scan the list, compare the first dword in each entry with the requested object pointer/id, and return a high-nibble encoded key on match.
- Ordered insertion helpers. - Removal helpers. These scan the relevant direct list or row table, compare entry object pointers, and remove the first match through the list virtual at slot `+0x1c`. Row-table variants check the computed row first and some also scan backward across rows when the exact row did not contain the object.

The helper patterns match the ObjectList layout documented in [UID:0001VG][ObjectListLayout](by-type/by-struct/ObjectListLayout.md): fields `+0x14..+0x28` are row/cell list storage, and fields `+0x2c..+0x40` are direct global tiers.
