IDA decompilation evidence:

- `0x0057b020` closes an existing `this+0x18` Redbook handle if present, cancels event `0x504d5244`, clears `this+0x18`, `+0x1c`, `+0x20`, and `+0x24`, opens the requested drive with `AIL_redbook_open_drive`, calls the SoundManager volume helper at `0x0057a340`, reads track count with `AIL_redbook_tracks`, and fills the 100-byte order buffer at `this+0x1034`. The order is shuffled through `rand()` when config byte `g_config+0x2919d2` is true; otherwise it is sequential.
- `0x0057b160` is the compact close path: stop Redbook playback, cancel event `0x504d5244`, close the Redbook handle, clear the four Redbook state dwords, and cancel the same event again.
- `0x0057b1b0` cancels event `0x504d5244`, handles out-of-range track requests by either wrapping to track 1 when config byte `g_config+0x2919d3` is true or clearing the current-track field, then calls `AIL_redbook_track_info`, `AIL_redbook_play`, and schedules the track-ended timer through `0x005975e0`.
- `0x0057b240` increments the order index at `this+0x20`, wraps through `trackCount` when repeat is enabled, calls `0x0057b1b0` with `*(this+0x1034+index)`, or stops/cancels Redbook playback at the end of the order list.
- `0x0057b2c0` refuses to rewind before index zero, otherwise decrements `this+0x20` and dispatches the selected order byte through `0x0057b1b0`.
- `0x0057b2e0` cancels the track-ended event and pauses for the true argument. On resume, it reads track start/end through `AIL_redbook_track_info`, calls `AIL_redbook_resume`, gets the current Redbook position, and schedules only the remaining duration.
- `0x0057b370` calls the SoundManager stop/fade helper at `0x0057a260`, reads music mode from config dword `g_config+0x2919c8`, closes Redbook and starts DAT/stream track 1 for mode 1, starts Redbook from the first order byte for mode 2, or closes Redbook and optionally restarts stream fallback when mode 0 and local flag `this+0x10a9` is set.

IDA disassembly evidence for unmodeled raw helpers in the historic range:

- `0x0057b350-0x0057b36a` has a normal compact method body despite no IDA function record: `push [esi+0x18]`, call `AIL_redbook_stop`, push timer token `0x504e4354`, and call `0x00597610`.
- `0x0057b3f0-0x0057b48d` has a normal method prologue/epilogue despite no IDA function record. It scans eight 8-byte sample slots beginning at `this+0x48`, calls `AIL_sample_status`, chooses either the first active-status-2 slot or slot 7, rotates/copies slots through helpers at `0x00516030`, `0x00516220`, and `0x00516240`, then calls `AIL_init_sample` if the selected slot handle is nonzero.
