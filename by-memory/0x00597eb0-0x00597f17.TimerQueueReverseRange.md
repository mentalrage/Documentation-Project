## Behavior

Reverses a logical range of scheduled timer records in the queue's ring slot array. Each swap copies a 20-byte [UID:0001VX][ScheduledTimerEvent](by-type/by-struct/ScheduledTimerEvent.md) record as a 16-byte block plus the trailing dword. It is a queue-local file-static iterator algorithm used by the rotate helper, not a public scheduler API and not a generic project container helper.

B015/B009 reanalysis confirms the ABI shape is four stack arguments for two iterator/control-plus-index pairs and does not use `ecx` as an ordinary receiver. Keep the [UID:0000F2][TimerMgrScheduledEventDequeCompilerSupport](by-class/TimerMgrScheduledEventDequeCompilerSupport.md) owner because all operands are queue slot/capacity/index state, but avoid presenting it as a public member method. The accepted source-facing declaration is the file-local `static void ReverseRange(TimerMgrTimerQueue::Iterator first, TimerMgrTimerQueue::Iterator last)`.
