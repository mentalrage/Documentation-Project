## Behavior

Copies the 16-byte `m_bounds` rectangle from `this + 0x04` into the caller-provided destination pointer and returns that same pointer. The machine body preserves the pointer loaded from `[ebp+8]` in `eax` through `retn 4`; therefore a historical `void` reconstruction discarded an observable return value and is superseded by `RectBounds *GetBounds(RectBounds *outBounds) const`.

This is the getter half of a retained paired API with [UID:0002JK][0x00516fd0-0x00516fe1.MenuItemSetBounds](by-memory/0x00516fd0-0x00516fe1.MenuItemSetBounds.md). Both methods copy the whole 16-byte rectangle with `movups`, are fenced as independent bodies, and are absent from the `MenuItem` vtable, which makes them ordinary nonvirtual member methods rather than virtual slots or compiler data.
