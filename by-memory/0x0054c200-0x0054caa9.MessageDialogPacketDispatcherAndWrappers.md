## Behavior

The dispatcher receives a dialog packet payload pointer. It reads `packet[1]` through the narrow character traits helper, tests bit `0x10`, and uses the low nibble as a dispatch selector. Direct constructor paths allocate `0x278` bytes for the message/menu-question dialog family, then pass `packet + 2` and a layout/text-mode flag to the selected constructor.

The source dispatcher is `void PursuitMessageDialogCreator::CreateDialog(const unsigned char *packet)`. Current caller evidence at `0x00512840` and `0x00507e2e` constructs a four-byte stack `PursuitMessageDialogCreator`, invokes this member at `0x0054c200`, ignores any incidental machine return, and performs ordinary `LObject` teardown. The binary default path leaving the selector nibble in `EAX` is an ignored artifact, not a source-level `DialogPane *` return.

The second half of the island is a set of allocation wrappers. Some are reached from the dispatcher, while others currently have no direct code callers in IDA but are layout-equivalent helper wrappers for the same dialog family. These wrappers are still project source behavior because they instantiate dialog classes and are not CRT/STL/compiler runtime support.
