## Range Role

This range owns fitting-room item-shop cache and catalog state, not JsonCpp itself. It constructs and decodes the local `ItemShop.jbn` cache, parses the item-shop document through JsonCpp helpers, loads one named item category at a time, and exposes the embedded [UID:0000KD][ItemCatalog](by-file/ItemCatalog.md) count/lookup API used by the fitting-room list pane.

The product/third-party boundary is:

- product-owned cache, category keys, item-entry parsing, vectors, and lookup storage live in this range;
- JsonCpp document/value parsing helpers such as `0x004298f0`, `0x00429b30`, `0x004278e0`, `0x00427500`, and `0x00426ea0` are library dependencies, not fitting-room-owned code. See [UID:0000WY][0x00424630-0x00428b4b.JsonCppValueCore](by-memory/0x00424630-0x00428b4b.JsonCppValueCore.md) and [UID:0000X0][0x004298f0-0x0042acdf.JsonCppDocumentParseFrontEnds](by-memory/0x004298f0-0x0042acdf.JsonCppDocumentParseFrontEnds.md).
