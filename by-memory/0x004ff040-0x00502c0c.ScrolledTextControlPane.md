## Behavior

`ScrolledTextControlPane` is the generic DAT-text scrolling control. It shares the module with the credits/"made by" variant but has distinct timer behavior: this generic class advances by one pixel/step and wraps back to zero, while [UID:00019X][0x004ff400-0x00502cbd.ScrolledTextControlPaneForMadeBy](by-memory/0x004ff400-0x00502cbd.ScrolledTextControlPaneForMadeBy.md) advances by two and closes the new-history dialog at the end.

The constructor pipeline is resource-to-image:

- initialize the base `ControlPane` as control type `8`;
- load the requested DAT/resource text through the DAT file helpers;
- allocate and initialize temporary text-edit storage, including a temporary `TextEditPane`;
- make the text-edit pane read-only/non-editable for rendering;
- render the final text into an embedded graphics/tile context;
- copy or retain that rendered context for later scroll-blitting;
- initialize scroll counters and timer state.

The destructor and scalar deleting destructor release the embedded render/tile storage and pane-owned state. The timer handler updates scroll state and invalidates the pane, while the draw handler paints the background and blits the current scrolled view of the pre-rendered text image.
