## Behavior

`ResolveCompositionPartRect` resolves a `Part.tbl` part/frame rectangle for bounds calculation.

1. Reads the Part.tbl row's descriptor count.
2. Returns without writing when the descriptor count is zero, then falls back to descriptor zero when `descriptorIndex` is out of range.
3. Selects a `NewHumanPartFrameDescriptor`.
4. Selects the inline `0x10`-byte motion slot and returns without writing when its `.frames` pointer is null.
5. Uses the packed 9-byte frame row's `recordIndex` plus `drawIndexBase` to select a raw record.
6. Copies `records[rectIndex].bounds` when the index is in range; otherwise clears the output through `RectBounds::SetLTRB(0, 0, 0, 0)`.
7. Applies the passed adjustment through `RectBounds::Offset(xOffset, yOffset)` and returns no source value.

The C++ uses inferred support names `NewHumanPartEntry`, `NewHumanPartFrameDescriptor`, `NewHumanSequenceFrameTable`, and `RectBounds`. These names are implementation-ready source-facing names, not proof of original spelling.
