## Encoded Scalar Wrapper Resolution

- Both exact wrappers call virtual `GetSize`, use unsigned `GetSize() >> 1` as a validation key, read exactly eight bytes through virtual `Read`, and immediately return [UID:00013W][0x004a5e60-0x004a609f.ParseEntries](by-memory/0x004a5e60-0x004a609f.ParseEntries.md)'s full-register `1`/`0` result.
- UID0004IY has 87 call sites in seven functions and supplies integer/count/ID/flag storage.
- UID0004IZ has six call sites in four functions and supplies Effect/Item/Light float fields later consumed as floats.
- Neither wrapper reads all entries, allocates a table, loops over records, parses the 17-byte outer archive directory row, converts an integer numerically to float, or initializes output on failure.
- Decoder failure leaves caller output untouched; its local eight-byte buffer was already mutated but is discarded by the wrapper. No allocation or ownership transfer occurs.
- Source-facing names `ReadEncodedTableInt` / `ReadEncodedTableFloat` replace historical `ReadAllEntries` / `ReadAllEntriesAlt` while retaining the old names in change history for search provenance.
