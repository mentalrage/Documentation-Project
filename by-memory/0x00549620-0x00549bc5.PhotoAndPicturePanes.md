## Constructor Evidence

IDA decompilation of `0x00549620` gives signature shape:

```text
_DWORD *__thiscall sub_549620(_DWORD *this, unsigned __int16 mapId,
                              unsigned __int8 avatarField,
                              int avatarTileX, int avatarTileY,
                              char avatarShapeOrDirection)
```

Observed phases:

1. Call `PictureViewPane::PictureViewPane` at `0x00549a30`, then install `PhotoPane` vtables.
2. Construct cached draw target at `this + 0xf8`.
3. Format and open `C%04d.MAP` using the `unsigned __int16` map id.
4. Compute a rectangle from global tile dimensions `word_66DA9C` and `word_66DAA0`, then size/clip the pane draw target.
5. Read terrain/static-object triples from the loaded map buffer and draw `17 x 15` terrain tiles through `g_pMapTileImageLib` (`dword_67A75C`).
6. Draw nonzero static-object ids through `g_pStaticObjImageLib` (`dword_69B448`) using `GetStaticObjectBounds` and `RenderStaticObject`.
7. Build a temporary human/avatar descriptor and draw it through `g_pNewHumanImageLib` (`dword_67A760`) at `avatarTileX * tileWidth`, `avatarTileY * tileHeight`.
8. End drawing and clean up the DAT/string temporaries.
