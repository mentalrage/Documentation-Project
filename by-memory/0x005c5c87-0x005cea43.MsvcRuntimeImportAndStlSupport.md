# 0x005c5c87-0x005cea43 Msvc Runtime Import And STL Support

## Status

- Disposition: ignored for NexusTK source reconstruction.
- Entity kind: import jump thunks plus Microsoft C/C++ runtime and STL support.
- Ignored ledger: [UID:0000VN][-ignored](by-memory/-ignored.md).
- Confidence: strong for external/toolchain ownership.
- Boundary source: IDA MCP function and byte review on 2026-05-28.

## Range Summary

This range begins immediately after the corrected [UID:0001O4][0x005c2ac0-0x005c5c87.WorldMapPane](by-memory/0x005c2ac0-0x005c5c87.WorldMapPane.md) `WorldMapPane` helper end at `0x005c5c87` and ends before [UID:0001O5][0x005cea43-0x005cea6d.CrtWtolWrapper](by-memory/0x005cea43-0x005cea6d.CrtWtolWrapper.md) `CrtWtolWrapper` at `0x005cea43`.

The block is not one hand-authored NexusTK source file. It is a toolchain/runtime island containing:

- import thunks for DirectDraw, VERSION, IMM, and libcurl functions;
- `std::exception`, `std::locale`, `_Lockit`, iostream/locale support, and CRT conversion helpers;
- MSVC startup, atexit, thread-safe static, security-cookie, invalid-parameter, and string/integer parsing helpers.

The `0x005c7d??` split is intentionally approximate because the exact internal library-boundary split is not useful for source reconstruction; all subranges remain external runtime support.

## Evidence

- IDA MCP reports `0x005c5c86` belongs to `sub_5C5B20` (`0x005c5b20-0x005c5c87`), so the previous `WorldMapPane` page was one byte short.
- IDA MCP reports `0x005c5c87` as the next function start, named `DirectDrawCreate`, with bytes `ff 25 ...`, matching an import jump thunk.
- IDA MCP enumerates 296 function starts between `0x005c5c87` and `0x005cea43`; early names include `DirectDrawCreate`, `GetFileVersionInfoSizeW`, `GetFileVersionInfoW`, `VerQueryValueW`, multiple `Imm*` APIs, and `curl_*` APIs.
- The same enumeration shows runtime/STL names such as `??0exception@std@@QAE@QBD@Z`, `_Lockit`, `__Getctype`, `__Tolower`, `std::locale` internals, `ios_base`, `__Stolx`, `__Stoulx`, CRT startup helpers, `__security_check_cookie`, `__alloca_probe`, `__invalid_parameter`, `__invoke_watson`, and `parse_integer`.
- IDA MCP reports `0x005cea10-0x005cea43` as `__ischartype_l`, followed by the existing [UID:0001O5][0x005cea43-0x005cea6d.CrtWtolWrapper](by-memory/0x005cea43-0x005cea6d.CrtWtolWrapper.md) `0x005cea43-0x005cea6d.CrtWtolWrapper`.
