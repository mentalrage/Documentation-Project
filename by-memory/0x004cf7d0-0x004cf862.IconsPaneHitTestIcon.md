This helper maps mouse coordinates to an icon-strip index. Full mode tests icons from index `0`; reduced mode starts at icon index `6`. It returns the current icon index when that helper returns `1`; otherwise it advances by 20 pixels and returns `-1` after the active range is exhausted.
