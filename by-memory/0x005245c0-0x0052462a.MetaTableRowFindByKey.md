## Function Role

IDA models this helper as `sub_5245C0`, size `0x6a` / 106 bytes (Verified with `int_convert.py`). It searches a `MetaTable` row red-black tree for a `SimpleUString` key and writes either the matching row node or the tree sentinel to the caller-supplied output slot. The source-facing helper name for reconstruction is `MetaTableRowFindByKey`; `MetaTableRowLowerBound` remains a behavior description, not the preferred emitted name.

The helper:

- starts from the `MetaTableRowNode` tree header/sentinel passed by the caller;
- loads the root from header/sentinel `+0x04` / `parent`;
- walks left/right child links at `+0x00` and `+0x08` while the node's sentinel byte at `+0x0d` is clear;
- compares row keys at node `+0x10` through the shared `SimpleUStringLessThan` comparator at `0x00453740`;
- keeps the best lower-bound candidate;
- writes the candidate to the output slot only when the requested key is not less than the candidate key, otherwise writes the sentinel/header.
