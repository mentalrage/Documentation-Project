## Function Role

IDA models this helper as `sub_5245C0`, size `0x6a`. It searches a `MetaTable` row red-black tree for a `SimpleUString` key and returns either the matching row node or the tree sentinel.

The helper:

- starts from the tree header/sentinel passed by the caller;
- walks left/right child links while comparing row keys through the existing `SimpleUString` comparator at `0x00453740`;
- keeps the best lower-bound candidate;
- returns the candidate only when the requested key is not less than the candidate key, otherwise returns the sentinel.
