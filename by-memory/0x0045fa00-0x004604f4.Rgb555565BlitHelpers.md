# 0x0045fa00-0x004604f4 RGB555/RGB565 Blit Helpers

## Status

- Disposition: reconstructable NexusTK render support code.
- Entity kind: low-level software blit helper island.
- Likely source file: [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md), or a neighboring `render/SoftwareRender.cpp` blitter module.
- Confidence: strong for function boundaries, caller context, and pixel-format behavior; medium for final original names.

This island is project render support, not C++ CRT/STL code and not Ranking UI ownership. Current generated output mostly surfaces these helpers as unresolved externs or missing references from `RankingEventListPane` callback bodies, but IDA caller/callee evidence ties them to the process-wide software render callback families.

## Covered Ranges

| Range | Provisional name | Primary caller | Behavior |
| --- | --- | --- | --- |
| `0x0045fa00-0x0045fa9f` | `BlitTransparentShadow555` | `0x004bc090` compat sprite blit callback | Copies nonzero RGB555 source pixels to destination. Source pixel `1` is treated as a half-bright shadow sentinel using mask `0x3def`; source pixel `0` remains transparent. |

The alignment/data gaps between these functions are not claimed as separate project logic.

## Pixel Format Notes

- RGB555 helpers use green mask `0x03e0` and combined red/blue mask `0x7c1f`.
- RGB555 half-blend paths use `0x3def` to average without cross-channel carry.
- RGB555 transparent-shadow copy treats source value `1` as a special half-bright destination shadow sentinel.
- RGB565 transparent-shadow copy uses `0x7bef`, the corresponding half-bright RGB565 mask.
- Alpha weights are five-bit weights in the `0..32` range; `16` is the exact 50 percent case.

- IDA MCP `py_eval` on 2026-05-27 confirms `sub_460410` spans `0x00460410-0x004604f4`; the old page end at `0x004604f3` excluded the final `retn` byte.
- IDA MCP `callers` shows:

  - `0x00460370` is called from RGB565 sprite blit callback `0x004c0f80`.
  - `0x00460410` is called from RGB565 alpha/color-LUT callback `0x004c3cf0`.
- IDA MCP `callees` for the callback families confirms these helpers are consumed by [UID:00016J][0x004bb8d0-0x004c069e.SoftwareRenderCompatCallbacks](by-memory/0x004bb8d0-0x004c069e.SoftwareRenderCompatCallbacks.md) and [UID:00016L][0x004c0770-0x004c5fde.SoftwareRenderRgb565Callbacks](by-memory/0x004c0770-0x004c5fde.SoftwareRenderRgb565Callbacks.md).

- Current `simroot_v2` does not emit standalone recovered files for this helper island, even though generated callback bodies reference `FUN_00460370`, `FUN_00460410`, and related low-level helpers.
