## Behavior

This helper scans the decoded byte pixel buffer in an `EPFTileContext` and returns whether any pixel value falls inside any caller-supplied inclusive byte range.

IDA decompilation shows:

- return `false` when `pixelMode` or the first context dword is zero;
- compute row count as `bottom - top`;
- use `rowStride` as the number of bytes to inspect per row;
- read the pixel buffer from `+0x04`;
- read range-pair pointer from `rangeSpec + 0x04`;
- read range-pair count from `rangeSpec + 0x08`;
- compare each pixel byte against pairs `[min, max]` stored as two consecutive bytes.

Equivalent reconstruction shape:

```c
bool EPFTileContext::HasPixelInRanges(const ByteRangeSet& ranges) const
{
    if (!pixelMode)
        return false;

    const int rows = bottom - top;
    const unsigned char* row = static_cast<const unsigned char*>(pixelData);
    for (int y = 0; y < rows; ++y, row += rowStride) {
        for (int x = 0; x < rowStride; ++x) {
            const unsigned char value = row[x];
            for (int i = 0; i < ranges.count; ++i) {
                if (ranges.pairs[i].min <= value && value <= ranges.pairs[i].max)
                    return true;
            }
        }
    }

    return false;
}
```

The `ByteRangeSet` name is provisional. The caller-side record appears to store a byte-pair table pointer and count, but its owner structure should be finalized during the LightObjImageLib/raw-image-library pass.
