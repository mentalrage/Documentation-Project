## Behavior

This helper scans the decoded byte pixel buffer in an `EPFTileContext` and returns whether any pixel value falls inside any caller-supplied inclusive byte range.

Live IDA decompilation and disassembly show:

- return `false` when the first context dword at `+0x00` is zero;
- compute row count as `bottom - top` from `+0x1c - +0x14`;
- use row stride from `+0x0c` as the number of bytes to inspect per row;
- read the pixel buffer from `+0x04`;
- read range-pair pointer from `rangeSpec + 0x04`;
- read range-pair count from `rangeSpec + 0x08`;
- compare each pixel byte against inclusive `[min, max]` byte pairs stored as two consecutive bytes;
- return `true` through the `AL = 1` path as soon as any pixel matches; otherwise return `false` after all rows/pixels/ranges are exhausted.

At source level this is reconstructable as an `EPFTileContext` query that returns true when any decoded byte pixel falls inside any caller-supplied inclusive byte range. The `ByteRangeSet`/range-record name is provisional. The caller-side record appears to store a byte-pair table pointer and count, but its owner structure should be finalized during the LightObjImageLib/raw-image-library pass.
