## Behavior

Creates a temporary hierarchy row and inserts it after a resolved sibling/reference payload, or appends when no sibling/reference payload is supplied. The accepted source-facing API is `void HierList::InsertAfter(const void *parentPayload, const void *referencePayload, const void *payload)`.

The structure mirrors [UID:0002IC][0x004ce860-0x004ce9ad.HierListInsertBefore](by-memory/0x004ce860-0x004ce9ad.HierListInsertBefore.md): the first argument is optional `parentPayload`, the second is optional `referencePayload`, and the third is the caller payload to copy. This variant allocates the temporary row with zeroed allocation (`ZeroAllocateBufferMemory` at `0x005160d0`), explicitly clears `node->childList`, then copies `m_elementSize - 11` payload bytes into `node->payload`.

When a parent payload is supplied, it resolves the parent with [UID:0002IK][0x004cec30-0x004ced0f.HierListFindNodeByData](by-memory/0x004cec30-0x004ced0f.HierListFindNodeByData.md) / accepted source method `FindNodeByPayload`, creates the child `HierList` on demand using the observed 24-byte allocation, `List` constructor, vtable install, and owner pointer write, and stores the resolved parent node into the new row as `node->parent`.

When no sibling/reference payload is supplied, this method chooses the last existing index of the selected target list (`m_count - 1` at root, or `childList->m_count - 1` under a parent). When a sibling/reference payload is supplied, `FindNodeByPayload` supplies the actual zero-based index. The virtual insertion slot `+0x14` is then called with `referenceIndex + 1`, so the null-reference default appends and the resolved-reference case inserts after the found row.

The root/reference path intentionally records `referenceOwnerList` from `FindNodeByPayload(referencePayload, &referenceOwnerList, &referenceIndex)`, but the final dispatch remains on `this`. The accepted source contract therefore assumes the reference payload belongs to the already selected root list; do not rewrite the method as arbitrary cross-list insertion through the returned owner list. The parent/reference path similarly inserts into the resolved parent's `childList` and uses the reference only for the insertion index.

Like the paired method, the live tail frees the temporary row with `FreeBufferMemory` immediately before returning. The observed return register is the free-helper zero, not a preserved `List::InsertAt` destination pointer; callers rely on the structural mutation, so the accepted source signature is `void`.
