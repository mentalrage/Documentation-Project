## Behavior

Creates a temporary hierarchy row and inserts it after a resolved sibling/reference payload, or appends when no sibling/reference payload is supplied.

The structure mirrors [UID:0002IC][0x004ce860-0x004ce9ad.HierListInsertBefore](by-memory/0x004ce860-0x004ce9ad.HierListInsertBefore.md): the first argument is an optional parent payload, the second is an optional sibling/reference payload, and the third is the caller payload to copy. This variant allocates the temporary row with zeroed allocation (`sub_5160D0`), explicitly clears row `+0x04`, then copies `elementSizeWithHierarchyOverhead - 11` payload bytes to row `+0x08`.

When a parent payload is supplied, it resolves the parent with [UID:0002IK][0x004cec30-0x004ced0f.HierListFindNodeByData](by-memory/0x004cec30-0x004ced0f.HierListFindNodeByData.md), creates the child `HierList` on demand using the same 24-byte allocation, `List` constructor, vtable install, and owner pointer write as the paired insert method, and stores the parent node in the new row at `+0x00`.

When no sibling/reference payload is supplied, this method chooses the last existing index of the target list (`count - 1`). When a sibling/reference payload is supplied, `FindNodeByData` provides the owning list and actual zero-based index. The virtual insertion slot `+0x14` is then called with `resolvedIndex + 1`, so the null-sibling default appends and the resolved-sibling case inserts after the found row.

Like the paired method, the live tail frees the temporary row with `sub_516170` immediately before returning. The observed return register is the free-helper zero, not a preserved `List::InsertAt` destination pointer; callers rely on the structural mutation.
