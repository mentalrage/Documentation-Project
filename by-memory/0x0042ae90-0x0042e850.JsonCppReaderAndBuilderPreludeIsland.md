## Ownership Decision

Keep this island with [UID:0000KI][JsonCpp](by-file/JsonCpp.md) and the proposed `third_party/jsoncpp/` source tree. Cash-shop, fitting-room, and downloader modules may consume parsed JSON, but they should not own these parser/builder helpers.

The directive imports both `json_reader.cpp` and `json_writer.cpp`, `json_tool.h`, and the required public headers from `third_party_embeds/jsoncpp/include/json`. The old `0x0042ae90-0x0042edeb` range crossed the adjacent writer-builder range. That was a structural documentation error rather than a meaningful mixed-owner overlap: both pages describe the same third-party JsonCpp library owner, but `0x0042e850` is a real function boundary and the dedicated writer-builder sibling already covers `0x0042e850-0x0042f3f0`.
