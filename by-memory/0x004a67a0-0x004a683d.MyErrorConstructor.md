## Source-Shape Decision

Use the formal block above as the source reconstruction for this exact range:

- `new wchar_t[length + 1]` is the best source-facing representation. The binary computes a wide-character count plus terminator, applies the MSVC-style overflow guard when converting that count to bytes, calls the runtime allocation thunk, and then stores a `wchar_t *` at object offset `+0x04`.

- The block intentionally omits explicit vtable stores, base `LObject` mechanics, allocation overflow guard details, and `this` returns because those are compiler/output mechanics around the human source constructor.
