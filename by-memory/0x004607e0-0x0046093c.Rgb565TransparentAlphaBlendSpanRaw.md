## Behavior

This is an RGB565 transparent weighted span helper. It uses a caller-supplied 5-bit weight and an inverse weight of `32 - weight`. The block path calls [UID:000209][0x004609e0-0x00460af9.Rgb565TransparentAlphaBlendMmxBlocks](by-memory/0x004609e0-0x00460af9.Rgb565TransparentAlphaBlendMmxBlocks.md); the scalar tail skips source pixels whose value is zero and blends nonzero source pixels into the destination using RGB565 masks `0xf81f` and `0x07e0`.

The helper advances source and destination pointers by row pitches and repeats for the row count.

## Reconstructed C++ Candidate

```cpp
static inline uint16_t BlendRgb565TransparentWeighted(uint16_t src, uint16_t dst,
                                                       unsigned int alpha32)
{
    if (src == 0)
        return dst;

    const unsigned int inv = 32 - alpha32;
    const unsigned int rb = ((((src & 0xf81f) * inv) +
                              ((dst & 0xf81f) * alpha32)) >> 5) & 0xf81f;
    const unsigned int g = ((((src & 0x07e0) * inv) +
                             ((dst & 0x07e0) * alpha32)) >> 5) & 0x07e0;
    return static_cast<uint16_t>(rb | g);
}

void Rgb565TransparentAlphaBlendSpanRaw(const uint16_t* src, int srcPitchBytes,
                                        uint16_t* dst, int dstPitchBytes,
                                        unsigned int alpha32,
                                        int widthPixels, int rowCount)
{
    const int blockPixels = (widthPixels / 4) * 4;
    const int tailPixels = widthPixels - blockPixels;

    if (blockPixels > 0)
        Rgb565TransparentAlphaBlendMmxBlocks(src, srcPitchBytes, dst, dstPitchBytes,
                                             32 - alpha32, blockPixels / 4, rowCount);

    src += blockPixels;
    dst += blockPixels;

    for (int y = 0; y < rowCount; ++y)
    {
        for (int x = 0; x < tailPixels; ++x)
            dst[x] = BlendRgb565TransparentWeighted(src[x], dst[x], alpha32);

        src = reinterpret_cast<const uint16_t*>(reinterpret_cast<const unsigned char*>(src) + srcPitchBytes);
        dst = reinterpret_cast<uint16_t*>(reinterpret_cast<unsigned char*>(dst) + dstPitchBytes);
    }
}
```
