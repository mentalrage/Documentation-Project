## Interpretation

`sub_5976C0` constructs a static `TimerMgr` instance at `dword_69B3AC`, writes the `TimerMgr` vtable, initializes queue/list fields, stores `-1` into field index 8, and publishes the object through the timer manager global path. The atexit wrapper at [UID:00024G][0x0060c26a-0x0060c320.StaticDestructorWrappersBeforePoolAllocators](by-memory/0x0060c26a-0x0060c320.StaticDestructorWrappersBeforePoolAllocators.md) destroys this static object.

The final source should keep this storage with [UID:0000OT][TimerMgr](by-file/TimerMgr.md), not as anonymous data next to the render globals.
