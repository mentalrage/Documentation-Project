## Behavior

`DATIndexVector::InsertNode` hashes the node's four-byte key with FNV-1a, selects a bucket with `bucketMask`, and inserts the intrusive node into the bucket's range inside a shared doubly-linked list.

Important behaviors:

- Scans the bucket range backward to find an existing node with the same integer key.
- If a duplicate exists, unlinks and frees the new node, marks `inserted = false`, and returns the existing node.
- Moves the new node before the bucket scan point when required and updates bucket first/last links.
- Computes `nodeCount / bucketCount`; if the value exceeds `maxLoadFactor`, grows the bucket count and reinserts existing nodes.
