## Behavior

This method converts the submitted wide-character name to a multibyte string and sends a length-prefixed clan rename packet.

Packet fields:

| Offset | Value | Meaning |
| --- | --- | --- |
| `+0` | `0x4b` | Clan request opcode. |
| `+1` | `0x0a` | Clan rename subtype. |
| `+2` | `0x01` | Submit/confirm action. |
| `+3` | converted byte length | Length returned by `WideCharToMultiByte`. |
| `+4..` | converted name bytes | Multibyte name bytes copied into the packet. |
