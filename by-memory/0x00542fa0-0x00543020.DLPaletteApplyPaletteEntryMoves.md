## Behavior

The method applies an ordered list of typed palette-range records in place. For this operation, each record's two inclusive endpoint bytes have these local roles:

| Byte | Role |
| --- | --- |
| `firstIndex` | destination palette index |
| `lastIndex` | source palette index |

For each move pair, the method saves the 16-bit mapped color at the source index, shifts the intervening entries to preserve order, and writes the saved entry at the destination index. If destination is less than source, entries between destination and source shift one slot upward toward the source. If destination is greater than source, entries between source and destination shift one slot downward toward the source index. If both indexes are equal, the saved value is written back unchanged.

There is no explicit bounds check for the byte indexes or the move count. The caller and palette data must supply valid indexes for the 256-entry `DLPalette` mapped color table.
