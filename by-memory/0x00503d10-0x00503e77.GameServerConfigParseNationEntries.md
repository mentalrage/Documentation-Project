## Behavior

The parser first checks whether the packet has remaining payload. If so, it reads the count byte at packet offset `+2`, adds one, resizes the embedded [UID:0000B4][ProtectedArray_struct_GameServerConfig__NationEntry_](by-class/ProtectedArray_struct_GameServerConfig__NationEntry_.md) through [UID:000234][0x00514ee0-0x00514f6b.GameServerNationEntryArrayResize](by-memory/0x00514ee0-0x00514f6b.GameServerNationEntryArrayResize.md), and then iterates through that many packet records.

For each entry it writes a zero-extended packet byte into the 16-bit id field, reads a byte string length, converts that many bytes to wide text through `MultiByteToWideChar`, writes the result into the `+0x02` label field, and terminates the wide string. After the loop, it overwrites the final allocated slot with id `10` and the verified wide literal `Neighborhood`.
