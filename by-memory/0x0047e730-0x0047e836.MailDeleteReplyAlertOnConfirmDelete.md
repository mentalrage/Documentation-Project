## Behavior

This method performs local deletion after the user confirms a mail reply deletion prompt. In delete-all mode it removes the selected reply rows from the active mail reply list and refreshes the owning mail dialog. In single-delete mode it finds the previous mail dialog, removes the reply row matching the current reply id when present, refreshes that dialog, and pops the current alert/session view.

Live branch shape:

- reads the owning mail dialog pointer from `this + 0x26c`;
- reads the delete-all/single-delete mode byte from `this + 0x270`;
- delete-all path:
  - opens child/view id `7` through the owning dialog's `+0x1fc` dispatcher;
  - obtains the reply-list container through the returned view's `+0x108` member;
  - calls `0x004f3e80` to collect up to `0x100` selected indexes into a stack array;
  - removes each selected row by calling `0x004f3d60`, subtracting the number already removed from later indexes;
  - calls the owning dialog virtual method at vtable offset `0x4c` to refresh after deletion.
- single-delete path:
  - uses the owning dialog's `+0x270` session/previous-dialog context through `0x004a1250`;
  - reads the target reply id from the owning dialog's `+0x274` word;
  - opens child/view id `7` on the previous dialog, obtains its reply-list container, and calls `0x0047acd0` to find the reply id;
  - if the reply id is found, removes one row with `0x004f3d60`;
  - refreshes the previous dialog through vtable offset `0x4c`;
  - calls `0x004a10e0` with flag `0` to pop/close the current dialog/session view.
