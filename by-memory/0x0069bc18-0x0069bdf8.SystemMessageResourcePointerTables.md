# System Message Resource Pointer Tables

## Summary

- Address range: `0x0069bc18-0x0069bdf8`
- Entity kind: global-data pointer-table cluster
- Disposition: reconstructable project data
- Rebuild handling: `source-declared/generated-binary`
- Confidence: strong for system-message ownership and bounds; medium for final table names

This span contains two parallel `0xf0`-byte tables of resource/string pointers used by the system-message pane family. The first table starts at `0x0069bc18`; the second starts at `0x0069bd08`.

## Evidence

- IDA MCP reports a run of dword anchors from `0x0069bc18-0x0069bd04` initialized by `sub_586480`.
- IDA decompilation of `sub_586480` fills `dword_69BC18` through `dword_69BD04` using `sub_4F0350(v2, resourceId)` calls and empty-string fallbacks through `word_60DB20`, then iterates from `&dword_69BC18`.
- IDA MCP reports a second matching run from `0x0069bd08-0x0069bdf4` initialized by `sub_589D30`.
- IDA decompilation of `sub_589D30` fills `dword_69BD08` through `dword_69BDF4` with the same resource-id pattern and then iterates from `&dword_69BD08`.
- Both initializer functions are within [UID:0001J6][0x00584ea0-0x0058af3b.SystemMessagePanes](by-memory/0x00584ea0-0x0058af3b.SystemMessagePanes.md) and correspond to new/old system-message pane construction paths.

## Rebuild Notes

Recreate these tables as typed pointer arrays or owned member/static arrays in the system-message pane source. Do not leave them as anonymous `dword_69BCxx` globals once final table roles are known.
