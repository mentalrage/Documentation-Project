## Interpretation

The exact original names are still open. Keep these in the `MainUiGraph`/UI layer group rather than assigning them to individual consumer panes.

Live IDA shows this range is the tail pair after the `0x0069b374-0x0069b378` layer slot and before the byte-sized active-dialog counter at `0x0069b380`. The first tail slot has 14 direct data refs; the second has 11 direct data refs. Both are constructed during main UI startup, passed through the same layer initialization helper, released during main UI shutdown, and then zero-cleared through guarded destructor paths.
