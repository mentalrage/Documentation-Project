## Behavior

`Application::ExchangeMSGHandler` swaps the active `MSGHandler` pointer and returns the previous pointer. It uses the process-global application critical section at `0x0067a9a4`, best source-facing name `s_messageHandlerCriticalSection`, while writing the new handler pointer to `Application + 0x844`, best source-facing name `m_activeMessageHandler`.

At the binary level this is a `thiscall` method that:

- writes the incoming handler pointer to `this + 0x844`;
- leaves/destroys the guard through `0x0049bd10`;
- returns the saved previous handler.
