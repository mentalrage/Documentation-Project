## Behavior

`Application::ExchangeMSGHandler` swaps the active `MSGHandler` pointer and returns the previous pointer. It uses the process-global application critical section at `0x0067a9a4` while writing the new handler pointer.

At the binary level this is a `thiscall` method that:

- reads the previous handler pointer from `this + 0x844`;
- constructs/enters the local critical-section guard through `0x0049bcf0` with [UID:000292][0x0067a998-0x0067a9c0.ApplicationErrorAndCriticalSectionStatics](by-memory/0x0067a998-0x0067a9c0.ApplicationErrorAndCriticalSectionStatics.md) / `stru_67A9A4`;
- writes the incoming handler pointer to `this + 0x844`;
- leaves/destroys the guard through `0x0049bd10`;
- returns the saved previous handler.
