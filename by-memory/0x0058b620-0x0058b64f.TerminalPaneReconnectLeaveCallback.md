## Function Role

This is the member callback installed by `TerminalPane::OnDisconnect` for the reconnect/leave alert. The callback chooses between restarting the terminal/reconnect flow and leaving through the application shutdown path.

## Behavior Notes

- Nonzero decision argument calls the terminal timer/restart helper at `0x005975e0` using the adjusted terminal-pane subobject at `this + 0xa4`.
- Zero decision argument calls the application leave/shutdown helper at `0x00464e40` through the global application pointer.
- The function has no ordinary direct callers because `TerminalPane::OnDisconnect` stores its address into a callback object at `0x0058b56d`.
- The function returns the selected callee's result through the `__thiscall` callback convention and cleans one stack argument with `retn 4`.
