## Index Scope

This file is an index for modeled `Decoder` functions and `Encoder`/`Decoder` vtable glue around `0x004a5630-0x004a5e54`. The exact per-body `by-memory` pages are canonical. The raw reader family remains quarantined in its own raw-code page because IDA currently does not model those starts as functions.
