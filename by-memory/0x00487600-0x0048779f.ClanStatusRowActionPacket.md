## Behavior

The helper is a short row-action packet dispatcher for the clan status pane:

| Input row | Packet behavior |
| --- | --- |
| `2` | sends `{ 0x4b, 1, 0 }` |
| `3` | sends `{ 0x4b, 2, 0 }` |
| `4` | sends `{ 0x4b, 3, 0 }` |
| `5` | sends `{ 0x4b, 4, 0 }` |
| `6` | sends `{ 0x4b, 5, 0 }` |
| `7` | calls [UID:00021K][0x00485960-0x00485abe.ClanSubtype6PacketHelpers](by-memory/0x00485960-0x00485abe.ClanSubtype6PacketHelpers.md) `0x00485960`, which sends `{ 0x4b, 6, 0 }` |
| `8` | sends `{ 0x4b, 7, 0 }` |
| `9` | sends `{ 0x4b, 8, 0 }` |
| `10` | sends `{ 0x4b, 9, 0 }` |
| `11` | sends `{ 0x4b, 10, 0 }` |
| `12` | sends `{ 0x4b, 11, 0 }` |
| `13` | sends `{ 0x4b, 12, 0 }` |

Rows outside `2-13` return without sending. The default return value is the decompiler's `rowIndex - 2` intermediate, not a meaningful success/failure API.

For inline send cases, the body writes byte `0x4b`, writes the mapped subtype byte, writes a zero action/value byte, then calls [UID:0001HU][0x00574bb0-0x00574c13.QueueAndSendPacket](by-memory/0x00574bb0-0x00574c13.QueueAndSendPacket.md) with [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) / `dword_67A7EC` and length `3`.
