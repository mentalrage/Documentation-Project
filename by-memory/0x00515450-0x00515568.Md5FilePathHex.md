## Behavior

The helper takes a file path pointer, zeroes a 1024-byte stack buffer, initializes a stack MD5 context with the standard state constants, then calls `_fopen_s` with mode `"rb"`.

When the file opens successfully, it reads in 1024-byte chunks with `_fread`, calls `Md5Update` at `0x00515690` for each non-empty chunk, finalizes through `Md5Final` at `0x00515750`, closes the stream with `_fclose`, and converts the final 16-byte digest through `Md5DigestToHexString` at `0x005151f0`.

When the file open fails, it returns the static fallback literal `"000011112222333344445555666677778888"`. Preserve this literal until all file-hash callers are audited.
