## Behavior

Reads a one-byte UTF-16 element count, then copies `count * 2` bytes from the Decoder input buffer into the caller's wide buffer. The method clears `out[0]` and optional `*outChars` on entry, checks the valid flag at `+0x11`, verifies the count byte and payload bytes fit within the Decoder limit at `+0x08`, checks the caller capacity, copies through [UID:0001BC][0x00516030-0x00516036.GetMemoryMan](by-memory/0x00516030-0x00516036.GetMemoryMan.md) / [UID:0001BH][0x00516220-0x00516238.MemmoveWrapper](by-memory/0x00516220-0x00516238.MemmoveWrapper.md), advances cursor `+0x0c`, and writes a wide NUL terminator after the copied text.

On any failed valid/capacity/input-span check after the valid flag test, it stores `0` to `this + 0x11` and returns without producing output.
