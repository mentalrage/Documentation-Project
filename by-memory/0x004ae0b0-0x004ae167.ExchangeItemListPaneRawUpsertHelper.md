## Behavior

This raw helper inserts or replaces an offered-item row by key byte.

The row layout matches `ExchangeItemListPane::DrawItemEntry`:

| Offset | Field |
| --- | --- |
| `+0` | key/slot byte |
| `+2` | item id word |
| `+4` | color byte |
| `+6` | wide item name |

The helper scans existing rows for the same key. If found, it removes the existing row, then inserts a new row containing key, item id, color, and copied wide name.
