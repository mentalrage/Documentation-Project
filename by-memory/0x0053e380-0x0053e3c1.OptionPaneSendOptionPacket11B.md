## Behavior

This is the older `OptionPane` local copy of the option packet sender. It builds a three-byte packet:

| Offset | Value |
| --- | --- |
| `+0x00` | word opcode `0x011b` |
| `+0x02` | caller-provided option code |

The helper sends exactly three bytes through [UID:0000Q5][g_packetSender](by-global/g_packetSender.md) via the common queue/send funnel at `0x00574bb0`.
