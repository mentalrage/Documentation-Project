## Behavior

`EffectObjImageLib::LoadEffectTables` loads the two effect metadata resources used by the effect image library:

- `EFFECT.TBL` supplies the main effect descriptor count and per-effect [UID:0001U8][EffectInfo](by-type/by-struct/EffectInfo.md) records;
- each descriptor includes two variable-length arrays of [UID:0001U7][EffectFrameRecord](by-type/by-struct/EffectFrameRecord.md) entries;
- each frame record is `0x10` bytes and is read as integer, integer, float, integer;
- `EFFECT.FRM` supplies the frame-remap count and one four-byte [UID:0001UA][EffectPixMapInfo](by-type/by-struct/EffectPixMapInfo.md) value per entry;
- the fallback remap at object offset `+0x58` is initialized to `-1`;
- the effect load/suspend/error byte `byte_69B420` is set when required reads fail or return unexpected field counts.
