# 0x0067a7f0-0x0067a830 MmxBlendWeightScratchData

## Summary

- Address range: `0x0067a7f0-0x0067a830`
- Entity kind: render helper static data
- Proposed name: `MmxBlendWeightScratchData`
- Disposition: reconstructable NexusTK render support data
- Confidence: strong for address, writer functions, and role

This `.data` span contains eight qword-sized MMX scratch constants used by low-level RGB555/RGB565 software blend helpers. Each helper writes a replicated five-bit source weight and inverse weight into a qword pair, then loads those qwords into MMX registers for four-pixel block blending.
