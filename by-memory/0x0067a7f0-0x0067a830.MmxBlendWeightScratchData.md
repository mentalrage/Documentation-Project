## Reconstruction Notes

For source reconstruction, keep this data concept with [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) as binary evidence, but do not emit standalone file-scope writable scratch globals. The original binary used writable globals as MMX scratch vectors, but every cell is written by one helper immediately before that helper loads it into `mm2`/`mm3`. Clean source should compute equivalent source/inverse weight vectors as local qword or `__m64` temporaries, or as inline-assembly operands, inside the block helpers if the helper behavior is preserved.

2026-06-29 B003 applies that local-temporary policy to [UID:0000YF][0x00460b00-0x00460c0a.AlphaBlendSpan16Blocks](by-memory/0x00460b00-0x00460c0a.AlphaBlendSpan16Blocks.md). The binary writes the replicated source weight to `0x0067a820` and the replicated inverse weight `32 - sourceWeight32` to `0x0067a828`, then immediately loads those qwords into `mm2` and `mm3`. UID0000YF's accepted first-draft formal C++ computes equivalent local qword weight vectors inside the helper instead of emitting global writable scratch declarations. This preserves the helper's behavior because no external code xref consumes the transient scratch side effect, while this page keeps the original binary storage and xref facts documented.

2026-06-29 B001 applies the same local-temporary policy to [UID:0004BG][0x0045fff0-0x00460111.BlendTransparentRgb555Blocks](by-memory/0x0045fff0-0x00460111.BlendTransparentRgb555Blocks.md) and [UID:0004BH][0x00460120-0x0046022f.BlendRgb555Blocks](by-memory/0x00460120-0x0046022f.BlendRgb555Blocks.md).
