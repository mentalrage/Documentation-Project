# 0x0067a7f0-0x0067a830 MmxBlendWeightScratchData

## Summary

- Address range: `0x0067a7f0-0x0067a830`
- Entity kind: render helper static data
- Proposed name: `MmxBlendWeightScratchData`
- Disposition: reconstructable NexusTK render support data
- Confidence: strong for address, writer functions, and role

This `.data` span contains eight qword-sized MMX scratch constants used by low-level RGB555/RGB565 software blend helpers. Each helper writes a replicated five-bit source weight and inverse weight into a qword pair, then loads those qwords into MMX registers for four-pixel block blending.

## Evidence

- IDA MCP reports this span in `.data`.
- IDA MCP xrefs show:
  - `qword_67A7F0` / `qword_67A7F8` are only read/written by `0x0045fff0`, the RGB555 transparent weighted block helper.
  - `qword_67A800` / `qword_67A808` are only read/written by `0x00460120`, the RGB555 weighted block helper.
  - `qword_67A810` / `qword_67A818` are only read/written by [UID:000209][0x004609e0-0x00460af9.Rgb565TransparentAlphaBlendMmxBlocks](by-memory/0x004609e0-0x00460af9.Rgb565TransparentAlphaBlendMmxBlocks.md).
  - `qword_67A820` / `qword_67A828` are only read/written by [UID:0000YF][0x00460b00-0x00460c0a.AlphaBlendSpan16Blocks](by-memory/0x00460b00-0x00460c0a.AlphaBlendSpan16Blocks.md).
- IDA Hex-Rays decompilation shows each writer storing `a5 | (a5 << 16)` and `(32 - a5) | ((32 - a5) << 16)` into the qword pair before loading the values into `mm2` and `mm3`.
- The RGB555/RGB565 block helpers then use masks `0x1f001f001f001f`, `0x3e003e003e003e0`, and `0x7e007e007e007e0` to weight packed 16-bit color lanes.
