# 0x0067ab54-0x0067ab84 ApplicationDialogTimerAndBackgroundGlobals

## Summary

- Address range: `0x0067ab54-0x0067ab84`
- Entity kind: mixed application global-data cluster
- Proposed name: `ApplicationDialogTimerAndBackgroundGlobals`
- Disposition: reconstructable NexusTK global data
- Confidence: medium for some timer-state field names, strong for individual address roles

This `.data` span contains connection/reconnect dialog singleton pointers, application heartbeat/timer guard counters, the raw mouse-wheel accumulator, the background-pane singleton pointer, and the timer-manager singleton pointer. The range is documented as one cluster because several middle dwords are application-loop state rather than class-owned pointers, but every dword in the span has IDA xrefs and is real runtime state.

## Evidence

- IDA MCP reports direct xrefs for every dword in this range; none of the bytes are padding.
- `0x00553c10` assigns `dword_67AB54` while constructing `ConnectionClosedDialog`; `0x00553d80` deletes/replaces `dword_67AB58` while creating `ReconnectDialog`.
- [UID:0000YT][0x00466ca0-0x004670ad.CheckTimerSkewAndSendHeartbeat](by-memory/0x00466ca0-0x004670ad.CheckTimerSkewAndSendHeartbeat.md) decompilation uses `dword_67AB5C`, `dword_67AB60`, `dword_67AB64`, `dword_67AB68`, and `dword_67AB6C` for local-static guarded tick baselines and one-shot skew reporting.
- `Application::RunMessageLoop` at `0x00464cd0` increments `dword_67AB70` to call the skew/heartbeat checker and increments `dword_67AB74` to yield through `Sleep(1)`.
- Older IDA-backed notes identify `dword_67AB78` as the raw mouse-wheel delta accumulator in `Main_WndProc` before dispatching the normalized wheel event through EventMan.
- `0x00467510` assigns `dword_67AB7C` during `BackGroundPane` construction.
- Existing global documentation [UID:0000SI][g_pTimerMgr](by-global/g_pTimerMgr.md) identifies `0x0067ab80` as the active `TimerMgr` singleton pointer.

The timer guard/counter fields are application-loop support data and should stay near [UID:0000HG][Application](by-file/Application.md) / [UID:0000YT][0x00466ca0-0x004670ad.CheckTimerSkewAndSendHeartbeat](by-memory/0x00466ca0-0x004670ad.CheckTimerSkewAndSendHeartbeat.md) unless later source evidence proves a dedicated timing module.
