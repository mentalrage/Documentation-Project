## Rebuild Notes

- Preserve import/library requirements through project configuration, headers, libraries, and dependency selection.
- Do not port import-table bytes directly into source.
- If later docs identify a specific import dependency or delay-load requirement, link it through `by-meta/client_libraries.md`, `by-file` ownership notes, or the relevant subsystem docs.
- Treat `binkw32`, `mss32`, and `libcurl` as separate runtime/procurement dependencies. The IAT proves their runtime boundary; product-owned source should remain in the wrapper modules that call them.
- Treat Windows modules as SDK/import-library dependencies. Reconstructed source should include the appropriate Windows headers and linker inputs, not recreate import thunks or IAT layout by hand.
