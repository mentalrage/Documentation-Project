## Layout Evidence

The string/blob reader block uses the same cursor-state fields documented for the primitive reader block:

```text
+0x04  input buffer pointer
+0x08  input buffer size/limit
+0x0c  current read position
+0x10  byte-order flag for 16-bit length fields
+0x11  valid/readable flag
```

Every read path checks `+0x11` before consuming input, bounds-checks `+0x08` against the requested span, advances `+0x0c` only on success, and clears `+0x11` on failure.
