## Behavior

This helper copies the process command line, skips the executable token, tokenizes the remaining wide command line, counts startup arguments, rejects oversized argument lists, and reasserts the startup-ready byte at the caller-supplied application/config state block.

It is the common lightweight argument-count/tokenization primitive used by the larger launcher-mode parsers in this island.
