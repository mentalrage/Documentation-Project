# 0x0066d888-0x0066da88 EventMan Key Translation Tables

## Summary

- Address range: `0x0066d888-0x0066da88`
- Entity kind: initialized keyboard translation tables
- Disposition: reconstructable project data
- Rebuild handling: `source-declared/generated-binary`
- Confidence: strong for `EventMan` constructor use; medium for final table names

This range contains two 256-byte keyboard translation tables copied into `EventMan` construction state. The first table maps unshifted keys and keypad codes; the second maps shifted keys and keypad variants.

## Layout

| Range | Current IDA name | Notes |
| --- | --- | --- |
| `0x0066d888-0x0066d988` | `unk_66D888` | Unshifted keyboard map. Visible rows include `Esc`, `1234567890-=`, `qwertyuiop[]`, `asdfghjkl;'`, `\\zxcvbnm,./`, and keypad `789-456+1230.`. |
| `0x0066d988-0x0066da88` | `unk_66D988` | Shifted keyboard map. Visible rows include `Esc`, `!@#$%^&*()_+`, `QWERTYUIOP{}`, `ASDFGHJKL:"~`, and `|ZXCVBNM<>?`. |

## Evidence

- IDA xrefs from `EventMan` constructor copy `0x100` bytes from `0x0066d888` at `0x004a8cfd` and from `0x0066d988` at `0x004a8d1d`.
- The copied data has the shape of two scan-code to character lookup tables, including normal and shifted ASCII rows.
- The parent `EventMan` page documents the constructor as setting cursor state and key tables.

## Reconstruction Notes

- Reconstruct as two named static key maps in the event/input subsystem.
- The exact arrays are source-relevant because they define keyboard event behavior.
- Keep this separate from higher-level `KeySpeedMgr`; this table maps keys, while `KeySpeedMgr` controls repeat/speed settings.
