## State And Resource Map

| State/resource | Evidence and interpretation |
| --- | --- |
| `this+0x04` | Tile catalog/archive metadata pointer. Constructor writes either modern `BuildTilecArchiveTable(L"TILEC.EPF")` output or legacy `LoadImageFrameTable(L"TILEC.EPD", 0)` output; destructors release its optional backing table and the catalog object. |
| `this+0x08` | Four-byte tile-class table allocated from `TILEC.TBL` or `TILEC.TBD`; each row stores a 15-bit tile id plus high-bit flag. |
| `this+0x0c` | Pointer array for variable-size `StaticObjEntry` records loaded from `SOBJ.TBL`; each record has a fixed header followed by `2 * layerCount` tile ids. |
| `this+0x10` | Static-object record count read from `SOBJ.TBL`, used by constructor allocation, bounds lookup, destructor cleanup, and renderer id validation. |
| [UID:0000SD][g_pStaticObjImageLib](by-global/g_pStaticObjImageLib.md) | Process singleton written by the constructor and cleared by the ordinary destructor, EH helper, and scalar deleting destructor. |
| `SOBJ.TBL` | Static object table read by the constructor; per-record byte at entry `+0x05` is used as layer count by bounds/render paths. |
| `TILEC.EPF` / `TILEC%d.EPF` | Modern tile archive family scanned by `BuildTilecArchiveTable` for static-object tile frames. |
| `TILEC.TBL` / `TILEC.TBD` | Tile-class table source; constructor validates the count against tile catalog frame capacity before allocating `this+0x08`. |
| `TILEC.EPD` | Legacy archive path loaded through the shared image-frame table helper when `byte_66DA97 != 1`. |
