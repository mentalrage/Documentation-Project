# 0x0067a7e4-0x0067a7e8 g_pRankingDialog

## Summary

- Address range: `0x0067a7e4-0x0067a7e8`
- Entity kind: global pointer
- Proposed name: `g_pRankingDialog`
- Disposition: reconstructable NexusTK global data
- Confidence: strong for address, owner class, and singleton role

This four-byte zero-initialized `.data` slot stores the active `RankingDialog` singleton pointer. Ranking child panes use it to reach category, page, and selection state, and reward-info dialog code uses it when preparing reward requests.
