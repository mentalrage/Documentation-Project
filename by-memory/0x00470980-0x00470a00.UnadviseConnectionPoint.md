# 0x00470980-0x00470a00 UnadviseConnectionPoint

## Scope

- Range: `0x00470980-0x00470a00` half-open.
- Entity kind: browser/OLE free helper.
- Direct owner: [UID:0000HV][Browser](by-file/Browser.md).
- Parent inventory: [UID:0000ZF][0x0046f010-0x004710b8.BrowserOleLegacyAndHelpers](by-memory/0x0046f010-0x004710b8.BrowserOleLegacyAndHelpers.md).

`UnadviseConnectionPoint` is the cleanup counterpart for `AdviseConnectionPoint`. It queries the connection-point container, locates the event connection point, calls `Unadvise(cookie)`, and releases temporary COM interfaces.

## IDA Evidence

- 2026-06-10 B001-024 live IDA MCP reports `sub_470980` at `0x00470980-0x00470a00`.
- Direct callers include BrowserWindow setup/shutdown, BrowserControlPane setup/shutdown, Browser destructor/scalar destructor, and BrowserThread host cleanup.
- Decompilation returns `E_INVALIDARG` for null source interface, queries the connection point container, calls `FindConnectionPoint`, calls the vtable slot consistent with `Unadvise(cookie)`, releases the connection point and container, and returns the HRESULT.
- The helper is shared across Browser classes and therefore belongs to [UID:0000HV][Browser](by-file/Browser.md), not to any single class.
