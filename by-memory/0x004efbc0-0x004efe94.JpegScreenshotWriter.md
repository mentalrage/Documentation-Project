# 0x004efbc0-0x004efe94 - JPEG Screenshot Writer

## Status

- Confidence: strong for IJG-backed JPEG writer behavior, exact terminal boundary, local error callback ownership, caller xref, callee set, and internal padding; medium for the exact source-facing names of the adjacent destination callback/null stubs.
- Proposed owner: [UID:0000K4][ImageWriters](by-file/ImageWriters.md) with caller-side ownership in [UID:0000ND][ScreenshotCapture](by-file/ScreenshotCapture.md)
- Related library owner: [UID:0000KN][LibJPEG](by-file/LibJPEG.md)
- Reconstruction status: source-owned wrapper is reconstructable, but `AUTOGEN_PARENT_UID` is intentionally blank because `ImageWriters` has no projected reconstruction path yet. C++ is intentionally blank until the libjpeg structure fields and local callback names are final-source quality.
- Evidence basis: read-only IDA MCP decompile/callee/xref/byte checks on 2026-05-25, 2026-05-26, 2026-05-28, and 2026-06-01.

## Functions

| `0x004efbc0-0x004efde2` | `sub_4EFBC0`, size `0x222` | `WriteJpegFileFromRgb565Surface` | Converts a 16-bit source surface to temporary 24-bit RGB rows and writes scanlines through IJG libjpeg compression helpers to a caller-supplied `FILE*`. |

The function receives source pixels, width, height, a byte controlling 555/565 channel extraction, and an output stream. It constructs an IJG compression object with version `62`, configures image dimensions and RGB input, allocates a `3 * width * height` temporary buffer, converts the source image to byte RGB, writes scanlines, frees the temporary buffer, and destroys the compression object.

## Library Boundary

This is not stock IJG source. It is NexusTK-owned output wrapper code that uses the statically linked [UID:0000VP][0x00401000-0x00414283.LibJpeg6bCore](by-memory/0x00401000-0x00414283.LibJpeg6bCore.md), specifically the public compression APIs mapped in [UID:0000VS][0x00403920-0x004048e2.LibJpegCompressApiFrontEnd](by-memory/0x00403920-0x004048e2.LibJpegCompressApiFrontEnd.md). This is analogous to [UID:0000K4][ImageWriters](by-file/ImageWriters.md) wrapping LodePNG for PNG output.

Keep IJG compression internals under [UID:0000KN][LibJPEG](by-file/LibJPEG.md). Keep the screenshot decision/path handling in [UID:0000ND][ScreenshotCapture](by-file/ScreenshotCapture.md).
