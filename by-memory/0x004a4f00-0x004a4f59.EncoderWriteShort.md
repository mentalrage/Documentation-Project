## Behavior

`Encoder::WriteShort(unsigned short value)` writes a 16-bit scalar at the current output cursor when the encoder is still writable and the caller-provided buffer has room for two payload bytes plus the final terminator reserve. It checks writable flag `+0x11` first; if the encoder is already invalid/not writable, it returns without touching cursor or buffer state. It then requires `m_capacity >= m_writePos + 3`. The extra byte is the family-wide final-NUL reserve consumed by [UID:00013K][0x004a55e0-0x004a5621.EncoderFinalize](by-memory/0x004a55e0-0x004a5621.EncoderFinalize.md), not a third short byte.

On overflow, the method clears `+0x11` and returns without partial writes. If byte-order flag `+0x10` is nonzero, it writes the high byte first, increments cursor, writes the low byte, and increments cursor again. If byte-order flag `+0x10` is zero, it stores the native 16-bit word at `m_outputBuffer + m_writePos` and advances `m_writePos` by two. The source draft intentionally preserves that native-word store in the non-big-endian branch instead of rewriting it as two portable byte stores.
