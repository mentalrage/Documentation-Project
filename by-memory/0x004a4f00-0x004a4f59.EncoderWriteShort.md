## Behavior

Writes a 16-bit value at the current cursor when the encoder is valid and has room for the two payload bytes plus the final terminator. If the byte-order flag is set, writes the high byte first and then the low byte; otherwise writes the native little-endian word directly. On insufficient capacity, clears the valid/writable flag.
