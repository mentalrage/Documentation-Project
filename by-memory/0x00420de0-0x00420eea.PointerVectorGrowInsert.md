## Behavior

The function implements the grow/reallocation path of a vector insert operation for 4-byte trivially movable/copyable elements. It is not a complete high-level vector insert routine: all confirmed callers enter this helper only on the full-capacity slow path, while non-full callers store directly at `*end` and advance the vector end pointer.

The helper treats `ECX` as a three-pointer vector header:
