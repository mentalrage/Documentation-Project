# 0x0060c0f0-0x0060c100 AutoInit Static Shutdown Thunk

## Scope

- Range: `0x0060c0f0-0x0060c100`
- Entity kind: static-lifetime cleanup thunk
- Current IDA name: `sub_60C0F0`
- Registered by: [UID:0000W8][0x00419ee0-0x00419ef4.InitializeOleSupport](by-memory/0x00419ee0-0x00419ef4.InitializeOleSupport.md)
- Related static slot: `off_66D42C`
- Disposition: compiler/static-lifetime cleanup glue, not a standalone handwritten source function
- Confidence: confirmed

## Behavior

This thunk is registered with `_atexit` by `InitializeOleSupport` at `0x00419ee0`. It writes the anonymous `AutoInit` vtable pointer into the static object slot `off_66D42C`, then tail-jumps to `OleUninitialize`.

The static lifetime shape is:

1. `0x00419ee0` calls `OleInitialize(0)`.
2. `0x00419ee8` pushes `0x0060c0f0`.
3. `_atexit` records this thunk.
4. At process shutdown, the thunk restores the static object's vtable and calls `OleUninitialize`.
