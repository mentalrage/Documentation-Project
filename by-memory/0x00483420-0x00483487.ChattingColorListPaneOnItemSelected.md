## Behavior

This virtual selection handler delegates to the base list selection update, reads the selected swatch color value, writes it into the owning [UID:00001T][ChattingColorPane](by-class/ChattingColorPane.md) color table for the current category, and refreshes the selector child if present.

The mode flag at `this+0x150` decides which owner-side table receives the selected color:

| Mode flag | Owner write target |
| --- | --- |
| nonzero | owner `+0x278 + currentCategory*4` |
| zero | owner `+0x290 + currentCategory*4` |

Approximate shape:

```cpp
void ChattingColorListPane::OnItemSelected(int row, bool notify)
{
    ListPane::OnItemSelected(row, notify);

    int color = GetItem(GetSelectedIndex()).colorValue;
    int category = m_owner->m_currentCategory;
    if (m_primaryTable)
        m_owner->m_primaryColor[category] = color;
    else
        m_owner->m_secondaryColor[category] = color;

    if (m_owner->m_categoryPane != NULL)
        m_owner->m_categoryPane->RefreshSubpane();
}
```
