This body performs `LogoPane` instance cleanup without freeing the object allocation. It installs the three `LogoPane` vtable views at offsets `+0x00`, `+0xa0`, and `+0xa4`, releases the decoded startup-logo tile context at `this + 0xf8`, releases and destroys the embedded palette object at `this + 0x120`, and then chains to the shared pane/base teardown helper at `0x00544580`.

The body is behaviorally paired with [UID:0002PR][0x004f5300-0x004f53a8.LogoPaneScalarDeletingDestructor](by-memory/0x004f5300-0x004f53a8.LogoPaneScalarDeletingDestructor.md), which repeats this cleanup and then applies scalar-delete flag handling.
