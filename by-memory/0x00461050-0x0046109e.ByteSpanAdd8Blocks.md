# 0x00461050-0x0046109e Byte Span Add 8-Byte Blocks

## Status

- Disposition: reconstructable NexusTK render/support code.
- Entity kind: free helper.
- Likely source file: [UID:0000NT][SoftwareBlend16](by-file/SoftwareBlend16.md) `SoftwareBlend16` or neighboring alpha-mask/span utility source.

- Rebuild handling: `source-authored`.

## Address Range

`0x00461050-0x0046109e` (`sub_461050`, size `0x4e`, 37 decoded instructions).

The preceding `0x0046104b-0x00461050` and following `0x0046109e-0x004610a0` bytes are alignment padding.

## Behavior

Adds eight-byte source blocks into destination blocks across one or more rows using MMX `paddb`. The helper receives a source row pointer, source row pitch, destination row pointer, destination row pitch, eight-byte block count, and row count.

It converts the block count into a byte count, saves the integer register set, loads each destination qword, adds the source qword with `paddb`, stores the qword back to destination, advances source/destination by eight bytes inside a row, advances source/destination by their row pitches between rows, restores registers, and emits `emms`.
