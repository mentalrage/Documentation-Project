## Behavior

This is the `CreateThread` entry routine passed by `ThreadMan::ThreadMan`. Its normal path calls [UID:0001K2][0x00596e10-0x005970df.ThreadManWorkerLoop](by-memory/0x00596e10-0x005970df.ThreadManWorkerLoop.md), which does not return under normal operation.

IDA caller/callee evidence shows exception-handling support around the worker loop. On an exception path, the entry formats an error message into a wide buffer, displays it with `MessageBoxW`, and calls the application-exit helper at `0x00464e40`.
