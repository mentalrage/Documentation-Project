## Behavior Summary

This range is a pre-login account/user-information dialog. The constructor installs `UserInfoDialogPane` vtables, initializes the modeless/dialog base, decodes packet-supplied text fields into wide strings, constructs the visible controls, populates choice lists, and stores validation alert strings. The command handler treats command `1` as OK: it calls `ValidateInput`, sends the user-info packet on status `10`, then closes the dialog; otherwise it opens an alert using the stored validation-message table. Command `2` closes/cancels.

The short input/key/focus functions are vtable callbacks that refresh focus state and forward to shared dialog/input helpers. `UpdateOkButtonState` reads controls through the child-control host at `this[127]`, checks text controls `3` through `6`, checks selection controls `7` through `9`, and enables the OK button only when required values are present. `ValidateInput` re-reads controls from the same host, copies text with bounded `0x80`-wide-character buffers, validates required name/numeric/selection data, and uses status `10` as the success code. `SendUserInfo` builds opcode `0x53`, subtype `1`, converts four text controls and four selected option labels to bounded multibyte packet fields, writes length bytes, copies payloads, and sends the assembled buffer through the session sender.
