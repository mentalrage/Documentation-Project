## Behavior

The helper island establishes the two major reward-list strides:

- reward item rows are 520 bytes (`0x208`);
- reward entry rows are 560 bytes (`0x230`) and contain an embedded item vector at offset `+0x224`.

The append helpers use MSVC vector growth behavior, including capacity growth by roughly 1.5x, max-size checks, aligned large-allocation headers, and destruction/cleanup paths for old allocations. The reward-entry append helper deep-copies each entry's nested item vector instead of copying only the begin/end/capacity pointers.
