## Behavioral Summary

- Constructor stores callback/cancel/min/max fields at `+0x26c`, `+0x270`, `+0x274`, and `+0x278`.
- If `g_useEpfAssets == 1`, it creates the EPF layout with a `239x283` background and smaller button/edit geometry.
- Otherwise it creates the EPD layout with a `287x277` background and `NPAL8.PAL`.
- The action handler treats button `1` as confirm and button `2` as cancel.
- Confirm reads edit control `4`, parses the text as an integer, rejects values outside `min..max`, and opens an [UID:00000B][AlertPane](by-class/AlertPane.md) with localized string `217` on failure.
- Valid confirm calls the confirm callback with the parsed value and closes the dialog. Cancel closes and calls the cancel callback.
