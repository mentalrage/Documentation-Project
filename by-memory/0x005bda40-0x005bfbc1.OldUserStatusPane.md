## Behavior Summary

`OldUserStatusPane` is the legacy local-player status panel for the older UI layout. The aggregate covers construction, cleanup, status accessors, legacy packet routing, hover help, painting, status-rectangle lookup, numeric glyph drawing, retained packet helper bodies, and the bitflagged payload application path. It uses `USERSTAT.EPD`, `NATION.EPD`, `TOTEM.EPD`, `CLASS.EPD`, bar/palette assets, and the `9X11FONT.BIN` glyph table. The payload path updates legacy status fields, invalidates the changed rectangles, creates or invalidates [UID:0000F4][TotemFrame](by-class/TotemFrame.md) when the raw spirit/totem byte changes, stores two full-status tail words, and returns `false` to router case `8`.

This page is now the aggregate ordering and evidence owner. It deliberately does not paste method/helper bodies into its C++ block. Exact body emission is split into the child pages listed above, with `[[CHILDREN]]` as the only formal aggregate C++.
