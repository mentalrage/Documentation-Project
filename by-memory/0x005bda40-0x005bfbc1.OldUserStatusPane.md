## Behavior Summary

`OldUserStatusPane` is the legacy local-player status panel used by the older UI layout path. It paints the `USERSTAT.EPD` frame, status bars, nation/totem/class icons, numeric fields, and hover-help zones, while sharing the `9X11FONT.BIN` glyph table and user-status resource family with the newer status panes.

The aggregate contains the constructor, cleanup body, small field accessors, packet/movement router, hover/help handler, paint method, legacy dirty/help rectangle lookup, glyph-number renderer, and bitflagged payload applicator. The payload path updates legacy status fields, invalidates changed rectangles, and creates or invalidates [UID:0000F4][TotemFrame](by-class/TotemFrame.md) when the spirit/totem value changes.
