## Behavior

Copies a caller-requested number of raw bytes from `inputBase + cursor` to the destination buffer, advances cursor `+0x0c` by the requested count, and leaves the output untouched if the Decoder is already invalid. If `cursor + byteCount` exceeds limit `+0x08`, it clears valid flag `+0x11` and returns without copying.
