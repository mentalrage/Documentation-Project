## Behavior

This helper takes a signed 16-bit row index and classifies whether the row is currently eligible for a clan-status action. It is directly adjacent to `ClanStatusPane::HitTestRow` and uses the same row-index model.

The helper defaults to allowed (`al = 1`) for rows outside the handled `2-15` window. Handled rows can return false when the pane is in a particular view state:

- Rows `2`, `4`, `5`, and `6` require receiver offset `0xf9 < 1` or offset `0xf8 != 0`.
- Row `3` requires receiver offset `0xf9 != 0` or offset `0xf8 != 0`.
- Rows `7-13` and `15` require receiver offset `0xf9 < 2` or offset `0xf8 != 1`.
- Row `14` requires receiver offset `0xf9 < 2` or offset `0xf8 != 0`.
