# MSVC STL Iostream Template Support

## Address Range

- `0x004361b0-0x00439df9`
- Entity kind: runtime / third-party template support.
- Disposition: ignored for NexusTK-owned reconstruction.
- Rebuild handling: `compiler/linker-generated` plus `third-party/runtime`.

## Summary

This range is a dense support island of MSVC/Dinkumware STL, iostream, locale, exception, string, and map/set template helpers. Many callers are JsonCpp value/writer/parser helpers, but the code is not NexusTK feature logic and should not become a product source module.

The rebuilt project should express the source-level JsonCpp and NexusTK uses of `std::string`, `std::map`, `std::set`, streams, and exceptions. Equivalent helper code should come from the selected compiler/runtime and template instantiation, not from hand-ported decompiler output.

## Evidence

- IDA MCP function inventory on 2026-05-27 reports 63 modeled functions from `sub_4361B0` at `0x004361b0` through `sub_439CF0` ending at `0x00439df9`.
- The range contains standard-library diagnostics and exception text, including `ios_base::badbit set`, `ios_base::failbit set`, `ios_base::eofbit set`, `map/set<T> too long`, `bad locale name`, and the exception string separator `: `.
- Callers into the early portion are JsonCpp value/writer/parser support functions such as `0x00427310`, `0x00428720`, `0x00428940`, `0x00430040`, `0x00430ae0`, `0x00431130`, `0x004354b0`, `0x004358c0`, `0x00435e10`, and `0x00436010`.
- Other callers are broader bundled/runtime users, including `0x00443200`, `0x004417e0`, and product/library callers that use standard containers or streams. This is expected for Dinkumware template helper code and does not make the helper implementation NexusTK-owned.
- Tail boundary is verified: `sub_439CF0` ends at `0x00439df9`, and bytes `0x00439df9-0x00439e00` are seven `0xcc` alignment bytes before [UID:0000XA][0x00439e00-0x00439ea3.DequeDestroy](by-memory/0x00439e00-0x00439ea3.DequeDestroy.md).

## Boundary Notes

- Start boundary: [UID:0001ZS][0x00434890-0x004361ae.JsonCppOurReaderUnicodeAndBuiltStyledStreamWriter](by-memory/0x00434890-0x004361ae.JsonCppOurReaderUnicodeAndBuiltStyledStreamWriter.md) ends at the raw JsonCpp `BuiltStyledStreamWriter::hasCommentForValue` body and the following two-byte padding at `0x004361ae-0x004361b0`; `sub_4361B0` starts at `0x004361b0`.
- End boundary: `sub_439CF0` ends at `0x00439df9`; `0x00439df9-0x00439e00` is confirmed `0xcc` padding; [UID:0000XA][0x00439e00-0x00439ea3.DequeDestroy](by-memory/0x00439e00-0x00439ea3.DequeDestroy.md) starts at `0x00439e00` and is project `DequeDestroy` code. - This page intentionally records support-code classification, not exact source names for every template helper. Exact per-helper Dinkumware names can be refined later if needed, but the rebuild action remains the same.

## Rebuild Decision

Ignore this as a NexusTK source-reconstruction target. Preserve normal C++ standard-library usage in the source that calls it and let the selected MSVC-era toolchain/runtime instantiate equivalent support code.
