## Behavior

This private static method maps Windows structured-exception codes to TCHAR diagnostic strings for the crash report. Under the NexusTK Unicode build, the 22 known cases return direct wide literals and the generic Win32/TCHAR source resolves to the observed W APIs and UTF-16 storage.

For unrecognized codes, it calls `FormatMessageW` with the module returned by `GetModuleHandleW(L"NTDLL.DLL")`, then returns shared static `TCHAR[512]` storage at `0x0069af28`. The storage is process-lifetime, mutable, overwritten by each unknown-code call, non-reentrant, and not thread-safe. The code intentionally does not test `FormatMessage`'s return value, so failure can expose an empty or previously formatted buffer.
