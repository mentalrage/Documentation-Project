## Registry Semantics

The helper queries:

```text
HKEY_LOCAL_MACHINE\SOFTWARE\Nexon\Kingdom of the Winds\<current-directory>\Type
```

It treats `Type` as a registry value name, not as a C++ type name. The result is accepted only when `RegQueryValueExW` succeeds, `valueType == REG_DWORD`, and `valueSize == sizeof(DWORD)`. The return value is the low byte of `typeValue`; missing, inaccessible, wrong-type, or wrong-size data returns `0`. The binary does not check the return value of `GetCurrentDirectoryW`, so the first-draft C++ intentionally mirrors that behavior.
