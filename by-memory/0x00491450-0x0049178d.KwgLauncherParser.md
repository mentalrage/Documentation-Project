This source-facing helper is currently best named `ParseKornetWorldLauncher(RegistryConfig *config)`. Unlike the host/port launcher parsers, this mode uses the fixed UTF-16 host `game.kornetworld.com` at `0x0061730c`. It then writes fixed port `0x2328` / decimal `9000` (Verified with int_convert.py) to `config + 0x2916c4`, sets `config + 0x2916ca` / `m_startupReady` to `1`, and sets state byte `config + 0x28de28` / `m_startupConnectionMode` to `5`.
