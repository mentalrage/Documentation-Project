## Behavior

This helper skips the executable path, tokenizes the remaining command line on spaces with `_wcstok_s`, and requires exactly five non-null tokens before accepting the parse. The first token must case-insensitively match UTF-16 `/KWG` at `0x0061729c`; the remaining four tokens are converted into four startup payload buffers.

Unlike the host/port launcher parsers, this mode uses the fixed UTF-16 host `game.kornetworld.com` at `0x0061730c`. It copies that host into `param_1 + 0x2915c4` with `_wcscpy_s`, converts it to an ANSI scratch buffer with `WideCharToMultiByte`, resolves it with `gethostbyname`, and copies four resolved address bytes into `param_1 + 0x2915b4`.

On success it converts the four launcher-provided payload tokens into `param_1 + 0x28d9e0`, `param_1 + 0x28d9f0`, `param_1 + 0x28da00`, and `param_1 + 0x28da10`; the first three buffers use a `0x10` byte output cap and the last uses `0x100`, with explicit NUL termination after each conversion. It then writes fixed port `0x2328` (`9000`) to `param_1 + 0x2916c4`, sets `param_1 + 0x2916ca` to `1`, and sets state byte `param_1 + 0x28de28` to `5`.

Malformed token streams or selector mismatches format the UTF-16 message `이 버전의 바람의 나라는 KornetWorld 전용입니다. 입력정보에 오류가 있습니다.` and show it through `MessageBoxW`, followed by `PostQuitMessage(0)` and `__loaddll(0)`. DNS failure uses the host-specific UTF-16 format string `이 버전의 바람의 나라는 KornetWorld 전용입니다. 입력정보 "%s" 에 오류가 있습니다.` before the same exit path.
