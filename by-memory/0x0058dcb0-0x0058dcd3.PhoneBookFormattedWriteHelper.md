# 0x0058dcb0-0x0058dcd3 PhoneBook Formatted Write Helper

## Status

- Disposition: ignored/runtime helper for NexusTK source reconstruction.
- Entity kind: static MSVC/UCRT `fwprintf`-style wide `FILE*` formatted-output wrapper.
- Confidence: very strong for exact range, call sites, CRT stdio-options/common-backend pattern, and non-PhoneBook ownership.
- C++ reconstruction: intentionally blank. Product source should call normal CRT formatted output at the caller level, for example `fwprintf(file, L"%s\n", entry->name);`.

## Function Role

This helper initializes a `va_list`, obtains local CRT stdio option storage through `0x0041b9a0`, and forwards the wide `FILE*` formatting operation to the common formatted-output backend at `0x005d2208`. It is retained compiler/runtime support, not handwritten `PhoneBookDialog` or `PhoneBookListPane` source logic.

The existing page filename is retained for continuity, but the best conceptual name is `CrtWideFilePrintfWrapper` or `MsvcWideFilePrintfWrapper`.

## IDA MCP Evidence

Checked on 2026-05-26 and rechecked on 2026-06-03:

- `lookup_funcs 0x0058dcb0` reports `sub_58DCB0`, size `0x23`, with half-open end `0x0058dcd3`; `0x0058dcd3-0x0058dce0` is `0xcc` padding.
- Modeled callers are the two [UID:0000AD][PhoneBookDialog](by-class/PhoneBookDialog.md) `SavePhoneBook` calls at `0x0058ce94` and `0x0058cea6`.
- Raw xrefs also exist at `0x0058d0db` and `0x0058d0ed`. B001 reanalysis identifies these as calls in a raw no-IDA-function save helper at `0x0058d090-0x0058d10e`, not in the `RenderEntry` neighborhood.
- Call-site disassembly shows `SavePhoneBook` passing a file handle, `L"%s\n"` format, and phone-book row name/number fields at `entry + 0x02` and `entry + 0x82`.
- Live decompile shows a varargs wrapper that calls `0x0041b9a0` for local stdio options and forwards to `0x005d2208`.

B001 reanalysis on 2026-06-17 added the source-quality interpretation:

- [UID:0000WO][0x0041b9a0-0x0041b9de.CrtStdioCommonSprintfGlue](by-memory/0x0041b9a0-0x0041b9de.CrtStdioCommonSprintfGlue.md) already documents the local-options accessor as CRT/UCRT stdio support.
- Sibling function `0x00579780` uses the same local-options plus common-backend shape but obtains stdout through `__acrt_iob_func(1)`, matching a wide stdout formatter. This helper is the wide `FILE*` formatter form.
- The body has no phone-book state, no row-specific behavior, and no feature-specific branch.

## Ownership Decision

Keep `CANONICAL_OWNER:NONE`, `RECONSTRUCTABLE:FALSE`, and blank `EMITTER_UIDS`. Reconstructed PhoneBook source should not emit this wrapper body; callers should use normal CRT-style formatted output.

Rejected alternatives:

- `PhoneBookDialog::WriteWideFormattedLine` or `PhoneBookFwprintf`: rejected because the body is a CRT stdio wrapper and has no PhoneBook-specific state.
- `PhoneBook` source ownership: rejected because retaining the helper as source would preserve compiler/runtime glue rather than the original source intent.
- `RenderEntry` dependency: rejected because the raw calls at `0x0058d0db` and `0x0058d0ed` are in the raw save helper span `0x0058d090-0x0058d10e`; `PhoneBookListPane::RenderEntry` uses drawing/text helpers instead.
