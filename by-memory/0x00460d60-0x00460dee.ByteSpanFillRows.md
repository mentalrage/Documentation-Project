## Reconstructed C++ Candidate

```cpp
void ByteSpanFillRows(unsigned char* dst, int dstPitchBytes,
                      unsigned char value, int widthBytes, int rowCount)
{
    const int blockBytes = (widthBytes / 8) * 8;
    const int tailBytes = widthBytes - blockBytes;

    if (blockBytes > 0)
        ByteSpanFill8Blocks(dst, dstPitchBytes, value, blockBytes / 8, rowCount);

    dst += blockBytes;

    for (int y = 0; y < rowCount; ++y)
    {
        unsigned char* row = dst;
        for (int x = 0; x < tailBytes; ++x)
            row[x] = value;

        dst += dstPitchBytes;
    }
}
```

The compiled tail uses dword and byte string stores instead of the simple scalar loop shown above. The loop is equivalent source-level C++ and avoids encoding compiler string-instruction artifacts as source requirements.
