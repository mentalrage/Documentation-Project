## Behavior

`0x00556070` tests two fixed rectangles:

- row 0: y `6..22`
- row 1: y `22..38`
- width: x `0..79`

It returns the row index or `-1`.

`0x00556100` sends the selected vote:

- converts the stored wide target name to a multibyte string;
- writes opcode `0x46`, submode `0`, name length, name bytes, and the promote/demote flag;
- sends the packet through the global packet sender path.
