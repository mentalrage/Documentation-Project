## Behavior

This helper maps Windows structured-exception codes to wide diagnostic strings for the crash report. The switch covers common status values including breakpoint, single-step, access violation, in-page error, illegal instruction, noncontinuable exception, stack overflow, invalid handle, and floating-point/integer arithmetic faults.

For unrecognized codes, it calls external message-formatting helpers and returns a shared wide buffer rather than one of the static string pointers.
