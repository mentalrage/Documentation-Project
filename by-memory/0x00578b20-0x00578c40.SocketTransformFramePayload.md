## Behavior

The method copies the leading payload byte, reads the packet sequence/key byte from `input[1]`, derives nonce state from the encrypted tail bytes, and transforms `inputLength - 5` payload bytes when the transformed payload is non-empty.

The transform sequence is:

1. Calls [UID:0001I0][0x00575cb0-0x00575d83.PacketNonceInitialization](by-memory/0x00575cb0-0x00575d83.PacketNonceInitialization.md) using tail bytes decoded with constants `0x24`, `0x74`, and `0x21`.
2. Calls [UID:0001I5][0x00578e00-0x00578e94.XorTransformBuffer](by-memory/0x00578e00-0x00578e94.XorTransformBuffer.md) with the dword LUT entry selected by the sequence/key byte.
3. Walks `g_packetTransformStride`-sized blocks and applies the LUT entry for each block index except the sequence/key byte.
4. Applies the primary table [UID:0000TG][PacketTransformGlobals](by-global/PacketTransformGlobals.md) or alternate table [UID:0000TG][PacketTransformGlobals](by-global/PacketTransformGlobals.md), depending on the method's alternate-key flag.
5. Writes a null terminator and returns `inputLength - 1`; very short transformed payloads terminate at `inputLength - 4`.

## Generated Output Caveats

Current `source-3/simroot_v2/class_Socket.cpp` still emits a `WAVE3 OMITTED METHOD BODY` marker for this method, but a generated body follows the marker. Treat that marker/body mismatch as a data-generation caveat. The body also declares [UID:0001I5][0x00578e00-0x00578e94.XorTransformBuffer](by-memory/0x00578e00-0x00578e94.XorTransformBuffer.md) as `extern void` with dword pointer arguments, while the recovered helper body and IDA evidence support a byte-returning, byte-buffer-facing prototype with dword key-word reads.
