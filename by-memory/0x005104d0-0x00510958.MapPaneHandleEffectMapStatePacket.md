## Day/Night Arithmetic

- Scale code is the low-byte quotient `dayNightAdjustment / 100`: zero maps to `1.0f`; nonzero maps to `(code - 1) * 0.25f`.
- Bias code is the low-byte remainder `dayNightAdjustment % 100`: zero maps to `0.0f`; values 1..15 map to `(code - 16) / 15.0f`; values 16 and above map to `(code - 16) * 0.0625f`.
- Adjusted brightness is `(s_dayNightBrightnessByHour[m_dayNightHour] - 0.5f) * scale + 0.5f + bias`, clamped to `[0.0f,1.0f]`.
- Tint is `m_dayNightTintCurveScale * (brightness - m_currentDayNightBrightness)^2 + m_dayNightTintCurveBase` and is passed as the second argument to `SetDayNightFadeTarget`. Historical duration terminology is disproved.
