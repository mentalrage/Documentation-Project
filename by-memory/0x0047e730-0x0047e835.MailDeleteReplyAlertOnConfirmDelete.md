## Behavior

This method performs local deletion after the user confirms a mail reply deletion prompt. In delete-all mode it removes the selected reply rows from the active mail reply list and refreshes the owning mail dialog. In single-delete mode it finds the previous mail dialog, removes the reply row matching the current reply id when present, refreshes that dialog, and pops the current alert/session view.
