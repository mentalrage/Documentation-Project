## Behavior

Updates the scrollbar value while the thumb is dragged. It computes the thumb rect, clamps the cursor-derived thumb position inside the track, converts that position into a new scroll value, and notifies the owning list pane when the value changes.

Observed state flow:

- reads the old scroll value from `this + 0xfe`;
- gets the current thumb rect through [UID:0002D7][0x0041e4f0-0x0041e777.FittingRoomScrollPaneGetPartRect](by-memory/0x0041e4f0-0x0041e777.FittingRoomScrollPaneGetPartRect.md) with part id `2`;
- uses orientation flag `this + 0xfc` to choose horizontal or vertical math;
- uses drag-offset point fields at `this + 0x108` and `this + 0x10c`;
- clamps against available track space and current scroll range `this + 0x100`;
- if the value changes, updates the parent/list state, synchronizes the embedded scrollbar value, calls `0x0041ee10`, and invalidates the parent pane bounds.

void FittingRoomScrollPane::UpdateThumbDragScroll(int x, int y)
{
    const int oldValue = m_value;
    Rect thumb;
    GetPartRect(ThumbPart, thumb);

    int newValue;
    if (m_horizontal)
        newValue = PositionToValue(x - m_dragOffset.x, thumb);
    else
        newValue = PositionToValue(y - m_dragOffset.y, thumb);

    newValue = Clamp(newValue, 0, m_range);
    if (newValue == oldValue)
        return;

    SetOwnerScrollValue(newValue);
    NotifyOwnerScrollChanged();
    InvalidateOwner();
}
