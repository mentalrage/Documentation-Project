## Behavior

Updates the fitting-room scrollbar value from the current active-part cursor position. The primary source role is thumb-drag scrolling, but [UID:0002D5][0x0041e8b0-0x0041e970.FittingRoomScrollPaneProcessActivePart](by-memory/0x0041e8b0-0x0041e970.FittingRoomScrollPaneProcessActivePart.md) also calls this helper for non-thumb active parts after a fresh hit-test still matches the active part. It computes the current thumb rectangle, clamps the cursor-derived position inside the available track, converts that position into a new scrollbar value, and notifies the owning [UID:000053][FittingRoomListPane](by-class/FittingRoomListPane.md) when the value changes.

Observed state flow:

- reads the old scroll value from `this + 0xfe` and stores it for the final change test;
- gets the current thumb rect through [UID:0002D7][0x0041e4f0-0x0041e777.FittingRoomScrollPaneGetPartRect](by-memory/0x0041e4f0-0x0041e777.FittingRoomScrollPaneGetPartRect.md) with part id `2`;
