## Behavior

This helper writes the selector-row rectangle for a row index:

- row `-1`: writes an empty `(-1, -1, -1, -1)` rectangle;
- otherwise: writes `(0, row * 16 + 6, 67, row * 16 + 22)`.

It is used by the paint method to draw the hover/pressed highlight frame around the current row.

Approximate C++ shape:

```cpp
void GetChattingVarietySelectItemRect(int row, Rect& out)
{
    if (row == -1)
        out.Set(-1, -1, -1, -1);
    else
        out.Set(0, row * 16 + 6, 67, row * 16 + 22);
}
```
