## Behavior

This worker formats ANSI text into the pointer-backed ref-counted string buffer. It starts with a capacity estimate of `strlen(format) + 64`, obtains CRT formatting options through `0x0041b9a0`, ensures a unique buffer with enough capacity, and retries with a doubled capacity when `__stdio_common_vsnprintf_s` reports truncation/failure.

After a successful format, it detaches shared storage if the refcount is greater than one, copies the content to a private buffer, releases the old storage, and stores the final character count using `strlen`.
