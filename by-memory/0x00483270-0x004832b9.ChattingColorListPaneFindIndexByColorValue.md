## Behavior

This helper returns the first swatch row whose stored color value equals the input value. If the list is empty or no row matches, it returns `0`.

Approximate shape:

```cpp
int ChattingColorListPane::FindIndexByColorValue(int colorValue) const
{
    for (int i = 0; i < GetCount(); ++i) {
        if (GetItem(i).colorValue == colorValue)
            return i;
    }
    return 0;
}
```
