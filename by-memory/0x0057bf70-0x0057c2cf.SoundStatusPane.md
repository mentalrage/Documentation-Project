## Behavior Summary

The constructor registers the singleton, installs the vtable set, and computes a 114-by-12 status region near the lower-right edge of the current screen. `HandleSoundHotkeys` accepts only event type `8`, decodes the keyboard character from event bytes `8` and `266`, and handles two shortcuts:

- `modifier == 2` plus lowercase `m`: toggles sound effects, then writes the persisted sound byte at `g_pConfig + 0x28de48`.
- `modifier & 2` plus uppercase `M`: toggles MIDI/music playback and calls paired `SoundManager` music enable/disable methods.

After a successful toggle, the handler subtracts `0xa0` from the subobject pointer and calls the owner pane repaint callback with the owner bounds rectangle. `RefreshSoundStatusText` resets selector/page fields, reads `SoundManager` music/sound state, formats a fixed 128-wide-character stack buffer, and sets the status text.
