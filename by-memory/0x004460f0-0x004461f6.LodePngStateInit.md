## Function Role

IDA models this as `sub_4460F0`. It matches upstream `lodepng_state_init` with the small default-initializer callees inlined or flattened by the compiler. The function initializes the decoder, encoder, raw color mode, PNG info, and default error state for a `LodePNGState` / `lodepng::State` object.

Observed default writes include:

- decoder flags enabled by default;
- encoder zlib/compression defaults such as method `8`, window size `2048`, min match `3`, and nice match `128`;
- encoder filtering/default conversion settings, including palette-zero filtering and auto-convert enabled;
- raw and PNG color defaults of RGBA color type `6` and bit depth `8`;
- state error initialized to `1`.
