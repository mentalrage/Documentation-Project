## Behavior

This helper fills a DWORD slot range with a single source value. The first argument is the destination start, the second is an end pointer/address, and the third points at the DWORD fill value. When `begin <= end`, it computes the slot count as `(end - begin + 3) >> 2`; if `begin > end`, it treats the range as empty.

For non-empty ranges, the helper copies the fill value into each destination DWORD. The live disassembly shows a bulk path for counts of four or more when the source value pointer is outside the destination range, using `rep stosd` for the aligned block, followed by the scalar tail loop. If the source pointer overlaps the destination range, or if fewer than four slots are requested, it uses only the scalar copy loop.
