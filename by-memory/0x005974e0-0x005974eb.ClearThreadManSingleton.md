## Behavior

This tiny helper clears [UID:0000SH][g_pThreadMan](by-global/g_pThreadMan.md) by writing `0` to the exact `ThreadMan *` item. The source-level singleton state is reconstructable through explicit `Singleton<ThreadMan>` specializations, but this standalone 11-byte range is reached only from the constructor unwind map and must not be emitted as a handwritten helper.

The same global is also cleared in the raw ordinary destructor and scalar deleting destructor. All three clears are compiler lowering of reverse `Singleton<ThreadMan>` base destruction: normal destruction, constructor unwind, and deleting destruction. This range is specifically the retained constructor-unwind action.

Do not introduce a `ThreadMan::ClearSingleton` or similar source method for this range. Source reconstruction expresses the clear in `Singleton<ThreadMan>::~Singleton()`; this exact helper is compiler/EH glue generated when the already-constructed empty base must unwind.
