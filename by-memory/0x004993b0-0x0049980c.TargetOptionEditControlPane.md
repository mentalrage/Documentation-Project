## Evidence

- Live IDA `lookup_funcs` on 2026-06-05 confirms local modeled functions at `0x004993b0` (`0x52` bytes), `0x00499410` (`0x1f`), `0x00499430` (`0x224`), `0x00499660` (`0x5`), `0x00499670` (`0xfd`), and `0x00499770` (`0x9d`). `0x00499810` is not a function.

- The constructor stores an option-mode word-sized value at the control payload field following the inherited pane/control state and two selection bytes immediately after it; the dialog constructor supplies those bytes from config-backed target-option values.
- Paint reads the `On` config style entries for selected and unselected buttons, prepares draw state through shared control helpers, selects `ARROW` or `SHIFT+ARROW` for the mode caption, draws `USER` and `MONSTER`, and paints two button rectangles at x ranges `110-130` and `200-220`.

- Hit testing is side-effect-free and returns `0` for the first rectangle, `1` for the second, and `-1` outside both.
- The scalar deleting destructor wrapper at `0x0049b740-0x0049b794` restores the three TargetOption vtables, calls the shared pane teardown at `0x00544580`, and frees the object only for the normal deleting flag path. Two adjustor thunks at `0x0049b045` and `0x0049b050` jump to it.
