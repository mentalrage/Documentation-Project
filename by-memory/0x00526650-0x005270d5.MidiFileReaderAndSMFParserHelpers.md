## Behavior

This island is the low-level Standard MIDI File reader used by the WinMM MIDI playback pipeline. It supports two backing sources:

- a memory/object adapter at `this + 0x18`, used through virtual read/seek/tell/open/close-style slots; and
- a Win32 file handle stored at `this + 0x2c`.

The helper set reads `MThd`/`MTrk`-style track content, maintains per-track 40-byte records, decodes variable-length quantities, handles running status, allocates payloads for SysEx/meta events, marks end-of-track, and emits WinMM stream event records. Tempo meta events update the cached microseconds-per-quarter timing state and produce stream tempo records.
