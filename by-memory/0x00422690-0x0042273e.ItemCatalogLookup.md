## Behavior Notes

Both methods use a category tree rooted at `this + 0x220` and compare the found node against the sentinel at `this + 0x224`. Category nodes carry a vector triplet for item pointers; the helpers only count or index into that vector.

Current evidence places `ItemCatalog` as an embedded fitting-room item-shop catalog facade at `g_pFittingRoomDialog + 0x504`. It should not be treated as a general client-wide item database unless later callers appear outside the fitting-room/shop browsing path.

The methods call the category-node lookup helper at `0x00423810`/related container support, then operate directly on the found node's `itemsBegin` and `itemsEnd` pointers.
