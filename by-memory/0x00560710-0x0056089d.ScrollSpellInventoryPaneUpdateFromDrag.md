It reads the current position at offset `+0xfe`, computes the updated short position from the track span and drag/click coordinates, clamps against the range at `+0x100`, then notifies the owning [UID:0000LU][NewSpellInventoryPane](by-file/NewSpellInventoryPane.md) when the position changes.

The orientation byte at `+0xfc` selects the vertical and horizontal math paths. Both paths use the part-rectangle helper `0x00560290` for the thumb/track rectangle and screen/client offset helpers `0x004a9090` and `0x005447c0` before converting the pointer delta into a scroll word.

The sibling input bridge at `0x00560650` is the only current caller.
