## Behavior

This helper recomputes the spell-inventory scrollbar position from pointer coordinates and scrollbar geometry. It reads the current position at offset `+0xfe`, computes the updated short position from the track span and drag/click coordinates, then notifies the owning [UID:0000LU][NewSpellInventoryPane](by-file/NewSpellInventoryPane.md) when the position changes.

The owner callback call is `0x0057d360`, reached through a virtual owner lookup at vtable slot `+0x1c`, with arguments `(orientation, oldPosition, newPosition)`.
