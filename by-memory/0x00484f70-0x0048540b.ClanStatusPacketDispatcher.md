## Behavior

This handler reads the packet pointer from event/message payload offset `+0x0c` and rejects packets whose first byte is not `0x43`. It then switches on the second byte:

- case `0`: forwards to [UID:00010B][0x004842b0-0x00484a50.ClanAttributePacketParser](by-memory/0x004842b0-0x00484a50.ClanAttributePacketParser.md).
- case `1`: forwards to [UID:00021S][0x004877d0-0x00488594.ClanStatusPacketDialogHandlers](by-memory/0x004877d0-0x00488594.ClanStatusPacketDialogHandlers.md) subrange `0x004877d0`.
- case `2`: forwards to [UID:00021S][0x004877d0-0x00488594.ClanStatusPacketDialogHandlers](by-memory/0x004877d0-0x00488594.ClanStatusPacketDialogHandlers.md) subrange `0x004879e0`.
- case `3`: decodes a variable-length name string and opens [UID:00002I][ClanLeaveConfirmDialog](by-class/ClanLeaveConfirmDialog.md).
- case `4`: opens [UID:00002A][ClanDepMoneyInputDialog](by-class/ClanDepMoneyInputDialog.md) when `packet[2] == 0`; accepts `packet[2] == 1` without opening a dialog.
- case `5`: opens [UID:000029][ClanDepItemDialog](by-class/ClanDepItemDialog.md) when `packet[2] == 0`.
- case `6`: forwards to [UID:00021S][0x004877d0-0x00488594.ClanStatusPacketDialogHandlers](by-memory/0x004877d0-0x00488594.ClanStatusPacketDialogHandlers.md) subrange `0x00487ea0`.
- case `7`: opens [UID:00002D][ClanExpelNameInputDialog](by-class/ClanExpelNameInputDialog.md) when `packet[2] == 0`; accepts `packet[2] == 1`.
- case `8`: opens [UID:00002M][ClanSummonNameInputDialog](by-class/ClanSummonNameInputDialog.md) when `packet[2] == 0`; accepts `packet[2] == 1`.
- case `9`: opens [UID:000023][ClanAppearNameInputDialog](by-class/ClanAppearNameInputDialog.md) when `packet[2] == 0`.
- case `10`: opens [UID:000028][ClanChangeNameInputDialog](by-class/ClanChangeNameInputDialog.md) for `packet[2] == 0`, [UID:000027][ClanChangeInputDialog](by-class/ClanChangeInputDialog.md) for `packet[2] == 1`, and accepts `packet[2] == 2`.
- case `11`: opens [UID:00002O][ClanWidMoneyInputDialog](by-class/ClanWidMoneyInputDialog.md) when `packet[2] == 0`; accepts `packet[2] == 1`.
- case `12`: opens [UID:00002N][ClanWidItemDialog](by-class/ClanWidItemDialog.md) when `packet[2] == 0`; accepts `packet[2] == 1`.

The handler adjusts `this` by `-0xa0` before calling `ClanStatusPane` member helpers, matching the secondary-vtable slot at `0x006155cc`.
