# DATFile Translation-Unit Retained Wide ReadLine Duplicate

## Disposition

`[0x0049c570,0x0049c5fe)` is a compiler-retained COMDAT/inline duplicate of inherited `File::ReadLine(StringBaseW&)` at `[0x004b1340,0x004b13ce)`. The two bodies are byte/behavior identical, each has zero inbound callers, and live `DATFile::ReadAllLines` contains the same base helper inlined. It is not a second authored DATFile overload.
