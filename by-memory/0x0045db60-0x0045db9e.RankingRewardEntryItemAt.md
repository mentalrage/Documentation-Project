## Behavior

This helper returns a pointer to a nested 520-byte reward-item row by index. It uses the vector begin/end pointers at reward-entry offsets `+0x224` and `+0x228`, computes the current item count by dividing `(end - begin)` by `0x208`, and returns null if the requested index is not below that count.

Equivalent reconstruction shape:

```c
RankingRewardItem* RankingRewardEntry::ItemAt(int index)
{
    char* begin = itemVectorBegin;
    char* end = itemVectorEnd;
    int count = (end - begin) / 0x208;
    if (count <= index)
        return 0;
    return reinterpret_cast<RankingRewardItem*>(begin + index * 0x208);
}
```

There is no explicit negative-index check in the recovered body, so caller-side index validation should be verified before finalizing the public API shape.

Live IDA shows the reward-info paint method performing the same nested item-vector traversal inline instead of calling this standalone body: it computes `(*(_DWORD *)(entry + 552) - *(_DWORD *)(entry + 548)) / 520`, iterates a non-negative local item index from zero, forms each row as `begin + index * 520`, reads icon id at row `+516`, palette/index byte at row `+518`, and formats the item label with the row text plus quantity at row `+512`.
