# 0x0061fbac-0x0061fbdc WorkThread Notification Vtable Data

## Range

- Address range: `0x0061fbac-0x0061fbdc`
- Entity kind: `vtable-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: `source-declared/generated-binary`

## Summary

This exact child range contains the complete-object-locator pointers and `LObject`-compatible vtables for the three `MiscWorkThread` notification payload classes: `brdir::Notification`, `httpget::Notification`, and `ncauth::Notification`. Each object vptr points to the first virtual slot after a preceding RTTI locator dword; the vtable then contains the scalar deleting destructor slot plus inherited `LObject` runtime-class/no-op virtual slots.

The range starts at the `brdir::Notification` locator immediately after the `MiscWorkThread` vtable region and ends before the `Baram` literal at `0x0061fbdc`.
