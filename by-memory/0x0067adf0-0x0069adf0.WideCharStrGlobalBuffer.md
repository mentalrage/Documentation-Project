## Storage

`0x0067adf0-0x0069adf0` is a 128 KiB global UTF-16 scratch buffer, named `WideCharStr` by IDA. The observed access pattern treats it as `WCHAR[0x10000]`. Live xrefs support Clan ownership because the only real code user of the buffer base is `sub_4877D0`, reached from the clan status packet dispatcher at `0x00484fdb`.

## Evidence

- 2026-06-14 live IDA byte review reports `0x0067adf0-0x0069adf0` in `.data`, size `0x20000` / 131,072 bytes, or `0x10000` / 65,536 wide characters. Current sampled bytes at the start and tail of the buffer are zero-initialized.
- IDA names `0x0067adf0` as `WideCharStr`. `lookup_funcs` reports `0x0067adf0` and `0x0069adf0` are not functions.

- 2026-06-14 decompilation of `sub_484F70` confirms packet family `C`, subtype `1`, is the caller that dispatches to `sub_4877D0`.
