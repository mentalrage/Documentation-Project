## Behavior Summary

The constructor registers the pane singleton, initializes the current hour to unset, and installs the class vtable set. The hour update handler receives a subobject pointer, subtracts `0xa0` to reach the owner, and updates `owner+0xf8` only when the payload's first byte is `0x20`. On a changed hour it invalidates the owner draw region at `owner+0x44`.

The mouse handler processes event type `4`. It closes any active [UID:0000D6][SimpleHelpPane](by-class/SimpleHelpPane.md) singleton with delete flag `1`, hit-tests the pane region, fetches localized string id `0x4d`, formats `"%s : %02d"` with the current hour, allocates a 252-byte `SimpleHelpPane`, and initializes it at the mouse coordinates for 5000 ms.

The paint handler reads the current hour and branches on `byte_66DA97`. In new/current mode, unset hour sets color `0` and invalidates; otherwise it loads `TIME.EPF`, selects `word_66DB04[(hour / 2) % 12]`, and draws with `TIME.PAL`. In old mode, unset hour sets color `0x80`; otherwise it loads `TIME.EPD` and draws through the old draw callback.
