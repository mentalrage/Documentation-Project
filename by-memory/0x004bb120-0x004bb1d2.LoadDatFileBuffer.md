## Behavior

The helper wraps the full [UID:00003G][DATFile](by-class/DATFile.md) lifecycle for callers that need a plain memory buffer:

1. Initializes allocation state, then constructs a local `DATFile`.
2. Opens the supplied DAT-backed path.
3. Reads the payload size through `DATFile::GetSize`.
4. Allocates `payloadSize + prefixSize` bytes through the shared buffer allocator.
5. Stores the total allocation size through `outSize` when that pointer is non-null.
6. Zero-fills the prefix when `prefixSize > 0`.
7. Reads the DAT payload at `buffer + prefixSize`.
8. Closes and destroys the local `DATFile`.
