## Behavior

This helper frees and clears a handler-record vector containing 28-byte records.

Observed behavior from IDA MCP:

- Reads the vector `begin` pointer and returns immediately when it is null.
- Computes the allocation size from the `capacity_end - begin` span in 28-byte records.
- For large allocations, validates the allocation header before freeing the true base pointer.
- Frees the buffer through the shared deallocator.
- Clears `begin`, `end`, and `capacity_end` to zero.
