## Behavior

This helper frees and clears a handler-record vector containing 28-byte records.

2026-06-06 live IDA evidence shows:

1. Reads the vector `begin` pointer from `this + 0x00` and returns immediately when it is null.
2. Reads `capacity_end` from `this + 0x08` and computes the allocated span in 28-byte records.
3. Reconstructs the byte count as `record_count * 28` and treats allocations of `0x1000` bytes or larger as large aligned allocations.
4. For large allocations, reads the saved raw base pointer from `begin[-1]` and validates `begin - raw_base - 4 <= 0x1f`; failure calls `__invalid_parameter_noinfo_noreturn`.
5. Frees the direct small pointer or saved large raw base through `sub_5C7526`, passing the computed byte count.
6. Clears the vector header pointers at `this + 0x00`, `this + 0x04`, and `this + 0x08`.
