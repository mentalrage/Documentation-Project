## Behavior

`0x0049d190` tears down the `_DATFileMgr` embedded name-index resolver:

- Checks the resolver bucket/vector allocation at offset `+0x0c`.
- If allocated, applies the MSVC-style large-allocation base-pointer check using capacity at `+0x14`, then frees the allocation through `0x005c7526`.
- Clears bucket/vector begin/end/capacity at `+0x0c`, `+0x10`, and `+0x14`.
- Resets the circular list sentinel held in the resolver state.
- Sets the indexed-entry count to zero.
- Walks each entry node, releases the shared wide-string key through `0x00582b70`, and frees the node.
- Frees the sentinel node.

The method is called from both the raw ordinary `_DATFileMgr` destructor at `0x0049c7e8` and the modeled `_DATFileMgr::DeletingDestructor` at `0x0049d462`.
