## Behavior Summary

`SpelledPane` is a reusable child text pane for look/status and system-message views. The constructor installs four SpelledPane vtable views, initializes the TextEditPane-like base/child state, and is reached by SelfLookPane, SelfLookPane2, and system-message construction paths.

The entry helpers maintain grouped display rows. The add/update path inserts or refreshes an entry, the remove path erases a matching entry, and the rebuild path formats the grouped entries back into the embedded text pane. The serialized parser uses a stack [UID:0000KQ][LineIterator](by-file/LineIterator.md), calls [UID:000190][0x004f3020-0x004f3060.LineIteratorReadNextLine](by-memory/0x004f3020-0x004f3060.LineIteratorReadNextLine.md), and splits fields with the UTF-16 delimiter [UID:000284][0x0066fe44-0x0066fe4a.SpelledPaneWhitespaceDelimiter](by-memory/0x0066fe44-0x0066fe4a.SpelledPaneWhitespaceDelimiter.md).

Two tiny virtual gates return false, while the tail refresh helper updates entry text/state through a frame-handler-style subobject view and schedules the display refresh path. Destructor and vector support are outside this aggregate and remain documented in the mixed look/group helper islands listed below.
