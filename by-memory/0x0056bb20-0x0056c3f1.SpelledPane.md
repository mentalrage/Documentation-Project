## Behavior Summary

`SpelledPane` is a reusable child text pane for look/status and system-message views. The constructor installs four SpelledPane vtable views, initializes the TextEditPane-like base/child state, and is reached by SelfLookPane, SelfLookPane2, and system-message construction paths.

The entry helpers maintain grouped display rows. The add/update path inserts or refreshes an entry, the remove path erases a matching entry, and the rebuild path formats the grouped entries back into the embedded text pane. Exact child [UID:0004N5][0x0056c0e0-0x0056c2db.SpelledPaneParseAndLoadEntries](by-memory/0x0056c0e0-0x0056c2db.SpelledPaneParseAndLoadEntries.md) clears the serialized parser vector, retains capacity, constructs a 16-byte stack [UID:000078][LineIterator](by-class/LineIterator.md), and calls [UID:000190][0x004f3020-0x004f3060.LineIteratorReadNextLine](by-memory/0x004f3020-0x004f3060.LineIteratorReadNextLine.md) for the first and subsequent rows. UID0000KQ remains the non-source historical family index rather than the generated owner.

The parser stops at the first empty row and skips nonempty rows with no space/tab. It uses the last delimiter to separate the numeric suffix and `FindLastNotOf + 1` to trim the final separator run from the text prefix. All-delimiter input yields an empty prefix. Invalid or empty numeric suffixes use existing `ToLong`/CRT conversion without a new rejection path; the LineIterator-included LF naturally terminates conversion.

The 12-byte local/vector record contains a ref-counted wide String, converted integer, and third scalar. The parser never defines the third stack scalar before copying it in either append path. UID0004N5 therefore deliberately uses default initialization and does not assign the inferred `entry.group`; value initialization would alter the binary. Available capacity copy/share-constructs String and copies both scalars, while full capacity calls [UID:00039O][0x00572fd0-0x00573232.SpelledPaneEntryVectorInsert](by-memory/0x00572fd0-0x00573232.SpelledPaneEntryVectorInsert.md). Source-level `push_back` preserves both paths without emitting STL/compiler internals.

[UID:000284][0x0066fe44-0x0066fe4a.SpelledPaneWhitespaceDelimiter](by-memory/0x0066fe44-0x0066fe4a.SpelledPaneWhitespaceDelimiter.md) is exact writable `.data` backing storage for one parser-local `static wchar_t` array. Its target page emits a position-`40` covered-by comment; UID0004N5 alone declares the array at position `50`, preventing a file/global duplicate. UID000190's method body remains owned by [UID:000078][LineIterator](by-class/LineIterator.md); this aggregate is parser source context, not ownership transfer.

B006's 2026-06-25 recheck of [UID:0002RF][0x0056b950-0x0056b9ef.SelfLookPaneSpelledTextDispatch](by-memory/0x0056b950-0x0056b9ef.SelfLookPaneSpelledTextDispatch.md) confirms a current `SelfLookPane` packet-text consumer: the helper reads a length-prefixed text field, reads an optional big-endian value, loads the embedded child at `SelfLookPane::this+0xfc`, calls `0x0056be20` when the value is zero/absent, and calls `0x0056bca0` when the value is nonzero.
