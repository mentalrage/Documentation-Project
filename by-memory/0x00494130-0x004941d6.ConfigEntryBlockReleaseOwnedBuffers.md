## Behavior

This helper releases heap-owned buffers from a `ConfigEntryBlock`-like structure and resets the active count/state fields.

IDA decompilation shows:

- if the input pointer is non-null, read the active count at offset `+0x300`;
- when the count is positive, iterate entries starting at offset `+0x4` / `+0x8`;
- free up to three owned pointer fields per entry;
- clear those pointer fields after freeing;
- advance by `0x18` bytes per entry;
- reset the count at `+0x300` and a state byte at `+0x304`.

The null-input else branch writes through absolute offsets `0x300` and `0x304` in the decompiler output, which should be treated as an artifact of the null path and reviewed before any final source reconstruction.
