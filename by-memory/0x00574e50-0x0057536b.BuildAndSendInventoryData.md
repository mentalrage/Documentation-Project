## Behavior

This helper builds an outbound opcode `0x77` packet from up to 20 saved config string slots at `g_pConfig + 2691552` through `g_pConfig + 2691632`.

Observed high-level flow:

1. Initialize a local packet buffer and write opcode `0x77` at offset `0`.
2. Walk 20 config string slots, each stored as a pointer-sized string reference.
3. Skip empty strings and insert nonempty unique names into a tree-backed set.
4. Write the unique-name count at packet offset `1`.
5. Walk the same slots again, deduplicate through a second tree, convert each unique wide string to ANSI, and append fixed 13-byte records.
6. Each record starts with marker `0x0c`, followed by 12 copied bytes of narrow string data.
7. If the send-disabled byte at `this + 240206` is clear, allocate `packetSize + 1`, copy the packet, append zero, and dispatch request code `8` through `0x00596960`.
8. Clear both tree containers before returning.

Wave3 now names the config range as friend-name slots and the method as `BuildAndSendFriendNameListSync`. The old inventory wording was a generated-name artifact; caller and config-slot evidence point to a friend/name-list update, not item inventory data.
