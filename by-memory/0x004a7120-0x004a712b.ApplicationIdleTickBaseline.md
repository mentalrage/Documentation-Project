## Behavior

This tiny helper snapshots the current timer tick from [UID:0000SI][g_pTimerMgr](by-global/g_pTimerMgr.md) into the helper state at offset `+0x2c`. `Application::RunMessageLoop` calls it once before entering the wait/message pump loop so the later idle worker can compute elapsed tick slices against a fresh baseline.
