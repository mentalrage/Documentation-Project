# 0x0067ab30-0x0067ab34 g_pEventDispatcher

## Summary

- Address range: `0x0067ab30-0x0067ab34`
- Entity kind: global pointer
- Proposed name: `g_pEventDispatcher`
- Disposition: reconstructable NexusTK global data
- Confidence: strong for address and singleton role

This four-byte `.data` slot stores the active [UID:00004M][EventDispatcher](by-class/EventDispatcher.md) singleton. It is constructed during application startup, consumed by pane/event routing paths, and used by idle scheduling code that lives beside the dispatcher implementation.

- IDA MCP reports 86 direct data xrefs to `0x0067ab30`.
- `EventDispatcher` documentation records the constructor at `0x004a6a80` as the owner that initializes the dispatcher and writes `g_pEventDispatcher`.
- [UID:000142][0x004a6c40-0x004a6cda.ApplicationIdleWorkScheduler](by-memory/0x004a6c40-0x004a6cda.ApplicationIdleWorkScheduler.md) reads `dword_67AB30` and calls dispatcher-adjacent scheduling/traversal helpers.
- Application cleanup/message-loop xrefs include `0x00464b80`, `0x00464cda`, `0x00464deb`, `0x00464e08`, `0x00466535`, and `0x00466690`, matching a process-wide UI event dispatcher rather than a local object.

## Reconstruction Notes
