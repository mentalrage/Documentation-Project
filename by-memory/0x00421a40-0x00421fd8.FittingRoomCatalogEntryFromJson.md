## Behavior

This helper parses one JsonCpp item object into a 0xc0-byte fitting-room category entry. The caller allocates the entry, preinitializes the category id and part-vector triplet, then calls this parser for each JSON array element in one item-shop category.

Confirmed parsed field names include:

- `name`
- `tile`
- `color`
- `items`
- `part`
- `gender`

The function starts by defaulting the item name path to `None`, then performs repeated JsonCpp field lookups and copies values into the entry. It also builds a nested vector of per-part records under the entry tail. The small per-part record lookup helper at [UID:0002E5][0x00421fe0-0x0042201c.FittingRoomCatalogEntryPartLookup](by-memory/0x00421fe0-0x0042201c.FittingRoomCatalogEntryPartLookup.md) reads those records as 6-byte elements.
