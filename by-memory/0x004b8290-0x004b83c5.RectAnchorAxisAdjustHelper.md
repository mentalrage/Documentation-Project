## Behavior

- maps anchor cases into start, center, or end alignment for the axis;
- compares the requested offset against the source/destination span difference;
- modifies the input edge pointers in place to keep the two rectangles aligned/clipped according to the selected anchor band.

Hex-Rays still types the first argument as `int *a1`, but the switch uses the value numerically. Treat it as an integer anchor selector:

| Anchor cases | Axis band | Alignment value used by the helper |

| `2`, `5`, `8` | high/end band | `destinationSpan - sourceSpan` |

The remaining parameters are the signed offset for that axis, low/high pointers for the first rectangle, and low/high pointers for the second rectangle. The helper reads both spans, computes `spanDelta = firstSpan - secondSpan`, then clips or shifts one pair of low/high edge slots depending on where the offset falls relative to the selected alignment band.
