## Behavior Summary

`TabPane::HandleInputEvent` ignores input when the application state byte at `g_pAppMan + 0x13eb1d` is set. Otherwise it resolves a tab action code from the mouse coordinates and dispatches action helpers. Event mode `1` handles action codes `0..5`; event mode `2` handles action codes `0`, `1`, `2`, and `5`.
