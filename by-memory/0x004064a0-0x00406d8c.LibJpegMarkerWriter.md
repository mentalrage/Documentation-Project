# IJG libjpeg Marker Writer `0x004064a0-0x00406d8c`

## Status

- Confidence: strong for `jpeg-6b/jcmarker.c` source-file ownership.
- Proposed owner: [UID:0000KN][LibJPEG](by-file/LibJPEG.md)
- Disposition: third-party static IJG libjpeg code; exclude from NexusTK product files.
- Evidence basis: read-only IDA MCP decompile/callee/function-list checks and source comparison against `jpegsrc.v6b.tar.gz` on 2026-05-25. `wave3.py` was not executed for this pass.

## Range Role

This range is IJG libjpeg's compression marker writer. It emits SOI/JFIF/Adobe/frame/scan/table markers, marker bytes, and file trailer data for JPEG compression.

The range begins at `0x004064a0`, immediately after the `jutils.c` helper cluster, and ends at `0x00406d8c`. The next function at `0x00406d90` is compression master initialization from `jcinit.c`.

## Evidence Notes

- `jinit_compress_master` at `0x00406d90` calls `0x004064a0`, matching stock compression master setup.
- IDA decompilation of `0x004064a0` allocates a marker writer at `cinfo + 332` and installs seven write callbacks, matching the `jcmarker.c` public marker writer struct.
- IDA decompilation of `0x00406c10` emits marker `218` (`SOS`), component count, component selectors, table selectors, and spectral/progressive parameters.
- IDA decompilation of `0x00406d10` emits marker `216` (`SOI`), then writes quant/Huffman tables before ending with marker `217` (`EOI`) in the paired trailer path.

## Ownership Decision

Keep this range in `third_party/libjpeg/jcmarker.c`. It is stock compression-side library code used by the retained JPEG screenshot writer through public IJG APIs.
