## Behavior

This helper fills a caller-provided WinMM MIDI stream buffer from the parsed Standard MIDI File document state. It resumes any partially emitted event stored in the parser scratch globals, chooses the active track with the smallest pending delta time, parses the next track event, converts it to a WinMM stream event record, and advances track/event state until the output buffer is full, parsing fails, or all tracks finish.

The helper is the producer used by the MIDI stream open and callback paths. It sits above the low-level reader/parser helpers documented in [UID:00023B][0x00526650-0x005270d5.MidiFileReaderAndSMFParserHelpers](by-memory/0x00526650-0x005270d5.MidiFileReaderAndSMFParserHelpers.md).

## Detailed Notes

- Uses parser scratch globals such as `dword_69B870`, `dword_69B874`, `dword_69B878`, `dword_69B87C`, and `xmmword_69B880` to preserve partially emitted event state between calls.
- Selects the next track by comparing the pending delta value stored in each 40-byte track record.
- Calls the MIDI event reader at [UID:0002BU][0x00526790-0x005269ea.MidiEventReader](by-memory/0x00526790-0x005269ea.MidiEventReader.md).
- Calls the stream-event encoder at [UID:0002BV][0x005269f0-0x00526ba8.MidiStreamEventEncoder](by-memory/0x005269f0-0x00526ba8.MidiStreamEventEncoder.md).
- Re-primes track state through [UID:0002BY][0x00526da0-0x00526f09.MidiTrackBufferPrimeReset](by-memory/0x00526da0-0x00526f09.MidiTrackBufferPrimeReset.md) when required by the stream-fill state machine.
- Returns negative status codes for parse failure, end-of-stream, or caller buffer exhaustion. These should become named enum-like constants once the surrounding MIDI stream contract is rewritten.
