# IJG libjpeg Input Controller `0x00404a60-0x0040505b`

## Status

- Confidence: strong for `jpeg-6b/jdinput.c` source-file ownership.
- Proposed owner: [UID:0000KN][LibJPEG](by-file/LibJPEG.md)
- Disposition: third-party static IJG libjpeg code; exclude from NexusTK product files.
- Evidence basis: read-only IDA MCP decompile/callee/function-list checks and source comparison against `jpegsrc.v6b.tar.gz` on 2026-05-25. `wave3.py` was not executed for this pass.

## Range Role

This range is IJG libjpeg's decompression input controller. It validates frame/scan dimensions, sets up component sampling geometry, latches quantization tables, and controls marker consumption versus scan-data input.

The range starts at `0x00404a60` with `jinit_input_controller` and ends at `0x0040505b`, just before the JPEG memory-manager range at `0x00405060`.

## Function Mapping

| Address/range | Stock IJG function/family | Evidence |
| --- | --- | --- |
| `0x00404a60-0x00404aa1` | `jinit_input_controller` | Allocates the input controller and installs `consume_input`, `reset_input_controller`, `start_input_pass`, and `finish_input_pass`; source anchor `jdinput.c:361`. |
| `0x00404ab0-0x00404ae9` | `finish_input_pass` | Resets `consume_input` back to marker consumption after scan input completes; source anchor `jdinput.c:271`. |
| `0x00404af0-0x00404c95` | `per_scan_setup` | Computes MCU/component scan layout, handles interleaved/non-interleaved scan setup, and enforces max blocks in MCU; source anchor `jdinput.c:121`. |
| `0x00404ca0-0x00404d4c` | `latch_quant_tables` | Copies quantization table slots into component-local tables when needed; source anchor `jdinput.c:220`. |
| `0x00404d50-0x00404d61` | small input-pass transition helper | Thin helper in the `start_input_pass` / `finish_input_pass` family. |
| `0x00404d70-0x00404e2e` | `consume_markers` | Calls marker reader, handles SOS/EOI state, and starts scan input when required; source anchor `jdinput.c:288`. |
| `0x00404e30-0x0040501c` | `initial_setup` | Validates image dimensions/data precision/component count and computes component downsampled dimensions; source anchor `jdinput.c:39`. |
| `0x00405020-0x0040505b` | `reset_input_controller` | Restores initial marker-consumption state and resets input progress fields; source anchor `jdinput.c:339`. |

## Evidence Notes

- `jpeg_CreateDecompress` at `0x004011b0` calls `0x00404a60`, matching the stock decompressor initialization path.
- `jpeg_read_header` / `jpeg_finish_decompress` call `0x004049c0`, a common API abort/reset helper immediately before this controller cluster.
- IDA decompilation of `0x00404a60` installs function pointers matching the `jdinput.c` public controller vtable.
- IDA decompilation of `0x00404e30` contains the stock image-size, data-precision, component-count, and sampling-factor setup checks.

## Ownership Decision

Keep this range in `third_party/libjpeg/jdinput.c`. Do not attach it to NexusTK image loader or DAT/resource modules.
