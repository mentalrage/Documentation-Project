## Behavior

This method walks the timer queue backward and removes queued events whose owner pointer equals the supplied `TimerHandler` owner and whose event/timer id differs from the supplied id. It is the inverse predicate of `by-memory/0x00597b80-0x00597c99.TimerMgrCancelTimer.md`: preserve the named event id and remove all other pending events for that owner. The historical UID00041F token is intentionally not linked because the current validator registry assigns that token to an unrelated VectorGrowLayer page.

Each matching one-entry range is removed through [UID:0002L6][0x00598290-0x00598471.TimerMgrTimerQueueSpliceTimerRange](by-memory/0x00598290-0x00598471.TimerMgrTimerQueueSpliceTimerRange.md). The generic wrapper at [UID:0001K9][0x00597610-0x00597645.TimerHandlerWrappers](by-memory/0x00597610-0x00597645.TimerHandlerWrappers.md) forwards to this helper for "cancel all except" behavior.
