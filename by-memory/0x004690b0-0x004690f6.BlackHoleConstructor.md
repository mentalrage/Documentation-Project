## Behavior

Constructs the singleton deferred-deletion queue. The body initializes the inherited/embedded `List` storage with pointer-sized entries (`4`) and initial capacity `1024`, installs the `BlackHole` vtable, and stores the singleton pointer in [UID:0000Q8][g_pApplicationCleanupQueue](by-global/g_pApplicationCleanupQueue.md) / `dword_67A74C`.

IDA decompilation contains an impossible-looking `this == -20` branch from the `lea eax, [esi+0x14]` / `test eax,eax` check. Treat that as compiler output around the singleton/list subobject pointer adjustment, not as intentional source logic for a real negative object address.
