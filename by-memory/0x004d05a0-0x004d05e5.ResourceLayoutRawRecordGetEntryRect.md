# 0x004d05a0-0x004d05e5 ResourceLayoutRawRecordGetEntryRect

- Autogen handling: reconstructable, but parent and C++ remain blank because the final source owner is still open between the `ImageLib`/`ResourceLayoutTable` helper family and shared human-image composition callers.

## Behavior

Copies a rectangle from a raw resource-layout record array into the caller's output rectangle, or zeros the output rectangle when the requested index is greater than or equal to the unsigned record count.

IDA MCP decompilation and disassembly on 2026-06-03 show the helper expects:

- `a1[0]` as an entry count;
- `*((DWORD*)a1 + 2)` as a pointer to 24-byte [UID:0000VB][ResourceLayoutEntry](by-item/ResourceLayoutEntry.md)-like records;
- `a2` as the requested frame index;
- `a3` as the 16-byte output rectangle.

If `a2 >= *a1`, it writes a zero rectangle in the order bottom, top, right, left. Otherwise it computes `entryBase + 24 * a2` and copies the first 16 bytes through `movups`. The assembly uses a signed `jge` after zero-extending the 16-bit count, so negative indexes are not rejected by this helper; current documented callers compute nonnegative overlay indexes before calling it.

## Ownership Notes

This helper should stay under the ResourceLayout/ImageLib layout-record family, not the image codec wrapper group. It consumes a raw record-array pointer and an index, not the `g_pEPFLib` registry object directly, and all current call evidence comes from human-image composition paths that already have a materialized overlay/resource table pointer.

Do not attach it to [UID:0000N5][ResourceLayoutTable](by-file/ResourceLayoutTable.md), [UID:0000K2][ImageLib](by-file/ImageLib.md), [UID:0000JY][HumanImageLib](by-file/HumanImageLib.md), or [UID:0000LR][NewHumanImageLib](by-file/NewHumanImageLib.md) yet. The physical placement and record format point to the ResourceLayout/ImageLib helper family, while the known callers are human-image composition code. That cross-file use keeps the final source declaration and helper name below final-source quality.
