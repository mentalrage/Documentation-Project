## Behavior

Copies the Application DAT filename fixed wide-character buffer addressed at `Application + 0x428` into a caller-supplied wide-character buffer through `wcscpy_s`.

B008 source-quality reanalysis rejects the older processor-name interpretation. The constructor and companion accessors show separate fixed string buffers: `Application + 0x28` is the world/server name, `Application + 0x228` is the player name, `Application + 0x428` is initialized from constructor argument `a4` plus `.DAT`, and `Application + 0x628` is initialized from `a4` plus `.SND`. CPU processor-name state remains the separate SimpleUString-style owner around `Application + 0x1c`, populated by [UID:0002JW][0x00465130-0x004651b8.ApplicationReadProcessorName](by-memory/0x00465130-0x004651b8.ApplicationReadProcessorName.md) and the constructor duplicate.
