## Behavior

The helper searches the `ObjectList` row bucket that stores static object panes and synchronizes the lighting companion for every static object pane whose stored object id matches the supplied `staticObjectId`.

1. It resolves static-object metadata through [UID:0000SD][g_pStaticObjImageLib](by-global/g_pStaticObjImageLib.md) by calling `sub_4DDA30(g_pStaticObjImageLib, staticObjectId)`.
2. It computes the signed short loop bound `m_gridHeight + 12`, iterates every `m_staticObjectRows[rowIndex]` list, caches each row count, and dereferences each `List` element as a `StaticObjectPane *` pointer slot.
3. For each pane, it compares unsigned `StaticObjectPane::m_staticObjectId` at `+0x128` with `staticObjectId` before doing any lighting work.
4. For a match, it first calls `StaticObjectPane::InvalidateRect(NULL)` through inherited virtual slot `+0x20`. The former detach/disable interpretation was incorrect; the zero argument and ObjectPane vtable contract prove invalidation.
5. It reads the current attached light through source-facing `ObjectPane::GetAttachedObject()`, the exact one-instruction `sub_5376C0` accessor over object offset `+0x118`.
6. If an attached light exists and the static-object metadata light-image index is negative, it scans `m_lightingObjects`, removes the matching pointer with `RemoveAt(lightIndex, 1)`, calls `staticObjectPane->DetachObject()`, and then deletes the `LightingObjectPane` in that exact order.
7. If an attached light exists and the metadata light-image index is non-negative, it calls [UID:0001DI][0x0053c980-0x0053c9b5.LightingObjectPaneSetLightImageIndex](by-memory/0x0053c980-0x0053c9b5.LightingObjectPaneSetLightImageIndex.md) to rebind the existing light to that signed image-table row.
8. If no attached light exists and the metadata light-image index is non-negative, it obtains `MapPoint` row/column through `ObjectPane::GetMapPosition`, allocates a `0x138`-byte [UID:000075][LightingObjectPane](by-class/LightingObjectPane.md), and constructs it with the matching static pane, row, column, `g_mapTilePixelWidth`, `g_mapTilePixelHeight / 2 - g_mapTilePixelHeight * lightHeightClass`, and `lightImageIndex`. It then calls `ObjectList::AddObjectPane` and finally `staticObjectPane->AttachObject(lightingObjectPane)` in exact source-significant order.

This makes the old `RemoveByObjectId` name incomplete. The function can remove an obsolete attached light, but its central job is to refresh static-object lighting state by object id.
