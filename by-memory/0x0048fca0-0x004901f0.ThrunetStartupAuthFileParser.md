## Address Range

`0x0048fca0-0x004901f0`.

IDA models this exact range as `sub_48FCA0`, size `0x550`.

## Behavior

This helper reads a launcher-provided file path from the process command line, opens/parses the file for remote address and port data, resolves hostnames when needed, initializes COM, creates a Thrunet URL-check/validation object, and stores the returned validation token/string into the startup-state block.

On success it copies the validated token string into `param_1 + 0x28d9e0`, sets `param_1 + 0x2916ca` to `1`, and sets the state byte at `param_1 + 0x28de28` to `5`.

| `+0x2916ca` | Writes byte value `1` on success. | Launcher/auth success flag. |
| `+0x28de28` | Writes byte value `5` on success. | Startup connection/authentication mode selector. |

Treat `param_1` as a shared startup/config state block for now. The evidence is strong for these offset writes, but the final source type is not yet proven as a class field layout.
