## Behavior

This helper reads a launcher-provided file path from the process command line, opens/parses that file for remote address, port, and auth-token data, resolves hostnames when needed, initializes COM, creates the Thrunet URL-check/validation object, and stores the returned validation token string into the startup-state block.

Observed flow:

1. Saves the incoming config/startup-state object and obtains `MemoryMan::GetMemoryMan()` for wrapper copy calls.
2. Copies `GetCommandLineW()` into a 1024-wide-character local command buffer, skips the executable token using quote-aware or space-delimited logic, and copies the remaining command-line tail into a 128-wide-character auth-file path buffer with the binary's `0x100` / 256-byte guard (Verified with `tools/int_convert.py`).
3. Opens that path through PlatformApi dispatch slot `0x0069be14`, source-facing `g_pfnWideOpenFile` / `_wfopen`, passing mode string `"ro"` from `0x006113b8`.
4. Reads the first file line byte-by-byte with `_fgetc` into a wide local buffer until LF (`0x0a` / 10, Verified with `tools/int_convert.py`).
5. If the first character is numeric, parses four dotted-IP components through the `_wtol`-style wide integer helper and stores the bytes at `config + 0x2915b4`.
6. Otherwise, copies the hostname portion up to the first space into `config + 0x2915c4`, converts it to ANSI with `WideCharToMultiByte(CP_ACP, ...)`, resolves it with `gethostbyname`, and copies four resolved address bytes to `config + 0x2915b4` through `MemoryMan::MemmoveWrapper`.
7. Reads the second line, converts it with the `_wtol`-style helper, and stores the full dword at `config + 0x2916c4`; for this target this offset is `m_startupPort`, not the [UID:0002BN][0x00490b10-0x004910c0.ComBackedLauncherAuthenticationParser](by-memory/0x00490b10-0x004910c0.ComBackedLauncherAuthenticationParser.md) COM-token overlay.
8. Clears a 256-byte narrow buffer, reads the next token through `sub_4944C0(file, "%s", buffer)`, and closes the file.
9. Calls `CoInitialize(0)`, creates/query-acquires the COM object from ANSI ProgID `"thrunet.clsURLCHK"` through `sub_4941E0(&ppv, ..., 0, 0x17)`, and takes the localized message/quit path if creation fails.
10. Converts the file token to `BSTR` through the out-of-range helper `0x005c8dd0`, calls COM vtable slot `+0x1c` with the request BSTR and a BSTR out parameter, raises the COM runtime error path on failure, converts the returned BSTR to ANSI through out-of-range helper `0x005c8cb0`, and duplicates/caches the result.
11. If the returned text starts with `'*'`, takes the authentication-rejected message path.
12. Otherwise copies the returned token text into `config + 0x28d9e0` with `strcpy_s(..., 0x40, ...)`, writes `1` to `config + 0x2916ca`, writes `5` to `config + 0x28de28`, releases the COM pointer, and returns.

Failure behavior is user-visible and must not be collapsed into silent returns.
