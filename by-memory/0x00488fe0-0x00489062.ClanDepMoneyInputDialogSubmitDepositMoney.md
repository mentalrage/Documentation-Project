## Behavior

This method receives the submitted dialog text, converts it to an unsigned integer using the same CRT conversion helper used by the withdraw-money variant, builds a seven-byte clan packet, and sends it through [UID:0001HU][0x00574bb0-0x00574c13.QueueAndSendPacket](by-memory/0x00574bb0-0x00574c13.QueueAndSendPacket.md) using [UID:0001P0][0x0067a7ec-0x0067a7f0.g_packetSender](by-memory/0x0067a7ec-0x0067a7f0.g_packetSender.md).

| `+2` | `0x01` | Submit/confirm action. |
| `+3..+6` | converted amount | Little-endian 32-bit numeric amount from the input text. |
