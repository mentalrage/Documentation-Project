# 0x0049d390-0x0049d3cd File Base Scalar-Deleting Destructor

## Summary

- Address range: IDA function `0x0049d390-0x0049d3ce` end-exclusive; the filename's `0x0049d3cd` is the last byte of the final `retn 4` instruction.
- Entity kind: `File` scalar-deleting destructor / vtable destructor slot.
- Disposition: reconstructable source-level `File` destructor requirement.
- Rebuild handling: `source-declared/generated-binary`.
- Owner: [UID:00004V][File](by-class/File.md).
- Source parent: [UID:0000JB][File](by-file/File.md), position `10`. The parent page is above the 80/80 attach gate and records `NexusTK/util/` placement; final C++ remains blank here because this compiler-shaped wrapper is below the 95/95 final-source code gate.

This function is the `File` base class scalar-deleting destructor used in the first slot of the abstract `File` vtable. It restores the `File` vtable, delegates the non-deleting base teardown to [UID:000195][0x004f4a80-0x004f4c0d.LObjectRuntimeShell](by-memory/0x004f4a80-0x004f4c0d.LObjectRuntimeShell.md) at `0x004f4a90`, then either returns the original object pointer or frees the storage through [UID:000197][0x004f4ac0-0x004f4b00.OperatorDeleteWrapper](by-memory/0x004f4ac0-0x004f4b00.OperatorDeleteWrapper.md) depending on the compiler delete flags.
