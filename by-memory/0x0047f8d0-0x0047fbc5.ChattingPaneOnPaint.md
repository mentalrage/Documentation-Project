## Behavior

This method paints visible chat messages. It selects current-layout or old-layout coordinates through [UID:0000SW][g_useEpfAssets](by-global/g_useEpfAssets.md) / `byte_66DA97`, builds clipping/region helpers, iterates the message list at `this + 0x130`, asks each [UID:00002Z][ColorStringChattingMessage](by-class/ColorStringChattingMessage.md) object how many 13-pixel rows it needs at the active width, intersects each candidate row rectangle with the viewport, and calls the message draw virtual when visible.

Current-layout branch:

- uses message width `783`;
- uses the pane offset around `this + 0x44`;
- conditionally restores a UI byte through `0x005446b0` while drawing;
- skips the full message loop when `*(dword_67ADE0 + 0x118)` is false, after setting up clipping/background state.

Old-layout branch:

- uses message width `408`;
- uses the pane offset around `this + 0x110`;
- otherwise follows the same iterate/measure/intersect/draw pattern.
