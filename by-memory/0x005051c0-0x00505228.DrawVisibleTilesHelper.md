## Behavior

The helper begins painting the MapPane cached surface at `this + 0x428`, computes visible tile bounds through `0x00505290`, iterates y from `bounds.top` to `bounds.bottom - 1` and x from `bounds.left` to `bounds.right - 1`, calls the tile draw helper `0x0050d8e0(this, x, y, 0)` for each visible tile, and then ends the paint lock through `0x004b98c0`.

This requires MapPane tile state at offsets `0x3f4`, `0x3f6`, `0x3fc`, `0x400`, `0x404`, `0x408`, and cached drawing state at `0x428`. It cannot be a [UID:0000A6][ParcelPane](by-class/ParcelPane.md) method because `ParcelIconPane::ParcelIconPane` allocates its child parcel pane with size `0x124`, far smaller than the `this + 0x428` state used here.
