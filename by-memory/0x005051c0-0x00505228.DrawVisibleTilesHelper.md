## Behavior

The helper begins painting the MapPane cached surface field at offset `0x428` through [UID:000165][0x004b9820-0x004ba24a.SurfacePaintHelpers](by-memory/0x004b9820-0x004ba24a.SurfacePaintHelpers.md) `UpdateSurfaceInfo`, computes clamped visible tile bounds through the MapPane bounds helper at `0x00505290`, then iterates top-to-bottom and left-to-right over the returned rectangle.

For each tile coordinate, it calls the MapPane tile renderer at `0x0050d8e0` with repaint mode `0`, so the tile renderer uses the paint lock already opened by this helper. After the nested loop completes, it closes the paint lock through [UID:000165][0x004b9820-0x004ba24a.SurfacePaintHelpers](by-memory/0x004b9820-0x004ba24a.SurfacePaintHelpers.md) `EndPaint`.

The bounds helper reads MapPane viewport origin fields at offsets `0x3fc` and `0x400`, visible span fields at offsets `0x404` and `0x408`, and dimension fields at offsets `0x3f4` and `0x3f6`. It returns a clamped left/top/right/bottom rectangle where the right and bottom values are loop-exclusive.

This is MapPane-owned code despite being called from ScreenPane refresh paths. Both executable callsites load [UID:0000PR][g_activeMapPane](by-global/g_activeMapPane.md), validate the active pane pointer, call this helper, and then invoke the pane refresh virtual slot.
