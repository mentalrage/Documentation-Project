                    slice.m_payloadData =
                        static_cast<unsigned char *>(malloc(slice.m_payloadLength));

## Behavior

This method handles patch response packets for the original `Auto Patch` dialog. It validates the leading response byte `0x40`, switches on the subtype byte, and drives patch-entry allocation, slice receipt, progress updates, and error exit.

| Subtype | Packet body after leading `0x40` | Behavior |
| --- | --- |
| `0` | `u8 nameLen`, `nameLen` bytes of CP_ACP name/path text, big-endian `u32 entryCount` | Starts a patch entry set: converts the entry name/path with bounded `MultiByteToWideChar(CP_ACP, 0, ..., 1023)`, compares it with `m_patchFileData.m_currentPatchName`, constructs an array of [UID:0000AC][PatchPane__PatchFileSlice](by-class/PatchPane__PatchFileSlice.md) entries when no slice array exists, sends initial pending entry requests, writes status control `0`, and resets progress control `1` to `0`. |
| `1` | `u8 nameLen`, `nameLen` bytes of CP_ACP name/path text, big-endian `u32 entryIndex`, big-endian `u32 payloadLength`, payload bytes | Receives one entry slice: validates the script/name context, reads the entry index and payload length with `PacketBufferReadUInt32BE`, allocates/copies the payload, counts completed slices, updates progress to `100 * completed / total`, and always calls `SendPendingPatchEntryRequests` after subtype handling. |
| `2` | no parsed payload beyond subtype | Reports patch failure through the localized alert/exit helper at `0x00547980`. |
