## Behavior

This method handles patch response packets for the original `Auto Patch` dialog. It validates the leading response byte `0x40`, switches on the subtype byte, and drives patch-entry allocation, slice receipt, progress updates, and error exit.

| Subtype | Packet body after leading `0x40` | Behavior |
| --- | --- |
| `0` | `u8 nameLen`, `nameLen` bytes of multibyte name/path text, `u32 entryCount` | Starts a patch entry set: converts the entry name/path from multibyte text, constructs an array of [UID:0000AC][PatchPane__PatchFileSlice](by-class/PatchPane__PatchFileSlice.md) entries, clears progress text/bar state, and sends initial pending entry requests. |
| `1` | `u8 nameLen`, `nameLen` bytes of multibyte name/path text, `u32 entryIndex`, `u32 payloadLength`, payload bytes | Receives one entry slice: validates the script/name context, reads the entry index and payload length, allocates/copies the payload, counts completed slices, updates progress, and sends more pending requests. |
| `2` | no parsed payload beyond subtype | Reports patch failure through the localized alert/exit helper at `0x00547980`. |
