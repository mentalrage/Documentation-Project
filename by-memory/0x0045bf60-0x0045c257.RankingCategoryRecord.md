## Layout Summary

The record is a 688-byte category/page record used by ranking panes and dialogs.

- `+0x00`: visible list index, returned as a 16-bit value.
- `+0x04`: category id.
- `+0x08`: state code.
- `+0x0c`: 36-byte start time/date block.
- `+0x30`: 36-byte end time/date block.
- `+0x54`: wide title text buffer.
- `+0x258`: user-entry vector begin pointer.
- `+0x25c`: current/end pointer used for count and reset.
- `+0x260`: capacity pointer.
- `+0x268`: selected/local user index, reset to `-1`.

See [UID:0001VN][RankingCategoryRecordLayout](by-type/by-struct/RankingCategoryRecordLayout.md) for the offset table.

The packed date/time setters split two decimal integers into six fields inside each 36-byte block:

- `0x0045c050` stores start date/time components into dwords `+0x0c` through `+0x20`.
- `0x0045c100` stores end date/time components into dwords `+0x30` through `+0x44`.
- The first input is split as `YYYY`, `MM`, `DD`; the second input is split as `HH`, `MM`, `SS` or equivalent three two-digit time parts. The observed write order is low-to-high time part first, then date part.
