## Status

- Confidence: strong for `jpeg-6b/jcapistd.c` source-file ownership.
- Proposed owner: [UID:0000KN][LibJPEG](by-file/LibJPEG.md)
- Disposition: third-party static IJG libjpeg code; exclude from NexusTK product files.
- Evidence basis: read-only IDA MCP decompile/function-list checks and source comparison against `jpegsrc.v6b.tar.gz` on 2026-05-25. `wave3.py` was not executed for this pass.

## Range Role

This range is the stock IJG `jpeg_write_raw_data` compression API entry point. It is adjacent to the already documented compression front end and remains part of `jcapistd.c`, even though the observed NexusTK JPEG screenshot writer uses `jpeg_write_scanlines` rather than this raw-data path.

## Function Mapping

| --- | --- | --- |
| `0x004048f0-0x004049bb` | `jpeg_write_raw_data` | Verifies compression scan state, calls the progress monitor, starts the pass if needed, invokes raw data path processing through the controller vtable, and advances `next_scanline`; source anchor `jcapistd.c:120`. |

## Ownership Decision
