## Behavior

1. Reads the old slider value from `this+0xfe` before performing any callback dispatch.
2. Computes the active thumb rectangle through the part-rectangle helper at `0x00565010`, using the same geometry model documented by [UID:0001W2][ScrollVolumePaneLayout](by-type/by-struct/ScrollVolumePaneLayout.md).
3. Combines the mouse coordinate passed by the commit helper with the drag reference/offset state at `this+0x108` and `this+0x10c`.
4. Clamps the resulting value against the slider range at `this+0x100` before treating it as the new current value.
5. Uses the volume-type byte at `this+0xfc` when notifying the option-pane side.
6. Calls `NewOptionPane::OnVolumeChanged` at `0x00540490` only when the computed value differs from the old value; unchanged drag positions do not dispatch a callback.
