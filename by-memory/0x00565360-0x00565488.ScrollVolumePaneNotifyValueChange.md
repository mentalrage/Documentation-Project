## Behavior

1. Reads the old slider value from word `this+0xfe` before performing any callback dispatch. This helper does not write the local value word back; it delegates the policy/application update to the owning option pane callback.
2. Computes the thumb rectangle through the part-rectangle helper at `0x00565010` with part code `2`, using the horizontal part model documented by [UID:0001W2][ScrollVolumePaneLayout](by-type/by-struct/ScrollVolumePaneLayout.md).
3. Inlines the constant left/right edge rectangle calculations that correspond to `GetPartRect(0)` and `GetPartRect(4)`. The code uses the collapsed left edge rectangle's `right` member as the left travel limit and the collapsed right edge rectangle's `left` member as the right travel limit; [UID:0001VP][RectBoundsLayout](by-type/by-struct/RectBoundsLayout.md) confirms the `left, top, right, bottom` field order.
4. Computes `thumbLeft = localX - m_thumbDragOffset.x + 1`. The second/+4 Point component is the horizontal drag offset created by `BeginInteraction`; the first component is the vertical/local-Y offset and is not used by this value math.
5. Clamps `thumbLeft` to `[leftLimit, rightLimit - thumbWidth]`, where `thumbWidth = thumbRect.right - thumbRect.left`.
6. Computes the new value as `((thumbLeft - leftLimit) * (range + 1)) / (rightLimit - leftLimit - thumbWidth)`, where `range` is word `this+0x100`; if the arithmetic result exceeds the range, clamps it back to `range`.
7. Uses the volume-type byte at `this+0xfc` when notifying the option-pane side. `this+0x103` remains current `m_hoverPart` and `this+0x104` remains `m_activePart` from sibling interaction helpers; this body only consumes drag/value fields. Historical `m_highlightPart` wording is superseded.
8. Calls inherited primary vtable slot `+0x1c` (`0x005447a0`) to obtain the containing/owner pane, treats that result as the `NewOptionPane *` receiver, and then calls `NewOptionPane::OnVolumeChanged` at `0x00540490` only when the computed value differs from the old value. Unchanged drag positions do not dispatch a callback.
