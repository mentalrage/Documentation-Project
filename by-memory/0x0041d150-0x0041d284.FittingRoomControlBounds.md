## Behavior

Maps fitting-room control IDs to fixed dialog-relative rectangles. The helper is used by the fitting-room dialog constructor and by the category-button rebuild path.

Observed rectangle table:

| ID | Rectangle `(x, y, w, h)` | Meaning |
| --- | --- | --- |
| `0` | `(379, 468, 63, 24)` | Close/confirm style button slot. |
| `1` | `(18, 50, 192, 192)` | Preview portrait/image pane. |
| `2` | `(218, 92, 586, 362)` | Main item list pane. |
| `3` | `(18, 248, 63, 24)` | Preview direction/action button. |
| `4` | `(149, 250, 63, 24)` | Preview direction/action button. |
| `5` | `(18, 276, 92, 30)` | Reset/current action button. |
| `6` | `(120, 276, 92, 30)` | Reset/current action button. |
| `7`-`16` | `(280 + 90 * ((id - 7) % 5), 50 + 26 * ((id - 7) / 5), 86, 22)` | Two-row, five-column category button grid. |
| other | `(-1, -1, -1, -1)` | Invalid/default bounds. |

## Reconstructed C++ Candidate

```cpp
void LoadFittingRoomControlBounds(short controlId, Rect& bounds)
{
    switch (controlId) {
    case 0: bounds.Set(379, 468, 63, 24); return;
    case 1: bounds.Set(18, 50, 192, 192); return;
    case 2: bounds.Set(218, 92, 586, 362); return;
    case 3: bounds.Set(18, 248, 63, 24); return;
    case 4: bounds.Set(149, 250, 63, 24); return;
    case 5: bounds.Set(18, 276, 92, 30); return;
    case 6: bounds.Set(120, 276, 92, 30); return;
    default:
        if (controlId >= 7 && controlId <= 16) {
            const int index = controlId - 7;
            bounds.Set(280 + 90 * (index % 5), 50 + 26 * (index / 5), 86, 22);
        } else {
            bounds.Set(-1, -1, -1, -1);
        }
        return;
    }
}
```
