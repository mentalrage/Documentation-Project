# 0x00620344-0x006205f0 Static/Item/Flying/Attached ObjectPane Vtable Data

## Range

- Address range: `0x00620344-0x006205f0`
- Entity kind: `vtable-data`
- Disposition: reconstructable source-declared/generated-binary data.
- Rebuild handling: generated by object-pane subclass declarations and virtual method implementations.
- Parent read-only aggregate: [UID:000260][0x00620284-0x00620c74.ObjectPaneReadOnlyData](by-memory/0x00620284-0x00620c74.ObjectPaneReadOnlyData.md)

## Summary

This mixed `.rdata` child contains vtable data for the static-object, ground-item, flying-object, and attached-object pane family. It is deliberately documented as a group because the current written evidence proves the class family and executable owners, but not enough slot-level layout to split every class table without a fresh IDA byte scan.
