## Behavior

This helper uses `LObject`/`SimpleUString`-style utilities to parse structured command-line markers including `/host:`, `/portno:`, and `/id:`. It resolves the host, stores port and id/region data, sets the shared startup-ready/state fields, and calls the fatal-error path when required arguments are absent or host resolution fails.

On success, the legacy report records the resolved host stored at `param_1 + 0x2915b4`, a numeric field at `param_1 + 0x2916c4`, ready/state writes at `0x2916ca` and `0x28de28`, and parsed id/region object data copied to `param_1 + 0x2918f0`.
