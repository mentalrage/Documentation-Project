# DATFile GetSize

## Role And Evidence

Exact virtual size query at `[0x0049c2f0,0x0049c304)`. It returns the cached payload size for an active entry and `-1` otherwise. The size is established from consecutive 17-byte record offsets by Open/OpenByIndex.
