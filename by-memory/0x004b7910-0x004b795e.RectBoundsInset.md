## Behavior

This method mutates the receiver in place and returns no meaningful value:

- `left += dx`;
- `right -= dx`;
- `top += dy`;
- `bottom -= dy`;
- if `left > right`, assign both horizontal edges to `(left + right) / 2`;
- if `top > bottom`, assign both vertical edges to `(top + bottom) / 2`.

The midpoint division uses signed MSVC truncation-toward-zero semantics. Equality is not collapsed; exact zero width or height is preserved. Negative `dx` or `dy` values act as an outset/expansion. This is the member-style counterpart to the free geometry helper at `0x004b7e30`, but this exact body is `thiscall` class-method-shaped and belongs to [UID:0000BU][RectBounds](by-class/RectBounds.md), not to the free-helper island.

The accepted class shell declares this as `void Inset(int dx, int dy)`. Raw return-register behavior rejects a chainable `RectBounds *` or meaningful `bool`/`int` return: the body leaves `eax` as an arithmetic temporary or midpoint value, never restores `eax` to `this`, and all known callers ignore the register.
