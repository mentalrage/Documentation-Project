# 0x00549c00-0x00549c18 PoolAllocator Free Chunk List

## Behavior

IDA decompilation shows a `thiscall`-shaped helper that treats `ecx` as the first chunk pointer. If the pointer is non-null, it reads the next pointer from the first dword of each chunk, frees the current chunk, and continues until the list is empty.

```cpp
static void FreePoolChunkList(PoolChunkHeader* chunk)
{
    while (chunk != nullptr) {
        PoolChunkHeader* next = chunk->next;
        free(chunk);
        chunk = next;
    }
}
```

## Evidence

- 2026-05-28 IDA MCP `analyze_funcs 0x00549c00` reports `sub_549C00` at `0x00549c00-0x00549c18`.
- Decompilation shows the loop reading `*Block`, calling `j_j_j___free_base(Block)`, and continuing with the saved next pointer.
- IDA caller evidence shows one caller at `0x004b1553` inside [UID:000152][0x004b13d0-0x004b1585.PoolAllocatorCore](by-memory/0x004b13d0-0x004b1585.PoolAllocatorCore.md), where `PoolAllocator::~PoolAllocator` passes the allocator chunk-list head from `this + 8` before clearing both chunk and free-list fields.

## Source-Structure Decision

Keep this helper with [UID:0000MM][PoolAllocator](by-file/PoolAllocator.md). It complements [UID:0001F4][0x00549bd0-0x00549bf1.PoolAllocatorChunkHelper](by-memory/0x00549bd0-0x00549bf1.PoolAllocatorChunkHelper.md) by freeing the chunk list that `AllocatePoolChunk` builds. It is not a general public allocator API and should be implemented as a file-local helper or private static utility in `PoolAllocator.cpp`.
