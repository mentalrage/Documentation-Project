# 0x00578f70-0x005797ae STL Tree/String Map Support

## Status

- Disposition: ignored for handwritten source reconstruction
- Entity kind: MSVC STL/Dinkumware tree/string template support
- Current generated owner: scattered missing-ref helpers around packet, socket, and VirusChecker output
- Source reconstruction rule: model the owning C++ maps/sets/strings in their real modules; do not port these helper bodies as handwritten NexusTK logic.
- Confidence: strong for compiler/STL support identity; medium for exact template type spelling.

## Covered Range

This range covers a compiler/STL helper family that was previously partly hidden inside [UID:0001I1][0x00575d90-0x005796c7.SocketTransportCore](by-memory/0x00575d90-0x005796c7.SocketTransportCore.md) and partly left as UNKNOWN before [UID:0001I8][0x005797b0-0x0057bc58.SoundManager](by-memory/0x005797b0-0x0057bc58.SoundManager.md). The helpers are real code, but the correct reconstruction is ordinary C++ container declarations at the owning call sites.

## Evidence

- 2026-05-28 IDA MCP disassembly shows the helper bodies allocate/free fixed 0x14-byte nodes, maintain self-linked header/sentinel links, recurse over child links, and call string construction/destruction helpers rather than Socket or audio methods.
- Direct callers cross feature boundaries: `0x00574e50-0x0057536b` calls the sentinel and destructor helpers from CashShopRequest packet-building code, while `0x005c0460-0x005c04e0` calls the sentinel helper from the VirusChecker constructor.
- `simroot_v2` contains matching generated leads such as `CreateTreeSentinelNode`, `WideStringMap_436260::DestroyNodes_579710`, and `CreateTreeSentinelNode` calls in `CashShopRequest`, `VirusChecker`, and `EventDispatcher`. Treat those generated names as leads only; IDA MCP supplies the boundary and caller evidence.
- The prior physical placement after Socket transform code is not ownership evidence. The caller spread and helper shape match compiler/STL tree support emitted for several owner modules.

## Reconstruction Decision

Ignore these helper bodies as standalone handwritten source. The rebuilt source should express the original owning data structures as STL/project tree containers in:

- [UID:0000I0][CashShopRequest](by-file/CashShopRequest.md), for packet-building temporary string/tree sets.
- [UID:0000P5][VirusChecker](by-file/VirusChecker.md), for process/tree tracking.
- [UID:0000J7][EventDispatcher](by-file/EventDispatcher.md), if the generated sentinel lead is confirmed against the separate dispatcher tree helpers.

If a later compiler-match pass requires exact library output, record the required compiler/STL version under project/library notes rather than converting this helper island into a source-authored module.
