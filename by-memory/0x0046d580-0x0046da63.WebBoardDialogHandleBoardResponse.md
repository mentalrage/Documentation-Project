## Behavior Notes

- The handler reads byte-length-prefixed fields from the response payload after the leading packet byte.
- If the flag byte at `payload + 1` is nonzero, it copies and converts two short fields with `MultiByteToWideChar`, formats a wide URL/path with `%s/%s.html`, and navigates the embedded browser control through `0x0046bd30`.
- In the main response path, it copies the URL into `szUrl`, copies another field into `MultiByteStr`, and copies a third field into a 256-byte buffer used as query/cookie data.
- It scans the query/cookie data for `=` and `&`, extracts the value between them into a 128-byte cookie buffer, then calls `InternetSetCookieA(szUrl, "domain", value)`.
- On first use, it initializes the active WebBoardDialog escape table using `byte_67ABA8` as the guard and `byte_67ABB0[256]` as the lookup table. The table marks non-printable/out-of-range bytes and the reserved URL character sets documented at [UID:000278][0x0066d430-0x0066d468.BrowserUrlEscapeCharacterSets](by-memory/0x0066d430-0x0066d468.BrowserUrlEscapeCharacterSets.md).
- It percent-escapes marked boardinfo bytes through the `%%%2X` format path, copies unmarked bytes directly, terminates the 1024-byte output buffer, then calls `InternetSetCookieA(szUrl, "boardinfo", escapedValue)`.
- Before navigation, it converts `szUrl` to UTF-16, copies it into the embedded browser-control state at offset `+300`, clears the following word at offset `+810`, converts the selected navigation target to UTF-16, and calls `0x0046bd30` with the browser-control pointer at `this[155]`.
- Successful paths return `1`; oversized conversions/copies branch to the compiler range-check failure path.
