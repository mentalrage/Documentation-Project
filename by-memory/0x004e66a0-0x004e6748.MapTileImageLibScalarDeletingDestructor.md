## Deleting-Destructor Flag Behavior

The decompile and disassembly show the usual scalar deleting destructor flag contract:

| Flag test | Behavior |
| --- | --- |
| `(flags & 1) == 0` | Run cleanup and return `this` without freeing object storage. |
| `(flags & 1) != 0 && (flags & 4) == 0` | Call `0x004f4ac0` with `this`, the ordinary object delete path. |
| `(flags & 1) != 0 && (flags & 4) != 0` | Follow the alternate vector/delete helper branch visible as `push 0x0c`, `push this`, then `_guard_check_icall_nop@4`; do not model this as authored project logic. |
