## Class Purpose

`TargetObjectWithKeyboardPane` is a [UID:000077][LineInputPane](by-class/LineInputPane.md)-derived target selector for the target-dispatch flow. It prompts the player to use arrow keys and press `v`, tracks the selected target id in `dword_69BF2C` / `s_targetObjectTargetId`, highlights the current target, and forwards target confirmation into the overlay/dispatch code.

It is close in structure to [UID:0000CT][SelectObjectWithKeyboardPane](by-class/SelectObjectWithKeyboardPane.md), but it uses a separate singleton/state set and confirms with `v` rather than Enter.
