# Struct Guidance

Use this folder for named structs, POD records, packet/resource record layouts, and helper structs that are not full classes.

Record field offsets, sizes, likely owner header, and the source/module that should declare the type.

Git is only a backup/sync tool for this documentation work, not a struct-documentation cleanup target. Only stop to commit/push after roughly 30 minutes of work or after a large batch of about 50+ meaningful edits; do not interrupt smaller struct documentation passes for Git, worktree tidying, or generated-file housekeeping.
