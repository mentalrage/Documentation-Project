## File Role

This source/header family is the client heap-allocation policy layer. It wraps CRT allocation functions, throws [UID:0000G7][Win32Error](by-class/Win32Error.md) on allocation failure, exposes the global `MemoryMan` singleton accessor, and supplies project-wide allocation/copy helpers used by UI, loaders, containers, networking, and image/resource code. `RingBuffer.cpp` includes `MemoryMan.h`, obtains the singleton before queue locking, and invokes `MemoryMan::MemmoveWrapper` through that retained receiver.

The original project may have named the source `MemoryMan.cpp` because Wave2 imported the class from `MemoryMan.cpp`. A shorter `Memory.cpp` or `MemoryUtil.cpp` remains possible, but the current best reconstruction is one utility source module rather than several one-function recovered files.
