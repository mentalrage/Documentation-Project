## Startup And Synchronization

Application startup constructs `MetaMan` and its direct Singleton base before later render/palette startup work. Session/network code then calls `LoadMetaDatAndRequestSync`, which loads the local cache and sends a metadata sync request. Incoming metadata packets are dispatched to `HandleMetaPacket`.

## Singleton, EBO, And Compiler Data

- UID000088 is `class MetaMan : public Singleton<MetaMan>` and retains every current API and field.
- RTTI PMD is `mdisp=4`, `pdisp=-1`, `vdisp=0`; EBO overlaps the empty Singleton base with the first map state at `+0x04`.
- Complete object size remains `0x14`; no field or map offset moves.
- UID0004SS contains `0x00000000`, MetaMan COL `0x0064c260`, and scalar-wrapper slot `0x005244e0`.
- Constructor/destructor/scalar-wrapper table stores at `0x0061fad8` are compiler effects.
- Publication and clear of UID0000RL `g_pMetaMan` are direct Singleton base construction/destruction effects, not manual MetaMan body statements.
- Existing UID0000RL remains the one external singleton definition. UID0004SS and exact storage UID0001PJ emit no duplicate source.
- No handwritten RTTI/vtable arrays, vptr assignments, scalar deleting wrapper, delete flags, storage free, or Singleton publication/clear belong in source.

The manager uses opcode `123` packets:

- subtype `1` requests or receives the table/checksum list;
- subtype `0` requests or receives one named table payload.

`LoadMetaDatAndRequestSync` sends the subtype `1` sync-list request after loading the local cache. `HandleMetaPacket` subtype `1` prunes local tables missing from the server list, validates cached payloads, sends subtype `0` requests for missing/stale tables, increments `m_pendingTableRequests`, and sets `m_synchronized` when no requests remain. Subtype `0` receives one compressed table payload, finds or creates a `MetaTable`, stores the payload at `MetaTable +0x10/+0x14`, validates it, marks `m_dirty`, decrements the pending count, and writes dirty state back to loose `Meta.dat` when synchronization completes.
