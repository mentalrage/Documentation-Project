## Responsibilities

`LanguageMan` is the process-wide localized string table. It opens the DAT-backed `str.res` resource, reads up to 1024 text records, converts each line to wide characters, stores an owned `wchar_t*` table, and serves localized strings to dialog, prompt, scanner, and startup code by numeric id.

Treat `LanguageManager` as a generated alias/view over the same concrete object, not a second original source class. Its old recovered method, `GetLocalizedString` at `0x004f0350`, is now the exact [UID:00040P][0x004f0350-0x004f0372.LanguageManGetLocalizedString](by-memory/0x004f0350-0x004f0372.LanguageManGetLocalizedString.md) child under [UID:000071][LanguageMan](by-class/LanguageMan.md), reading the layout initialized by `LanguageMan::LanguageMan`: `m_strings` at `+0x04` and `m_stringCount` at `+0x08`.
