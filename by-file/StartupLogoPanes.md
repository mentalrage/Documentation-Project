## File Role

`StartupLogoPanes.cpp` is the startup splash and intro-media UI module. It owns the static logo pane that inflates and renders the startup `.LGO` image, handles click/timer advancement, and calls back into the application startup flow. It also owns the logo video pane that reads a segmented Bink payload, opens each segment, and lets keyboard or left mouse button release input skip to the next segment.

This module should stay app/startup-adjacent rather than moving into generic UI dialogs. The code is driven by startup sequencing, completion callbacks, logo resources, and application-level transition logic. The reusable Bink frame pumping belongs in [UID:0000P4][VideoPlayerPane](by-file/VideoPlayerPane.md).
