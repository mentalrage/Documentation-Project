## File Role

`Palette.cpp` is the broad umbrella for native 16-bit palette objects, free palette helpers, palette slot constants, and shared render-palette support. Focused `PaletteLib.h/.cpp` owns the process-wide manager class, its singleton definition, and its screen/filter methods; this umbrella does not duplicate those source definitions.

`DLPalette` owns the actual palette data: optional typed two-byte `DLPaletteRange` records, a fixed palette header, and a 256-entry native 16-bit color table. UID0004HV provides the exact source-ready deep-copy constructor and declaration in `Palette.cpp`/`Palette.h`; copy allocation, loading, application, and EPF consumption now share one range-record model. `PaletteLib` owns the runtime policy: loading `baram.pal`, category palette files, optional `SUPER0.PAL` through `SUPER6.PAL`, named lazy-loaded palettes, and source/runtime palette lists. Rendering code should request palettes through `PaletteLib` rather than opening raw `.PAL` files directly.

`Palette.cpp` uses the archive `DATFile` interface only for [UID:0004I0][0x00542df0-0x00542e5f.DLPaletteLoadFromFile](by-memory/0x00542df0-0x00542e5f.DLPaletteLoadFromFile.md), the source-ready wide-path convenience wrapper. That method constructs a complete `DATFile`, calls throwing Open, delegates to the separate `void DLPalette::LoadFromStream(File *stream)` decoder, explicitly closes on success, and relies on automatic destruction for exceptional cleanup. This dependency requires `../archive/DATFile.h` in the Palette CPP shell but does not move palette parsing, object state, or method ownership into archive/DATFile source.

`ScreenPanePaletteState_543D30` is a historical recovered alias over the `PaletteLib` object, not a source helper/facet type or separate `ScreenPane` singleton. IDA callers pass `g_pPaletteLib` as `this`, and the `PaletteLib` constructor initializes the mode/list/bank fields used by those methods. Keep the alias docs for audit context, but emit `PaletteLib::SetScreenPaletteMode` and `PaletteLib::ResetScreenPaletteSlots` only through focused `PaletteLib.cpp`.
