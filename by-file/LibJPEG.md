## Rebuild Strategy

1. Obtain or use the staged official `jpegsrc.v6b.tar.gz` IJG source.
2. Build a VC6-era compatible static library or add the source files under `third_party/libjpeg/`.
3. Use `jmemnobs.c` as `SYSDEPMEM` for the first Windows rebuild attempt; `jpeg-6b/makefile.vc` recommends `jmemnobs.obj` for Windows NT/95 style builds.
4. Keep by-memory formal C++ for stock source children as validator inline import directives with blank multiline blocks; do not duplicate upstream C bodies or retain legacy marker comments once a staged source file is importable.
5. Keep product-facing wrapper code in image loader/writer/screenshot modules.

The UID00028D audit confirms that `jerror.c`/`jerror.h`/`jversion.h` regenerate the 124 diagnostics, pointer table, and `%s\n`, while `jmemmgr.c`/`jmemsys.h` regenerate `JPEGMEM` and `%ld%c`. No separate hand-written message array or target-local source import is valid. Historical 121-entry wording omitted the final three pointer slots; historical 123-message wording confused the inclusive final index with the count.
