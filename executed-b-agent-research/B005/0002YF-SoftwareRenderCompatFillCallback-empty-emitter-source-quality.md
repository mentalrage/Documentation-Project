## Heuristic / Inference Reanalysis And Validation

### ABI and source shape

- Physical `retn 4`, ECX receiver use, initializer target type, representative slot consumers, and ignored EAX after calls prove a void receiver-plus-one-pointer callback. IDA's `char __userpurge@<al>` rendering is a stack-alignment/decompiler artifact, not source truth.
- `GrafPort *port` and `const RectBounds *bounds` are accepted because current UDTs, the SurfaceFillRectProc declaration, both initializers, and the RGB565 peer independently agree.
- `SoftwareRenderCompatFillCallback` is adopted over `FillRgb555RectCallback`: the former is already used by the current initializer and matches the accepted compatibility provider family. The latter remains a rejected plausible alias, not an unresolved blocker.

### Clipping and destination addressing

- `m_drawEnabled` at `+0x71` guards every helper and write.
- The callback gets the current clip rectangle, copies the requested rectangle, intersects clip/request into the request local, and returns when empty or invalid.
- Destination pixels are 16-bit words. The exact logical index is `clipped.left + rowStridePixels * (clipped.top - context.bounds.top) - context.bounds.left`, starting from `m_surfaceContext.pixelData`.
- Current UDT layouts close all prior offset uncertainty: GrafPort is `0xa0`; embedded EPFTileContext is `0x28`; `pixelData`, `rowStridePixels`, and `bounds` are at context offsets `+0x04`, `+0x0c`, and `+0x10`; RectBounds is four signed ints.

### Palette and special fill value

- This RGB555 callback always uses `g_pPaletteLib->GetCurrentPalette()`. It does not use `port->m_palette`; importing RGB565 peer fallback behavior would be wrong.
- It maps `m_drawColor` to the fill pixel, then maps `m_textBackFillColor` and discards that result. The source preserves the second call and explicitly discards the value.
- When `m_usesSoftwareBuffer` is true and raw `m_drawColor` equals 128, mapped fill is overridden to pixel value 1.

### Four draw modes

- Mode 0 directly fills every clipped pixel.
- Mode 1 returns when raw `m_drawColor` is zero; otherwise it performs the same direct fill.
- Mode 2 blends every clipped pixel.
- Mode 3 returns when raw `m_drawColor` is zero; otherwise it performs the same blend.
- Any mode outside 0..3 performs no pixel writes.

### Direct fill and blend lowering

- Direct fill writes the odd final word first and uses packed repeated dword stores for pairs. Calling the already accepted `__forceinline FillRgb555Span` expresses the human source and permits the observed lowering.
- Blend weight is exactly `static_cast<unsigned char>(static_cast<int>(m_alpha * 32.0f + 0.5f))`. It is intentionally not clamped.
- `BlendRgb555(destination, fillPixel, destinationWeight)` has the exact direction: the first pixel receives the provided weight, while the second receives byte-wrapped `32 - weight`.
- The live body conditionally uses SSE4.1 only when width is at least eight and `__isa_available >= 2`, processing eight pixels before a scalar tail. This is compiler lowering of the scalar loop, not a source-level ISA branch.
- Unlike the accepted RGB565 mode-3 peer anomaly, both RGB555 blend modes cover each width pixel exactly once. No extra odd-width write is reconstructed.

### Rejected alternatives

- GrafPort ownership is rejected: the function operates on a GrafPort receiver but is selected and stored by the Surface backend table, is not a class method, and has no GrafPort vtable route.
- SoftwareBlend16 ownership is rejected: BlendRgb555 is a stateless primitive there; this callback performs clipping, palette lookup, Surface slot installation, and context addressing.
- `g_pfnLockSurface`, fill/invalidate ambiguity, and raw `dword_69B3FC` are rejected as final source names. Exact consumers and both installed bodies establish rectangle fill semantics.
- A standalone XMM constant table, handwritten switch table, raw ISA branch, and decompiler-style vector code are rejected because scalar source naturally generates those binary artifacts.
- No research blocker remains. Stripped original spellings cap confidence but do not justify retaining raw names or blank code.

static void __fastcall SoftwareRenderCompatFillCallback(
    GrafPort *port,
    int /*unused*/,
    const RectBounds *bounds)
{
    enum FillMode {
        kFillCopy = 0,
        kFillColorKey = 1,
        kFillBlend = 2,
        kFillColorKeyBlend = 3
    };

    if (!port->m_drawEnabled) {
        return;
    }

    RectBounds clipBounds;
    port->GetClipRect(&clipBounds);

    RectBounds clippedBounds = *bounds;
    IntersectRects(&clipBounds, &clippedBounds, &clippedBounds);
    if (IsRectEmptyOrInvalid(&clippedBounds)) {
        return;
    }

    const int width = clippedBounds.right - clippedBounds.left;
    const int height = clippedBounds.bottom - clippedBounds.top;
    const int rowStridePixels = port->m_surfaceContext.rowStridePixels;
    unsigned short *rowPixels =
        static_cast<unsigned short *>(port->m_surfaceContext.pixelData) +
        clippedBounds.left +
        rowStridePixels *
            (clippedBounds.top - port->m_surfaceContext.bounds.top) -
        port->m_surfaceContext.bounds.left;

    DLPalette *palette = g_pPaletteLib->GetCurrentPalette();
    unsigned short fillPixel = palette->MapColor(port->m_drawColor);
    const unsigned short secondaryPixel =
        palette->MapColor(port->m_textBackFillColor);
    (void)secondaryPixel;

    if (port->m_usesSoftwareBuffer && port->m_drawColor == 128) {
        fillPixel = 1;
    }

    switch (port->m_drawMode) {
    case kFillCopy:
        for (int y = 0; y < height; ++y) {
            FillRgb555Span(rowPixels, width, fillPixel);
            rowPixels += rowStridePixels;
        }
        break;

    case kFillColorKey:
        if (port->m_drawColor == 0) {
            return;
        }

        for (int y = 0; y < height; ++y) {
            FillRgb555Span(rowPixels, width, fillPixel);
            rowPixels += rowStridePixels;
        }
        break;

    case kFillBlend: {
        const unsigned char destinationWeight =
            static_cast<unsigned char>(
                static_cast<int>(port->m_alpha * 32.0f + 0.5f));

        for (int y = 0; y < height; ++y) {
            for (int x = 0; x < width; ++x) {
                rowPixels[x] = BlendRgb555(
                    rowPixels[x], fillPixel, destinationWeight);
            }
            rowPixels += rowStridePixels;
        }
        break;
    }

    case kFillColorKeyBlend: {
        if (port->m_drawColor == 0) {
            return;
        }

        const unsigned char destinationWeight =
            static_cast<unsigned char>(
                static_cast<int>(port->m_alpha * 32.0f + 0.5f));

        for (int y = 0; y < height; ++y) {
            for (int x = 0; x < width; ++x) {
                rowPixels[x] = BlendRgb555(
                    rowPixels[x], fillPixel, destinationWeight);
            }
            rowPixels += rowStridePixels;
        }
        break;
    }

    default:
        return;
    }
}
