## Heuristic / Inference Reanalysis And Validation

1. Conversion direction:
   - Best inference: RGB565 input to RGB555-compatible 15-bit output.
   - Evidence: JPF/JPEG/PNG decoders explicitly construct 16-bit words as red 5, green 6, blue 5 before calling UID000200; UID000200 invokes the target only when `g_surfaceUsesRgb565Pixels` is false; target clears bit 15 and shifts the upper field down one.
   - Rejected: RGB555-to-RGB565, because the target removes one high-field bit and never creates a sixth green bit.
2. Exact bit semantics:
   - Binary fact: result is `(pixel & 0x001f) | ((pixel >> 1) & 0x7ff0)`.
   - Resolution: red bits 15..11 become 14..10; green bits 10..6 become 9..5; green bit 5 becomes destination bit 4; source blue bits 4..0 remain 4..0. Destination bit 4 is therefore the OR of source green bit 5 and source blue bit 4. Destination bit 15 is always zero.
   - Rejected: replacing `0x7ff0` with canonical `0x7fe0`. That would discard source green bit 5 instead of OR-folding it into blue bit 4 and changes outputs such as `0x0020` and `0x07e0`.
3. Count signedness and contract:
   - Machine fact: the 32-bit count is tested for zero, decremented with `sub`, and looped on nonzero. No signed comparison exists.
   - Best source inference: retain `int pixelCount`, matching the signed bounds differences/product at UID000200 and the surrounding SoftwareBlend16 `int` width/row/count convention.
   - Contract: valid callers provide nonnegative geometry. Zero touches no buffer. Positive N reads/writes N consecutive 16-bit words. Negative input is invalid; the machine would decrement modulo 2^32 until zero and overrun memory. A source rewrite using `pixelCount > 0` is rejected because it changes this binary behavior.
   - Alternative: `unsigned int` is ABI-equivalent and models modulo countdown, but is weaker as an original-source inference because the producer expression and family conventions are signed. This uncertainty caps perfection but does not leave the type unresolved.
4. Pointer and return types:
   - Accepted: mutable 16-bit unsigned pixel pointer and source `void` return.
   - Evidence: `movzx` word load, word store, two-byte stride, no meaningful return value, and caller stack cleanup.
   - Rejected: byte pointer, 32-bit pixel pointer, const pointer, or returned converted value.
