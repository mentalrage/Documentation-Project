- IDA prototype lead is `int __thiscall(char *this, char)`.
- Disassembly at `0x0059d2c0` is `movsx ax, [ebp+arg_0]`, proving a one-byte signed promotion into the 16-bit page calculation.
- All source callers pass exact values `-1`, `0`, or `1`; no caller passes a 32-bit domain value.
- Plain `char` is the strongest source form because the local project already uses plain `char` where the MSVC default signed-char ABI is intended. `signed char` is a valid runner-up but is less consistent with adjacent source style. `int` is rejected because it would not explain the byte load.
- Source return is `void`. The final instruction sequence calls virtual invalidation and returns its EAX byproduct, but all four call sites ignore EAX and adjacent source methods use `void` invalidation wrappers.
